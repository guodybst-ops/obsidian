# Khazix Skills

**GitHub：** [KKKKhazix/khazix-skills](https://github.com/KKKKhazix/khazix-skills)

这是一组可让 Codex 在对应场景自动按流程做事的技能。已安装：`aihot`、`hv-analysis`、`khazix-writer`、`leader`、`storage-analyzer`；`neat-freak` 原已安装。

| Skill            | 作用                     | 什么时候用／直接这样说                            |
| ---------------- | ---------------------- | -------------------------------------- |
| leader           | 把模糊想法写成可独立执行的任务书       | 任务大、需求说不清：`帮我给 agent 写个目标：……`          |
| neat-freak       | 项目收尾，核对代码、文档和 AI 规则    | 改完代码或交接前：==跑一下洁癖 或 /neat==             |
| hv-analysis      | 深度研究产品、公司、概念或人物，生成 PDF | 需要系统调研和竞品对比：`深度研究一下……，重点看……`           |
| khazix-writer    | 以「数字生命卡兹克」的公众号文风写长文    | 认可该写作口吻：`用 khazix-writer 把这份素材写成长文：……` |
| aihot            | 查询当天／近一周 AI 新闻与热点      | 要实时 AI 资讯：`今天 AI 圈最重要的 5 条新闻`          |
| storage-analyzer | 扫描磁盘占用，分级给出清理建议        | C 盘满、想找大文件：`帮我看看 C 盘为什么满了，只扫描别删除`      |

> 提示：skill 只在合适场景触发；直接点名最稳。安装后需在**下一轮对话**使用。
