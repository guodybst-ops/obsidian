# 小宇宙播客转写工具：新电脑部署说明

## 这份包里有什么

- `server.mjs`：本地网页工具，打开 `http://127.0.0.1:23100` 使用。
- `bin/xyz.exe`：读取小宇宙订阅、节目和音频链接的本地接口。
- `scripts/transcribe.mjs`：本地 Whisper 转写脚本。
- `public/index.html`：网页界面。
- `start-tool.vbs` / `start-tool.ps1`：后台启动脚本。
- `node_modules`：已打包好的 Node 依赖。

不包含你这台电脑的小宇宙登录 token、历史节目数据库、模型缓存和临时音频。新电脑要重新短信登录。

## 新电脑需要先安装

1. Node.js 22 或更新版本。
2. ffmpeg，并确认在命令行里运行 `ffmpeg -version` 能看到版本。

如果已经安装过 Node 和 ffmpeg，可以直接进入下一步。

## 推荐放置位置

最好把整个文件夹放在新电脑的 Obsidian Vault 里：

```text
Obsidian Vault/
  03_其他项目/
    小宇宙播客转写工具/
```

这样转写后的笔记会自动写入：

```text
Obsidian Vault/01_收件箱/内容/播客
```

如果你想把工具放到别的位置，可以给启动脚本设置环境变量：

```powershell
$env:OBSIDIAN_PODCAST_OUTPUT_DIR="D:\你的Obsidian Vault\01_收件箱\内容\播客"
```

## 启动方式

双击：

```text
start-tool.vbs
```

然后浏览器打开：

```text
http://127.0.0.1:23100
```

第一次使用时：

1. 输入手机号。
2. 获取短信验证码。
3. 登录小宇宙。
4. 点击“检查新单集”。
5. 需要自动处理新更新时，点“启用自动模式”。

## 开机自启

按 `Win + R`，输入：

```text
shell:startup
```

把 `start-tool.vbs` 的快捷方式放进去。以后 Windows 登录后，工具会在后台启动。

## 常见问题

如果页面打不开，先确认两个地址：

```text
http://127.0.0.1:23020/ping
http://127.0.0.1:23100
```

如果提示找不到 Node，请重新安装 Node.js，或者确认 `node -v` 能在 PowerShell 里运行。

如果提示音频转换失败，请重新安装 ffmpeg，或者设置：

```powershell
$env:FFMPEG_PATH="D:\你的ffmpeg\bin\ffmpeg.exe"
```

本地转写默认使用 `Xenova/whisper-tiny`，速度相对快，但准确率一般。想提高准确率可以设置：

```powershell
$env:WHISPER_MODEL="Xenova/whisper-base"
```

但 `base` 会更慢、更吃内存。
