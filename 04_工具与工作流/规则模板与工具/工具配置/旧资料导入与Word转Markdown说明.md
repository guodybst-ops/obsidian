# 旧资料导入与 Word 转 Markdown 说明

旧 Word、图片和历史资料已经统一归位。以后新增资料按以下流程处理。

## 推荐流程

1. 先列出要处理的一批旧资料。
2. Word / PDF 原件放入 `04_资料库/01_原始资料/旧资料导入` 或 `99_系统与归档/03_附件`。
3. 转出的 Markdown 放入 `04_资料库/01_原始资料/旧资料导入`。
4. AI 教育知识卡片放入 `02_AI教育/01_知识与研究/知识卡片`，其他知识放入 `04_资料库/02_其他知识`。
5. 能变成文章、报告或脚本的，放入 `05_内容输出`；尚未成熟的选题放入对应选题目录。

## 需要你确认

- 是否要批量转换根目录已有 Word 文档。
- 是否保留原文件原名。
- 是否按项目、时间、来源或主题分类。
