# 自动知识库入库规则

上级入口：[[⭐00_首页]] · [[99_系统与归档/02_规则模板与工具/入库规则/双向链接与层级规则|双向链接与层级规则]]

## 一句话原则

先判断资料是否服务于我的研究领域，再决定进入选题、知识卡片、参考资料、归档或忽略。

## 五项检查

1. 相关性：是否和 AI 教育、教育内容产品、创业验证、知识库建设有关。
2. 新鲜度：是否包含新趋势、新案例、新工具、新政策、新数据或近期变化。
3. 价值度：是否值得保存、引用、研究、复盘或作为决策依据。
4. 可输出性：能否转成文章、报告、视频脚本、课程、周报、项目方案。
5. 关联性：能否连接已有笔记、项目、概念、问题或输出。

## 判定结果

- `S 进选题池`：AI 教育选题放入 `02_AI教育/01_知识与研究/选题`；其他选题放入 `04_资料库/03_其他选题`。
- `A 做知识卡片`：AI 教育知识放入 `02_AI教育/01_知识与研究/知识卡片`；其他知识放入 `04_资料库/02_其他知识`。
- `B 存参考资料`：暂时只保留原文或素材，放入 `04_资料库/01_原始资料`。
- `C 归档`：已过时但可能有历史参考价值，放入 `99_系统与归档/04_历史归档` 或项目内部归档。
- `D 忽略`：和目标无关、重复、低质量或不可追溯，不进入正式库。

## 推荐路径

| 来源 | 默认入口 | 最终去向 |
| --- | --- | --- |
| 行业新闻 / 热点 / RSS | `01_收件箱/内容/自动抓取` | `04_资料库/01_原始资料/行业新闻` 或 `04_资料库/03_其他选题/选题池` |
| 深度文章 / 论文报告 | `01_收件箱/内容/自动抓取` | `04_资料库/01_原始资料/深度文章`、`04_资料库/01_原始资料/论文报告`，或提炼为知识卡片 |
| 网页文章 / 视频字幕 / 灵感内容 | `01_收件箱/内容/手动剪藏` | AI 教育内容进 `02_AI教育`；其他内容进 `04_资料库` |
| 小红书 / 公众号 / 社媒链接 | `01_收件箱/内容/手动剪藏` | `04_资料库/01_原始资料/社媒内容` 或 `04_资料库/03_其他选题/选题池` |
| 飞书文档 / 会议纪要 / 团队资料 | `01_收件箱/内容/自动抓取` | `04_资料库/01_原始资料/会议纪要` 或 `05_内容输出/内容/报告` |
| Word / 旧笔记 / Notion 导出 | `04_资料库/01_原始资料/旧资料导入` | `02_AI教育`、`04_资料库` 或 `05_内容输出` |
| 成稿 / 输出文章 / 视频脚本 | `01_收件箱/内容` | `05_内容输出` |

## 文件命名建议

`YYYY-MM-DD 来源 - 标题.md`

示例：`2026-07-07 GitHub - AI 出题工具调研.md`
