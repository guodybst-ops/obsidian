# 新笔记分类决策卡

上级入口：[[⭐00_首页]]

## 先记住一句话

**拿不准时，一律放 `01_收件箱/内容`。** 分类不是考试，先收集，再判断。

## 30 秒决定放哪里

按顺序问：

1. **这是刚收集、还没处理的东西吗？**
   - 是 → [[01_收件箱/00_入口|收件箱]]
2. **它主要是别人说的原文、报告、新闻、会议记录或证据吗？**
   - 是 → [[04_资料库/00_入口|资料库]]
3. **我已经把它提炼成一个可以独立复用的概念、观点、案例或方法了吗？**
   - 是 → [[04_资料库/00_入口|资料库]]
4. **它是一个需要持续研究的问题、专题、机会或内容选题吗？**
   - 是 → [[04_资料库/00_入口|资料库]]
5. **它已经有明确读者、用途或交付形式吗？**
   - 是 → [[05_内容输出/00_入口|内容输出]]
6. **它是在记录进展、结果和下一步吗？**
   - 是 → [[99_系统与归档/00_入口|系统与归档]]
7. **它是以后可以重复调用的规则、模板、提示词或自动化吗？**
   - 是 → [[99_系统与归档/00_入口|系统与归档]]
8. **它属于一个有目标、期限和交付物的正在执行事项吗？**
   - 是 → 对应项目；项目资料必须能回到项目索引。

## S / A / B / C / D 怎么用

| 判断 | 去向 | 最小动作 |
| --- | --- | --- |
| S 进选题池 | `04_资料库/03_其他选题/选题池` | 写清目标受众、核心问题、可能形式 |
| A 做知识卡片 | AI 教育内容进 `02_AI教育`；其他内容进 `04_资料库/02_其他知识` | 用自己的话写结论，并保留来源链接 |
| B 存参考资料 | `04_资料库/01_原始资料` | 保留来源、日期和一句话价值判断 |
| C 归档 | `90_Archive` 或项目归档 | 不再主动使用，但暂时保留 |
| D 忽略 | 不入正式库 | 没有持续价值，不继续加工 |

## 5 项评分不需要复杂计算

只要快速判断：

- **相关性**：服务 AI 教育、内容产品、创业或知识库吗？
- **新鲜度**：提供了新趋势、新案例、新工具或新政策吗？
- **价值度**：未来值得引用、验证或复盘吗？
- **可输出性**：能变成文章、报告、视频、课程或产品实验吗？
- **关联性**：能链接到已有专题、知识卡或项目吗？

有 4–5 项明显成立，优先 S 或 A；有 2–3 项成立，通常 B；只有 0–1 项成立，通常 C 或 D。

## 禁止继续制造的新目录

- 不再新建另一套“知识库”“模板”“图片”“待办”一级目录。
- 不用主题名做一级目录；主题进入专题地图。
- 不把代码依赖、构建文件和批量素材当作知识笔记。
- 不因为只有一篇笔记就建立三级、四级文件夹。

## 一条合格笔记至少有

- 一个明确标题。
- 一句话说明它为什么值得留下。
- 一个上级入口：专题、知识地图、项目索引或输出计划。
- 如果引用外部信息，保留来源。
