# 双向链接与层级规则

上级入口：[[⭐00_首页]] · [[04_资料库/02_其他知识/索引地图/知识库目录地图|知识库目录地图]]

这份规则用来保证新笔记不是孤岛。核心目标：每篇重要笔记都能被上级入口找到，也能反向看到自己服务于哪个专题、问题或输出。

## 1. 每篇重要笔记至少有 3 类链接

```text
上级入口：它属于哪个地图、专题或项目
相关概念：它和哪些概念、案例、方法有关
输出去向：它可以转成什么文章、报告、脚本或 MVP 记录
```

建议放在正文开头：

```markdown
上级入口：[[02_AI教育/01_知识与研究/研究专题/AI教育/AI教育专题地图|AI教育专题地图]]
相关概念：[[错题闭环]]、[[学习报告]]、[[AI 批改]]
输出去向：[[05_内容输出/内容/报告/AI教育/AI教育输出路线图|AI教育输出路线图]]
```

## 2. 不同类型笔记怎么链接

| 类型 | 必须链接 | 可选链接 |
| --- | --- | --- |
| 来源资料 | 专题地图、来源分类、可回答的问题 | 输出路线、竞品、概念卡 |
| 知识卡片 | 知识地图、来源资料、相关概念 | 输出路线、案例、方法论 |
| 专题笔记 | 总入口、知识地图、问题清单 | 项目文件、输出文件 |
| 项目文件 | 专题地图、待办、决策记录 | MVP、竞品、报告 |
| 输出文件 | 来源资料、知识卡片、专题地图 | 复盘记录、下一篇选题 |

## 3. 什么时候新建链接

需要新建链接：

- 出现核心概念，例如 `错题闭环`、`学习报告`、`知识图谱`。
- 出现重要竞品，例如 `StudyFetch`、`豆包爱学`、`师者AI`。
- 出现长期项目，例如 `Learning State Engine`。
- 出现可复用方法，例如 `MVP 验证`、`题目审查清单`。

暂时不新建链接：

- 只出现一次的普通名词。
- 没有后续研究价值的泛泛表达。
- 过细、过碎、无法复用的临时词。

## 4. 层级命名建议

```text
00 总入口 / 说明 / 背景
01 资料 / 输入 / 用户
02 概念 / 知识 / 结构
03 竞品 / 案例 / 对标
04 MVP / 实验 / 验证
05 输出 / 商业化 / 路线
06 复盘 / 决策 / 变更
```

旧文件不强制改名。新建重要项目文件时，可以参考这个顺序。

## 5. 和图片 5 层实现方式的关系

- 直接投喂型：允许没有双链，但处理后必须判断去向。
- 目录化知识库：至少放对文件夹。
- 索引地图型：必须链接到地图，这是当前重点。
- RAG / 向量检索型：必须保留元数据、来源、摘要和明确主题。
- 系统集成型：必须有稳定字段和流程，避免把混乱资料直接接入系统。

## 6. 最小合格标准

一篇 AI 教育相关重要笔记，至少应该满足：

- 能从 [[⭐00_首页]] 或 [[02_AI教育/01_知识与研究/研究专题/AI教育/AI教育专题地图|AI教育专题地图]] 走到它。
- 它自己能返回上级入口。
- 它说明自己回答了哪个问题，或能服务哪个输出。
- 它不只是一段原文，至少有一句“对我有什么用”。
