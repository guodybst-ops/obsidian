# 做了个 Skill，公众号文章秒变爆款短视频...

这是苍何的第 563 篇原创！     大家好，我是苍何。

昨天刚发布 WorkBuddy 实战蓝皮书的文章小火了一波，点赞转发都还不错。

![图片](https://mmbiz.qpic.cn/mmbiz_png/zw8bZHsVSaCTwPOHGnODVScmRnpPG1meUqyORQXsYX8vjD8MXJlwERKF16ShVwwQ7xTYo0l24rCiazhcGo1JWbAB8o27KTwSvmNTFsJicoHFQ/640?wx_fmt=png&from=appmsg)

我想着趁热打铁，快速的把这一篇公众号文章输出为短视频，然后去各发大视频平台。

但一想到做视频这件事，我就头大。

这种我感觉完全可以借助 Agent 来完成，于是我花了一些时间用 Codex + LibTV Agent 做了个 Skill，一键将公众号文章转为爆款短视频。

LibTV Agent 配合其中的 Seedance 2.0，视频整个效果会更好。

现在你可以在 LibTV 的 Skill 市场找到这个技能，名字为「公众号转爆款短视频」。

![图片](https://mmbiz.qpic.cn/mmbiz_png/zw8bZHsVSaBAvSvfeT4QQjGUVaH3EgibgxED42Hkia0otEdkX7Wu8feRupr29UibiaH7S8olCFJsmP8vjyb8aHLEjGrZrLkQVesMJFT6UiapeVzg/640?from=appmsg)

点击添加 Skill，然后将公众号文章 markdown 文件发给他，就摸摸的等待就好了。

如果你没有本地文件，也可以配合苍何的 canghe-wechat-article-extractor 技能，丢个文章链接就能帮你下载好文章到本地。

LibTV Agent 就会加载 Skill，读取文档和图片内筒，并将素材放到画布中。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/zw8bZHsVSaBQw1YEfmU0NepYFdB9JHNVKOS501Z36xPfmCib7910pr8BJv4xlELiaic8qIg4AxH39kbkLMSq7ooOYp5GjalFFjbbqV0GJzZv2s/640?from=appmsg)

这个技能需要你确认几个配置：画幅、时长、风格、配音、字幕、音乐、封面，当然你也可以都用默认的，Agent 会按照文章内容给你快速匹配。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/zw8bZHsVSaBzbhs6iat7SGqhVxtsyK7Gz3XsiagcAh0IIHLTeR29LibSNvwMng3YMqqgxwfhGo0zJgg3Pq0H3Hmu3SXV3cDib4wHvqRR24hKTNo/640?from=appmsg)

之后 LibTV Agent 会进入工作流，依次生成口播脚本，分镜，分镜会沿用公众号中的图片素材，具备更加的真实性。

![图片](https://mmbiz.qpic.cn/mmbiz_png/zw8bZHsVSaBGuQS8KEevdBHgZk7X2mQasKLXk2UOKQCKhPFT4eBPuCp3keQ4FXUuCsZLvAuuTCY4QiaaGgQX9x1vwElFiberHiaWk2B16udOJk/640?from=appmsg)

然后会生成视频封面，这个我设计的也是提炼了爆款视频封面要素，Agent 自动生成适合的爆款封面。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/zw8bZHsVSaArAoE7VMIPlRxIibQbILzv6IvN9niclCaj8sH396kqjdJBbiaOpphYEfXXF054EUz0y0bqicyBBibicuSZ1IbbVhvXwyZQ18vtXzXPE/640?from=appmsg)

最后生成配音和背景音乐，在画布中点击视频合成，可以对视频剪辑，当然也可以直接导出为成品视频，快速的完成创作。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/zw8bZHsVSaBQlGL5HZC2iajUibAoL1rAW5Qf8FKm2RNYcpcEBicphP28AXAGiaJcPQ4VSoStZxZBaUZC57RP27slIEicxY1XicP8q0KwskSAiaFia4c/640?from=appmsg)

这个 Skill 搞完后，我以后每次只需要传公众号文章进来，其他的我就什么都不用再做了，等着 Agent 帮我干活，直接发布就好。

确实很方便。

LibTV 大家都很熟悉了，之前主要是画布+节点那套专业工具链。现在有了 Agent，选一个 Skill，一句话描述需求，从剧本、分镜、配乐到成片全流程自动完成，出来的是能直接发的完整视频。

官网地址：liblib. tv

目前平台已经有 100 多个专业 Skill，广告、短剧、MV、自媒体基本都覆盖了。每个 Skill 背后都是专业创作者沉淀的方法论，选一个就相当于请了一位 AI 导演。

最后多说两句。

AI 视频这个方向，模型能力肯定是基础，画面不行一切白搭。LibTV 底层接了 Seedance 2.0 这些模型，生成质量本身是过关的。

但光有模型还不够。你给普通人一个再强的生成器，他也不知道提示词该怎么写、镜头该怎么编排、节奏该怎么卡。

Skill 解决的就是这个问题，把专业创作者的经验直接封装成可复用的能力，让模型的天花板真正被普通人够到。

对我来说，最实在的一点是，我把自己的创作流程沉淀成了 Skill，以后每篇文章转视频就是丢个文件的事。这个效率提升是实打实的。
