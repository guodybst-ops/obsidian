# 别再用 TUI 的 Claude Code 了

不要再用 TUI 的 Claude Code 了。

用下来真的是桌面端的 Claude Code 比 TUI 的更好用，之前用 TUI 是感觉它更轻量，而且我可以在一个 tmux 里 split 几十个 pane 来用，感觉非常方便。

甚至还可以随手就搓一个小插件可以用上，把 TUI 硬是用成了 GUI 的风格。

但既然这么做，那直接用 GUI 不是更好吗？

不需要 Ctrl+O 去展开命令的输出，对子 Agent 的查看、对于 Model 的切换、对 AI 正在查看的页面的情况、对指令的输入和编辑、不同 session 的切换/分组/排序等等，都非常的方便，比 TUI 好用很多很多。

所以我现在基本都不用 TUI 的 Claude Code 了，真用也就用 claude -p 来跑些任务。

不过也偶尔会有些奇怪的问题，比如 4.6 的 Opus 它是 200K，而不是 1M 的……

还有一个问题是，由于它的 session 是存在 claude-code-sessions//<账号>/<组织>下面的，所以一旦你切换某个账号、登录新账号之后，就看不到上一个登录账号的 sessions 了。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/ZKqVLiaIpzFkfgXjwX9qxnCyib7uPnic7r23f11JiaDicgiaic3hkgmMsibqwlssqgcmhnFiaKMWIdep4uRl2OPaXuicNmd3GWibKDBNCYoddcQJW4nbUw/640?from=appmsg)

本机用量（没算其他几台上的）     而我因为用量还算比较大，日常有三个 claude code 200$ Max 的账号在切换使用（还有几个 200$ 的 Codex），那么问题来了：切换了号之后怎么查看原来的 session 呢？

办法也很简单：让 Claude Code 自己解决就好！

直接给它说：

“    我切换claude code账号后好多session 都看不到了，请恢复一下

![图片](https://mmbiz.qpic.cn/mmbiz_png/ZKqVLiaIpzFnicC1GfibkIo6hBJPjCbnfgJzJiamePbjicaOpcc19wyZSziaIgniaibUXVOxfHAMupROjo7OBic8iaibQamkLzHqAW7ib2hJKOqVDVtq4PE/640?wx_fmt=png&from=appmsg)

让 Claude Code 自己解决     然后，就可以了。（需要重启）

但还是要注意话术……我特别担心他发现我多个账号轮流用，会给我把号封了。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/ZKqVLiaIpzFneEX8QwpxkGKXShTCj9Rqzp2z1aXUWRVxcZFa7b8eR8Tbk2BBSWp27iarRBs36a5M4zJPh0OsJ2X6XQpdh9AD1u5ofZibib2w1qQ/640?from=appmsg)

让 Claude Code 自己解决     而我有好多台 Mac，经常会在上面来回切换号。好在截至目前，我这几台电脑上还没有号被封过。

相比之下，Codex 就没有这个问题：退出登录之后，换一个账号再登也不会有，会话都还在。
