![图片](https://mmbiz.qpic.cn/mmbiz_png/0m9F5vC1OGiaia957Zp9Kx4yuibTiaVYYvnMibZbX5Vjpcfoo8y5Vj7bibo7wic6a2ibymgbLGsIsUib0tsHia9C30vAmvqoA2sfiaUUxS4xUcBZtfltwU/640?from=appmsg)

粘贴JSON内容如下：

{
"mcpServers"   : {
"better-godot-mcp"   : {
"command"   :    "node"   ,
"args"   : [
"/Users/dracohu/.kimi/tools/better-godot-mcp/bin/cli.mjs"
],
"env"   : {
"GODOT_PROJECT_PATH"   :    "/Users/dracohu/REPO/word-adventures"
}
}
}
}

当然，文件目录请根据实际情况填写

然后，让Qoder确认是否已经通过MCP连接上了Godot引擎 ... ... OK ! done！

##  体验小结
目前Preview版本的Qwen3.8 Max和Fable5的确还是有差距的，主要差距在于任务的规划能力上还没有办法做到“你只要把需求讲清楚，就一次性高质量完成”这个程度，中间基本需要tune几轮做校正。

当然，当你的需求精准时，代码质量和完成速度是相当不错的。

并且对于新项目和中间接手的项目都能保持较高的稳定性和准确度。

整体而言，Qwen3.8 Max Preview这个版本给我的感觉和Grok4.5非常像，非常快。

对于绝大多数人而言，Qoder+Qwen3.8-Max-Preview，绝对是绰绰有余了。

当然，这是Preview版，希望Qwen3.8 Max在正式版时能有更出色的表现~
