# Fable 5 再次续命到 19 号

又来了……

![图片](https://mmbiz.qpic.cn/mmbiz_png/ZKqVLiaIpzFml6ibwHs8xaDTelIolIYWaob9zQw5Je0UATbUKe3wTDgnCQicy0icA94aFZibBKqZqJj2Cbw4uB8XHHJZ193SqLWibGBq6hZNLQtzQ/640?wx_fmt=png&from=appmsg)

Claude 刚刚官宣：   Claude Fable 5 在所有付费计划上的访问权限，延长到 7 月 19 日   。同时，还将 Claude Code 每周速率限制还提  高了 50%  ，且一并保持到19 号。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/ZKqVLiaIpzFm2vS1ibXs0jZ9hUiaibuGsVuckIQ80wicUEtn1qtkr8kNjjnV9eGu23dw6ichRwfO5LL8X0iaBKpBZWhr1EyCY7gDCAIePVYuuFPgjQ/640?from=appmsg)

官方公告推文     用量多了，但用法和之前一样：

每周额度里，最多可以有一半花在 Fable 5 上。用完了这一半，要么上 usage credits 接着跑（这个走的是按量付费，花的是真钱），要么切回其他模型，省着点用剩下的额度。

![图片](https://mmbiz.qpic.cn/mmbiz_png/ZKqVLiaIpzFkFjb1lHibWrKDAIymc1byPGmw6ZO6JLTicSNVY8yico9SSHomVXClnmY0Mlia9Nm4MlOQbL1iboafPh8zmGRicOj2yHeES7G0LU4icyc/640?from=appmsg)

50% Fable     对我等天天被周限额卡脖子的 Claude Code 用户来说，多的这 50% 额度就当反复放鸽子后的一点小补偿吧（虽然再多的额度，也是不够用的）。

而这，已经不是第一次延了。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/ZKqVLiaIpzFnAA0bje0jJTXYF7E8D2DuMmfbBqpBtdOf7NJvaQQGOfNjAE2iauhZLpDkSuLicDic73liaK7hDv6BXrkQUURPdZKMFMjb1iagLkSP8/640?wx_fmt=png&from=appmsg)

无限续期     按最初的说法，6 月 23 日 Fable 5 就该从订阅里移除、改成纯按量付费，结果先是延到了 7 月 12 日。

然后一看 GPT 5.6 要发布了，索性就再延两天，看看 5.6 会不会造成威胁。

而 OpenAI 这边，则还在疯狂更新 ChatGPT（Codex） 的各种体验和新功能，同时还派出大军直接杀进了自己家里：

官方人员周末加班，教给网友们如何在 Claude Code 里使用 GPT-5.6-sol，并亲切地取了个 claudex 的小昵称。

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/ZKqVLiaIpzFkePlic1nov6s4Xu1eic6Rul0ANAHnXCwczHcAgfPUALmtbnibRU9B62mfTyPVFFFw0J5KQ7RePXVnL7u9QDyhEsI8NSRCdzRROOA/640?from=appmsg)

在 Claude Code 中使用 GPT-5.6     所以，在 12 日即将结束的今天，  还没有看明白 5.6 到底行不行的   Claude 只好无奈再次官宣续上一周，到了 19 日。

真的是一次一周，到时再议。（不知道这叫敏捷，还是应该叫草台……）

![图片](https://mmbiz.qpic.cn/mmbiz_png/ZKqVLiaIpzFkovbfXK2icwkzvO0OZAKTh5DHrjl41o9mMlwThlgPSPSWygBpJ2HmzxiaT0XFYujkNBeHwVBNl8V8WSmG0vz3rOuBgOHPRm8RBE/640?wx_fmt=png&from=appmsg)

而这波滚动续期，到底要滚到什么时候呢？

官方之前给过的口径是：   产能充足后，会重新把 Fable 5 纳入订阅   。在那之前，可能还得这么一周一周地续着。
