# 试了腾讯首个设计 Agent-Miora，彻底回不去了！

这是苍何的第 566 篇原创！     大家好，我是刚从 WAIC 回来  累麻了  的  苍何

上午刚回武汉，就看到各大群都在讨论腾讯的 Miora。

于是本来想好好躺会的我，又咔咔起来，猛猛测评。

Miora （腾讯设计妙境）是腾讯新出的首个设计 Agent 平台，能覆盖从 brief 到交付的完整创意流程。

![图片](https://mmbiz.qpic.cn/mmbiz_png/zw8bZHsVSaCwxxUDwibqq5wEBgK2WsWSK2CAXsTLtJ7oSc1gIL9380DzaqqJsFyDZpdtiaNh16XfZZxHPrWxAEO6cH1zBeh2xnAyCxcQiaS8lQ/640?from=appmsg)

今天官宣全量发布了，要知道之前都是需要邀请码，而且还需要排队。

我感觉非常像是创意版的 WorkBuddy，毕竟 Miora 也是 WorkBuddy 团队做的。

前两天还在 WAIC 跟朋友唠，说 AI 做创意这事儿最麻的就是切平台，出图一个工具、剪视频一个工具、做网页又是另一个工具，一天下来光切窗口就切麻了。

Miora 我觉得是专门为创意场景打造的。图片、视频、网页，全在一个画布里搞定。就很方便。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/zw8bZHsVSaCLHfOL3MKI0fptv4906MxGJ70qnIDbYTuazyqG0uicqvKFgicvtO1Q3ibt1UlPJb4ibFhllg8XnG7uEeVjkfzvoRcTN3AK6ib6rJ2s/640?from=appmsg)

不瞒你说，我的这个鸣人的头像，在很多场景都不能用，我一直很想有一套自己的 IP 形象，当然我也尝试过各种办法，朋友塔塔甚至还帮我定制过一次形象。

但终归还是得按照自己的想法自己设计，毕竟没人比你更懂你究竟想要啥。

于是我让 Miora 给苍何这个 IP 出一整套全案，从 0 到 1，也算是测评下 Miora。

![图片](https://mmbiz.qpic.cn/mmbiz_png/zw8bZHsVSaD2got4J4rHr0xBxtqGpjgguDw0awrjzjfoEGsx93HXKolZMQZQoe8YmgFibIrzqOgE3Uydb2eia8lUAUZm9jkWRk6FKb74sjgx0/640?from=appmsg)

到这一步，图这块就算稳了。

接着就是视频。

我直接把大白话丢给它，选中两张图，作为首尾帧，帮我生成一段自然过渡的视频。

感觉提示词有点糙，我点了下右下角的「润色提示词」，大白话立马被翻译成了完整版。而且从流程里能看到，它调的是 audio-video-agent 这个 skill 来干活。

●    ●    ●     请根据我选中的这两张图像生成一段视频，将上传的两张图像分别作为视频的首帧和尾帧。要求：1）实现自然流畅的过渡效果；2）过渡过程平滑、无明显跳跃或断裂；3）保持画面连贯性和视觉舒适度；4）过渡时长适中，符合观看体验。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/zw8bZHsVSaBicogg80Q9LDSg3MlbP85PoIGfUBglS5mBBkNTkJ3Oibibm1HXvAGmH9tntNCA0RcE9ZLm9vG8ibRXLB3iaZQcibIZThw2iaZibhf13zg/640?from=appmsg)

更骚的是，Miora 自带多模态调度。

模型让它自动选没问题，你也可以自己指定，很灵活。

![图片](https://mmbiz.qpic.cn/mmbiz_png/zw8bZHsVSaAic9rz5AFdWDzmX7n8jMjSFGK1GqhQv73k21P6kSm0lHIGGVSxSYhDwIUL7SRSww3xVq9TYoRicEvDhaaia7IPOW0fJA0iaUBH77w/640?from=appmsg)

来看下过渡效果，我觉得挺自然。

视频搞完，我顺手让它再生成一个网页。

真香。

跑完这一整套流程，我发现 Miora 还可以把整个链路沉淀成一个 skill，还能一键发到市场里。

![图片](https://mmbiz.qpic.cn/mmbiz_png/zw8bZHsVSaAls8w2ggiakmIxdYt2zFsSB5oxmdx0CRISAIKbKNUknry16gh6mcyajvpqMOS9nI0wdCSQmXoVr2f2c1vdS6CoZDDibibfGdtGYo/640?from=appmsg)

这意味着你踩过的每一次坑、跑通的每一套流程，都能沉淀成可复用的资产。

除了 IP 设计，还有一个我很在意的点是游戏场景。

以前自己搞游戏设计的时候真的头大。灵感总在半夜三点乍现，一熬就是通宵，第二天顶着黑眼圈继续搬砖。

现在我把提示词丢给 Miora。，选着「互动游戏」这个 skill。

●    ●    ●     创建一个像素风横版动作游戏第一关场景：黄昏森林。场景包含橙红色夕阳光照、茂密古老森林、远近分层树木、雾气    与光影效果。设计适合平台跳跃与战斗玩法的关卡布局，包括地面平台、高低差地形、隐藏路径、危险障碍物、碰撞区域、起点入口和终点出口。输出独立资源层：远景视差背景、中景装饰层、前景互动层、平台与障碍物组件、碰撞体数据、关卡连接点。保持经典   16   -bit像素游戏风格，清晰轮廓，适合横版动作冒险游戏开发。

![图片](https://mmbiz.qpic.cn/mmbiz_png/zw8bZHsVSaCN1xAkSiaK3sKSH9Wx02sxlkepq7evmxoY0VtXeSByK9ia5lk4yxf8F1xGJ4khgNOqc9GPnba58ibj5dSmkzeMiaIN7m7rYFWzgiaY/640?from=appmsg)

它是分层来干的，远景、中景、近景、前景遮挡层，一层一层拆着生成。

每一步都能单独调，这个思路很专业。这就是 skill 的强大之处。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/zw8bZHsVSaBobvTe1cohTkbLYrVnv8quSU5lV7TK7RsdyfclZ4sBfo9iaibrN5tR6jCWYFLtvHNSqS9fGUuJ4icicoy9HseFvScWAVFURpA5piaQ/640?from=appmsg)

能。

但真正让我觉得它「不太一样」的，是记忆功能。

你可以把自己的习惯、工作流、项目都喂给它。Miora 不只是记得你用过什么，它更记得你怎么创作。

每一次协作，它都在学你的审美、你的品牌规范、你的手感。

用得越久，它就越懂你。

![图片](https://mmbiz.qpic.cn/mmbiz_png/zw8bZHsVSaCrI7Qx72FGgS8OcVZyOrWNT2Y71m4QaOVEmDy7F52dGm5UH5v94mS7olhPwrA1DrEx2hotUQc43WDHEmWoq2HKtDaehQIa2M0/640?from=appmsg)

以前做一个完整创意，从灵感到成品，中间隔着一堆工具、一堆流程，还有无数次重复修改。

但现在，你只需要先把脑子里的那个想法说出来。

剩下的事情，AI 会陪你一起往前推，它正在成为每个创作者身边那个随时在线的搭档。

到最后你会发现，会用 AI 只是入场券，真正拉开差距的，是你脑子里的想法够不够多、够不够好。
