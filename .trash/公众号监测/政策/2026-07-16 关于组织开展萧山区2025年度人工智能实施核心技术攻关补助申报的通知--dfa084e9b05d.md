# 关于组织开展萧山区2025年度人工智能实施核心技术攻关补助申报的通知

为落实《关于促进人工智能产业创新发展的若干政策（2025版）》（萧政发〔2025〕35号），支持人工智能产业创新发展，构建人工智能产业生态，进一步助力萧山打造人工智能产业创新发展高地，现组织开展补助申报，有关内容及要求通知如下：

![图片](https://mmbiz.qpic.cn/sz_mmbiz_gif/wzCiczzSSVKuN6KM5uibqB9KqyB0hAibOSF8YakYmfIu0quPsh6K1gT6MztfX0cVLRNVEtcBsbJ3LZYz9SuEgUhzkbX7TaOKFbke2q2CLMUczU/640?wx_fmt=gif&from=appmsg&tp=wxpic&wxfrom=5&wx_lazy=1#imgIndex=2)

一、适用范围

本政策适用于在萧山区合法经营，财务管理制度和会计核算体系健全的企业。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_gif/wzCiczzSSVKuT8kdBdRC8MrN1YG1sXk5SrrJcZqJAeiawhFZSpRayTuPDJYNwzjYBIhaaLbXoaz9gSXHwh69x7TiaN6laZwlKvzibmYRLaPibPkk/640?wx_fmt=gif&from=appmsg&tp=wxpic&wxfrom=5&wx_lazy=1#imgIndex=3)

二、支持内容

实施核心技术攻关。     鼓励针对人工智能关键技术开展研发攻关，支持申报国家、省、市各级科技计划项目。对符合政策规定的项目，按照国家、省实际到账资助经费的30%给予补助，最高不超过5000万元。

![图片](https://mmbiz.qpic.cn/mmbiz_gif/wzCiczzSSVKvk3dWH5pYDxW9lKjvrAOiaQWHHfAiccqJmkYsLf6JPK0gFZNbWfRDM0jXFLtK3evibTPzy2fP2rQwHaWffaIyqTlU1wlXgOkvc14/640?wx_fmt=gif&from=appmsg&tp=wxpic&wxfrom=5&wx_lazy=1#imgIndex=4)

三、申报流程及条件

核心技术攻关补助

0    1

【申报要求】

1.申报项目：2025年1月1日至2025年12月31日期间，实际获得国家、省级科技计划项目资助的。

2.申报单位：承担国家、省级科技计划项目的萧山区范围内注册登记并纳税的企业。

0    2

【申报材料】

1.国家、省级科技计划项目立项文件、项目任务书（课题任务书）；

2.当期项目经费拨款通知单、银行入账凭证等。属项目牵头承担单位，需提供国家、省级财政补助资金分配方案以及资金外拨至课题承担单位（参与单位）的拨款凭证；属课题承担单位的，需提供牵头承担单位的拨款通知单、银行入账凭证等；属项目参与单位并接受课题承担单位拨款的，需提供课题承担单位的拨款通知单、银行入账凭证等。

0    3

【  申报截止日期  】

7月31日17:00

0    4

【受理单位】

萧山区科技局科技促进科

电话：    0571-89619174、     0571-     89618912

0    5

【申报流程】

纸质材料提交至金城路685号萧山区行政中心综合楼529办公室89618912,所有材料电子稿发送至邮箱395612729@qq.com。申报材料包括：

国家、省级重点研发项目立项文件、项目任务书（课题任务书），当期项目经费拨款通知单、银行入账凭证等。属项目牵头承担单位，需提供国家、省级财政补助资金分配方案以及资金外拨至课题承担单位（参与单位）的拨款凭证；属课题承担单位的，需提供牵头承担单位的拨款通知单、银行入账凭证等；属项目参与单位并接受课题承担单位拨款的，需提供课题承担单位的拨款通知单、银行入账凭证等。

如项目有涉密内容，申报单位需对申报材料进行脱密处理并进行审查后，将书面材料提交至上述地址。
