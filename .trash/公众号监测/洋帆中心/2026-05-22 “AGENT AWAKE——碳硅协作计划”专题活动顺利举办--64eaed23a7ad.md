# “AGENT AWAKE——碳硅协作计划”专题活动顺利举办
![图片](https://mmbiz.qpic.cn/mmbiz_png/ulAa9rpfQT3RHJ3IyPIqsRm7gHRv6v873hdiaVcDRxm6Zvjl4OlWcc6EBjKkCVlOWVeVepaFFU8fuMZGagSTGEu7fFMZFt6iaTJgPK880kEHM/640?wx_fmt=png)

为进一步推动人工智能技术在园区企业办公场景中的应用，助力企业提升数字化、智能化办公水平，5月22日，   “AGENT AWAKE——碳硅协作计划”   专题活动在洋帆中心顺利举办。活动围绕 AI Agent 工具的实际应用展开，吸引园区企业代表及相关从业人员参与。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/eEZkWHhHdTVQW7zl78dCsjqCpPicIRicHKkib1IibZfZHDMo2pLzC9QCahSic3gQmD1JAvFBwP58Hk2LRDmMrCTUXuXcTPNpdHNr0icpDJgg9a9Kg/640?wx_fmt=jpeg)

本次活动聚焦腾讯云 WorkBuddy 的安装配置与场景化使用，现场工作人员从基础操作入手，系统讲解了 WorkBuddy 的安装流程、功能入口及使用方法，帮助参会人员快速了解 AI Agent 在日常办公中的应用方式。

活动还围绕实际办公需求，重点演示了如何通过 WorkBuddy 辅助制作小程序、检索所需 Skill、调用相关能力完成任务处理等内容，使参会人员对 AI 工具在内容生成、流程协作、效率提升等方面的作用有了更加直观的认识。

此次活动以实际操作为导向，进一步降低了园区企业接触和使用 AI Agent 工具的门槛，为推动人工智能技术融入园区办公场景提供了有益探索。下一步，洋帆中心将持续关注企业数字化转型需求，链接优质技术资源，开展更多面向企业实际应用的交流活动，助力园区企业提升创新能力与办公效能。
