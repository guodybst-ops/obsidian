#   倒计时9天！最高1500万补助！余杭区2026年 “海创未来” 人工智能专项评审征集进行中！
杭企之家     2026年7月20日 20:09       浙江     听全文

根据《关于推动经济高质量发展的若干政策（2025年版）》（余政发〔2025〕3号）、《余杭区“海创未来”高层次人才创新创业项目扶持政策指导意见》（余人才办〔2024〕1号）文件精神，余杭区委人才办将于 2026年     8月初     举办余杭区“海创未来”领军人才项目人工智能专项评审，现面向全球开放项目征集，大家一起来报名吧！本轮评审线上申报截止时间为    7月29日17:00    ，我们将根据报名情况适时开展专家评审，逾期或过数的将自动排入下批评审计划。

一

申报条件

（一）申报项目要求为海内外高层次人才领衔，符合余杭区产业导向且落地时间不超过2年的创新创业项目。

0    1

项目应重点聚焦“人工智能+”等前沿赛道，推动人工智能与具身智能、低空经济、类脑智能、新材料、生物医药、高端装备、智能纺织等领域深度融合。项目须拥有核心自主知识产权或关键技术壁垒，具备显著的产业化开发潜力。

0    2

项目企业需具有健全的财务管理制度和会计核算体系。

0    3

项目建设必须符合低碳减排、环境友好等条件。

0    4

主申请人全职创业（主申请人为高校教师或科研院所研发人员的，其联合创始人全职创业），应为企业主要创始人、第一大股东或最大自然人股东，在创业项目中出资占比15%以上。

（二）主申请人条件

领军人才

符合以下条件之一：

●     一般应获得博士学位，在海内外知名企业、高校、科研机构担任高级职务或副教授及以上的技术、管理人才。

特别优秀的可放宽学历等，具体和工作人员咨询确认后申报。

●     市级或区级C类及以上人才或相当层次人才。

杭州市人才分类认定可通过“杭州市高层次人才分类认定申报管理系统（https://rc.hzrs.hangzhou.gov.cn/）”进行申报认定；余杭区人才分类认定可通过“余杭人力资源服务系统（https://yhrlzyfww.hrss.hzyuhang.cn:11446/）”进行申报认定。

优秀人才

一般应获得博士学位，回国时间不超过5年，且符合下列条件之一：

●     在海外高校、科研机构或企业有正式职位工作经历。

●     有海外创业经验。

特别优秀的可放宽学历等，具体和工作人员咨询确认后申报。

二

扶持政策

（一）领军人才领衔项目政策

0    1

入驻三年内，可享受最高1200万元研发补助；

0    2

入驻三年内，可享受最高300万元工作场所租金补助；

0    3

3年内可享受最高本金1000万元贷款贴息资助，按上年最后一期LPR一年期利率的50%给予补贴；

0    4

可享受政府产业引导基金支持，可申请最高1000万元的天使引导基金；

0    5

可享受每年2万元的服务券补贴。

（二）优秀人才领衔项目政策

0    1

入驻三年内，可享受最高600万元研发补助；

0    2

入驻三年内，可享受最高150万元工作场所租金补助；

0    3

3年内可享受最高本金500万元贷款，按上年最后一期LPR一年期利率的50%给予补贴；

0    4

可享受政府产业引导基金支持，可申请最高1000万元的天使引导基金；

0    5

可享受每年2万元的服务券补贴。

优秀人才项目晋级政策：     项目企业累计获得创投机构投资额达2000万元及以上的，或自主培育国家级、省级领军人才及以上人才的，优秀人才项目政策可晋级为领军人才项目政策，总计不超过1200万元研发补助和300万元房租补贴，晋级时间以相关纪要为准。享受晋级政策的，每年享受研发补助金额不超过600万，房租补助金额每年不超过150万。

具体政策以相关政策实施细则为准。

三

申报流程

（一）领军人才项目

“领军人才项目”实行“平台推荐+集中评审”遴选机制，具体流程如下：

0    1

项目申报

常态化受理项目申报，由项目方登录余杭人才项目全生命周期管理系统进行申报。产业平台、镇街参照“领军人才”项目标准做好日常人才项目引进工作。对符合条件的申报项目做好推荐。

0    2

专家评审

根据项目推荐情况适时开展领军人才项目专家评审会，按产业类别邀请相关领域专家组成评审组，坚持公开、公正、公平、择优的原则，对项目进行集中评审。

0    3

项目公示

根据专家评审意见，项目遴选结果将在“余杭先锋”微信公众号进行公示。

（二）优秀人才项目

“优秀人才项目”实行“标准化认定”遴选机制，具体流程如下：

0    1

项目申报

常态化受理项目申报（操作流程见下）。

02

审核

对“优秀人才”项目的申报人选的资格条件、申报资料的真实性、完整性进行形式审查。

03

实地走访

对符合条件的落地项目进行实地走访核查。

04

集体审议

根据走访核查情况等进行集体审议，对通过审议的项目给予政策支持。

四

申报入口及操作说明

（一）申报入口

（1）     申报地址：     项目方请于PC端进入“余省心”企业（人才）综合服务平台（https://www.ysx.com.cn/），并在特色应用板块点击余杭区“海创未来”高层次人才创新创业项目征集模块。

欢迎有意向人才与产业平台（镇街）工作人员取得联系，在专员辅导下完成申报，并提供项目申报所需信息及证明材料。

（一对一免费辅导）

1.     申请人提交的相关信息和材料应当真实、准确、有效，其中所涉的技术知识产权明晰，凡提供虚假申报材料的、或有其他不当行为的，一经查实，将永久取消项目及相关申请人参评资格，并保留进一步追究相关责任的权利。

2.     申报材料中的相关经济指标需如实填写，通过遴选的项目落地后将与落地平台签订《企业发展任务书》。《企业发展任务书》将作为后续项目政策兑现依据。

3.     最近一次领军人才项目评审将于8月初开展，具体评审时间将通过电子邮件及联系人电话另行通知，请填报准确的联系信息。

4.     本次项目征集的最终解释权归区委人才办所有，项目信息一经提交，即视为同意上述规则。
