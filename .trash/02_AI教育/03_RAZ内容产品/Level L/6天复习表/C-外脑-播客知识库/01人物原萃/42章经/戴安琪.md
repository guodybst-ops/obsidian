# 戴安琪

> 基于 42章经 045 集提炼。不是语录合集，是可调用的思维框架。

## 画像

- **身份**：某科技家办 VP
- **背景**：在科技家办负责 BD 与 sales，核心任务是把资金引入家办。大学时曾写下希望成为"中外交流的桥梁"
- **标签**：BD 实战派 / 科技家办 VP / 长期主义销售 / 真诚增信

## 擅长 & 不擅长

- **擅长**：高净值客户的 BD 全流程操作（从线索到持续经营）；向上社交中的真诚增信策略；将 BD 拆解为可执行的五阶段步骤
- **不擅长**：产品型 PLG 增长（她的方法论建立在深度关系和信任上，不适用于大规模自助式转化）；不确定是否适用于家办/金融之外的 BD 场景；数据不足——仅一集播客

## 核心心智模型

### 模型1：BD 五阶段漏斗

- **一句话**：BD 是一个从线索确认到持续经营的完整漏斗，每阶段都有核心动作和信号。线索确认→建联→增信→转化→持续经营，其中增信不是单独一个环节，而是贯穿所有环节的底色。
- **来源**：[[42章经]] 045 — 全流程展开 [归纳]
- **怎么用**：
  1. 线索确认：先画客户画像（什么人、在什么圈层、有什么需求）和渠道伙伴画像（谁能接触到这些人、谁愿意转介绍）
  2. 建联：目标客户之间的转介绍是最强线索。判断转介绍的两个关键：你是谁（让人能一句话说清你的价值），介绍人是谁（意愿度 > 资源数量）
  3. 增信：头像、朋友圈、建联话术、会面安排、送别细节、后续反馈——所有触点都在传递"你是谁"
  4. 转化：成交 = 需求匹配 × 信任到位。如果对方需要的不是你有的，主动介绍给更合适的人
  5. 持续经营：想清楚你是谁、你要什么、你愿意付出什么代价。只有目标与自我认同一致，BD 才不会变成消耗
- **局限性**：这个框架假设你有充足的时间做深度关系建设。在短周期、高频次、快速转化的场景（如电销、电商）中不适用。五阶段在理论上是完整的，但每个阶段都有大量"知道但不一定能做到"的细节——比如增信的具体执行高度依赖个人情商和判断力，难以标准化传授。他没有提供"失败了怎么办"的案例，所有论述都偏成功经验的总结。

### 模型2：价值二分法——经济价值 vs 情绪价值

- **一句话**：价值只有两类，经济价值是人脉和专业能力，情绪价值是让对方觉得舒服、可信、被理解。很多厉害的人是理性判断但感性决策——当专业差异没有本质区别时，情绪价值成为决策关键。
- **来源**：[[42章经]] 045 — 核心框架 [归纳]
- **怎么用**：
  1. 分析你面对的交易或关系：经济价值的边际增量是多少？情绪价值的边际增量是多少？
  2. 如果专业差异没有本质区别（经济价值趋同），把所有精力放在情绪价值上——真诚、谦逊、让对方向你倾诉
  3. 向上社交时的关键：不要在比你拿到更大结果的人面前秀小聪明。真诚和谦逊是起点
  4. 把废话说好是一项高级技能——有人天生就会，但多数人需要刻意练习
- **局限性**：情绪价值的衡量是主观的——什么叫"让对方舒服"可能因人而异。过度追求情绪价值可能变成讨好和失去自我边界。二分法在极度强调理性决策的领域（如量化投资、法律合规）可能不适用。她对这个模型的展开缺少"情绪价值做过头了会怎样"的边界讨论。

### 模型3：长期主义 BD 的三问

- **一句话**：持续经营的根本问题是三问——你是谁，你想要什么，你愿意付出什么代价。只有三者一致，BD 才不会变成消耗自己的短期行为。
- **来源**：[[42章经]] 045 — 她用自己的经历验证（大学时写下的初心与今天的工作一致）[归纳]
- **怎么用**：
  1. 第一问：你能一句话讲清楚你为别人提供的价值吗？不够清楚意味着线索质量和转介绍率低
  2. 第二问：你真正想要什么？赚钱/理想/证明自己？不敢承认真实目标，BD 行为会被伪目标牵引
  3. 第三问：你愿意为这个目标放弃什么？如果一个客户需要的不是你的核心方向，你敢不敢不接？
  4. 每季度回溯三问，确保 BD 行为与三问一致
- **局限性**：这个框架极度依赖自我认知的准确性。大多数人高估了自己对"我想要什么"的清晰度。三问对已经在职场上建立了明确方向的人有效，但对还在探索阶段的人（如早期创业者）来说，三问本身可能就是把客户推远的武器。她以自己为案例（大学时就有清晰目标），但这是幸存者偏差——很多人的初心是在试错中逐步浮现的。

## 决策启发式

1. **先画客户画像再行动**：不是因为"认识更多人"就能做成 BD，先搞清楚你要找的人存在于什么圈层、谁可以搭桥 — [[42章经]] 045
2. **转介绍人 > 资源数量**：一个愿意把人介绍给你的中间人，比一百个只是认识客户的中间人更有价值。意愿度比资源数量更重要 — [[42章经]] 045
3. **最消极的反应不是反驳，是不说话**：对方有反应就有机会，没反应意味着需要换个切入角度 — [[42章经]] 045
4. **不要每个客户都想要**：如果你没有对方真正需要的能力，主动把机会让给更合适的人。短期少一单，长期多一个人信任你 — [[42章经]] 045
5. **经济价值拉不开差距时，拼情绪价值**：很多厉害的人本质上理性判断感性决策 — [[42章经]] 045

## 内在张力 / 盲区

1. **真诚的工具化悖论**：她强调"真诚和谦逊是向上社交的起点"，但如果真诚是一种刻意为之的策略（为了增信），它还能被定义为真诚吗？这个矛盾她没有讨论——如果对方察觉到这种"真诚"是策略性的，增信效果可能反向。
2. **长期主义与业绩压力的张力**：家办 VP 有获客 KPI，长期主义三问在实践中能否和短期业绩压力兼容，她没有给出具体回答。
3. **信息源密度**：仅一集播客，全部内容围绕 BD 方法论展开，缺少对失败案例、客户流失、竞争压力等维度的讨论。她说的"有效"没有独立验证。
4. **领域偏见**：她对 BD 的理解高度绑定在高净值客户的深度关系型销售上。对 SaaS 的 PLG 模式、内容营销、社媒获客等方式没有讨论空间。
