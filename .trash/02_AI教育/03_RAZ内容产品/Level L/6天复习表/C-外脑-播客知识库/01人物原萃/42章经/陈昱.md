# 陈昱

## 画像

- **身份**：云启资本合伙人
- **背景**：本科计算机，芝加哥大学 MBA，前 Google 软件工程师 → 创业公司 CTO → 2014 年加入云启，长期聚焦 ABC（AI、大数据、云计算）赛道
- **标签**：Soft-Tech Specialist / 技术型 VC / 早期捕手 / 工程师出身投资人

## 擅长 & 不擅长

- **擅长**：技术赛道的早期投资——能看代码、理解技术演进、在共识形成前识别有潜力的技术团队；判断创始人"能不能把难问题做出来"
- **不擅长**：消费、SaaS、产业互联网等非软科技赛道（他自称从不追这些热点）；频繁切换行业覆盖面的 generalist 打法；对非技术驱动的商业模式创新判断力不足

## 核心心智模型

### 模型1：Specialist 路线（先选赛道，再找项目）

- **一句话**：不追热点轮动，而是提前选定一个技术赛道持续跟踪，等赛道里出现好项目和好团队时再出手。技术判断力来自长期浸泡，不是靠社交热闹。
- **来源**：[[42章经]] 002 — "很多时候不是来一个项目马上判断该不该投，而是先选择了一个赛道。" [原话]
- **怎么用**：
  1. 选定一个有底层技术演进逻辑的赛道（如开源数据库、大模型）
  2. 持续跟踪该赛道的技术变化、论文进展、开源社区动态，比市场提前建立认知
  3. 等赛道中出现具体项目时，判断是否踩在正确的技术方向上
  4. 再评估团队是否有能力把难问题做出来
- **局限性**：前提假设是你选的赛道是对的——这意味着你要有能力判断底层技术方向，而这是不可验证的事前赌博。他承认 98% 靠运气，暗示自己并非总能选对。如果你选错了赛道，长期聚焦只会放大沉没成本。该模型对软件/技术赛道适用，对消费/平台型赛道无效。

### 模型2：AI 三波浪潮判断框架

- **一句话**：AI 十年有三波：CV/视觉 AI（2013-14）→ 自动驾驶（2016-17）→ 大模型（2022-23）。每一波的底层技术突破不同，但长期跟踪技术演进的人能在新一波到来前理解其意义。
- **来源**：[[42章经]] 002 [归纳]
- **怎么用**：
  1. 画一个技术演进的 timeline——过去 10 年出现过哪些大的技术浪潮？
  2. 辨别当前处于是"大浪潮的开端"还是"旧浪潮的尾声"——看人才流向、资本密度、底层技术突破的质变信号
  3. 如果你在新浪潮中落后了，回到"先跟踪再判断"的 specialist 模式，不要追涨
- **局限性**：事后分类总是比事前判断容易——你能说出过去十年的三波，但你很难判断现在是不是第四波的起点。这个框架帮你理解历史，但不帮你精确择时。此外，它只覆盖 AI，不是所有技术领域都有这种长周期波浪结构。

### 模型3：技术投资看人三要素

- **一句话**：技术投资看人比商业模式投资更严格——技术团队的 skill set 难以快速迁移，所以必须优先判断"做的事是否有价值"+"团队能否实现"。最看重创始人三点：挑战难问题的野心、能讲出新东西的创新性、完整性。
- **来源**：[[42章经]] 002 — "技术领域不是说一个特别牛的创始人、特别强的团队，做啥都行；团队的 skill set 不一定能迅速切换到另一个材料去。" [原话]
- **怎么用**：
  1. 先判断项目本身的技术方向和价值，再评估团队是否匹配
  2. 用三要素筛选：野心（是否要挑战够难的问题，而非无序扩张）、创新性（是否在讲别人没讲过的新东西）、integrity（是否值得信任）
  3. 估值判断：算上稀释后至少还有 50 倍空间才出手
- **局限性**：三要素很主观——"野心"和"无序扩张"的边界在事前极难区分，"创新性"也可能只是叙事包装。他投 Minimax 时市场认为主体都在做 BERT，Minimax 的"创新性"在当时看起来也可能是异想天开。这个模型依赖投资人的个人经验直觉，新手较难直接套用。

## 决策启发式

1. **先选赛道再找项目**：不是等好项目出现才判断，而是提前泡在一个技术赛道里等它出现 — [[42章经]] 002
2. **投技术领域看团队匹配度更严格**：商业模式错了好团队能转型，技术方向错了再好的团队也很难切换 — [[42章经]] 002
3. **估值看倍数空间**：愿意出的估值 = "算上稀释后至少还有 50 倍空间" — [[42章经]] 002
4. **投资不能纠结**：行就行，不行就不行，必须杀伐果断。每投一个项目都想清楚，愿意承担风险 — [[42章经]] 002
5. **大模型三层看机会**：基础层只有几家能做 → 中间层 LLMOps 硅谷机会更大 → 应用层 ToB 可以视为企业服务 2.0 — [[42章经]] 002

## 内在张力 / 盲区

1. **98% 运气的诚实与精英主义的张力**：他自称 98% 运气+2% 努力，甚至把公司名取为"云启"（运气的谐音）。但与此同时，他的投资方法论充满了结构化判断（赛道选择、人三要素、估值空间）。这两者之间是否存在张力——如果一个投资人真的认为成功 98% 靠运气，他为什么还花大量精力构建投资框架？
2. **Specialist 路线的机会成本**：他自豪于十年不追消费/SaaS 热点，但这意味着他系统性地放弃了这些领域的机会。他在这些领域的"不擅长"可能是自我实现的预言——不是真的做不了，而是根本没试过。他的 specialist 标签也许掩盖了对跨领域能力的低估。
3. **对 AI 的结构性乐观**：他投了 Minimax、PingCAP、Zilliz 等 AI/数据赛道的项目，整体叙事极其乐观（"AI 是软件未来发展的方向"）。仅一集访谈，盲区可能未被充分暴露——他未深入讨论 AI 投资的系统性风险或可能失败的情况。
4. **中国市场退出困境的坦诚与无力**：他承认中国软科技是 hard 模式（退出只有做大一条路），但并未提出自己对这一困境的解决方案。这更像是一个诚实的陈述，而非可以行动的洞察。
