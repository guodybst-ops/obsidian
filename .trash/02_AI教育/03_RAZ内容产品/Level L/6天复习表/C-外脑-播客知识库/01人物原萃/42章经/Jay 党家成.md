# Jay 党家成

## 画像

- **身份**：FlowGPT 创始人/CEO，全球最大 Prompt 社区的创建者
- **背景**：2002 年出生，伯克利 CS 大二辍学；小学/初中在国内打基础（卷+干），高中赴美适应，大学积累+真正做事
- **标签**：02后创业者 / Prompt社区 / AI Native平台 / 伯克利辍学 / Do Things That Don't Scale / Android生态信念者

## 擅长 & 不擅长

- **擅长**：从零到一的社区冷启动（一对一私聊打法）；识别被主流理论忽略的直觉型创业机会；以 Android 式开放生态对抗封闭平台
- **不擅长**：规模化后的大团队管理（FlowGPT 仍在成长期，未验证）；中国的本土市场逻辑（全程做全球市场）；对「经验丰富」型创业者所使用的完整商业计划方法论不熟悉

## 核心心智模型

### 模型1：直觉驱动决策（Feeling > 理论）

- **一句话**：当内心的感觉和所有"好的创业建议"冲突时，先相信感觉，快速做出来验证。
- **来源**：[[42章经]] 016 — FlowGPT 这个 idea 违背了他读到的所有"好的创业想法"（不要做平台、不要拿痒点、不要锤子找钉子），但感觉对了就先做出来 [归纳]
- **怎么用**：
  1. 当你有一个创业想法被所有教科书认为是"坏想法"时，问自己：你**感觉**这个需求真实吗？
  2. 用两天时间做出第一版——不是两周，不是两个月
  3. 如果用户来了（第一周就有自来水传播），那就用行动代替犹豫
  4. 如果失败了：没什么 ego，可以做别的
- **局限性**：22 岁年轻人的直觉在成熟市场可能完全失效——他承认自己"没什么可以丢的"，这种零机会成本的心态对于有沉没成本的人不可复制。直觉驱动在技术浪潮早期更有效，在存量竞争市场可能是灾难。

### 模型2：Do Things That Don't Scale

- **一句话**：早期阶段不要追求规模化的获客方式——亲自一个一个私聊潜在用户，把前 500-600 个种子用户关系做到极致。
- **来源**：[[42章经]] 016 — 在 Discord/Reddit 上一个一个私聊数千人，前 500-600 人是这样拉来的 [归纳]
- **怎么用**：
  1. 定位你的种子用户在哪里聚集（Discord/Reddit/X 等社区）
  2. 搜索关键词找到发过相关内容的用户
  3. 逐一私聊，不群发、不模板化——让对方感受到你的产品是**为他们做的**
  4. 前几百个用户的质量远比数量重要——这些人会成为社区文化的奠基者
- **局限性**：仅适用于社区/平台型产品的早期阶段。当用户到达万级后此方法不可持续。另外，他自己承认这群早期用户是"失败的、愿意花时间在 Prompt 上的人"——如果目标用户画像更宽泛，这种打法可能吸引不到正确的人。

### 模型3：开放生态 vs 封闭平台（Android vs iOS 战略）

- **一句话**：不做封闭平台上的一个应用商店，做一个跨模型的开放 Prompt 分发层——让用户跟着创作者走，而不是被平台锁死。
- **来源**：[[42章经]] 016 — FlowGPT = Android（开放、开源、多模型、创作者自由度高），GPT Store = iOS（封闭、绑定 OpenAI 服务）[归纳]
- **怎么用**：
  1. 判断你的赛道是否正在被一家公司封闭垄断
  2. 如果所有大模型都做自己的应用商店 → 反而是好事 → 用户需要一个跨平台的比较和分发层
  3. 把焦点放在**创作者**而非用户——创作者要模型选择自由，用户会跟着创作者走
  4. 平台主动放弃下场做应用——"创作者做的比我们好"
- **局限性**：开放平台需要等生态成熟后才能收割价值——前提是市场真的有多个有竞争力的大模型并存。如果最终只剩 1-2 个模型统治市场，开放策略的价值会大大缩水。他在 23 年做的这个判断至今（26 年）仍在验证中。

## 决策启发式

1. **Fast MVP > 完整分析**：两天写出第一版，而不是两周做规划。实例：FlowGPT 第一版两天写完，第二周用户暴涨 — [[42章经]] 016
2. **一对一冷启动**：不投广告、不买流量，一个人一个人聊。实例：Discord 上只要发过 Prompt 的人他几乎都聊过 — [[42章经]] 016
3. **先上车再辍学**：验证了需求（用户暴涨）再决定辍学，不是先辍学再找方向 — [[42章经]] 016
4. **文娱拉新、生产力拉留存**：流量产品负责拉新拉频次，工具属性负责留存和付费 — [[42章经]] 016

## 表达DNA

- **句式偏好**：直给式陈述，不加修饰词，不绕弯子。"我也没什么 ego""我感觉是对的，就先做出来了"
- **核心类比域**：iOS vs Android 生态对比——贯穿整个商业逻辑
- **语言特点**：有 02 后特有的"无包袱感"——不解释自己为什么辍学，不强调自己多努力，只讲做什么和为什么

## 内在张力 / 盲区

1. **零机会成本的逻辑不可复制**：他的核心策略（辍学、不担心失败、没 ego）建立在他 22 岁、无家庭负担的基础上。对于有房贷、有家庭、有职业沉没成本的人，这套逻辑不具备可迁移性
2. **直觉至上的风险**：他在播客中承认自己的 idea 违背了所有创业理论——如果他的直觉错了而理论对了，这就是一场灾难。他尚未经历过这种失败
3. **"没经验"作为优势的前提是创新在快速迭代期**：在更成熟的市场中，没经验会直接导致被有经验的对手降维打击
4. **用户群年龄断层**：他承认自己可能"太老了，没法理解那些石油级用户的文化"——创始人与核心用户之间的文化代沟是一个沉默风险
