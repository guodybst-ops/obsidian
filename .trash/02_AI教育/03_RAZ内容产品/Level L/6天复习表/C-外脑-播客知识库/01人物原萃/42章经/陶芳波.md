# 陶芳波

## 画像

- **身份**：心识宇宙创始人/CEO，Mebot 创始人
- **背景**：AI 研究者出身（博士、Facebook、阿里达摩院）；2021 年底判断 AGI 时代即将到来，创立心识宇宙；早期做 MindOS（Agent 平台），后转向 Mebot（个人模型）
- **标签**：个人模型 / Bot社会 / 记忆系统 / 供给侧vs需求侧bot / 上传智能

## 擅长 & 不擅长

- **擅长**：从认知科学和记忆系统的角度重新定义 AI Agent 的终极形态；用"个人模型"概念替代"AI 助手"概念对未来进行想象力推演；区分 Agent 的"脚手架阶段"和"持续学习阶段"
- **不擅长**：短期商业化路径的清晰规划（Mebot 目前服务不到 100 人，仍在技术验证阶段）；大规模产品的工程化落地（他的强项在概念架构和认知设计，不在 scaling）

## 核心心智模型

### 模型1：Bot 社会的两种 Agent——供给侧 vs 需求侧

- **一句话**：未来是千亿 bot 的世界，一个大模型结合一个场景/个人就形成一个 bot。但最重要的 bot 不是供给侧（服务/内容代表），而是需求侧/身份型 bot——代表"我"来发起需求、整合需求。Mebot 想做的不是 her/him/them，而是 me。
- **来源**：[[42章经]] 027 — 他从 MindOS 转向 Mebot 的核心判断 [归纳]
- **怎么用**：
  1. 供给侧 bot：主动提供服务/内容——类似今天的客服机器人、内容生成 bot。这类 bot 的价值依赖于承载的服务本身
  2. 需求侧 bot：代表一个具体的人——存储这个人的记忆、偏好、价值观，主动在 bot 网络中为这个人谈判、搜索、过滤
  3. 判断一个 bot 属于哪类：它是在为谁的利益工作？服务方的还是需求方的？
  4. Bot 的价值不在于网络效应，而在于与真实世界主体（人）绑定并持续优化的深度
- **局限性**：需求侧 bot 的前提是每个人愿意把自己的全部数据交给一个 bot——这涉及巨大的隐私信任问题。而且供给侧 bot 会先完善（因为商业驱动力更强），当供给侧 bot 充分发展后，需求侧 bot 的存在价值是什么？如果所有服务都有极好的供给侧 bot，为什么还需要一个需求侧 bot 作为中间层？

### 模型2：Agent 的两阶段进化

- **一句话**：Agent 分两个阶段发展——第一阶段是脚手架（RAG、工具、workflow、prompt engineering），第二阶段是持续学习（从真实实践和反馈中获得智慧，将反馈转化为记忆并改造 workflow）。今天大多数 Agent 的差距不是初期学习，而是实践反馈无法改造初始设计。
- **来源**：[[42章经]] 027 — 他区分 Agent 发展阶段的框架 [归纳]
- **怎么用**：
  1. **脚手架阶段**（当前）：搭好工具链、知识库、prompt 模板——这是"工程师能做的事"
  2. **持续学习阶段**（目标）：系统自动从每一次交互中学习——哪些 feedback 应该转化为永久记忆？哪些应该触发 workflow 更新？
  3. 关键指标：你的 Agent 在用了三个月后和三个月前相比，有没有本质区别？如果没有，你还在脚手架阶段
  4. 从脚手架到持续学习的关键不是更多的数据，而是"将反馈转化为记忆并改造 workflow"的闭环机制
- **局限性**：持续学习阶段的理论基础来自认知科学和心理学（体验自我 vs 记忆自我），但这些理论本身在应用到 AI 系统时可能不适用——人的记忆系统和 AI 的记忆系统有本质差异。而且"从反馈中持续学习"的工程实现远比理论上困难——目前 Mebot 服务不到 100 人，能否在更大规模下工作完全是未知数。

### 模型3：记忆系统——个人模型的核心

- **一句话**：人是一种高度由记忆决定的生命体。每天新记忆像流一样灌入，思想结构也在默默变化。如果要创造个人 AI，就必须让 AI 经历并学习你的记忆流。真正决定决策的不是所有经历的堆叠，而是记忆自我通过预测机制形成的抽象框架。AI 真正的记忆不是"记住所有细节"，而是"能 reasoning in history"。
- **来源**：[[42章经]] 027 — 他引用心理学中体验自我 vs 记忆自我的经典框架来解释 AI 记忆系统设计 [归纳]
- **怎么用**：
  - 体验自我（experiencing self）：每时每刻感受到的经历——数据量大但不直接决定决策
  - 记忆自我（remembering self）：从经历中抽取的抽象框架——这才是决策的基础
  - 个人 AI 需要构建：记忆的流入（capture）→ 从记忆中提取抽象框架（abstraction）→ 基于框架做 reasoning in history（推理）
  - 个人记忆可能成为 AI 时代的新超级入口——互联网数字化了社交和内容数据，但没数字化个人体验数据
- **局限性**：这个概念极为宏大，但实现路径极不清晰。Mebot 目前服务不到 100 人，本质上是一个高度实验性的产品。从"记忆系统"到"超级入口"的逻辑链条中，有无数未验证的假设。而且这个模型假设个人愿意接受"被持续记录和分析"的程度远超当前社会规范。

## 决策启发式

1. **先帮每个人做好自己的 Agent，比把所有软件变成 Agent 更可行**：这是从 MindOS 转向 Mebot 的核心逻辑——供给侧 Agent 的前提是需求侧 Agent 先到位 — [[42章经]] 027
2. **高估了 AI 基础能力的价值，低估了它在场景中的 know-how 价值**：通用大模型的能力只是起点，真正有价值的是如何将能力适配到具体的人和场景 — [[42章经]] 027
3. **Personal model 类似 PC 从大型机到个人电脑的演化，但压缩到可能只要 5 年**：技术民主化从"为企业/组织构建"到"为个人构建"是必然方向 — [[42章经]] 027

## 表达DNA

- **语言风格**：学术研究者和哲学思考者的混合——用认知科学（体验自我 vs 记忆自我）和个人计算史（大型机→PC→Personal model）构建叙事
- **核心叙事**：从"AI 帮人做事"到"AI 变成人的一部分"——一场关于人和机器关系的身份重塑
- **标志性句式**："不是 her，不是 him，也不是 them，而是 me"

## 内在张力 / 盲区

1. **从概念到产品的巨大鸿沟**：他的理论框架极具想象力，但 Mebot 目前服务不到 100 人，很多核心假设（记忆系统、持续学习、requirement side bot）完全未在规模上验证。存在"用宏大叙事覆盖缺乏执行验证"的风险
2. **隐私与记忆的未解矛盾**：个人模型需要一个人的全部数据——浏览记录、聊天记录、消费行为、情绪波动。他轻描淡写地提到"收集数据"，但这是整个方案中最难被社会接受的部分。Apple 的隐私定位和陶芳波的"持续记录你的一切"是互斥的价值观
3. **供给侧 bot 可能让需求侧 bot 不必要**：他承认"高估了 AI 基础能力的价值，低估了 know-how 的价值"。但如果供给侧 bot 的 know-how 足够好（如一个极好的旅行规划 bot），你不需要一个代表"你"的需求侧 bot——直接和服务 bot 交互就够了。需求侧 bot 的增量价值需要被更严格地证明
4. **从 MindOS 到 Mebot 的 pivot 本身说明不确定性**：他的 pivot 被包装为"更深刻的判断"，但也可能是"上一个判断错了"
