# 周健

## 画像

- **身份**：澜码科技创始人/CEO，做下一代 To B 业务流程自主化（AI Agent）
- **背景**：ACM 冠军（首次为亚洲拿下）→ 谷歌中国/美国 → 阿里云创始团队成员（王坚团队）→ 依图（AI 四小龙）10 号员工 6-7 年 → 弘玑 Cyclone（RPA）CTO → 2023 年初创立澜码
- **标签**：ACM冠军 / AI四小龙老兵 / RPA转AI Agent / To B企业家 / 人机协同派 / AGI不可知论者

## 擅长 & 不擅长

- **擅长**：从技术底层到商业组织的全链路判断（芯片→云→AI→RPA→Agent）；识别技术浪潮中的"真正变量"和"伪变量"；在组织生命周期中处理子弟兵与职业经理人的动态平衡
- **不擅长**：对 AI 2.0 的具体消费级 To C 场景缺乏深入判断（全程聚焦 To B）；对 AGI 的路径缺乏确定性的立场（自己承认不可知论）

## 核心心智模型

### 模型1：AI 1.0 → 2.0 的本质差异判断

- **一句话**：AI 1.0（CV）失败不是技术不行，是商业模式没有弹性——CV 不是通用技术，找到 PMF 后到天花板就结束。AI 2.0（大模型）不一样：自然语言理解是通用技术，能把治理变生产力，商业模式有持续打开的可能。
- **来源**：[[42章经]] 017 — 完整经历依图（AI 四小龙）从兴起到天花板，亲眼见证海康威视用国家标准降维打击 [归纳]
- **怎么用**：
  1. 判断一项 AI 技术是否为通用技术：它能否跨行业、跨职能提供价值？
  2. 如果是点状技术（如人脸识别），商业模式弹性的天花板 = 那个行业的规模上限
  3. 检查是否存在"降维打击者"——像海康威视用国家标准+社会资源一次性圈走 AI 四小龙的后续空间
  4. 真正杀死你的不是友商竞争，是来自另一个维度的大玩家
- **局限性**：这套框架是 AI 1.0 的事后反思，对 AI 2.0 的前瞻预测是否正确，取决于大模型的能力上限能否超越当前假设。他自己也承认这一波"其实不是面向用户，还是面向资本"。

### 模型2：创业组织管理的"刹车关"

- **一句话**：创业成功的必经之路是踩刹车——从追求增长转向追求效率。老兄弟（子弟兵）是压舱石，职业经理人是雇佣军；踩刹车时后者最容易走，处理不好，组织基石就坏了。
- **来源**：[[42章经]] 017 — 基于他在依图带 2000 人、弘玑做 CTO 的组织管理经验 [归纳]
- **怎么用**：
  1. Upside 阶段：职业经理人和老兄弟都能共存，看不出来差异
  2. 踩刹车阶段（降本增效）：观察谁留谁走——职业经理人最容易走，因为没有"我们一起从 0 到 1"的情感契约
  3. 处理原则：不要因为走了几个职业经理人就怀疑自己的决策方向，但也不能只靠老兄弟（他们可能已经跟不上公司阶段）
  4. 关键句子："电梯往上走了，有人会以为是自己做俯卧撑使电梯往上走的"——区分电梯（大势）和俯卧撑（个人能力）
- **局限性**：这套判断带有明显的"老兵"视角——他自己就是 AI 四小龙的老兵。对于没有经历过完整周期的年轻创始人，区分"电梯"和"俯卧撑"在事前几乎无法做到。而且他对职业经理人的描述偏负面，可能忽略了优秀职业经理人对组织专业化的贡献。

### 模型3：CPU → GPU 价值链迁移

- **一句话**：五年内企业 IT 预算的 30% 会从 CPU 切到 GPU 这条线（算力+模型+应用+中间件），这期间出现一个怪异的甲方逻辑：客户投了算力后，反而要求应用把利用率提上去——价值反转了。
- **来源**：[[42章经]] 017 — 核心判断，基于澜码与央国企客户的合作经验 [归纳]
- **怎么用**：
  1. 判断哪些企业已经大规模投了 GPU 算力（央国企、金融机构优先）
  2. 这些客户的核心痛点：我投了一个亿买了算力，怎么用起来？→ 需求从"降本增效"变为"消灭算力闲置"
  3. 创业者从"求客户买单"变为"客户求你把应用做出来"——这种窗口期只持续到算力利用率被普遍拉高之前
  4. 在这个窗口期内，做大模型应用的公司应该优先服务"已有算力但缺应用"的客户
- **局限性**：这个判断高度依赖于 GPU 算力持续大规模部署的假设。如果大模型推理成本降到极低导致本地 GPU 需求下降，这种价值反转就会消失。另外，他自己也承认这种逻辑"只在当下阶段成立，一年后就没了"。

## 决策启发式

1. **判断慢变量而非快变量**：创业最难的是判断新技术尺度、社会反应、行业 merge 速度、甲方变化速度——这些每次都不一样。实例：花 20-30% 时间做品牌在当时看来不合理，但央国企主动找上门后证明赌对了 — [[42章经]] 017
2. **希望友商更多**：一家公司不断培训客户太累，把市场做大对所有人都好——先做大蛋糕再分蛋糕 — [[42章经]] 017
3. **大模型公司不能端到端打通**：头部企业找上门根本服务不过来，必须围绕生态链竞争 — [[42章经]] 017
4. **低代码不会消失但天花板被封**：以后人应该写声明式需求，具体实现交给机器 — [[42章经]] 017

## 内在张力 / 盲区

1. **AI 1.0 的复盘可能存在幸存者偏差**：他站在 AI 2.0 的起点回看 AI 1.0，把 CV 的失败归因为"不是通用技术"——但当时没人知道大模型会涌现。他在依图时也未能预见并避开 AI 四小龙的困境
2. **对 AGI 的不可知论与创业行动的矛盾**：他说 AGI 不可知、Transformer 不是通向 AGI 的路径，但他同时在做 AI Agent 创业——如果你的核心技术不会导致 AGI，你押注的是什么？
3. **老兵视角的局限**：他的所有洞见都来自已有成功/失败经验，但 AI 2.0 的速度和不确定性可能让这些经验失效——"每次慢变量都不一样"是他自己说的
4. **利益立场**：他正在做 AI Agent 创业，他对 AI 2.0 的乐观和对 RPA 的否定需要放在他正在融资/做事的背景下理解
