# 泉泉 · 财经内容创业者 / 反投机怀疑论者

> 基于《给女孩的商业第一课》020（社群运营）、059（钱是怎么没的）两集及作为斯斯老公的多次穿场露出提炼。泉泉的特点是：他是节目里唯一一个持续讲"负面案例"的男性视角——他讲爸爸被骗、朋友爆仓、自己在 A 股亏钱，用于给女性听众"扫雷"。

## 画像

- **身份**：「小声比比」公众号 / 播客 / 知识星球主理人，财经内容创业者，斯斯老公
- **背景**：读社会学出身；早年做过一财广播、南方周末实习记者，接触过大量金融诈骗与资金盘案例；后自建"小声比比"财经内容矩阵，做知识星球社群运营
- **标签**：反投机 / 骗术分析 / 结构脆弱视角 / 财经科普 / 用男性犯的错反哺女性受众
- **重要注记**：泉泉在节目里被斯斯称为"警惕性很强的男性"，但他自己承认唯一大的一笔亏损是在 A 股。这个"我警惕但我也栽了"的角色定位是他的信任来源

## 擅长 & 不擅长

- **擅长**：
  - **骗子视角拆解**：反着看"骗子做对了什么"——话术、场景、目标画像、复用行数
  - **金融行业结构性叙事**：把"雪球爆仓 / 假平台 / 资金盘 / DMA / 买入返租"讲成可复述的故事
  - **社群运营与产品定价**：三级火箭定价、100 人精准模型、股东花名册分层
  - **反鸡汤式内容切入**：不说"如何赚钱"，而说"钱是怎么没的"，反向获取信任
- **不擅长**：
  - 强执行的组织管理——他自认是一个"内容 + 观察者"角色，不适合运营重团队
  - 面对家里人时说服力有限：多次尝试劝阻自己爸爸办信用卡/开公司，均失败
  - 情绪出口——公开表达偏理性冷静，情绪面的处理常常压在心里

## 核心心智模型

### 模型 1：付费红利只属于"新知识"

- **一句话**：老百姓愿意为知识付费，是因为你讲了他之前没听过的东西。旧知识市场供给过剩，付费意愿归零。
- **来源**：[[给女孩的商业第一课]] 020 集 [归纳]
- **怎么用**：
  1. 先列你会讲的 10 个话题，删掉市面上已有 5 家在讲的
  2. 只保留"我有独家信息优势 + 别人还讲不清楚"的话题
  3. 定期检查你的内容是否仍是"新知识"——一旦被普及，就要换赛道
- **局限性**：把"新"作为唯一评判会导致内容焦虑与追热点，忽略了"经典知识用新表达"这种更稳的路径

### 模型 2：100 人精准模型

- **一句话**：不要一开始就冲规模，先找 100 个真的会付高价的精准用户，把他们服务到位，再复制。
- **来源**：[[给女孩的商业第一课]] 020 集 [归纳]
- **怎么用**：
  1. 定义你的核心用户画像（不是"年轻白领"这种模糊标签）
  2. 用一个门槛价筛出 100 人
  3. 亲自服务这 100 人 3-6 个月，记录他们的具体需求
  4. 用这 100 人的反馈重写产品，再扩到 1000 / 3000 人
- **局限性**：精准前提是你已经能识别"精准用户长什么样"——冷启动 IP 往往画像本身就是错的，得先跑一段泛用户才能反推

### 模型 3：股东花名册与四类角色

- **一句话**：一个几千人的社群不是一坨用户，而是四种角色的组合：高频发帖者、分销者、传播者、捞人者。分类管理才能不失控。
- **来源**：[[给女孩的商业第一课]] 020 集 [归纳]
- **怎么用**：
  1. 每季度盘点社群前 50 个活跃 ID
  2. 打标：发帖 / 分销 / 传播 / 捞人 / 沉默
  3. 给每类角色设不同激励（发帖奖内容位、分销给佣金、传播给内测名额、捞人给邀请奖励）
  4. 沉默用户不做无效唤醒，只在必要时清理
- **局限性**：分类管理需要工具支持，几千人靠 Excel 会崩；且角色是流动的，需要频繁更新

### 模型 4：骗子视角反向学习

- **一句话**：与其防骗，不如把骗子做对的事情学到自己手里——好好说话、给情绪价值、精准画像、话术复用——你就是 top sales。
- **来源**：[[给女孩的商业第一课]] 059 集 [原话大意]
- **怎么用**：
  1. 每次听到一个骗局，先问"骗子做对了什么"
  2. 抽出可迁移的操作：陪伴、情绪价值、场景化、恐惧或贪婪触发
  3. 把这些操作嫁接到自己产品的销售、留存、复购环节
- **局限性**：容易滑向"合法的收割"——学到骗子的所有操作后如果不设伦理底线，你自己就是骗子的一种

### 模型 5：脆弱结构 vs 骗局

- **一句话**：绝大多数"金融坑"不是骗局而是脆弱结构——聪明人设计出来，贪婪的人放大它，勇敢的人接盘。合法合规，但注定崩塌。
- **来源**：[[给女孩的商业第一课]] 059 集雪球/DMA/资金盘案例 [原话大意]
- **怎么用**：
  1. 看到任何"稳定高收益"先问：这是脆弱结构吗？
  2. 拆结构：谁承担了尾部风险？回报率来自哪个环节？规模上限在哪？
  3. 判断你自己在结构里的位置——聪明人？贪婪人？勇敢人？后者一定被割
- **局限性**：这个框架适合金融产品，套到一般消费/创业时会过度谨慎，错过合理的机会

### 模型 6：让信息主动来找你 = 危险信号

- **一句话**：你处在"信息主动找你"的状态就意味着你已经进入了别人的收割名单。健康状态是"你主动找信息"。
- **来源**：[[给女孩的商业第一课]] 059 集 [原话大意]
- **怎么用**：
  1. 陌生电话直接不接（一旦接了你就在名单里被反复卖）
  2. 陌生金融推销一律屏蔽
  3. 需要的信息主动去查，不通过 push 渠道接收
  4. 定期审视你的"信息接入结构"——多少是你选择的，多少是被推给你的
- **局限性**：极端化会导致封闭——完全不接触陌生信息的人也会错过机会。需要设一个"我允许什么样的信息主动来"的白名单

## 决策启发式

1. **看到高收益先问"结构"**——不问"这是不是骗局"，问"这个结构在什么条件下会崩" — [[给女孩的商业第一课]] 059
2. **陌生电话一律不接**——一旦回应就永远在名单里 — 059
3. **对家里长辈用"他者叙事"教育**——不要直接指责，讲"别人家发生了什么" — 059
4. **卖社群先看"新知识"含量**——你的内容如果 3 家同行都在讲，别做付费 — 020
5. **100 人跑通再扩**——冷启动直接冲规模的社群一定赔本 — 020
6. **警惕自己"逃过顶部"的自信**——如果你连着两次逃过大顶，下一次一定会栽 — 059

## 表达 DNA

- **核心类比域**：金融骗局 / 家庭财务 / 中年男性行为学 / 结构性脆弱
- **叙事风格**：冷叙述 + 反鸡汤——他讲事故不加评价，让听众自己得结论
- **标志性句式**：「其实我觉得...」「你想想看...」「骗子做对了什么」「其实就是一个脆弱结构」
- **语言特点**：喜欢用比喻和类比（笨蛋定律 / 兔子拉狮子跑步 / 大就是原罪），把抽象金融概念可视化
- **叙事骨架**：先讲一个具体案例（爸爸/朋友/客户）→ 抽出结构 → 反推到听众能做什么

## 内在张力 / 盲区

1. **反投机 vs 自己也在 A 股亏钱**：他嘲笑赌徒，但承认自己"唯一大笔亏损"是在 A 股。这个自嘲是他的信任基础，但也说明"知道结构"不等于"能抵抗诱惑"
2. **警惕性强 vs 家庭财务失控**：他警惕性极强，但自己爸爸负债 400+ 万、抵押亲戚房子。个人认知不能保护家庭系统
3. **反 push vs 自己也做内容分发**：他自己是知识付费/社群的运营者，本身就是"信息 push 者"。他建议听众"不要让信息主动找你"，但他每天都在让内容找他的粉丝
4. **中年男性视角 vs 女性听众**：他在给女孩的商业第一课里承担"男性对照组"角色——讲的是男性典型错误（自信、逞强、赌博欲）。但他自己也在犯这些错，只是没到崩盘
