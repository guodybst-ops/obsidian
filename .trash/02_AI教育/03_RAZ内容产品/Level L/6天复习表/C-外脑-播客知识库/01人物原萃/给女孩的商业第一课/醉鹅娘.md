# 醉鹅娘 · 从红酒 IP 到负债 5600 万的反脆弱创业者

> 基于《给女孩的商业第一课》001（首集，"树 vs 藤"）与 064（负债 5600 万复盘）两集提炼。醉鹅娘是节目里唯一被拍过两次、且两次都是"命运齿轮转动点"的嘉宾。第一次是"要成为树而不是藤"的宣言者；第二次是把 3 亿年营业额亏到欠债 5600 万后，做完减法只剩 20 人 + 一个自酿酒品牌的复盘者。她的价值不在于成功案例，而在于她公开承认"我以前根本不算数"的诚实。

## 画像

- **身份**：醉鹅娘（原名王胜寒），红酒 KOL / 内容电商创始人；负债 5600 万；今年 all in 自酿酒品牌"广寒记"（"代愿人长久" 300 元中秋款一年卖大几万瓶）
- **背景**：知识分子家庭（妈妈搞环保 + 反资本 + 教育"广告赚肮脏的钱"；爸爸在美国做程序员）；北大学历史；上过湖畔大学（跟兔头妈妈刘楠、王小卤鲁基同学）；12 年前进入红酒行业
- **标签**：红酒 IP / 负债创业者 / 反资本妈妈之女 / 一儿一女妈妈 / 内容电商 / 品牌破局尝试者
- **重要注记**：她的价值是**代表输过还没放弃的女性创业者**——不是成功案例，是幸存 + 诚实拆解的案例

## 擅长 & 不擅长

- **擅长**：
  - **红酒的文化叙事**：把红酒讲成中式美学 + 情绪 + 场景（"代愿人长久"是宣纸酒标 + 长相思艺名的例子）
  - **IP 内容能力**：穿透手机屏幕的表达，一次拍摄大几万瓶爆品
  - **公开自我拆解**：能在直播里坦诚说"我以前根本不算数""我把妈妈搭进去了 = 最不道德"
  - **迭代反思**：从"树 vs 藤"到"狼 vs 羊"，从"渠道加法"到"品牌减法"，主动更新框架
- **不擅长**：
  - **财务敏感度**：12 年没看过公司账；产品毛利 4 万/600 万营业额都不知道
  - **组织管理**：从 200 人裁到 20 人才发现"其实一个人都不留也能做"
  - **做减法的胆量**：优化 10% 砍不下去，直到欠 5600 万才敢砍 90%
  - **说"不"**：知识分子家庭 + 想当好人 → 权益之计的班子会反噬

## 核心心智模型

### 模型 1：树 / 藤 / 狼 / 羊四象限（身份认同框架）

- **一句话**：先看清你的身份牌是哪张。做树、做藤、做狼、做羊各有残酷，但混淆身份牌 = 用羊的价值观做狼的事 = 双重痛苦。
- **来源**：[[给女孩的商业第一课]] 001 + 064 [原话]
- **怎么用**：
  1. 承认你**已经不是**什么（醉鹅娘：我已经不是羊了）
  2. 看你打算**成为**什么（她：既然要选，就选狼）
  3. 处理**过渡期道德包袱**（她：当羊的价值观让我不坚决做狼该做的事）
- **局限性**：四象限是简化叙事，真实人是混合体；把"选哪个"当决策核心会忽略"具体情境该用哪张牌"

### 模型 2：不负债 vs 想赚钱（防御 vs 进攻）

- **一句话**：为了不负债而活 vs 为了赚钱而活，是完全两种状态。前者是防御，后者才是进攻。
- **来源**：[[给女孩的商业第一课]] 064 [原话]
- **怎么用**：
  1. 每个决定问："这件事**在不在提高公司赚钱的生产力**"（不是"这件事对不对/理不理想"）
  2. 判断你处在哪种状态——每天算"怎么不亏"而不是"怎么多赚" = 防御状态
  3. 认识到**反资本教育背景的女创业者**很容易停在防御状态
- **局限性**：赚钱驱动没有伦理约束会滑向割韭菜；且亏损期"想赚钱也赚不到"，防御反而理性

### 模型 3：真正的做减法（砍 90% 而不是 10%）

- **一句话**：优化 10% ≠ 减法。要真砍就砍到只留 10%，让强制重排优先级替你做决定。
- **来源**：[[给女孩的商业第一课]] 064 [原话]
- **怎么用**：
  1. 提问："**如果我今天重新开始创业，会做什么**？"
  2. 只做这个假设下会做的事，其他一律不做
  3. 200 人 → 砍 10% 砍不动，宣布只留 20 人 → 反而砍得下去
- **局限性**：这是"逼到绝境"才能用的方法；健康公司试着砍 90% 会伤筋动骨

### 模型 4：A/B 犹豫 = 认知没到位

- **一句话**：在两个选择之间反复犹豫 = 你没有彻底看清。真看清了不会犹豫。
- **来源**：[[给女孩的商业第一课]] 064 [原话]
- **怎么用**：
  1. 承认犹豫本身是**信号**（不是缺点）
  2. 花时间在"看清楚"而不是"做选择"
  3. 醉鹅娘听曾明教授"要么渠道要么品牌"后又花一年多做选择——这段时间是必须的"看清成本"
- **局限性**：某些场景犹豫是理性的（信息不足）；这个模型会误诊为"没想通"跳过真正需要的信息收集

### 模型 5：品类三角（毛利率 / 复购率 / 获客成本）

- **一句话**：一个生意能不能做，看毛利率 + 复购率 + 获客成本三角。三个都不好差到无法翻盘。
- **来源**：[[给女孩的商业第一课]] 064 [归纳，源自王小卤鲁基 via 醉鹅娘]
- **怎么用**：
  1. 分析目标品类三角状态
  2. 对比你正在做的品类，坦承承认三角短板
  3. 内容能力是**放大器**——好品类 + 你 = 20 亿，坏品类 + 你 = 5600 万负债
- **局限性**：宏观品类判断，微观里同品类也有细分好坏；没考虑创始人的独特禀赋加成

### 模型 6：论迹不论心的复盘法

- **一句话**：过去持续努力却没正反馈 = 努力方向一定是错的。只看结果，不用"我用心了"安慰自己。
- **来源**：[[给女孩的商业第一课]] 064 [原话]
- **怎么用**：
  1. 复盘时**屏蔽情感和意图**，只看数据
  2. 反问："这件事从结果角度给我带来了正反馈吗"
  3. 反直觉引入理性
- **局限性**：短周期未见效的正确决策会被误判为"错的"；纯结果论会导致丢失长期战略

### 模型 7：势不在你这边 = 做啥都错

- **一句话**：当"势"不在你这边的时候，所有决定都是错的。人能做的最正确决定是**让自己站在势那一边**。
- **来源**：[[给女孩的商业第一课]] 064 [原话]
- **怎么用**：
  1. 承认宏观周期比努力更重要（红酒品类过去两年下滑 60%）
  2. 判断"势"的位置（品类、平台、监管、代际、经济周期）
  3. 逆势时收缩、顺势时 all in
- **局限性**：宿命论倾向；很多人用"势不在我这边"给自己开脱努力不足

### 模型 8：立 flag 会被老天爷考验

- **一句话**：立一个人设/flag = 老天爷会想方设法考验它。不坚定的话不要说。
- **来源**：[[给女孩的商业第一课]] 064 [原话]
- **怎么用**：
  1. 心里想清楚 vs 公开宣告 = 两种成本
  2. 公开 flag 会被反复考验（醉鹅娘 4 年前立"当树"→ 被考验 4 年）
  3. 只在**已经做到**之后再宣告
- **局限性**：不宣告 flag 会失去公开承诺动力；对 IP 型创业者，"人设建构"就是产品

## 决策启发式

1. **问身份牌，不问"要不要"** — 是狼还是羊？答完再谈选择 — 001/064
2. **每个决定问"这在提高赚钱的生产力吗"** — 而不是"这个理不理想" — 064
3. **优化 10% 砍不动就砍 90%** — 强制重排优先级 — 064
4. **犹豫 = 没看清** — 花时间在信息收集，不是决策 — 064
5. **品类先于努力** — 三角全糟就换品类，不要在坏品类里勤奋 — 064
6. **只论迹不论心** — 结果没正反馈 = 方向错 — 064
7. **不坚定的话不要说** — flag 会被考验 — 064
8. **想当好人的时候警惕自己是否在做最不道德的事** — 抵押妈妈的房子还不告知 — 064

## 表达 DNA

- **核心类比域**：红酒 / 家庭 / 树藤狼羊 / 蹦极 / 中式美学 / 网红生态
- **叙事风格**：自我拆解 + 反鸡汤 + 情感浓度高——她哭、她惭愧、她公开说"我以前叽里呱啦自以为是"
- **标志性句式**：「其实...」「你知道吗？」「我以前...但是我现在...」「说到底...」
- **语言特点**：容易走感性 / 情绪化叙述，但会用简短句收回一个理性判断（如"婚姻是每个赌狗的龙华寺"、"良心 ≈ 毛利低"）
- **叙事骨架**：先讲一个私人化的沉痛感受（月子里坐在客厅看月光；坐月子拍视频恶心到反胃）→ 承认自己错在哪 → 抽出一个可复用的模型（做减法、砍 90%、品类三角）

## 内在张力 / 盲区

1. **想当好人 vs 做最不道德的事**：抵押妈妈的房子还骗她"公司发展需要"——想当好人反而害了最亲的人。这是知识分子家庭养出来的道德包袱和商业现实之间的核心张力
2. **反资本妈妈 vs 商业化女儿**：妈妈教育"广告赚肮脏的钱"，她做红酒 IP + 广告变现——每次公司账目问题都不敢跟妈妈说清楚。这个未和解的代际张力延续了整整 12 年
3. **想赚钱 vs 想要意义**：她坦承"我们家不食人间烟火"让她 35 岁才第一次真正把赚钱当第一目的。但她又说"红酒的本质是超越生活的美好" = 意义追求。**赚钱 vs 意义的顺序不能颠倒**，但她仍在拉扯
4. **信念驱动 vs 结果验证**：她说"我的天赋是迷之自信"、"我总相信这个事情会有解决方法"——正是这个天赋让她持续借款、持续加码、持续错失止损。所以她的"信念"既是核心竞争力，也是核心漏洞
5. **公开赤诚 vs 自我保护**：她的 IP 建立在"敢说真话"上，但每次说完真话又害怕流量、害怕团队看到、害怕失去权威。这个张力是所有 IP 型创业者的共有困境，她比大多数人更诚实地承认它
