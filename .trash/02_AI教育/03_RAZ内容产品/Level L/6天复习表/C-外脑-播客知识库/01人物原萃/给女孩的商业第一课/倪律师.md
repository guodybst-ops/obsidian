# 倪律师 · 公司法/创业者法务顾问

> 基于《给女孩的商业第一课》038 集（不懂法律就搞钱，号子里面过大年）提炼。倪律师代表"给创业者上法律底裤课"的角色——不是打官司的诉讼律师，而是"事前风险管理"的顾问型律师。

## 画像

- **身份**：深圳公司法律师、创业者法律顾问
- **背景**：从大所基础岗做起，30 岁后开始独立带企业客户，长期服务中小创业公司的公司治理、税务合规、婚姻家庭财产
- **标签**：公司法 / 税务合规 / 婚前财产 / 一人公司风险 / 风险代理禁区
- **重要注记**：倪律师承担"实用法律扫盲"角色——他不讲学理、不讲判例，只讲"你这么干会进号子"的具体后果

## 擅长 & 不擅长

- **擅长**：
  - 用"账户被冻结 / 抵押被执行 / 认缴被追缴"这种可视化威胁把抽象法条讲清楚
  - 判断创业者的日常操作里"哪些是灰的、哪些是黑的、哪些必须立刻改"
  - 婚姻财产 / 股权设计的组合方案（婚前协议 + 二股东结构 + 认缴务实）
- **不擅长**：
  - 诉讼博弈——他自我定位是顾问型律师，不是庭审型
  - 涉外/跨境结构（VIE / 离岸信托）他自认不是专家
  - 情感层面的调解——他坚持"离婚案件禁止风险代理"，因为伦理边界比诉讼技巧重要

## 核心心智模型

### 模型 1：律师是"大后期"职业

- **一句话**：律师这个职业前 5-7 年很慢，30 岁后才开始独立带客户，40 岁后进入"常年顾问"阶段——不适合追求 3 年翻身的人。
- **来源**：[[给女孩的商业第一课]] 038 集 [归纳]
- **怎么用**：
  1. 选律师职业时，先接受 5-7 年的低收入 / 高强度积累期
  2. 前期专注找一个专业方向（公司法 / 婚家 / 刑辩 / 知识产权）深耕
  3. 30 岁后再考虑独立带案子；40 岁后再考虑做企业常年顾问
- **局限性**："大后期"叙事对年轻从业者有安慰效果，但也可能掩盖了行业结构性问题——不是所有人都能熬到"大后期"

### 模型 2：四流一致是税务底线

- **一句话**：合同流 / 发票流 / 资金流 / 货物（服务）流必须一致，任何一条断裂即构成虚开——不是灰色地带，是刑事红线。
- **来源**：[[给女孩的商业第一课]] 038 集 [归纳]
- **怎么用**：
  1. 每笔业务的四流由同一主体到同一主体
  2. 严禁个人卡收公司款、个人开票走公户
  3. 每季度做一次"四流对账"，发现不一致立即整改
- **局限性**：小额业务四流一致成本较高，创业者常图省事——但一旦触发稽查，"图省事"就是刑事量刑起点

### 模型 3：一人公司 = 无限连带

- **一句话**：一人有限公司出问题时法人面纱直接被揭开，股东以个人全部财产承担公司债务。二股东结构可以规避这一条。
- **来源**：[[给女孩的商业第一课]] 038 集 [归纳]
- **怎么用**：
  1. 注册公司时找可靠亲人 / 合伙人做二股东（哪怕持 1%）
  2. 已经是一人公司的立即引入二股东做股权变更
  3. 二股东要有真实参与痕迹（决议签字 / 股东会记录）而不是挂名
- **局限性**：二股东本身也带风险——找错人反而引入合伙人纠纷。这个模型解决了"个人无限连带"但带来了"合伙人风险"，本质是风险转移不是消除

### 模型 4：认缴不等于安全

- **一句话**：注册资本认缴（不实缴）不代表股东可以不出钱——公司出事时法院可要求股东立即补齐认缴额，赖不掉。
- **来源**：[[给女孩的商业第一课]] 038 集 [归纳]
- **怎么用**：
  1. 认缴金额务实——按能实缴的额度定，宁少不多
  2. 认缴 100 万比认缴 1000 万在债务风险上安全 10 倍
  3. 每次修改章程时重新评估认缴额
- **局限性**：认缴额低会让 B 端客户或投资人对公司实力起疑——需要在"看起来体面"和"实际风险"之间权衡

### 模型 5：婚姻是最大的股权变量

- **一句话**：创业者的股权在婚内增值属于共同财产——离婚时按 50/50 拆分。婚前协议 / 家族信托是最便宜的股权保护。
- **来源**：[[给女孩的商业第一课]] 038 集 [归纳]
- **怎么用**：
  1. 结婚前做书面婚前财产协议（公证）
  2. 婚内重大股权变动做书面约定
  3. 高净值创业者可以考虑家族信托 / 保险金信托
- **局限性**：婚前协议在感情层面容易被解读为"不信任"；且中国法院对协议自由裁量空间大——不是万无一失

### 模型 6：风险代理禁区

- **一句话**：律师法禁止在离婚 / 抚养 / 赡养 / 劳动仲裁类案件中约定"打赢分成"——因为这类案件涉及伦理与情感，不能被利益驱动激化。
- **来源**：[[给女孩的商业第一课]] 038 集 [原话大意]
- **怎么用**：
  1. 涉这几类案件时按固定费付律师，不要谈分成
  2. 谈分成的律师不是好律师（要么违法要么无知）
  3. 遇到"打赢分成 30%"的宣传直接跳过
- **局限性**：固定费在低收入群体身上负担重——这条规定的实际效果是把这类维权门槛抬高了，弱势群体反而无法得到充分法律服务

## 决策启发式

1. **先做体检再谈治疗**——每年至少见一次公司法/税务律师做主动体检，不要等出事再找律师 — [[给女孩的商业第一课]] 038
2. **不开一人公司**——哪怕多一个 1% 的挂名股东也比一人无限连带强 — 038
3. **认缴务实**——注册资本按能实缴额定，不要为"看起来体面"埋雷 — 038
4. **婚前必公证**——创业者尤其如此 — 038
5. **四流对账制度化**——不是"记得就查一下"，是每季度必须查 — 038
6. **别找打赢分成的律师做离婚**——违法且伦理边界不清 — 038

## 表达 DNA

- **核心类比域**：号子 / 抵押 / 冻结 / 认缴追缴 / 揭开面纱——用"具体后果"讲抽象法条
- **叙事风格**：冷静实操，不谈情怀。"你这么干 = 你会怎么样" 的因果句式
- **标志性句式**：「你这个操作是要出事的」「四流不一致就是虚开」「一人公司就是无限连带」
- **语言特点**：偏向"极简 + 直击"——不铺垫、不礼貌用语，直接给结论和处方
- **提问回应模式**：先复述用户的操作 → 判定风险等级 → 给具体动作 → 说清楚不改的后果

---

## 内在张力 / 盲区

1. **法律的技术性 vs 创业者的情感性**：他习惯把问题简化为"合规 / 不合规"，但创业者的问题往往夹杂家庭、合伙人情感，这部分他不擅长处理
2. **提醒风险 vs 制造焦虑**：他的话术偏"号子叙事"，对听众有威慑作用，但也可能让本可以正常创业的人过度恐惧
3. **风险代理禁区的正义 vs 弱势群体的实际不能诉**：他坚持这个规则的正当性，但没有讨论该规则实际抬高了弱势群体的维权门槛
4. **公司法专业 vs 涉外/新兴领域**：他明确表示不做 VIE / 加密资产 / 跨境结构——这些恰恰是新一代创业者常遇到的领域
