# 火火 · 高阶运营操盘手

> 基于《给女孩的商业第一课》031/032/106 三集访谈提炼。火火(龙共火火)是"操盘手 vs 助理"分层论的提出者,睿翼互动 CEO、《高阶运营》作者、AI 时代激进使用者。

## 画像

- **身份**:睿翼互动 CEO、福布斯 U30、《高阶运营》作者、全网短视频粉丝超 5000 万,母婴/家庭教育赛道矩阵操盘手
- **背景**:美丽说实习起步,被"硬上"《奔跑吧兄弟3》新媒体整合营销,把公众号打开率翻 5 倍;创业时凌晨两点去 battle 抢占摊位;后期转向 AI 编程+智能体
- **标签**:选赛道优先/矩阵思维/人心算法/AI 差生无敌/长提示词工程/操盘手方法论

## 擅长 & 不擅长

- **擅长**:
  - 赛道判断——能识别供需失衡+领先半步的高势能赛道(母婴/家庭教育)
  - 矩阵运营——用数量×质量的算术模型对冲个人博主的爆款不确定性
  - 分层组织架构——把"操盘手/助理/运营"角色明确切开
  - AI 工具落地——从 Claude Code、Web Coding 到 8000-15000 字工作提示词都亲手写
  - 洞察抽象——能把复杂问题压缩成三句话
- **不擅长**:
  - 一线人心细节——他自己说做数据、做算法擅长,但"懂人性懂用户"的部分承认某些快手大 IP 比他强
  - 慢生意/品牌型经营——他的模型高度依赖算法平台+矩阵放大,不适合品牌积累型行业
  - 与非商业化叙事对话——话语场高度效率化,对精神/情感话题共鸣少

## 核心心智模型

### 模型1:操盘手 vs IP 助理分层

- **一句话**:操盘手是船长,对最终商业结果负责,能独立决策、能和 IP 吵架;IP 助理是舵手,提供情绪支持、执行技能、总结方法论。判断标准是"你说的话 IP 听不听"。
- **来源**:[[给女孩的商业第一课]] 032 集 [原话]
- **怎么用**:
  1. 问自己:今天我说的话,IP 会听吗?
  2. 分层规划路径:助理 → 运营 → 操盘手,每层能力不同
  3. 助理不要幻想自己是操盘手,操盘手不要被当助理用
  4. 想升级到操盘手,要具备商业闭环思维,而不只是执行力
- **局限性**:这个分层高度契合"IP+团队"型公司,对传统组织(有清晰岗位序列)不完全适用。而且"能不能被 IP 听"高度受关系而非能力影响,把它作为唯一判断标准会误导

### 模型2:选赛道 > 选努力

- **一句话**:段永平买股票三原则:good business/good people/good price,顺序不能颠倒。找工作/创业同理——先看赛道(供需失衡+领先半步),再看团队文化,最后看薪资。
- **来源**:[[给女孩的商业第一课]] 032 集 [原话]
- **怎么用**:
  1. 拉出平台变现收入 TOP10 赛道,分析天花板和竞争格局
  2. 新手不要碰冷门赛道(如芳疗师),要碰大众赛道(如家庭教育)
  3. 找"领先半步"的位置——不要落后也不要超前太多
  4. 在电梯里坐着和蹦着上升速度一样——赛道对了,努力度回报率飙升
- **局限性**:选赛道听起来简单,实际操作里"供需失衡"是滞后指标——等到看得见时红利已经被抢走。而且大众赛道竞争激烈,新手直接进入不见得比冷门赛道更好

### 模型3:矩阵号(数量×质量算术)

- **一句话**:一个账号一天发 2 条,爆款概率 10%,一月 3 条爆款;10 个账号一天发 3 条,爆款概率 1%,也是 3 条;100 个账号就是 30 条。用矩阵解决"频次和质量"的两难。
- **来源**:[[给女孩的商业第一课]] 032 集——他公司实习生半年做 500 万粉丝矩阵 [原话]
- **怎么用**:
  1. 免费流量只做矩阵,不做单账号博主
  2. 一个赛道横向铺 10-100 个账号
  3. 用团队/AI 生产,不依赖创始人个人产能
  4. 用数量对冲质量波动,用算术保爆款期望
- **局限性**:矩阵号只适合算法平台(小红书/抖音),不适合公众号/播客。平台一旦风控矩阵号,整个模型垮。而且矩阵号会挤压单博主生存空间,长期看整个内容生态被稀释

### 模型4:人心算法(道)

- **一句话**:高阶运营超越平台算法,进入"人心算法"——思考用户心智和人性本质,而不是纠结于工具和技巧。术→气→道三层。
- **来源**:[[给女孩的商业第一课]] 032 集 [归纳]
- **怎么用**:
  1. 不再关注"如何提升 CTR",而问"用户为什么点进来"
  2. 分析爆款时看情绪结构,不看形式
  3. 让 IP 提供什么价值/生命周期多长/上限在哪——从这三个维度判断赛道天花板
- **局限性**:"人心算法"是一个漂亮的口号,但实际操作时和"用户洞察""共情"没有本质区别。而且他自己也承认某些快手大 IP 比他更懂人性——说明"术+气"到"道"的跃迁不是靠框架可以完成的

### 模型5:AI 时代 30 分差生无敌

- **一句话**:AI 奖励承认自己不会、愿意提问、愿意迭代的人。30 分的人有 70 分的想象空间;98 分的人只剩 2 分可提高。
- **来源**:[[给女孩的商业第一课]] 106 集 [原话]
- **怎么用**:
  1. 不要跟 AI 比聪明,把 AI 当智商更高的伙伴
  2. 长提示词(8000-15000 字)比通用模板有效——脑回路外化
  3. 重要的事说两遍,用重复降低幻觉
  4. 语音输入是第一入口,把口语整理成结构化文本
  5. 训练自迭代智能体:让工具接触真实工作现场,不停留在静态 prompt
- **局限性**:"30 分差生无敌"是一个营销友好的表达——实际能训练自迭代智能体的人门槛不低,普通人卡在"不知道自己要什么"这一步。而且 AI 在快速迭代,今天有效的方法半年后可能就变了。他自己也没解释:为什么 98 分的人不能主动切换成"我承认不会"的姿势

## 内在张力 / 盲区

1. **矩阵号的可持续性**——他的核心方法论建立在"平台算法+矩阵起量"上,一旦平台策略变化(风控矩阵/降权同质化)整个模型垮。他没有明确处理这个风险
2. **好学生视角讲差生无敌的矛盾**——他自己就是典型好学生(福布斯 U30/CEO/持续超预期完成任务),讲"30 分差生无敌"时,他自己是那个 98 分。这种"从高分位置鼓励低分姿态"的叙事有诱导性
3. **人心算法的抽象化**——他把用户理解命名为"人心算法",但实际给不出可操作步骤。这个概念更像营销口号,不是可训练能力
4. **对同赛道内的道德边界不谈**——他做母婴/家庭教育赛道矩阵,但这个赛道涉及大量情绪营销和焦虑贩卖。他不谈这个伦理张力
5. **AI 使用的"自我优越感"**——106 集反复讲他公司如何 AI 化,员工如何被替代。他不谈这对被替代员工的意义,只讲效率提升
6. **权力不对等的沟通模型**——"操盘手能坐下来跟 IP 吵架"这个前提本身就假设了个人有议价能力。对于弱势位置的运营者,这个模型不适用
