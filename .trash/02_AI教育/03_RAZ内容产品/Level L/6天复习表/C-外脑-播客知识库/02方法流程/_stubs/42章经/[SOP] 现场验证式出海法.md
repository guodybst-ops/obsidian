# 现场验证式出海法

## 一句话

出海不是在国内想象海外市场，而是直接站到真实用户所在的土壤上（行业展、用户社群、流量阵地），通过现场展示和面对面互动验证产品、找到真正的流量入口。英语不好不是障碍。

## 怎么用

### Step 1：判断是否值得出海

问三个问题：
1. 你的用户群体在海外是否比国内更大？
2. 海外用户的付费意愿和定价空间是否更好？
3. 你的产品是否不需要强本地化就能使用？

ACE Studio 的判断：全球音乐人有 1500 万（vs 国内约 10 万），海外付费率约 15%（vs 国内约 1-1.5%）。

### Step 2：找到行业的真实土壤

你的目标用户在哪里聚集（线下+线上）？
- 找到行业的核心展会、聚会、社区
- 找到他们日常使用的社交平台（不一定是你以为的那个）

ACE Studio 的方式：
- 线下：报名参加全球最大音乐展 NAMM
- 线上：发现洛杉矶音乐圈把 Instagram 当微信用（不是当抖音用），不是 Twitter

### Step 3：亲自去到那里展示产品

**不是先写好邮件**——Joe 联系了 100 多个 YouTuber 无人回复。

**而是直接出现**：
- 即使没有展位也挂个牌子给人展示
- 3 天制作物料，在当地买电视、音箱，搞定展台
- 现场展示产品 → 获得直接反馈 → 获取联系方式

### Step 4：建立信任背书 → 撬动流量

ACE Studio 的经历：
- NAMM 展上约 20 个格莱美获奖/提名音乐人留了联系方式
- 虽然没有直接带来新增，但建立了「被信任的氛围」
- 之后 YouTubers 开始回邮件（"朋友在 NAMM 上看到你们了"）
- 甚至更大 YouTuber 主动发邮件

### Step 5：找到真正的流量阵地 → 精准投放

- 不是泛投搜索广告（ACE Studio 投 Google 搜索 ROI 为 0）
- 而是找到该行业的流量阵地（对 ACE Studio 是 YouTube + Instagram）
- 只投 5 个 YouTuber 合作推广视频，平均几百到几千美金单价 → 收入从几十万人民币顶到几百万人民币

### 核心原则

Joe 的总结："我英语四级都没过。很多国内创业者一提到出海就天然害怕——其实是舒适圈。走出去那一下特别难，像起床。但起来之后，你会觉得挺爽。"

## 完整示例

以 ACE Studio 出海推演：

| 阶段 | 操作 | 结果 |
|---|---|---|
| 判断 | 全球音乐人 1500 万 vs 国内 10 万，海外付费率 15% vs 国内 1-1.5% | 决定出海 |
| 联系 YouTubers | 邮件联系 100+ 人 | 0 回复 |
| 参加 NAMM | 紧急报名、3 天备展、现场展示 | 20+ 格莱美级音乐人留下联系方式 |
| 建立信任后 | YouTubers 开始主动联系 | 获得合作机会 |
| 精准投放 | 投 5 个 YouTuber 视频 | 收入 10x+ |
| 结果 | 1 月时人民币收入 90% → 几个月后美金收入 90% | PMF 确认 |

## 适用场景与边界

### 什么时候用
- 产品的核心用户群体在海外比国内大
- 海外用户付费意愿更强（订阅制、信用卡绑定）
- B2C / Pro-C 类产品（个人信用卡决策）

### 什么时候不用
- 强依赖本地资源和关系的业务（如本地 O2O）
- B2B 大客户销售（需要更结构化的企业销售流程）
- 产品需要强本地化才能使用（但语言往往不是最大障碍）

### 已知局限
- 只适用于有明确行业聚集地的品类（NAMM 是音乐行业的特例）
- 需要创始人愿意亲自出国（Joe 英语四级没过也去了，但这需要勇气）
- B2B 场景下 Chinese exposure 可能有影响（但对 C 端/Pro-C 用户不 care）
- 效果并非立竿见影——ACE Studio 从联系 YouTubers 到真正起量花了好几个月
