# 定价动态调整三步法

## 一句话

定价不是上线后固定不变的，而是可以被持续测试的最强增长抓手。三步：识别高付费意愿的功能点 → 围绕定制化和品牌能力设付费门槛 → 保护老用户权益的同时做全生命周期 AB test。

## 怎么用

### Step 1：识别高付费意愿的功能点

付费意愿 = 用户真正在乎什么？

对于 AI 产品，重点看两类：
- **定制化能力**：用户想要独特的、与品牌相关的能力。例如自定义声音、角色一致性、品牌 kit、字幕模板
- **生产力上限**：用量上限、并发数、处理速度、存储空间

不是所有功能都可以收费。如果用户对该功能的价值感知不强，收费反而会吓跑用户。

### Step 2：测试定价元素

三个维度可以独立测试：

| 测试维度 | 具体项目 | 示例 |
|---|---|---|
| 价格 | 月付/年付/周付价格 | $19/月 vs $29/月 |
| 权益 | 不同 plan 包含什么功能 | Basic 不含 brand kit，Pro 含 |
| 触发时机 | 用户在哪个 moment 看到付费弹窗 | 用完免费额度 vs 创建第一个项目时 |

**优化付费弹窗**：单纯优化触发时机 + copywriting 可能带来 10%-30%+ 转化提升。弹窗应包括：
- 用户当前已使用的价值（"你已经创建了 5 个视频"）
- 升级后能获得的具体好处（"升级后解锁自定义品牌包"）
- 清晰的价格对比

### Step 3：保护老用户

任何定价调整的核心原则：**老用户不受损**。

- 涨价 → 老用户锁旧价格（grandfathering）
- 拆分 plan → 老用户自动获得最接近或更好的权益
- 增加年付折扣 → 老用户可自愿切换，不强制

为什么？老用户是口碑的基石。如果老用户感觉受损，流失的不仅是收入，还有品牌口碑。

## 完整示例

以 AI 视频产品为例：

1. **初始定价**：$19/月，所有功能全含
2. **数据分析发现**：用户最愿意付费的是"品牌包"（自定义 logo、字体、字幕模板）
3. **调整方案**：
   - Basic $19/月：基础剪辑 + 模板（老用户自动升级为此档，且锁价）
   - Pro $39/月：+ 品牌包 + 角色一致性 + lip sync
   - 年均约 $29/月（引导年付）
4. **AB test**：测试付费弹窗在"用完第三个免费视频后"出现 vs "用户首次用品牌包功能时"出现
5. **结果**：触发时机优化后转化率提升 20%，年付占比从 30% 提升到 50%

## 适用场景与边界

- **适用**：SaaS 产品、AI 工具、订阅制产品的早期到成长期定价调整
- **不适用**：已建立强品牌心智的大规模产品（大幅调整可能引起公关危机）
- **已知局限**：需要产品本身有足够的价值感知，否则定价调整是杯水车薪；AB test 需要用户量基础
