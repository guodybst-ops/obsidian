# [SOP] BD 全流程五阶段法

## 一句话

按五个阶段推进 BD：**线索确认 → 建联 → 增信 → 转化 → 持续经营**，每阶段有交付物和过关判据。

## 什么时候用

- 高客单价 B2B 销售 / 金融服务 / 专业服务 / BD 岗位
- 从零开始搭一条新的客户拓展链路
- 老客户开发效率下滑，需要按阶段回查漏在哪一步
- **红线**：不适用于纯自助式 PLG 产品、标准化低价快消

## 输入

- 明确的产品和成交额假设（例："客单 50 万起的家办服务"）
- 每周 ≥ 15 小时可分配的 BD 时间
- 预算：至少 3 个月生活储备（客户信任期通常 3-6 个月）

## 输出

- 一份**双画像卡**（客户画像 + 渠道伙伴画像）
- 一条**可复用的建联话术**（陌拜版 + 转介绍版）
- 一份**增信 6 项清单**
- 一份**成交前 3 问关单表**
- 一份**长期定位三问答案**

## 主流程

### Stage 1：线索确认——画出两张画像

- 写出**客户画像卡**：资产门槛 / 行业 / 圈层 / 所在地
- 推导**渠道画像卡**：谁会接触到你的客户？回答"他们在哪些圈层出现？谁会转介绍？"
- 判断过关信号：能列出 20 个以上具体的候选客户名字 + 10 个以上候选渠道人

### Stage 2：建联——陌拜 or 转介绍

- **陌拜路径**：3-10 秒话术必须切"这件事和你有关"（对方近期公开活动/成就/需求），**不要**用"我是谁"作为开场
- **转介绍路径**：先定义自己（让介绍人能一句话说清"你是谁 + 为什么值得见"）→ 再筛介绍人（**意愿度 > 资源数量**）→ 首选目标客户之间互相介绍
- 判断过关信号：本周至少产生 3 次实质对话（≥15 分钟深度）

### Stage 3：增信——按 6 项清单自查

对着**增信 6 项清单**（见下方）逐条打勾，任一项否 → 回补再见客户。

### Stage 4：转化——按公式和 3 问关单

- 套用公式：**成交 = 需求匹配 × 信任到位**
- 关单前对着"成交前 3 问关单表"（见下方）自问，任一"否" → 不谈成交，回退到 Stage 3 或 Stage 1

### Stage 5：持续经营——回答长期定位三问

每季度回顾 + 回答：
- **你是谁**？（自我认同与目标一致）
- **你想要什么**？（明确目标，才能让别人知道如何帮你）
- **你愿意付出什么代价**？（资源、时间、精力的边界）

判断过关信号：老客户主动转介绍新客户 ≥ 1 次/季度。

## 判断点 / 决策树

```
Stage 1 完不成 → 产品定位不清，回头改产品定义，不是练 BD
Stage 2 建联率 < 10% → 陌拜话术错 or 渠道人意愿度筛错
Stage 3 6 项自查 < 4 项 → 别急着谈单，先修个人形象一致性
Stage 4 关单 3 问有"否" → 别硬推，转介给更合适的人（长期信誉>单次成交）
Stage 5 一年没老客户回头 → 回 Stage 1 重画画像，客户群选错了
```

## 模板 / 清单 / 打分卡

### A. 双画像卡（Stage 1 交付物）

| 画像项 | 客户画像 | 渠道伙伴画像 |
|---|---|---|
| 门槛/身份 | 例：1000 万美金以上境外资产 | 例：跨境律师 / CFO / 上市公司高管圈 |
| 出现在哪 | 例：跨境贸易圈 / 美港股上市公司 / 科技圈高管圈 | 例：律所活动 / CFO 私享会 |
| 关键筛选 | 明确一票否决线 | **意愿度 > 资源数量** |

### B. 建联话术模板

**陌拜版**：
> "[对方名字]老师你好，看到你上周[具体公开活动/成就]，我在做的[XX 服务]恰好可能对你[具体场景]有帮助。想约 15 分钟聊聊，你方便的时间是？"

**转介绍版**（给介绍人的一句话托付）：
> "我在做[一句话产品定位]，你如果遇到[具体客户画像]，能不能帮我提一句？我可以先请你喝个咖啡，聊聊我这边最近的案例。"

### C. 增信 6 项清单（Stage 3 过关表）

- [ ] 头像、朋友圈、表达风格与目标形象一致
- [ ] 建联话术真诚、不秀小聪明
- [ ] 会面安排专业（时间、地点、准备）
- [ ] 送别和后续反馈到位
- [ ] 提供经济价值 or 情绪价值（至少一种，最好两种）
- [ ] 长期行为保持一致性（3 个月内没有出现"人设崩塌"事件）

### D. 成交前 3 问关单表（Stage 4 过关表）

- [ ] 我清楚对方**真正**需要什么吗？（不是他嘴上说的，是深层动机）
- [ ] 我能提供对方需要的东西吗？（评估产品能力与承诺边界）
- [ ] 如果我不能，我是否应该介绍给更合适的人？（长期信誉 > 单次成交）

### E. 长期定位三问（Stage 5 季度自答）

| 问题 | 本季答案 | 上季答案对比 |
|---|---|---|
| 你是谁？ | | |
| 你想要什么？ | | |
| 你愿意付出什么代价？ | | |

## 常见坑

- ❌ **跳过 Stage 1 直接建联**——没画像的建联是撞大运，转化率不到 5%
- ❌ **用"我是谁"作为陌拜开场**——对方 3 秒内就会走神
- ❌ **拿转介绍数量当 KPI**——意愿度 < 3 分的介绍人给你的机会全是应付
- ❌ **Stage 3 靠一次会面完成**——增信是长期一致性，不是单次表演
- ❌ **Stage 4 强推**——一次强推可能毁掉三次转介绍机会

## 附录 A：完整跑通示例（科技家办）

1. **线索确认**：客户画像 = 1000 万美金以上境外资产的科技圈高管。渠道画像 = 跨境律师、会计师、美港股上市公司 CFO、科技圈意见领袖。
2. **建联**：从一位已合作客户处获得转介绍——客户说"我认识一个人，刚上市，正在考虑海外资产配置，我帮你问问"。
3. **增信**：第一次见面先聊对方关心的上市后挑战，再展示家办的专业能力（历史业绩、团队背景），最后表达真诚的合作意愿。
4. **转化**：对方最关心子女海外教育和税务规划——家办恰好有这两方面的专家资源，专业匹配 + 信任达成。
5. **持续经营**：每季度提供一次市场分析和资产配置建议，不频繁推销，让对方觉得你是专业伙伴而不是销售。

## 附录 B：适用与边界

- **适用**：高客单价 B2B 销售、金融服务、专业服务、BD/商务拓展
- **不适用**：纯自助式 PLG 产品、标准化低价产品
- **已知局限**：高度依赖个人信任和长期关系，难以规模化；不适合短期交易型业务
