# 扑克式资金管理与情绪控制原则

## 一句话

将每次下注/投资的金额控制在不会影响心态的水平，确保资金波动不影响决策质量。核心原则：如果投入金额本身会影响情绪和判断，就说明级别过高。

## 怎么用

### Step 1：设定单次投入上限

参考Ricky Mao的建议：锦标赛单场买入控制在可支配资金的0.5%左右。
原因：100个买入的下风期很常见。只有把单次波动控制到足够小，人才能保持稳定心态。

迁移到其他场景：
- 投资：任何单一仓位不应放大到足以摧毁心理稳定的程度
- 创业决策：任何单一赌注不应让你输不起
- 时间分配：不把所有时间押在一个不确定的方向上

### Step 2：重置心态——下一手从零开始

每次决策后，无论输赢，心理上重置：
- 从下一手牌开始，所有东西从零开始
- 过去输赢不能影响当前动作
- 输钱后想"赶本"会让心理状态暴露，被对手利用

### Step 3：Double Down需有理性理由

亏损后加仓不是绝对错误，但必须有理性理由：
- 资产被低估、安全边际提高
- 市场情绪错杀、基本面未变
- 不是因为想翻本或为了降低平均成本让自己舒服

### Step 4：观察自己的情绪偏移

把自己当成样本定期观察：
- 经历bad beat（小概率反向事件）后，哪些动作与平时不同？
- 即使100手牌中只有1手受影响，也可能吞噬整个session的盈利
- 定期复盘自己的情绪状态和决策质量

## 完整示例

以个人投资者的资金管理推演：

```
可支配资金：100万元
单笔最大投入（按0.5%）：5000元
（实际上投资可能需要更大，但核心原则不变：不要让单次损失影响你晚上睡觉）

场景1：你投了5万元在一个项目上，它腰斩到2.5万
- 如果这让你焦虑失眠→说明投入过高
- 调整：下次同类项目最多投2万

场景2：你在市场上连续亏损3笔
- 心理状态：想"把亏损赚回来"
- 正确做法：暂停交易，重置心态，从零开始重新分析
- 错误做法：加大仓位试图翻本

场景3：你遭遇了一个小概率坏事件（bad beat）
- 观察自己：愤怒？想立刻报复性交易？
- 记录：这种情绪下我的决策和平时有什么不同？
- 下次有同类情绪时，识别并暂停
```

## 适用场景与边界

**适用场景**：
- 投资/交易的仓位管理
- 创业中的风险管理
- 任何需要持续决策且结果波动大的领域（销售、谈判等）

**局限性**：
- 0.5%是锦标赛场景的数字，其他场景的比例需要自行校准 [AI推理]
- 过于保守可能导致错失机会——需要在"不被波动影响"和"足够激进"之间找平衡点
- 现实世界的很多机会无法精准控制"买入量"（如创业机会往往是一锤子买卖）[AI推理]
