# 生命力四维度评估模型

## 一句话

用于评估创业者（或自己）穿越周期的底层能力。四个维度：韧性、定力、自我净化、自我突破。每个维度都可以通过行为信号来观测，不只是概念层面的讨论。

## 怎么用

### 四个维度的操作定义 + 观测信号

**韧性 — 遇到痛苦时不散**

| 观测信号（这个人有韧性） | 观测信号（这个人韧性不足） |
|---|---|
| 经历过多次低谷又爬起来，能具体说出某次低谷中学到了什么 | 第一次真正遇到挫折后就放弃或转行 |
| 痛苦经历不是「忘掉了」，而是「被整合进自己的叙事」 | 回避谈论失败经历，或把失败全部归因于外部 |
| 能用身体感受而非抽象词汇描述艰难时刻（如张津剑描述打完青霉素膝盖疼20分钟） | 对艰难时刻的描述全是「那段时间挺难的」之类的抽象概括 |

→ 评估方式：让对方讲一个最低谷的时刻。不是在问「发生了什么」，而是在观察他**讲述低谷时的具体程度和情绪整合程度**。

**定力 — 膨胀时收住，悲观时保持思考**

| 观测信号 | 危险信号 |
|---|---|
| 能明确说出「哪些钱/机会我主动放弃了」 | 所有机会都要抓、所有钱都要拿 |
| 在市场最热时做过减速决策（如张津剑 2021 年全年不投新项目） | 融资、扩张节奏完全跟随市场情绪 |
| 在市场最冷时还能讨论「长期看这个方向是对的」 | 悲观时否定整个方向，乐观时否定所有风险 |
| 十年坚持做一件事，不追逐短期风口 | 每年换方向，追逐热点（高频策略） |

→ 自检方式：回想上一次你被表扬/追捧的时刻。你内心有没有「一丝骄傲」？那一刻你做了什么？唐朝和尚的寓言——「起那一丝骄傲，下一秒所有神通都消失」。

→ 022 新增视角：定力不是一天做十件事，而是十年坚持做一件事。有定力的人是频率更低的人——频率更低，能耗更低，穿透力更强。面对高频世界，解法不是更快而是更定；回到产业核心问题和自身核心能力上。

**自我净化 — 旧经验失效时放下 ego**

| 观测信号 | 危险信号 |
|---|---|
| 能明确说出「我过去相信但现在不再相信的东西」 | 始终用同一套方法论解释所有问题 |
| 主动寻求反馈，尤其是否定性的反馈 | 只在舒适圈内与人交流，回避批评 |
| 能从失败中提炼出「我的哪个假设错了」，而不是「市场不行/团队不行」 | 失败后的归因全是对外指责 |
| 能区分「事实」和「对事实的标签」，不过度打标签遮蔽世界 | 快速给人/事物打标签，用弹幕掩盖 4K 电影 |

→ 自检方式：你上次承认「我以前的判断是错的」是什么时候？如果是三年以前，你可能卡在某个旧荣耀里了。

→ 022 新增视角：张津剑反思自己作为投资人过度标签化的习惯——世界是 4K 高清电影，每一个标签都是一条弹幕。弹幕太多，就看不见世界本身。现在练习看到一个人时先不打标签，全然看见对方。

**自我突破 — 从旧壳中挣脱**

| 观测信号 | 危险信号 |
|---|---|
| 有明显的「版本迭代」轨迹（如从技术思维→商业思维→组织思维） | 三年前的自己和现在没有本质区别 |
| 能在低谷中完成进化，而非在顺境中才成长 | 只在成功时「感觉成长了」 |
| 对自己有清晰的「下一阶段我要变成什么」的想象 | 对未来的自己的想象只是「更大的现在的自己」 |
| 做过「面向死亡的复盘」：不是强迫改变自己，而是接纳真实自我后重组团队和策略 | 复盘总想改变自己，但从未接受过自己 |

→ 自检方式：如果三年前的你看到现在的你，会觉得「这个人不一样了」还是「还是老样子」？

→ 043 新增视角：两个关键操作——① 把自己的问题当成朋友的问题来思考；② 模拟认可的高手会如何回答这个问题，再向对方请教校准差异。这本质上是对自己做蒸馏、SFT 和 RL 的认知训练。

### 022 新增：生命力的事后表现——实事求是 + 爱自己

张津剑在 022 集进一步将生命力展开为两个可观察的行为特征：

**特征一：实事求是**
- 真正强的创始人听到刺耳信息时，不会先陷入自尊、感受或反击，而是立刻判断这句话是否指向真实问题。如果问题真实就马上修正。
- 实事求是需要勇气——大多数人做不到是因为没有勇气面对潜在风险和困难。
- → 观测方式：给别人一个否定性的反馈，观察对方的第一反应是「辩解/防御」还是「判断这个反馈是否真实」。

**特征二：爱自己**
- 不是自恋，而是无条件接纳当下的自己，放过自己。
- 一个爱自己的人会把经历过的弯路看成生命材料，而不是用自责和苛责反复消耗自己。
- 很多人不爱自己只是假装爱别人——用对外付出换取预期回报。当预期落空就会愤怒：「我给了你饼干，你居然没说谢谢」。真正的「爱自己然后溢出去」就像把骨头丢给狗——不会期待狗说谢谢。
- → 自检：你对自己这半年走的弯路的第一反应是什么？是「我真傻浪费了时间」还是「有点意思，以后写书知道写什么了」？

### 综合评估：四个维度画线

快速打分（1-5）：

| 维度 | 评分 | 证据（必须填写具体事件，不能是感觉） |
|---|---|---|
| 韧性 | /5 | |
| 定力 | /5 | |
| 自我净化 | /5 | |
| 自我突破 | /5 | |

**解读**：
- 四维都低（<3）：在顺境中可能表现不错，但第一次真正挫折会暴露
- 韧性高但定力低：能扛事但扛不住诱惑——资本热的时候容易飘
- 定力高但自我净化低：能稳得住但不能自我更新——适合守成不适合创新
- 四维都高（≥4）：有穿越周期的底层能力。注意这不等同于「一定会成功」，而等同于「即使失败也能再来」

### 043 补充：心力的角色

张津剑在 043 集提出：「工业革命让人从体力工作者变成智力工作者，而 AI 时代会让人从智力工作者变成心力工作者。」驱动注意力的不是智力而是心力——在困难时坚持、在骄傲时克己。

**保护心力的方法**：
1. 早上起床前一段时间尽量不看手机——刚醒来心力和注意力都在恢复，立刻进入信息流容易被带走
2. 不要把心力消耗在让自己痛苦、无意义、无法产生价值的事情上
3. 让自己进入低能耗状态：坚持长期事情，减少对短期变化的即时响应

## 适用场景与边界

**适用场景**：
- 创业团队评估创始人/联合创始人
- 投资人对创始人的深度判断（尤其穿越周期的能力）
- 个人自我诊断（在一个低谷期想了解自己的真实状态）

**不适合**：
- 短期项目或单次交易的参与者评估（不需要穿越周期）
- 对不熟悉的人做快速判断（需要深入了解或多次接触才能获取有效观测信号）

## 为什么这个模型不只是「鸡汤」

张津剑的关键区分：

| 常见误解 | 实际含义 |
|---|---|
| 生命力 = 正能量/热血 | 生命力 = 反复经历痛苦-康复-重新开始形成的身体记忆 |
| 定力 = 冷静/稳重 | 定力 = 在聚光灯和低谷中都能控制心的能力，不是性格而是训练；也是一种「降频」——降低自身信息处理的频率 |
| 自我突破 = 学习新技能 | 自我突破 = 放下过去让你成功的那个自己 |
| Gartner曲线是技术曲线 | Gartner曲线是人心的曲线——膨胀→绝望→自我救赎 |
