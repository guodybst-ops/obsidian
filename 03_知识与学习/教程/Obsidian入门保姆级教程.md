## 二、视频逐板块核心内容

### 1. 软件下载与仓库新建

1. 官网下载适配电脑系统的安装包，安装无捆绑、极简轻量化。
2. 核心概念：**仓库 (Vault)** 就是电脑本地文件夹，所有笔记以**纯 Markdown 格式**本地保存，数据完全属于自己，无平台锁限制，离线也能正常使用。
3. 新建仓库步骤：命名→选择存储路径（建议非 C 盘，可放云盘文件夹实现多设备同步）→一键创建。

### 2. 新手必做基础设置

1. 语言设置：修改为简体中文，适配国内使用习惯。
2. 文件与链接配置：设置附件（图片等）单独存入指定子文件夹，避免仓库杂乱；默认启用 **[[双链链接]]** 格式。
3. 编辑器设置：开启自动配对符号，新手推荐实时预览模式，兼顾编辑与排版预览。
4. 外观基础：可更换简约主题，优化界面观感。

### 3. 基础操作与核心功能

1. 笔记基础：新建、重命名、删除笔记，侧边栏文件栏快速管理文件。
2. **双链核心用法**（Obsidian 灵魂）：输入`[[笔记名]]` 快速关联已有笔记；未存在的笔记直接输入名称回车可一键新建，自动生成双向反向链接，知识点互联互通。
3. 知识图谱：开启图谱视图，可视化查看所有笔记关联网络，直观梳理知识体系。
4. 反向链接：自动展示当前笔记被哪些其他笔记引用，方便回溯梳理。

### 4. Markdown 常用语法速成

教程精简新手必备语法，直接套用即可：标题、粗体、斜体、列表、待办勾选、引用、代码块、高亮等，满足日常笔记、学习、工作记录全部需求。

### 5. 核心插件安装与使用

1. 关闭安全模式，开启第三方插件市场。
2. 必装基础插件：绘图白板插件（思维导图、自由构图）、冗余图片清理插件（自动删除无用缓存图片）、每日笔记插件（自动生成日记模板）。
3. 插件极简配置，无需复杂调试，安装即用。

### 6. 文件夹结构规划（新手直接抄作业）

给出通用标准目录，适合所有人：收集箱、每日日记、项目笔记、学习领域、资源素材、归档、模板文件夹，层级简洁不复杂，养成规整笔记习惯。

### 7. 高阶快速技巧

1. 快捷键入门：快速唤起命令面板、分屏编辑、笔记切换，提升效率。
2. 模板用法：新建通用笔记 / 日记模板，一键套用，省去重复排版。
3. 标签与属性基础：用标签分类知识点，用属性标注笔记元信息，方便后期检索筛选。
