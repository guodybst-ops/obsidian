# XML

> [!summary]
> **XML（可扩展标记语言）是一种用标签组织结构化数据的文本格式。** 它主要用于描述、存储和传输数据；标签由数据设计者自行定义，而不是像 HTML 一样由标准预先规定。

## XML 是什么

- XML 全称为 **eXtensible Markup Language**（可扩展标记语言）。
- 它用成对的标签和层级关系表达数据，例如一张便签可以包含收件人、发件人、主题和正文。
- “可扩展”指可以按业务需要定义自己的标签和数据结构，例如 `<student>`、`<score>`、`<course>`；并不表示 XML 会自动增加功能。
- XML 本身只是数据的载体。要读取、传输、校验或显示它，还需要相应的软件或程序。

## 一个最小示例

```xml
<note>
  <to>Tove</to>
  <from>Jani</from>
  <heading>Reminder</heading>
  <body>Don't forget me this weekend!</body>
</note>
```

这段内容表达的是一条便签：`note` 是整体，内部字段分别说明发给谁、来自谁、主题和正文。即使不认识英文，也能从标签大致理解数据含义，这就是 XML 的“自描述性”。

## XML 与 HTML 的区别

| 对比项 | XML | HTML |
| --- | --- | --- |
| 首要目的 | 描述、存储和传输数据 | 展示网页内容 |
| 标签 | 可自行定义 | 大多由 HTML 标准预先定义 |
| 关注点 | 数据的含义和结构 | 内容的外观与页面结构 |
| 是否直接展示效果 | 否，需要程序或样式配合 | 是，浏览器可直接渲染 |

因此，**XML 不是 HTML 的替代品**。两者可以配合：XML 提供数据，HTML（或其他界面技术）负责呈现。

## 需要避免的误解

- XML 不是编程语言：它不能自行计算、判断或执行任务。
- XML 不等于网页：它是文本格式，网页只是它可能服务的一种应用场景。
- XML 不负责“好看”：它只定义数据的结构；显示方式需要由应用程序、样式或界面另行决定。

## 记忆方式

把 XML 想成一份**带字段名的数据表单**：

```text
数据内容 + 自定义标签 + 层级结构 = XML 文档
```

例如在 RSS 中，XML 可用来描述每篇内容的标题、链接和发布时间，阅读器再根据这些数据展示更新。
