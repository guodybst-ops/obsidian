### 一、工具定位：Claude Code 的国产平替

腾讯 WorkBuddy 是一款适合国内网络环境的 AI 办公智能体，可替代 Claude Code / Codex 完成以下工作：

- 将常用流程沉淀为 **Skills（技能）**，反复调用；
    
- 设置**自动化任务**，定时运行；
    
- 打通**微信/企微/飞书/钉钉**，通过聊天远程命令电脑操作。
    

---

### 二、安装与界面速览

**安装（无门槛）**

- 官网下载

**界面结构**

- **左上角**：搜索历史任务。
    
- **聊天框**：与普通 AI 对话一致，模型选"Auto"即可自动适配难度。
    
- **头像处**：查看剩余积分余额。
    
- **Cloud 栏**：手机端发送的消息汇总于此。
    
- **专家**：预设角色提示词（如"内容创作专家"可一键生成小红书文案）。
    
- **技能**：预设工作流，对话时触发关键词会自动激活，也可手动点击 Skills 启用。
    

**连接微信/飞书等**

- 在"Claw设置"中选择对应应用，按步骤配置即可。
    

---

### 三、与 Obsidian 联动的三种用法

**用法一：直接读取知识库回答问题**

1. 新建任务，告诉 WorkBuddy 你的 Obsidian 仓库路径（复制仓库路径粘贴即可）。
    
2. 它会自动扫描所有笔记并统计内容。
    
3. 可提问如"我今天生产效率怎么样？"或"我看过哪些主题的书？有什么共同点？"，它会综合分析日记、笔记内容给出答案。
    

**用法二：批量处理笔记**

- 直接下达指令，如"批量修改某类笔记的标签"或"将某些笔记移动到指定文件夹"，它会自动执行。
    

**用法三：将高频操作沉淀为 Skills**

- 调试成功后可固化为技能，例如：
    
    - 将 Obsidian 文稿整理后上传至公众号草稿箱；
        
    - 读取一个月日记中的工作记录生成月报；
        
    - 将书籍原文与读书笔记结合提炼为播客大纲。
        
- 一次调试，后续一键调用。

### 四、优缺点总结

**优点**

- 完美适配国内网络环境，无需科学上网；
    
- 微信/企微/飞书等聊天入口配置简单，上手极快；
    
- 技能和自动化功能满足绝大多数日常需求。
    

**缺点**

- 模型能力偏弱（相比 Claude Code / Codex），处理复杂任务时分析深度不足；
    
- 长链路任务可能卡顿或跑死；
    
- 手机端操作需电脑保持开机（与同类工具一致）；
    
- 自由度有限，所有功能均为预设，不适合深度折腾型用户。
    

---

### 五、结语

WorkBuddy 不是最强大的，但门槛极低、基本够用。若你因网络或费用问题无法使用 Claude Code / Codex，它是很好的平替。

**核心建议**：无论用哪款工具，关键是从现在开始持续在 Obsidian 中积累数字资产。将可执行操作的 AI 接入后，生产才有参考依据和工作流程手册——这才是 Obsidian 记笔记的本质：成为你在 AI 时代的**神经中枢**。
