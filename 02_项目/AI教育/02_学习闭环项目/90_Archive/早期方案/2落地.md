# 一、先纠正一个关键认知

你现在脑子里的AI老师是：

> “一个什么都懂、随时讲课的超级老师”

但真正可落地的AI老师应该是：

> **“一个被知识库和规则约束的出题与练习引擎”**

区别非常关键：

|模型幻想|现实产品|
|---|---|
|无限自由讲课|被知识点结构约束|
|自由生成答案|有标准答案体系|
|追求“聪明”|追求“稳定正确”|

---

# 二、你这个MVP的核心架构（非常重要）

你这个产品要拆成3层，而不是直接让AI“自由发挥”。

---

## 🧠 第一层：知识层（防幻觉核心）

👉 你必须先“限制AI能用的知识”

不是让AI随便讲，而是：

### ✔ 输入必须结构化

例如：

```
知识点：分数加法规则：1. 同分母分数直接相加分子2. 分母不变3. 结果要约分例题：1/3 + 1/3 = 2/3
```

👉 这一层的本质是：

> 给AI一个“标准教材范围”

---

## 🧠 第二层：生成层（AI做题）

AI只能做一件事：

> “基于给定知识点生成题目”

输出必须结构化：

```
{  "question": "1/4 + 1/4 = ?",  "type": "填空题",  "answer": "1/2",  "knowledge_point": "分数加法"}
```

⚠️ 关键限制：

- 不允许AI自由讲解知识
- 不允许扩展知识点
- 不允许“猜”

👉 只允许“出题”

---

## 🧠 第三层：校验层（防幻觉核心）

这是你这个产品**真正的护城河**

### 每道题必须经过2次校验：

### ✔ 校验1：规则一致性检查

- 是否符合知识点规则？
- 是否超纲？

### ✔ 校验2：答案可验证

- 用计算器 / Python / 规则引擎验证答案

比如：

- 数学题 → 用代码算一遍
- 英语语法 → 用模板规则检查

---

👉 这一步是关键：

> AI负责“生成”，系统负责“正确性”

---

# 三、错题系统怎么做（你产品的核心价值）

这里是你真正能赚钱的地方。

---

## 📌 错题不是“记录”，而是三件事：

### ① 错因识别（AI做）

例如：

- 计算错误
- 概念不清
- 题型没见过

---

### ② 知识点回溯（系统做）

错题 → 绑定知识点

比如：

```
错题：1/3 + 1/6→ 知识点：通分
```

---

### ③ 自动再训练（AI生成）

系统自动生成：

- 同类题（简单）
- 变形题（中等）
- 提升题（进阶）

---

👉 这一块本质是：

> “错题 → 训练闭环引擎”

---

# 四、你最关心的问题：怎么避免AI胡说？

我给你一套**实战级解决方案**：

---

## 🚫 方案1：禁止自由生成（最重要）

不要让AI“讲课”

只允许：

- 出题
- 改题
- 生成解析（基于规则）

---

## 🚫 方案2：知识点白名单

每个AI请求必须带：

```
允许知识点列表：- 分数加法- 分数减法- 分母通分
```

👉 AI不能跳出这个范围

---

## 🚫 方案3：答案必须可验证

所有题目必须：

- 数学 → Python验证
- 英语 → 模板匹配
- 语文 → 标准答案库对比

---

## 🚫 方案4：双模型机制（进阶）

- 模型A：生成题目
- 模型B：审题（检查错误/超纲）

---
