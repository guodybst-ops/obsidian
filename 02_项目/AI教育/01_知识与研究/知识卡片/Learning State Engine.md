# Learning State Engine

上级入口：[[02_AI教育/01_知识与研究/AI教育知识地图|AI教育知识地图]] · [[02_AI教育/01_知识与研究/研究专题/AI教育/AI教育专题地图|AI教育专题地图]]

## 一句话定义

Learning State Engine 是一个用学习证据持续更新学生状态，并决定下一步训练策略的系统。

## 核心链路

```text
知识点 -> 题目 -> 作答 -> 批改 -> 错因 -> 状态更新 -> 下一步练习 -> 报告
```
