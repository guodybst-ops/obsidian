# AI教育知识地图

上级入口：[[⭐00_首页]] · [[02_AI教育/01_知识与研究/研究专题/AI教育/AI教育专题地图|AI教育专题地图]]

这张地图负责把 AI 教育相关概念、案例、方法、项目和输出接起来。以后新增资料时，优先想清楚它属于下面哪一块。

## 1. 核心命题

> AI 教育产品的关键，不是多生成一些内容，而是能不能把学习过程做成可验证、可复训、可报告、可收费的闭环。

主线闭环：

```text
内容 / 知识点输入
-> AI 出题
-> 学生做题
-> AI 批改
-> 错因分析
-> 同类题再练
-> 掌握度更新
-> 学习报告 / 老师报告 / 家长报告
```

## 2. 基础概念层

- [[04_资料库/02_其他知识/概念卡片/旧知识库概念/LLM 大语言模型|LLM 大语言模型]]：底层能力，不是最终壁垒。
- [[04_资料库/02_其他知识/概念卡片/旧知识库概念/RAG 检索增强生成|RAG 检索增强生成]]：未来做教材、题库、资料检索的基础。
- [[04_资料库/02_其他知识/概念卡片/旧知识库概念/MCP|MCP]]：未来工具接入和自动化能力入口。
- [[AI 出题]]：从资料、知识点、错因生成练习。
- [[AI 批改]]：识别答案、过程、错因和反馈。
- [[错题闭环]]：从错题到再练，再到掌握度更新。
- [[学习报告]]：把学习结果转成家长、老师、机构能理解的证据。
- [[知识图谱]]：知识点、题型、错因之间的关系网络。
- [[掌握度模型]]：红黄绿、概率、证据权重等状态表达。

## 3. 产品模块层

- 内容输入：教材、真题、讲义、PDF、Word、视频字幕、老师手写资料。
- 题目生成：选择题、填空题、阅读理解、听力、作文、错题再练。
- 作答采集：文字、拍照、表单、小程序、网页。
- 批改反馈：答案判断、过程判断、错因判断、讲解。
- 状态更新：知识点掌握度、题型熟练度、错因频率。
- 报告输出：学生报告、家长报告、老师报告、机构续费报告。

## 4. 竞品与案例层

- [[StudyFetch]]：资料输入 -> 笔记 / 闪卡 / Quiz，强在轻入口，弱在深闭环。
- [[师者AI]]：偏 AI 老师和讲题入口，风险是容易变成通用模型套壳。
- [[豆包爱学]]：大模型和流量强，机会在更垂直、更闭环、更结果导向。
- [[PEP 英语]]：当前最小验证场景之一。
- [[RAZ 分级阅读]]：适合作为英语阅读内容产品和 AI 陪练素材。
- [[K12 B端教培机构]]：更像生意，买的是降本、续费、报告和招生工具。
