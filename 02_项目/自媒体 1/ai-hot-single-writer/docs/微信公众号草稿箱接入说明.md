# 微信公众号草稿箱接入说明

当前项目已经预留接口：

```text
POST /api/wechat/draft
```

但默认不会真正推送到微信公众号。

## 为什么默认关闭

公众号自动发布不是普通网页自动化，涉及平台权限和内容风险。

第一版建议只做到：

```text
生成公众号草稿
→ 保存到 Obsidian
→ 人工确认
→ 手动复制到公众号后台
```

等账号权限确认后，再接：

```text
生成公众号草稿
→ 上传正文图片
→ 上传封面素材
→ 创建公众号草稿箱草稿
→ 人工确认发布
```

## 接入前需要确认

| 检查项 | 说明 |
|---|---|
| 公众号主体类型 | 个人号和企业号权限不同。 |
| 是否认证 | 认证号通常接口权限更完整。 |
| AppID / AppSecret | 服务端接口调用必需。 |
| IP 白名单 | 微信公众号接口通常要求服务器 IP 在白名单。 |
| 素材上传权限 | 正文图片和封面图需要先上传到微信素材系统。 |
| 草稿箱接口权限 | 需要能调用新增草稿接口。 |

## 后续要实现的接口步骤

1. 获取 `access_token`。
2. 上传正文图片，换成微信图片 URL。
3. 上传封面图，获取 `thumb_media_id`。
4. 把 Markdown / HTML 正文转换成微信兼容 HTML。
5. 调用新增草稿接口，生成草稿箱内容。
6. 返回草稿 ID 和状态。

## 环境变量

```env
WECHAT_DRAFT_ENABLED=false
WECHAT_APP_ID=
WECHAT_APP_SECRET=
```

真正接入时再改成：

```env
WECHAT_DRAFT_ENABLED=true
```

## 建议策略

先不要做无人值守自动发布。

更稳的策略是：

```text
自动进草稿箱，人工点发布。
```

公众号内容涉及事实、版权、平台审核、标题风险，最后一步人工确认很有价值。
