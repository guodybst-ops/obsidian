# Lucy的雷霆英语王国小程序产品需求说明

## 一句话定位

给小学六年级学生 Lucy 使用的 RAZ 英语课后复习小程序：老师课后录入生词和词组，小程序自动生成发音、释义、例句和复习任务，学生通过学习日历和积分奖励保持每日复习。

## 目标用户

- 学生：Lucy，小学六年级，需要课后复习 RAZ 课文、生词、词组和句子发音。
- 老师：课后不能每天陪读，需要把课堂知识点变成可自主学习的小任务。
- 家长：希望看到孩子是否学了、学了多久、有没有坚持。

## 核心场景

1. 老师上完课后，把本节课的单词和词组输入小程序。
2. 小程序自动生成发音、中文、音标、原文句子和造句。
3. Lucy 打开小程序，按课文复习知识点，点击播放跟读。
4. 系统记录当天学习时长、学习知识点、连续学习天数。
5. Lucy 完成每日任务获得积分，用积分兑换奖品。

## 页面一：知识点

### 页面目标

让 Lucy 快速找到某篇 RAZ 课文，并复习课后知识点。

### 页面结构

- 顶部标题：Lucy的雷霆英语王国
- 筛选区：Level 下拉框 + 搜索框 + 录入按钮
- 照片墙：默认露出一部分，点击展开后展示全部，右下角显示选择照片
- 课文卡片：展示课文名、知识点列表
- 知识点详情：点击后展开中文、音标、原文句子、造句

### 关键功能

- 支持按 Level A-Z 筛选。
- 支持搜索课文名、知识点、单词、词组。
- 支持播放单词、词组、句子发音。
- 支持老师录入知识点并生成预览。

## 页面二：学习日历

### 页面目标

让老师、家长和 Lucy 看到学习是否持续。

### 页面结构

- 今日已学时长
- 今日已学知识点数量
- 月度学习热力图
- 月度累计学习数据
- 下方预留区域

### 关键功能

- 记录当天学习时长。
- 记录当天学习知识点。
- 统计累计学习时长、天数、知识点数量。
- 用热力图展示本月学习强度。

## 页面三：任务与积分库

### 页面目标

通过任务和奖品，让 Lucy 愿意每天打开小程序复习。

### 页面结构

- 上方头像区：可替换头像。
- 下方叠卡区：今日任务卡 + 积分兑换库卡。
- 点击露出的卡片切换任务和兑换库。

### 今日任务

- 每日登录：+1
- 阅读课文：+2
- 阅读单词：+2
- 阅读词组：+2
- 阅读句子：+2

### 积分兑换库

- 奖品卡片展示图片、奖品名称、所需积分。
- 卡片底色黑白交替。
- 支持下拉查看更多奖品。

## 后续迭代优先级

1. 第一优先级：老师录入 + AI 生成知识点 + 学生播放跟读。
2. 第二优先级：学习记录和积分自动统计。
3. 第三优先级：奖品兑换后增加“待发放/已发放”。
4. 第四优先级：多学生、多课程、多老师。
5. 第五优先级：AI 批改跟读录音、错题闭环、学习报告。
