# Lucy的雷霆英语王国小程序

这是一个微信小程序原型工程，不是 HTML 页面。可以直接用微信开发者工具导入当前文件夹预览。

## 项目判断

- 入库判断：`S 进选题池` + `A 做知识卡片`
- 原因：这个项目服务于 AI 原生英语学习、RAZ 分级阅读、课后复习闭环和可验证 MVP，适合继续沉淀为产品方案。

## 当前实现

### 1. 知识点页

路径：`pages/knowledge/knowledge`

已经实现：

- 顶部标题：Lucy的雷霆英语王国
- Level A 到 Level Z 下拉选择
- 搜索课文名、单词、词组、知识点
- 照片墙，默认下方被课文卡片遮住一部分
- 在课文卡片区域下拉后完整展示照片墙，并渐显“更换图片”按钮
- 照片墙图片可从本机相册或相机选择
- 课文卡片为 3 行 3 列正方形，白底粉字；选中样式为粉底白字
- 点击知识点卡片展开中文、音标、原文句子、造句
- 点击播放按钮触发英文发音接口
说明：当前发音按钮已接入有道词典在线发音地址 `https://dict.youdao.com/dictvoice`。开发者工具可在关闭域名校验时预览；正式上线前需要在微信小程序后台把 `https://dict.youdao.com` 加入合法域名。老师录入知识点的能力后续建议改为独立教师入口，不再放在学生首页顶部。

### 2. 学习日历页

路径：`pages/calendar/calendar`

已经实现：

- 今日已学时长
- 今日已学知识点数量
- 月度学习热力图
- 累计已学时长、累计已学天数、累计已学知识点
- 今日知识点列表
- 点击知识点卡片或播放按钮后自动计时，10 秒无交互自动暂停
- 今日和月度知识点数量按知识点去重统计

说明：下面预留区域暂时空着，符合当前需求。后续可以放“本周复习建议”“薄弱词汇”“老师留言”。

### 3. 积分库页

路径：`pages/rewards/rewards`

已经实现：

- 顶部头像区，点击可替换头像
- 当前积分显示
- 今日任务卡：每日登录、阅读课文、阅读单词、阅读词组、阅读句子
- 完成任务后自动增加积分
- 积分兑换库：奖品卡片两列展示，可下拉
- 奖品卡片黑白交替，支持图片、奖品名、所需积分
- 点击后消耗积分兑换
- 点击露出的另一张卡片区域，可在“今日任务”和“积分兑换库”之间切换

## 正式开发建议

### MVP 第一版只做这些

1. 老师录入课文名、Level、单词和词组。
2. AI 自动生成：发音、音标、中文、例句、原文句子、复习任务。
3. 学生每天点开知识点学习，自动记录学习时长和知识点数量。
4. 每日任务给积分。
5. 积分兑换礼物，老师线下发放。

### 后续需要补的技术能力

- 云数据库：存课文、知识点、学习记录、积分、奖品。
- 云函数：接 AI 接口生成知识点内容。
- 音频生成：当前先用有道词典在线发音地址。正式小程序 AppID 开通插件权限后，也可改用微信同声传译插件、云函数 TTS 或自有音频文件。
- 登录身份：至少区分“老师”和“学生”。
- 图片上传：课文封面、照片墙、奖品图需要上传到云存储。
