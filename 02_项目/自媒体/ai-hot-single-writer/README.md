# AI 热点单篇公众号工作台

这是一个本地网页工具，用来把 AI HOT 里的单条 AI 热点新闻改写成一篇公众号草稿。

当前版本只做单篇内容，不生成热点合集。

## 已实现功能

- 拉取 AI HOT 今日精选和日报内容。
- 按模型、产品、行业、论文、观点、AI 教育等分类筛选。
- 选中单条新闻后生成单篇公众号稿。
- 生成标题备选、推荐标题、正文、封面图提示词、正文配图提示词。
- 生成事实核查清单和风险提示。
- 保存草稿到 Obsidian：
  `05_内容输出/内容/公众号草稿/AI热点单篇/`
- 预留微信公众号草稿箱接口位置。

## 本地启动

```bash
npm install
npm run dev
```

浏览器打开：

```text
http://localhost:3000
```

如果 3000 端口被占用，Next.js 会自动提示改用其他端口。

## 配置 AI 生成

复制配置文件：

```bash
Copy-Item .env.example .env.local
```

在 `.env.local` 里填入：

```env
OPENAI_API_KEY=你的 API Key
OPENAI_TEXT_MODEL=gpt-5.6
```

没有配置 API Key 时，工具仍然能拉取新闻和生成占位稿，用来验证流程。

## 配置封面图生成

默认是提示词模式，只生成封面提示词，不直接生成图片：

```env
AI_IMAGE_MODE=prompt
```

如果要直接生成封面图：

```env
AI_IMAGE_MODE=image
OPENAI_IMAGE_MODEL=gpt-image-2
OPENAI_IMAGE_SIZE=1536x1024
OPENAI_IMAGE_QUALITY=low
```

公众号封面建议采用：

```text
AI 生成背景图 + 后期手动叠加中文标题
```

不要让图片模型直接生成中文大字，稳定性会差一些。

## 推荐工作流

1. 点击左侧刷新，拉取 AI 热点。
2. 选择一条新闻。
3. 点击「打开原文」，核查关键事实。
4. 设置写作口吻和目标字数。
5. 点击「生成单篇稿」。
6. 点击「生成封面」。
7. 点击「保存」，草稿会进入 Obsidian 输出目录。
8. 人工修改标题、观点、事实表述。
9. 再复制到微信公众号后台或接入草稿箱接口。

## 公众号草稿箱

当前默认不自动发布，也不自动推送草稿箱。

原因是微信公众号接口需要确认：

- 公众号主体类型。
- 是否认证。
- 是否有 AppID / AppSecret。
- 是否能配置 IP 白名单。
- 是否具备素材上传和草稿箱接口权限。

确认后再看：

```text
docs/微信公众号草稿箱接入说明.md
```

## 内容边界

AI HOT 在这里作为热点线索源，不作为可直接搬运的原稿库。

更稳的做法是：

```text
AI HOT 发现热点
→ 回原文核查事实
→ 生成你的公众号解读
→ 保存草稿
→ 人工确认后发布
```
