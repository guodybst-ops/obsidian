# 产品说明

## 产品定位

这是一个给 AI 自媒体使用的单篇内容生产工具。

它解决的是：

```text
每天看到很多 AI 新闻
→ 不知道哪条值得写
→ 手动整理费时间
→ AI 改写容易没风格
→ 公众号排版和封面也麻烦
```

第一版目标：

```text
选一条 AI 新闻，生成一篇可编辑的公众号草稿。
```

## 频道边界

| 频道 | 用途 |
|---|---|
| AI 热点 | 主频道，用来生成公众号单篇文章。 |
| AI 教育 | 副频道，只做标记和收集，不默认进入改写主流程。 |

## 页面结构

```text
左侧：AI HOT 资讯列表
右侧：单篇成稿工作台
```

右侧包含：

- 写作口吻。
- 目标字数。
- 额外要求。
- 打开原文。
- 生成单篇稿。
- 生成封面。
- 保存到 Obsidian。
- 公众号草稿箱预留按钮。

## 文章生成结构

每篇文章生成：

- 标题备选。
- 推荐标题。
- 一句话摘要。
- 正文。
- 封面图提示词。
- 正文配图提示词。
- 事实核查清单。
- 风险提示。
- 来源链接。

## 内容原则

不要做简单同义词替换。

工具应该做的是：

```text
新闻事实
→ 你的理解
→ 对普通 AI 用户 / 创作者 / 产品人的影响
→ 后续观察点
```
