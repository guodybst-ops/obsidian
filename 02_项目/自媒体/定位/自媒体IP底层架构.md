# 自媒体IP底层架构

> 猫耳AI助理，帮小白把AI工具变成可复制的工作流。

## 核心定位

| 模块 | 内容 |
|------|------|
| 账号类型 | AI小白工具实战型虚拟IP博主 |
| IP形象 | 猫耳AI管家/实验室助手 |
| 核心人群 | 自媒体小白、职场效率人群 |
| 核心价值 | 把AI工具变成普通人能复制的工作流 |
| 内容主线 | AI工具实测 + AI工作流教程 + AI避坑 |
| 视觉形式 | 主画面录屏/案例，虚拟形象右下角旁白 |
| 人设风格 | 可爱、吐槽、聪明、可信，不擦边 |
| 平台打法 | 抖音测流量，B站沉淀教程，小红书做图文搜索 |
| 更新节奏 | 每周5条短视频，1条长教程或合集 |
| 变现路径 | 模板包、小课、工具推广、培训、咨询 |
| 合规底线 | AI标识、原创/授权素材、拒绝低俗性暗示、拒绝虚假夸大 |

## 差异化定位

普通AI博主：
> "这个工具很强，我教你用。"

你的差异化：
> "猫耳AI助理替小白先踩坑，然后给你一套能直接复制的做法。"

你的每条内容都要回答三个问题：
1. 这个AI工具能帮谁？
2. 小白第一步怎么用？
3. 它哪里容易翻车？

## IP人设设计

### 身份设定
推荐设定：**AI实验室里的猫耳助理**

关键词：可爱、聪明、效率、吐槽、陪伴感

不要变成：女仆陪伴、恋爱陪伴、擦边角色

### 名称选择
| 名称 | 特点 |
|------|------|
| 猫耳AI助理 | 搜索友好，定位明确 |
| 喵小算AI | IP感强 |
| AI喵管家 | 服务感强 |
| 小喵AI实验室 | 适合长期品牌 |

**首选：猫耳AI助理**

### 视觉设计
保留元素：猫耳发箍、JK水手服、围裙、平板电脑、文件夹、教鞭

姿势设计：正常站立、指向屏幕、抱文件夹、拿平板、举手提醒

表情包（至少5个）：正常、开心、惊讶、吐槽、严肃

### 口癖设计
可以：
- "猫猫帮你拆开讲"
- "这一步别急"
- "我替你踩坑了"
- "这个地方容易翻车"

不要：
- "主人"、"奖励"、"调教AI"、"贴贴"、"服侍"

原则：**可爱可以，暧昧不要**

## 目标用户

### 核心用户1：自媒体小白
需求：选题、脚本、标题、封面、分镜、剪辑
特点：结果导向强

### 核心用户2：职场新人
需求：PPT、Excel、周报、会议纪要、信息整理
特点：效率导向强

### 暂不推荐
- 学生党：流量有，但变现弱
- AI绘画党：工具链太重
- 程序员：门槛太高
- Agent玩家：起号不友好

## 视频结构模板

| 场景 | 表情 |
|------|------|
| 开头抛问题 | 惊讶/吐槽 |
| 教程步骤 | 认真 |
| 展示效果 | 开心 |
| 避坑提醒 | 严肃 |
| 结尾引导 | 微笑 |

每条短视频建议控制在30-90秒，新手先做60秒左右。固定结构如下：

1. **0-3秒：痛点��子**
   "不会写短视频脚本？别再让AI直接'帮我写一条'，这样问基本废了。"

2. **3-10秒：给出承诺**
   "今天猫管家教你一个三段式提示词，能直接生成选题、脚本和分镜。"

3. **10-45秒：屏幕演示**
   展示你输入什么、AI输出什么、哪里要改、结果如何。

4. **45-55秒：总结方法**
   "记住：角色 + 目标 + 限制 + 示例，比单纯一句'帮我写'稳定得多。"

5. **55-60秒：评论引导**
   "评论区打'脚本'，我下一期拆封面提示词。"

## 平台策略

| 平台 | 角色 | 内容形式 |
|------|------|----------|
| 抖音 | 测爆款、拿短视频流量 | 30-60秒强钩子教程、工具实测 |
| B站 | 建信任、沉淀粉丝 | 3-8分钟完整教程、合集、复盘 |
| 小红书 | 做搜索和收藏 | 图文笔记、工具清单、提示词模板 |
| 视频号 | 做职场/私域转化 | 更稳重的效率型内容 |

| 平台 | 优先级 | 原因 | 做法 |
|------|--------|------|------|
| 抖音 | 第一优先 | 反馈快，适合测爆款 | 发30-60秒教程 |
| 小红书 | 第二优先 | 搜索和收藏强，适合AI模板 | 同步图文版 |
| B站 | 第三优先 | 接受二次元形象，但长视频成本高 | 每周做合集 |
| 视频号 | 暂缓 | 更偏熟人/职场，二次元风格未必最适合 | 后期再分发 |

**主阵地：抖音或B站二选一。**
**分发阵地：小红书。**

## 90天起号路线

### 第1-7天：搭建期
完成账号名、头像、简介、形象、封面模板、字幕模板、前20个选题。

### 第8-30天：测试期
发布20-30条短视频。重点测试三类内容：AI工具验货、AI工作流教程、AI避坑。

### 第31-60天：放大期
保留表现最好的两个栏目，砍掉没人看的栏目。开始做系列化。

### 第61-90天：产品化期
做一个免费的"AI短视频提示词模板包"作为粉丝沉淀入口。

## 小白最容易犯的错

| 坑 | 后果 |
|------|------|
| 一开始做完整数字人 | 成本高，更新慢，容易放弃 |
| 每天追AI新闻 | 选题压力大，容易搬运 |
| 只展示工具，不展示结果 | 观众不知道价值 |
| 形象太抢内容 | 被记住可爱，但没人关注AI |
| 标题太大 | 比如"AI改变普通人命运"，容易空 |
| 教程太长 | 新号初期完播率差 |
| 急着卖课 | 信任没建立，转化弱 |
| 全平台同时精细运营 | 小白会被流程拖死 |
