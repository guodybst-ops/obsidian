**五、视频结构模板**

|场景|表情|
|---|---|
|开头抛问题|惊讶/吐槽|
|教程步骤|认真|
|展示效果|开心|
|避坑提醒|严肃|
|结尾引导|微笑|


每条短视频建议控制在30-90秒，新手先做60秒左右。固定结构如下：

1. 0-3秒：痛点钩子  
    “不会写短视频脚本？别再让AI直接‘帮我写一条’，这样问基本废了。”
    
2. 3-10秒：给出承诺  
    “今天猫管家教你一个三段式提示词，能直接生成选题、脚本和分镜。”
    
3. 10-45秒：屏幕演示  
    展示你输入什么、AI输出什么、哪里要改、结果如何。
    
4. 45-55秒：总结方法  
    “记住：角色 + 目标 + 限制 + 示例，比单纯一句‘帮我写’稳定得多。”
    
5. 55-60秒：评论引导  
    “评论区打‘脚本’，我下一期拆封面提示词。”
    

你的虚拟形象只在这些地方发挥作用：开头表情吸引、过程吐槽、结尾总结。不要让形象抢走教程本身。

**七、平台策略**

小白不要一开始全平台精细运营，会累死。建议这样：

|平台|角色|内容形式|
|---|---|---|
|抖音|测爆款、拿短视频流量|30-60秒强钩子教程、工具实测|
|B站|建信任、沉淀粉丝|3-8分钟完整教程、合集、复盘|
|小红书|做搜索和收藏|图文笔记、工具清单、提示词模板|
|视频号|做职场/私域转化|更稳重的效率型内容|

| 平台  | 优先级  | 原因                 | 做法        |
| --- | ---- | ------------------ | --------- |
| 抖音  | 第一优先 | 反馈快，适合测爆款          | 发30-60秒教程 |
| 小红书 | 第二优先 | 搜索和收藏强，适合AI模板      | 同步图文版     |
| B站  | 第三优先 | 接受二次元形象，但长视频成本高    | 每周做合集     |
| 视频号 | 暂缓   | 更偏熟人/职场，二次元风格未必最适合 | 后期再分发     |

**主阵地：抖音或B站二选一。**  
**分发阵地：小红书。**

如果你的猫耳二次元形象比较明显，B站接受度会更高。  
如果你想快速测流量，抖音反馈更快。  
如果你想积累“可搜索内容”，小红书适合做图文版教程。

我的建议：**短视频首发抖音，教程合集发B站，图文拆解发小红书。**

单条视频制作流程：

1. 选一个具体问题：比如“AI写脚本太空泛”。
2. 写60秒脚本：开头钩子、操作步骤、结论。
3. 录屏演示：一定要有真实输入和真实输出。
4. 加旁白：语气像朋友解释，不要像播新闻。
5. 加虚拟形象：右下角，关键步骤时缩小。
6. 加字幕和重点框：让静音用户也能看懂。
7. 发出去后看评论：下一条视频回答评论区问题。

**九、90天起号路线**

第1-7天：搭建期  
完成账号名、头像、简介、形象、封面模板、字幕模板、前20个选题。不要花太多钱定制高级数字人，先验证内容。

验证内容形式  
目标：发10条。  
重点看：哪类标题点击高，哪类内容收藏高。

第8-30天：测试期  
发布20-30条短视频。重点测试三类内容：AI工具验货、AI工作流教程、AI避坑。不要急着变现。看哪类内容收藏、评论、关注最高，保留表现最好的2类内容，比如“提示词改写”和“AI做短视频”。。

第31-60天：放大期  
保留表现最好的两个栏目，砍掉没人看的栏目。开始做系列化，例如“AI自媒体小白课第1集、第2集”。B站开始发5-8分钟合集。

“猫耳AI助理第01课：脚本提示词”  
“第02课：标题提示词”  
“第03课：封面文案”

第4周：做一个免费资料
