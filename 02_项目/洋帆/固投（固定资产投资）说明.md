# 固投（固定资产投资）说明

## 一句话理解

**固投**是“固定资产投资”的简称：企业或政府为形成长期使用的资产而投入的资金，例如厂房、设备、生产线、仓库、土地配套和基础设施。

它常用于招商、项目备案和经济统计，帮助判断一个项目的实体投入规模与后续产能。

## 7000 万元固投是什么意思

“7000w 固投”通常指一个项目计划投入 **7000 万元人民币**用于固定资产建设或购置。

它**不等于**：

- 企业年营收；
- 企业利润；
- 注册资本；
- 企业账上已经支付的现金；
- 项目一定会如期完成的实际投资额。

在项目备案、招商洽谈材料中，该数字往往是计划总投资中的固定资产部分；具体是否包括土地款、流动资金、装修、软硬件设备，应以项目投资测算表或备案材料为准。

## 7000 万元大概是什么规模

| 企业/项目类型 | 对 7000 万元固投的判断 |
| --- | --- |
| 小微企业、普通门店、轻资产互联网公司 | 很大，通常不常见 |
| 制造业、食品加工、仓储物流、文旅酒店、教育/医疗场地项目 | 中等规模，较常见 |
| 大型制造、汽车、芯片、能源、地产、重大基建 | 较小，可能只是一条产线或一个子项目 |

> 这只是经验判断，不构成对单个企业实力的结论。轻资产公司的价值可能很高但固投很低；实体工厂营收未必很高，固投却可能较高。

## 常见投向

- **制造业扩产**：厂房、自动化生产线、检测设备。
- **仓储物流**：仓库、冷链、分拣设备。
- **新能源/环保**：储能、充电设施、污水处理、能源设备。
- **商业与文旅**：酒店、园区配套、商业空间建设或改造。
- **教育与医疗**：校区、实训基地、专科设备、场地改造。

## 洋帆招商或项目研判时该怎么用

不要只看“固投 7000 万元”这一句话。至少要求项目方补充以下信息：

1. **投资构成**：厂房、设备、装修、土地、软件、流动资金各占多少？
2. **建设周期**：何时开工、何时投产、分几年完成？
3. **资金来源**：自有资金、银行贷款、股东增资、融资各是多少？是否已落实？
4. **实际需求**：需要多大面积、什么层高/承重/用电/环保条件？
5. **产出指标**：投产后的预计营收、税收、就业人数、亩均效益或单位面积产出。
6. **兑现机制**：固投是合同承诺、备案计划，还是已审计/已支付的实际完成额？

## 风险提醒

高固投不天然等于优质项目。需要警惕：

- 为获得政策或空间而虚高申报投资额；
- 投资大量用于低效装修、土地或非生产性建设，实际产能有限；
- 资金未落实，项目后续停滞；
- 设备投入高，但没有订单、技术或团队支撑，难以形成稳定产出。

## 可直接对外使用的表述

> 项目计划固定资产投资约 7000 万元，拟主要用于场地建设/改造、设备购置及配套设施建设。后续需结合投资构成、资金落实情况、建设进度及预计产出，对项目实际落地能力进行核验。
