# 未来智航稿件官方站台风险审查（v2）

> 审查对象：`2026-07-20-未来智航-公众号初稿编辑包.md`
> 审查视角：杭州良渚新城官方微信公众号
> 最终结论：**不建议按现有单企产品稿形式发布。**

## 一、官方发布建议

`不建议由官方公众号发布`

现稿虽然删除了“国内领先”“开创者”等夸张词，也多次标注“企业宣传资料”“仍需验证”，但整体结构仍以单一企业及其产品为中心：标题替企业概括技术价值，正文连续解释产品功能、工作流程和应用场景，配图全部围绕产品展示，结尾再从产品推导产业意义。

对官方账号而言，风险不能只按“每句话是否真实”判断。即使内容全部来自企业并经过确认，官方平台对这些信息进行选择、组织和放大，也可能使读者理解为管委会认可该企业、产品成熟度和技术价值。因此，现稿存在较明显的单企站台、产品背书和变相品牌传播风险。

## 二、主要风险

### 必须修改

1. **缺少独立新闻由头，文章本质上是产品介绍。**

   当前没有已核实的良渚项目落地、正式交付、验收、公共服务应用、权威获奖或开放活动。文章主要回答“产品是什么、如何工作、能用在哪里”，没有回答“最近发生了什么、为什么需要由官方账号现在报道”。仅凭企业宣传册不足以支撑单企专题报道。

2. **核心证据全部来自企业材料，无法支撑官方平台对产品价值的集中展示。**

   AI巡检触发采样、大模型生成报告、检测能力和智能车流程均来自企业宣传册，尚无项目方、使用方、验收材料、公开数据或第三方机构验证。写成“企业介绍”只能解决信息归属，不能消除官方账号放大企业自述产生的信用背书。

3. **标题和结尾替企业完成了价值判断。**

   “探索AI水环境监测新路径”“水环境监测有了新解法”等标题，容易被理解为官方认可其技术路线具有创新性或代表性。正文结尾从单一产品延伸至“AI+低空经济”的产业价值，也超出了现有证据能够支持的范围。

4. **版面呈现接近产品画册。**

   现稿设置无人机作业、采样设备、软件界面、智能车和企业办公场景等5类配图，且三个正文小节均围绕产品能力展开。即使文字克制，标题、篇幅、品牌露出和图片组合后的整体传播效果仍具有产品推介性质。

### 建议修改

5. **没有说明企业选择标准，存在公平性疑问。**

   官方账号单独报道一家企业，需要能够解释报道时点和筛选依据。当前只有工商登记地址线索，尚不能说明企业在良渚实际开展了什么业务，也无法回答“为什么此时报道这家企业，而不是同类企业”。

6. **个别行业判断超出了企业材料的证明范围。**

   “传统水环境监测通常依赖固定点位和人工采样”“这种组合为扩大作业范围提供新的技术路径”等表达看似中性，实际承担了论证产品必要性和先进性的作用。没有行业部门、专家或公开资料支持时，不宜由管委会账号直接作出。

7. **风险提示不能抵消主体结构的推广倾向。**

   稿件写入“仍需真实项目验证”“AI不能替代规范流程”，说明风险意识较强，但这些提示只占少量篇幅，无法改变大部分正文仍在帮助读者理解并记住企业产品的事实。

## 三、逐项结论

| 审查项 | 结论 | 说明 |
|---|---|---|
| 新闻由头 | 不通过 | 无近期可核实事件，只有企业宣传册 |
| 公共价值 | 待确认 | 水环境监测具有公共议题价值，但现稿主要服务产品介绍 |
| 良渚关联 | 不通过 | 只有登记地址线索，未证实实际办公、项目或本地业务 |
| 证据独立性 | 不通过 | 产品功能和效果均来自企业材料，缺少外部验证 |
| 产品背书 | 高风险 | 官方账号集中解释产品功能、流程和应用价值 |
| 行业背书 | 中高风险 | 标题和结尾将单企实践概括为“新路径”“新解法” |
| 资源背书 | 中风险 | 单独发布本身可能被理解为管委会认可或重点推荐 |
| 公平性 | 不通过 | 缺少企业筛选标准和明确报道时点 |
| 图片与品牌露出 | 高风险 | 配图方案近似产品宣传册 |
| 综合发布建议 | 不建议发布 | 应先改变选题依据和文章结构，而非只做文字降调 |

## 四、推荐改造方向

### 方向A：等待真实事件后写“事件简讯”

适用条件：未来智航在良渚有已经发生并可核实的项目落地、试点启用、正式交付、验收、开放活动或公共服务应用。

建议结构控制在600至900字：

1. 发生了什么：时间、地点、参与方、项目阶段；
2. 为什么与良渚有关：本地场景、服务对象或产业联系；
3. 企业承担什么：只说明与事件直接相关的工作；
4. 项目如何验证：项目方评价、验收情况或阶段数据；
5. 下一步是什么：只写已确认安排。

产品功能说明不超过正文三分之一；删除型号、完整参数、适用客户清单和泛化产业评价。配图优先项目现场、参与方和公共应用场景，产品特写最多1张。

可用标题框架：

- 良渚一项目启动低空水环境巡测应用
- AI与无人机如何参与水环境巡测？良渚一项目展开实践
- 从巡检到采样，良渚新增一项低空应用场景

以上标题只有在对应事件真实发生、可以公开并有项目材料后才能使用。

### 方向B：改成“产业主题稿”，未来智航只作为案例之一

建议主题：`AI+低空如何进入水环境治理的真实流程？`

稿件应至少包含：

- 水环境巡检或低空应用的公开政策、行业规范或公共需求；
- 2至3个不同主体的真实案例，避免只展示一家企业；
- 环境、水利或检测领域专业人士对适用条件和局限的解释；
- AI识别、无人机采样、检测设备和人工复核之间的责任边界；
- 良渚新城相关产业或应用场景的已公开事实。

未来智航的篇幅建议不超过全文25%至30%，仅说明已核实的产品设计或项目事实，不使用“新路径、新解法、标杆、领先”等评价。

### 方向C：由企业自有渠道发布

如果现阶段目标就是完整介绍“智航水灵”和水质采测智能车，现有稿件更适合用于企业公众号、官网、产品手册或行业展会材料。企业渠道可以明确承担品牌传播和产品介绍功能，不必让官方账号承受不必要的背书风险。

## 五、重新成稿前必须补充

| 优先级 | 需要确认的事项 | 合格材料 | 决定什么 |
|---|---|---|---|
| 必须 | 在良渚已经发生的新闻事件是什么 | 项目文件、活动通知、交付或验收材料 | 是否具备报道由头 |
| 必须 | 企业在良渚实际开展哪些业务 | 营业执照、办公证明、团队和业务书面说明 | 是否具有实质良渚关联 |
| 必须 | 谁使用或验证了产品 | 项目方或使用方确认、验收材料、公开报道 | 是否能避免仅靠企业自述 |
| 必须 | AI功能是否已投入真实运行 | 任务记录、演示记录、项目说明、自研与第三方边界 | AI能否进入正文或标题 |
| 必须 | 官方账号为何选择此时报道该企业 | 可公开的选题依据和统一筛选标准 | 是否能够回应公平性质疑 |
| 增强 | 使用前后的结果数据 | 截至日期、样本量、统计口径和第三方确认 | 是否可以写效果变化 |
| 增强 | 专业人士或主管部门意见 | 可追溯原话和引用授权 | 是否能形成公共议题而非产品说明 |
| 图片 | 真实公共场景图片 | 时间、地点、人物、版权和授权信息 | 是否减少产品画册感 |

## 六、对原稿的处理建议

- 原稿保留为企业材料分析和采访提纲，不作为待发布稿流转。
- 在文件标题或编辑备注中明确标注“官方公众号不建议发布”。
- 不建议继续通过替换形容词、小幅删减功能或增加免责声明进行修补。
- 等取得真实事件和外部证据后，重新选择“事件简讯”或“产业主题稿”，不要沿用原有产品说明结构。

## 七、管委会口径终审

- `宣传价值：待重构`。AI与低空水环境监测具有选题潜力，但现有材料只能证明企业如何介绍产品，不能证明值得由官方账号单独报道。
- `政府调性：文字层面基本通过，整体传播效果不通过`。问题主要在选题、证据、结构和版面，而非夸张用词。
- `良渚关联：不通过`。登记地址不能替代实际落地和本地项目事实。
- `背书边界：不通过`。官方账号对单企产品进行系统说明，本身会形成隐性产品和信用背书。
- `站台风险：高`。企业名、产品功能、品牌配图和产业评价高度集中。
- `公共价值：待确认`。需要用真实公共场景、行业规范和多方证据重新建立。
- `公平性：不通过`。缺少可解释、可复用的企业选择标准。
- `最终建议：不建议发布现稿`。优先转为企业自有渠道；具备真实事件后另起官方稿件。
