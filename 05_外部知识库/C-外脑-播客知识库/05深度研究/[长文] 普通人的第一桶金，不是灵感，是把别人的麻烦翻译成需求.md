# 普通人的第一桶金，不是灵感，是把别人的麻烦翻译成需求

很多人想做副业时，先问的是：“我到底能做什么？”

于是他开始盘点技能。会拍照，能不能接单？会做饭，能不能摆摊？懂一点 AI，能不能卖课？喜欢穿搭，能不能做博主？想来想去，最后常常卡在同一个地方：每个方向都有人做过，自己又没有特别耀眼的天赋，于是什么也没开始。

但“我能做什么”常常不是最好的起点。

它太容易把人带回自我表达：我喜欢什么、我会什么、我想成为什么样的人。可一门小生意真正的起点，往往在另一个方向：**谁正在为一个具体麻烦付出时间、金钱和情绪？**

麻烦不是机会的低配版。麻烦本身，就是机会还没有被翻译的原料。

有人每天收纳却始终越收越乱，表面上是在抱怨东西太多，真正付费的可能是“我需要一个能维持秩序的空间系统”；有人不断搜索“孩子挑食怎么办”，表面上在找信息，真正需要的是一套让家庭能坚持的饮食解决方案；有人反复说“我不会做小红书”，他缺的未必是一门泛课程，而可能是一套针对自己行业的选题、样稿和复盘服务。

这也是为什么播客知识库里关于普通人创业的材料，反复出现下拉词、抱怨、访谈、场景、付费验证这些看起来很琐碎的词。它们都在解决同一件事：不要靠想象发明需求，要从人们已经暴露出来的摩擦里识别需求。

## 机会不是“我想做什么”，而是“谁正在难受”

在《给女孩的商业第一课》045 里，嘉宾讨论“没有赚钱机会”时，把问题从“我想做什么”扳到了“谁有具体需求”。这个转向很重要。

因为普通人最缺的通常不是想法，而是教育市场的预算。

大公司可以花钱制造一个新品类：它能投广告、做渠道、培养用户习惯，甚至承受几年亏损。普通人没有这种空间。你一开始就拿着一个自认为很新、很酷、很有表达欲的东西冲进市场，很可能先遇到的不是客户，而是一串解释成本：为什么要买、为什么现在要买、为什么不自己解决、为什么要找你。

解释成本越高，生意越难。

所以，普通人反而应该从已经发生的麻烦开始。杨涛在《平民创业手册》关于“场景—需求—产品”的讨论里，把选项目拆成了三个层次：先看一个真实场景里发生了什么，再看当事人卡在哪里，最后才问能不能做成产品。顺序不能倒过来。

先找产品，再给它编场景，容易自嗨。

先找场景，再观察人们怎样解决，才更容易看见钱已经在往哪里流。

比如“年轻人想要更健康”不是需求，它太大、太抽象，也很难判断谁会付钱；“加班到十点的人不想做饭，但又不愿天天外卖”才是场景；“能不能在十五分钟内吃到一顿不难吃、无需洗锅、热量可控的晚餐”才逐渐接近需求；这时预制菜、轻食订阅、办公室团餐、半成品调料包，才是不同的产品答案。

创业者的工作，不是最先发明答案。

是先把问题问准。

## 抱怨、搜索和笨问题，都是需求在漏出来

需求很少会端端正正地站在你面前说：“请为我开发一款产品。”

它更常以抱怨、犹豫、重复搜索和外行问题的形式出现。

《搞钱女孩》026 里，七天路过和黄小刀讨论过“把抱怨翻译成需求”。这不是让人对所有负面情绪都趁火打劫，而是提醒创业者：当一群人反复为同一件事感到麻烦，且现有解决方式让他们不满意，那里就可能有一条可收费的路径。

抱怨“总找不到合适尺码”，背后可能是非标身材的服装需求。

抱怨“资料看了一堆还是不敢报税”，背后可能不是知识不足，而是陪同办理、风险核验和情绪安抚。

抱怨“孩子写作业每天鸡飞狗跳”，背后也未必只是辅导班，而可能是家庭分工、任务拆解、学习陪伴等一整套问题。

杨涛在《平民创业手册》196 里把“下拉词”看作比热词更接近真实意图的信号。热词告诉你什么在被讨论，下拉词却常常暴露用户在下单前、决策前和行动前的犹豫：价格、对比、避坑、适不适合我、哪里可以买、有没有替代方案。

这两种材料放在一起，会得到一个很实用的观察法：

**看一个赛道，不要只看它有多少内容；要看用户在内容之外，还在追问什么。**

内容多，说明注意力在。

追问多，才说明问题没有被解决。

《搞钱学姐》070 里的“小白访谈信息差挖掘法”又补上了另一块。真正有价值的访谈，不是听人讲成功故事，而是不断追问他第一单怎么来、成本怎么算、客户为什么买、哪些环节最麻烦、今天重来会避开什么坑。外行问题有时反而更有价值，因为内行会默认的麻烦，往往正是新用户愿意付钱解决的地方。

所以，普通人不必急着证明自己很懂行业。

先学会像一个好记者那样，把问题问到具体。

## “大家都说好”，不等于“大家愿意付钱”

识别到麻烦以后，还有一个更常见的误区：把夸奖当成需求。

朋友说“这个好有意思”“你做出来我会支持”，不等于他会下单。

内容点赞很多，不等于它能带来客户。

问卷里一百个人说“需要”，也不等于有人会在今天掏钱。

姚楠在《搞钱女孩》006 里讨论真需求时，强调的是付费、复购、教育成本和盈利空间。这个标准很冷，但很重要：真正的需求不只要有人认同，还要有人愿意为更好的解决方案付出稀缺资源。

这也是为什么“小验证”比“大准备”更适合普通人。

不要先花三个月开发完整课程，再去问有没有人要。

不要先囤一屋子货，再去研究哪个平台适合卖。

不要先把品牌视觉做得像大公司，再去想第一批客户是谁。

更好的顺序是：

```text
真实场景 -> 具体麻烦 -> 找十个当事人聊 -> 给出一个小方案 -> 尝试收费 -> 观察复购与转介绍
```

收费不是为了马上赚很多钱。

收费是为了让需求从“礼貌反馈”变成“真实证据”。

当用户愿意付钱、愿意继续用、愿意介绍别人，你才知道自己碰到的不是一阵情绪，而是一个值得继续打磨的问题。

## 第一桶金，常常来自“翻译能力”

很多人把创业想成创造能力的比拼。

当然，创造很重要。但对大多数普通人来说，第一桶金更常来自一种没那么浪漫的能力：翻译能力。

把模糊抱怨翻译成具体问题。

把具体问题翻译成可交付的服务。

把服务翻译成客户听得懂、愿意尝试的产品。

再把第一次交付里的失败，翻译成下一版的改进。

这套能力的门槛不低，但它不要求你先拥有伟大的灵感。它要求你愿意靠近真实的人、真实的麻烦和真实的钱。

这是本文的 AI 综合判断：把“场景—需求—产品”的选项框架、抱怨与下拉词的观察方法、小白访谈的追问方式、付费验证的硬标准放在一起看，普通人的机会雷达并不是预测下一个风口，而是更早发现别人已经在为哪些麻烦付出代价。

你不一定要先找到一个宏大的创业方向。

先找到一个有人愿意让你帮他变轻一点的问题，就够了。
