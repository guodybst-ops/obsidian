# [判断] 030-工作 vs 事业 该怎么选

## 一句话判断

先把现金流和事业拆开；能带来现金流但不吞掉主目标的事可以做，吞掉自由时间和主线目标的事别做。

## 决策节点

- 你面前有一件能赚钱的事，但你分不清它是工作、事业还是短期现金流。
- 你在犹豫要不要继续做，还是应该把精力挪去别的地方。
- 你已经知道自己想要自由，但还没把自由和赚钱的关系说清。

## 候选路径

| 路径 | 做法 | 代价 | 适用信号 |
|---|---|---|---|
| A 把它当工作工具 | 先保证现金流，把它当赚钱手段 | 可能不那么有成就感 | 你需要先活下来，且这件事能稳定供血 |
| B 把它当事业主线 | 把它当成长期方向，持续投入 | 代价是时间和心力 | 这件事真的在你的内在驱动里 |
| C 先小额试错 | 先用小规模验证，再决定 | 时间成本换判断 | 你现在还拿不准，但不想错过 |

## 选择依据

| 判断维度 | 关键问题 | 更偏向 |
|---|---|---|
| 能力圈 | 这件事是不是你真的做得动 | A / C |
| 自由吞噬 | 它会不会把你的时间和注意力吃光 | A / C |
| 内在驱动 | 你是不是发自内心愿意长期做 | B |
| 现金流压力 | 你现在是不是先需要活下来 | A |
| 可复制性 | 它能不能变成长期可复用的方法 | B / C |

## 什么时候选 A

- 你现在最需要的是现金流，不是情绪满足。
- 这件事能赚钱，但它不一定是你终局想做的。
- 你需要把工作当工具，把事业单独开线。

## 什么时候选 B

- 这件事不只是赚钱，它本身就会让你持续有动力。
- 你愿意为它投入时间、关系和长期学习。
- 它不会把你想要的自由全吞掉。

## 什么时候选 C

- 你暂时分不清它是不是主线，但又不想直接错过。
- 你能接受先花小成本换判断。
- 你要先验证能力圈和市场反馈。

## 反转条件

- 如果你自问三次都说不清“为什么是我”，就先别重注。
- 如果你发现这件事越来越像现金流工具，而不是主线事业，就及时调整。
- 如果你发现它会明显吞掉你的自由时间，就退回 A 或 C。

## 可迁移用法

- 以后遇到新机会，先拆成“工作 / 事业 / 试错”三层。
- 不要一上来就用“首战必胜”的心态把所有筹码压上去。
- 先问“这是不是帮我更自由”，再问“这是不是能赚钱”。
