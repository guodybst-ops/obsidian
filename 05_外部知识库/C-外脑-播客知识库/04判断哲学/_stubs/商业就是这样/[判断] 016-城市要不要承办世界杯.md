# [判断] 016-城市要不要承办世界杯

## 一句话判断

如果核心权益归国际足联、城市只能承担硬成本，就必须先封顶财政风险，再谈承办。

## 决策节点

- 面临的问题：城市是否要承办世界杯比赛。
- 决策时刻：提交申办、签 host city agreement 或追加预算前。
- 决策对象：城市、城市委员会、场馆方和本地公共财政。

## 候选路径

| 路径 | 做法 | 代价 | 适用信号 |
|---|---|---|---|
| A 承办并招商 | 接受赛事要求，用本地赞助、补贴和球迷消费补成本 | 财政与舆论压力大 | 城市有强本地赞助、上级补贴和成熟场馆 |
| B 放弃申办 | 不承担不透明成本 | 放弃曝光和旅游机会 | 主办方要求过高且收益不可量化 |
| C 重新谈权益 | 要求预算透明、减少球迷节天数、开放本地招商 | 谈判时间长，可能失去资格 | 城市有议价力或替代城市不充分 |

## 选择依据

| 判断维度 | 本次证据 | 权重 | 指向 |
|---|---|---:|---|
| 成本 | 单城支出可接近 3 亿美元 | 高 | B / C |
| 收入归属 | 门票、转播、全球赞助归国际足联 | 高 | B / C |
| 本地开源 | 本地赞助商权益可卖数百万美元，但未必卖满 | 中 | A / C |
| 财政风险 | 芝加哥因不愿开空白支票退出 | 高 | B / C |
| 长期外溢 | 城市曝光和旅游带动难直接入账 | 中 | A |

## 为什么选 C

- 本集不是说城市一定不该办，而是说明“照单全收”风险很高。
- 重新谈权益能保留曝光机会，同时控制球迷节天数、公共成本和财政兜底范围。
- 如果主办方能给更多本地招商、票务分成或补贴，承办才更接近可算账项目。

## 为什么不直接选 A

- 门票和全球权益不归城市，城市很难靠最硬收入回本。
- 球迷节、安保和交通等脏活累活成本确定，但本地赞助不一定卖满。
- 不是说承办永远不划算，而是当前缺少足够透明的成本和收入对照。

## 反转条件

如果出现以下变化，需要重新判断：

- 国际足联开放门票或本地赞助更大分成。
- 上级政府补贴足以覆盖大部分安保和运营成本。
- 城市已有成熟场馆和交通，不需要大额升级。
- 本地赞助商承诺足以覆盖明确缺口。

## 可迁移用法

- 下次遇到大型活动承办，先问：谁拿门票、谁拿赞助、谁付安保、谁背舆论。
- 可复用判断句：曝光是外溢收益，财政缺口是现金成本，二者不能混算。
