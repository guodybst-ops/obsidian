# 04 判断哲学写作规范

> 本层用于补齐播客知识库里过去缺失的一环：在一个具体节点上，为什么选择 A 而不是 B。它记录决策背后的推理链，而不是再写一个方法、概念或专题文章。

## 一、04 层的本质定义

**04 判断哲学 = 决策节点的取舍记录。**

它回答的问题是：

- 当时有哪些可选路径？
- 判断者看重了哪些约束、证据和权重？
- 为什么最终选择这条路，而不是另一条路？
- 什么条件变化后，原判断需要重算？

一句话判据：**如果一段素材的重点是“怎么选、为什么这么选、不选什么”，就优先进入 04。**

## 二、与 01/02/03/05 的边界

| 层 | 回答的问题 | 不要混淆 |
|---|---|---|
| `01人物原萃` | 这个人如何思考、擅长什么、不擅长什么 | 人物整体心智模型留在 01；具体某次选择的理由链进 04 |
| `02方法流程` | 怎么做、怎么评估、怎么执行 | 有步骤/打分表的是 02；为什么在节点上选 A 不选 B 是 04 |
| `03概念链接` | 这个词是什么、和什么概念相邻 | 概念定义和辨析进 03；概念被拿来做取舍依据时进 04 |
| `05深度研究` | 跨节目专题的判断和洞察 | 跨源大论点进 05；单个决策节点的取舍链进 04 |

## 三、收录范围

适合进入 04 的素材：

1. 明确出现二选一或多选一：做品牌还是做渠道、先讲题还是先转化、融资还是自造血。
2. 嘉宾解释了选择背后的权重：阶段、资源、风险、现金流、团队能力、用户密度、时间窗口。
3. 观点中有“而不是”“不要先”“先做 X 再考虑 Y”“在这个阶段不适合”等取舍表达。
4. 01 人物文件里发现“他说了 A 又说了 B，但没解释什么时候用 A、什么时候用 B”的缺口，需要单独补出判断条件。
5. 02 方法或 03 概念之间发生冲突，需要说明在具体场景下调用哪个。

不进入 04 的素材：

- 只有一句金句，没有候选路径和理由链 → 留在 01 或 89。
- 只有概念定义，没有具体选择 → 03。
- 只有执行步骤，没有取舍解释 → 02。
- 只是把多个观点凑成大文章 → 等材料足够后去 05。

## 四、文件命名

主区文件：`[判断] <决策节点>.md`

stub 文件：`_stubs/[判断] <节目集号>-<决策节点>.md`

命名要优先写成“节点”，而不是抽象主题。例如：

- `[判断] 品牌优先还是渠道优先.md`
- `[判断] AI教育先做讲题还是先做转化.md`
- `[判断] 创业者该辞职还是先做副业验证.md`

## 七、六关自检

- [ ] 有明确“选择 A 而不是 B”的节点？
- [ ] 至少列出 2 个候选路径？
- [ ] 写清了证据、约束或权重，而不是只写结论？
- [ ] 写清了“不选项”的合理性和放弃理由？
- [ ] 写了反转条件，避免把阶段性判断写成永久真理？
- [ ] 所有判断都标注 `[原话]` / `[归纳]` / `[AI推理]`，并能回链来源？

## 八、写作红线

1. 不把 AI 推理伪装成嘉宾原话。
2. 不把单个结论写成万能原则；必须写适用场景和反转条件。
3. 不把 04 写成 02 的步骤手册；如果主体是步骤，回到 02。
4. 不把 04 写成 03 的概念解释；如果主体是定义，回到 03。
5. 不为了凑数强建 04；没有候选路径和舍弃理由，只写进 89 拆解记录。
