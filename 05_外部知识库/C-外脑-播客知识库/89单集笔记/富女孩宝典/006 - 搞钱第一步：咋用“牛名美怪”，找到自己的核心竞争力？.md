# 006 - 搞钱第一步：咋用"牛名美怪"，找到自己的核心竞争力？

## 摘要

这一集是**狂喜博客节现场录制的特别集**——主持人斯斯 + 新氧董事长金星联合答疑，节奏和平时的连麦咨询集完全不同。金星把商业问题拆解成**上中下游、产业链全景图、连锁的中台能力、四大护城河**——从一个上市公司老板的视角回答"能力 / 复制 / 副业 / 创业"这四组问题。主持人的话反而少，因为她自己也被击中——**"哇，原来上市公司的老板在思考问题的时候，跟我用的框架是不一样的"**。金星丢出的核心方法论是奇葩说式的**"牛名美怪"**——你在任何一个领域要么做到最顶尖（牛）、要么背靠名人 IP（名）、要么做到极致美感（美）、要么足够独特（怪）——**四选一你就有活路**。

四位提问者串起一条主线：**从起点到打工到副业到创业，每一步该怎么想。**第一位 18 岁大一女生问天崩开局咋整——金星讲了 1 万小时定律 + 差异化，主持人补一刀"**不追寻的过程就是最好的结果**，你就当信息搬运工先把 100 个人的微信加了"。第二位阿金在布拉格开面馆到第 3 家店，金星用新氧做轻医美连锁的完整故事教她**"向内看中台 + 向外看市场空间"**——**"做中台就像盖房子打地基，楼要盖多高地基就要打多深"**。第三位跨境电商一人一年 100 万想转培训，金星给了产业链全景图方法论——**"用俯视的视角看，选'体量在涨但玩家在减少'的环节"**——并劝她**"邓永平说做企业像跳水、动作越少越好"**。

第四位 35 岁上海打工人问副业方向，金星反过来抱怨自己招人多难——**"千军易得、一将难求"**——主持人补充**"你没有 option 浮现，说明你还没让自己进入主动方"**。第五位 1-3 年电商新人问什么时候创业，金星和主持人一起泼冷水——**"创业一定比打工更难；打工没成功、创业大概率也不成功"**、**"我从每一家公司离开都是以胜利者的姿态"**。整集串起来的母题是：**牛名美怪四选一 · 差异化就是定位 · 打工先做胜利者 · 老板视角看上中下游 · 创业是背债不是搞爽**——现场的年轻人被打得有点晕，但笔记本上都在飞快记东西。

## 金句

1. 我们发现哇，上市公司的老板在思考问题的时候，跟我用的框架是不一样的——他会把产业分为上中下游。
2. 性格改变命运，不是读书改变命运——书读得很好但人生过得很悲剧的多的是。
3. 赚钱只跟能力相关——跟你善不善良、爱不爱钱都没关系；能力到了那个份上你不想赚，钱也追着你走。
4. 牛名美怪四选一——牛是领域最顶尖，名是名人 IP，美是颜值到极致，怪是独特到出圈。
5. 你在上海市静安区这条街上是最好的——你就有机会；你不用是上海市最好的。
6. 不追寻的过程就是最好的结果——你 18 岁把 100 个人的微信加了，就比同学多一个信息差优势。
7. 你一生都要参透一个词叫与众不同——差异化既要跟别人不同，又要能变成商业价值。
8. 做企业就像跳水，动作越少越好——没有必要变就不要变，所有的变第一是成本、第二是风险。
9. 做中台就像盖房子打地基——你的楼要盖多高，你的地基就要打多深。
10. 连锁的思考是全局最优，不是局部最优——你为了规模去牺牲差异化。
11. 千军易得、一将难求——好用的人真的很少，招不到好多年都招不到。
12. 我从每一家公司离开都是以胜利者的姿态——老子是跳槽，是我主动不要你。

## 要点

### 1. 金星的开场自我介绍：79 年老登 → 新氧 6 年上市 → 轻医美 40 家店

- 79 年生，上大学之前没用过计算机——**"标准的老登"**。
- 大学疯狂喜欢互联网 → 做校园网站 → 毕业进大厂 → 猫扑网、人人网第一任产品总监。
- 2007 年第一次创业失败 → 腾讯学习两年 → 又出来创业失败 → 2013 年创立新氧。
- 6 年后新氧美股纳斯达克上市（正好赶上医美红利期）。
- 疫情后业务转型 → 做**轻医美连锁**"轻氧" → 2023 年 5 月第一家店到现在 40 多家 → **中国最大的轻医美连锁**。
- 定位："能力和赚钱是高度相关的——我是老派的人，高度相信 1 万小时定律"。

### 2. 赚钱与能力：三个反直觉判断

- **判断 A：性格 > 读书**——"读书好但人生悲剧的多得是；性格才和命运强关联"。
- **判断 B：善恶与能力无关**——"为什么坏人也能赚钱？因为他有能力。一个人的善恶跟能力的高低没关系"。
- **判断 C：赚钱与态度无关**——"很多大艺术家淡泊名利但又有名又有利，因为赚钱只跟能力相关"。
- 金句："能力到了那个份上，你不想赚，钱也追着你走"。
- 应用：所以搞钱的第一件事**不是找赛道**，是想清楚"你跟别人拼哪一个专业能力、哪一个维度"。

### 3. 牛名美怪（核心方法论）：任何领域四选一

- 出处：奇葩说筛选嘉宾的四字标准。
- **牛 = 大牛人 / 领域顶尖**：在任一领域做到前 10% / 第一名 → 永远不会被替代（美甲、寿司先人、米饭先人）。哪怕 AI 来了也替代不了美甲前 1%。
- **名 = 名人 IP**：范冰冰的 Fanbeauty 面膜、卡戴珊内衣、Mrs. Beast 的巧克力——**"你只要有名，做什么天然就有流量基础"**。
- **美 = 颜值到极致**：厦门那家艺术家开的医美机构、汉服主题餐厅——**"进来就是打卡拍照，也有生存空间"**。
- **怪 = 独特到出圈**：安福路熊爪咖啡——**"墙上一个洞、熊爪伸出来做，口味未必最好、但奇怪独特就有生意"**。
- 金句："生意难做是因为你没有差异化、你没有特点——牛名美怪四选一就能出来。"

### 4. 差异化 + 定位：你是货架上一个被卖的商品

- 上海交大商科教授金句："**你一生都要参透一个词叫与众不同**——既要跟别人有差异化，又要能变成商业价值。"
- 反面：中国大同思维——女孩容易觉得"天下大同"，其实**世界一定是有竞争的**，你只需要比别人好一点点就行。
- 类比：**每个人都好像是货架上被卖的商品**——你是在卖自己的什么东西？为什么有人买单？
- 变现方式：可能是打工工资 / 付费产品 / 点击量 / 各种流量 → 归根到底是"**别人为什么买你**"。
- 应用底层：找到自己**跟别人不同的那个点**——这就是"定位"，就是赚钱的方向。

### 5. 品类 × 区域 × 价格段：市场可以被拆成无数格子

- 反直觉洞察：中国餐饮"最卷"——但**活得好的非常多**，因为它被切成无数细分品类。
- 拆解维度：
  - **品类**：中餐 / 西餐 / 正餐 / 快餐 → 中餐里陕西面馆 / 火锅 / 火锅里的巴奴（毛肚火锅）/ 鲜牛肉火锅。
  - **区域**：某某公司在湖北做得特别好 → 你在自己老家能不能做类似的。
  - **价格段**：高端 / 中端 / 低端 → 每个价格段都是不同的客群。
- 结论：**"品类 × 区域 × 价格段，市场可以被细分成无数小格子"**——你只要在这一个格子里比其他人强，就能占领这个细分市场做**根据地**，再向外拓。

### 6. 主持人给 18 岁女孩的具体动作：先做信息搬运工

- 场景："你今天花钱来到狂喜现场——这场子起码 100 个人吧、走之前把 100 个人微信全加上。"
- 逻辑：**"你不用得到一个答案叫我到底能干啥——你有一个欲望和动力就行"**。
- 底层心法："**不追寻的过程就是最好的结果**——你啥也不知道、你这张白纸看到什么都行、你把自己当成一个小中介、做信息搬运工"。
- 竞争优势：**"你比班里同学更早知道优秀年轻人在干嘛"**——你以肉身参与现场的时间比同学长，你有信息差优势。
- 反面："女孩有时会刻意忽视这点、觉得天下大同——不对，这个世界一定是有竞争的，你只需要比别人好一点点。"

### 7. 阿金案例：布拉格 3 家面馆——扩张问题的正确拆法

- 背景：在欧洲做中餐面馆品牌 + 一年内做到第 3 家店 + 主业外的副业 + 团队在布拉格和上海两边。
- 主诉："商业模式跑通到什么程度才算能复制？怎么判断这个节点？"
- 主持人翻译："她在布拉格开面馆——遇到了第三家店之后怎么扩张的问题。"
- 金星第一反应：**"分两步——向内看 + 向外看"**——不是先想"要不要扩"，是先分两条线各看一遍。
- 前置判断：**"前两家店的财务回报应该还不错、肯定是赚钱的对吧？"**——单店盈利是复制的前提。

### 8. 连锁的中台能力：五大模块 + 何时该建

- **五大中台能力**（金星拆解）：
  - 人员招聘 + 培训 + 品控能力
  - 供应链能力
  - 品项迭代能力（新品研发）
  - 品牌市场获客能力
  - 数字化 / 远程管理能力（规模大了必须）
- 中台的本质：**"中台是成本中心——它是不产生收益的"**。
- 判断规则：
  - **目标 5-10 家店 + 有 2-3 个好合伙人各盯 3 家 → 完全不需要中台**。
  - **目标 50+ 店 / 100+ 店 → 才需要中台**——因为投入巨大、短期看不到收益。
- 金句："**做中台就像盖房子打地基——你的楼要盖多高，你的地基就要打多深**"。
- 反面：只有 5 家店时盖大中台，反而拖累——**"这 5 家店还要去适应使用你的这套系统、其实是起负面效果的"**。

### 9. 向外看：市场空间 + 竞品壁垒 + 品牌 vs 地道

- **判断问题一**：市场空间到底有多大？——这个品类在海外是"一段时间流行"还是"长期能流行"？
- **判断问题二**：竞品会怎么进来？——如果开了之后同胞发现是好生意跟着开，你的壁垒到底是什么？
- **判断问题三**：当地人认品牌还是认地道？
  - 如果**认品牌** → 你可以做连锁 + 有先发优势 + 供应链优势。
  - 如果**认地道**（华人多 + 老外觉得品牌 = 不地道）→ 你可能就不能做连锁。
- 应用方法：**做当地用户调研**——已有顾客为什么喜欢你？会不会定期来吃？市面上同类里为什么选你？
- 主持人翻译："她要在布拉格及周围城市开面馆——是靠开 100 家面馆挣钱，还是横向加河粉、盖浇饭、麻辣烫、糖葫芦？"

### 10. 新氧做轻医美连锁的完整决策路径（黄金案例）

- **2021 年做的判断**：
  - 中国 2 万家医美机构 + **没有一家大型连锁**——历史上医美 70-80% 是整形（无法标准化、高度依赖个体医生）。
  - 转折点：2021 年**轻医美占比第一次超过整形**——欧美发达国家轻医美 80%+ → 中国要走同样的路。
  - 轻医美相对能标准化：光子嫩肤 / 血光针 / 瘦脸针都是一台仪器 + SOP + 培训好的医生。
  - 韩国 / 日本 / 香港 / 台湾都有成功连锁 → 韩国第一名接近 50 家店（4900 万人口 + 首尔一个大城市）→ 中国按比例可以做**千店连锁**。
- **新氧的独家优势**：
  - **获客能力**——医美获客占成本 30-50%，新氧作为互联网平台有天然优势。
  - **供应链前置布局**——上游厂家在中国正快速兴起。
- **4 年分阶段验证**：
  - **第 1 年**：买上游光电设备工厂（8+ 亿）——先夯供应链。
  - **第 2 年**：又花 2 亿代理几款针剂 + **做虚拟连锁**（心氧优享）——找 200 家医美机构、每家出几个诊室合作、SOP / 定价 / 供应链全部我做 → 除了门店不是我的，其他跟连锁一样，把中台先搭起来。
  - **第 3 年**：开第一家店（400 平米、第一个月 40 个到店 → 第 4-5 个月盈利 → 第 10 个月月接待 1200 人）——只开一家。
  - **等第一家店跑完 10 个月后**，才开**第二批店**（长沙 / 成都 / 重庆 / 武汉、100-700 平米、市中心 / 郊区、写字楼 / 商场 → 半年跑出**最佳店型**）。
  - **第四批店开始复制**。
- 底层：**"每一步都是一点小东西撬动稍微大一点的东西"**——绝对不能一年就到大规模。

### 11. 大单品 + 连锁的"全局最优"逻辑

- 反直觉：连锁不能"局部最优"——一个新品类的成本远大于收益。
- 举例：瑞幸咖啡有几十个 SKU 但一贯策略叫"**拿铁帝国**"——生椰拿铁、丝绒拿铁、陨石拿铁——**都是拿铁**。星巴克世界菜单都接近一致。
- 拆解成本：每上一个 SKU → 供应链 / 培训 / 品控 / 营销物料**全部要改**——连锁的成本是小饭店的几十倍。
- 金句："**连锁的思考方式是全局最优、不是局部最优——你为了规模会去牺牲差异化**"。
- 应用：
  - 阿金**核心品类聚焦**（陕西面馆就是陕西面馆、别加河粉盖浇饭）；
  - 当主品类足够强了，**加新品类不会挨骂**（瑞幸卖奶茶大家也不觉得奇怪）；
  - 但一开始就多品类 → **老外会被竞品攻击"不地道"** → 会输。

### 12. 跨境电商案例：一人一年 100 万 → 转培训是南辕北辙吗？

- **主持人翻译**：一人一年 100 万，卖水（培训）是不是比淘金子（继续跨境）更好？
- 邓永平箴言："做企业就像跳水，动作越少越好"——所有变动都是成本 + 风险，**没必要变就不要变**。
- 金星建议：跨境本身**不亏就继续做**；再判断要不要"横向去做培训"。
- 关键警示：把同行都培训好，他们就会回来跟你竞争——**你把护城河亲手拆掉**。

### 13. 产业链全景图分析法：从平视升到俯视

- 问题根源："我们困惑，是因为我们只在产业链平视——看不清"。
- 方法：把跨境电商 / 医美 / 任何行业的**上中下游全景图**梳理出来——上游是产品设备，下游是终端消费机构，中游是导流/代运营/培训/会展/经销……
- 每个环节写清楚：**盘子多大、玩家数量、玩家数量近 3 年是变多还是变少**。
- 最优选择标准：**盘子在增长 + 玩家数量在减少**——说明壁垒变高、剩者为王。
- 最差选择：**盘子在缩水 + 玩家数量激增**——红海必输。
- 金句："**选择比努力更重要——因为趋势就是红利**"。

### 14. 培训 vs 交易的能力模型：不是同一件事

- 交易能力：**做生意的能力**——投流、供应链、成交效率、资金周转。
- 培训能力：**营销 + 抽象 + IP + 陪跑**——能不能把经验翻译成知识（抽象），能不能卖出去（营销），能不能有稀缺资源背书（大咖）。
- 卖书案例：出版社 → 分销公司 → 名人切片 → 投流 → 佣金——**核心能力是投流规模优势 + 现金垫付能力**。
- 卖课的坑：**没有壁垒的课**——你 999 卖出去，闲鱼 9.9 就有盗版。
- 陪跑与社群的核心能力：**触达 + 信任 + 运营** → 都需要个人 IP 与人脉密度。

### 15. 巴菲特四大护城河：判断生意能做多久

- **迁移成本**（微信：关系链沉淀 → 换 App 成本极高）。
- **品牌**（新公司要从零建立认知，耗时 5-10 年）。
- **知识产权**（独家专利、独家代理、独家合同）。
- **规模优势**（投流成本随规模下降、供应链谈判权提升）。
- 应用：**先想清楚你想构建哪条护城河，再决定要不要变**。
- 金星原话："你想长期去做，就总要抓住一些什么东西——那个东西只能被你独家掌握到"。

### 16. 上、中、下策：为跨境电商同学提炼的三条路

- **上策**（向上抓）：拿某类产品的**独家代理权**（如智能割草机器人在欧美爆火）→ 从电商跃迁成品牌方。
- **中策**（向下抓）：做大到能跟平台谈**独家合作条件 / 成本优势**——渠道话语权。
- **横向做培训**：只是**平着做**——不增加壁垒，且亲手教出竞争对手。
- 主持人总结："你可以用'**上和下**'的思考维度，比平着做增加了你的选择空间"。

### 17. 35 岁打工焦虑 & 副业副本

- 现场提问者：38 岁上海互联网打工人，抗风险能力弱，问该继续深耕本职还是开副业副本。
- 金星反问："**35 岁槛只针对不突出的人**——真正牛的人才，硅谷现在贵到打破天，全世界所有好公司都在抢"。
- 主持人补充："好公司讲究**人才密度**——牛人放一起自己会卷"。
- 举例：新仰的 CMO 是 13 年入职的女孩，先做内容 → 3-4 年前突然管理能力上线 → 今年才升 CMO——**"我真的是等着他一点点长起来"**。

### 18. 副业本质：能力溢出 + 交叉领域

- 副业 = **专业能力已经溢出**（你能操盘 1000 万的案子，但公司只给你 300 万的项目让你做）。
- 溢出方向 1：**同专业接外部单子**——直接变现你已经会做的事。
- 溢出方向 2（更值钱）：**交叉领域**——不是单点做到 Top，而是"互联网 × 医美"的交叉节点上做第一名。
- 乔布斯范式："**科技 × 艺术**"的交叉点上做出苹果——同样适用于个人。
- 现场案例：阿金（前排陕西面馆同学）本来主业是餐饮出海，副业是给"想来大厂打工的人做咨询和改简历"——因为他自己在大厂打了 8 年工，就有 7 年的经验溢出。

### 19. 1-3 年新人 → 副业选择的两个前置问题

- 现场提问者：1-3 年互联网电商运营新人，想在做播客采访、大厂 vlog、跨境代运营三个方向里选副业。
- 主持人诘问一："你出来的**动机**是什么？——是钱不够多，还是不想当'嫡系'？"
- 主持人诘问二："自媒体是**极度吃资源、极度吃人脉**的行业——你**手里能拿出什么和别人交换**？"
- 主持人自曝："我出来创业能拿到你们眼中很爽的钱，其实是**一笔负债**——之所以敢背，是因为手机里已经有 **7500 个客户**"。
- 结论：**数量多的打败数量少的**——你在打工时位置越高，能控的盘、能带走的人脉越多。

### 20. 老板思维 vs 打工思维：先在职场成为一个胜利者

- 金星底层观点："**一个年轻人如果想创业，要做的第一件事是先在职场成为一个胜利者**"。
- 心法：每次从一家公司离开，**必须以胜利者姿态离开**——"老子是跳槽、是我主动不要你"，不是被 PUA 走的。
- 信心机制：**每一段路都胜利 → 信心叠加 → 越来越能看清事情的本质**；反之挫折累积会耗光判断力。
- 主持人加码："打工也好，创业也好，要达到的是 **win win**——我多倍给你东西，你把我需要的给我；创业只是更难的版本，本质仍是**交换**"。
- 金句："**创业更难并不是挑战不过去，而是你没有想到它的本质就是交换——怎么让别人感觉他赚到了、他赢了，然后把真正的胜利留给自己**"。

## 关键问答

### Q1. 18 岁大一学生天崩开局，怎么搞钱？

**关键回答（主持人）**：不要急着定义"我到底能干啥"，先做**信息搬运工的小中介**——把现场 100 个人的微信加上，把优秀年轻人在做什么这件事**摸爬一遍**。你不需要答案，只需要**欲望和动力 + 信息差优势**。差异化不用大，"比别人好一点点"就够了。

### Q2. 赚钱到底跟什么强相关？

**关键回答（金星）**：**跟能力强相关**，不跟善恶、爱不爱钱、读多少书相关。1 万小时定律仍然管用——在任何一个领域做到前 10%，AI 都替代不了你。大艺术家淡泊名利也能名利双收，因为**能力到了那份儿上，钱是追着你跑的**。

### Q3. 一个人的核心竞争力怎么定位——用什么方法？

**关键回答（金星）**：套用《奇葩说》选嘉宾的四字标准——**"牛、名、美、怪"**：
- **牛** = 领域前 10%（美甲女孩做埃及艳后指甲、寿司先人、米饭先人）；
- **名** = 名人或大品牌背书（范冰冰 Fenbeauty、卡戴珊内衣、野兽先生巧克力）；
- **美** = 颜值/审美体验（艺术馆式医美机构、汉服餐厅）；
- **怪** = 独特（安福路熊爪咖啡）。
四条任选其一做到极致即可。

### Q4. 布拉格开了第三家中餐面馆，什么时候该扩张？该不该建中台？

**关键回答（金星）**："向内看 + 向外看"两步走：
- **向内**：单店盈利模型跑通了没？中台 5 项能力（招聘培训 / 品控 / 供应链 / 品牌获客 / 数字化）建不建，取决于目标店数——**5-10 家不用中台，50+ 家才必须建**；中台是成本中心，"盖房子打地基——楼多高、地基就多深"。
- **向外**：市场空间 + 竞品壁垒 + 老外认品牌还是认地道——**如果认地道，就做不成连锁**。

### Q5. 中餐连锁想扩张，是横向加品类还是纵深打大单品？

**关键回答（金星）**：**先聚焦大单品**。瑞幸 = 拿铁帝国（生椰/丝绒/陨石都是拿铁），星巴克全世界菜单一致——**连锁的思考方式是"全局最优"不是"局部最优"**。老外攻击你的最佳武器就是"不地道"——一开始加河粉盖浇饭麻辣烫会输。**主品类足够强以后加新品类不挨骂**（瑞幸卖奶茶大家不觉得奇怪）。

### Q6. 跨境电商一年 100 万卡瓶颈，要不要转做跨境培训课？

**关键回答（金星）**：
- 邓永平箴言 "**做企业像跳水，动作越少越好**"——**跨境本身别停，继续做**；
- 用**产业链全景图 + 玩家数量趋势**判断培训环节该不该进入；
- 培训是**平着做 → 亲手教出竞争对手**；
- 更好的选择是**上策（拿产品独家代理权）**或**下策（做大后与平台谈独家条件）**——从店主/电商跃迁到品牌方或渠道方，才有护城河。

### Q7. 打工人 38 岁抗风险弱，该深耕本职还是开副业副本？

**关键回答（金星 + 主持人）**：
- 金星："35 岁槛只针对不突出的人"——**"千军易得、一将难求"，好人才所有大厂都在抢，硅谷 AI 人才现在贵到爆**；
- 主持人："**副业是能力溢出的产物**"——公司平台放不下你，才有副业空间；**能力还没溢出就先补短板**；
- 关键前置问题："你上过桌了吗？——公司里位置越高，能控的盘子、能带走的资源越多"。

### Q8. 1-3 年新人，打工要熬几年才能出来做副业/创业？

**关键回答（主持人 + 金星）**：
- 主持人："**打工没有非常成功的人，创业大概率也不成功**"——因为对能力维度的要求
是全方位的；如果你能在打工时"以胜利者姿态离开"，累积信心和资源，出来做副业/创业的成功率才够高。
- 金星："**兼职是最好的创业方式**"——反正你有工资兜底，可以走一步看一步；但**很怕走一步看一步**（脑子必须极其好使，事事都要想到强关联/无关联）。
- 主持人："**做自媒体极度吃资源、极度吃人脉**"——我出来创业敢背几百万负债，是因为微信里有 7500 个客户；你手里没牌，就先在职场把牌攒够。

## 关联
### 概念（stub 候选）

- [[概念/牛名美怪]]：核心竞争力定位四标准（牛=前 10%、名=背书、美=审美溢价、怪=独特），源于《奇葩说》嘉宾筛选，被金星迁移到个人与生意定位。
- [[概念/大单品-拿铁帝国]]：瑞幸围绕拿铁做无限 SKU 变体，星巴克全球菜单一致——连锁品牌的品类聚焦策略。
- [[概念/中台]]：连锁品牌的成本中心（招聘培训/品控/供应链/品牌获客/数字化 5 大能力），5-10 家不用建，50+ 家才必须建。
- [[概念/巴菲特四大护城河]]：迁移成本 / 品牌 / 知识产权 / 规模优势——判断生意能做多久的核心框架。
- [[概念/能力溢出]]：副业的本质定义——公司平台承载不下你的专业能力时，才有副业空间；否则先补短板。

### 方法 / 框架（stub 候选）

- [[方法/[框架]产业链全景图分析法]]：把行业上中下游拆成 20-30 个环节，标注每个环节盘子大小 + 玩家数量趋势（3 年变多还是变少），选"盘子涨 + 玩家降"的环节。
- [[方法/[SOP]连锁开店的向内看-向外看]]：向内=单店盈利、中台能力5件套、目标店数；向外=市场空间、竞品壁垒、用户认品牌还是认地道。
- [[方法/[SOP]虚拟连锁验证]]：新仰做医美连锁前 2 年，先不开店，用 200 家机构合作电中店，验证模式 + 建立中台，再开第一家店。
- [[方法/[框架]店型定义]]：连锁的最佳店型 = 面积 × 分区 × 诊室数 × 人员配比 × 选址类型 × SKU 数 × 价格段——第一家店验证盈利后，第二批店验证店型，第三批店才复制。
- [[方法/[心法]信心叠加机制]]：每段职场路都要以胜利者姿态离开——挫折累积消耗判断力，胜利叠加放大判断力。
