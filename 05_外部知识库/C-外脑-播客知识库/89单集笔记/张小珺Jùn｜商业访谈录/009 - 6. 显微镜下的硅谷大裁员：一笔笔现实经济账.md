# 009 - 显微镜下的硅谷大裁员：一笔笔现实经济账

> 结构化说明：本笔记基于机器转写与清洗稿整理，属于 L4 萃取成品；原始音频、原始转写、清洗稿应继续作为原料保留。

## 一句话核心

在硅谷科技寒冬中，亲历者以理性视角看待裁员，强调个人能力与业务判断的重要性，并对比中美职场差异，认为只要补偿到位、心态躺平，裁员并非灾难。

## 摘要

Meta产品经理Neal Zhang亲历了公司史上最大规模裁员（11000人，13%）。他从亲历者视角讲述了裁员始末：华尔街日报提前爆料、周三凌晨邮件通知、全员会议、补偿方案（4个月工资+ N/2 + 股票兑现+6个月医保）。他因经历过国内双减和游戏行业多次重组，心态平稳，认为能力强的人应提前预判业务重点并准备面试。节目还深入对比了中美薪酬、职级、生活成本、年龄歧视、签证压力等现实问题，并给出冷血建议：被裁不可怕，关键是提前找工作。

## 发言人

- **张小珺**：主持人，商业访谈录主理人。
- **Neal Zhang**：Meta产品经理，所在部门为现代推荐系统（Modern Recommendation System），此前在游戏公司、腾讯投资的教育公司工作，经历过国内双减。

## 故事与场景

- **Neal的双重风暴**：去年经历国内教育双减（腾讯投资的教育公司部门解散），今年又亲历Meta史上最大裁员，两次都在风暴中心。
- **裁员周的时间线**：周日华尔街日报爆料 → 周三凌晨3点（西部时间）小扎发全员信 → 6点收到个人邮件（未被影响） → 周三小扎20分钟讲话 → 周五小扎回答员工问题 → 所有工作会议取消，只保留一对一。
- **补偿金计算实例**：以E5（工作5年左右）为例，年薪约50万美金，一半股票一半现金。被裁可拿4个月工资+ N/2（工作两年多拿一个月）+ 一个季度股票兑现，税后约12万美金。E6年薪约60万，补偿约20万美金。
- **有绿卡vs无绿卡**：无绿卡员工需在60天内找到新工作（H1B宽限期），且正值节假日招聘淡季，压力巨大；有绿卡者甚至有人“无缝衔接”，周五被裁、下周一新公司上班。
- **面试准备**：Neal在裁员前后主动准备面试，联系十几个猎头、投三四十家公司、练习60小时、实际面试近100场（包括微软12次、谷歌7次、Meta 6次等）。
- **中美生活成本对比**：美国吃饭一顿60-150美金（含税和小费后实际支出约65%额外费用），中国一顿三四百人民币；美国看胃溃疡要3个月，中国上午挂号中午出结果。
- **华人最高层级**：Meta CFO是华人ABC（美国出生华人），从大陆过来的最高是VP，清华北大毕业的很多。

## 核心概念

- **裁员补偿公式**：Meta裁员补偿为“4个月工资 + N/2（N为工作年数，每两年多一个月） + 11月15日股票兑现 + 6个月COBRA医保”。这是硅谷大厂的标准做法，补偿金额可观，对有绿卡者甚至是一种“福利”。
- **业务判断力**：Neal认为产品经理和数据科学家应该有能力判断自己所在的业务是否是公司未来重点。他主动选择推荐系统和短视频（Discovery Engine），因为这是Meta的核心方向，所以团队受影响最小。
- **H1B签证压力**：被裁后H1B持有者只有60天宽限期找到新工作，否则必须离境。在节假日和招聘冷冻期，这是华人最焦虑的痛点，也是硅谷裁员与国内裁员最大的区别。
- **职级体系与薪酬对标**：Meta E5 ≈ 字节3-2到4-1 ≈ 腾讯P12 ≈ 微软66 ≈ 谷歌6 ≈ 亚马逊7。美国年薪约55-65万美金（420万人民币），国内同级别约240-250万人民币。但美国税后实际到手少，生活成本高。
- **职业打工人**：Neal自认是“职业打工人”，没有创业冒险精神，追求稳定、家庭和健康。他认为只要极简生活可以生存，额外收入都是恩赐，因此对裁员心态平和。
- **科技红利结束**：移动互联网增长到头，手机红利结束，所有靠增长做估值的公司都遇到瓶颈。Meta裁员根源是收入不再增长、成本膨胀、元宇宙投入巨大、股票下跌。
- **年龄歧视差异**：硅谷没有35岁年龄坎，30岁不结婚、40岁买房都很正常；国内竞争激烈，越早上车越好，存在隐性年龄歧视。
- **极简生活心态**：Neal的生存哲学：降低自我满足感，躺平，健康快乐与家人在一起。只要不工作也能生存，工作就是恩赐。

## 我的批注

> [!NOTE] 冷血建议背后的理性逻辑
> Neal反复强调“产品经理应该提前预判业务重点”，这其实是一种职业生存的元能力。在科技行业，个人努力固然重要，但选择赛道（是否在核心业务）往往比努力更关键。他的“冷血”不是冷漠，而是对商业规律的清醒认知。

> [!NOTE] 中美职场对比的深层启示
> 硅谷的高薪背后是高昂的生活成本和税负，国内虽然薪资低但生活成本（尤其租房、吃饭、医疗）更低。更重要的是，硅谷没有年龄歧视、工作节奏更轻松，但文化隔阂和家庭分离是长期代价。Neal最终打算回国，说明“硅谷梦”正在被重新定义。

> [!QUESTION] 如果裁员发生在国内，补偿和签证压力会有什么不同？
> 国内裁员补偿通常按N+1（工作年限+1个月），没有股票兑现和医保延续，且没有签证宽限期问题。但国内有社保和公积金，裁员后可以领失业金。中美两套体系下，员工的实际保障和焦虑点完全不同。如果国内也出现大规模科技裁员，员工的心态和应对策略会如何？

## 可行动清单

- [ ] 定期审视自己所在业务是否是公司未来1-2年的核心方向，如果不是，提前准备跳槽或转岗。
- [ ] 建立至少3个月的紧急生活储备金，确保即使被裁也能维持基本生活。
- [ ] 对于H1B持有者，提前了解60天宽限期规则，并保持与移民律师的联系。
- [ ] 在就业市场冷冻期，主动联系猎头、投递简历，每周至少练习2次模拟面试。
- [ ] 降低自我满足感，练习“躺平”心态：把健康、家庭、快乐放在职业成就之前。
- [ ] 学习计算裁员补偿：了解公司政策（如Meta的4+N/2+股票+医保），提前估算自己能拿多少钱。
- [ ] 如果计划回国，提前了解国内职级对标（如Meta E5对应字节3-2/腾讯P12），并关注年龄门槛。
- [ ] 建立个人“业务判断力”清单：每季度评估公司财报、战略会议纪要、内部资源分配，判断自己所在部门的优先级。
- [ ] 对于有绿卡者，把裁员视为“带薪休假+跳槽机会”，利用补偿金期间面试和休息。
- [ ] 在社交媒体（如LinkedIn、Blind）上关注裁员动态和行业趋势，但避免过度焦虑。

## 对话稿

**张小珺**：简单跟我们说一下，你现在所在的位置啊？

**Neal Zhang**：我现在定居在美国的尔湾，是位于洛杉矶和圣地亚哥之间的一个海滨城市。我实际工作地点在Meta总部，但公司允许灵活办公。

**张小珺**：讲一讲裁员的话，实际上我们上周日就从华尔街日报已经了解到公司有裁员的动向。

**Neal Zhang**：周三早上陆陆续续通知所有员工，就跟中彩票一样，有的人收到email说“你很幸运，你被留下了”，有的人说“抱歉，你被裁掉了”。

**张小珺**：补偿给到位了吗？你觉得是4+4+N/2？

**Neal Zhang**：对，4个月工资加4个月补偿是4个月离职金，如果你给公司工作了两年，再额外多拿一个月，就是N/2。再加6个月COBRA医疗保险，11月15号的股票也会兑现。

**张小珺**：你经历过好几次这种大的风波吧，你觉得自己的心态是怎么一次一次变化和进化的？

**Neal Zhang**：我跟我私下的朋友聊天的时候，讲得很冷血。作为产品经理和数据分析师，如果被裁了，在Meta和Google这种公司实际上是不应该的。因为你应该对自己的业务有个判断，它是不是公司的重点项目。

**张小珺**：有绿卡和没绿卡挑战完全不一样？

**Neal Zhang**：对，没绿卡的人要在60天内找到工作，在节假日和招聘冷冻期很难。有绿卡的同学被裁掉了，对很多人来说都是一种幸福，尤其是能力强的人。

**张小珺**：硅谷的薪酬和国内的薪酬的对比？

**Neal Zhang**：拿腾讯P12、字节3-2到4-1、微软66、谷歌6、Meta E6来算，美国年薪约55-65万美金（420万人民币），国内同级别约240-250万人民币。但美国税后实际到手少，生活成本高。

**张小珺**：硅谷是没有35岁这个坎是吗？

**Neal Zhang**：对，硅谷总体来说没有。美国到30岁不结婚都很正常，买房子都是40岁以后。国内竞争的人太多，不缺人才，越早上车越好。

**张小珺**：你觉得这次裁员潮的根源是什么？

**Neal Zhang**：外界判断三点：小扎明年还会继续加大元宇宙投入，成本降不下来；收入不再增长；对财务未来预期错误，超额雇了太多人。

**张小珺**：08年那次金融危机和现在，哪个更良意？

**Neal Zhang**：肯定是08年。当时H1B都抽不完65000个名额，现在H1B明年4月肯定还是一抽而空。现在只是大的企业遇到瓶颈，移动互联网增长结束了。

**Neal Zhang**：我在知道自己要被裁和没被裁的时候，开始准备面试。猎头找了十几个，自己投了三四十家，练习面试至少60小时，实际面试不到100场。跟微软面试了11次，谷歌7次，Meta至少6次。
