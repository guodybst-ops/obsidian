# 111 - 余凯口述30年史：世界不止刀光剑影，是一部人来人往的江湖故事

> 结构化说明：本笔记基于机器转写与清洗稿整理，属于 L4 萃取成品；原始音频、原始转写、清洗稿应继续作为原料保留。

## 一句话核心

创业的本质不是技术和商业的刀光剑影，而是理解人、共情客户、在反共识中寻找窄门，并始终思考“死门”在哪里的江湖故事。

## 摘要

地平线创始人余凯口述30年经历：从南京大学逃课生到慕尼黑大学博士，从西门子、NEC研究院到百度深度学习研究院院长，再到2015年创立地平线。他经历了学术圈的籍籍无名、互联网圈的秘密竞拍、创业圈的暗无天日、资本圈的融资策略、汽车圈的客户攻坚。核心方法论是“反共识”——永远在没有竞争的地方竞争，70%精力思考死门，做人做事留有余地。他认为自动驾驶即将被解决，未来十年目标是让机器人时代的计算平台像CUDA一样成为基础设施。

## 发言人

- **张小珺**：主持人，商业访谈录主理人
- **余凯**：地平线创始人兼CEO，南京大学、慕尼黑大学博士，前百度深度学习研究院院长

## 故事与场景

1. **学术圈的“吃闷饭”**：2002年NIPS会议，余凯看到Richard Sutton一个人沉默地吃闷饭，没人搭理他，因为强化学习在当时是旁门左道。多年后Sutton拿了图灵奖。
2. **秘密竞拍Geoffrey Hinton**：2012年，余凯代表百度参与竞拍Hinton及其两个学生。他拿到2400万美金授权，抢先出价1200万美金试图吓退对手，最终竞拍到4400万美金。Hinton选择了谷歌，但余凯认为自己是赢家——让李彦宏看到了AI人才的价值。
3. **忽悠吴恩达回国**：2014年初，余凯在帕拉阿图酒店偶遇吴恩达，发现他做在线教育不顺。余凯用“你想买多少GPU就可以买多少GPU”打动他加入百度。一个月后余凯告诉吴恩达自己要创业，吴恩达震惊：“你小子把我忽悠到百度，自己跑掉！”
4. **与李想爬山**：2019年初，湖畔大学开学仪式上，余凯和李想一起爬山。李想穿着军大衣，身体很差爬不上去，在山下等余凯。李想建议余凯聚焦汽车方向。
5. **长安踢球故意输**：与长安汽车联合开发时，双方团队三伏天累到在现场睡觉，有同学中暑。余凯和长安领导一起去看望。踢球时余凯让团队“优雅地、不露声色地故意输”。
6. **C轮融资12小轮**：2020年下半年到2021年上半年，资本市场狂欢。余凯反向操作，在已有8亿美金授权后继续融资，又拿了8亿美金，中间没涨一分钱估值。后来市场急转直下，地平线手握100亿现金。
7. **一个月裁600人**：2019年底决定聚焦汽车，原计划分三次裁员。余凯梦中惊醒，意识到这是让自己舒服而不是对员工好。改为一个月内全部裁完，亲自谈，年终奖照发，N+1补偿。
8. **与王传福的合作**：比亚迪另一家供应商供货出问题，地平线逮着机会“门开一个小缝就呲溜一声冲进去”。王传福亲自为地平线站台，这在以前从未有过。

## 核心概念

1. **反共识**：是什么——不跟随主流判断，从第一性原理推导出与众不同的结论。为什么重要——共识要么是错的（线性外推未来），要么是对的但没差异化。原文例子：所有人做云端芯片时，地平线做车规级芯片；所有人做软件算法时，地平线做软硬结合。

2. **耐得寂寞**：是什么——地平线的核心价值观之一，愿意去人迹罕至的地方，把非主流做成主流。为什么重要——长期坚持才能建立壁垒，不被短期热点干扰。原文例子：地平线花了5年才找到PMF（产品市场契合点）。

3. **生门与死门**：是什么——地平线的思考框架，70%精力思考死门（风险）在哪里，然后离它无限远。为什么重要——确保公司不在悬崖边跳舞，保持财务健康。原文例子：C轮融资时预判泡沫会破灭，反向狂拿现金。

4. **战略聚焦（舍九取一）**：是什么——砍掉所有非核心业务，集中所有炮火猛攻一个山头。为什么重要——资源有限，分散无法击穿。原文例子：2019年砍掉AIOT方向，裁600人，全部投入汽车。

5. **客户同理心**：是什么——To B生意的核心是理解客户的需求、痛点、情感，建立信任和共情。为什么重要——商业的本质是同理心。原文例子：长安最困难时地平线去帮忙；理想换供应商时地平线8个月完成量产。

6. **物理世界AI**：是什么——地平线的战略选择：在物理世界做AI（自动驾驶、机器人），而不是数字世界（推荐算法、内容平台）。为什么重要——物理世界的AI更“干净”，真正把人从繁重危险劳动中解放出来。

7. **机器人CUDA**：是什么——地平线未来十年的愿景：为机器人时代打造类似CUDA的计算平台和开放生态。为什么重要——自动驾驶收敛后，机器人是下一个万亿级市场，需要全新的计算架构。

## 我的批注

> [!NOTE] 反共识的代价与回报
> 余凯反复强调“反共识”，但地平线前5年“暗无天日”、融资困难、战略迷茫，正是反共识的代价。直到2019年聚焦汽车，才迎来爆发。反共识不是盲目标新立异，而是基于第一性原理的长期判断，并愿意承受不被理解的痛苦。

> [!NOTE] “江湖智慧”的底层是To B思维
> 余凯说自己擅长人际关系是因为做To B生意。To B需要推己及人、共情客户，这与To C“做自己”完全不同。他把学术圈、互联网圈、资本圈都视为“To B”——理解对方需求，找到结合点。这种思维可以迁移到任何需要协作的场景。

> [!QUESTION] 理想汽车既做供应商又做自研，余凯说“能接受”，但这是否意味着地平线的护城河不够深？
> 余凯认为自动驾驶是标准化功能，主机厂最终不会自研。但理想汽车把自动驾驶作为通往AI公司的“以战养战”路径。如果理想自研成功，地平线是否会失去最大客户？余凯的“能接受”是格局还是无奈？

## 可行动清单

- [ ] 在做重要决策前，先花70%精力思考“死门”在哪里，制定风险预案
- [ ] 与投资人第一次见面，坚持约在自己办公室，筛选真正有投资意愿的机构
- [ ] 创业初期如果战略不清晰，先回答三个问题：客户是谁？客户痛点是什么？如何难以复制地解决？
- [ ] 裁员或组织调整时，不要为了让自己舒服而拖延，一个月内完成，亲自沟通，坦诚原因
- [ ] 面对客户拒绝时，用“客户虐我千百遍，我待客户如初恋”的心态持续跟进
- [ ] 在热门赛道之外寻找“人迹罕至”的方向，用第一性原理判断而非类比
- [ ] 融资时保持克制，不在估值高点盲目扩张，预留足够现金应对寒冬
- [ ] 定期与不同圈层的人交流（学术、产业、资本），保持对“江湖”的感知
- [ ] 培养一个与主业无关的兴趣（如美术、哲学），提升“taste”和共情能力
- [ ] 离职或结束合作时，不说任何负面评价，给自己和对方都留有余地

## 对话稿

**张小珺：** 你虽然是科学家创业，但是你非常擅长人的关系，是这样吗？
**余凯：** 不知道哎，我觉得可能是因为做To B的生意，生意难做，所以必须要有同理心，能够共情。做To C的产品是要做自己，做To B的产品要更多地推己及人。

**张小珺：** 你当时为什么选择回国加入百度？
**余凯：** 我觉得中国的互联网苗头已经开始是世界级的了，有大量数据，有资源，是应用人工智能最好的场景。而且国内没有做深度学习的团队，我想做第一个。我应该是旅美人工智能华人学者第一个回国的。

**张小珺：** 你当时怎么忽悠吴恩达回国的？
**余凯：** 我说，Andrew，你如果加入百度，你想买多少GPU就可以买多少GPU。他当时在Google lead谷歌大脑，有一个frustration是不能买GPU。后来他加入百度，一个月后我告诉他我要创业，他震惊了。

**张小珺：** 你创业时做了哪三个投资？
**余凯：** 买了英伟达，买了特斯拉，全身心把我投到地平线。地平线刚创立那天，英伟达才107亿美金公司，现在是3万亿。

**张小珺：** 你融资有什么策略？
**余凯：** 我定了一个铁律：跟投资人第一次见面，绝不能在他办公室，一定要在我办公室。这样说明他敲门来了，是在漏斗下端接近出牌。我还要继续装，说我没时间，我是一个专注的、情商低的科学家。最后剩下的几家，才是真正想投的。

**张小珺：** 2019年你为什么决定聚焦汽车？
**余凯：** 曾鸣教授那堂战略课对我帮助很大。李想在2019年初爬山时也建议我聚焦汽车。我花了半年时间想明白，与其砸很多小坑，不如挖一口大油井。我们砍了600人，一个月内全部裁完。

**张小珺：** 你怎么搞定王传福的？
**余凯：** 比亚迪另一家供应商供货出问题，我们逮着机会窗口，相当于门开一个小缝，就呲溜一声冲进去。王总特别务实，我们天然容易谈到一起。

**张小珺：** 你最喜欢的领导者是谁？
**余凯：** 我的role model是刘邦，游刃有余，知道迂回进退。电影角色最喜欢《飘》里的白瑞德，在监狱里都能活得很滋润。

**张小珺：** 你怎么看主机厂自研自动驾驶？
**余凯：** 未来主机厂不会自研自动驾驶，它是一个标准化的功能。就像手机厂商不自研打电话功能一样。但理想汽车不一样，他的理想是成为AI公司，造车只是以战养战。

**张小珺：** 你对未来的预判是什么？
**余凯：** 3年完成100% hands-off，5年完成100% eyes-off，10年完成100% minds-off。人类未来不可避免会被AI算法圈养，但地平线要反其道而行之，在物理世界做AI，让机器归机器，人类归人类。
