# 014 - 11. 新加坡的淘金热和政商环境

> 结构化说明：本笔记基于机器转写与清洗稿整理，属于 L4 萃取成品；原始音频、原始转写、清洗稿应继续作为原料保留。

## 一句话核心

新加坡在 Web 3 时代成为全球枢纽而非中心，其政商环境以高效、高薪养廉、KPI 驱动著称，政府通过补贴和投资鼓励创业，但生活成本高，适合作为跳板而非终点。

## 摘要

嘉宾韩轶东（Neil HAN）在新加坡生活 16 年，经历多次创业浪潮。本期重点分析 2021 年底开始的 Web 3 淘金热，对比 Web 2 时代，讨论新加坡政府如何通过宽松政策吸引企业，淡马锡主权基金的运作特色，以及新移民带来的社交与租房冲击。他指出新加坡不会成为 Web 3 中心，只会是枢纽，并给中国创业者三条建议：新加坡不是终点、充分利用枢纽、以开放心态融入。

## 故事与场景

- **韩轶东第一次创业**：做音乐流媒体，新加坡政府通过企业发展局下属机构无条件给了 250 万人民币，条件“匪夷所思”但最终满足。
- **第二次创业（Snyppit）**：亚太第一款短视频，比字节跳动早四五年，用户增长极快，但因东南亚投资环境差、投资人要求收支平衡而失败。
- **淡马锡发比特币**：2010 年左右，淡马锡给每人发了一个比特币，让员工感受新技术，但大部分人把密钥丢了。
- **token2049 热潮**：2022 年 9 月，两天的活动衍生出 100 多场周边活动，史无前例。
- **徒步社交**：新移民组织大量徒步局，token2049 期间一次徒步有一二百人参加。
- **租房抢房**：去年每月房租涨 10%，看房必须立即下定金，否则被抢。
- **红杉印度投资**：红杉在新加坡的第一位员工，后来专职看 Web 3 投资。
- **政府 KPI 实例**：新加坡经济发展局官员用微信 24 小时联系，随时回复，开出优惠政策吸引企业设亚太总部。

## 核心概念

- **Web 3**：去中心化、数据透明、利益均摊的新一代互联网，用户拥有数据所有权，平台仅作为平台。例子：音乐人可通过 NFT 直接发行单曲，绕过华纳等版权公司。
- **淡马锡（Temasek）**：新加坡主权基金，以 VC 方式运作，投资范围极广（基建、生物制药、Web 3），投资回报率高，拿到其投资是本地人的极大荣耀。例子：淡马锡投了 FTX 遭受损失，但整体方向不变。
- **新加坡企业发展局（Enterprise Singapore）**：政府机构，下属“慈善机构”拨专款鼓励创业，占股份但退出条件简单。例子：韩轶东两次创业分别拿到 250 万和 150 万人民币。
- **枢纽 vs 中心**：新加坡经济体量小、缺乏技术人员和用户基础，无法成为 Web 3 中心，但凭借政策宽松、金融中心地位成为连接全球的枢纽。例子：前十大 Web 3 公司有三家注册在新加坡。
- **公积金账户（CPF）**：每个新加坡人有一个账户，政府每年给 500 新币（约 2500 人民币）用于学习新课程；很多人自愿多存钱让政府管理，从未亏损。
- **KPI 导向政府**：新加坡官员有明确 KPI，薪资对标企业高管（总理约 1000 万人民币），政策极严，数据驱动决策。例子：经济发展局官员用微信 24 小时跟进企业。
- **“Web 3 时代的犹太人”**：指一群有先进信息、全球游窜、不被某些国家待见的 Web 3 从业者，在新加坡聚集。例子：token2049 期间大量活动。

## 我的批注

> [!NOTE] 新加坡政府通过高薪养廉和 KPI 管理官员，效率极高，值得其他地区借鉴。但高薪也带来创业选择成本——放弃高管职位创业收入可能降至三分之一。

> [!NOTE] 淡马锡的运作模式（主权基金 VC 化、投资范围宽泛、民众自愿存钱）形成正向循环，但 FTX 投资损失也暴露了风险。

> [!QUESTION] 随着新加坡监管收紧（如限制本地人交易、加强 KYC），Web 3 热潮是否会降温？枢纽地位能否持续？

## 对话稿

**张小珺**：这波淘金热是怎么形成的？

**韩轶东**：2021 年底开始，Web 3 技术成熟，国内政策限制，资金和人才涌入新加坡。文化相通、政策宽松、金融中心地位共同促成。

**张小珺**：有多火？

**韩轶东**：token2049 那一周有 100 多场活动，史无前例。以前是我们找投资人，现在是不想见、不敢见投资人。

**张小珺**：新加坡政府为什么对 Web 3 开放？

**韩轶东**：新加坡小，没资源，愿意在沙盒内尝试新事物。淡马锡 2010 年就给每人发了一个比特币。

**张小珺**：新加坡创业和国内有什么不一样？

**韩轶东**：非常不一样。政府给钱但条件简单，比如第二次创业投 30 万新币占 15%，任何投资人可按原估值买走。国内投资环境更激进。

**张小珺**：你第二次创业做短视频，比头条早四五年，为什么失败了？

**韩轶东**：东南亚投资环境差，投资人要求收支平衡，而国内只看用户增长。政府投资公司不愿稀释股份，最终公司关掉。

**张小珺**：怎么看待张一鸣常驻新加坡？

**韩轶东**：字节跳动在新加坡有三四千人团队，新加坡作为华人社会、出差方便，可能是他思考未来的好地方。

**张小珺**：给想去新加坡的中国企业家三条建议？

**韩轶东**：第一，新加坡不是终点，是跳板；第二，充分利用枢纽，多接触新加坡人；第三，以开放心态融入国际社会。

**张小珺**：淡马锡的资金来源和运作特色？

**韩轶东**：来自国库积累和公积金，以 VC 方式运作，投资范围比红杉更宽泛（包括基建），中国最大的外资来源就是新加坡。

**张小珺**：一道必吃食物？

**韩轶东**：辣椒螃蟹。

**张小珺**：一个必须打卡地？

**韩轶东**：金沙酒店。

**张小珺**：一个少有人知道的新加坡文化知识点？

**韩轶东**：新加坡 1 元硬币是八卦形状，据说是李光耀听风水建议放的。

**张小珺**：一本必读书？

**韩轶东**：《李光耀观天下》，很多观点后来被验证。

**张小珺**：一个新加坡有潜力的创投机会？

**韩轶东**：（未明确回答，但暗示 Web 3 基础设施和出海服务）
