# 105 - 102. 和张祥雨聊，多模态研究的挣扎史和未来两年的2个“GPT-4时刻”

> 结构化说明：本笔记基于机器转写与清洗稿整理，属于 L4 萃取成品；原始音频、原始转写、清洗稿应继续作为原料保留。

## 一句话核心

多模态研究的“GPT-4时刻”将在未来两年内到来，核心路径是先在视觉空间实现Long CoT（长思维链），再通过自主学习/在线学习实现真正的智能突破。

## 摘要

阶跃星辰首席科学家张祥雨回顾了十年多模态研究史，从ResNet到视觉自监督学习的困境，再到多模态生成与理解一体化的挣扎。他揭示了训练大模型时发现的怪现象：模型越大，推理能力（尤其是数学）反而下降，根源在于Next Token Prediction的本质缺陷——更大的压缩率未必对应更高的计算精度。O1系列的成功本质是引入了反思等思维链Pattern，实现了Meta-CoT。张祥雨认为，视觉生成可控性差的根本原因是缺少COT，未来两年将出现两个“GPT-4时刻”：多模态推理（视觉空间的Long CoT）和自主学习/在线学习。

## 故事与场景

1. **训练万亿参数模型的怪现象**：张祥雨团队在训练Step-2万亿参数模型时发现，模型在文科上非常强，但数学推理能力反而下降。经过测试，从1B到70B的模型，推理能力呈现先上升后平缓再下降的曲线。
2. **模型跳步的蛛丝马迹**：更大的模型做数学题倾向于跳步，直接报出结果，虽然大部分正确，但一旦出错就导致整题错误。小模型反而会老老实实一步步计算。
3. **O1范式的反思Pattern**：张祥雨发现，O1模型在解决数学题时会自动产生反思、验算、回退、大循环等Pattern，这些Pattern在预训练语料中已有分布，但数量极少。
4. **视觉空间Long CoT的尝试**：张祥雨团队尝试在图像上做圈点批注（如数数时打点、走迷宫时连线），但效果不佳，因为这类数据在预训练语料中不存在，无法泛化。
5. **O1泛化到诗词创作**：张祥雨在纯数学数据上训练O1模型，发现它自动将反思Pattern泛化到古诗词创作，会先写草稿、检查格律、反复修改。

## 核心概念

1. **特征坍缩现象**：生成模型在训练时，会优先建模简单的分布，复杂分布需要更长时间或更大模型才能刻画。原文例子：小模型只能学会一步步计算，大模型会直接报出结果，因为后者更接近数据分布。
2. **Meta-CoT**：O1范式的本质，是CoT的CoT，即模型可以在多种思维链Pattern之间自由切换和排列组合，解决更复杂的网状问题。原文例子：从数学题到诗词创作，模型自动迁移了反思、验算等Pattern。
3. **视觉空间的Long CoT**：在视觉空间上做长思维链推理，如数数时打点、走迷宫时连线。原文例子：人类在图像上做圈点批注，模型需要学会这种动作空间。
4. **Critical Decision**：思维链中真正影响结果的关键决策点，数量很少（如四五千长度的序列中不超过10个）。原文例子：模型走到某一步时，需要决定走左边还是右边分支，这个决策无法在一个token内解决。
5. **自主学习/在线学习**：下一代智能的核心，模型能自主与环境交互、从自然语言反馈中学习、自我驱动。原文例子：人类写作文后老师给出多维度评价，但当前RL只能将评价压缩成一个数字。
6. **环境Scaling**：当前RL面临的新瓶颈，需要人工搭建大量环境（如编程任务），效率低下。原文例子：解编程问题需要搭Docker环境、写测试数据，一个project只能产生一条数据。

## 我的批注

> [!NOTE] 模型越大推理能力越差的现象值得关注
> 张祥雨揭示的“模型越大推理能力反而下降”现象，在业界尚未广泛讨论。这提示我们，Scaling Law并非万能，Next Token Prediction的压缩本质与推理精度存在根本矛盾。这可能是未来模型架构和训练方法变革的重要信号。

> [!NOTE] 视觉推理的难点在于预训练语料中缺乏相应Pattern
> 张祥雨团队尝试在图像上做圈点批注，但效果不佳，因为这类数据在预训练语料中不存在。而O1之所以能泛化，是因为反思Pattern在语料中已有分布。这揭示了预训练数据质量对模型能力的关键影响。

> [!QUESTION] 自主学习/在线学习是否真的能在两年内实现？
> 张祥雨预测自主学习/在线学习可能在两年内突破，但当前连“从自然语言反馈中学习”这一基础问题都未解决。这个时间表是否过于乐观？需要关注学术界在自然语言反馈和内生奖励方面的进展。

## 对话稿

**李广密**：训练过程中发现了一件百思不得其解的怪事——模型的通用对话能力、情商、知识量确实模型越大越强，但模型的推理能力（尤其是数学）表现是先上升后平缓，再扩大反而是下降。

**张祥雨**：我们发现更大的模型做数学题倾向于跳步，不老实。经过分析，这是next token prediction的本质缺陷——更大的压缩率未必对应更高的计算精度。

**张祥雨**：O1的核心是思维链的pattern——“做思考模型，pattern is all you need”。当模型走到某一步，摆在面前有两个分支，一个token之内到底能不能解决？不能，所以引入反思pattern。

**张祥雨**：O1范式的本质是一种Meta-CoT，是CoT的CoT。它使得模型可以在多种COT pattern之间自由切换，进行排列组合，把更复杂的网状问题解掉。

**张祥雨**：研究完O1，返回研究为什么视觉生成可控性这么差，就有了眉目。简单把生成和理解做到一起，难度非常大，缺失了重要一环——COT。

**张祥雨**：去年中开启新的project：视觉理解（视觉空间的Long CoT）。尝试了半年，结果只能说——不是完全没有效果，但完全没有在语言模型上看到的这么强大的泛化能力。

**张祥雨**：O系列不仅泛化了domain，更吸引人的是泛化了pattern。比如纯数学数据上训练的模型，可以自动将反思Pattern泛化到古诗词创作。

**张祥雨**：架构不重要，架构是服务算法和系统的。为什么我说Linear Transformer不本质？因为今天的算法是auto regressive的NTP，如果你用不同的算法，根本不需要Linear Attention。

**张祥雨**：下一个“GPT-4时刻”？模型的在线学习/自主学习。人虽然没有生成器官，但人有世界模型。我们的智能水平还在为视觉挣扎，机器人领域在抢跑。
