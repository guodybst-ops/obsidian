## 一句话核心

AI 正处于“把电机塞进蒸汽机”的阶段——每个人都在把 AI 加入工作流，但很少有人重新设计流程本身；组织架构需要从接力赛变为篮球赛，而模型公司的竞争已因 coding agent 成熟导致的递归自我改进变得几乎无法追赶。

## 摘要

本集 Freda Duan 深入探讨了 Token 作为计量单位的误导性——同样任务不同模型消耗 token 可差几十倍，行业将逐渐从按 token 收费转向按效果付费。她指出 coding agent 成熟后出现了“更好的 AI 训练更好的 AI”的循环，模型公司领先优势可能不再轮换。组织架构上，她类比电机取代蒸汽机的历史，认为当前处于“把电机塞进蒸汽机”阶段，未来应像篮球赛一样由 3-5 人小分队同步推进。她还分析了 AI 对投资行业的影响、应用创业公司的处境，并坦诚分享了在硅谷的焦虑与孤独，强调人和人之间剩下的只有情感连接。

## 故事与场景

- **Freda 深夜装 OpenCloud 痛哭**：几个月前，Freda 在家装不上 OpenCloud，因为需要写 JSON、找 API key，她连光标都找不到，当时非常着急、焦虑，觉得自己要被时代淘汰。
- **Anthropic Cowork 两个人做出来**：Cowork 是给普通人用的产品，增长斜率比 Claude Code 当时还要陡峭，而这么成功的产品只有两个人开发。
- **Serra 按效果收费**：做 AI 客服的公司 Serra，按解决率收费——AI 帮客户解决了问题才收钱，转了人工就不收，客户非常认可。
- **Meta 裁员与 AI 开支的巧合**：Meta 裁员 10%，Freda 算了一下，裁员节省的成本刚好对应它在 Claude 上的年花费（几十亿美元），但她说不是直接因果关系。
- **XAI 租数据中心给 Anthropic**：XAI 有三个数据中心，把其中一个不太用的（300 个 H100）租给最缺卡的 Anthropic，租出四五十亿美元收入，是一个很合理的商业决策。
- **Palo Alto 的真诚对话**：Freda 在 Palo Alto 随便跟一个朋友坐下来，本来没准备聊什么，结果话题跑到做事情的勇气、人生遗憾、在乎什么、什么让自己有 spark——那次对话没有信息增量，但很有“人味”，是她近一段时间最有内容的对话。

## 核心概念

### Tokenmaxxing
- **是什么**：当前行业大量消耗 Token 的现象，很多公司以 Token 用量作为指标。
- **为什么重要**：Token 消耗不等于价值创造，同样任务不同模型消耗可差几十倍，存在大量浪费。
- **原文例子**：Cursor 同一个问题消耗更多 token，但效果并不更好；Meta 在 Claude 上一年花几十亿，Uber 三个月花掉一整年 AI budget。

### Token per task
- **是什么**：完成一个具体任务所需的 Token 数量，是衡量模型效率的关键指标。
- **为什么重要**：不同模型输出长度、推理 token、工作流放大效应导致 token per task 差异巨大，未来最有效率的模型会被认可。
- **原文例子**：好的 coding 模型一两百行精炼代码写完，弱模型需要几千行啰嗦代码。

### 负向滚雪球
- **是什么**：Dario 提出的概念，指模型公司训练成本每年几倍增长，而收入增长跟不上，导致利润越滚越负。
- **为什么重要**：跳出这个循环只有两条路——训练 scaling 变慢，或者收入增长斜率更陡峭。
- **原文例子**：Anthropic 年初需求爆发，被迫把更多算力放在推理上，突然暴利，证明收入增长可以快于训练成本增长。

### 技术扩散与经济扩散
- **是什么**：Dario 提出的两个概念，技术扩散指模型能力本身的进步，经济扩散指模型能力被企业和经济吸收落地的速度。
- **为什么重要**：经济扩散可能落后技术扩散几年甚至十几年，研究组织架构就是在判断经济扩散的速度。
- **原文例子**：电灯泡发明后，生产率提升用了 40 年，因为工厂只是把电机塞进蒸汽机的位置，直到流水线形成才真正提升效率。

### 接力赛变篮球赛
- **是什么**：AI 时代组织架构的比喻——过去像接力赛，一棒一棒传递信息；未来像篮球赛，3-5 人小分队同步推进，自己拍板。
- **为什么重要**：传统层级本质是信息传递机制，AI 降低了信息传递成本，需要重新设计流程。
- **原文例子**：产品开发中，PM 写 PRD → Designer 解读 → Developer 开发 → QA → Go-to-market，每个环节都是翻译成本，AI 进来后每个环节都会变成新瓶颈。

### 效果付费
- **是什么**：从按 token 收费转向按实际效果收费的商业模式。
- **为什么重要**：Token 不可比，效果付费使客户与供应商利益对齐，共同追求效率。
- **原文例子**：Serra 按客服解决率收费，解决了才收钱；但写作等创意类场景效果难量化，可能长期仍按 token 收费。

### 递归自我改进
- **是什么**：当 coding agent 成熟后，更好的 AI 能训练出下一代更好的 AI，形成自我加速循环。
- **为什么重要**：一旦过了临界点，曲线变得非常陡峭，后来者可能再也追不上。
- **原文例子**：模型大厂出新模型速度从大几个月缩短到一个月，Meta 愿意花几十亿用别的公司模型，因为自己没有就会迭代慢一大档。

## 我的批注

> [!NOTE] Token 浪费与用量上升并不矛盾
> Freda 拆解了 AI 总投入公式：用户数 × 任务数 × token per task × dollar per token。前两项必然大幅增长（用户破圈到白领），后两项会优化。所以“浪费存在”和“用量上升”同时成立，这是行业早期特征。这个框架对理解 AI 投资很有用。

> [!NOTE] 组织架构变革的启示
> “接力赛变篮球赛”的比喻非常形象。传统层级本质是信息传递机制，AI 降低了传递成本，但很少有人退一步问“为什么公司需要这么多层级”。这提示我们，真正的变革不是把 AI 加入现有流程，而是围绕 AI 重新设计流程本身。

> [!QUESTION] 模型公司竞争真的到了无法追赶的地步吗？
> Freda 用马车换汽车类比，认为一旦 coding agent 的递归自我改进循环跑起来，后来者就追不上了。但历史上也有反例，比如 Google 在搜索领域后来居上。这个判断是否过于绝对？也许“无法追赶”指的是同一代技术路线，但新范式可能从别处出现。

## 对话稿

**小俊：** Token 的消耗是越多越好吗？
**Freda：** 肯定不是，而且是反过来的。比如 Cursor 同一个问题消耗更多 token，但效果并不更好。最终大家要的是效果和效率。

**小俊：** 模型公司现在到了无法追赶的地步了吗？
**Freda：** 我觉得已经非常非常快了。就像马车换汽车，最早汽车经常抛锚，快马还能跟一跟；一旦汽车稳定跑起来，没有引擎的马再快也追不上。

**小俊：** 投资人是在抛弃软件公司吗？
**Freda：** 对，简单说是。二级市场软件已经被卖了 50% 以上，但一级市场还有很多公司停留在 AI 之前的估值逻辑，存在一二级估值倒挂。

**小俊：** AI 现在在曲线的哪个位置？
**Freda：** 在“把电机塞进蒸汽机”的位置。每个人都把 AI 加进工作流，但很少有人问流程本身为什么长成现在这样，为什么需要这么多层级。

**小俊：** 重新设计后的组织架构可能长什么样？
**Freda：** 过去是接力赛，一棒接一棒；未来更像篮球赛，3 到 5 个人一个小分队，必要技能都在队里，同步推进，自己拍板，只有重大方向才向上汇报。

**小俊：** AI 对投资行业会带来什么变化？
**Freda：** 投资行业非常低效。如果给 Agent 足够干净的数据和清晰的交易目标，它理论上百分之百会比人做得好。难点在于数据非常细碎，以及需要理解不同市场玩家的决策。

**小俊：** 2026 年了，你还投应用创业公司吗？
**Freda：** 投还是投的。但模型公司四处开战，我重新开始担心模型公司的竞争。Anthropic 说先吃编程，第二大业务吃金融；OpenAI 马上推出音频模型，对 ElevenLabs 会有影响。

**小俊：** 硅谷现在最火的是什么？
**Freda：** 这几个月肯定是 Neo Labs，从 AI lab 出来的研究员自己开的新 lab，可能有 100 家。另一个重要方向是给 Agent 做基础设施的创业公司。

**小俊：** 你焦虑吗？
**Freda：** 实话说就是很焦虑。几个月前我深夜装不上 OpenCloud，痛哭出来。你连一个东西装不上，就会想：我连这个都跟不上，是不是要被时代淘汰了？

**小俊：** 你觉得人和人之间还剩下什么？
**Freda：** 剩下的就是情感的连接。以信息交换为目的的对话，意义正在被快速掏空。现在见人反而更单纯了，去观察别人，聊心路历程，聊真诚的东西。

**小俊：** 你对创业的人有什么建议？
**Freda：** 不要听我上面任何分析。不能去想一个终局的概念，要脑子一热，好好准备，想做就做。
