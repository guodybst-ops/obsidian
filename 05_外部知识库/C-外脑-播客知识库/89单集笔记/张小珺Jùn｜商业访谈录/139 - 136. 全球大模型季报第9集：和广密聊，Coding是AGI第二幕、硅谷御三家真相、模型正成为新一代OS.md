## 一句话核心

Coding 是 AGI 的第二幕，它把 AI 从聊天机器人推向了能完成高价值任务的 Agent 模式，领先的 Coding 模型就像领先的 GPU，正在加速 AGI 实现，同时社会正进入白领通缩与失业的窗口期。

## 摘要

本集季报聚焦 2026 年 Q1 的 AI 进展。广密指出，过去一个季度模型智能水平的进步幅度超过了 2025 年全年，关键转折是 Anthropic 的 Opus 4.5 到 4.6 的跨代际提升。Coding 成为主线任务，硅谷一线研究员已基本不写代码，AI 能显著加速 AI 研究。广密深入分析了硅谷御三家（Anthropic、OpenAI、Google）的战略、组织与文化差异，认为 Anthropic 的胜利是战略与执行的胜利，OpenAI 因过度专注 ToC 而误判 Coding，Google 是“最领先的追随者”。模型正成为新一代操作系统，未来最领先的模型公司可能成为全球 GDP 的基础设施。同时，社会层面面临白领通缩、失业加剧的挑战，建议积极拥抱 AI。

## 故事与场景

- 广密提到，硅谷一线 AI 研究员去年七八成代码是人写，今年小于 1%，日常变成“AI 写、人审”，且人审的能力都不够了。
- Anthropic 在过去 50 多个工作日发布了 70 多款产品和功能，这在互联网时代根本做不到。
- 广密自己从 ChatGPT 用户变成了 Claude Code 的众多用户，每月消耗约 100 美金 token，但还没用满；身边朋友每天消耗几百美金，一周几千美金。
- 广密说，OpenAI 的 Sam Altman 最近两次被袭击，未来这类事件可能越来越多。
- 广密认为 Cursor 本质是吃模型公司技术溢出的红利，如果模型公司不开放最强 API，Cursor 可能卖给微软或马斯克。
- 广密提到，美国本科毕业生就业率创历史新低，AI 已经自动化了工作两三年、三四年的初级岗位。

## 核心概念

- **Coding Agent**：AI 从聊天机器人（第一幕）进入能直接完成高价值任务的 Agent 模式（第二幕）。例子：Claude Code 和 Codex 在多个任务上达到 Meta L8/L9 水平，两三次迭代就能跑通一个 feature。
- **语言即世界，代码即方案**：自然语言描述世界，代码描述解决方案，两者高度抽象且覆盖范围极广。广密认为，如果这个假设成立，做好 Coding 就能自动化白领知识工作者的大部分任务。
- **塔尖用户**：高价值任务的核心用户，贡献大量 token usage。例子：Anthropic 一两百万用户贡献的收入超过 OpenAI 五六千万订阅用户，塔尖用户的 token usage 可能比 DAU 更有意义。
- **战略组织文化**：做好 Coding 的关键不仅是技术 knowhow，更是战略聚焦、组织和文化。例子：Anthropic 放弃多模态和 ToC，创始人亲自带团队搞数据；OpenAI 自下而上文化导致不聚焦，什么都想要。
- **模型即操作系统**：未来最领先的模型成为全球基础设施，支持应用无限扩展，类似 Windows、iOS、安卓、微信。例子：生活问题、工作自动化、科研支持都依赖同一个模型。
- **白领通缩与失业**：AI 自动化知识工作，导致中产岗位消失，人类知识和智力变得廉价。例子：美国本科就业率历史新低，印度 IT 外包被替代，今年可能 30% 的工作岗位消失。
- **Harness Engineering**：把 AI Agent 当一等公民，提供工作环境和管理，类似人类加入公司需要组织约束。例子：有了 harness，普通模型也能做高价值任务，开源模型也能被用上。
- **一人公司（One-Person Company）**：个体借助 AI 平台实现从想法到收入的高效闭环。例子：广密认为模型平台足够强大，每个人可以做很多事情，消耗 100 美金 token 能否赚到 110 美金是 ROI 指标。

## 我的批注

> [!NOTE] 核心洞察
> 广密强调 Coding 是 AGI 加速器，其重要性仅次于 GPU。这提示我们关注模型公司对 Coding 的投入程度，可能成为未来竞争分水岭。Anthropic 的胜利是战略聚焦的胜利，而 OpenAI 因 ToC 成功反而误判了 Coding 的优先级。

> [!NOTE] 社会影响警示
> 节目指出白领通缩窗口已至，美国本科就业率新低，今年可能 30% 的工作岗位消失。这提醒我们技术变革的阵痛可能比预期更剧烈，需要提前规划职业转型，积极拥抱 AI 工具。

> [!QUESTION] 模型公司终局
> 如果模型成为新一代操作系统，那么未来是否会出现类似安卓/iOS 的生态垄断？中小模型公司还有生存空间吗？广密认为再出现新的模型公司难度极大，但技术变化快，格局可能还会交替。

## 对话稿

- **张小珺**：过去一季度哪些事情最值得划重点？
- **广密**：最本质的关键转折点是 Anthropic 的 Opus 4.5 到 4.6 的跨越，从 GPT-3 到 GPT-4 水平的跨代际提升，让我们从 chat 问问题变成了真正的 agent 模式。

- **张小珺**：Coding 的难点在哪里？
- **广密**：最重要的是组织和文化，其次是数据。很多 AI lab 最聪明的人不愿做脏活苦活，都想做 0 到 1 的突破。Anthropic 的创始人亲自带团队搞数据，重视数据刻在骨子里。

- **张小珺**：OpenAI 做的不好的地方？
- **广密**：不聚焦，什么都想要；文化上重视 0 到 1 突破，不重视 1 到 100；预训练和 Coding 没做好。Sam 是 VC 出身，容易摊大饼，团队要卡就给，导致资源分散。

- **张小珺**：Google 的 Gemini 被高估了吗？
- **广密**：Gemini 3 被高估，Coding 严重落后，战略误判。Google 忙着跟 ChatGPT 争 ToC，忽视了 Coding，现在才意识到重要性，但已经晚了三四个月。

- **张小珺**：模型公司竞争终局？
- **广密**：模型就是新一代操作系统，未来最领先的三五家模型公司可能每家 10 万亿美金。投资上要投能持续做好 sota model 的公司。

- **张小珺**：对社会的影响？
- **广密**：白领通缩，今年 30% 的工作岗位可能消失，人类知识和智力变得廉价。美国本科就业率历史新低，印度 IT 外包被替代。

- **张小珺**：给听众的建议？
- **广密**：AI 取代的是不拥抱 AI 的人，积极拥抱 AI 可能是受益者。未来创造力、审美和 taste 可能更重要。

- **张小珺**：你自己生活有什么变化？
- **广密**：很担心跟不上 AI 的进步，学习压力大。我从 ChatGPT 变成了 Claude Code 的众多用户，生产力提升很多，但还没像塔尖开发者那样消耗大量 token。
