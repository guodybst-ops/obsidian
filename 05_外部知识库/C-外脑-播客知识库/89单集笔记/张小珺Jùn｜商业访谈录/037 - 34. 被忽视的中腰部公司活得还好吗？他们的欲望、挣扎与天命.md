# 037 - 被忽视的中腰部公司活得还好吗？他们的欲望、挣扎与天命

> 结构化说明：本笔记基于机器转写与清洗稿整理，属于 L4 萃取成品；原始音频、原始转写、清洗稿应继续作为原料保留。

## 一句话核心

中腰部公司的命运很大程度上由“赛道”决定——它们大多生于二级赛道，创始人虽有改天换命的野心，但受限于先天站位、资源禀赋和时代土壤，多数难以摆脱“二级赛道诅咒”。

## 摘要

吴杉杉先后在唯品会、好未来担任首席战略官，他从中腰部公司的内部视角出发，揭示了这类企业的真实生存状态。中腰部公司通常指在某个二级赛道（千亿级）中排名前三至前五的企业，它们曾有一段黄金生长期，但很快会遭遇增速瓶颈。创始人普遍怀有巨大野心，不愿安于现状，拼命折腾试图跳出赛道局限，但“时也命也”，多数多元化尝试以失败告终。唯品会因专注特卖赛道、创始人低调务实而活得滋润；好未来因不可抗力而陨落，但其反思文化和军团化作战方式极为强大。吴杉杉认为，中腰部公司仍是职场人的好选择，因为其成长空间和演化动力优于已内卷的头部企业。

## 故事与场景

1. **麦肯锡招聘场景**：上个世纪末，麦肯锡在波士顿区域召集100个博士集体考试，做三个半小时的商业逻辑与数学题，淘汰率极高，最终录取者需经过五六轮面试。
2. **唯品会创始人办公室**：两位温州老板沈亚和洪晓波并排坐在一张3米长的圆木桌两侧，中间隔着一摞高高的书，用温州话吵架，吴杉杉听不懂。
3. **拼多多崛起监测**：唯品会通过跟踪APP月活跃用户增速前100的企业，在拼多多上线仅几个月时就监测到其高速崛起，曾讨论收购但未成功。
4. **好未来告别会**：双减政策后，好未来组织全员在线告别会，老师们感慨“一鲸落而万物生”，公司将所有老师转移到新成立的NGO组织，延续工资直到老师主动离职。
5. **新东方与好未来风格对比**：新东方将售卖桌椅变成一次marketing动作，广为流传；好未来默默处理，不对任何地方宣传，风格截然不同。
6. **创始人反思文化**：好未来创始人张邦鑫沉默寡言，但一直在思考，整个公司形成日报、周报、月报层层反思的机制，每个人在每件事上以金字塔方式集体迭代优化。

## 核心概念

- **中腰部公司**：指在中国除排名前三或前五之外的公司，体量规模品牌能达到疫情前约100亿美元市值，通常在一个二级赛道（千亿级）中处于翘楚位置。例如唯品会（特卖电商第三极）、好未来（学科培训头部）。
- **二级赛道**：相对于一级赛道（万亿级）而言，是大赛道里开辟的一个细分领域。例如电商是一级赛道，特卖电商是二级赛道；燃油车是一级赛道，智能汽车目前仍是二级赛道。二级赛道不一定小，但天花板有限。
- **二级赛道诅咒**：中腰部公司因生于二级赛道，其资源禀赋、文化、创始人特质帮助它成为王者，但这些成功打法形成惯性，阻碍它跳出赛道。多数多元化尝试失败，因为二级赛道之间的可复制性和可转移性不强。
- **特卖电商护城河**：唯品会的护城河不是简单打折，而是基于大数据对女性消费者的深刻洞察：培养每日定时浏览习惯（早8点、晚8点）、第三次下单后成为终身客户、消费者在三个APP内切换比价后建立心智信任。
- **反思文化**：好未来由创始人确立的强文化，无论做好做坏都要总结，通过日报、周报、月报层层对比反向，从每个人的工作成绩中积累点滴智慧，形成组织性迭代和演化。
- **去明星化**：好未来明确提出的策略，不培养明星讲师，而是打造体系化、军团化的作战方式，把每个可塑之才迅速变成攻坚中坚力量，与新东方培养脱口秀明星的风格截然不同。
- **资源禀赋**：中腰部公司创始人的特殊资源，包括个性资源（偏执、不近人情、第六感）、行业资源（原有赛道的经验与积累）、以及极强的学习和反思能力。
- **不可抗力**：指超出企业控制的外部因素，如双减政策。吴杉杉比喻为“温度提高0.5度，大部分海洋生物都死掉”，看似微小但影响无比巨大。

## 我的批注

> [!NOTE] 赛道决定论 vs 创始人能动性
> 吴杉杉反复强调“出生决定命运”“先天决定”，但同时也承认有企业通过长达几十年的演变实现脱胎换骨。这提示我们：赛道是天花板，但天花板不是固定的；创始人的偏执、反思和迭代能力，可能是在边界条件内不断抬升天花板的关键变量。

> [!NOTE] “抠”的另一种解读
> 嘉宾提到中腰部公司老板普遍“抠”，但解释为“成就感来自于更大的事业，不是来自于大量花销”。这颠覆了外界对富豪生活的想象。对员工和高管，他们并不抠，因为激励人才是实现野心的最有效方式。这种“抠”本质上是资源分配的高度理性化。

> [!QUESTION] 中腰部公司对职场人真的是好选择吗？
> 嘉宾认为中腰部公司有成长空间和演化动力，优于已内卷的头部企业。但他在前面也承认，现在成立中腰部公司的机会越来越少，大多数企业只是“活下去”。那么对于职场人，如何识别一家有真正成长潜力的中腰部公司，而不是陷入“伪增长”的陷阱？

## 可行动清单

- [ ] 识别你所在公司或目标公司所处的赛道：是一级赛道（万亿级）还是二级赛道（千亿级）？赛道天花板在哪里？
- [ ] 观察公司创始人的“野心信号”：是否持有大量股票不套现？是否持续折腾、尝试多元化？
- [ ] 研究公司的反思文化：是否有日报、周报、月报等机制？是否从失败中系统性地提炼经验？
- [ ] 分析公司的“资源禀赋”：创始团队有哪些独特资源（个性、行业经验、学习能力）？这些资源是否与赛道匹配？
- [ ] 评估公司的多元化策略：是相关多元化（有连续性）还是不相关多元化（纯粹避险）？试错成本高吗？
- [ ] 对比新东方与好未来的文化差异：思考哪种文化更适合自己的职业发展——明星化还是军团化？
- [ ] 练习“沉默思考”：像张邦鑫一样，在讨论中先听半小时，再沉淀酝酿，形成成熟成体系的观点。
- [ ] 建立个人反思机制：每天/每周记录一个工作决策的得失，形成可迭代的“个人智慧库”。
- [ ] 关注经济周期与行业稳定性：在经济下行期，接近消费行业的公司（如唯品会）稳定性更好。
- [ ] 面试时追问“赛道故事”：了解公司如何看待自己的赛道位置、增长瓶颈和突围策略。

## 对话稿

**张小珺**：总体而言，如何界定中腰部公司？

**吴杉杉**：在中国除了排得上前三或者最多前五的公司，全部算中腰部。它在一个二级赛道里是翘楚，第一名吃肉，第二名喝汤，第三名可能什么都没有。

**张小珺**：唯品会两个温州老板是怎么合作的？

**吴杉杉**：他们用温州话吵架，我听不懂。两人并排坐，中间隔着一摞书，完完全全是极端平等的合伙人。

**张小珺**：拼多多刚上线几个月你们就监测到了？

**吴杉杉**：对，我们跟踪所有APP月活跃增速前100的企业，拼多多以极高速度冲出来。当时讨论过收购，但它不卖。

**张小珺**：中腰部公司如何摆脱二级赛道诅咒？

**吴杉杉**：大多数企业的反应是多元化。但不幸的是，数据上看大多数都没有成功。很多时候出生就决定了命运。

**张小珺**：为什么聚美优品没了，唯品会却还活着？

**吴杉杉**：唯品会专注做特卖，创始人基因适合做这件事。他试过多元化，但浅尝辄止，快速退回来，专注于自己擅长和喜欢的事情。

**张小珺**：好未来的张邦鑫是个什么样的人？

**吴杉杉**：他大多数时候很沉默，即使跟高管在一起。但他一直在思考，等他把想法说出来时，已经非常成熟成体系，多维度都考量过了。

**张小珺**：新东方和好未来面对双减的处理有什么不同？

**吴杉杉**：新东方把售卖桌椅变成一次marketing动作；好未来默默把所有老师转移到新成立的NGO组织，延续工资直到主动离职。风格截然不同。

**张小珺**：中腰部公司CEO的最大共性是什么？

**吴杉杉**：都不想做一家中腰部企业。他们对头部CEO怀抱着巨大的仰望，然而“时也命也”。

**张小珺**：这些老板抠吗？

**吴杉杉**：都挺抠的。他们身上穿几十上百人民币的衣服，身价是亿倍。但他们对人才不抠，因为激励人才是实现野心的最有效方式。

**张小珺**：中腰部公司是职场人的好选择吗？

**吴杉杉**：绝对是好选择。最佳方式是加入一个不断演化和成长的组织，它会必然给你制造成长的土壤。
