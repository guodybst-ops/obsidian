## 一句话核心

AI 发展像攀登一座无限的山，K2 模型是重要里程碑——它让模型从封闭的“缸中之脑”长出“手”，开始操控外部数字世界，而未来关键在于提升 Agent 的泛化性，并用 AI 训练 AI 来突破数据墙。

## 摘要

杨植麟时隔一年再次对话，分享 K2 模型（基于 MoE 的开源编程和 Agentic 大模型）的研发思路：通过 Muon 优化器、数据改写等手段提升 token efficiency，并通过强化学习训练 Agent 的泛化能力。他认为 AI 发展是“无限的山”，问题不可避免但可解决。讨论 Agentic LLM、test-time scaling、数据墙、开源策略、商业模式等话题。也谈及创业心态——用 RL 方式管理团队、恐惧与成长，以及“在自己的故事里面”不断感受自己。

## 故事与场景

- 杨植麟提到最近在看《The Beginning of Infinity》，书中说有两句话要刻在石头上：“问题不可避免”和“问题可以解决”，并以此比喻 AI 研发过程——每次解决问题都会产生新问题。
- K2 训练中遇到 Muon 优化器导致 max logic 爆炸的问题，在小规模实验无法复现，只有在大规模训练时才暴露，团队需要临时修复。
- 杨植麟说团队管理上，Tim（周昕宇）天天跟他讲要用 RL 方式管理而不是 SFT，他正在实践平衡 SFT 和 RL，避免团队失去主观能动性或被 hack。
- 杨植麟提到曾问过 Kimi（模型）：“AI 是什么？”Kimi 回答：“AI 是人类文明的放大器。”他也问过关于风险的问题，Kimi 说不能因噎废食，放弃就等于放弃人类文明的上限。
- 投资人对杨植麟的印象：第一次见面时杨植麟不讲 GPT-4、GPT-5，而是讲 GPT-10 可能长什么样。

## 核心概念

- **缸中之脑**：模型不与外界交互，只在内部思考推理（如纯推理模型）。K2 让模型走出缸中之脑，开始操控外部数字世界。
- **Agentic LLM**：模型能多轮使用工具（搜索、代码、浏览器等），与外部世界交互，核心特征是“多轮”和“工具”。
- **Test-time scaling**：在推理时通过增加 token 数量（思考 token 或交互轮次）来提升能力，包括基于强思考的 RL 和基于多轮 Agent 的 RL。
- **Token efficiency**：用同样多的数据获得更多智能。K2 通过 Muon 优化器、数据改写等方式提升 token efficiency，使一份数据等价于两份。
- **数据墙**：高质量数据增长缓慢，Scaling Law 遇到瓶颈。突破方向是提升 token efficiency 和 scale 更多 compute 到 RL。
- **泛化性**：Agent 模型面临的最大挑战——避免过拟合到特定任务或工具，需要让模型在未见过的工具和环境中也能表现良好。
- **用 AI 训练 AI**：让模型参与到训练过程（如 alignment research、数据生成），提升泛化性，类似 L4 创新者阶段。
- **模型级产品**：模型训练完成即产品基本完成，交互是锦上添花。产品形态随模型能力变化而演进。

## 我的批注

> [!NOTE] 技术信仰与市场博弈的平衡
> 杨植麟在开源策略上明确说“客观的说是都有”——既有技术体系的信仰（加速社区进步），也有市场博弈的考量（吸引人才、形成生态）。这种坦诚值得借鉴：技术决策往往不是纯理想主义，而是多重因素的综合权衡。

> [!NOTE] 用 RL 管理团队的隐喻
> 杨植麟将团队管理类比为模型训练：SFT 是直接指令（容易扼杀主动性），RL 是设定奖励（容易导致 hack）。他正在实践中寻找平衡。这个隐喻对技术管理者很有启发——过度控制 vs 过度放任，需要动态调整。

> [!QUESTION] 泛化性瓶颈何时能突破？
> 杨植麟反复强调 Agent 泛化性是当前最大挑战，并认为“用 AI 训练 AI”是潜在解法。但具体如何实现？需要什么样的基础设施和评估方法？这个问题值得持续跟踪。

## 对话稿

**张小珺**：你最新的感受是什么样的？

**杨植麟**：就像爬雪山，又走了一段距离，解锁了新场景，但仍有未知问题。可能这座雪山没有尽头，我希望它一直没有尽头。

**张小珺**：过去一年全球大模型最重要的范式变化是什么？

**杨植麟**：一是基于强思考的推理模型（如 o1），通过反思和猜想验证提升能力；二是基于多轮 Agent 的强化学习，让模型与外界交互。两者都是 test-time scaling 的不同维度。

**张小珺**：K2 的重点是什么？

**杨植麟**：一是好的基础模型，提升 token efficiency——用 Muon 优化器、数据改写等方式，让一份数据等价于两份；二是好的 Agentic 能力，强调泛化性，避免过拟合到特定任务。

**张小珺**：为什么从闭源转向开源？

**杨植麟**：开源可以让社区贡献推理侧优化，但模型本身的提升仍需原厂。开源也有市场博弈因素，希望形成生态加速技术推进。我们会持续开源，但不是所有东西都开。

**张小珺**：你怎么定义 Agent？

**杨植麟**：从缸中之脑变成可以跟世界交互，核心是多轮使用工具。关键是泛化性——能在未见过的工具和环境中表现良好，而不是只拟合几个 benchmark。

**张小珺**：用 RL 管理团队是什么意思？

**杨植麟**：用奖励（RL）而不是直接指令（SFT）来管理，避免失去主观能动性。但也要防止被 hack——大家只刷指标而实际没进步。需要平衡 SFT 和 RL。

**张小珺**：你恐惧吗？

**杨植麟**：肯定有恐惧，但更多关注当前能做什么。问题是不可避免的，但问题是可以解决的。做时间的朋友。

**张小珺**：AI 会摧毁人类文明吗？

**杨植麟**：风险不能说不存在，但放弃就等于放弃人类文明的上限。人的体验、情感无法被替代，需要好的社会机制来过渡。
