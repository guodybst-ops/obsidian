# 059 - 拼多多、名创优品崛起，是消费降级胜利吗？漫谈名创全球化之路

> 结构化说明：本笔记基于机器转写与清洗稿整理，属于 L4 萃取成品；原始音频、原始转写、清洗稿应继续作为原料保留。

## 一句话核心

消费并非简单的降级，而是分级；名创优品的崛起是极致供应链、品牌力与运营能力综合溢出的结果，而非单纯低价胜利。

## 摘要

本期节目邀请财经作家沈帅波，基于其正在撰写的名创优品专著，深入探讨了名创优品从国内小店到全球连锁的成长路径。沈帅波分享了其独特的调研方法论（从县城切入、跟班学习、临摹文章），并分析了名创优品成功的核心：零售业没有虹吸效应，靠的是吃苦耐劳和极致运营。节目还讨论了消费分级趋势、中国企业出海的三个阶段（贸易型、制造型、品牌运营型），以及创始人叶国富的极致思考特质。最后，沈帅波对完美日记等新消费品牌的兴衰给出了判断，并指出消费理性化、分层分级化是未来趋势。

## 故事与场景

1. **沈帅波的实业创业经历**：开奶茶店和馄饨店，遭遇服务员春节前离职、仓库货物被均匀偷窃、垃圾站管理员年赚500万等现实冲击，认识到商学院理论在实业中无效。
2. **名创加盟商分钱场景**：沈帅波采访拥有500家店的加盟商时，对方手机突然狂响，满面笑容地说“现在正在分钱”，随后收到500条短信，是分昨天的营业款。
3. **叶国富的极致思考**：叶国富曾送给商品负责人一个玩偶，对方解读为“老板希望我赶紧去研究这个玩偶为什么这么火”；叶国富在云南调研时，白天看三四家店后只吃路边摊，立刻要求再去看两个店。
4. **菲律宾的消费观察**：名创在菲律宾被视为中高端品牌，当地人圣诞节送礼送名创的迪士尼联名杯子；菲律宾没有轻工业，名创的产品在当地无法被本地企业低成本复制。
5. **印尼粉丝的故事**：一位印尼的墩墩基IP爱好者，买了所有新款墩墩基，还写信给名创说“我要结婚了”，名创为其定制了一个长得像他的墩墩基。
6. **时代广场的店型**：名创在纽约时代广场的大店，卖得最多的是各类迪士尼、漫威、三丽鸥的联名产品，主要面向全球游客。

## 核心概念

- **消费分级**：不是简单的升级或降级，而是每个人在不同品类上做出不同的价值选择。例如，有人可能花600元买lululemon瑜伽垫（升级），但觉得60元一杯的精品咖啡是智商税，转而喝瑞幸（降级）。
- **零售业竞争壁垒**：即“retail is detail”，是复杂的一切细节的总和，包括运营、渠道、营销、陈列等综合能力，而非单一产品创新。
- **类直营加盟模式**：名创的托管模式，加盟商只负责找店铺和付钱，运营管理由名创团队负责，每日分账，加盟商只需等待短信通知分钱。
- **店型即产品**：零售连锁公司最重要的产品不是里面的一个个商品，而是那个能够大规模复制的店型，即“消费的最大公约数”。
- **飞轮效应**：足够多的门店带来采购规模，规模带来极致成本，极致成本又支撑更多门店扩张，形成正向循环。
- **品牌 vs 营销**：品牌是群体的偏见和心智，需要长期沉淀；营销是流量和广而告之的动作。完美日记的衰落在于只做了营销，没有做成品牌。
- **中国企业出海三阶段**：第一阶段是贸易型出海（廉价商品），第二阶段是制造型出海（手机、家电等3C数码），第三阶段是品牌与运营能力出海（如名创优品）。
- **低成本战略 vs 低价战略**：低成本战略是通过极致供应链和规模实现成本优势，卖10块还有利润；低价战略是卖一个亏一个，无法持续。

## 我的批注

> [!NOTE] 零售业的“吃苦耐劳”是隐性壁垒
> 沈帅波反复强调零售业没有虹吸效应，靠的是普通人的吃苦耐劳。这种“铁军”式的执行力（如通宵排货、早操跑步）是难以被资本快速复制的，构成了名创优品早期扩张的隐性护城河。

> [!NOTE] “消费分级”比“消费降级”更准确
> 节目用“消费分级”替代了流行的“消费降级”叙事，并给出了具体案例（如星巴克在中国仍在增长，但瑞幸也在增长）。这提醒我们，宏观叙事容易掩盖微观层面的结构性变化，做商业判断时应更关注具体品类和人群的分化。

> [!QUESTION] 中国能否诞生自己的奢侈品品牌？
> 沈帅波认为中国奢侈品可能不会出现在箱包化妆品领域，而会在瓷器等中国专属领域出现。但这是否意味着中国品牌在高端化上只能走“文化专属”路线，而无法在全球化品类（如服装、皮具）中建立奢侈品牌？这需要更长时间的观察。

## 可行动清单

- [ ] 调研一个行业时，先找到该行业第一的企业建立信任，再以此为基础拓展到第二、第三梯队。
- [ ] 实地调研工厂时，第一件事是看装卸区：来多少料、走多少货，这是最真实的生意指标。
- [ ] 评估一个地区的酒店饱和度时，用“旅行社电话抽样法”询问不同酒店的满房率。
- [ ] 研究一个品牌的经销商体系时，优先找其竞品的经销商交流，而非品牌安排的经销商。
- [ ] 做零售生意时，将“店型”视为核心产品，先跑通一个可大规模复制的店型模型。
- [ ] 在制定价格策略时，追求“极致低成本”而非“极致低价”，确保卖10块还有利润。
- [ ] 做品牌出海时，先研究目标国家的工业基础：若当地缺乏轻工业，则中国品牌有供应链优势。
- [ ] 在热带国家或南半球市场，增加IP联名娃娃和彩色商品的供应，迎合当地消费偏好。
- [ ] 做消费品时，区分“品牌”与“营销”：品牌是长期心智，营销是短期流量，不要用营销替代品牌建设。

## 对话稿

**张小珺**：能不能先聊聊你那篇爆文《藏在县城的万亿生意》的创作过程？

**沈帅波**：这篇文章不是我想了一个选题然后写成的，而是基于前几年工作和创业的状态得出的思考。2018年国庆节，我跟合伙人回他老家江苏淮安的金湖县，以这个县为蓝本，讲了当时我们理解的消费。

**张小珺**：你开奶茶店那三年，目标是什么？

**沈帅波**：当时的目标就是赚到钱，证明你自己。过去的经验没有用，你得重新学，它让你回到原点上去创业。

**张小珺**：你是怎么深入开始研究名创优品的？

**沈帅波**：零售业没有虹吸效应，靠的是普通人的吃苦耐劳。名创的员工需要通宵排货，这是一群普通人的胜利。另外，有非常多人做过类似项目，但名创一年又一年做出了自己的护城河，找到了特许经营的路。

**张小珺**：创始人叶国富是个什么样的人？

**沈帅波**：他走路特别快，普通人跟不上。他去云南调研，白天看三四家店，晚上吃个路边摊，立刻要求再去看两个店。他疯狂热爱自己的事业。他送商品负责人一个玩偶，不是提供情绪价值，而是希望对方赶紧去研究这个玩偶为什么这么火。

**张小珺**：名创优品的发展过程可以分成哪几个阶段？

**沈帅波**：第一阶段是跑通店型，找到“消费的最大公约数”。第二阶段是通过极致管理和类直营加盟模式实现快速扩张。第三阶段是从渠道品牌升级为消费品品牌，包括做IP联名、升级视觉、请明星。第四阶段是全球化。

**张小珺**：名创在发达国家和发展中国家，出海策略是不是不一样？

**沈帅波**：不一样。美国是直营，因为市场巨大且分散；菲律宾是合作，因为当地商场控制在少数几个家族手上，必须与当地最大集团合作。小市场可能直接供货。

**张小珺**：拼多多市值超过阿里，是消费降级的胜利吗？

**沈帅波**：不能简单说消费降级。你花了600买lululemon是升级，但觉得60一杯的咖啡是智商税变成瑞幸，这是降级。每个人都在分级，不是有的人全升了，有的人全降了。

**张小珺**：你怎么看完美日记的衰落？

**沈帅波**：品牌跟营销是两件事。完美日记没有做成品牌，它没有找到能和欧美大牌竞争的路，也没有守住国内小弟的山头。它失去了根据地，又没有拿到新的根据地。

**张小珺**：中国未来20年可能做奢侈品吗？

**沈帅波**：欧美的奢侈品本质是皇室东西的平民化。中国要出现自己的奢侈品，还需要很长时间，它应该不会在箱包化妆品领域出现，可能会在中国人专属的领域出现，比如瓷器。
