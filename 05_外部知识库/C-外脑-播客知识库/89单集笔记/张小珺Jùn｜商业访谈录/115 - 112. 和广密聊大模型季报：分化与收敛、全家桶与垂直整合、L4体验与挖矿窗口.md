# 115 - 和广密聊大模型季报：分化与收敛、全家桶与垂直整合、L4体验与挖矿窗口

> 结构化说明：本笔记基于机器转写与清洗稿整理，属于 L4 萃取成品；原始音频、原始转写、清洗稿应继续作为原料保留。

## 一句话核心

模型公司开始分化赛道，产品体验成为竞争焦点，L4 级别的端到端体验（如 Deep Research 和 Claude Code）正在重塑格局，而创业窗口期已从两年急剧缩短至三个月。

## 摘要

本季报聚焦硅谷大模型公司的分化趋势：OpenAI 和 Google 坚持通用路线，Anthropic 全面押注 Coding+Agent，Mira 的 Thinking Machines Lab 专注多模态原生交互。产品重要性首次超越模型智能成为讨论重心，ChatGPT 凭借品牌壁垒在 C 端形成头部收敛，Claude Code 等 L4 体验产品快速崛起。创业窗口期从 Perplexity 的两年缩短至 Manus 的三个月，横向全家桶与纵向垂直整合成为巨头策略。广密还分享了“犹太人的金融，华人的 AGI”这一观察，并对 AI 投资策略提出集中而非分散的建议。

## 发言人

- **广密**：嘉宾，AI 投资人/创业者，长期关注全球大模型动态。

3. “ChatGPT 身上有很多非技术性的壁垒，而 Coding 或模型公司只有技术壁垒。”
4. “做 AI 产品很像挖矿，第一个做出来让用户惊叹的体验最重要，哪怕 token 消耗很大。”

6. “最优秀的两个 Agent 都有了 L4 体验：ChatGPT 的 Deep Research 和 Anthropic 的 Claude Code。”

## 核心概念

- **模型分化**：各模型公司选择不同赛道，不再追求通用能力。例子：Anthropic all in Coding+Agent，Thinking Machines 做多模态原生，Grok 还在摸索生态位。
- **横向全家桶**：一个产品包含多种功能，用户付费一次获得多个套件。例子：ChatGPT 已包含 Chat+搜索+Coding+Agent+Workspace，类似 Office 三件套。
- **纵向垂直整合**：从芯片到模型到应用全栈自研，形成超级集成。例子：Google 从 TPU 到 Gemini 到 Agent 再到 Chrome/安卓/YouTube。
- **L4 体验**：端到端让用户惊叹的体验，触发商业模式升级（从 20 美元到 200 美元订阅）。例子：Deep Research（信息搜索）和 Claude Code（软件开发）。
- **挖矿窗口**：第一个做出惊艳体验的产品能获得 5-10 亿美金的营销红利，但窗口期持续缩短。例子：Perplexity 窗口 2 年，Cursor 窗口 9 个月，Manus 窗口 3 个月。
- **非技术壁垒**：品牌心智、用户习惯、社会时间窗口积累的不可复制优势。例子：ChatGPT 像可口可乐，用户首选，即使模型能力趋同。
- **非共识**：与主流观点不同的判断，往往带来超额回报。例子：Coding 价值被低估，华人创业者未来 3-5 年会很牛，Thinking Machines 团队被低估。

## 我的批注

> [!NOTE] 广密对 ChatGPT 品牌壁垒的强调，与之前季报中更侧重模型智能形成鲜明对比，说明产品化阶段已到来。模型能力趋同后，品牌和分发成为决定性因素。

> [!NOTE] 窗口期缩短至 3 个月，意味着 AI 创业公司必须极快验证并抢占先机，否则会被模型公司自身产品碾压。Claude Code 从发布到反超 Cursor 仅用几个月，验证了这一趋势。

> [!QUESTION] 如果模型公司都开始做端到端产品，第三方应用公司是否只能选择被收购或做非常垂直的利基市场？广密提到“绝望”情绪，但依然相信会有新一代“黄峥”出现，那么破局点可能在哪里？

## 对话稿

- **张小珺**：模型和产品在你看来哪个更重要？过去两个月大家开始更注重产品的原因是什么？
- **广密**：过去两三个月确实是更重视产品了。第一个原因，ChatGPT 在流量上的成功或壁垒非常高。第二个，Anthropic 的 Claude 在 Coding 领先，但 Gemini 2.5 Pro 很快追上，说明模型红利需要转化成产品壁垒。

- **张小珺**：做 AI 产品很像挖矿，窗口期特别关键。你能具体讲讲窗口期的变化吗？
- **广密**：我让同事专门拉了一下，Perplexity 窗口两年，Cursor 窗口 9 个月，Manus 窗口 3 个月。窗口在缩短，但第一个做出来让用户惊叹的体验依然能获得 5-10 亿美金的营销费用。

- **张小珺**：你觉得 Cursor 有可能终局就是跟哪个大厂合并？
- **广密**：微软、Google、Meta 都有可能。Cursor 今天盼着 GPT-5 成本降低，Gemini 能力上来，但模型动态变化很快。如果模型公司自己下场，Cursor 的 token 成本劣势会非常致命。

- **张小珺**：你对 Google 看法的转变是什么？
- **广密**：ChatGPT 和 Google 最终产品形态会殊途同归，像小红书融合了搜索、短视频、朋友圈。ChatGPT 后面肯定会做广告平台，但 Google 是全球最好的广告平台，规模效应很强。

- **张小珺**：AGI 会有泡沫吗？什么事情可能是导火索？
- **广密**：观察最聪明的一波人在用什么。今年 AI Capex 可能 3000 亿美金，最怕套娃收入，前端不创造价值。如果泡沫破，第一批受冲击的是基座模型公司，资本会收敛到前几家。

- **张小珺**：华人团队在 AI 这一波的优劣势是什么？
- **广密**：未来肯定要全球竞争。中国本土供给充裕但内需不够强，北美付费需求强。劣势可以克服，核心是快速迭代学习，做好硅谷圈子。有一个总结非常好：犹太人的金融，华人的 AGI。

- **张小珺**：今天还有哪些非共识？
- **广密**：第一，格局看似已定，但还会有这个时代的黄峥。第二，很牛的团队价值被低估，比如 Anthropic 和 Thinking Machines。第三，Coding 的价值依然被低估，这一轮科技革命 Coding 会贡献很大。第四，机器人未来的突破可能不是今天做机器人的人，而是语言模型的人。
