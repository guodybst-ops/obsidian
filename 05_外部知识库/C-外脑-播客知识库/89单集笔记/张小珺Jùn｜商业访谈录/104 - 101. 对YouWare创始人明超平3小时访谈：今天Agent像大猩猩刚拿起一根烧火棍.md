# 104 - 对YouWare创始人明超平3小时访谈：今天Agent像大猩猩刚拿起一根烧火棍
> 结构化说明：本笔记基于机器转写与清洗稿整理，属于 L4 萃取成品；原始音频、原始转写、清洗稿应继续作为原料保留。

## 一句话核心
今天的Agent还处于非常早期的阶段，就像大猩猩刚拿起一根烧火棍，远未形成协同网络；创业的关键不是靠个人努力，而是找到并顺应时代最大的变量。

## 摘要
明超平（小明）从武大辩论和智能汽车竞赛的经历出发，分享了他从OnePlus、字节跳动到Moonshot的产品经理之路，以及创立YouWare的思考。他提出AI时代的关键指标是“token消耗速度”和“per token valuation”，认为“壳”作为容器和环境的价值被低估。他将今天的Coding发展类比为手机摄影的兴起，指出新人群“Vibe Coder”的出现是重要趋势。他认为Agent未来可能形成类似人类社会部落的网络效应，但当前仍处于孤独的野人阶段。作为90后创始人，他更自信、叛逆，但始终保持如履薄冰的心态，有意识地对抗Ego。

## 发言人
- **张小珺**：主持人，商业访谈录主理人。
- **明超平（小明/Leon）**：嘉宾，YouWare创始人，前OnePlus、字节跳动、Moonshot产品经理。

## 金句收藏
1. “辩论不是说服你的对手，你的对手不可能被你说服。你要说服的是在场下听你辩论的评委和那些观众——本质上那是你的用户。”
2. “数据是‘开车的后视镜’，它可以让你看到过去走过的路，但它没法指引你往前开。”
3. “永远相信Model会变好，永远相信Model和你无关。”
4. “今天的Agent有点像大猩猩刚开始拿起一根烧火棍，或者拿起石头来开始砸东西。”
5. “只给用户一个Chatbot输入框，是蛮不负责任的。”
6. “我们99.9%是要死掉的，我们的创业心态就是默认自己会挂掉，然后想办法让自己不要挂。”
7. “重要的不是最终的那个棋谱长什么样子，重要的是他下棋的那个顺序。”
8. “人脑就25瓦，但能处理得很好；GPU那么大功率，功耗很高。人的设计极其精妙且高效。”
9. “如果你连这个时代最大的变量——AI——都跟你无关，那你离一个大的公司或者伟大的公司已经很远了。”
10. “一秒钟把自己变傻子——你的观众没有准备过辩题，你的用户也不知道你的故事。”

## 故事与场景
1. **辩论的挫败与成长**：明超平在武大打了两年辩论，是输掉比赛最多的队员，也是拿最佳辩手最多的队员。他复盘发现，自己表现太抢眼反而抢走了队友表达的机会，导致团队输掉比赛。最愧疚的一次是学长的退役比赛，他因得意忘形在结辩时讲了太多东西，模糊了胜负点。
2. **智能汽车竞赛**：大三大四时，他睡在实验室里做智能汽车竞赛，团队四人，他负责软件。这段经历让他学会了“成长性思维”——任何困难都能通过学习克服，也让他对硬件不再恐惧。
3. **OnePlus导师带坐地铁**：导师带他去坐地铁、逛商场，告诉他“这才是你们的用户”。他观察到早高峰用户电量常是红色，发现续航数据和续航体验不等号：用户对95-100%和0-5%的电量最敏感。
4. **与杨植麟的10小时深谈**：从中午聊到晚上8点，聊音乐、艺术、爱好、产品，最后吃披萨时才让杨植麟讲技术。杨植麟用简单的方式讲明白了“压缩即智能”，让明超平觉得“他是唯一一个给我讲明白的”。
5. **Noisee的走红与骤停**：在Moonshot时，他观察到Suno用户创作音乐后缺乏分享载体，于是做了Noisee——把Suno链接丢进去就能生成音乐MV。产品在Discord里意外火爆，但后来因公司资源集中到Kimi而被关停。关停那天他没什么感觉，但后来域名打不开时“那一瞬间还是很伤感的”。
6. **失眠的顿悟**：创业后绕了半年弯路，给产品加了很多模板和脚手架。2025年春节后，因频繁向投资人输出，某天晚上失眠时突然意识到：AI时代的关键指标不是DAU，而是“token消耗速度”。他随即停掉了那个不AI native的产品。
7. **YouWare的诞生**：某天晚上10点刷Twitter，看到很多人用Claude写游戏但无法分享，于是从10点写到凌晨1-2点，做了一个能把代码变成可分享网站的产品。产品很糙，他都不好意思承认是自己的。

## 核心概念
1. **Token消耗速度**：AI时代的关键指标，代表产品消耗模型智能的程度。消耗越快，产品价值可能越大。但后来迭代为“per token valuation”——每个token产生的价值更重要。
2. **壳/容器/环境**：被低估的价值。产品不只是工具，更是一个影响用户行为的环境。就像去大排档和法式餐厅，环境会改变人的行为。只给用户一个输入框是不负责任的。
3. **Vibe Coder（氛围编程师）**：新出现的人群，指用自然语言编程的人，以前不会编程但现在可以。类比手机摄影师——以前只有专业摄影师，现在人人都是摄影师。
4. **Agent的网络效应**：未来Agent之间会互相调度、协作，形成类似人类社会的部落。这需要解决信任、身份、密码锁等问题，目前还远未实现。
5. **Agent rank**：未来的Page rank会变成Agent rank——用户选择哪个Agent取决于其排名和信誉，类似今天的搜索引擎。
6. **OS Agent**：明超平设想的未来操作系统是“活的”，界面由Agent实时生成，基于用户的任务场景动态变化。他认为离OS最近的领域是Coding。
7. **Per token valuation**：每个token产生的价值。好的Agent应该用更少的token完成更多有价值的事，而不是单纯追求消耗速度。
8. **压缩即智能**：杨植麟教给明超平的理念。能把复杂信息压缩成简单公式或一句话，就是智能的体现，就像爱因斯坦的E=mc²。

## 我的批注
> [!NOTE] 辩论思维与产品决策
> 明超平从辩论中学到的“永远具备第三方视角”和“一秒钟把自己变傻子”，与字节的数据驱动方法论形成了有趣的张力。他选择在直觉和数据打架时相信直觉，这或许解释了为什么YouWare的产品形态如此独特——它不是一个被数据验证出来的产品，而是一个基于对趋势判断的“信仰决策”。

> [!NOTE] “壳”的价值被重新定义
> 明超平对“壳”的阐释很有启发性。他不仅把产品界面看作容器，更看作影响用户行为的“环境”。这超越了传统的UI/UX讨论，指向了产品如何塑造用户认知和创作动机——就像Midjourney的Discord社区教会了用户如何写Prompt。

> [!QUESTION] Agent的网络效应何时到来？
> 明超平认为Agent之间需要先“碰到”，形成协同，才能产生网络效应。但当前Agent都是“孤独的野人”。那么，触发这个“碰到”时刻的关键变量是什么？是模型智能的进一步提升，还是某个杀手级应用的出现，抑或是基础设施（如协议、信任机制）的成熟？

## 对话稿
**张小珺**：你从辩论中学到最重要的东西是什么？
**明超平**：永远具备第三方视角。辩论不是说服你的对手，你的对手不可能被你说服。你要说服的是在场下听你辩论的评委和那些观众——本质上那是你的用户。你得关注你说出去的这句话，在第三方的视角里怎么理解。

**张小珺**：字节的方法论劣势是什么？
**明超平**：它会磨灭掉很多灵光一现的创意。数据是“开车的后视镜”，它可以让你看到过去走过的路，但它没法指引你往前开。很多颠覆式创新，比如iPhone、特斯拉，是无法被AB实验出来的。

**张小珺**：为什么绕了半年才回到YouWare这个产品？
**明超平**：还是传统的产品经理那种想雕花的本能。你接受不了阶段性模型交付的结果不够好，就想给它更多脚手架、更多设计。这些东西一加上去，AI含量就从80%变成20%，你跟这个时代最大的变量背道而驰了。

**张小珺**：你怎么看“壳”的价值？
**明超平**：壳被低估了，我更愿意叫它“容器”或“环境”。环境是人的反应器。去大排档吃烧烤和去高档法式餐厅，你的行为、说话方式甚至声音都会不一样。只给用户一个Chatbot输入框，是蛮不负责任的。

**张小珺**：今天的Agent发展到什么阶段了？
**明超平**：今天的Agent有点像大猩猩刚开始拿起一根烧火棍，或者拿起石头来开始砸东西。还远没到智人的水平，可能只是直立人的状态。Agent之间还没碰到，都是孤独的野人。

**张小珺**：你对团队说过“咱们99.9%是要死掉的”？
**明超平**：对，我们的创业心态就是默认自己会挂掉，然后想办法让自己不要挂。我会直接跟团队说，创业是不稳定的，我们大概率会失败。但我会把这件事好玩的地方也传递给他们——和不确定性一起共舞是挺好玩的。

**张小珺**：你做CEO不擅长的地方是什么？
**明超平**：不够aggressive，太nice了。比如有的项目体验有问题，我很暴躁，希望今晚加班到12点解决。但另一面会想：何必呢，大家都挺累的。大部分情况我会让员工先走。

**张小珺**：90后founder和上一代有什么不同？
**明超平**：更自信、更洒脱、更叛逆。我有一条原则：做重大决定一定要找到一个反对意见。如果所有人都出奇一致觉得好，那它大概没那么好。

**张小珺**：融资风生水起时，你会有ego吗？
**明超平**：一定会。你会觉得自己无所不能。但你得马上把自己一巴掌拍醒。投资人对我来说是镜子，让我看到真实的自己——一个犹豫的自己、一个不够坚决的自己。
