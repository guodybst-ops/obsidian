# 092 - 逐句讲解DeepSeek-R1、Kimi K1.5、OpenAI o1技术报告——“最优美的算法最干净”

> 结构化说明：本笔记基于机器转写与清洗稿整理，属于 L4 萃取成品；原始音频、原始转写、清洗稿应继续作为原料保留。

## 一句话核心

DeepSeek-R1-Zero 通过纯粹的强化学习（无监督微调）让模型自主涌现出长思维链、自我纠错等推理能力，证明了“最优美的算法最干净”——后训练范式革命刚刚开始，其 scaling law 增长曲线比预训练更陡峭、成本更低。

## 摘要

本集邀请加州大学伯克利博士生潘家怡逐句解读 DeepSeek-R1、Kimi K1.5 和 OpenAI o1 三篇技术报告。核心发现：强化学习（RL）是让大模型学会推理的关键范式，DeepSeek-R1-Zero 仅用 GRPO 算法和规则奖励，就让模型自发产生“顿悟时刻”——自我纠错、搜索等高级行为。Kimi K1.5 公开了更多工程细节（如思维链奖励模型、长度惩罚、课程学习），与 DeepSeek 异曲同工。报告还揭示了蒸馏的有效性：小模型通过蒸馏大模型推理能力可超越传统聊天机器人。后训练成本极低（约10万-100万美元），而预训练已遇瓶颈，RL 路线正成为 AGI 新引擎。

## 故事与场景

- **顿悟时刻（Aha Moment）**：在训练 DeepSeek-R1-Zero 的某个中间版本时，模型突然输出“等一下，这里有一个 aha 时刻，我可以看一看”，然后重新验算之前的步骤，发现错误并纠正。这一行为并非程序员写入，而是模型自己涌现的。
- **潘家怡的复现经历**：R1-Zero 发布当晚，他花几个小时就完成了小规模复现（24点游戏），发现即使是3B模型也能通过 RL 发展出自我纠错和搜索能力。
- **OpenAI 的数据标注**：小道消息称 OpenAI 一直以100-200美元/小时的价格找博士生标注数据，标注内容为“问题-解题思路-答案”三元组。
- **DeepSeek 的情商表现**：用户发现 DeepSeek 回复中经常使用表情，中文理解深刻，输出“浪漫”，可能与其后训练中标注要求有关（如要求标注员倾向于更浪漫的回复）。

## 核心概念

- **强化学习（RL）**：一种训练范式，不教模型具体怎么做，而是告诉它什么好、什么不好，让模型自己摸索出最优策略。在推理模型中，RL 让模型学会长思维链、自我纠错、分解复杂步骤。
- **GRPO（Group Relative Policy Optimization）**：DeepSeek 提出的强化学习算法，舍弃了传统 PPO 中的价值函数（因为长思维链下价值函数难以精确），只使用策略梯度，通过组内相对优劣来更新模型。算法极其简洁。
- **思维链（Chain-of-Thought）**：模型在输出最终答案前，先生成一段内部推理过程（慢思考），类似于人内心的逐步推理。这是实现推理时 scaling 的关键。
- **蒸馏（Distillation）**：用大模型（教师）生成的高质量推理数据来训练小模型（学生），使小模型获得推理能力。DeepSeek 发现蒸馏后继续做 RL 效果更好。
- **奖励模型（Reward Model）**：用于给模型输出打分的神经网络。在推理场景中，DeepSeek 使用基于规则的 ground truth 奖励（如答案是否正确、格式是否规范），避免奖励破解。Kimi K1.5 则探索了思维链奖励模型（让奖励模型也进行推理），精度从84%提升到98.5%。
- **冷启动数据（Cold Start Data）**：在 RL 之前，先用少量高质量的长思维链数据（人工编写或通过 prompt 生成）对模型进行监督微调，让模型一开始就具备基本的推理模式。DeepSeek-R1 使用了这一方法，而 R1-Zero 完全不用。
- **推理时 scaling（Test-time Scaling）**：在推理阶段投入更多算力（让模型生成更长的思维链），性能会近似线性提升。这是后训练范式革命的核心发现之一。

## 我的批注

> [!NOTE] 后训练成本极低，但数据标注成为新瓶颈
> DeepSeek-R1 的训练成本估算仅10万-100万美元，远低于预训练的600万美元。然而，RL 需要大量高质量的问题-答案对（尤其是难题），标注成本可能很高。OpenAI 以100-200美元/小时雇佣博士生标注，说明数据标注正在成为新的稀缺资源。

> [!NOTE] “顿悟时刻”是 RL 美学的集中体现
> 模型自发产生自我纠错行为，且研究人员事先并未设计该行为——这证明了 RL 可以解锁超出人类预设的智能。这种“涌现”是 RL 区别于监督学习的核心魅力，也是 DeepSeek 报告成为爆款的关键。

> [!QUESTION] 如果蒸馏后继续 RL 是更优路径，那么小模型能否通过“蒸馏+RL”最终超越教师模型？
> 潘家怡提到蒸馏后做 RL 能进一步提升性能，但未说明上限。理论上，小模型通过 RL 可能发展出教师模型没有的独特策略。这是否意味着“学生”可以超越“老师”？需要更多实验验证。

## 对话稿

**张小珺**：很多人说 DeepSeek 一举改写了全球 AGI 的宏观趋势，你认同吗？

**潘家怡**：我觉得有几点一定成立。一个是 DeepSeek 让美国大厂在反思自己的模型训练效率和创新能力。同时，从 R1-Zero 和 R1 来看，大家终于知道用强化学习可拓展地提高语言模型能力的秘密了。

**张小珺**：在业内人士看来，DeepSeek-R1 是对 OpenAI o1 的复刻吗？它究竟是追赶者还是创新者？

**潘家怡**：我觉得像是 OpenAI 出了个谜语，DeepSeek 是第一个找出答案的，而且答案非常漂亮。它已经在做出杰出的创新，比如 V3 的稀疏 MoE、注意力机制创新等。

**张小珺**：为什么 DeepSeek 的论文能成为爆款，而 Kimi K1.5 关注度低很多？

**潘家怡**：DeepSeek 有长期的开源文化和自来水粉丝。另外，K1.5 技术细节丰富但缺乏“顿悟时刻”这样的爆点，而 DeepSeek 隐藏了细节，把算法的精妙和美展现给你，更震撼。

**张小珺**：R1-Zero 和 R1 哪个更重要？

**潘家怡**：从技术干净性上讲，R1-Zero 更重要——它不需要冷启动数据，推理能力是自发涌现的。但从商业部署看，R1 更实用，性能更好、用户友好。

**张小珺**：模型能有意识吗？

**潘家怡**：这得看定义。有些人觉得它只是预测下一个词，就没有意识；有些人比如 Hinton 认为现在模型已经有意识了。但能开始探讨这个问题，说明模型能力真的有了卓绝突破。

**张小珺**：数据标注现在有多重要？

**潘家怡**：非常重要。OpenAI 一直以100-200美元/小时找博士生标数据。标注内容主要是“问题-解题思路-答案”三元组。未来可能需要更多专业领域的标注人员，可以理解为 AI 的教练。

**张小珺**：DeepSeek 的回复情商很高，经常发表情，这是怎么做到的？

**潘家怡**：可能跟后训练中价值对齐的标注要求有关。比如梁文峰可能在标注要求里加了一条“倾向于更浪漫的回复”，就导致了这种现象。

**张小珺**：你觉得 DeepSeek 会超越 OpenAI 吗？

**潘家怡**：OpenAI 的护城河很深：算力充沛（几十万张 H100），组织管理也出色。DeepSeek 资源少得多，但创新能力突出。要完全打垮 OpenAI 还有距离。
