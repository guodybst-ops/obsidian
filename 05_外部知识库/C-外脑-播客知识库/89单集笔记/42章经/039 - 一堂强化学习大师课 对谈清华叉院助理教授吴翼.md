# 039 - 一堂强化学习大师课 对谈清华叉院助理教授吴翼

## 摘要

本期《42章经》邀请清华大学交叉信息院助理教授吴翼系统讲解强化学习。对谈从“什么是 RL”开始，逐步串起传统机器学习、游戏决策、RLHF、O1 式慢思考、DeepSeek R1、agent、预训练与后训练、强化学习系统框架、人才培养以及人生决策等主题。吴翼的核心观点是：强化学习处理的是多步决策和结果反馈问题，它比传统监督学习更接近真实世界，但也更难求解。

节目解释了为什么强化学习在大模型时代重新成为核心能力：RLHF 主要解决指令遵从和可用性，O1/R1 类推理强化学习则开始提升模型“思考”和决策能力；再往后，Deep Research、Operator、代码 agent 等产品把强化学习从单轮做题推进到多轮交互与环境反馈。吴翼强调，今天最强的 agent 模型不是单靠 RL，也不是单靠预训练，而是预训练理解能力与强化学习决策能力的乘法结果。

在产业层面，嘉宾认为 RL 人才稀缺来自研究门槛高、工业机会少、工程要求极强。做好 RL 不只靠算法，更依赖数据、训练系统和高效基建。节目最后，吴翼把强化学习中的多样性探索、主动寻求信息和跳出局部最优，类比到人生选择，鼓励年轻人不要只走风险最低路径，而要在可承受范围内追求更高熵、更丰富的生活。

## 金句收藏

- “RLHF 让模型更好用，但 O1 式强化学习开始让模型更聪明。”

- “强化学习里，基建远大于所有；没有屠龙刀，算法想法很难真正 scale up。”
- “创业公司不能只想终局，如果终局已经到来，就没有你的机会。”
- “人生不是先想清目标再行动，而是在行动和交互中寻找 reward。”
- “跳出 local optimal，大不了再跳回来；人生怎么也能选三四次。”

## 核心要点

### 1. 强化学习与传统机器学习的区别

- 传统监督学习通常是输入一个样本，输出一个答案，例如判断图片是猫还是狗。
- 强化学习处理的是多步决策：智能体需要连续做动作，最后根据结果好坏获得反馈。
- 传统监督学习有标准答案；强化学习没有每一步的标准答案，只有最终 reward。
- 因此，强化学习更接近现实世界，比如出差、职业选择、合作沟通等都不是一步答案题。

### 2. RLHF 解决“好用”，推理 RL 追求“更聪明”

- 大模型预训练本质是 next token prediction，初始目标只是续写，不天然理解“指令遵从”。
- InstructGPT 和 ChatGPT 通过 RLHF 让模型按照人的指令输出，使模型从“会续写”变成“好用”。
- RLHF 的 reward 来自人类偏好：人对不同回答排序，再训练奖励模型。
- 但 RLHF 主要提升可用性和对齐，并不直接形成新的 scaling law，也不显著提升智力上限。
- O1/R1 类推理强化学习的突破，在于让模型通过 thinking tokens 和结果验证，获得更强推理能力。

### 3. 慢思考的核心：让模型多写，再用结果反馈训练

- O1 式方法让模型在给出答案前先输出大量思考 token，这被称为 inference-time scaling。
- 为什么“多写”能让模型想得更好，目前还没有完全清晰的理论解释，但实证有效。
- 训练这类模型时，中间思考过程很难由人评判，因此通常选择数学、代码等有标准答案的问题。
- 模型可以自由探索思考路径，只要最终答案正确即可获得奖励。
- 难点在于控制成本、长度、效率和思考质量，避免简单问题也过度思考。

### 4. DeepSeek 的意义：证明路径可做

- OpenAI 花了很长时间证明 slow thinking 和强化学习推理可行。
- DeepSeek 的重要贡献是让行业看到这条路径可以被较快复现和工程化。
- 它不一定做了别人完全做不到的事，但它足够专注、足够早、足够扎实。
- 做好这件事需要好的基座模型、稳定高效的训练系统、长输出支持和大量并行探索能力。

### 5. Agent 是“对文本之外世界产生影响”的模型

- 吴翼认为，一个通行的 agent 定义是：模型不只是输出文字，还能对软件、网页、硬件或虚拟环境产生影响。
- 早期 AutoGPT、LangChain 等也是 agent，但主要依赖 prompt engineering 和流程编排。
- 新一代 agent 更希望用一个强决策模型端到端完成多步操作，减少人为拆流程。
- Deep Research、Operator 等代表强化学习从单轮答案推理，走向多轮交互和环境反馈。

### 6. 只有 RL 不够，必须有预训练理解能力

- OpenAI 早在 2016 年就尝试用 RL 在网页上买机票，后来又尝试机器人操作，但都遇到泛化瓶颈。
- 单靠强化学习容易变成在特定环境里记忆策略，换一个网页、任务或场景就失效。
- 预训练提供世界知识、语言理解、视觉理解和泛化表征，RL 提供决策、探索和行动能力。
- 因此，强 agent 的基础是“预训练理解能力 × 强化学习决策能力”。

### 7. 后续发展：泛化、代码和 agent 三条分支

- 吴翼认为，强化学习 scaling law 仍处早期，未来仍会出现更好的推理和决策模型。
- 不同公司可能形成不同个性：有的擅长泛化，有的擅长代码，有的擅长 agent function calling 和多轮交互。
- 未来用户端的体验不只看 benchmark，还看准确率、交互体验、是否会主动提问、是否能个性化决策。

### 8. RL 的关键不只是算法，更是数据和基建

- 强化学习训练是复杂系统：模型生成、环境交互、奖励判断、训练回传等模块高度耦合。
- 实验迭代速度直接影响算法进步，一个快 10 倍的框架可能带来 10 倍试错机会。
- 数据像老师出题，好的训练数据能针对模型弱点提升能力；无效刷题则很难产生进步。
- 吴翼强调，RL 中基建极其重要，需要懂算法的工程能力来搭建，而不能把工程和算法割裂。

### 9. 人才稀缺与团队建设

- RL 研究门槛比视觉、NLP、推荐等方向更高，论文和从业者规模都更小。
- 工业界长期缺少大规模使用 RL 的机会，导致很多人没有工程化训练经验。
- 对创业公司而言，是否必须配 RL 人才取决于阶段，但至少要有人理解 RL 的能力边界和潜在机会。
- 吴翼认为，创业公司不能只想终局，应抓住终局尚未到来的窗口，把可用产品先做出来。

### 10. RL 对人生的启发：多样性、探索和主动寻求信息

- 传统 RL 容易找到一个最稳定获胜策略后反复使用，但人生需要 diversity。
- 吴翼喜欢 diversity-driven reinforcement learning：既要 reward 高，也要和已有解法不同。
- 面对不确定世界，人需要通过行动和交互主动寻找 signal，而不是等想清楚所有目标再开始。
- 过度选择风险最低路径，容易停留在局部最优；年轻人应在可承受范围内探索高熵生活。

## 关键问答

### Q1：什么是强化学习？

A：强化学习是一套处理多步决策和结果反馈的算法框架。智能体在环境中连续行动，每一步不一定有标准答案，最后根据整体结果获得 reward。它适合描述打游戏、机器人控制、agent 操作、甚至人生选择这类复杂问题。

### Q2：强化学习和监督学习有什么本质差别？

A：监督学习通常给定输入和标准答案，比如图片分类；强化学习则没有每一步正确答案，只有最终结果好坏。监督学习像答单题，强化学习像打一整局游戏。

### Q3：RLHF 为什么重要？

A：大模型预训练只会续写，不天然理解“请完成我的指令”。RLHF 通过人类偏好训练奖励模型，让模型学会输出符合人类指令和偏好的回答，因此显著提升可用性和指令遵从。

### Q4：RLHF 和 O1/R1 类强化学习有什么区别？

A：RLHF 主要让模型更好用、更符合人类偏好；O1/R1 类推理 RL 则通过 thinking tokens 和标准答案验证，让模型获得更强推理能力。前者偏 alignment，后者开始形成提升智能的 post-training scaling law。

### Q5：为什么推理强化学习通常用数学和代码训练？

A：因为模型的中间思考过程太长、太复杂，人很难判断哪条推理路径更好。数学和代码有标准答案或可验证结果，可以只看最终答案是否正确，从而提供清晰 reward。

### Q6：DeepSeek 在强化学习上的最大意义是什么？

A：它证明 O1 式路径不是遥不可及，而是可以由专注团队较快做出可用结果。它给行业提供了信心和技术路线感，但真正做好仍需要强基座模型、训练系统、数据和工程积累。

### Q7：为什么早期单靠 RL 做网页操作和机器人失败？

A：因为 RL 只有决策能力，缺少足够的理解和泛化能力。它可能学会某个网页或某个场景，但换一个环境就失效。预训练模型出现后，语言、视觉和世界知识表征增强，RL 才能更好地发挥决策能力。

### Q8：什么是 agent？

A：吴翼给出的简洁定义是：能对文本之外的世界产生影响的模型。它可能调用工具、操作网页、控制软件或硬件。早期 agent 依赖 prompt 和流程编排，新一代 agent 更依赖模型自身的端到端决策能力。

### Q9：RL 训练框架为什么重要？

A：强化学习涉及模型生成、环境交互、奖励计算、训练回传等复杂模块。框架决定能否 scale up、是否稳定、实验迭代是否足够快。没有高效基建，算法想法很难被验证。

### Q10：创业公司要不要配 RL 人才？

A：吴翼认为有必要至少储备相关认知。虽然未来能力可能被基础模型平台化，但创业公司不能只等待终局。窗口期内，用微调、API、产品工程把能力做成可用产品，就是创业公司的机会。

### Q11：研究 RL 对人生决策有什么启发？

A：人生的 reward 往往不是预先清晰的，需要通过行动、交互和试错主动发现。不要只走风险最低路径；在可承受范围内跳出局部最优，追求更多样化、更高熵的生活，可能带来更高期望。

## 润色版逐字稿

### 开场：为什么强化学习突然变重要

主持人开场说，过去一年 RL 已经开始受到关注，而今年在 agent 热潮中，一个团队如果有很强的 RL 算法人才，就显得尤其稀缺。吴翼自我介绍说，他 2020 年从 OpenAI 回国，目前在清华大学交叉信息院任助理教授，长期研究强化学习、强化学习泛化性和多智能体强化学习。他的博士论文题目是《Building Generalizable Learning Agents》，其中已经包含了强化学习、泛化和 agent 三个关键词。

主持人希望这期节目能像一堂“大师课”：受众未必都有技术背景，但可以理解强化学习的历史、概念和它在大模型时代的重要性。

### 什么是强化学习

吴翼先把强化学习放在机器学习的大概念下解释。传统机器学习或监督学习，往往是给模型大量数据和人类标注好的答案，例如给一万张猫和一万张狗的图片，每张都标注正确类别，模型通过训练学会判断新图片。

强化学习最早常用于打游戏。与图片分类不同，打游戏需要连续做很多动作：发球、接球、回球，或者在游戏里向左、向右、跳跃。每一步未必有唯一正确答案，但最后会有输赢或分数。强化学习要解决的就是这种问题：智能体做一连串决策，中间没有标准答案，最后根据结果获得好坏反馈。

他进一步说，强化学习比传统机器学习更一般。人的生活中很多问题更像强化学习，而不是标准答案题。比如去美国出差，需要订票、准备材料、安排行程，最后是否顺利、是否开心才构成整体反馈。人生中很多选择没有标准答案，因此“人生就是一个强化学习的过程”。不过，人生比标准 RL 更复杂，因为人往往连 reward function 都不清楚，很多时候是在探索自己真正想要什么。

### 大模型与指令遵从

主持人追问，很多 agent 任务没有明确标准答案，这时强化学习如何发挥作用。吴翼先解释大模型本身：大模型的预训练目标是 next token prediction，即根据已有文本预测下一个词。它像“熟读唐诗三百首，不会作诗也会吟”，通过海量语料获得泛化能力。

但这与强化学习一开始没有关系。大模型预训练后会续写，却不一定会遵从指令。例如早期 GPT-3 看到“请解释登月是什么”时，可能只是重复这句话，而不是回答登月的内容。因为模型只被训练去续写，不知道用户是在下达一个指令。

OpenAI 的 InstructGPT 解决的就是 instruction following。它把“给定指令后输出符合指令要求的内容”建模为强化学习问题：指令是任务，模型生成的每个 token 是动作，最终回答是否符合人类期待就是 reward。

### RLHF：让模型更好用

reward 如何定义？吴翼说，这无法靠简单规则解决，只能靠人。OpenAI 找人写指令、比较模型回答、排序好坏，再用这些数据训练奖励模型。这就是 RLHF：reinforcement learning from human feedback。

RLHF 在 ChatGPT 时代非常重要，因为它让模型变得好用，能够遵从指令、回答问题、符合人类偏好。吴翼打比方说，RLHF 像是让一个聪明的清华北大学生经过实习后，成为公司里能打的员工。但它并不能让模型本身更聪明，也没有形成明显的 scaling law。

### O1：从好用到更聪明

真正让强化学习重新成为焦点的是 O1 式慢思考。吴翼认为，人面对复杂问题时会先思考，而传统大模型通常马上开始输出答案。OpenAI 探索的问题是：如何让模型思考。

最后被证明有效的方法，是让模型在回答前多写一些 thinking tokens。也就是模型先生成一段很长的思考过程，再给出最终答案。想得越久，很多问题上答案越准，这被称为 inference-time scaling。

为什么多写 token 会产生更好思考，目前没有完全清楚的理论解释。可以类比人打草稿，但这只是直觉解释。OpenAI 从 slow thinking 的想法到真正做出 O1，花了很长时间，难点在于坚持相信这条路径并把它工程化。

### 推理 RL 如何训练

要训练慢思考模型，就回到了强化学习。模型中间吐出一万甚至几十万 token，具体怎么想很难由人评价。相比 RLHF 中几百字回答可以让人排序，慢思考过程太长、太复杂，人很难判断哪条思考链更好。

因此，O1、R1 等推理模型主要使用答案可标准检验的问题，例如数学和代码。模型可以自由探索中间思路，最终只看答案是否正确。比如解方程，答案是 3 就正确，是 4 就错误。

这种方法也带来问题：如果只看最终答案，模型可能对简单问题也过度思考。Anthropic 的 Claude 在这方面被认为体验较好：简单问题少想，复杂问题多想。至于背后是多个模型路由，还是一个模型训练得好，外界并不确定。

### 从理科题泛化到文科题

主持人问，既然训练多用标准答案题，为什么模型也能回答文科题。吴翼解释，这依赖大模型的泛化能力。模型在数学和代码中学会“想一想”，被要求回答文科问题时，也能迁移出一部分思考能力。

但不能只靠泛化。做完大规模理科强化学习后，还需要通过文科数据、SFT、RLHF 等方式把模型“掰回来”。否则模型会过于理性、过于 nerd，回答体验不够自然。DeepSeek 的报告中也体现了这种合并思路：把极致推理模型和基础模型能力结合，再做后续训练，使最终模型既有深思考能力，也能正常对话。

### DeepSeek 的意义：证明可行路径

主持人问 DeepSeek 在强化学习上强在哪里。吴翼认为，DeepSeek 最重要的意义是证明这条路真的可做。OpenAI 像是在完全黑暗中告诉大家东方有灯塔；DeepSeek 像是有人走过去又走回来，告诉大家灯塔确实在那里，而且并不遥远。

这带来的信心非常重要。DeepSeek 未必做了别人完全不能做的事，但团队专注、做得早、做得扎实。真正做好这件事仍不容易：需要好的基座模型、强训练系统、长输出支持、大量并行采样和稳定高效的训练框架。

### 行业路径是否已经确定

主持人问，DeepSeek 是否已经证明了最优路径。吴翼认为，国内头部团队如 DeepSeek、字节等肯定还在探索多个方向，其他团队则至少需要先追赶。海外方面，OpenAI 和 Anthropic 仍有不同 belief，并且强化学习已经不只用于推理。

比如 Deep Research 和 Operator，已经从“一次指令、一次答案”的推理，发展到“指令—思考—操作—环境反馈—再思考—再操作”的多轮交互。这要求模型与虚拟网页、工具环境持续交互，训练系统复杂度大幅提升。

### 什么是 agent

吴翼给出自己对 agent 的定义：只要模型能够对文本之外的世界产生影响，就可以称为 agent。例如模型输出“关灯”，并真的通过电路把灯关掉，这就是 agent。重点不在输出文本，而在它对软件、网页、硬件或虚拟世界产生了影响。

早期 AutoGPT、LangChain 等也属于 agent，但主要依赖 prompt engineering 和流程编排。开发者要写清楚每一步怎么做，用脚本把模型输出转换成函数调用或具体动作。现在的 Deep Research、Operator 等新范式，则希望用一个更强的决策模型端到端完成任务，减少人为拆解流程。

主持人补充，用 prompt 的前提是人明确知道每一步该做什么。但很多真实任务中，人自己也不知道该如何拆解，需要模型探索多种可能。吴翼用做饭类比：新手需要父母告诉你开火、倒油、下菜；大厨只需要知道菜品目标，就能自己做出决策。

### 为什么单靠 RL 不够

主持人问，如果强化学习本身就能做复杂决策，为什么历史上没有单独基于 RL 的通用模型。吴翼回顾了 OpenAI 的两次早期尝试。

2016 年，OpenAI 做过 Universe 项目，希望通过强化学习让模型在网页上买机票。团队搭建了网页环境和大规模 RL 系统，但失败了。2019 年，OpenAI 机器人团队用强化学习控制机械手拧魔方；2020 年又尝试用图像输入整理桌面，也未能真正成功。

这些失败说明，强化学习提供决策能力，但缺少理解能力和泛化能力。模型可能学会某个具体网页或某个具体机器人环境，但换一个航空公司、换一个网页布局，就不一定会用。后来 CLIP、DALL·E、GPT-4 等预训练模型出现，提供了语言、图像和世界知识表征，RL 才有了更坚实的基础。

吴翼总结：预训练和强化学习是乘法关系。预训练提供理解、记忆、视觉和基础逻辑，强化学习激发决策、探索和行动能力。两者乘起来，才构成更完整的智能体。

### 为什么这条路径现在才清晰

主持人提出一个“马后炮”问题：先训练理解能力，再用 RL 训练决策能力，听起来很顺，为什么大家摸索了这么多年才找到。吴翼回答，因为每一步在当时都处于战争迷雾中。

首先，大家花了多年才确认单靠 RL 不够。其次，预训练到底用什么范式也经历争论：监督式、对比学习、生成式，直到 GPT-3 和 scaling law 才证明 next token prediction 的威力。再次，大模型能否产生通用推理能力，在早期也不是确定结论。今天回看逻辑很顺，是因为我们知道每一步答案；在当时，每一步都可能走错。

### 创业公司要不要配 RL 人才

主持人问，现在很多 agent 公司都想配一个 RL 能力强的人，这是否必要。吴翼认为 make sense，至少要有人理解这件事。虽然 RL 门槛现在还很高，但随着开源框架和工具成熟，一两年后门槛可能降低。提前储备相关认知总是有价值的。

主持人类比前两年大家讨论应用公司是否要自己做 pre-training，如今这个问题基本消失。未来会不会 agent 和 RL 能力也平台化，创业公司不需要自己做？吴翼回答，创业公司不能只想终局。创业公司的机会恰恰是在终局还没到来时，用最快方式把能力做成可用产品。Manus 就是一个例子：不论终局是否如此，它在当下市场缺少对应产品时，快速用微调、API 和产品工程做出了可用东西。

### 为什么 RL 人才稀缺

吴翼认为，RL 人才少有三方面原因。第一，研究门槛高。相比视觉、NLP、推荐，RL 的问题定义更复杂，环境搭建和复现都更难，数学也更麻烦。第二，工业界长期缺少大规模使用 RL 的场景，很多人没有实际工程化机会。第三，RL 对工程要求极高，大规模训练系统、并行环境、稳定性和效率都很难。

他提到自己团队一直在做强化学习框架，从 MAPPO、SRL 到最近的 AReaL，希望通过开源降低工程门槛。

### 强化学习的历史与伯克利环境

谈到个人经历，吴翼说自己 2014 年读博时甚至不知道 reinforcement learning 是什么。第一次听说是在 Berkeley campus visit 时，旁边有人提到 large-scale reinforcement learning。他后来进入伯克利，赶上了当地强化学习和机器人研究的氛围。

伯克利的 Pieter Abbeel、Sergey Levine、Stuart Russell 等老师，以及 OpenAI 早期与伯克利的联系，都为他提供了很好的研究环境。吴翼强调，很多时候不是自己多厉害，而是运气好在对的地方，愿意敲门、合作和尝试。

### 未来方向：泛化、代码和 agent

吴翼认为，强化学习的 scaling law 还在早期，未来会继续提升模型智能。之后会出现分叉方向，例如泛化能力、专业代码能力和 agent function calling。

不同模型可能形成不同个性：有的适合做 deep research，有的适合写代码，有的什么都能做一点。用户端感知不只来自 benchmark，还来自实际体验：准确率、交互质量、是否主动提问、是否理解上下文、是否能根据用户偏好做个性化决策。

他特别提到，好的 agent 不只是执行任务，还应在适当时候向用户提问。例如 Claude 在代码 debug 时，会问用户安装了什么包、版本是什么，而不是直接瞎改。这背后既需要理解，也需要推理和决策。

### AReaL 框架：为什么基建重要

主持人请吴翼介绍团队新发布的框架。吴翼说，他们与蚂蚁研究院一起开源了 AReaL，全称是 Ant Reasoning Reinforcement Learning。新版本 AReaL-boba 在 7B 模型上做到了较高的 AIME24 分数，并开放了源代码、数据、模型和评测脚本。

为什么框架重要？第一，强化学习也是 scaling law，要 scale up 就需要能在大量卡上稳定训练的框架。第二，复杂系统效率极其重要。RL 训练包括模型生成、环境交互、奖励判断和训练等模块；如果框架快 10 倍，就能做 10 倍实验，算法进展也会更快。

吴翼强调，RL 中基建、数据和算法都重要，但基建常常被低估。很多人把工程和算法分开看，但大规模强化学习不行。好的基建需要懂算法的工程能力，能服务算法迭代。

### 中美差距与谨慎乐观

主持人问国内外在 RL 上的差距。吴翼认为，美国仍较领先，尤其在探索性方向上。OpenAI 和 Anthropic 已经展示出大规模训练 agent 的能力，Deep Research、Operator 和 Claude 的一些能力都说明他们的 RL 训练系统很强。

国内推理模型进展很快，代码能力也在追赶，但在细粒度交互式 agent 方面仍能看到差距。他对国内保持“谨慎乐观”：DeepSeek 证明小团队可以在有限资源下把一件事做到极致，但整体上 pre-training 和 post-training 都还有追赶空间。

### 人生、reward 与探索

最后，主持人问研究强化学习是否影响吴翼的人生决策。吴翼提到自己喜欢一类论文：diversity-driven reinforcement learning。传统 RL 会找到最高效、最稳定获胜的策略后反复使用；但人玩游戏和过人生并不是这样，人会追求不同玩法、不同体验和多样性。

他认为，人之所以为人，在于有 diversity driven 的倾向。很多学生喜欢选择风险最低路径，比如保研、避免签证风险、选择最稳妥道路。但年轻时应该追求更高熵的生活。在可承受范围内多探索，多选择，可能带来更高期望。

主持人指出，RL 可以无限试错，但人生会后悔。吴翼回应，人生当然不是无限次，但也并非只能选一次。很多时候，大家因为害怕小概率变差而不愿意探索，结果停留在 local optimal。现实中跳出去试一试，大不了还可以跳回来。

关于 reward，吴翼强调，人生往往不是先找到目标再行动，而是在行动中发现目标。与不确定世界交互时，必须 active seek，主动寻找信息和信号。你不试，就永远不知道真实 reward 是什么。

### 收尾：AReaL 开源

节目最后，吴翼再次介绍 AReaL-boba：这是清华团队与蚂蚁研究院合作开源的强化学习训练框架，强调速度、稳定性和完整开放。他们希望更多人能用这个框架尝试强化学习，并参与开源社区。

主持人感谢吴翼，也提醒听众可以关注项目并为其点赞。
