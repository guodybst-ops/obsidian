# 023 - 英伟达的阳谋、破绽与野心：对话行云创始人 Mackler 季宇

## 摘要

这一期是曲凯与行云集成电路创始人 Mackler 季宇关于英伟达、GPU、CUDA、AI 芯片和计算机系统演化的一场深度对话。季宇的背景横跨芯片架构、AI 编译器、硬件、软件和开发者生态，因此这一期不是普通的英伟达商业史复盘，而是从「计算机系统如何被重新定义」的角度解释英伟达为什么能成为今天的英伟达。

本集最核心的判断是：英伟达不是单纯押中了 GPU 赛道，也不是只靠技术领先，而是通过一套长期的「阳谋」，把原本以 CPU 为中心的计算机系统，逐步拖入 **CPU + GPU** 的新体系。它没有直接替代 CPU，而是先作为协处理器进入 CPU 生态，再让 GPU 在关键计算任务中变得不可或缺，最终改变计算机系统里「谁更重要」的问题。

季宇认为，英伟达最厉害的能力不是标准半导体公司的制造或单点技术能力，而是 **定义新芯片品类、塑造开发者生态、推动计算机系统进化方向** 的能力。传统半导体公司擅长在既有品类中竞争，但英伟达擅长创造一个新器官，并让整个计算机系统围绕这个新器官重新组织。

英伟达的阳谋分为几层：第一，把问题从「纯 CPU」拖到「CPU + GPU」；第二，让所有人一起推动 GPU 变重要；第三，在 GPU 赛道上利用先发优势、软件生态和 CUDA 事实标准取得垄断。即使英特尔、AMD 后来意识到 GPU 重要，也已经被拉到一个英伟达更擅长的战场。

对于英伟达的破绽，季宇并不认为会来自一个更强的 GPU 替代品。GPU 这场仗已经基本打完。真正的机会在于：当英伟达把 GPU、显存、互联、网络、CPU 等都整合成 NV 全家桶时，它也会因为「过度全能」和「体系封闭」暴露新的可解构空间。下一代竞争者需要像当年的英伟达一样，为英伟达塑造新的阳谋，而不是在 GPU 维度上正面硬刚。

后半段还讨论了大模型算法、one-shot 能力、语言模型与深度学习的关系，以及英伟达未来的收入、野心和产业博弈。季宇认为，AI 没有让英伟达的地位变薄，反而让它更接近成为下一代计算机系统的核心；但如果它的高溢价伤害行业投入产出比，也可能倒逼行业重建开放体系。

## 金句收藏

> 英伟达不是简单押中 GPU 赛道，而是在重新定义计算机系统的进化方向。

> GPU 不是 CPU 的替代品，而是 CPU 体系里的一个外挂、一个延展、一个协处理器。

> 英伟达真正做成的，不是取代 CPU，而是把纯 CPU 体系拖进了 CPU + GPU 体系。

> CPU 像几个老教授，擅长解复杂题；GPU 像一万名小学生，擅长同时做大量简单题。

> CUDA 的本质，是让开发者能够调度这几万个「小学生」的一套开发方式。

> 英伟达的竞争不是设备之争，而是计算机系统灵魂之争。

> 如果英伟达没有跑得比 CPU 快，GPU 很可能早就被 CPU 集成掉了。

> 它的阳谋在于：你越跟它一起推动 GPU，GPU 在计算机系统里就越重要。

> 英特尔不是没有能力做 GPU，而是被拖到了一个不符合自己基本盘利益的战场。

> 软件生态一旦成为事实标准，底层算力形态就很难被撼动。

> 半导体公司擅长卷既有品类，但英伟达擅长定义新品类。

> 算力芯片不是标准品，它的护城河来自指令集、编程模型、软件生态和开发者心智。

> 垄断机会不是大势所趋卷出来的，而是公司自己创造出来的。

> 想打英伟达，不是做一个更便宜的 GPU，而是要给它塑造一整套新的阳谋。

> 当一个芯片越全能，它反而越有可能被重新解构。

> 英伟达想要的不是卖单块 GPU，而是把计算机系统变成 NV 全家桶。

> 开放体系是整个计算机产业的底座，高度封闭的体系最终会伤害行业投入产出比。

> 大模型相对传统深度学习的新东西，是把语言的抽象能力和 one-shot 能力压缩进模型。

> 英伟达今天的问题，不是能不能赢 GPU，而是能不能把整个 AI 产业真正推向落地。

## 核心要点

### 1. 这期不是英伟达历史复盘，而是计算机系统演化分析

这一期的价值在于，Mackler 季宇不是从普通商业史角度讲英伟达，而是从芯片架构、软件生态、编译器、开发者和计算机系统形态的角度，解释英伟达为什么能从图形加速卡公司变成 AI 时代最重要的底层公司。

他的核心视角是：英伟达的故事不是「一个公司押中一个赛道」这么简单，而是「一个公司推动计算机系统从纯 CPU 体系，演化到 CPU + GPU 体系」。

### 2. CPU 与 GPU：教授和小学生的区别

节目用非常直观的比喻解释 CPU 和 GPU：

- CPU 像几个老教授，擅长解决复杂、串行、逻辑分支多的问题；
- GPU 像一万名小学生，擅长同时完成大量简单、并行、重复计算任务。

AI、图形渲染、挖矿、高性能计算等场景，都需要大量并行计算，因此更适合 GPU。

CUDA 的意义，就是让开发者能够用相对通用的方式调度这批「小学生」，把 GPU 的并行算力用起来。

### 3. GPU 原本可能只是 CPU 生态里的临时扩展卡

在早期计算机系统里，CPU 是中心，其他加速卡往往只是为了满足某些行业暂时需求。等需求收敛后，CPU 厂商可能把这些功能集成进去，加速卡市场就消失。

3D 图形加速卡本来也可能走这条路：先作为独立扩展卡存在，等功能稳定后被 CPU 或集成显卡吞掉。

英伟达之所以能让 GPU 成为独立品类，关键是它意识到：必须跑得比 CPU 集成速度更快。于是英伟达坚持更激进的性能迭代，避免被 CPU 吞并。

### 4. 六个月翻一倍：英伟达用速度逃离被集成命运

季宇特别强调，英伟达当年提出要比摩尔定律更快地演进：英特尔按照约 18 个月翻倍，英伟达要做到约 6 个月翻倍。

这不是单纯技术口号，而是战略选择。因为如果 GPU 演进不够快，就会被 CPU 集成；只有性能不断拉开差距，独立显卡才有存在价值。

因此，英伟达早期的大功耗、高性能、激进迭代，并不是缺点，而是它为了保住独立生态位必须付出的代价。

### 5. 英伟达没有替代 CPU，而是改变了 CPU 的角色

英伟达最聪明的地方，不是做一个更强 CPU 去正面挑战英特尔，而是作为 CPU 协处理器进入体系。

它让计算机系统从：

- 纯 CPU 体系；

演化为：

- CPU 负责控制；
- GPU 负责计算；
- 二者共同组成新的主流形态。

这是一种以小博大的方式。它没有要求行业放弃原有 CPU 系统，而是在原系统上增加一个越来越重要的新器官。

### 6. 英伟达的竞争本质：争夺计算机系统里的「谁更重要」

英伟达和英特尔的竞争，不是简单的「你买谁的芯片」之争。早期用户仍然要买 CPU，也要买 GPU。

真正的竞争是：在计算机系统里，谁是核心？

如果纯 CPU 体系成立，英特尔继续是唯一中心；如果 CPU + GPU 体系成立，GPU 的重要性就会不断提升，英伟达也会逐渐从附属设备变成系统关键部件。

### 7. 英伟达的阳谋：把对手拖到自己的战场

季宇把英伟达的策略称为「阳谋」。它至少有三层：

1. **第一层**：让行业承认未来不是纯 CPU，而是 CPU + GPU；
2. **第二层**：如果英特尔也做 GPU，那等于一起推动 GPU 变重要；
3. **第三层**：在 GPU 这个战场上，英伟达已有先发优势、CUDA 生态和开发者积累。

所以无论英特尔是否跟进，它都不舒服：不跟进，纯 CPU 体系被削弱；跟进，则承认 GPU 体系更重要，并进入英伟达更擅长的战场。

### 8. 英特尔为什么难以反击

英特尔不是没有能力做 GPU，而是它的基本盘在 CPU。承认 GPU 重要，本质上会削弱 CPU 在计算机系统中的全能地位。

如果英特尔全力做 GPU，它就等于一起推动 CPU + GPU 体系，进一步解构 CPU 的中心地位；如果它坚持 CPU 全能，又会错失 AI 和并行计算的关键机会。

这就是大厂在面对结构性阳谋时的困境：不是看不到，而是每一步反击都可能伤害自己的既有利益。

### 9. CUDA 的护城河：不是软件工具，而是事实标准

CUDA 很早就出现，它的作用不只是提供一个编程接口，而是在 GPU 计算领域建立开发者生态和事实标准。

算力芯片不同于普通硬件，因为它涉及：

- 指令集；
- 编程模型；
- 编程语言；
- 算子；
- 框架；
- 开发者习惯；
- 上层软件积累。

一旦大量软件建立在某种算力形态之上，底层硬件形态就很难被替代。这和 x86 多年难以被 ARM、RISC-V 替代是同一类逻辑。

### 10. 英伟达不是标准半导体公司

季宇认为，标准半导体公司擅长的是在既有品类中竞争：CPU、GPU、内存、网卡、控制器等。一旦品类和接口标准化，大家就可以卷技术、成本、功耗、价格。

但英伟达最特殊的能力是 **定义新品类**。

它不是在已有 GPU 品类中简单卷赢别人，而是推动 GPU 从图形加速器变成通用计算器，再变成 AI 时代的核心算力器官。

这种能力更像苹果定义智能手机，而不是一般半导体公司做更好的零部件。

### 11. AMD 为什么只能 follow

AMD 的角色更像传统半导体强者：既做 CPU，也做 GPU，在已有品类里追赶和竞争。

但它没有像英伟达那样强势定义一个新的计算机系统方向。AMD 能吃到一部分 CPU 和 GPU 市场，是因为它在 x86 交叉授权和标准品类中有竞争力；但在「定义新品类、塑造生态」这个层面，它很难成为英伟达式公司。

### 12. 英伟达的护城河不是单点技术专利

节目中反复强调，英伟达的护城河不是某一个 PHD、某一个专利、某一个硬件技术别人做不了。

如果只是技术护城河，巨头有钱、有资源、有半导体能力，最终一定会追上。

英伟达真正的护城河是组合式的：

- 产品定义能力；
- 软硬件一体化；
- CUDA 生态；
- 开发者心智；
- 计算机系统演化方向控制权；
- 高速迭代能力；
- 对新应用的提前布局。

### 13. GPU 这场仗已经基本打完

季宇的判断是：如果仍然只在 GPU 这个市场里竞争，英伟达的垄断很难被打破。

算力芯片市场天然容易走向垄断，因为算力形态一旦被软件生态绑定，就不再像普通标准品那样靠价格和技术参数轻易替换。

所以后来者如果只是做「更便宜的 GPU」「更高性价比的 GPU」，很难真正撼动英伟达。

### 14. 真正的破绽：当英伟达变得太全能

英伟达今天的产品体系越来越全能：GPU、显存、互联、网络、交换机、CPU、整机系统、软件栈都在往 NV 全家桶方向演进。

季宇提出一个反直觉观点：当一个芯片或体系越全能，反而越有可能被解构。

因为全能意味着它要兼顾更多维度：算力、显存、互联、网络、控制、分布式计算等。每多兼顾一个维度，就可能在某个维度上产生新的取舍和矛盾。

这也意味着，未来真正的机会不是挑战 GPU 本身，而是重新拆解英伟达全家桶中承担过多功能的部分。

### 15. 打英伟达，需要重新激活开放体系

英伟达正在从开放体系里成长出来，再试图把计算机系统改造成自己的封闭体系。它希望用户进入 NV 全家桶：你可以买不同套餐，但最好都在它的体系内组合。

这符合英伟达利益，但未必符合整个产业利益。

如果高度封闭导致行业投入产出比变差，那么重新激活开放体系，就可能成为对抗英伟达的方向。

这不是在 GPU 上正面对抗，而是为行业提供第二选择：一个更开放、更可组合、更符合全产业利益的新计算底座。

### 16. 大模型的新东西：语言带来的 one-shot 能力

关于大模型算法，季宇认为，大模型不是简单替代深度学习，而是在深度学习基础上叠加了新的能力。

传统深度学习擅长从数据集中学习和压缩；大模型的新能力是：它把语言的抽象能力和上下文学习能力压缩进模型，使模型可以从 prompt 和上下文中快速学习。

这就是 one-shot / in-context learning 的价值：模型不只是从训练数据中学习，也能从当前上下文中快速吸收信息。

### 17. 英伟达的野心：把 AI 市场做大，同时提高自身溢价

英伟达一方面需要 AI 产业真正落地，把市场做大；另一方面也希望通过更完整的产品体系和更高规格，把自己的单价、溢价和体系控制权做大。

它讲「the more you buy, the more you save」，本质是告诉用户：我把性能提高 100 倍，只收你 10 倍价格，你总体更划算。

但这也带来一个微妙矛盾：高溢价越高，短期英伟达越赚钱；但如果高溢价伤害整个行业 ROI，反而可能让 AI 产业冷下来。

### 18. 老黄如果继续推进，核心是两件事

如果站在黄仁勋视角，后续最重要的事情可能有两件：

第一，推动大模型产业真正落地。只有 AI 应用、模型、推理和企业采用真正爆发，算力需求才能持续扩大。

第二，把今天的计算机系统进一步改造成 NV 全家桶。如果软件生态和硬件体系在封闭系统里绑定十年以上，那么英伟达的护城河会比今天还深。

### 19. 英特尔和 AMD 的困难

英特尔最合理的策略，可能是提升 PCIe 等开放体系带宽，重新增强开放计算系统竞争力，联合更多 GPU / AI 芯片公司对抗英伟达。

但它的矛盾在于：它仍然不愿彻底承认 CPU 只负责控制，仍希望把计算拉回 CPU。

AMD 的诱惑则是从 GPU 角度直接和英伟达竞争，但季宇认为这条路几乎不可能真正推成。AMD 更像 follow 两边，而不是定义全新系统方向。

## 关键问答

### Q1：CPU 和 GPU 最简单的区别是什么？

CPU 像少数老教授，擅长复杂、串行、逻辑判断多的问题；GPU 像大量小学生，擅长同时做海量简单、重复、并行的问题。AI 训练和推理中大量矩阵计算更接近后一类，因此 GPU 适合 AI。

### Q2：CUDA 是什么？

CUDA 是英伟达让开发者调用 GPU 并行计算能力的一套通用开发方式。它让开发者可以更方便地调度 GPU 中大量计算单元，把 GPU 从图形渲染工具扩展成通用计算平台。

### Q3：为什么 GPU 没有被 CPU 集成掉？

因为英伟达让 GPU 性能演进得足够快，远超 CPU 集成速度。只要独立 GPU 在性能、画质和算力上持续拉开差距，CPU 集成方案就无法替代它。

### Q4：英伟达的核心战略是什么？

不是直接替代 CPU，而是作为 CPU 的协处理器进入系统，逐步把计算机系统从纯 CPU 体系拖进 CPU + GPU 体系。它改变的是系统结构，而不是单点芯片。

### Q5：为什么说这是阳谋？

因为英特尔无论怎么选择都不舒服：如果不做 GPU，CPU 中心地位会被 GPU 削弱；如果做 GPU，就等于承认 GPU 重要，并一起推动 GPU 体系壮大，进入英伟达更擅长的战场。

### Q6：英特尔为什么不能简单反击？

英特尔的基本盘是 CPU。承认 GPU 承担核心计算，就会削弱 CPU 的全能地位。大厂不是看不到变化，而是很多反击动作都会伤害既有利益。

### Q7：英伟达和普通半导体公司的区别是什么？

普通半导体公司擅长在既有品类中竞争，例如做更好的 CPU、GPU、内存或网卡。英伟达更特殊的能力是定义新品类，并推动计算机系统围绕这个新品类重新组织。

### Q8：AMD 为什么没有成为另一个英伟达？

AMD 在 CPU 和 GPU 既有品类里都有能力，但它更多是在 follow 已有体系，而不是定义新的计算机系统方向。它能吃到市场份额，但很难像英伟达一样创造新垄断。

### Q9：英伟达的护城河主要来自哪里？

来自产品定义、CUDA 软件生态、开发者心智、编程模型、上层框架、软硬件一体化和计算机系统演化方向的控制权，而不是单一硬件技术或专利。

### Q10：为什么更便宜的 GPU 很难打败英伟达？

因为算力芯片不是普通标准品。用户不只买硬件算力，还买软件生态、开发工具、框架兼容、算子优化和开发者确定性。只在价格或性能上局部领先，不足以迁移整个生态。

### Q11：英伟达真正的破绽在哪里？

不在 GPU 单点，而在它越来越全能、越来越封闭的全家桶体系。当一个体系需要兼顾算力、显存、互联、网络、控制等太多维度时，就可能被新的结构重新解构。

### Q12：下一代竞争者应该怎么打英伟达？

不能只做更便宜的 GPU，而要像当年的英伟达打英特尔一样，为英伟达塑造新的阳谋：重新定义系统结构，激活开放体系，让行业有第二选择。

### Q13：大模型相对传统深度学习的新能力是什么？

大模型把语言的抽象能力和上下文学习能力压缩进模型，使模型具备 one-shot / in-context learning 能力。它不仅从训练数据中学习，也能从当前上下文中快速吸收信息。

### Q14：英伟达未来最想做成什么？

一是推动大模型产业真正落地，把 AI 市场做大；二是把计算机系统进一步改造成 NV 全家桶，让硬件、软件和开发者生态更深绑定。

### Q15：英特尔和 AMD 还有机会吗？

英特尔如果能重新强化开放体系，联合行业提升开放计算系统竞争力，仍有战略机会；AMD 如果只从 GPU 角度正面追赶英伟达，机会很小。关键不是 follow，而是重新定义游戏。

### 二、CPU、GPU 与 CUDA：教授、小学生和调度系统

**曲凯：**

大家可能看过很多科普文章，花很大精力讲 CPU、GPU、CUDA 这些概念。我们先用最简单的话，把这个点解释清楚。

**Mackler：**

CPU 是中央处理器，是通用计算机的基础。所有通用计算机，都是因为有了 CPU，才能搭建出通用计算机系统。

GPU 有两个概念：GPU 和 GPGPU。它最开始叫 GPU，是因为面向 3D 图形加速场景，graphics，所以叫 GPU。当时它是作为 CPU 在游戏或渲染方面的补充，因为那部分非常需要算力。

后来演化成 GPGPU，意思是 GPU 这套范式也可以做通用计算。类似游戏那些场景，有高度并行度的计算，今天所有 AI 也基本都是在这上面做计算。

CPU 里其实也具备一定 GPU 能力，只是相对弱一点。GPU 是把其中某部分能力扩大化。

计算分很多种。CPU 可能擅长解一道非常复杂的高等数学题；GPU 擅长做很多小学数学题。CPU 更像串行地得到一个结果，GPU 更多是并行地得到结果。

一边是几个教授去解题，一边是一堆小学生。几个老教授当然也能做几万个小学生做的事情，但会比一万个小学生慢得多。

CUDA 就是一套系统，让你能调度这几万个小学生。它让开发者可以利用这样的计算能力，开发这种「算一堆小学数学题」的通用开发方式。

**曲凯：**

对于 CPU 来讲，有没有类似 CUDA 的东西？

**Mackler：**

CPU 今天所有软件开发工具，大家可以认为就是 CPU 的「CUDA」。只不过 CPU 太通用了，所以语言非常丰富。

**曲凯：**

但 CUDA 是英伟达出的。C、C++ 不是英特尔出的。

**Mackler：**

对。英特尔没有做过类似事情。因为 CPU 是计算机基础，硬件出来之后，自然会有人把上面一层一层建起来。

所以英伟达很厉害。英特尔本质上还是偏半导体基因的公司，很多别人在帮它做事情；但英伟达要克服的势能非常大，它要自己建很多东西。

### 三、英伟达的第一层战略：跑得比 CPU 集成更快

**曲凯：**

很多人知道英伟达历史，但我们不一定按时间线讲。你从自己的研究视角讲一下，怎么看这家公司的历史、发展和战略。

**Mackler：**

90 年代确实有一波 3D 图形加速热潮。英伟达不是最早做 3D 图形加速的公司，但它能跑出来，我觉得有两方面原因。

今天很多人认为英伟达是押中了一个好赛道，并且坚持投入。但这个说法低估了黄仁勋个人的战略魄力，好像更多是靠运气。

当年英特尔作为 CPU 中心，有一整套逻辑。除了 3D 图形加速卡，历史上也出现过很多扩展卡。这是英特尔处理器开放体系的一部分。开放体系的目的，是让围绕 CPU 的计算机系统能进入所有行业。每个行业都有独特需求，CPU 如果不能短时间快速满足，就让加速卡先去满足。

但一旦这些加速卡把需求做收敛，CPU 就会集成。集成完之后，加速卡市场就没了。

3D 图形加速在当时也面临类似过程。CPU 短期内没法很好覆盖，但 3D 图形加速市场也在快速做 PMF，找到硬件上到底要做什么功能单元，才能更好支持 3D 图形需求。

如果没有英伟达深刻洞察这一点，3D 图形加速可能过几年慢慢成熟，然后 CPU 集成进去，3D 图形加速就消失了。

英伟达当时坚持一个重要点：英特尔按照摩尔定律演进，18 个月翻一倍；我们要做到 6 个月翻一倍。

它意识到，如果按照 CPU 的速度走，很可能会被 CPU 快速集成。必须跑得比 CPU 快得多，才能避免被集成。

前几天大家也在算，英伟达过去十年大概提升了 1000 倍性能。但这个事情其实在当时就做成了，所以 GPU 变成了独立品类。

今天我们默认觉得 PC 集成显卡是垃圾，独立显卡是打高端游戏必需品，觉得计算机形态就应该这样。但实际上这件事是事在人为。如果当时英伟达没有如此激进地推动 3D 图形加速性能、快速满足游戏市场需求，GPU 未必会成为今天这样独立的生态位。

### 四、硬件边界决定软件边界，创新者必须跑得更快

**曲凯：**

我一直觉得英伟达很有意思。一般互联网创业是先有海量需求，然后做产品满足需求。但英伟达做东西，好像有点领先于市场需求。

**Mackler：**

从软件角度讲，你不可能做一个硬件满足不了的软件。所以硬件是所有软件的边界条件。

但是用谁的硬件，是可以选择的。只要市面上存在一个更快满足用户需求的硬件，它一定会淘汰满足更慢的硬件，或者至少成为主流形态之一。

回到 AI 芯片领域，大家卷的速度没有英伟达快。或者说你跟它一样快，今天看起来已经非常不容易，但仍然没有太大意义。因为如果它能按照这个速度满足需求，它永远至少是第一梯队产品。大家没有必要从主流第一梯队产品切换到其他产品，动力不足。

这就是追赶者和创新者之间的区别。

**曲凯：**

你觉得英伟达能做到 6 个月迭代一块，是因为战略选择逼着大家必须做到，还是聚集了一批很好的人，或者有某种技术起点？

**Mackler：**

技术永远非常难。但这件事想做成，不只是技术上面临难题，宏观战略层面更重要。

如果没有这样的认知，哪怕有技术，也不会追求十年 1000 倍。但有了这样的认知，追求十年 1000 倍，在技术上仍然非常难。

英伟达也没有魔法，它也是在按照摩尔定律演进的半导体工艺上，跑出了比别人更快的曲线。这个确实有代价，比如功耗越来越大。大家说它是核弹，GPU 功耗大。

但功耗大对它来讲也不一定是坏事。因为它能做得这么激进，CPU 能不能做这么激进？CPU 想集成它，也得吃那么大的功耗。这个时候 CPU 会陷入两难。

如果 GPU 不激进，功耗友好，性能也没提升那么多，就和集显拉不开显著差距，到时候英特尔一集成，GPU 市场就没了。所以这才导致 GPU 成为独立生态位。

### 五、GPU 不是 CPU 替代品，而是计算机系统的新器官

**曲凯：**

我总结一下。CPU 里具备多项功能，也有一定算力。英伟达相当于把其中一部分解构出来，只把其中一部分拿出来做到足够好，而不是仍然做整个 CPU。

所以很多人可能不了解：GPU 不是 CPU 的替代或升级，而是 CPU 的外挂、延展。两者还是要合在一起使用。

**Mackler：**

对。这其实是非常有智慧的做法。

芯片行业里，想把整个计算机系统彻底颠覆，是非常难发生的。计算机行业有巨大惯性，这个系统是前人一代代积累出来的一整套系统。不可能为了一个新兴需求，就把整个计算机系统直接替换掉。

从这个角度，如果英特尔当时是 king，今天一定还是 king。哪怕它各方面不一定做得最好，这个关系也会很重。

英伟达选择的竞争方式，不是做一个 CPU 去取代 CPU，甚至更精确地讲，它不是做 GPU 去取代 CPU，而是把 CPU 计算机系统从纯 CPU 体系，拖到 CPU + GPU 组合体系。

这个变化是平滑的，因为它没有把 CPU 扔掉，只是做了一个 CPU 协处理器，让大家依赖这个协处理器，使整个计算机系统比纯 CPU 更好。

无论从生态惯性角度，还是从一家小公司面对当时巨无霸的角度，这都是很好的以小博大方式。

**曲凯：**

它没有说要做一个更好的 CPU，也没有说做一个全新的东西完全替代 CPU，而是做补充，融入原有体系。

这很有意思。英特尔和英伟达的竞争，不是设备到底买谁，而是在计算机系统里谁更重要。

**Mackler：**

是。更有意思的是，英伟达不做 CPU，英特尔当时也不做 GPU。他们相互不做对方的东西。

甚至英伟达想推的主流系统形态，是站在竞争对手英特尔的基础之上，做系统扩展。

这种竞争模式可以大量借鉴竞争对手做的所有工作。英特尔把 CPU 做得更好，CPU + GPU 体系也会变得更好；英伟达把 GPU 做得更好，这个体系也会变得更好。

**曲凯：**

当时英特尔像绝对领先的生态，像现在的英伟达一样。英伟达想的不是彻底颠覆你，而是先进入你的生态，再慢慢把你蚕食掉，最后形成宿主转换。

**Mackler：**

对。黄仁勋在过去，尤其是零几年的采访里，经常强调：这是关于计算机系统的灵魂，到底是谁的问题。

### 六、英伟达的阳谋：让英特尔每一步都难受

**曲凯：**

他一开始到底是韬光养晦，说 CPU 更厉害，我们只是附属生态位；还是从一开始就讲 GPU 更好？

**Mackler：**

他一直想讲 GPU 更好。

英特尔一定会打他。但英特尔最开始为了保证围绕 CPU 的计算机系统能进入各行各业，必须保持开放体系。这带来了巨大好处：计算机系统能推广到所有行业。否则计算机可能只用于军事、航天等特定领域，普通人根本不需要。

在这个基础上，英特尔没有办法把门关上。因为关上之后，整个计算机系统的可扩展性也会受损。

**曲凯：**

所以这是一个阳谋：我知道我在做什么，你也知道我在做什么，但你拿我没办法。

**Mackler：**

对。这个阳谋有几层。

第一层，不管是英特尔还是英伟达，都要想一个问题：未来计算机系统是纯 CPU，还是 CPU + GPU？答案一定是 CPU + GPU。只要 CPU + GPU 这件事成立，英伟达就赢了第一步。

第二层，如果英特尔也做 GPU，那大家就一起推动 GPU 往前发展，让 CPU + GPU 体系里 GPU 变得越来越重要。

第三步才是，谁的 GPU 是主流。这个赛道本身是英伟达主推的，它有先发优势。它把英特尔拖到一个英特尔不熟悉的赛道：到底是加入它，一起把原来的赛道干没，还是回到原来的赛道里。

这确实是阳谋。

**曲凯：**

这不像软件产品里的 cannibalize。比如 Google 如果做 Perplexity 式搜索，会打自己原本的份额。但硬件是 CPU + GPU，反而扩充了市场。

**Mackler：**

其实也有自我解构的问题。CPU + GPU 不只是补充，它也在解构 CPU 的作用。

如果是纯 CPU 计算机系统，CPU 是全能的，所有东西都由它负责。不管市场有多大、需求有多大，最后都转换成要买多少 CPU。

但一旦系统变成 CPU + GPU，CPU 功能就不再是全部。它可能只负责控制，GPU 负责计算。

所以英伟达已经把英特尔拖到一个新体系里，而且让英特尔不得不面对：在 GPU 这个战场上，英伟达已经领先。

### 七、英特尔何时意识到问题？

**曲凯：**

GPU 是 1999 年出来的。你觉得英特尔在哪个节点开始认这个事情？

**Mackler：**

从 3D 图形加速角度，1999 年之后英特尔基本已经认了。但那个市场很小，从英特尔角度看，自己还是最重要的，GPU 只是显卡，不是所有人都要显卡。而且数据中心里，英特尔还能赚很多钱。

真正到数据中心里开始重视，我觉得是在 AI 爆发之后。

2012 年深度学习开始爆发，英伟达迅速抓住机会，让自己在数据中心份额越来越大，也把 AI 软件生态高速积累在自己上面。等其他家回过神来，大概要到 2016、2017 年。

那个时候大家慢慢意识到，这个赛道越来越重要，纯做 CPU 好像扛不住。

但直到今天，英特尔也没有完全放弃「GPU 做计算、CPU 做控制、CPU 只是打杂」这个争夺。它仍然希望提升 CPU 算力，把计算从英伟达那里抢回来。

**曲凯：**

这听起来非常违背常识。站在英特尔视角，它这样想，是理性决策的必然结果，还是历史包袱？

**Mackler：**

因为做 GPU 打不过英伟达，而 CPU 还是相对垄断的，所以它一定希望让 CPU 更重要，这才符合它的利益。

大厂在这种顶级阳谋面前，其实没有招架之力。

### 八、为什么生态比硬件更难追

**曲凯：**

有没有一个时刻，英特尔说：GPU 重要性我认，我花最多的钱、组合团队，也要做一个比你更好的 GPU？

**Mackler：**

如果这样做，这时英伟达已经是在 GPU 领域跑得足够快的公司了。它的软件生态也会阻挡英特尔去抢。

**曲凯：**

这里最主要的阻挡，是硬件还是 CUDA 软件生态？

**Mackler：**

软件生态，或者说生态。

计算芯片很不一样。算力是有形态的。算力芯片涉及指令集、编程模型；编程模型会影响上面的编程语言，以及上面所有开发的东西。

如果上面已经积累了大量软件，下面算力芯片的形态，也就是指令集、编程模型，就会成为事实标准。这个时候你要撼动它，不只是算力指标要强，算力形态也很难撼动。

这形成了隐形护城河。这个护城河也守护了英特尔 x86 体系。哪怕英特尔多年犯了很多错，它仍然很难被动摇。

今天很多做 ARM、RISC-V 的想取代英特尔，仍然非常难。反过来讲，英伟达现在的地位，也很难被其他 GPU 或 AI 芯片轻易替代。

### 九、为什么英伟达不是标准半导体公司

**曲凯：**

整个过程中，AMD 在干嘛？

**Mackler：**

英伟达不是常规意义上的标准半导体公司。

常规半导体公司像 AMD：它会跟英特尔竞争 CPU，也会跟英伟达竞争 GPU。大家擅长做半导体技术，但很难定义新的半导体品类。

定义新半导体品类是非常特殊的能力。就像苹果发明智能手机，后面一堆厂商都可以跟这个品类；但真正发明智能手机这种全新东西，非常难。

在计算机行业里，这相当于说：今天计算机系统里应该增加一种新设备，这个设备解决什么需求，是什么形态，和今天体系怎么组织起来。

更重要的是，这个产品如何面向开发者，面向计算机行业里的软件人，撬动他们投入到 CPU + GPU 这样的体系里。

这件事和半导体技术研发有关系，但关系不是最核心的。半导体公司擅长做的是：已经有一个芯片品类，比如 CPU、GPU、内存、控制器、网卡，行业已经接受了，然后我去卷这个品类。

大部分品类都是相对标准化的。标准品意味着你只要技术足够强、价格足够好，就会快速把半导体行业毛利率打下来。

但算力芯片为什么高度垄断？因为你没有办法靠这种方式取代它。你看到英特尔 CPU 做成了，做一个 CPU 根本竞争不过它；你看到英伟达 GPU 做成了，想取代它，也很难。

英伟达是唯一一个能在这种游戏规则下玩得非常顺畅，甚至把英特尔做成「笼中鸟」状态的公司。

**曲凯：**

我在想，有点像细胞分裂。原来是单细胞，完全是英特尔；后来慢慢分裂出一些东西，英伟达从里面分裂出来，最后变成两个细胞。这两个细胞中间可能还连在一起。

CPU 那块，英特尔仍然是老大，也很难动；GPU 这块，英伟达绝对老大，CPU 也很难动它。AMD 则是两边都提供方案，从纯硬件层面拼，也能吃到一些市场。

**Mackler：**

大概是这个概念。半导体最难的是产品定义。一旦产品定义标准化，半导体公司就可以进去卷。

AMD 能吃到一些 CPU 市场，是因为它在 x86 标准 CPU 算力形态下有交叉授权，可以做 x86 CPU。这个时候形态一致，就可以按照纯半导体竞争方式竞争。

ARM 也是给大家塑造一个标准形态，然后 license 给不同公司，所以有很多 ARM 芯片公司。

### 十、为什么 CUDA 难以被 ROCm 替代

**曲凯：**

英伟达和苹果挺像。CUDA 有点像 iOS 系统。ARM 能不能类比成安卓式开源系统？AMD 出过 ROCm，那是不是类似开源替代？

**Mackler：**

ROCm 更像一个替代品。看到英伟达在这块吃肉了，于是想做一个替代品。但这个很难。

难在哪里？从软件行业角度，已经过了「对新兴需求有巨大诉求，愿意在这个位置疯狂造轮子」的阶段。

这个阶段大概率出现在 2012 年深度学习爆发之后。大家突然对算力有巨大需求，那个阶段大量开发者写框架、写算子，折腾框架到底应该是什么形态。

一旦需求过了那个阶段并且稳定下来，不管现在稳定形态有没有别的可能性，至少它是一个稳定工作的东西。今天大家愿意折腾的，不再是这一层东西。

所以这个时候再去推任何类似东西，都会比较难。

**曲凯：**

CUDA 是哪年出的？

**Mackler：**

很早，大概 2005 年左右。

**曲凯：**

我能理解为什么英特尔或 AMD 没把这个做好。但英伟达当年仍然是一家偏创业阶段的公司。它把 GPU 和 CUDA 做出来，已有巨头没有看到市场或者因为既有原因没有做，这可以理解。为什么没有其他类似体量和阶段的公司跟英伟达竞争？为什么让英伟达有这么长时间把 CUDA 体系建立起来？

**Mackler：**

因为塑造这个阳谋，本身不是大势所趋的事，而是事在人为的事。

大势所趋是计算机行业保持现状继续往前走，现状里哪里有痛点就提升哪里。英伟达塑造的阳谋，是借着新兴需求变化来改造行业。

如果你没有改造成功，大家不会觉得这是行业趋势；你改造成功的时候，你也已经垄断了。

**曲凯：**

这和软件市场不太一样。软件市场领先一两年，后面的人花更多钱进来还能抢市场。

**Mackler：**

对。因为芯片更接近 fundamental 的东西，包括计算机系统形态。这个东西一旦改变，很难往其他方向纠正。

越接近应用，稳定性越差，但短期内越赚钱；越往下，可替代性越难撼动。

### 十一、英伟达如何塑造计算机系统进化方向

**曲凯：**

你觉得黄仁勋一开始就想得非常清楚吗？

**Mackler：**

我觉得一定是想得非常清楚。你回头看他过去的采访和讲话，会发现他那时就有这样的认知。比如要 6 个月翻一倍，比如讲这是关于 PC 灵魂之争，不是设备争夺。

而且他在很多地方都会讲一个重要点：我们要做别人没做过的事情，不要在同一维度上跟已有东西竞争。

他非常擅长卷上层逻辑。上层逻辑指的是软件生态、怎么调动开发者、怎么调动需求，让计算机系统往他想推动的方向走。

你刚才讲单细胞，我更倾向于讲一个生物怎么进化。

计算机系统最开始像一个简单生物形态，但它到底可以走向什么形态？今天世界上所有动物都代表可能形态，大家都有自己活下去的方式。计算机系统会往哪个方向走，在一个大行业里最多只会有一两种可能性。

到底往哪个方向进化，就会变成争夺重点。英伟达就是不断塑造进化方向，让它往对自己更有利的方向动。

**曲凯：**

英伟达像是带大家走上陆地。英特尔可能觉得我往更深海区域走，或者我靠原有器官演化也能上陆地。问题是长出新器官，还是原有器官量变来满足需求。

**Mackler：**

对。这个事情赌性很大，而且难在软硬件结合。不是只看器官怎么做出来，而是进化压力到底来自哪里，以及希望计算机系统走向什么生存方式。

这就是芯片产品定义很难的地方。它一方面要理解上层需求和计算机系统演化逻辑，另一方面又要知道硬件边界在哪里。

软件公司绝对做不了这个事情，因为你必须知道硬件边界。英伟达当时看英特尔，也觉得英特尔所有维度都垄断，工艺比台积电还强，垄断性比今天英伟达还强得多。

小公司要怎么在资源各方面不如大公司的情况下跟它博弈？答案是对方没有明显劣势，唯一劣势是所有维度都要兼顾。

如果你什么都不放弃，跟它一样所有维度兼顾，那你就是在做它的替代品，一定打不过它。

但如果你选择一个点，跑得比它快得多，并放弃其他点，才有机会跑得更快。

### 十二、吞吐：英伟达选择拉爆 CPU 的维度

**曲凯：**

更具体一点，英伟达押注 GPU，它 all in 的是吞吐。吞吐能不能用人话解释一下？

**Mackler：**

吞吐就是，比如今天要算 1000 道小学数学题。英特尔是一个大学教授，可能擅长解微积分，但没有办法在很短时间内把几万道题全部快速做完。

如果找一万个小学生，就可以在很短时间内快速做完。它其实就是并行计算。

英特尔很多业务是单线程的，是串行任务，希望这个任务做得非常快。这就不能找一堆小学生，还得找资深教授。

英伟达选择的是：完全不要单线程延迟，把小学生数量堆得足够多。这样在做简单并行的大规模计算时，可以跑得比 CPU 快得多。

它用的技术，英特尔也都有，比如多核、多线程。今天处理器也会讲四核八线程，一个核跑多个线程。英特尔只要改参数，也可以往 GPU 方向演进，把 CPU 逐渐演化成 GPU 形态。

但这么做，单线程延迟就崩了。它必须保证单线程延迟足够低。

这两个东西会冲突。所以这就是以小博大的机会：选择对方自身一定有矛盾、有博弈的点，逼对方做选择。

### 十三、英伟达吹：为什么它的垄断比想象中更难打破

**曲凯：**

所以英伟达现在是类似当年英特尔的无敌状态了。你在知乎上好几次提到自己是英伟达吹，你对它看好到什么程度？

**Mackler：**

首先，它的能力在半导体行业确实独一无二。不光有这种能力，能以小博大，今天它还是巨无霸。所以它的垄断性比大家想象得更难打破。

今天很多人讲 transformer is all you need，模型收敛了，护城河是不是变薄了。但可以想一个简单道理：今天大家对 x86 CPU 还有多少需求？没有多少新需求。但 x86 CPU 今天连英伟达想扳倒它，都要花很大精力布局，能不能做成还要看未来几年。

所以英伟达的护城河，不是某个技术别人做不了。如果是这种护城河，市场会演化成多家巨头，因为世界上有钱、有资源、有半导体研发能力的公司还是有的。

典型例子是内存条，今天就有三家巨头，而不是一家高度垄断。

英伟达的垄断来自产品定义、软硬件生态一体化、对市场的信心和预判。它不是某个 PHD 或专利只有自己能做。

**曲凯：**

所以如果现在说英伟达有什么破绽，缺点在哪里？

**Mackler：**

这些破绽不是说它从大势所趋上有什么缺点。它有什么缺点，自己一定会改。

如果想和英伟达竞争，本质上还是要像英伟达当年一样，给英伟达塑造一整套阳谋。

比如 CPU + GPU，再加一个什么东西。

这个东西要仔细看今天怎么解构它。很多人会说，除了 GPU 再加 NPU，专门针对 AI。但我觉得这个不现实，因为 AI 是英伟达 all in 的优势。

就像互联网蓬勃发展时，英特尔 CPU 在数据中心大把赚钱。如果你说我要做一个专门针对数据库的专用处理器，其实机会不大，因为英特尔处理器在 IO 和控制上很强，没有明显弱点。

所以一定要用最保守方式充分考虑英伟达所有可能性，而不是说只要在 GPU 上加一个新东西，就一定能成为未来。

### 十四、英伟达真正的破绽：全能之后的可解构性

**Mackler：**

今天大家想往 AGI 上走，意味着 GPU 在计算机系统里承担的功能也变得非常庞大。它可能要计算、显存、互联，什么都要。

这个时候也有进一步解构它的可能性。

这件事很反直觉：当一个芯片越全能，反而越有可能被解构。因为全能意味着它要兼顾的东西非常多。

以前英伟达定义的是：CPU 做控制面，GPU 做计算面。今天计算面的事情也变得非常庞大，涉及网络互联、分布式计算、巨大显存需求、巨大算力需求，也变得非常综合。

这个时候有没有机会把它拆开来？说实话，仍然是事在人为。

**曲凯：**

它现在是当一个解决方案全套卖。但如果把它拆开，它现在是不是也能拆着买？

**Mackler：**

它也可以拆，但不是英特尔开放体系那种拆。它更多是说，今天你的数据中心到底要什么配比，交换机和 GPU 配比是什么样。一定是在它体系内。

它希望整个计算机系统演化成 NV 全家桶。全家桶里可以给你不同套餐、不同组合方式，但你逃不开这个全家桶。

**曲凯：**

这是不是商业演进的必然？软件系统也是这样：一个做得好，就要带其他东西，形成全家桶。用户总归会觉得有的东西不爽。

**Mackler：**

这符合英伟达利益。它能做成，一定会往这个方向做。

英特尔当年也是一样。它虽然是开放体系，但逻辑是你帮我试错，试完我就帮你集成，集成完我又是全能的东西。

英伟达逻辑是干脆不给你开放体系，直接买我的全家桶。

但我讲的破绽，是你要给它塑造一个阳谋。它不是全方面无敌。事情总有两面性。当它选择各方面都很强时，同时也在做一个各方面都兼顾的事情。

今天很多半导体惯性思维是：它各方面都兼顾，我也照着这个品类做一个各方面都兼顾的产品。那自然打不过它，也会觉得绝望。

它今天把体系搞得越来越封闭。整个计算机系统是一个有机体，如果你操纵开放体系往你想要的方向走，这个开放体系仍然是你说了算的。但如果你想从开放体系里 fork 出一个封闭体系，开放体系就被扔到一边了；同时你也给了别人机会，去把开放体系重新激活。

### 十五、重新激活开放体系，是产业第二选择

**Mackler：**

作为一家小公司，怎么给今天市值这么高的半导体公司创造一个难受的事情？听起来非常夸张，但这里面充满机会。

英伟达往私有体系走，整个行业其实受损，只有它获得高溢价。这个时候，如果能推动白盒开放体系，整个行业就有第二选择。

这里的白盒体系，类似英特尔那套开放体系。最初计算机系统是由英特尔开放体系奠基的，英伟达加入进来、融入进去，然后让自己越来越重要。

重要到一定程度后，它开始做私有化改造，往自己的体系上改。今天它想做最后临门一脚，把 x86 处理器也踢掉，真正完成整个计算机系统的闭环。

这对整个产业发展是不利的。所以如果想塑造新的阳谋，就可以利用这一点。

如果它今天还驾驭着开放体系，你要和它在这个体系里争方向盘，非常难。但今天它越来越想往私有体系里搞，相当于证明私有体系才是王道，开放体系不行。

如果有人能把开放体系重新拉起来，就可以趁它从这辆车上跳下来时，重新掌握这辆车。

我们宏观上也希望塑造一些新的芯片品类，让今天开放体系重新变得有竞争力。因为无论是大模型产业、PC 产业还是互联网产业，硬件底座一定要是一个白盒开放体系。高度垄断体系最终会让大家投入产出比算不过账。

**曲凯：**

所以总结一下，英伟达在 GPU 这场仗其实早就打完了。如果只是看 GPU 这块，未来也不会有人能和它竞争，除非整个体系变化，或者出来新的东西。

**Mackler：**

算力芯片市场是垄断市场。垄断企业都是独一无二的。不是大势所趋之后出现一堆公司去卷一个垄断机会。垄断机会一定是公司自己创造出来的。

如果今天希望在这个市场分一杯羹，最终目标一定是走向垄断。至少在某一个芯片品类上走向垄断。怎么塑造这样的市场，一定是独一无二的策略。

### 十六、大模型算法：语言带来的 one-shot 能力

**曲凯：**

你之前也写过大模型算法相关内容。你怎么看现在大模型的发展，以及它和芯片之间的结合？比如最新的 MoE。

**Mackler：**

大模型从算法角度讲，又往上走了一个台阶。算法演进也和我们刚才讲的一样。

过去很多人说深度学习不行，想打破或搞新算法解决深度学习的问题。这个方向可能是对的，但我觉得深度学习的潜力远不止过去大家看到的程度。

未来取代或革命深度学习的，不一定是另起炉灶的一套东西，也可能是基于深度学习演化出来，在别的维度产生新东西。

大模型也是这样。只不过过去我想得更复杂，没想到这么简单的方式就能产生新东西。

后来我反思，大模型相对深度学习，有一个新变化：one-shot 能力。

它可以理解上下文，可以从上下文里快速学东西，而不像过去深度学习只能从数据集里学东西。这个能力一定程度上来自语言。

OpenAI 首席科学家讲压缩，我觉得压缩是深度学习本身的能力。你给一个数据集和一个深度学习模型，它都可以做压缩。

但大模型产生的新东西，是把语言的抽象能力，包括 one-shot 能力，压缩到模型里，使这个模型获得语言本身附带的 one-shot 能力。

这个能力没有被今天的 scaling law 完全覆盖，所以我觉得还有更多扩展空间。

未来算法继续发展，不一定是大模型被颠覆，或者换成另一种算法。更可能是大家在语言模型、上下文、模型尺度发展到一定阶段后，因为某些尺度变得非常庞大，又产生新的雕花方式。雕着雕着，又出现新的平台化东西，叠加新的能力。

但这一定是更长时间尺度上的事情。

### 十七、英伟达的收入、溢价与产业矛盾

**曲凯：**

你觉得英伟达后面的出货和 revenue 会怎么变化？

**Mackler：**

这很有意思。英伟达很知道怎么把市场越做越大。从它自己的商业利益看，它讲 AI factory 的概念，也是为了让芯片产品和最终产品卖得越来越贵，溢价越来越高。

它讲「the more you buy, the more you save」。我帮你把规格提升 100 倍，然后收你 10 倍价格，始终是这个逻辑。

但我们也不知道，当它的高溢价真正开始伤害行业，让行业冷下来时，它会怎么做。

它会有很强动力，想把行业重新变大，把整个市场变大。但在市场还愿意高度投入的阶段，它肯定希望自己溢价足够高，并借着趋势，把自己做成一个计算机系统完全封闭的形态。

这很 tricky。英伟达像在和自己打仗，或者和自己所在行业打仗。

它很早之前已经完成了「自己是计算机不可或缺的一部分」这件事。剩下的问题是：怎么让这样的计算机系统像当年英特尔一样，覆盖各行各业，而不是只用于弹道、航天等领域。

它既要让市场变大，又要让自己赚更多钱，这两者之间关系很微妙。

### 十八、黄仁勋接下来最重要的两件事

**曲凯：**

如果你是黄仁勋，后面最重要要做的事情是什么？

**Mackler：**

第一，把大模型产业真正推向落地。只有市场真正变大，它才有更大空间。

第二，怎么让自己在那套游戏规则里真正变成全家桶，把今天计算机系统真正改造成 NV 全家桶。

如果大家在它封闭体系里演进十年以上，整个软件体系和它绑定非常死，那再想突破它就会变得非常困难。那个时候，它的护城河会比今天大家想象的还要深得多。

**曲凯：**

如果你是 AMD 或英特尔呢？

**Mackler：**

站在英特尔角度，今天它很矛盾。一方面不希望承认 CPU 只做控制，仍希望计算能拉回 CPU 上做。

但从现实角度，对它更好的做法，反而是把 PCIe 这些带宽提升起来，让围绕它的开放系统重新变得有竞争力。它可以拉全行业做 GPU、做 AI 芯片的人一起和英伟达竞争。

但它现在仍然存在矛盾，还不愿意承认自己在「计算到底在谁上面做」这件事上已经失败。

AMD 就这样吧。AMD 本身是两边 follow。它也是 x86 很重要的一环，如果能牵引整个系统，至少它的 CPU 围绕这个系统能做得更好。

但 AMD 还面临另一个问题：它还是做 GPU 的。所以看起来更诱人的做法，可能是从 GPU 角度入手，直接和英伟达竞争。虽然在我看来，这件事几乎不可能真正推成。

**曲凯：**
