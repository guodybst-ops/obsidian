# 027 - 27｜送礼"XIN"法：高净值客户维护的"攻心计"

> **上下集关联**：本集是 026《脱长衫·任玲心法集》的直接续集——026 讲的是"心法"（心态如何重塑），027 讲的是"兵法"（招式如何落地）。米莱在开场语明确点题："上一期我们聊的是心法，今天这一期任玲将毫无保留地交出他的兵法。"两集是**高净值客户维护双专题共同体**。

> **形态**：一对一深度访谈 · 主嘉宾任玲 · 米莱主持 · 85 行中集 · 兵法招式密度极高

## 摘要

- **段一 · XIN 三字命名法与用心的深度**：任玲的送礼哲学核心是"用心"——不追求贵，追求**被洞察感**。她把从复星 PR 时代养成的**「见完客户第一时间记信息」**的习惯，延续到现在的保险行业：微信备忘录记生活细节（不能喝牛奶/爱吃苹果/小朋友爱哪吒），日历 Calendar 记时间提醒（保单周年日/客户生日/小朋友生日/阴历转阳历），每年重复自动触发。经典案例——**6 年前为一位不喝咖啡爱喝茶且常出差欧洲的高净值客户，专门找方便出差装茶包的小盒 + 分装小壶定制款**——客户"很感动"，至今仍是超高净值客户。哪吒生日蛋糕案例（客户在外，蛋糕送给小朋友，客户反馈"你比我还了解我儿子"）证明送礼贵不如送**被洞察感**。任玲把这套做法命名为「XIN 法」——**心（用心洞察）· 新（不做标准化）· 信（信任建立）** 的三字谐音结构。
- **段二 · 分层预算 × 个性化 × 意义赋予的组合拳**：任玲的送礼有**标准化 + 个性化双轨制**——按保单金额分层（10 万以下 / 10-30 万 / 30-50 万 / 50 万以上）设预算标准，但同时允许突破成本考虑「意义赋予」。经典案例——她给所有客户寄陕西阿姨家乡的苹果，同时告诉客户"这是助农果，让农民赚一点"——**礼物本身廉价，但赋予了公益意义**，客户觉得"你既想到我又善良"，成了个人魅力的加码。她把两个孩子（自己女儿）也拉进送礼流程——**女儿手写贴纸「to XXX」**——变成家庭事业合伙人。任玲在车里常备礼物盒——"我基本上不允许自己裸奔"——超市买日本饼干巧克力+丝带+盒子，回家和女儿一起重新组装，拒绝任何直接买得到的标准化款。
- **段三 · 从名单到成交的完整兵法**：本集不止讲送礼，更是任玲**保险销售完整兵法体系**——① **客户拓展**：以缘故+转介绍为主，转介绍中心的三条标准（必须是我的客户 + 保险观念好 + 爱分享有强大内心）；② **裂变机制**：饭局上"必须加全部人的微信"作为最低目标；③ **心态破冰**：面对高净值客户前期放低姿态用"请教心态"，但到专业上要果断"启动价值切换到平等互动心态"；④ **顾问式销售 SPIN 结构**：现状 → 难点 → 暗示 → 需求；⑤ **泄压式沟通**：不要让客户觉得你在推销，把身份从"销售"泄压为"分享者/参考者"；⑥ **拒绝复盘**：客户没有错，是你没准备好——模糊拒绝多说明你根本没聊透；⑦ **借力打法**：从上海飞成都硬仗案例，任玲带上海师傅一起去成都签单，客户感受"你们很认真"，临场组合方案（各买一半保险公司产品）赢下客户利益最大化的信任；⑧ **AI 陪练**：任玲现在每条发给客户的信息都让 AI 以「专业顾问」或「闺蜜」等角色帮她矫正表达。任玲的总原则贯穿全程——**「客户是没有错的，只有你准备好了吗？」**

## 要点 · 12 节 · 逐条标注

### 1. XIN 法三字命名：心 / 新 / 信 · **独家框架 · 全档最强显性命名候选之一** · [归纳]

任玲整集反复用「用心」两个字定义送礼原点，但对应招式远超"用心"两字表面含义。综合原文所有招式，可拆解为三字谐音：

| 字 | 含义 | 核心动作 |
|---|---|---|
| **心 · Heart** | 用心洞察 · 记住细节 · 从对话中捕获 | 微信备忘录 + Calendar 双系统 · 阴历转阳历 · 车牌尾号 double check |
| **新 · Novelty** | 不做标准化 · 拒绝人人买得到 · 组装 + 意义赋予 | 自组饼干礼盒 · 女儿手写贴纸 · 助农苹果 · 定制茶盒（6 年前哪吒生日蛋糕） |
| **信 · Trust** | 礼是信任建立的媒介 · 破冰道具 · 传导载体 | 转介绍中心信任传导 · 初次见面伴手礼破冰 · 陕西醋 = 礼轻情意重 |

**关键洞察**（原文第 25、27、42 行）：**任玲反复强调「礼物贵不贵不重要，关键是让客户觉得被洞察」**——这是 XIN 法的元逻辑。三字之间存在递进关系：**因用心（心）而洞察 → 因洞察而不做标准化（新） → 因不做标准化而建立信任（信）**。

### 2. 客户分层体系 · 独家框架 · [原话·任玲]

任玲不用市面上"可投资资产 1000 万"这种数字定义，而是用**「关系深度 × 复购潜力」**双维度：

| 层级 | 定义 |
|---|---|
| **可成交客户** | 能与我成交一次的客户 |
| **优质客户** | 不止成交一次，未来会重复复购的客户 |
| **高净值客户** | 企业高管 / 小企业主 |
| **超高净值客户** | 大企业家 / 企业上市 / 财富自由 · 资产亿级以上 |

**关键动作**：任玲对超高净值客户设"储备"概念——不是马上要成交，而是要长期养。她目前储备 500+ 高净值客户，目标推到 800+，因为"这个行业是漏斗，没有足够体量，漏下来的不多"。（原文第 14-15、33 行）

### 3. CRM 双系统：微信备忘录 + Calendar 日历 · 独家工具组合 · [原话·任玲]

任玲从复星 PR 时代（当年为接待马云记他的车牌尾号，之后 double check 而不是重问）延续下来的**信息落存双系统**：

- **微信备忘录**：记生活细节 · 不能喝牛奶 / 爱吃苹果 / 小朋友喜欢电子产品 / 家人喜好 / 关键对话摘要；
- **Calendar 日历**：记时间提醒 · 保单周年日 / 客户生日（阴历转阳历 / 明年阳历都提前记）/ 小朋友生日；标注"每年重复提醒"实现自动触发；同步在提醒里放**下一步 action plan**（不用二次查询）。

**关键原则**（原文第 20 行）：**「见完客户第一时间落信息，否则时间一过就忘」**——记录不是可选项，是硬性肌肉习惯。（原文第 16-20 行）

### 4. 分层预算标准 × 意义赋予突破 · [原话·任玲]

分层预算（按保单金额）：
- 10 万以下 · 有一个预算标准
- 10-30 万 · 更高一档
- 30-50 万 · 再高一档
- 50 万以上 · 最高档

**但任玲允许突破成本考虑**——因为"人是感性的，看见某个东西小朋友会很喜欢，明知超预算也会送"，她"不太计成本"。**意义赋予**：陕西助农苹果案例——礼物本身不贵，但赋予公益意义后，客户觉得"你既想到我又善良"，成个人魅力加码。（原文第 16、21-22 行）

### 5. 送礼三经典案例 · [归纳]

| 案例 | 关键洞察点 | 客户反馈 |
|---|---|---|
| **6 年前定制茶盒**（原文第 24-25 行） | 客户不喝咖啡 + 只喝热的 + 常出差欧洲 = 需要方便出差装茶包的小盒 + 分装小壶 | 至今仍是超高净值客户 · "客户觉得很用心" |
| **哪吒生日蛋糕**（原文第 25-26 行） | 客户忙不在家 + 小朋友喜欢刚上映的哪吒 2 | "他比我还了解我儿子" · 客户激动转发 |
| **陕西助农苹果**（原文第 17、21-22 行） | 家乡阿姨的苹果 + 助农赋意义 | 客户被感动 · 觉得任玲有个人魅力 |

**共同结构**：**礼物本身不贵 + 洞察感强 + 意义赋予**——三要素齐备则客户成为长期铁粉。

### 6. 家庭事业合伙人：女儿参与送礼 · [归纳]

任玲拒绝直接买"人人可得的标准化礼物"，坚持自组装：
- 超市买日本饼干巧克力 + 丝带 + 盒子；
- 回家 + 女儿一起打包；
- 女儿手写「to XXX」贴纸；
- 送客户时补一句「这是我和女儿一起做的」——家里有小朋友的客户感觉不一样。

**深层动机**（原文第 28-29 行）：**「以后她也要做小事业，这件事儿还不如提前交给她——你是我的小小事业合伙人，也是人生合伙人」**——把家庭教育、母女陪伴、客户经营三合一。

### 7. 转介绍中心三条筛选标准 · 独家框架 · [原话·任玲]

任玲挑选**转介绍中心**（渠道级伙伴）的三条标准（原文第 36-37 行）：

1. **必须是我的客户**——"他都没在你这里买过保险，凭什么让别人来买"（信任先验）
2. **保险观念要好**——"他在转介绍时已经在做客户认知教育"（观念先验）
3. **爱分享 + 内心强大**——"他没有心理压力"（心理先验 · 转介绍 1-2 个不成不能退缩）

**价值层次追加**（原文第 38 行）：转介绍中心自身的社会阶层要与你的目标客户群体匹配。

### 8. 三进攻升级：饭局 → 二次共邀 → 我来做东 · 独家框架 · [归纳]

高净值客户破冰邀约流程（原文第 40-41 行）：

- **一进攻**：任玲主动约（"感谢那天见到您 + 印象深 + 是否可以带茶邀您品尝"）
- **二进攻**：让共同朋友再作局（同一个人再见面 = 熟悉度提升）
- **三进攻**：任玲自己做东回请（"两次都朋友做，我该回馈一下大家"）

**心理机制**：**「三面下来就没办法拒绝你了」**——把陌生扭转为熟络。

### 9. 顾问式销售 SPIN 结构 · 落地案例 · [原话·任玲]

任玲用**「顾问式销售 SPIN」**框架破冰高净值客户理财对话（原文第 53-55 行）：

- **S · Situation 现状**：了解客户现在的银行定存等财富管理现状
- **P · Problem 难点**：识别当下的卡点（定存率降低 / 财富分散管理耗时）
- **I · Implication 暗示**：暗示保险可以替代管理这笔钱（占用时间少 + 保本 + 长期）
- **N · Need 需求**：客户主动问"是什么工具"→ 任玲切入保险

**关键泄压动作**：**不要让客户觉得"你今天来做销售"**——把身份泄压为"分享者/参考者"。任玲这个 case 拿下 1000 万保费。

### 10. 硬仗案例：上海飞成都签单 · **借力打法 · 临场组合方案** · [归纳]

**背景**：任玲从北京刚转上海，需要快速验证自己。缘故朋友（外地）主动找她买保险，签约当天秘书说"他有事，不来了"。

**任玲的关键动作序列**（原文第 71-78 行）：
1. **不放弃**：模糊拒绝立刻电话争取；
2. **飞过去**：告诉客户"您买不买、从我这买不买都不重要，我希望您多花半小时做一个正确的决策"；
3. **借力**：任玲带上海师傅一起飞成都——"客户感觉我们是很认真的在对待这件事情"；
4. **心理临阵**：进办公室之前"手脚都在抖"，但心里给自己设三档预设：不成 / 全成 / 底线（至少切一万）；
5. **临场组合**：意识到长向不是自家优势，**给客户设计"两家保险公司各买一半"的组合方案**——客户利益最大化；
6. **当场拍板**：客户直接确定，第二天回上海签约。

**核心洞察**：**「借力 = 用师傅证明重视度 + 用师傅的 20 年经验补自己几年数据 + 打组合拳」**——这与 022 集陆小玲「用老板做浇灌思维」形成同源共识。（米莱在原文第 79 行明确点出这个跨集串联）

### 11. 泄压式沟通 + 拒绝复盘 · [原话·任玲]

**泄压式沟通**：客户会因"你今天来推销"产生防御——任玲主动泄压："我今天不是来做销售的，只是分享还有一个管理工具，或许对您以后有个参考。"（原文第 53 行）

**拒绝复盘**（原文第 67-69 行）：
- **客户模糊拒绝**（"再等等 / 到时候再说"）说明**前面根本没聊透**；
- **反问追进**："您觉得什么时间下我们再聊会有必要？"
- **明年定存出来的话**：直接追问"明年几月份找您合适？"锁定具体时间；
- **底层原则**：**「客户是没有错的，只有你准备好了吗？」**——第一时间反省自己而不是甩锅客户。

### 12. AI 陪练 · 反舞文弄墨 · 反直觉哲学输出 · [归纳]

**AI 陪练**（原文第 63 行）：任玲**每条要发给客户的信息都让 AI 帮她矫正**——
- 高净值客户 → 请 AI 以「专业顾问」身份优化；
- 女生客户 → 请 AI 以「闺蜜」身份优化；
- 建立自己的 **AI 邀约模板库**（共情模板）——反馈非常好。

**反舞文弄墨**（原文第 64 行）："现在大家非常强调活人感，动不动舞文弄墨这些会没朋友——大家一定要接地气。"

**反直觉哲学输出**（原文第 47 行）：任玲不发保险相关内容，改**用健身发朋友圈输出保险观念**——
- 「健康的第一性原理是自律，不是预防」→ 保险观念底层：**主动 vs 被动**；
- 「财富安全的第一性原理是被动工具管理」→ 直接把保险定位为财富管理的默认解。

## 关键问答 · 6 组

### Q1 · 定义高净值 / 超高净值客户？

**任玲答**（[原话] · 原文第 14-15 行）：
- 不用可投资资产 1000 万这种市面数字标准；
- **可成交客户 vs 优质客户**（复购）为轴；
- 附加背景：企业高管/小企业主 = 高净值；大企业家/上市企业家/财富自由（亿级+） = 超高净值。

### Q2 · 客户信息记那么多怎么保证不忘？

**任玲答**（[归纳] · 原文第 17-20 行）：
- **微信备忘录**记细节 + **Calendar 日历**记提醒 = 双系统；
- 阴历生日转阳历、明年阳历都提前落存；
- 每年自动重复触发（不用二次查询）；
- **关键原则**：见完客户**第一时间**落信息 + 同步把 action plan 放进日历。

### Q3 · 从名单到成交，破冰第一次自我介绍怎么说？

**任玲答**（[原话] · 原文第 38 行）：
- 饭局上：**「大家好，今天特别感谢谁谁的邀请认识大家，我是做保险的，如果有任何疑问……我也非常荣幸能够跟您有更多的互动」**——清亮简洁基本信息即可；
- **第一次不放太多信息**——保留后续跟进空间；
- 加微信后主动约"茶邀"："感谢那天见到您 + 印象深 + 是否带几款茶邀您一起品"（原文第 40 行）。

### Q4 · 面对高净值客户如何做心态破冰？

**任玲答**（[原话] · 原文第 57-61 行）：
- **前期放低姿态用"请教心态"**——大佬愿意扮演老师/教授/专家；
- **但请教要有备而来**——功课做足（行业/公司/成长经历），否则是"假学习"；
- **切换时机**：到了保险专业上"术业有专攻"→ 果断切换到**平等互动心态**；
- **难点**：**「请教容易，切入自己那部分变得很难」**——开口怕被拒；
- **解方**：专业够夯实 + 表达方式对（AI 陪练）+ 客户看见你能有价值贡献才愿意长期链接。

### Q5 · 客户 say no 怎么处理？

**任玲答**（[归纳] · 原文第 66-70 行）：
- **say no 是销售常态**——但要了解背后真相；
- 分类：其他选择 / 预算太高 / 情绪价值没满足 / 想再等等；
- **模糊拒绝的深层原因**：**前面根本没聊透**——不是这句话本身的问题；
- 追问："您觉得什么时间下我们再聊会有必要？"直接锁定时间点；
- **反省视角**：**「客户是没有错的，只有你准备好了吗？」**

### Q6 · 具体成交硬仗案例？

**任玲答**（[归纳] · 原文第 71-78 行）：
- 上海转任 · 缘故朋友主动咨询 · 签约当天秘书回绝；
- 电话追进 · 争取到"愿意让您再来一次"；
- 带上海师傅一起飞成都（借力）；
- 心理设三档预设（全成/不成/底线一万）；
- 临场组合方案：两家保险公司各买一半 · 客户利益最大化；
- 当场拍板 · 关键"客户觉得我们很认真"。

## 反直觉观点 · 本集贡献

1. **送礼贵不如送巧**——6 年前几十块的定制茶盒收留客户至今，礼物本身不贵，但"被洞察感"击穿客户心防（原文第 25 行）。
2. **朋友圈不发保险内容反而更好**——任玲用**健身、抗衰、社会新闻、茶酒兴趣**输出保险观念，因为客户"启动想保险这件事儿，一定是经历过身边哪个人跟我说影响到他"（原文第 46 行）——直接推销朋友圈是最低效的。
3. **健康 & 财富的第一性原理都是"主动"**：健康的第一性是自律不是预防，财富安全的第一性是被动工具管理不是频繁选择——直接颠覆"买保险 = 防御 = 恐惧"的市场心智（原文第 47 行）。
4. **客户拒绝是你没准备好**——不是客户的问题，是你的问题。模糊拒绝往往意味着"前面根本没聊透"（原文第 68-69 行）。
5. **前期请教式姿态，专业上要果断切换**——高净值客户不希望被高高在上地推销，也不希望你永远卑微。**心态切换的时机是"到了保险专业术业有专攻"**——从请教心态切到平等互动（原文第 61 行）。
