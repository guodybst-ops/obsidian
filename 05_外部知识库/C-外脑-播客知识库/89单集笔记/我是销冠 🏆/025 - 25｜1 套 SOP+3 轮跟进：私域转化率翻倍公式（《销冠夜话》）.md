# 025 - 25｜1 套 SOP+3 轮跟进：私域转化率翻倍公式（《销冠夜话》）

> **本集为双主播对谈实录（销冠夜话首播），米莱 + 吴惊喜（008 集嘉宾）11 月 6 日杭州直播基地首次视频号直播实况，参照 012 集圆桌处理方式，正文关键要点按发言人标注。** 双主播观点整体高度契合，罕见冲突时并列呈现。

## 摘要

《我是销冠》第 025 集是本节目的**"售后特别版" ·《销冠夜话》系列首播**，也是主播米莱与 008 集嘉宾吴惊喜（8 年私域经验、从负债百万到年入 2 亿）在杭州直播基地进行的首次视频号直播实况，几乎完整还原了当时的对话场景。本集**没有嘉宾**，两位主播围绕听友群预征集的三大高频难题展开——**客户关系管理系统化 / 朋友圈躺平好友激活 / team leader 团队目标拉起**——用 90 分钟给出一套可直接抄作业的私域转化 SOP。

三大议题各成体系但底层贯通"**被看见 = 关系深度**"：**第一议题·CRM** 提出**"三类标签"体系**——来源标签（决定开场）/ 状态标签（决定跟进节奏，五档：待激活 / 意向客户 / 进群客户 / 重点客户 / 沉睡）/ 需求价值标签（决定你能给什么），并配套动态更新机制与轻量工具选型（微信原生分组 / Excel / 飞书多维表格 / 有赞等 SaaS）；**第二议题·激活**提出**"1 套 SOP + 3 轮跟进"**——3 分钟内打完标签、24 小时内互联网亲戚小作文自我介绍、一周与一个月内二次跟进，配套**"朋友圈提前包装"**方法（活人感 + 专业内容 + 生活方式栏目化，如"吴惊喜的做饭糊弄学"）、**FAB + USP 价值传递结构**、"跟我有什么关系"（what's in it for me）个性化落点、以及**战败客户复盘**大于沉睡客户激活的反直觉洞察；**第三议题·目标**提出**销售增长公式**（收入 = 客户量 × 客单价 × 复购频率，四变量不同时提升先攻转化能力）、SMART 目标模型 + 期待值管理 + 打胜仗氛围下让团队自己定目标 + 动态复盘校正的完整闭环。

本集的独特价值有三：**第一**，作为**《销冠夜话》系列首播 + 吴惊喜二次登场（对 008 集"好人如何赚大钱"的私域方法论下半场展开）**，把 008 集散落的方法论首次系统化为可执行 SOP；**第二**，是**"跟进方法论族"的关键补强节点**——001 米莱三铁律首次提出"跟进"环节 → 022 陆小玲首次系统化为"大客户四步 SOP" → **025 私域场景补强为 1 套 SOP + 3 轮跟进公式**，形成 To B 大客户 vs To C 私域的完整跟进方法论矩阵；**第三**，反直觉观点密度高——"不赚你的钱是伪命题"、"意向客户比沉睡客户更容易转化（嫌货才是买货人）"、"复盘才是私域个体创业者最缺的动作"、"人群不精准是伪问题，本质是转化能力问题"——每一条都直击私域从业者常见误区。适合所有做私域、带小团队、有 200+ 微信好友但只能聊起来二三十个的从业者。它不是听完就完的一集，是**当天就能落地一半动作**的一集。

## 结构化要点

### 一、底层锚点：被看见 = 关系深度

- **吴惊喜观点（[原话]+[归纳]）：**「让每一个女生能够被看见、被理解、被成就」是私域，特别是女性客群的底层逻辑。做客户档案 / SOP 的本质不是记录，而是在**对的时间用对的方式说对的话**。
- **米莱观点（[归纳]+[推理]）：**高净值客户需求可提炼为两件事——**被倾听 + 被看见**。这与吴惊喜的"关系深度 = 被看见"底层同构，是两位主播独立得出的相同结论。
- **反直觉洞察（[推理]）：**微信通讯录 500-2000 人是常态，但真正能聊起来的只有二三十个——**卡点不是好友数量不够，而是没有"看见"任何人**。（连接：022 陆小玲"真心换真心"融创案例、013 王恺"90% 续客率"上瘾产品逻辑、007 张聪心理韧性）

### 二、议题一 · CRM 客户关系管理体系（三类标签 + 客户档案）

#### 2.1 CRM 概念还原（米莱）

- **米莱观点（[归纳]）：**CRM = Customer Relationship Management，从名字就能拆出三个部分——**客户信息 / 关系状态 / 管理动作**，任何 CRM 工具或方法论都在这三个部分上做文章。
- **米莱观点（[原话]）：**「你既然有他的基础信息了，知道你跟他之间的关系是怎么样，那你要怎么利用这些信息能够去把它运转起来——这个部分就是管理。」

#### 2.2 吴惊喜"三类标签"体系（独家方法论 · 全集最硬框架之一）

> **框架来源：吴惊喜（首创系统化表述） · 米莱补充"客户档案"字段**

| 标签类型 | 决定什么 | 具体分档 | 应用触点 |
|---|---|---|---|
| **来源标签** | 怎么开场 | 播客社群 / 小红书 / 视频号 / 线下局 / 朋友介绍 | 加微信瞬间 · **故事的起点** |
| **状态标签** | 接下来该怎么做 | 待激活 / 意向客户 / 进群客户 / 重点客户 / 沉睡 | 决定跟进节奏与频次 |
| **需求价值标签** | 我能给对方什么价值 | 增收 / IP / 内容 / 社群 / 培训等 | 决定推荐匹配 |

- **配套客户档案字段（米莱 + 吴惊喜共同扩展）：**基础信息（昵称/官方名一键备注 + 商务名与昵称对齐）+ 神奇信息（生辰 / 家庭情况 / MBTI / 星座 / 命理五行）+ **小细节动态更新**（例：吴惊喜在网球学校听到"孩子上完网球课要去上芭蕾课"，立刻记入档案 → 后续沟通提到"别耽误芭蕾课"→ 客户被惊喜到「你居然记得」）。
- **反直觉洞察（[推理]）：**标签不是给客户"贴人格标签"，是**给自己贴"沟通指令"**——每个标签背后都对应一个具体动作。

#### 2.3 工具选型（米莱）

- **米莱观点（[归纳]）：**从轻到重四档选型——① 微信原生标签分组（吴惊喜主用） / ② Excel 表格（米莱主用 · 年度重要人物生日 + 去年送礼参考） / ③ 飞书多维表格（个人 CRM 首选） / ④ 有赞等 SaaS CRM。
- **米莱金句（[原话]）：**「不用就没有用——工具不重要，重要的是你真的有信息、真的更新信息。」

### 三、议题二 · 朋友圈激活 SOP（1 套 SOP + 3 轮跟进 · 独家框架）

> **框架来源：吴惊喜（原始版本 · 首次公开完整时间节奏） · 米莱系统化归纳**

#### 3.1 完整时间节奏表

| 阶段 | 时间约束 | 动作要点 | 反直觉点 |
|---|---|---|---|
| **Step 0：打标签** | **加好友 3 分钟内 · 180 秒一秒都不能多** | 完成三类标签体系全部打完 | 大部分人从不做，甚至 3 天都想不起来 |
| **Round 1：自我介绍** | **24 小时内** | 互联网亲戚小作文模板 | 你介绍自己的颗粒度 = 期待对方反馈给你的颗粒度 |
| **Round 2：朋友圈互动 + 跟进** | **一周内** | 高频关注对方朋友圈 + 定制化点赞评论 | "勇敢的人先享受世界"·「最好的猎人总以猎物的形式出现」 |
| **Round 3：二次跟进** | **一个月内** | 结合状态标签调整节奏 | 频率不是死的，根据关系深度与业务状态动态调整 |

#### 3.2 互联网亲戚小作文模板（吴惊喜首创）

> **完整模板结构（[原话]拆解）：**

1. **开头（定位）：**「你好，我是你微信互联网的亲戚，我叫吴惊喜。」——**「微信互联网亲戚」定位立刻拉近距离**（对比：现在中国有很多亲戚有血缘关系但从来不联系，"互联网亲戚"反而更走心）。
2. **坐标：**我 base 在哪里。
3. **过去做什么：**上一段主要经历。
4. **现在做什么：**当前主要业务与身份。
5. **前置动作 · 包装朋友圈：**发小作文之前，先包装朋友圈——对方一定会点开你头像看朋友圈，通过刷你**三天朋友圈**判断你长什么样、在做什么、基本信息是否清晰。若不做，至少要有**置顶朋友圈**兜底。
6. **结尾 Q 对方基本信息（让对方被看见）：**「我关注到你最近朋友圈发的动态，你跟女儿很可爱……」

- **激活五步（吴惊喜从 A 开头通讯录批量激活方法）：**① 包装朋友圈 → ② 从 A 开头通讯录批量激活 → ③ 差异化开头（对方独特信息）→ ④ 中间自我介绍统一（可复用）→ ⑤ 结尾 Q 对方基本信息（被看见）。
- **反直觉洞察（[归纳]）：****中间可复制，头尾必定制**——群发感与个性化的分界线就在头尾两段。

#### 3.3 朋友圈"栏目化"包装法（吴惊喜）

- **吴惊喜观点（[原话]）：**「一般大家都说你要开始做业务就先展示自己生活要活人感，专业的东西会强制自己开一些栏目。」
- **案例：**「吴惊喜的做饭糊弄学」——把锅烧了、蒸蛋羹 40 分钟没蒸成、炒宝贝当土豆丝、生抽当老抽——网友评论「这是炒面吗？」→ **活人感 + 参与感**是私域信任的最快加速器。
- **米莱补充案例（[归纳]）：**朋友的女作家/艺术家用"不同颜色小球 + 文学/运动/生活小标签"视觉化区分朋友圈内容——**栏目化 + 视觉标签**让专业露出与生活露出可搜索、可辨识。
- **配比建议（米莱[归纳]）：**价值观 + 生活方式 + 业务垂直三类内容混排，具体比例不必死抠，但**活人感是稀缺项**（大家专业都够多，反而是活人感缺）。

### 四、议题二·延展 · FAB + USP + "跟我有什么关系"价值传递结构

> **框架来源：米莱（专业销售训练体系提炼）**

- **FAB 结构（米莱[原话]）：**Feature（特点核心是什么）+ Advantage（对比竞品的优势是什么）+ Benefit（这个优点对我意味着什么·客户利益点）。
- **USP 独特卖点（米莱[归纳]）：**「不是我这个独特卖点跟 100 个人都说这一个点」——**同一款产品面对不同客户要抽取不同独特卖点**，这个卖点必须匹配眼前这一个人的需求维度。
- **"What's in it for me（跟我有什么关系）"落点（米莱[原话]）：**「你这个东西好是好，跟我有什么关系？你要把跟客户的连接点阐述清楚，客户才能说'对我来说这个东西打折特别划算再不买就买不到'。」
- **案例（米莱[归纳]）：**保险从业者自我介绍反例——「我拿了 MDRT / 一年赚多少 / 换了什么车」→ 客户内心 OS「跟我没关系」；正例——「我可以帮助在座女孩子让老公乖乖上交银行卡」→ **全场女生秒加微信**。
- **反直觉洞察（[推理]）：****跟进的核心不是话术勤奋，是价值锚点是否落在客户身上**。

### 五、议题二·反直觉洞察 · 意向客户 > 沉睡客户 · 战败客户必须复盘

- **吴惊喜观点（[原话]）：**「战败客户比沉睡客户更容易转化——嫌货才是买货人。」
- **米莱观点（[原话]）：**「所有的失败都是需要复盘的，这才是进步点——但做私域的人，尤其是个体创业者，是绝对不复盘的。他会觉得'我的人群不精准'。」
- **米莱反直觉洞察（[推理]）：****「人群不精准」是伪问题，本质是转化能力问题**——如果你连朋友圈存量都转化不了，打开新流量端口进来结果依然一样。**根本问题不解决，换 100 个对象都会卡在同一个原点上**（连接：016 复盘 × 金钱管理系族）。
- **战败原因归类（[归纳]）：**① 时机不对（意向客户但沟通节奏错位） / ② 产品说服力不足（专业度问题） / ③ 我的自我表达匹配度问题 / ④ 需求本身不匹配（对方压根不是目标客户）——**只有归类清楚了，才能校对转化能力**。

### 六、议题二·底层信念 · "我不赚你的钱"是伪命题

- **米莱观点（[原话]）：**「私域里做生意就不要说'我不赚你的钱'——没人相信不赚我的钱，反而觉得你是不是有别的想法。」
- **米莱观点（[原话]）：**「不能够或不愿意向别人收费的东西，是不是本身也意味着它不具备收费的价值——真正有非常高价值的东西你怎么可能不去收。」
- **吴惊喜切身案例（[原话]）：**做微商时期客户砍价（按经销商进价打折），吴惊喜当场怼「到底是你觉得这个东西不值钱、还是我不值钱」——**背后逻辑：售后服务 + 长期陪伴才是私域产品真正的价值，一次交易只是入口**。
- **反直觉洞察（[推理]）：****主动收钱 = 主动为价值定位**（连接：024 集销售羞耻 × 配得感；002 高客单金字塔；010 顶级客户成交心法）。

### 七、议题三 · 团队目标对齐（销售增长公式 + SMART + 打胜仗氛围）

#### 7.1 销售增长公式（米莱系统化）

> **公式：收入 = 客户量 × 客单价（品数 × 单价）× 复购频率**

- **米莱观点（[归纳]）：**四变量**不建议同时提升**——先客观盘点你的能力、资源、状态在哪里，选阻力最小的那一档。
- **优先级建议（米莱[原话]+[推理]）：****存量激活优先于新流量拓客**——「你朋友圈里 30 个客户已激活，剩下 2700 你都没激活，先回到激活环节可能就能完成 10 万增幅。这代表的是转化能力，而不是流量能力。」
- **反直觉洞察（[推理]）：****转化能力 = 私域个体的核心资产**——从线下汽车行业到直播平台，每一个触点都有转化率（到店率 / 兴趣转化 / 成交转化 / 金融方案渗透），私域场景可完整套用。

#### 7.2 SMART 模型 + 期待值管理（米莱）

- **米莱观点（[归纳]）：****S**pecific（精准）+ **M**easurable（可衡量·必须量化）+ **A**chievable（要比现能力水平稍高、跳一跳够得着）+ **R**elevant（相关）+ **T**ime-bound（有时长约束，越长期约束越能容纳短期波动）。
- **反直觉洞察（[推理]）：****目标时长决定失败容忍度**——2-3 年目标 vs 单年目标，第一年下降在 2-3 年框架下不是失败，只是 KR 需要调整；单年框架下就是彻底失败。**期待值管理 = 目标时长管理**。

#### 7.3 打胜仗氛围 · 让团队自己定目标（吴惊喜）

- **吴惊喜观点（[原话]）：**「带团队打一次胜仗——在胜利氛围下让大家自己给自己定目标，那种氛围下他们定的目标其实是最 OK 的。」
- **米莱观点（[归纳]）：**目标没对齐往往两种情况——① 目标本身没让团队理解到 ② 目标本身是老板一厢情愿，团队心里有小 99「反正也完不成」。
- **对齐机制（[归纳]）：**明确目标 → 让团队自己拆解 → 让阶段性达成好的成员出来"被看见" → 团结与合作氛围 → 复盘校正精准度。

#### 7.4 动态复盘校正机制（米莱）

- **米莱观点（[原话]）：**「团队目标就是要不断复盘去校正你的目标设定的精准度……执行过程中不是流程结束才复盘，是每周甚至每半个月激予原目标去对一对，看看方向对不对、有没有跑偏。」
- **备用方案（米莱幽默观点[原话]）：**「如果目标达不到，那就调一下目标就好了——可能是目标说得不对，或者能力模型不一样。」
- **反直觉洞察（[推理]）：****目标不是承诺，是校正原点**——真正的目标管理者是把目标当参照系而不是终点。

### 八、贯穿全集的"所有相关方都是客户"心法

- **米莱观点（[原话]）：**「你的团队成员也是你的客户——被看见这个角色要先从你的客户扩到团队层。」
- **米莱观点（[归纳]）：****所有相关方（团队 / 外部合作方 / 上级 / 老板）都是你的客户**——永远可以站在客户角度听见他内心的声音，看见他真实的需求。
- **反直觉洞察（[推理]）：****"客户视角"是通用底层能力**——不只用于销售场景，同等适用于团队管理与向上管理（连接：021 教练式沟通、018 即兴力、010 顶级客户成交心法）。

## 案例故事

### 案例 1：网球学校"芭蕾课"细节记忆（吴惊喜）

- 吴惊喜在网球学校听到小朋友与妈妈的对话——「网球课结束后要去上芭蕾课」，立刻记入客户档案的"小细节"字段。
- 后续跟妈妈沟通时说「别耽误孩子接下来上芭蕾课」→ 妈妈瞬间被惊喜到「你居然记得，我都没有特意讲」。
- **底层机制：**「让他感觉到你记得他 = 你比别人用心」——**动态更新 + 无意信息 = 客户被看见的最快路径**。
- **[推理]延伸：**大部分销售的败点不在专业度而在"细节存量"——你听到但没记下的每一个细节，都是下一次触点的伏笔。

### 案例 2：奢侈品腕表店"两位 sales"的对比（米莱）

- 一位商务男士到国内腕表店试戴，说明"过两天要出差国外，想去国外买"。
- **第一家店 sales 反例：**给出的是「国外风险」信息——海关可能扣押 / 售后不如国内方便……
- **第二家店 sales 正例：**第一句话是「你马上要去出差，那个地方是个非常美好的地方」——**情绪价值 + 关系定位改变**。
- **[归纳]分析：**第一家把这位先生定位为"竞品客户"→ 只想防御；第二家把这位先生定位为"要去美好地方的朋友"→ 关系瞬间从"防御"切到"成全"。
- **[推理]反直觉：**客户抛给你的信息主线可能不是"我要买什么"，而是"我要去哪 / 我在做什么"——**能听到主线之外的东西，是敏感度而非技巧**。

### 案例 3：吴惊喜微商时期"砍价怼客户"事件

- 吴惊喜早期做微商，客户要求按经销商进价打折。
- 情绪管理未成熟时期，吴惊喜当场怼「到底是你觉得这个东西不值钱、还是我不值钱？」
- **背后逻辑（[原话]）：**「我提供很久的售后服务，我觉得我的服务是很值钱的。」
- **[推理]延展：**发火的表面是情绪失控，本质是**"产品笃定 + 自我价值笃定"双确信**——如果自己都不确信产品与服务的价值，客户砍价你会退让；如果确信，客户砍价你会看见他的错位。
- **配套底层信念（[归纳]）：**「你既然玩不过（割韭菜式销售），那我们就 be real 坦诚相见——总归以你的本我状态吸引来的人，一定是真的喜欢你这个人。」

### 案例 4：保险从业者"让老公上交银行卡"自我介绍（米莱转述）

- 米莱线下 SOHO 场景遇到一位金融行业女性朋友，自我介绍原话：「我是做金融行业的，能够帮助在座的女孩子让你们的老公乖乖上交银行卡。」
- **结果：**全场女生秒加微信——不管有没有对象、单身还是已婚，全部加。
- **[归纳]拆解：****「跟我有什么关系」的最短路径是共同幻想 + 群体共鸣**——她没讲 MDRT、没讲专业术语，只讲了在场女性最想听的具体好处画面。
- **[推理]反直觉：**自我介绍不是"我是谁"，而是"我能让你的生活变成什么样"。

### 案例 5：吴惊喜"做饭糊弄学"栏目（活人感朋友圈）

- 吴惊喜自我认知不会做饭，反而开了个栏目「吴惊喜的做饭糊弄学」——分享今天怎么糊弄自己吃饭。
- 栏目内容：把锅烧了、蒸蛋羹 40 分钟没蒸成、宝贝炒成土豆丝、生抽当老抽等。
- 网友评论区反馈热烈：「这是炒面吗？」——**共同讨论感 = 参与感 = 关系流通**。
- **[归纳]关键机制：**朋友圈本质是"社交软件"而非"广告牌"——用户潜意识期待的是"躺在屏幕后方窥探朋友生活"。
- **[推理]反直觉：****缺陷型内容比完美型内容更能建立信任**——完美人设让人敬而远之，"糊弄学"让人愿意点开你的头像。

### 案例 6：米莱"7-8 年没联系朋友圈互动破冰"（呼应 001 集 William）

- 米莱录 001 集《LV 销冠》前，与 William 至少 7-8 年没有实质互动。
- 米莱刷到 William 一条朋友圈内容"还蛮感兴趣"，简单点赞 + 评论互动。
- 由此开启对话，成为节目开门红嘉宾。
- **[归纳]核心机制：**「勇敢的人先享受世界」 + 「最好的猎人总以猎物的形式出现」——**先迈那一步的人在关系里赢**。
- **[推理]延展：**朋友圈互动本身就是激活 SOP 的一部分，无需等自我介绍模板，一个点赞就能重启关系。

## 三大反直觉观点合集

1. **「我不赚你的钱」是伪命题——没人相信不赚我的钱**（米莱）
   > 私域的"人情价"陷阱：越强调"不赚"，客户越怀疑你的动机。
2. **意向客户处理好比沉睡客户更容易转化——嫌货才是买货人**（吴惊喜）
   > "有意见的客户"其实是关心你的客户，投入了时间和精力，方向对了就能反转成忠诚客户。
3. **「人群不精准」是伪问题，本质是转化能力问题**（米莱）
   > 存量转化不了就打开新流量，结果依然一样——**先把转化能力做出来，再谈流量**。

## 关键问答

### Q1：私域客户档案要怎么系统化管理？

- **A（吴惊喜为主 + 米莱补充）：**基于微信原生"标签分组"功能起步，套用**三类标签（来源 / 状态 / 需求价值）**+ 客户档案（基础信息 + 神奇信息 + 小细节动态更新）；工具从轻到重四档：微信原生分组 / Excel / 飞书多维表格 / 有赞等 SaaS。核心不在工具，在于**真的记 + 真的更新**。

### Q2：朋友圈里躺平的好友怎么激活？

- **A（吴惊喜为主 + 米莱系统化）：****1 套 SOP + 3 轮跟进**——3 分钟内打完标签 → 24 小时内互联网亲戚小作文 → 一周内朋友圈互动 → 一个月内二次跟进；前置动作是**朋友圈提前包装**（活人感 + 专业内容 + 生活方式栏目化）；小作文结构是**开头定位 + 坐标 + 过去 + 现在 + 结尾 Q 对方基本信息**。

### Q3：产品介绍怎么不生硬？

- **A（米莱[归纳]）：**用 **FAB + USP + "跟我有什么关系"三段式**——Feature（特点）→ Advantage（对比优势）→ Benefit（客户利益点）；USP 独特卖点必须匹配眼前客户维度，不是给 100 个人同一个卖点；最后落到"跟我有什么关系"（what's in it for me）具体画面。

### Q4：意向客户和沉睡客户先激活谁？

- **A（吴惊喜[原话]）：**先激活**意向客户**——嫌货才是买货人，他花了时间和精力，反倒最容易转化为忠诚客户；沉睡客户是暂时不需要触达的客户，反而不是优先项。

### Q5：目标达不成到底是能力问题还是目标问题？

- **A（米莱 + 吴惊喜双观点）：****先复盘再判断**——① 若目标本身没让团队理解到，是沟通问题 ② 若目标是老板一厢情愿团队心里有小 99，是共识问题 ③ 若共识与沟通都到位，才是能力模型问题；核心机制是**打胜仗氛围让团队自己定目标 + 每周 / 半月动态校正**。

### Q6：小团队 team leader 怎么让团队目标对齐？

- **A（米莱 + 吴惊喜）：****SMART 模型 + 期待值管理 + 打胜仗氛围 + 让阶段性达成好的成员被看见 + 动态复盘校正**——目标必须比现能力水平稍高（跳一跳够得着），时长约束越长期越能容纳短期波动；关键动作是**让团队自己定目标**而非老板下达。

### Q7：私域个体创业者最缺什么动作？

- **A（米莱[原话]）：**「复盘」——所有的失败都是需要复盘的，这才是进步点；但个体创业者绝对不复盘，会把责任归结为「人群不精准」，其实是转化能力问题。
