# 021 - 21｜未来领导力：从管控到激发，教练式沟通成核心竞争力

> **单集形态**：一对一深度访谈 · 中集（原文 80 行）
> **嘉宾锚点**：永豪——99 后教练二代 · 深耕企业教练 20+ 年周老师之子 · 破局点播客主播 · 曾任纽约房地产销冠 · 前大厂员工 · 现从事高管教练/事业教练
> **核心命题**：**未来领导力 = 从管控到激发**——教练式沟通不是话术，是让个体自驱、让组织从内部生长出答案的元技能

> **注**：本集永豪与 012 圆桌四人组之一的永豪为同一人——是**跨集深度回访**，把 012 里"沙盘 vs 复盘 / 标品 vs 非标品"的框架进一步下沉到**教练行业的深度剖面**。

---

## 摘要

**第一段：13 岁美国留学 → 纽约房产销冠 → 大厂 → 教练创业的四段生存路径。**
永豪的客户洞察启蒙来自 13 岁独自赴美德州留学、一年内轮换过 8-9 个不同种族寄宿家庭（黑人 / 南非瑞士混血 / 韩裔 / 非裔 / 拉美裔 / 香港华人）的**被逼式跨文化训练**。他从"抓行为"升级到"抓文化和价值观"——**先做背调 → 再从文化和信仰入手判断行为**，这是他销售洞察的元方法。大学在纽约做 Leasing Broker（不是 Agent），半个月做到销冠。他并非直接找客户，而是**用两个方式建立信任**：找同校的合伙人（"陌生地方 4M 陌生 → 必须借同频信任基础"）+ 用万事屋整案的方式增加接触面。疫情中断这段创业，回国进大厂锻炼**心力 / 专业度 / 情商 + 相关利益方视角**，最终跨入企业教练行业。

**第二段：企业教练行业系统性拆解——ICF 认证体系 + 三大聚焦领域 + 与咨询/培训的区别。**
教练本源是**体育教练 → 北美绩效对话 → 商业教练**。市场主流认证是 ICF（国际教练联合会）三阶：**ACC（入门 · 百千元 / 小时）→ PCC（企业采购起点 · 千万元 / 小时 · 国内千人规模）→ MCC（大师 · 万元起 / 小时 · 国内百人规模）**。企业高管教练聚焦三方面：**团队沟通（跨部门 + 内部）+ 教练式领导力 + 组织文化**。**教练 ≠ 咨询 ≠ 培训**——咨询做过去创伤 + 标准解决方案、培训单向传知识、**教练做现在 + 未来的定向 + 创造体验 + 引发觉察**。核心信念：**每个人都是本自具足的完整人，资源由他内心自己产生出来，教练只做镜子和反馈**。

**第三段：两代教练的客群差异 + 倾听三层次 + 新媒体×专业人士的破局。**
父辈周老师（20+ 年资深）服务**制造业 / 保险 / 银行等人员密集型企业**——痛点是战略转型、高管统一思想、接班问题。永豪服务**AI 团队 / 出海团队 / 艺人公司**（估值高但组织体量小、高知人群）——痛点是**CTO/CEO 冲突、初创合伙人关系、内耗和方向迷茫**。教练角色也随之从"威严型导师"变为"平等陪伴者"——**核心不再是管控，而是激发个体自驱力：从"我要你做"到"我想要做"到"我们在一起共创"**。教练最核心的工具是**倾听三层次**：假象倾听（肉身在场心不在焉）→ 内容倾听（累且丢词）→ 沉浸式倾听（关注框架和逻辑层次而非具体内容）。米莱补充新媒体运营的两条原则：**要么有趣要么有料 + 同理先同自己的理**——运营不是消耗人品，而是让专业价值流动起来；**未来的超级个体必须是六边形战士——专家深度 + 操盘手传播思维**。

## 十大金句

1. **"教练就像镜子。我们相信每个人都是本自具足的完整人，资源由他内心自己产生出来，我们所做的只是照见和反馈。"** ——教练行业的一句话哲学。
2. **"未来的管理不是"我要你做"，而是激发"我想要做"——不是我在管理你，而是我们在一起共创一份事业。"**
3. **"倾听分三层：假象倾听（肉身在场心不在焉）→ 内容倾听（累且会丢词）→ 沉浸式倾听（关注对方说话的框架和背后的逻辑层次，而非内容本身）。"**
4. **"从抓行为升级到抓文化和价值观——行为每个人都不一样，但文化和价值观是大类相同的。从上而下落，比抓细微行为更高效。"** ——13 岁跨文化生存法则升级到销售洞察。
5. **"陌生地方 4M 陌生——陌生的人、陌生的地方、陌生的学校、陌生的资历——必须借同频的信任基础，才能撬动大决策。"**
6. **"教练是一个技术。它 = 打游戏的天赋点 + 你可以应用于任何行业。就像 AI 加什么一样——教练加什么，就是给对方的赋能。"**
7. **"教练做的是现在和未来的定向。咨询做过去的创伤，培训做单向的知识传授——教练做的是创造体验让人自发觉察。"**
8. **"当你足够真实的时候，你肯定已经赢了一半了——最高级的表达不是华丽辞藻，是人品合一。"**
9. **"新媒体运营原则：要么有趣要么有料。同理心的起点是同自己的理——从你真实的感受出发，相信至少有一部分人跟你想的一样。"**
10. **"一个企业做得非常好，是你的愿景里有他人。愿景里包含利他，把大家都含进去，做事情就不费力。德行合一、人品合一，自然有人跟随。"** ——收尾一句锁定长期主义。

## 核心要点

### 1. 13 岁德州留学 · 8-9 个寄宿家庭轮换的跨文化洞察启蒙

- [原话·永豪] "13 岁独自去美国德州留学，一年可能会有一两个新家庭，总共不下八九个——种族各异：纯黑人、南非和瑞士混血、香港华人、韩裔、非裔、拉美裔……每一个都沾点。"
- [归纳] 生存本能被环境压出来的**跨文化观察力**——这是永豪销售洞察的原点，也是米莱称为"客户洞察的启蒙阶段"的原因。
- [推理] 这是**元认知型销冠**的典型成长路径——不是主动学习销售，是**被生存环境逼出来的观察 + 归因 + 迭代**的元能力。可与 001 William、005 田野等的成长路径合族。

### 2. 从"抓行为"到"抓文化价值观"——洞察方法的进化

- [原话·永豪] "一开始我从行为上判断对方的不同，直到我预错了让对方不舒服，才开始改行为方式。但不断失败之后我开始总结——真正在意的是文化和价值观。"
- [原话·永豪] "后面到一个新家庭我会先从价值观入手、从文化入手——大类判断他是什么样的人，是从上而下落，而不是抓他很细微的行为。"
- [归纳] 客户洞察的**层级化模型**：行为（表层，每个人都不一样）→ 环境（中层，地域文化）→ 文化 / 价值观 / 信仰（底层，大类相通）。
- [推理] 这直接对标销售训练中的"**先做客户背调、再定沟通策略**"——把跨文化家庭的经验抽象为**面对任何陌生客户群的通用 SOP**：先看信仰宗教 → 判断价值观 → 预测行为 → 定制策略。建议为**客户洞察层级化模型**建立独立 stub。

### 3. 纽约房产 · 半个月做到销冠的三大杠杆

- [原话·永豪] "在纽约我们叫 Leasing Broker——broker 不是 agent，社会地位很高，很 fancy。曼哈顿豪宅经纪。"
- [归纳] 三大杠杆：
  1. **产品差异化**：不只是租房，是**万事屋整案**（解决生活琐碎烦恼），让客户决策成本降到最低。
  2. **合伙人分销**：不直接找客户（4M 陌生 → 没信任基础），而是找**同校有意愿的同学做合伙人**，用他们的信任基础做转介。分成两种：只推荐学生（推荐费）/ 陪同看房（用他的证）。
  3. **系统化学习 + 客源渠道扩张**：YouTube 学销售 + 各种聚会做链接 → 各学校布点。
- [推理] 这是**"陌生市场破冰"经典案例**——三大杠杆同时用，是**元认知型销冠**的实操版。建议提炼为"陌生市场·三杠杆破冰法"stub。

### 4. 大厂三年 = 三种能力锤炼 + 相关利益方视角扩容

- [原话·永豪] "大厂锻炼我三个方面——心力和压力承受能力、做事的专业度、情商（沟通）。因为大厂组织架构非常大，跟不同人接触，是很宝贵的经验。"
- [原话·米莱] "这里补充：永豪的父亲是资深企业教练，服务的都是 CXO 级别。永豪之前只见过老板，没见过员工或总经理——大厂让他真正下基层，同理"大"的同时同理"下"。"
- [归纳] 大厂对未来教练的最大价值不是业务技能，而是**"相关利益方"视角扩容**——从只见老板到见到中基层，是回到管理层视角时的**同理心加权**。
- [推理] 这是**教练二代的独特训练路径**——先见"上"（父亲的 CXO 客群）→ 补"下"（大厂员工视角）→ 回到"上"时同理心厚度立体。这解释了为什么本集永豪能同时理解创始人和团队成员的双侧痛点。

### 5. 教练本源 · ICF 三阶认证体系 · 国内量级

- [原话·永豪] "教练本源是体育教练 → 北美绩效对话 → 商业教练——本质都是通过沟通帮对方拿成果。"
- [归纳] ICF（International Coach Federation 国际教练联合会）三阶认证：
  - **ACC**（Associate Certified Coach · 入门款）：上完课程和培训小时数即可，市场供给多，费用**百元-千元/小时**。
  - **PCC**（Professional Certified Coach · 升级款）：需要小时数 + 考试，**企业采购起点**，国内约**千人规模**，费用**千元-万元/小时**。
  - **MCC**（Master Certified Coach · 大师款）：几年积累，国内约**百人规模**，费用**万元/小时起**。
- [推理] 这是**教练行业市场结构最精炼的一张地图**——建议独立 stub。也可为团队后续考察合作教练时提供选择框架。

### 6. 独家框架：教练 vs 咨询 vs 培训的三时相区分

- [原话·永豪] "本质区别在时间维度：**心理咨询**聚焦于个人的创伤（past 过去）；**培训**聚焦于知识层面的单向传授；**教练（Coaching）**是给现在和未来做定向，让大家聚焦在现在和未来，去拿到计划好的成果——创造体验让大家自发感受、提升认知。"
- [原话·米莱] "所以：咨询给标准解决方案、培训直接给方法、教练像镜子——通过专业工具的提问方式引发觉察，然后陪跑对方按自己觉察到的方案去行动。"
- [归纳] 三时相 × 三角色：**咨询 = 过去 · 医生** / **培训 = 静态 · 老师** / **教练 = 现在未来 · 镜子 + 陪跑者**。
- [推理] 这是**软实力行业最简明的一图分类**——建议独立 stub，可与 015 婷婷奢侈品培训、018 Andy 即兴培训并列做对照。

### 7. 独家框架：企业高管教练的三大聚焦领域

- [归纳·永豪] 高管教练服务企业时聚焦三个方向：
  1. **团队沟通**：跨部门沟通摩擦 + 团队内部沟通（尤其是学历高但沟通不擅长的高知团队）。
  2. **教练式领导力**：中层想上升但无法领导更大规模团队 = 领导力天花板问题。
  3. **组织文化**：文化落地和组织能力建设。
- [推理] 这三大领域**几乎覆盖企业采购高管教练的 90% 需求**——建议独立 stub。

### 8. 独家框架：教练交付形式的四阶递进（1V1 → 小 Group → Workshop → 长期项目）

- [归纳·永豪] 交付形式与项目周期：
  - **1V1 高管教练 / CEO 教练**：一年 6 次 Session。
  - **小 Group**（CEO + 1-2 位直属下属）：把创始人思想落到下层。
  - **Workshop**：十几到二十几人不等，半天/一天/两天，用于团队沟通/内部合作。
  - **半年周期**：2-3 次；**年度周期**：3-4 次。
- [推理] 这是**教练行业交付节奏 SOP**——建议独立 stub。

### 9. 两代客群差异：制造业密集型 vs AI/艺人公司高知型

- [归纳] 父辈周老师客群 vs 永豪客群：

| 维度 | 父辈客群 | 永豪客群 |
|---|---|---|
| **企业类型** | 制造业 / 保险 / 银行等人员密集型 | AI 团队 / 出海团队 / 艺人公司 |
| **组织特征** | 组织庞大、层级完整 | 估值高但体量小、几乎无标准组织 |
| **人员特征** | 层级化 | 高知人群（知识水平认知水平都高） |
| **核心痛点** | 战略转型 / 高管统一思想 / 接班 | CTO-CEO 冲突 / 合伙人关系 / 内耗 / 方向迷茫 |
| **教练角色** | 威严型导师（1→100 规模化） | 平等陪伴者（0→1 生存阶段） |
| **管理理念** | 我要你做（管控） | 我想要做（激发） |

- [推理] 这是**代际管理迭代**最凝练的对照表——两代教练面对的其实是**中国经济从制造业主导向 AI/新经济主导过渡期**的两侧客户。建议独立 stub。

### 10. 独家框架：倾听的三个层次

- [原话·永豪] "倾听分三层：
  1. **假象倾听**（第一层）：刷手机 / 只点头 / 心不在焉——肉身留在这里配合流程，但心和脑子都不在。
  2. **内容倾听**（第二层）：聚焦在对方说了什么内容——但很累，还会丢失一两个关键词。
  3. **沉浸式倾听**（第三层）：非常 flow 的过程——真正沉浸式地同理对方，倾听说话的**框架**和**背后的逻辑层次**，而非内容本身——是全然临在的感受。"
- [归纳] 三层递进的核心区别：**第一层丢客户 / 第二层丢关键词 / 第三层不丢任何东西**——因为你听的是结构不是字面。
- [推理] 这与 018 Andy 的"慢放快进倾听练习"、001 William 的"看见客人"、006 具体赞美族形成完整的**倾听工具族**。**倾听族累积达 5 集（001+006+015+018+021）** 已经彻底成型，强烈建议拔高进 04 主区。

### 11. 客源渠道拆解：自媒体 20% + 线下 80%（展会 30% + 私域 50%）

- [归纳·永豪] 客源结构：
  - **线上自媒体**：20%
  - **线下 · 展会**：30%
  - **线下 · 私域**：50%（同专业学习 / 商学院同学 / 私董会 / 同频小组织）
- [推理] 这是**高客单知识服务型创业者**的典型渠道结构——私域权重最大，因为教练是**高信任 + 大决策成本**产品。可与 015 婷婷的 3 年客户铺垫、001 William 的 VIP 私域并合并观察。

### 12. 90 后创始人的沟通卡点：同理心稀薄 + 就事论事的角色僵化

- [原话·永豪] "现在的初创者学历高背景好，但**同理心相对少很多**——他会以事情为中心讨论，你的表达是没有情绪的，不是很有人情味儿，比较生硬。做项目没问题，但要管理团队，这样说话不是所有人都能接受。"
- [原话·永豪] "本质是**角色包袱太重**——CEO / 创始人有光环，但需要跟团队融合、需要切换到成员角度思考。当他能卸下包袱，表达会变得更真诚。"
- [归纳] 沟通卡点定位：**同理心稀薄** + **角色僵化** = 表达失温。
- [推理] 这与 018 Andy 的 Yes And（让自我变得更小、更包容）、012 米莱强调的"以事为中心 vs 以人为中心"完全同步——**"同理心"是跨集共识候选族的最核心内环**。

### 13. 新媒体运营两条原则：有趣 or 有料 · 同理先同自己

- [原话·米莱] "在朋友圈发内容的原则——**要么有趣，要么有料**：有趣可以是文字 / 声音 / 视觉 / 综合；有料是有真正的价值（信息差 / 认知差）。"
- [原话·米莱] "所谓同理，**首先要同自己的理**——从你很真实的感受出发，相信至少有一部分人跟你想的一样。如果连你自己都不想看的东西，别人自然也不会看。"
- [归纳] 这是**新媒体×专业人士破局**的两条元规则——把"内容"和"心态"两端都摁在**真实**上。

## 关键问答

### Q1：教练到底是什么？和心理咨询、培训有什么区别？

**A（三时相分类）**：
- **心理咨询**：聚焦 **past 过去**——处理个人创伤，做治疗和疗愈。
- **培训**：聚焦**知识**——单向传授给学员。
- **教练**：聚焦**现在和未来**——创造体验让人**自发觉察**，去拿到自己想要的成果。

**教练像镜子**——不是给答案的人，是**提问题的人**。核心信念：**每个人都是本自具足的完整人，资源由他内心自己产生出来**，教练只做**照见和反馈**。

### Q2：市面上教练类型都有哪些？

**A**：**四大类**——
1. **职场商业类**：高管教练 / 商业教练 / 领导力教练 / 职业生涯教练
2. **个人生活成长类**：人生 / 生活 / 情感两性 / 亲子育儿 / 灵性觉察教练
3. **健康身心灵类**：健康康养 / 体能健身 / 心理技效（运动员/电竞/高压职场）
4. **特定细分领域**：财务教练 / ADHD 教练 / 演讲沟通教练

关键：教练本身是**技术** —— "教练加什么"就是给对方赋能，就像"AI 加什么"一样。

### Q3：ICF 认证体系怎么走？国内量级？

**A**：ICF（国际教练联合会）主流三阶——
- **ACC**：入门 · 完成课程+培训小时即可 · **百-千元/小时**
- **PCC**：**企业采购起点** · 需小时+考试 · 国内**千人规模** · **千-万元/小时**
- **MCC**：大师 · 几年积累 · 国内**百人规模** · **万元/小时起**

企业挑选教练：**PCC 是起点线**；从业者：从 ACC 起累积时长。

### Q4：企业高管教练聚焦什么方向？怎么交付？

**A**：**三大方向 × 四阶交付**——
- **方向**：团队沟通（跨部门+内部）/ 教练式领导力 / 组织文化
- **交付**：1V1 CEO 教练（年 6 次）→ 小 Group（CEO+1-2 直属）→ Workshop（十几-二十人 · 半天/一天/两天）→ 长期项目（半年 2-3 次 · 年 3-4 次）
- **信任建立**：已有信任 → 从最上层 1V1 自上而下落；第一次见面 → 轻量产品/课程/Workshop 介入建立信任基础

### Q5：倾听的三个层次分别是什么？怎么练？

**A**：
- **第一层·假象倾听**：肉身在场心不在焉。**代价：丢客户**。
- **第二层·内容倾听**：聚焦对方说了什么。**代价：累+丢关键词**。
- **第三层·沉浸式倾听**：flow 状态——**倾听说话的框架+背后的逻辑层次**，而非内容本身。**代价：无——听结构不是字面**。

练习方法：从二层到三层的关键是**"放下内容焦虑"**——不再纠结每个字，转而追问"他为什么这样组织表达？他的逻辑起点是什么？他真正想解决的问题是什么？"

### Q6：教练是给创始人的，普通职场人怎么用教练式沟通？

**A**：**三条核心可以立刻用**——
1. **相信对方本自具足**：先假设对方内心有解，你的角色是**帮他把答案照见出来**。
2. **提问代替告知**：把"你应该……"换成"你怎么看？""你想到哪些可能性？"
3. **听结构而非内容**：练第三层倾听，给到**结构性反馈**（"我听到你的关注点在 A 和 B，但你没提到 C，是否值得思考？"）

这套模式对**下属管理、家庭亲子、朋友求助**都适用——是**未来领导力**的通用协议。

### Q7：这一集给非教练行业的普通读者有什么用？

**A**：**四层价值**——
1. **管理理念升级**：从"我要你做"到"我想要做"到"我们一起共创"——所有管理者的核心迁移图。
2. **倾听能力升级**：三层倾听模型是**通用沟通工具**（销售、面试、亲密关系、朋友倾诉全部适用）。
3. **陌生市场破冰**：纽约房产三杠杆（差异化产品+合伙人分销+系统学习）= 所有陌生市场创业者的实操模板。
4. **新媒体×专业人士破局**：有趣 or 有料 + 同理先同自己——**未来超级个体的六边形战士框架**：专家深度 + 操盘手传播思维。
