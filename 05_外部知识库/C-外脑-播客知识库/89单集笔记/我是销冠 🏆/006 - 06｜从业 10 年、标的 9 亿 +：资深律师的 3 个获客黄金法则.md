# 006 - 06｜从业 10 年、标的 9 亿 +：资深律师的 3 个获客黄金法则

## 摘要

《我是销冠》第 006 集，主播米莱对谈中国政法大学本硕毕业、执业近 10 年、经手标的 9 亿 + 的上海资深诉讼律师 **婷婷律师（徐婷婷）**。整期从"如何科学选律师、高效合作"这一用户视角切入，逆向拆解律师行业的销售底层——**律所平台不重要，个体律师才是产品；服务是纯非标的，本质靠口碑；给客户提供的除了法律，更是资源整合与预期管理**。

主线拆成三条子线：**① 选律师五步——熟人推荐 → 面对面沟通 → 拿案情做诊断测试 → 避雷过度承诺 → 内心化学反应**；**② 律师的三层价值阶梯——找法条 → 依赖经验 → 资源协调直指核心，越往上买的越是"人 + 关系网"而非"法律服务"**；**③ 无形服务的报价心法——不好意思报价就先报"你好意思的价格"，供不应求自然提价；对客户做预期管理既是签单技巧更是自我保护**。

对普通行业读者的价值在于：律师是**"专家型 IP + 高客单成交 + 长决策周期 + 强隐私依赖"**的典型场景，与 001 LV 高净值客户信赖路径、002 文成的专家型 IP 金字塔、003 蒋逸鸣的无形产品价值分层完全同构。特别适合律师、医生、私人财富管理、B 端咨询顾问、任何"卖自己时间和判断力"的自由职业者收听。

## 金句收藏

> 对于律师来说，那你就要积累很多很多的资源给你客户提供全方位的服务，而不仅仅是法律服务。

> 你找的专业律师，你买的相当一部分是在买他的资源。

> 顶级的律师就是帮你直接解决这个问题，直接跳过所有的基础的东西，直指核心。

> 当你还不好意思报价的时候，那你就先报一个你好意思的价格嘛。

> 对客户进行预期管理是非常非常重要的事情，不仅仅是为了承单，更多的是你是要保护好自己的。

> 一个律师站在你面前，你跟他交流几句，交流一下案情，你能不能够信任他，其实你的内心会告诉你。

> 我们卖的是自己的时间跟经历，还有经验。

> 唯一不变的是改变。只有不断的提升自己的能力，才能够有应对风险的能力。

> 但凡有负面的，肯定那就是事实了。有正面的，那你可以考虑考虑是不是他的包装。

> 帮客户解决越多的问题，客户对你的信任跟依赖就会越强，那你就越实现正向循环。

## 核心要点

### 1. 律所只是平台，个体律师才是真正的产品

破除"红圈所光环"迷信：**律所不给律师分案子、不给律师分客户**，每位律师本质是"挂靠平台的个体户"。所谓红圈所（如均衡、金杜等 8-10 家）只是英国法律杂志按创收和影响力评的综合排名，与你当下签的那位律师的能力没有直接因果关系。

更需警惕的是**连锁型律所**（在多城市挂同名分所）——它们大多只签了冠名协议，业务完全各自为政。给你服务的仍是单个律师，而这个律师的水平"平台随便给你分，你根本不知道"。婷婷的核心建议：**跟着律师走，别跟着律所走**——律师去哪家所，客户就跟到哪家所。

### 2. 律师专业能力没有官方等级，全靠"面对面化学反应"判断

法律行业最反直觉的一点：**没有律师职业等级认证**。律师证只是入行执业证，市面上的"沪上知名律师""东方大律师"多为地方媒体/机构自颁，"花钱就能买到"。综艺加持、自媒体粉丝、律所光环都不能等同于对你这单案子的胜任度。

真正可靠的判断动作只有一个：**拿着你的案情证据面对面测试他**——看他能不能给你分析出案子的 1、2、3 三种走向，能不能提示风险，能不能给出可选方案。**过度承诺（"100%胜诉""绝对能要回来"）的律师必须避雷**——律师职业规范本身就禁止百分百承诺，敢拍胸脯的要么违规要么无知。

### 3. 律师价值三层阶梯：找法条 → 依赖经验 → 直接协调

节目里最凝练的一个模型（婷婷复述的行业笑话）：

- **L1 找法条律师**：接到问题就上法律数据库检索法条、翻类似案例，然后告诉你"这事不太行"
- **L2 经验型律师**：说"根据我以往经验，这类案子应该这样这样处理"
- **L3 资源型律师**：说"对方律师是我同事" / "对方企业是我之前的法律顾问，我打个电话协调一下"——**直接跳过所有基础环节，直指核心解决**

**推广逻辑**：任何"专家型 IP + 高客单"的行业都有类似三层——L1 卖信息、L2 卖判断、L3 卖关系网。**客户付 L3 费用买的其实是关系资源和路径压缩**，与 001 William 讲的"LVMH 平台调用者"、003 Steven 讲的"帮企业撬动内部资源"是同构逻辑。

### 4. 律师行业 70% 靠口碑转介绍，网络投放几乎全是坑

传统律所 70-80% 业务来自熟人介绍 / 客户转介绍，仅 20-30% 来自线上。婷婷对朋友圈广告律所的判断非常犀利：**羊毛出在羊身上，营销费一大部分转嫁给客户，最终真正给你服务的律师只能拿到律师费的 15%，服务质量必然缩水**。

更严重的是网络推广律所的分工陷阱：**线上营销 → 销售（不是律师）过度承诺 → 交钱后转给真正律师 → 律师费严重不足 → 客户预期与结果错位 → 大量投诉与纠纷**。全流程可以避雷判断：**朋友圈广告、百度/高德竞价、"央视认可"标语的律所，一律 pass**。真正靠谱的自媒体律师只有一种——**自己认真在做个人号、输出个人观点和专业内容的**，不是律所矩阵号。

### 5. 选律师五步 SOP：熟人 → 背调 → 案情测试 → 避雷承诺 → 内心化学反应

婷婷给普通人的完整选律师流程（可直接照抄）：

1. **优先本地律师**——本地才能通过打听打通口碑网络
2. **网络背调**——但凡有负面就 100% 是事实，正面则要防包装
3. **拿案情面对面测试**——听他分析走向、提示风险、给出方案
4. **过度承诺一票否决**——拍胸脯 = 违规 / 无知
5. **相信内心化学反应**——"你跟他交流几句，你能不能信任他，你的内心会告诉你"

婷婷把选律师类比"选医生 / 相亲"：**别人再推荐都没用，一定要自己坐下来聊完再决定**。这个五步 SOP 同样适用于选医生、私人财富顾问、任何强隐私 + 长周期的服务型合作。

### 6. 无形服务定价：先报"你好意思的价格"，供不应求自然提价

年轻律师普遍卡在"不敢报价"的心理关。婷婷提供的破解模型极简：**当你还不好意思报价的时候，先报一个你好意思的价格 → 客户接单量超过你时间承载能力 → 说明市场认可 → 自然提价**。这是完全符合经济学供需规律、可行动的 MVP 方案。

底层认知升级：**律师卖的是"时间 + 经历 + 经验"**——每小时都有市场价，为客户投入的时间就是产品成本。不敢报价的两个根因：① 心理不自信（要突破）② 产品/服务真的不够格（要提升）。**先抛出一个价格才能启动讨价还价**，与创业界的 MVP 心法完全一致。

### 7. 预期管理：既是签单技巧，更是律师的自我保护

关于"过度承诺"的另一面：**对客户做正向预期管理，不只是为了签单，更多是保护律师自己**。婷婷用借贷纠纷举例——**中肯律师说"证据齐全大概率胜诉，但钱能不能要回来还看对方财产线索"；过度承诺销售说"100% 帮你要回来"**。后者会导致客户对结果预期错位，最终 → 要求退费 → 司法局投诉 → 律师额外花精力处理。

**这是所有非标服务提供者都必须建立的意识**：**预期错位是所有客诉的根源**，而客诉在律师行业会被强制走司法局工单流程（类似 12315），无法通过"退钱私了"绕过。反过来，这也给客户端提供了武器——**若被过度承诺，务必留痕（书面 / 录音），司法局投诉是官方渠道**。

### 8. 律师签单全流程 = 汽车销售的完整映射

婷婷把律师签单流程与汽车销售做了逐项对齐，证明"卖非标法律服务"和"卖标准汽车"底层流程一致：

| 环节 | 汽车销售 | 律师签单 |
|---|---|---|
| 需求提出 | 客户说"我要 SUV" | 客户描述案情困境 |
| 需求诊断 | 销售帮判断是否合理、匹配款型 | 律师分析需求是否合理、可行 |
| 方案定制 | 加减配置 | 起草协议 / 单诉讼 / 组合诉讼 |
| 双方确认 | Q&A 澄清疑问 | 律师解答方案疑问 |
| 报价议价 | 车价 + 金融方案 | 律师费 + 三种收费模式 |
| 支付方式 | 全款 / 分期 | 固定收费 / 风险模式 / 组合模式 |

**核心差别**：产品有形、服务无形——所以**律师签单前的这些环节比卖车更重要，因为客户没有可视化的产品参照，只能靠这个流程建立信任**。这与 003 蒋逸鸣讲的"无形产品的四层价值梯度"高度呼应。

### 9. 律师收费三模式：固定 / 风险 / 混合

按案件类型对应不同收费方式：

- **计时收费**：常年法律顾问、咨询、合同起草修改等非诉讼类
- **固定收费（口价）**：打官司简单案件，一口价打完
- **风险模式**：按挽回损失比例分成——律师前期收极少，赢了拿大头
- **混合模式**：底薪 + 提成，前期少量固定费 + 后期风险费

婷婷特别提示：**律协/司法局都会有报价参考依据可以查**；客户不必纠结市场行情，只需扪心自问"**若能达成这个结果，我愿意付多少钱**"——**这个愿付意愿就是你的心理价位**。同时提醒：**3 万以下标的的案子不要找律师**，律师起收 5-10 万起，得算投入产出比，能自己 DIY 就 DIY。

### 10. 律师的隐形核心资产：为客户做"跨行业资源撮合"

高阶律师的收入结构里，**"跨行业资源整合"逐渐超过纯法律服务**。婷婷举了几个具体场景：

- **不良资产处置**：律师帮客户竞调完资产包，发现客户现金不够，直接对接资方配资 → 客户生意继续，律师锁定长期合作
- **艺人经纪纠纷**：律师积累够多艺人和 MCN 客户后，反向做撮合，兼任经纪商务
- **师妹通过公众号找到出书机会**：她 co-host 的《不止于法》被法制出版社主动邀约出书

**核心逻辑**：**"帮客户解决越多问题，客户对你的信任依赖就越强，正向循环滚起来"**。律师本质上处于**"跨行业信息与关系的汇聚节点"**——因为每单法律服务都会深入客户业务/生活/隐私，天然成为信息中枢。这与 001 William 讲的"销冠是平台调用者"完全同构。

### 11. 副业变主业客户的私域样本：小红书羊绒穿搭博主 → 法律客户

婷婷同时在小红书运营"生活日"账号——**副业不是为了赚外快，而是"工作之余的情绪出口 + 潜在客户蓄水池"**。真实转化数据：**买买买群里的粉丝，后续变成了她的法律客户，甚至资产配置客户**。

底层机制：**律师是超高信任门槛职业，客户第一次见你就要把隐私倒给你**。私域穿搭副业让客户**"先以粉丝身份低门槛熟悉你的人品和生活方式"**，再在有需求时无缝转化为法律客户。这是**"专业型 IP + 私域信任前置"** 的典范样本——先建立人格信任，再让专业服务顺流而下。与 001 William 讲的"朋友圈是第二店铺，只发生活不发广告"的方向完全一致。

### 12. AI 提效只覆盖 10-20%，律师核心能力不被替代

婷婷对律师行业 AI 冲击的判断相当克制：**AI 能加速的仅限"法条检索 + 案例整合 + 基础分类"，占律师工作量的 10-20%**。真正核心的部分 AI 拿不到：

- **单个案子的实际耗时**（上海法院一年才排下来，诉前调解 2 个月 + 立案 + 调解 + 法官分案）——**这是系统性的经验，AI 学不会**
- **面对面判断力**（客户情绪、案情走向、诉求真实性）
- **资源协调能力**（打个电话调一下的关系）

**扩展启示**：**单点提效救不了单点，除非全流程一起提效**——律师再快，法院排期还是排期。这个判断可以推广到所有"节点在系统里"的职业（医生、教师、投行 IPO）。

### 13. 女性律师的天然优势：细心 / 温柔 / 综合协调

行业结构在变：中政法男女比 3:7，女生占 70%，且婷婷所在的律所"现在招人更倾向女性"。原因：

- **踏实 + 细心**——出错率低、客户交付质感高
- **不与客户/法官吵架**——避免情绪化决策，服务场域更 peaceful
- **综合协调力强**——统筹案件资源、协调多方沟通

**这与"生育后回归家庭"的旧假设彻底相反**——女性律师执业率、合伙人比例都在上升。婷婷的判断："**改变才是不变的，不要把'稳定'（考公考研）当成人生唯一解**"。

### 14. 律师入行黄金建议：找一个好师傅 + 出卖劳力换成长

对刚入行年轻律师，婷婷的两条硬核建议：

1. **找靠谱大佬合伙人做代教律师**——不是挂名的那种，是真能带你的。前 3 年拿固定薪水、勤勤恳恳出卖劳力换经验积累，别急着独立
2. **能力才是唯一确定性**——**"唯一不变的是改变"**，考公考研不是唯一解；要充分试错后找到自己擅长且不讨厌的方向，不断提升"随时能独立养活自己"的能力

**对普通行业启示**：任何专家型职业前 3-5 年都是熬能力，无捷径；"稳定"是伪需求，"随时能重建"才是真安全感。

## 关键问答

### Q1：律所光环重要还是律师个人重要？

**A**：律师个人重要一万倍。律所只是平台不给分案子、不给分客户，你签的红圈所律师个人能力可能远逊于个人律所律师。跟着律师走，别跟着律所走。特别是"某科律所"式的连锁分所，业务完全各自为政，只是共用招牌。

### Q2：普通人怎么选律师？

**A**：五步——① 优先本地律师（能打听口碑）；② 网络背调（负面 100% 是事实）；③ 拿案情面对面测试他能不能分析出 1、2、3 三种走向 + 风险提示；④ 过度承诺（100% 胜诉）一票否决；⑤ 相信内心化学反应，跟他聊完你是不是信任他，心里会告诉你。类比选医生和相亲，别人再推荐没用，坐下来聊完再决定。

### Q3："我付的律师费值不值"怎么判断？

**A**：**不看外部标准，看你自己的愿付意愿**——"若能达成这个结果，我愿意付多少钱"，这个数就是你的心理价位。同时注意投入产出比：**3 万以下小案子别找律师**（起收 5-10 万），能 DIY 就 DIY。律协和司法局有报价参考依据可查。

### Q4：为什么朋友圈广告的律所要避雷？

**A**：网络投放的营销费转嫁给客户，最终服务律师只能拿到律师费的 15%，服务质量必然缩水。且流程有陷阱：**销售（不是律师）在线上过度承诺 → 客户交钱 → 转给真正律师 → 律师费不足 + 客户预期错位 → 大量客诉**。可信任的自媒体律师只有一种：**认真做个人号、输出个人观点的**，不是律所矩阵账号。

### Q5：不敢报价怎么办？

**A**：**先报一个你好意思的价格**——如果客户量超过你时间承载力，说明市场认可，自然提价；如果长期没客户，说明产品/服务本身要升级。核心认知：律师卖的是"时间 + 经历 + 经验"，每小时都有市场价，不敢报价是心理关不是技术关。这个模型适用于所有无形服务定价。

### Q6：律师能被 AI 替代吗？

**A**：能替代 10-20%——法条检索、案例整合、基础分类。核心不能替代：**实际耗时判断（法院排期是系统经验）、面对面判断力、资源协调能力**。年轻律师不必恐慌，但要意识到"基础活会越来越便宜，靠稀缺资源和判断力才能溢价"。

### Q7：这一集对非律师行业有什么用？

**A**：律师是"专家型 IP + 高客单 + 长决策周期 + 强隐私依赖"的典型场景，其获客/定价/客户关系逻辑可**直接迁移到医生、私人财富顾问、B 端咨询、独立顾问、任何靠"时间 + 判断力"卖钱的自由职业者**。三个可复用心法：① 你卖的相当一部分是资源与关系；② 无形服务定价用 MVP 心法；③ 预期管理既是签单技巧也是自我保护。
