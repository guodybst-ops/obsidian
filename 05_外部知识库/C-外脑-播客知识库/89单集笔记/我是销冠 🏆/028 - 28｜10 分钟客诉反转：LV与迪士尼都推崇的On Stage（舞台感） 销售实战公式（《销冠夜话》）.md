# 028 - 28｜10 分钟客诉反转：LV与迪士尼都推崇的On Stage（舞台感） 销售实战公式（《销冠夜话》）

## 结构化要点

### 一、底层锚点：顾客不是上帝 · 以客为尊（William 首次系统化）

- **William 观点（[原话]）：**「'顾客就是上帝'这句话今时今日应该要有变化了——我们更愿意讲'以客为尊'。」
- **William 观点（[归纳]）：****"以客为尊 ≠ 地位不对等"**——服务是我的专业，我以你为尊，是**因为专业**而尊重你，而**不是**因为地位而卑微。销售员与客人在人格上完全平等。
- **William 案例（[原话]）：**Ritz-Carlton「我们是一群绅士和淑女，为绅士和淑女提供服务」——**双主体平等**是国际顶级服务业共识。
- **反直觉洞察（[推理]）：****销售员的"自我认同感"是 On Stage 的前提**——低人一等的心态会污染后续所有专业动作，无法真正 On Stage。

### 二、On Stage 四维法则（本集独家框架 · William 首次系统化）

> **框架来源：William · 首次把 001 集抛出的 On Stage 概念完整拆解**

#### 2.1 第一维 · 第一印象（外表与仪态）

- **William 观点（[原话]）：**「顾客看到你的第一印象在**前 3 到 10 秒之间**，这个印象决定他愿不愿意跟你讲话、愿不愿意听你说话，会决定 80% 你跟他的相处时间——他会带着这个'有色眼镜'看你。」
- **William 观点（[归纳]）：****破冰其实在你们开口之前就已经结束了**——仪容仪表 / 着装 / 职业装 / 妆容 = 销售员第一课。
- **反直觉洞察（[推理]）：****"破冰话术"是伪命题**——真正的破冰是外表与仪态在客户开口前完成的预判决。

#### 2.2 第二维 · 心态（演员的自我修养）

- **William 观点（[原话]）：**「所有销售人员的第一个技能不应该是销售技巧，而应该是演员的自我修养。」
- **William 观点（[归纳]）：**核心机制类比——**演员演乞丐 / 反派我们不会因此讨厌演员本人，反而佩服演技**；同理，销售员遇到"指着鼻子说我是你上帝"的客人时，专业心态让你**用最专业的态度应对**，回到销售场景之外**不让此事对你个人产生影响**。
- **William 反直觉观点（[原话]）：**「不要认为正常生活情况下如果有人骂了你要回击、否则自尊心受不了——no，在这个时候你用最专业的态度来应对，能够不动声色、能够在受到很突发情况下仍然保持基本的礼貌和从容。」
- **反直觉洞察（[推理]）：****销售的心态修炼 = 演员的角色抽离能力**——On Stage 时角色被批评，Off Stage 时"本人"完好无损。

#### 2.3 第三维 · 态度（一以贯之的专业）

- **William 观点（[原话]）：**「至始至终有一个一以贯之的态度给到你的客人——不是说因为我看到你光鲜亮丽、感觉你是有钱人、穿得很体面，我才对你有所服务。」
- **William 观点（[归纳]）：****态度的公平性**是**对自己工作时间最负责的状态**——你永远不知道面对的人背后的财富、能力，以及未来可能建立的关系。
- **反直觉洞察（[推理]）：****态度的一以贯之 = 概率化收益的最大化**——用偏见筛客本质上是主动放弃概率收益。

#### 2.4 第四维 · 行为（同时影响面对面客人与旁观客人）

- **William 观点（[原话]）：**「你的行为不仅仅在影响你面对面的这个客人——其实看着你的其他客人也在观察你们。」
- **William 案例（[归纳]）：**广州 LV 店客诉案例后（详见"案例故事·10 分钟客诉反转"），店内闲逛客人稀稀拉拉想鼓掌 / 用鼓励眼神观察他——**之后跟这些旁观客人沟通时，破冰与铺垫都不需要了，因为他们已完全认可**。
- **反直觉洞察（[推理]）：****On Stage 行为的杠杆是 3 层观众**（面对面客人 + 旁观客人 + 同事影响）——一次专业行为可创造 3 层放大效应。

### 三、10 分钟客诉反转 SOP（本集全档最有名的显性实战公式 · William 首次公开完整节奏）

> **框架来源：William · 广州 LV 店真实案例复盘 · 分钟级 SOP**

#### 3.1 SOP 分钟级节奏表

| 阶段 | 动作 | 底层机制 |
|---|---|---|
| **T+0：抽离同事** | 二楼楼长（William）冲下场把即将挨打的同事拉到旁边 | 同事已被"品牌维护感"激起对抗情绪，**继续沟通只会升级冲突** |
| **T+1：询问诉求** | 「先生，是什么事情我可以帮你？」 | **开放式提问 ≠ 复述指责**——把客户从"卖假货"话术拉回真实诉求 |
| **T+2：目标拆解为 3 选项** | 「这个包我看到坏了：① 维修 / ② 更换 / ③ 像您说的卖假包·三件事不同处理方式」 | **把泛化愤怒拆解为具体选择** = 客户被迫理性化 |
| **T+3：解释每选项后果** | 卖假包 → 超出门店权限，须走公司法务邮件流程；维修 → 我马上帮你解决 | **把成本与收益摆到台面** = 客户自动选择最优路径 |
| **T+4：物理降温** | 倒一杯水 | **打断愤怒节奏 · 建立"被照顾感"** |
| **T+5：数据核实** | 让同事查购买记录 → 实际近一年（超过半年保修） | **事实澄清 · 但不用来羞辱客户** |
| **T+6：超预期方案** | 「维修价 4500，理论上要收费，但你是我们很好的客人，我可以申请免费维修」 | **超预期让步 = 关系账户存款** |
| **T+7：闭环重申** | 「你觉得这样处理好可以吗？还是坚持要投诉我们卖假包？」 | **给客户台阶 · 让客户主动关闭升级路径** |
| **T+8-10：握手致谢** | 客户握着 William 的手连说三次感谢离开 | **前 vs 后：从要动手 → 握手致谢，同一人两种状态** |

#### 3.2 SOP 底层设计原理

- **William 观点（[归纳]）：****客诉的本质不是回应愤怒，是帮客户澄清目标**——「卖假包」只是话术，真实诉求是**通过极端方式获得优待或赔偿**。
- **William 观点（[推理]）：**同事"激起品牌维护感"的错误在于**接住了话术却错过了诉求**——真正专业的做法是**跳过表层话术，直接对准底层目标**。
- **反直觉洞察（[推理]）：****客诉是 On Stage 的最高级考试**——不是靠话术平息，而是**帮客户重新组织他自己的目标**。

#### 3.3 案例的旁观者杠杆

- **William 补充（[原话]）：**闹得很大，一楼到二楼所有闲逛客人都在看着，事后"稀稀拉拉想鼓掌 / 鼓励眼神"——之后跟这些旁观客人沟通时**破冰和铺垫都不需要了**。
- **反直觉洞察（[推理]）：****一次高质量客诉处理 = N 个新客户破冰豁免券**——ROI 远超正常销售。

### 四、迪士尼原版 On Stage 三维沉浸设计（薇拉·迪士尼开园团队视角）

> **框架来源：薇拉 · 2016 年上海迪士尼开园团队 · 沉浸式舞台原版理论**

#### 4.1 第一维 · 环境渐变设计

- **薇拉观点（[原话]）：**「当你从加勒比园区走到梦幻世界，你会听到海盗歌曲慢慢变成梦幻音乐——你甚至不知道什么时候这个歌曲变了。」
- **薇拉观点（[归纳]）：**建筑 / 植物 / 演职人员服装 / 员工语言全部与环境融入，运用科技做**无感切换**——沉浸式体验 = 感知不到边界的过渡。

#### 4.2 第二维 · 演职人员 cast member + 换演出服

- **薇拉观点（[原话]）：**「我们叫 cast member（演员）——只要进入这个场地，我们就是演员。」
- **薇拉观点（[归纳]）：**员工进入迪士尼工作先进"演出大楼"→ 换演出服（冒险岛穿海盗风格 / 米奇大街穿米奇专属）→ **换服过程 = 心理暗示"我 ready 了"**→ 从后台走向前台 = 完全 On Stage 状态。
- **[推理]反直觉：****物理换装 = 心理换角色**——为什么演员的自我修养要"仪式化"，因为**仪式感是心态切换的开关**。

#### 4.3 第三维 · 工作语言不出戏

- **薇拉案例（[原话]）：**冒险岛员工去洗手间不能说"我要去洗手间"，要说「我要去航海了 / 我要去杀海盗了」；公主去休息时同事对游客说「公主要和王子约会去了」。
- **薇拉案例（[归纳]）：**巡游中中暑的迪士尼好朋友（如妮娜贝尔）无论多热**都不摘头套**——要坚持被带回后台再摘。
- **反直觉洞察（[推理]）：****"不出戏"是一种系统性设计而非个人自律**——语言 / 服装 / 环境三重保险共同锁住 On Stage。

### 五、爱的四个层次销售化（William 独家框架）

> **框架来源：William · 从心理学"爱的四层次"迁移到销售场景**

| 层次 | 定义 | 销售应用 |
|---|---|---|
| **① 慷慨美誉** | 喜欢一个人就永远不吝啬赞美 | 破冰第一句 = 具体赞美（不是空泛"你好漂亮"，而是"你的高跟鞋 + 主持这么长时间都没下场，专业状态让我佩服"）|
| **② 礼物** | 爱对方有送礼冲动 | Engage（订婚 = 付钱）关系需要主动送礼动作 · 呼应"engage"双关（订婚 = 客户付款仪式）|
| **③ Touch（碰触）** | 触碰是爱的表达 | **装模作样的 Touch**：试衣走出更衣室时扶肩看宽度 / 卷裤脚；试鞋时用手指按脚尖看长度——**表面是量尺寸，实际是构建成交概率**|
| **④ 精心一刻** | 烛光晚餐式的场景布置 | 为客人布置一个"专属时刻"（如产品试用体验环节 / 记住客户偏好的场景化服务）|

- **反直觉洞察（[推理]）：****销售的高级技巧根源不是"话术"而是"爱的原始表达"**——所有让人心动的关系动作都可迁移到销售场景。
- **[归纳]关键点：**Touch 环节的"装模作样"设计精妙——**给了 touch 一个功能性借口**（量尺寸），既完成心理连接又不越界。

### 六、隐私分享构建信任体系（William 独家框架）

- **William 定义（[原话]）：**「隐私是**他不说你就不会知道的事情**——不是限制级的隐私。」
- **William 观点（[归纳]）：**关系亲密度 = 隐私分享程度——**你知道的越少关系越远，知道越多关系越近**；夫妻关系密度 = 隐私分享深度。
- **William 案例（[原话]）：**「米莱告诉我他喜欢蓝色，这就是他的一个隐私」——**隐私 = 细节量化**。
- **William 观点（[推理]）：****不要觉得"我对客户关系很难进步"就沮丧**——从"赵先生"到"知道全名 / 行业 / 喜欢的东西"的每一步都是进步，**在某一个时刻这些信息会用到**。
- **William 案例（[归纳]）：**知道客户最近生了女儿并常晒朋友圈 → 后续可将这些信息**链接到印象塔（产品推荐）**上。
- **反直觉洞察（[推理]）：****隐私分享是"关系温度计"** ——不必焦虑关系的抽象好坏，只需盘点具体信息量。

### 七、线上经营与"不拉踩"原则（William）

- **William 观点（[归纳]）：**奢侈品线上销售相对落后（客单价高客户重视线下）——但**打字比语言更容易八卦**（客户会问"你们家 vs 别人家"）。
- **William 反直觉观点（[原话]）：****「你的高级来自于你永远不说别人坏话。」**——LV 员工遇到客户提爱马仕，正确应对是「爱马仕也是非常棒的品牌」，而非拉踩。
- **William 观点（[推理]）：****拉踩永远产生不了强连接**——你的专业 = 大方承认别人的优势 + 精准展示自己的差异化。
- **反直觉洞察（[推理]）：****"竞品夸奖 + 自我差异化"是奢侈品线上销售的通用打法**——广泛适用于任何品牌矩阵中的品牌销售。

### 八、"我不赚你钱是虚妄清高"（William · 呼应 025 米莱同款观点 · 双集共识）

- **William 观点（[原话]）：**「不要试图去掩盖自己的商业目的——这是一个掩耳盗铃的动作……不要有这种'我要赚你钱我就心虚'的态度。」
- **William 观点（[归纳]）：**LV 员工在店里穿工服不心虚客户付钱，只觉得**"你付得不够多"**——**牌子挂在那里 = 商业目的天然合理**。
- **William 观点（[推理]）：**当**你自己相信"卖东西 OK"**的时候，付钱的人才会觉得"给你付钱 OK"——**自信心是双向的镜像**。
- **William 案例（[原话]）：**视频号博主做知识分享中间植入广告，评论区从没反对，反而说「我就喜欢你这么务实的样子」——**坦诚的商业目的 > 遮遮掩掩的清高**。

### 九、因客而异达成销售（LVs 培训体系 · William）

- **米莱观点（[原话]）：**「所有销售最后都应该是 win-win——你是把产品和服务介绍给了特别匹配这个产品和服务的人，就跟媒婆介绍对象一样。」
- **米莱观点（[归纳]）：**媒婆分成功率高低 = **洞察客户需求准 + 提供品品质好 + 匹配度高**。

- **十一段反直觉（[推理]）：**销售不是零和 · 是精准匹配。

### 十二、面具 & 舒适圈优先原则（William + 米莱）

### 案例 1：广州 LV 店 · 10 分钟客诉反转（本集核心案例·全档最有名实战案例之一）

- **背景：**William 时任广州 LV 二楼楼长。一楼一位五大三粗男士拿着开裂的包冲进店，声称"LV 卖假包用了半年就坏"，对同事情绪激动到即将动手。
- **同事的错误：**被"品牌维护感"激起对抗——"从店铺出去的产品不可能是假的"→ 不断在真伪话题上纠缠 → 客户出离愤怒。
- **William 介入的完整 SOP：**（详见"结构化要点 · 三、10 分钟客诉反转 SOP"分钟级节奏表）

- **[归纳]关键洞察：****客诉的表面是话术，底层是诉求**——同事接住了"卖假包"话术，William 跳过话术直接对准"客户想要优待"的底层目标。
- **[推理]反直觉：****客诉是 On Stage 的最高级考试 · 也是最强大的口碑放大器**——一次高质量客诉处理 = N 个新客户破冰豁免券。

### 案例 2：Ritz-Carlton "绅士淑女服务绅士淑女"口号

- **[推理]延展：****"以客为尊 ≠ 顾客是上帝"**——顶级酒店集团用这句话完成了对"上帝论"的正面替代。

### 案例 3：上海迪士尼演职人员中暑不摘头套

- 上海迪士尼夏日巡游中妮娜贝尔等演职人员中暑 → **在任何情况下都不摘头套**，坚持被演值员带回后台再摘。
- **[归纳]背后设计：**"神奇不能被破坏" = 迪士尼把 On Stage 提到了**员工职业操守**的层级。
- **[推理]反直觉：****不出戏是系统性设计而非个人自律**——语言 / 服装 / 环境三重保险 + 员工职业培训四重锁定。

### 案例 4：LV 员工遇客户提爱马仕的"专业应答"

- 客户在 LV 店提「我喜欢爱马仕」→ 专业销售的正确应答：「爱马仕也是非常棒的品牌」。

- **[推理]反直觉：****拉踩不产生强连接 · 反而暴露不安全感**。

### 案例 5：Touch 环节"装模作样"卷裤脚 / 按脚尖

- 卖衣服的同事在客人从更衣室走出到全身镜前时，扶着他的肩膀装模作样看肩宽 / 卷卷裤脚；试鞋时用手指按一下脚尖看长度。

- **[推理]反直觉：****Touch 提升买单成功率**——人类爱的表达机制在销售场景的迁移。

### 案例 6：William 破冰"高跟鞋 + 主持 + 佩服"具体赞美

- **破冰话术（[原话]）：**「你今天这双高跟鞋真的太漂亮了——我在想说你是怎么坚持下来的，你在舞台主持了这么长时间，你的鞋子又漂亮，可是我一直很担心你的脚，你的专业状态真的让我非常佩服。」
- **[归纳]关键点：****慷慨美誉 ≠ 空泛赞美**——具体 + 观察细节 + 关切 = 慷慨美誉三要素。

### 案例 7：南京 Gucci 打烊广播"相聚的时光总是短暂的"

- **[归纳]关键机制：**广播本身就是**品牌 On Stage 的收尾仪式**——不催促客户、把选购权交给客户、用诗意包裹商业。
