# 004 - 04｜高精力超级个体：1 个人如何干出 1 个销售团队的业绩？

## 摘要

《我是销冠》第 004 集，主播米莱把公认「特别自由、不走寻常路」的**关雅荻**（狂喜播客节发起人、艺人企业创始人、越野跑推广者）拽回到节目框架里，围绕**"一个超级个体如何在没有团队的情况下，做出一个销售团队的年度业绩"**这条主线，把关雅荻从辞职以来 12 年的生活方式与经营哲学一次性摊开——从体能、具身经验、随波逐流，一路讲到艺人公司模式、涌现思维、反粉丝观、广义销售论。

对普通听众来说，本集不是「销售话术清单」而是**"一个人怎样活成自己最有效的销售武器"**的完整心法：**① 精力管理是伪问题，真正的问题是体能**——精力是二楼、体能是地基；**② 30 岁前深挖专业 7 年，30 岁后可以"随波逐流"**（跟随脑电波与心流，非世俗财富自由目标）；**③ 一个人的艺人企业**——拒绝对赌、拒绝利润最大化、社会创新放第一位；**④ 涌现思维 + 极致原则**（狂喜播客节两天塞 102 场、狂喜观影会一年 60-80 场）；**⑤ 无人设 = 无塌房**——不要打造人设、只做自己；**⑥ 反粉丝观**——只要关注者不要粉丝，防止主体性被反向压倒；**⑦ 广义销售 = 销售自己**——产品是价值的载体，个人 IP 才是终极商品。

适合三类读者：**已经有一定专业积累（工作 5-8 年）、想探索"一个人也能做事"的路径**；**做内容 / 做 IP / 做私域运营、思考如何避免被"粉丝"反噬**；**想理解"广义销售"——把自己作为最高价值单元来经营**的职场人与创业者。**注意**：本集听感偏散、口语化极重，主线是"边聊边被框回来"，需要读者自己抽出脉络。此篇笔记提供 12 节主脉 + 6 组关键问答的骨架，作为反复回听的索引。

> 我们经常讲的一个思维，就是一定要让客户觉得他赢了。

> 怎么能够把这个销售做好？我选择的是我们直指最核心的价值。

## 核心要点

### 1. 精力管理是伪问题：真正的问题是体能

关雅荻反复被问「你精力这么好、怎么做精力管理」，他的回答很反直觉——**"所有的精力管理问题都是体能或者体力问题"**。

他的比喻：精力是**开花结果的美好果实**，大家总以为可以直接摘；但精力其实是**体能这栋楼的二楼**——你必须先打好地基（日常规律作息 + 阻力训练 + 心肺训练 + 一点点身体打磨），二楼才会自然生长出来。大部分人的现状是"地基一团乱麻、三通四平都没做，却光盯着电脑里二楼样板间的精美设计图"。

**通用启示**：任何"我怎么才能精力充沛"的问题，都要先降维成"我的体能训练做够了吗"。搞不定地基就想抄小道搭个"空中楼阁的小梯子"直接上二楼，只会适得其反。

### 2. 具身经验（In-body Mind）：身体是综合信息接收器

关雅荻自称「经验主义者」，反复强调**"具身不只是依赖大脑，身体的感受力非常重要"**——他从环球帆船赛回来后越发笃定这点。

他的观察：我们习惯把"心智"里的"智"绑到大脑，好像"心"跟心脏才有关。**其实"心"指的是整体身体**——皮肤、内脏、肠道菌群（第二大脑）都是信息接收器，都是与自然界互动的反馈机制。日常生活中我们跟自然与城市的互动方式太过单一，导致大量"算力"和"感受能力"被荒废——原始语料（raw data）不丰富，输出的算法自然也贫乏。

**方法**：主动把身体放到极限或极致的场景里"超频"，让身体这台综合接收器采集更丰富的原始信号。他自己的做法就是从极限运动（越野跑、帆船）到"把上海这座钢筋混凝土大都市推向极致"——用高频、高密度的线下活动激发感受器。

### 3. 随波逐流 ≠ 随大流：跟随的是自己的脑电波

「随波逐流」在关雅荻这里被彻底重解——**"波"是他自己的脑电波，"流"是心流状态**。

**核心操作**：日常生活中，主动让心流体验的比例越大越好。刨掉吃饭睡觉，剩下的"从事创造力活动"的时间里，心流占比从 1% 提到 10% 再到更高——录播客常常忘记时间就是他的高频心流场景。

**红线**：一定要有前提——**30 岁前不能随波逐流**。30 岁前要在某个专业赛道深挖 ≥ 7 年（可以在同一赛道内轮岗），达到能与行业前沿对话的水平；有了自食其力的基本盘、有了同行给的基础尊重之后，才有资格谈"随波逐流"这种奢侈的自由选项。**理由**：AI 时代来临前是"混日子越来越难混"，你没有专业地基就"随波"，是把自己扔进 UBI 之前的悬崖。

### 4. 30 岁前深挖 · 30 岁后释放：融会贯通的两阶段模型

关雅荻把人生粗分两阶段：

- **第一阶段（30 岁前）**：本科毕业到 30 岁前，聚焦一个赛道（专业 / 兴趣 / 专长任选），**不能少于 7 年**。可以在赛道内多个岗位轮转，最终对整个行业前沿有深度洞察。这是"打通融会贯通所必需的地基"。
- **第二阶段（30 岁后）**：地基打牢之后，可以选择继续在窄领域挖到 Top 10 / Top 5，也可以像他一样**"横向释放"**——把过往积累的元能力（如制片管理、协同调度、决策洞察）迁移到新领域。他自己从电影 → 越野跑 → 播客 → 学业 → 艺人公司，切来切去的底色是"同一套元能力在不同赛道上的复用"。

**判断句**：过往的具体成绩不必刻板复制粘贴——**你只抓管理背后真正想达到的效果 / 价值就够了**。

### 5. 一个人的艺人企业：拒绝对赌、社会创新第一

关雅荻从 2013 年裸辞开始经历两个创业阶段：**2013-2018 年小团队创业**（越野跑推广，账面稳定亏损，钝刀割肉三年半，主动瘦身、回购合伙人股份、把公司壳留着）→ **2019 年至今的"一个人艺人企业"**（也叫"艺人社会企业"）。

**这家公司的四条硬规则**：
1. **社会创新放第一位**——不是不要利润，是"利润最大化不在考虑范围"
2. **从不签对赌协议**——所以"公司做不下去是很安全的"
3. **拒绝需要十几人以上团队的项目**——不再做电影制片人（几百人）、不做十几人以上的创意公司
4. **只做一个人能快速决策、能主推进的事**——狂喜播客节志愿者 100 多人 OK，因为决策还在他一人手里

**关键选择**：所有超出这个边界的机会默认 say no；日程本默认空白，可以随时改；不用传统公司管理逻辑管理自己的生活——**"我不知道这么说对不对，但这可能更有助于创造力的迸发"**。

### 6. 视觉化预判：从制片理念挪到日常决策

关雅荻的决策底层机制被他称为**"脑内视觉化"（Pre-visualization / Priization）**——沿用自电影行业的视觉预览：拍真人之前先用动画把全片过一遍，跟灯光、摄影、美术、动作等各部门拉齐。

他把这套挪到日常决策——**"事情在我脑袋里呈现的清晰度、颗粒度、完成度越高，我对它的把握就越大"**。

**具体案例**：狂喜播客节第一届开场前两个月（6 月 5、6 号）在他脑中已经呈现的画面，跟 8 月 10 号开幕当天几乎完全一致——樊玉如进门看一眼就说「这事成了」，因为画面早已在关的脑里落地。

**推广逻辑**：拍电影其实"开机前 80-90% 已经决定成败"——剧本、筹备、选角、视觉预览做扎实了，后面就是把预览拍出来。生活里也一样：能不能在脑内清晰视觉化，是判断"这件事我能不能做"的门槛。**内观 + 神经网络式的多版本推演**在 10-15 秒内会给出「行 / 不行 / 卡住」三种结果之一。

### 7. 涌现思维 + 极致原则：狂喜播客节的 16 字方针

狂喜播客节的核心方针是关雅荻直觉弹出、一年反复咀嚼后确认的 16 个字：**"去中心化、自组织性、超量供应、开源分享"**。

- **去中心化**：不区分主播 / 平台 / 场地方 / 观众 / 志愿者的身份阶层，跳出来找一个更高的、大家共同可及的价值
- **自组织性**：给规则和场景，让人和人之间的关系自己涌现
- **超量供应**：两天塞 100+ 场 90 分钟的开放对话（第四届 102 场），把"最小规模的涌现"推向密度极致——**"你想想砍掉一半，我就一点兴趣都没有了"**
- **开源分享**：每届活动决算对外公开，把执行透明化到"你自己找公关公司来干也就这个价"

**为什么要推向极致**：**"我不做到一定的量，根本就换不来我期待的那种反馈"**。前三届都在亏钱（第三届靠 4 家合作方几万现金差点持平，账上就差 1 万），但他认为"社会创新层面已经大赢"。

**通用启示**：想在小场域制造"涌现"，密度是唯一杠杆——观众来回交错的人次、场次、时间压缩到某个临界点，才会自然长出新的连接。

### 8. 无人设 = 无塌房：不要拥有房子

关雅荻反复强调**"我从没打造过人设"**——所以有人调侃"关雅荻塌房无人上网"时他觉得特别好笑。

**心法**：
- **不要打造人设**——不管是实体的财产（房子）还是虚拟的人设，一旦"拥有"就有塌的风险
- **只做自己**——每个阶段大变样，别人来贴任何"人设"都建立不住，所以**"塌无可塌"**
- **主动 self-roast**：他比任何人更先承认自己"哪不好"——"你说我我就是，比你跌 100 倍也 OK"，像明星本人先把偷拍照放出来一样，让攻击的路径失效

**理由**：**"人无完人，放在大众视野下永远有一个角度切进来能挑你毛病"**——你打造得越精致，塌房面积就越大。不如从一开始就展示真实的自己，接受度反而更稳定。

### 9. 反粉丝观：只要关注者，不要粉丝

关雅荻明确拒绝"粉丝"这个身份，只接受**听友 / 观众 / 关注者 / Follower**。

**核心区别**：
- **粉丝 = 主体性反向压倒偶像**——表面上说"我粉你"，本质是"以退为进的控制欲"：粉丝集结成群体后会**把主播的选择拽进他们的期待框架**里
- **关注者 = 松耦合的同频者**——可听可不听、可喜欢可不喜欢，主播的主体性不被侵蚀

**冲突点**：粉丝会**固化你的成长和面对不确定性的能力**——你越想探索新赛道，粉丝越会拽你回原来的样子。这跟他坚持"随波逐流、主体性优先、每几年大变样"的底层追求根本冲突。

**代价**：坚决不做社群、不做私域粉丝群（通票群除外），可能会失去一些商业化机会——**"我不知道会付出多大代价，但我坚持多久算多久"**。

### 10. 让客户觉得他赢了：核心销售心法

在整场看似发散的对谈里，关雅荻不经意抛出了他的销售底层公式——**"一定要让客户觉得他赢了"**。

米莱的进一步展开更精准：**"你要比观众聪明一点点，但你给他的东西还得让他觉得他比你聪明"**——不是真的"让他赢"，而是**给到期待之外的价值、同时让他保持"我掌控了这场交互"的感受**。

**推广**：这条公式对内容创作、电影、播客、销售全通用——你要预判观众的期待、然后在期待边界的**外一点点**给他惊喜；边界之外太远就"作死"，边界之内就"无聊"。分寸感是核心手艺。

### 11. 广义销售论：终极商品是"你这个人"

关雅荻在结尾把整场对谈拉高到"广义销售"的层面——**"这期节目我不想聊传统 To C 销售策略，我想聊你个人 IP 的销售观理"**。

**核心命题**：
- **你所有的产品（线下活动 / 播客 / 课程 / 文字）都是价值的载体**，本身不亏钱就够（"别人以为我在搞慈善"）
- **真正的商品是"你这个人"**——你的品味、判断、精神气质、独品，成为品牌方邀请你、观众来场的根本理由
- **收入结构**：底层产品做到收支平衡 → 累积个人 IP 影响力 → 品牌方 / 甲方为"你这个人"付高价（讲课、代言、深度合作）

**关键路径**：**"把自己作为商品来销售"**不是短期人设包装，而是长期投喂——具身经验、跨领域积累、生活方式的示范、精神能量的传导。这跟前面反粉丝、反人设是一体两面：**你不要打造一个"人设商品"，你要把自己活成一个越来越丰满的"个体商品"**。

### 12. 面对 AI：只积累"无法被取代的"

关雅荻的收尾极干脆——**"随着人工智能发展，除了你肉身之外的东西，几乎所有一切都会逐渐达到可取代的水准。既然如此，为什么不直接奔着那个最终极不可替代的东西（具身感受 + 具身经验）积累它？"**

**判断框架**：
- **会被 AI 取代的**：知识型输出、模板化服务、可解释的技能、纯线上内容
- **无法被 AI 取代的**：**具身感受 / 具身经验 / 亲身在场的能量传导 / 只有肉身能承接的偶然涌现**

**行动建议**：
- 别再一层层追着"哪个技能又被取代了"跑——那是徒劳
- 直接把精力投在**只有肉身能做的事**上——线下活动、面对面链接、极限体验、跨领域的具身探索
- 他自己的完整押注：**只做线下**（3C Studio + 狂喜播客节 + 狂喜观影会），线上作为触点、线下作为核心——因为"线上正在变得越来越廉价"

## 关键问答

**Q：为什么你反对"精力管理"这个说法？**
A：因为大家把它当成"低垂的果实"想直接摘。真相是精力只是果实，**体能才是那棵树的地基**——规律作息 + 阻力训练 + 心肺训练 + 兴趣爱好的身体打磨。地基没打就想上二楼，只会适得其反。别问"怎么精力管理"，先问"我的体能训练做够了吗"。

**Q：30 岁前该不该"随波逐流"？**
A：**不该**。30 岁前必须在一个赛道深挖 ≥ 7 年（可在赛道内多岗位轮换），达到能与行业前沿对话的水平——这是"融会贯通"的地基。30 岁后有了自食其力的能力、有了同行的基本尊重，才有资格"随波逐流"。前提是经济上能给自己留 1-2 年可承受的亏损空间。

**Q：为什么坚决不打造人设、不做粉丝？**
A：**"打造人设 = 埋塌房的种子；养粉丝 = 让自己的主体性被反向压倒"**。人无完人，人设越精致塌房面积越大，不如从一开始展示真实自我，反而塌无可塌。粉丝群体会用"我们喜欢的样子"拽住你的成长，与"每几年大变样、持续探索新赛道"的追求根本冲突。宁可要松耦合的关注者。

**Q：一个人怎么做出一个销售团队的业绩？**
A：三条线——**① 只做自己能主决策的事**（拒绝需要十几人以上团队协作的项目）；**② 把每件事做到极致密度**（狂喜播客节两天 100+ 场、狂喜观影会一年 60-80 场），涌现只在密度临界点之上出现；**③ 把自己作为终极商品**——底层产品收支平衡就够，真正的收入来自"你这个人"作为品牌 / 讲者 / 合作方的高价值调用。

**Q：狂喜播客节亏钱亏了三届，为什么还继续做？**
A：**因为他兜底**。所有"激进的创新"必须有一个"愿意为最糟结果承担后果的兜底人"，这个人是关雅荻本人。他的账算法不是"利润率"而是**"社会创新价值 + 个人 IP 积累 + 具身经验积累"**——前三届亏几万到 1 万，但换来了 16 字方针的公开、志愿者 70% 回头率、观众 ~50% 复购率、以及"这个人真在做事、不忽悠"的品牌沉淀。第四届开始盈亏平衡就足够。

**Q：AI 时代普通人的最佳押注是什么？**
A：**积累"只有肉身能做的事"**——具身感受、具身经验、面对面链接、亲身在场的能量传导。别再追着"哪个技能又被 AI 取代了"跑，那是徒劳的猫鼠游戏。直接把精力压在最不可替代的那一层——线下、真实、身体、当下——让 AI 帮你处理其他所有可解释、可复制的部分。
