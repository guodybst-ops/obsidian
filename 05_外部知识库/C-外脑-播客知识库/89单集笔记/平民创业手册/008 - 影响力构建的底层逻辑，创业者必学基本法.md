# 008 - 影响力构建的底层逻辑，创业者必学基本法

## 摘要

这一集用“势能”和“做功”解释影响力：影响力不是静态名声，而是调动人、财、物的能力；它会自然消耗，必须通过持续输出、交付、交互、广告、事件和价值创造来维持。杨涛把个人影响力定义为可见度、正面声量、持续输出价值所形成的信任，而信任本身已经接近钱。

他反对普通人把“做 IP”当作神圣梦想，认为 IP 是结果，是提供价值、解决问题、业务和内容长期沉淀后的副产物。真正可操作的是围绕注意力、信任、够用指数和转化行为去做正向循环：消耗势能去变现，但如果变现行为本身能提供真实价值，它又会变成新的做功。

整集还讨论了信任的使用边界。杨涛提出“先相信，直到露出破绽”，因为相信能降低决策成本；同时也提醒影响力有崩坏点，推荐不好的东西、贱卖信用，会让人产生失望。避免崩坏的方式，是不断提高自己的够用指数、自我期待和市场定价。

## 金句收藏

- 影响力就是调动人财物的能力。
- 不输出不发生，不做功就泯然众人。
- 信任的纯度和体量，就是一个人势能的大小。
- 信任就已经是钱了。
- IP 是结果，是价值的副产物，是业务的副产物，是结果的副产物。
- 注意力在哪里，钱就在哪里；钱在哪里，注意力就在哪里。
- 势能就是用来消耗的，品牌就是用来霍霍的。
- 先相信，直到露出破绽。

## 核心要点

### 一、影响力会自然消耗，持续做功是防御动作

- 杨涛把影响力比作势能，获得势能必须不断做功。
- 个人关系也是如此：今天能借到的钱，不代表两年后仍能借到同样数额，因为朋友的财务状态、关系密度和外部环境都会变化。
- 品牌同样需要持续做功。可口可乐即使市场占有率极高，也要持续广告和代言，因为停止做功后心智占有会下降。
- 手机淘宝、明星、博主等例子都说明：如果停止更新、停止事件、停止交互，打开率、关注度和变现能力会逐渐降低。

### 二、个人势能来自可见度、正面声量、价值输出和信任

- 原文给出的势能定义包括：在人们视野里的可见度或频次，正面的声量，以及不断输出给人们的价值。
- 价值既包括实际价值，也包括情绪价值，最终都会转化为信任。
- 正面声量很关键，因为频繁出现不等于正向做功。群发、刷屏、低价值日更可能是在副做功。
- 当输出质量不够、价值不足时，过度日更会让人取关、屏蔽，反而失去再次触达机会。

### 三、日更不是天然正确，关键看它是自我记录还是影响力做功

- 如果日更是为了悦己、记录美好生活、群体认同，杨涛表示支持。
- 如果日更目的是获取影响力，就不能忽视读者注意力成本。无价值日更是在消耗别人对你的信任。
- 在注意力稀缺的时代，点开文章、收听播客本身已经是信任消耗。
- 相比低质量日更，原文更推崇磨出一篇能穿透圈层、有传播属性的爆文。

### 四、普通人不要神化做 IP，IP 是价值交付后的结果

- 杨涛认为普通人真正意义上做成 IP 很难，比上清华北大还难很多。
- 很多人说想做 IP，本质是想获得更便宜的流量，或让转化更轻松。
- 这些目标未必必须通过“IP 梦想”完成，也可以用流量打法实现。
- 原文借制药公司的座右铭类比：药是用来治病的，利润随之而来；IP 也是提供价值、解决问题之后自然出现的结果。

### 五、变现不一定伤粉，关键看转化本身是否提供价值

- 常见看法认为知识博主一卖货、带货、开课，就是消耗势能。
- 杨涛承认势能本来就是用来消耗的，但提出一个更重要的条件：如果推荐、带货、开课让用户获得真实价值，转化行为本身就是另一种做功。
- 例如用户说“要不是你我怎么能加入这么好的星球”“你推荐的书真棒”，这类转化不会伤粉，反而增强信任。
- 这背后依赖的是“够用指数”：推荐者的认知和信息源刚好能帮助受众提高效率、降低决策成本。

### 六、避免影响力崩坏，要提高够用指数和自我定价

- 影响力的崩坏点出现在推荐不好的东西、为了钱把自己卖得太低、让用户产生“终究还是一样”的失望时。
- 杨涛认为解决方法不是永远不变现，而是不断提高够用指数，让自己的势能和自我期待都提高。
- 当自我定价高于市场给出的诱惑价格，就不容易贱卖自己的信用。
- 他还提出一个判断：如果犹豫要不要推荐，就不要推；推荐时内心应该是笃定、淡定、坦然的。

## 关键问答

**Q1：影响力到底是什么？**

A：原文把影响力定义为调动人财物的能力，也是一种通过别人乐于接受的方式改变思想、指导行为、辅助决策的能力。它的底层是信任，信任的纯度和体量决定势能大小。

**Q2：为什么影响力必须持续做功？**

A：因为影响力会自然消耗。关系会变淡，朋友的资源状态会变化，用户会被新品牌、新内容、新人群分走注意力。如果不持续交付价值和保持可见度，势能就会下降。

**Q3：为什么日更可能是副作用？**

A：如果日更内容没有价值，只是低质量刷存在感，就会消耗读者注意力和信任，导致取关、屏蔽或失去触达机会。日更若用于自我记录可以，但若用于影响力做功，就必须关注价值密度。

**Q4：普通人应该怎么理解 IP？**

A：不要把 IP 当成先验目标。杨涛认为 IP 是结果，是提供价值、内容输出、解决问题和业务沉淀之后的副产物。想要便宜流量和更轻松转化，也可以通过流量打法实现。

**Q5：影响力变现怎样才不伤粉？**

A：关键是变现行为本身要提供真实价值。好的推荐、课程、社群、书单会降低用户决策成本，让用户觉得“幸好有你推荐”。这时势能被消耗后又能转化为新的势能。

**Q6：面对能影响自己的人，该不该先相信？**

A：原文给出的方针是“先相信，直到露出破绽”。这是一种决策路径短、成本低的当前最优解；当自己认知提升后发现对方不过如此，或对方出现表里不一、知行不合等破绽，再停止相信。
