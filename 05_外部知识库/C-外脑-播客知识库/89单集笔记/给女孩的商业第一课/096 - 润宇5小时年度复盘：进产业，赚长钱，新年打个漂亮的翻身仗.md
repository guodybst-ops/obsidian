# 096 - 润宇5小时年度复盘：进产业，赚长钱，新年打个漂亮的翻身仗

## 摘要

这是斯斯和润宇在 2025 年双十二录制、跨 2026 年播出的年度收官对谈，长达 5 小时，是给女孩系列自开播以来密度最高的一集，也是润宇 2025 年最系统的一次对外框架输出。整期节目从"2025 年知识付费行业已死"这个惊悚判断切入，一路把新媒体行业的过去、现在、未来拆解到底层。

**上半场（问题诊断）** 从视频号红利在 2025 年 9 月宣告结束讲起。润宇把这四轮流量红利（微博 → 公众号 → 短视频 → 直播）视作一条完整曲线，指出微信生态作为 8 亿日活的"最后一个大平台"关门之后，"高流量"这三个字作为一个可以支撑十年叙事的红利资产就正式退场。与之伴生的公域-私域界限也在消融——加了微信不等于是你的人，私域已经进入 3.0 阶段（筛选而非圈人）。"知识付费"作为流量红利的 B 面，作为一个能允许你把"空气"（课程）卖给你的方案，在四轮红利喂完存量之后同样走到尽头。

**中场（用户四分层）** 润宇给知识付费的消费者画了一张完整地图：K12 学生 / 职业培训 / 商学院 / 想搞钱者。前三类是真需求会长期存在，最后一类才是过去十年知识付费黄金期最主要的付费主力。他借"想进步的人 vs 想改命的人"这一对区分，指出改命的关键从来不是知识而是挑战，因此这波"改命型付费"必然萎缩。他从这一层引出五层营销漏斗：接触 → 理解 → 认同 → 买单 → 传播，判断整个新媒体行业的竞争已经卷到第 5 层（人均精细化运营）。

**下半场核心（三种活法与河床模型）** 面对"知识付费已死"，1个 IP 未来的活路只有三条：**内容消费付费**（如小宇宙付费播客、付费电影）/ **技能培训**（K12 型 / 蓝翔型职业教育）/ **营销服务**（To B 深度绑定产业）。润宇公开了他自己已经走通的第三条路——大厂直播打法。这不是一个直播技术活，而是一个进入企业决策中心的战略入口：老板一年只憋一次年会 / 周年庆，那半小时的高光时刻他会把公司的战略、产品、心思全部倒给你，你趁这个窗口植入完整的年度营销方案。他进一步给出了 2026 年新媒体营销的完整架构——**"河床模型（合床模型）"**：两侧堤坝是老板 IP + 大厂直播，中间河床是日常营销界面（短视频 / 投放 / 日常直播），用户像流水一样被两侧堤坝拦住、留在中间河床。

**深水区（IP 资本化）** 他公开了刘润三段教诲的完整下游化解读：不要死磕 C 端 / To B 要找更贵的人的更贵问题 / 老板 IP 是发动机不是终点。核心变现路径是 **"三步收费模型"**：知识免费换流量 → 咨询免费挑客户 → 服务收费做深度 → 最后一步是资本化（销量杠杆 / 预算杠杆 / 资本增值杠杆）。他还给出了 **"挑客户四层"**：项目外包 → 代运营 → 外挂 CMO → 合伙人，四层责任逐步加重、收益逐步放大。以及产品化拆解的 **"三差竞争演进"**：认知差 → 信息差 → 执行差 → 资源差。

**方法论层（三个底层动作）** 润宇解释了他为什么现在开始服务"引领型高端品牌"——因为"高端品牌 = 持续引领需求，创造用户新供给"，只要在抄就一定不是高端。他从"边缘发起创新"讲到"结构洞"——蓝翔为什么至今没有出现在新媒体行业，是因为共识已经形成但产业整合还没启动，中间存在人才结构洞。而进入产业最有效的三个动作是：**变回用户 → 进入场景对话 → 找原点用户**（原点用户 + 原点任务 + 原点产品 = 最小营销闭环）。

**心法层（回归母体）** 最后一小时是全场高光。斯斯问润宇：如果所有能想的都想了、所有能做的都做了，还是想不明白，怎么办？润宇给了一个字：**回归母体**。母体不是老婆孩子同事，是客户；心法不是自我审视，是"敬畏用户"。他解释自己 2025 年过得比 2023-2024 差，是因为主动离开顺风顺水的旧码头，去到没人到过的新码头——熬当中受苦受难，是每一个先行者必须付出的代价。他把这个也叫做"企业家精神"：在面对不确定性、面对常识的碾压、面对团队和客户的质疑时，还能顶住。

**收尾（商业叙事构架）** 全期最落地的方法论集中在最后一小时：河床模型 / 商业叙事构架（起点=产品，终点=向往）/ 原点用户三角 / 内容消费 vs 技能培训 vs 营销服务 三种知识付费未来形态。整期是对 2026 年新媒体行业最完整的一次内部揭牌。

## 核心要点

### 1. 视频号红利在 2025 年 9 月宣告结束

- 微信生态是最后一个 8 亿日活的商业闭环平台。它 2025 年 9 月开始规则收紧、优质商家筛选、私域倒流被压制。
- 平台的商业模式是撮合（marketplace），成熟之后一定会把交易关进监管，就一定不能允许流量从直播间倒到私域外的地下室成交。
- 三个"关门信号"：视频号红利在 2025 年 9 月转折 / 群响从"搞流量来群响"改口"陪跑年轻创业者" / 各平台大 V 集中退网。
- 广义"高流量"这三个字作为一个能撑起十年叙事的红利资产，正式退场。

### 2. 私域 1.0 → 2.0 → 3.0：加人不等于认同

| 阶段 | 特征 | 时间 | 备注 |
|---|---|---|---|
| 1.0 | 亮码就能加 | 2010-2013 | 微商时代 / 电子秤扫码 / 领资料的鼻祖 |
| 2.0 | 领资料激活 | 2015-2022 | 三个字：领资料。删粉率高达 30% |
| 3.0 | 筛选而非圈人 | 2025+ | 加不加私域跟点不点关注越来越像 |

- 关键判断："我不再关注谁离我而去，我只关注谁留下来了。"
- 会员专区 365 + 7 天无理由 = 用极低成本快速筛掉不适合的人。
- 公域和私域正在合流。人心（用户是否认同）大于渠道。

### 3. 消费者需求的五层营销漏斗

```
接触 → 理解 → 认同 → 买单 → 传播
```

- 前四层是营销漏斗的传统结构。
- **第 3 层"认同"** 是分水岭：喜欢 or 讨厌都是认同；怕的是冷漠。
- **第 5 层"传播"** 是内卷终极目标——今天新媒体行业已经卷到"人均精细化运营"。
- 当所有玩法都透明（闲鱼 9.9 → 直播间免费），大家真正在竞争的不是话术，而是供给差异化——过分强调话术离诈骗只有一步之遥。

### 4. 知识付费四类真实用户地图

润宇画了一张完整的知识付费用户地图，指出过去十年最火热的付费主力其实是第 4 类：

| 类别 | 需求 | 供给形态 | 未来 |
|---|---|---|---|
| K12 学生 | 天职学习 | 学而思 / 新东方 | 真需求长存 |
| 职业培训 | 上岗谋生 | 蓝翔 / 新东方厨师 / 火锅学校 | 真需求长存 |
| 商学院 | 持续经营学习 | 得到 / 混沌 / 樊登 | 真需求长存 |
| 想搞钱者 | 想改命但没业务 | 各种个人 IP 陪跑 | 逐步萎缩 |

- 第 4 类用户是过去十年最给行业送钱的一群，但**改命的关键从来不是知识，而是挑战**。
- 大众心里跟"不确定性"疏远，考公 / 大厂 / 期望明确愿景——一旦选择确定性，就没有挑战，就不成长——反过来买课，越买越没用。
- 得到之所以稳，是因为它锚定的是"在干事的中层力量"（企业创始人 / 中层栋梁 / 政府要员 / 真挑战人群），这些人的学习是真需求。

### 5. 知识付费 = 流量红利的 B 面

- 知识付费不是产业，是**流量红利的伴生物**：
  - 罗辑思维借公众号红利起来
  - 樊登借抖音切片红利起来
  - 董十一借直播红利起来
- 内容释放的本质是让用户能在短时间内建立"高额信任"以替代面销。三轮内容红利（公众号 / 短视频 / 直播）过完，没有新的更大内容渠道出现，增长就到顶了。
- "空气产品"（课程）能卖出去，本质靠的是信任。而信任靠面销以外，还有内容释放来加速。

### 6. 三种未来的知识付费形态

| 形态 | 本质 | 案例 | 变现路径 |
|---|---|---|---|
| **内容消费** | 付费内容（不追求上岗） | 小宇宙付费播客 / 付费电影 / 得到掉量后转型的方向 | 订阅制 / 打赏 |
| **技能培训** | 打执行差，把执行力交付出去 | K12 / 职业教育 / 车间主任培训 | 学费 |
| **营销服务** | To B 深度绑定产业 | 润宇的大厂直播 / 全年营销顾问 | 服务费 + 分成 + 资本化 |

- 一句判断："知识不付费，山药来付费"（大健康 / 瑜伽的本质就是"我给你上完课，然后我再把东西卖给你"）。
- 一句预警："绝大部分上个年代的操盘手都得掉队。"

### 7. 三差竞争演进（认知差 → 信息差 → 执行差 → 资源差）

行业竞争的四个阶段：

```
认知差（萌芽期）→ 信息差（早期）→ 执行差（成熟期）→ 资源差（终局）
```

- 新媒体行业目前已经卷到 **执行差 → 资源差** 的过渡段。
- 认知差信息差在直播间免费讲、9.9 引流课，已经不值钱。
- 培训只有在"执行差"这一层才是刚需——"我会开连锁酒店，你不会，我培训你"。
- 未来的高价服务只能靠资源差（帮头部客户降低不确定性，用小小的服务费撬动他们的大额预算）。

### 8. 挑客户四层（介入深度 × 责任 × 收益）

从浅到深，四种介入模式：

| 深度 | 模式 | 客户体量 | 责任 | 计费方式 |
|---|---|---|---|---|
| 最外层 | 项目外包 | 任意 | 交付一次性成品 | 单项目结算 |
| 中层 | 代运营 | 千万级 | 帮干活但不进决策中心 | 服务费 |
| 内层 | 外挂 CMO | 千万-亿级 | 对营销 KPI 负责 | 年薪 + 分成 |
| 最深 | 合伙人 | 亿级以上 | 对战略负责 | 股权 + 分红 |

- **核心洞察**："这四个是财务区别，不是事儿的区别。"
- 100% 收益 → 100% 成本 = 自己干。想少承担成本 = 合伙 / 外挂 / 项目。
- **主动退出的心法**：如果甲方不让你进决策中心，宁愿主动退回代运营外面 → 因为机会成本更贵。

### 9. 河床模型（合床模型）：2026 年新媒体营销三板斧

润宇 2025 年最原创、也是他"没干呢，你就给我招来一帮竞争对手"的一张牌：

```
┌────────────────────────────────────────────┐
│                                            │
│   [老板 IP / 员工 MCN]                     │  ← 堤坝 A（种草）
│                                            │
│   ═════════════════════════════════════    │  ← 中间河床
│   日常营销界面                              │
│   （短视频 / 投放 / 日常直播 / 客户资讯）    │
│   ═════════════════════════════════════    │
│                                            │
│   [大厂直播 / 发布会 / 周年庆]              │  ← 堤坝 B（打爆）
│                                            │
└────────────────────────────────────────────┘
```

- **两侧堤坝** 负责种草和市场教育（高势能）
- **中间河床** 负责收货（承接流量并沉淀）
- 势能一定是"两边高、中间低"，用户像流水一样被留在中间河床
- 非标程度越高的行业，两边越要厚、中间越要饱

### 10. 大厂直播为什么是进入产业的最优入口

- **老板一年只憋这一次**：产品发布 / 周年庆 / 年度演讲——那半小时是老板最用心、最愿意倒出全公司战略的时刻。
- **一把手工程 = 结果保证**：老板都来了，你想失败都难。
- **部门壁垒被彻底打掉**：企业服务最难的圈层壁垒，因为一把手在场自动瓦解。
- **杠杆最大**：借由大厂直播这个入口，你可以顺势植入全年的营销叙事重塑（四个面 CT 扫描：产品面 / 展示面 / 业务面 / 成交面）。

### 11. 商业叙事构架（起点=产品，终点=向往）

润宇团队在陪客户走话术时的核心方法论：

- **起点：产品** — 你能给用户提供什么
- **终点：销售额 / 向往** — 用户想去到的那个未来
- **中间的桥**：为什么用户会意识到今天有这个需求？→ 需求的原因？→ 解决方案在哪？→ 为什么今天你的公司有能力交付？→ 你的产品是什么？
- 打恐惧 vs 打向往：恐惧简单但对社会不好（制造焦虑），向往难打但值得——只跟有表达能力的企业合作。
- 关键动作 = **道理的视觉化**：所有抽象逻辑必须通过具象故事和视觉表达出来（撕板 / 站在碑林前讲唐太宗 / 讲加拿大老奶奶带孙子游 100 家博物馆的例子）。

### 12. IP 中介本质 + 高端品牌 = 引领需求

- **原话**："所有 IP 都是中介都是中介啊，都是一种情感情绪。"
- IP 唯一提升的是"交易效率"。它连着用户圆心，外面绕一圈是产业（行业 → 品牌 → 产品）。
- **高端品牌 = 持续在引领需求 / 持续在创造用户需求上的新供给。** 苹果比小米更高端不是因为价格，而是因为引领。
- 抄没错，但**抄很难高端**。抄可以填性价比位、降低决策成本，但要溢价必须引领。
- 反过来：IP 想成为高端品牌，就得对行业往前的洞察付出努力——哪怕当下没有回报，跨年演讲这种"没植入不上单"的输出也要做。

### 13. 边缘发起创新 + 结构洞：为什么至今没有蓝翔

- **边缘发起创新**：所有新行业创新都从边缘发起——电商第一波是卖不掉货的人，短视频直播第一波是无业游民。既得利益者不会参与创新。
- 一旦边缘创新打到中心 / 形成社会共识（当下的时点），**既得利益者（大品牌 / 大厂）就会大举进入**——服装行业的 HM / ZARA 是等到"新媒体营销的付费投流都 OK 了"才进场。
- **结构洞**：新媒体 × 垂直产业交叉地带的人才缺口。前一波操盘手懂算法但不懂服装；服装老板懂行业但不懂平台——中间的桥梁人才极度稀缺。
- 沈梦辰 / 杜海涛的服装品牌是典型信号：他们签 MCN 不是为了让博主带广告，而是**"当主播"（招聘面试）**——"以前叫面向流量做生意，现在叫面向生意做流量"。
- 未来的蓝翔 = 围绕行业的定向蓝翔（旅游行业蓝翔 / 服装行业蓝翔），把学员塞进那个行业的老板 IP 或 MCN 里。

### 14. 三步收费模型（含资本化第四步）

```
知识免费换流量 → 咨询免费挑客户 → 服务收费做深度 → 资本化谋长利
```

- **知识免费换流量**：把值钱的内容放到直播间 / 短视频免费讲（同行会骂"这东西我们卖钱的"）。
- **咨询免费挑客户**：咨询也要免费换来"识别高价值客户"的权利。免费才拥有拒绝的权利——"欢迎白嫖我。"
- **服务收费做深度**：为筛出的头部客户提供高价服务。核心是"更贵的人的更贵的问题"。
- **资本化（第四步 - 后端）**：随着前三步内卷，利润必然后移到：
  - **销量杠杆**（帮卖货抽成，直播最好卡）
  - **预算杠杆**（3000 万 - 5000 万营销预算里当外挂 CMO）
  - **资本增值杠杆**（合看一家公司 / IP 出流量作为出资，未来上市分红）

### 15. 刘润三段教诲下游化解读

润宇公开了他从刘润那里得到的三次点拨，每一次都拉他上一个台阶：

| 阶段 | 刘润教诲 | 润宇原来的做法 | 转型后 |
|---|---|---|---|
| 阶段 1 | 不要在 C 端把钱收太透（会突破信任边界，被骂割韭菜） | To C 收几百万一个月 | 转 To B |
| 阶段 2 | To B 的核心是"更贵的人的更贵的问题" | To B 收 3 万 5 万 | 单价升到 100 万 |
| 阶段 3 | 从体力型转为杠杆型：帮 10 亿资产的老板降低 20% 不确定性，500 万不算什么 | 卡在 200-300 万一单 | 走向 500 万级战略咨询 |

- **模型不对，天花板就不对**：不是换客户，是换收费逻辑——从"卖体力（拍多少条视频）"改为"卖决策（帮老板锁定判断）"。
- 华与华一句 slogan 收 600 万——因为飞鹤一年花 2 亿投在那个渠道上，提升 10% 就是 2000 万，划 600 万给你，飞鹤还是赚的。
- 战略咨询很难外化，但**营销咨询可以占大便宜**——你帮别人做的事天然是外化的（短视频拍完就得发出去、门头装出来）。

### 16. 原点用户三角（最小营销闭环）

润宇给"想切入产业但不知道怎么开始"的听众最简单的武器：

```
原点用户 + 原点任务 + 原点产品 = 最小营销闭环
```

- **原点用户**：不是"一群人"，而是**具体的一个人**，遇到了一个**具体的问题**。
- **原点任务**：从"我有什么"翻转到"他要什么"。什么事儿能帮上他？先不谈收钱。
- **原点产品**：能解决就算成本、加毛利，再看有没有替代品——"想解决，又找不到替代品"就有溢价。
- 空气有价值但没有价格：**价值 → 价格 = 稀缺**。做原点产品，就是把自己的稀缺性捏出来。
- 三步进入产业的落地动作：**变回用户 → 进入场景对话 → 找原点用户**（润宇为什么花 4 天去大理陪必胜爬山：他就是在做这三步）。

### 17. 回归母体（心法层）

全场高光：斯斯问润宇"如果所有方法都用完还是想不明白怎么办"。润宇的答案：

- **母体不是老婆孩子同事，母体是客户。**
- 客户是商业的母体，妈妈是生命的母体——迷茫时应该回到"你当年为什么成功"的原点。
- 只要你是一个真诚的人，人家对你的爱今天不会变；如果变了，大概率是你变了。
- 心法两个字 **"敬畏"**：
  - **敬（jìn）** = 尽力：所有能穷举的努力都做一遍。
  - **敬（jìng）** = 尊敬：不要因为自己挣钱多就看不上小白问的问题——用户才是所有生意的根。

### 18. 春运迁徙钱 vs 大草原食物链

- **春运迁徙钱**：跑马圈地时代赚的红利钱——中登和老登还不会玩要交学费，我们赚族群迁徙的钱。
- **大草原食物链**：迁徙完了，草原恢复弱肉强食。你要么已经离场，要么找到自己的生态位。
- 迁徙一定不是常钱。**技能一定是平民化的**——今天教发朋友圈拍短视频，就像 2010 年教开公众号一样，注定平民化。

### 19. 生物进化论视角

润宇本科生物 + 商业双专业，反复用进化论视角看新媒体行业：

```
变异（创新）→ 竞争（内卷）→ 选择（流量 / 消费者买单）
```

- **选择是结果，流量是结果**——你在结果上用力永远改变不了原因。
- 要在**原因上用力**，就是在创新上用力，不是在流量上用力。

### 20. 冰川消融的隐喻

- 每个 IP 都是站在一块冰川上的小松鼠。
- 冰河世纪结束了，温度在上升，冰块会越来越小。
- 每只松鼠都想跳到更大的冰块，但作为生态观察者，你的冰块**一定会消失**。
- 冰面退去后是**大草原**（产业化的世界）——你要找到自己是什么动物、跟谁做结合、往哪个方向做演化。

## 关键问答

**Q1：润宇为什么判断"2025 年知识付费行业已死"？**
A：知识付费的本质不是产业，而是"流量红利的 B 面 / Bonus"——它三次爆发（公众号→短视频→直播）都是渠道红利在托举。到 2025 年 9 月视频号红利结束、微信生态商业闭环（微信小店 + 视频号 + 私域）打通、平台不再允许流量外流，最后一个内容渠道也宣告完结。渠道红利没了，作为衍生品的知识付费当然就死了。它没死的是"想学习的心"，死的是**用课堂灌输 + 焦虑营销来卖空气**的那套模式。

**Q2：那 2026 年的知识付费会分化成什么？**
A：三条出路。① **内容消费**（付费内容/播客/电影，用户消费本身就是终点）；② **技能培训**（垂直行业内的车间培训，SOP 化，把员工培训上岗）；③ **营销服务/产业化**（真正跟着优质供给走进产业，做 CMO 外挂或合伙人）。第三条才是润宇选的路，也是他 2026 年最看好的方向。

**Q3：私域 3.0 和 1.0/2.0 到底差在哪？**
A：私域 1.0 = **扫码就加**（2010-2013，微商时代）；私域 2.0 = **领资料换关注**（裂变、诱导分享，一大堆"删粉率 30%"的领资料用户）；私域 3.0 = **公域私域界限消融**，加不加微信跟点不点关注差别不大，因为消费者已经"通货膨胀+看透套路"了。所以策略从"大口呼吸抓所有人"转向"不关注谁离去，只关注谁留下"，用 7 天无理由帮自己筛掉不合适的人。

**Q4：什么是"消费者 5 层营销漏斗"？现在打到哪一层？**
A：接触 → 理解 → 认同 → 买单 → 传播。以前红利期只打接触和转化，用户是"号码牌"；现在整个行业都卷到了第三层"认同"以后，甚至第四层"买单"，比拼的已经是精细化运营和真实价值。前 4 层的玩法免费教材满天飞，谁都能学。这才是内卷的真正含义。

**Q5：知识付费的用户到底有几类？**
A：4 类。① **K12** 学生（学习是天职）；② **职业培训**（美甲、剪辑、火锅学校等上岗培训）；③ **商学院 / 真正在做事的中层与创业者**（得到的核心用户）；④ **想搞钱但没业务的人**（前 10 年的知识付费金主，也是最不复购的）。前 3 类是坚挺真需求，第 4 类才是让整个行业"短命"的原因——他们赚不到钱之后就集体撤退。

**Q6：什么是"河床模型（合床模型）"？为什么是未来营销三板斧？**
A：两侧堤坝 + 中间河床的结构。左堤坝 = **老板 IP / 员工 MCN**（种草认同）；右堤坝 = **大厂直播**（品牌高光、发布仪式）；中间河床 = **日常营销界面**（短视频 / 投放 / 日常直播，负责收货）。用户像黄河一样在河床里沉淀下来，两侧堤坝把势能拉高，中间接住转化。非标程度越高，堤坝越厚。这是"枪口向左向右差 5 公分，中间成本差一个亿"的核心。

**Q7：为什么大厂直播是切入产业的最佳入口，而不是老板 IP？**
A：三重理由。① **老板年会只憋一次**，一把手工程，所有部门壁垒都会为它让路；② **老板最有耐心的时刻**，你能拿到他一年最多的深度对话；③ **结果最容易保证**——老板亲自上，团队全 all-in，转化怎么会差？做完这一场，你就自然进入到全年营销框架、产品调整、商业叙事构架的全景服务，从"直播操盘手"升级为"外挂 CMO"。

**Q8：挑客户的四层怎么选？**
A：从浅到深：① **项目外包**（一场直播 / 30 条短视频，几十万，最轻责任）；② **代运营**（帮干活，不参与决策，只有万不得已才做）；③ **外挂 CMO**（把自己作为对方年薪 100-200 万的 CMO 平移过去，收年度服务费+分成）；④ **合伙人**（合资公司，共同承担成本共同分享收益）。核心不是选模式，是**看你想要多少责任、承担多少成本、拿多少利润**——本质是一笔财务算账。

**Q9：什么是"三步收费模型 + 资本化"？**
A：① **知识免费换流量**（把过去卖钱的干货全部放出来）；② **咨询免费挑客户**（用免费咨询筛选出识货的高价值客户）；③ **服务收费做深度**（对更贵的人的更贵问题，收更贵的价格）。最后一步是 **IP 资本化**——把小小的 IP 装进资本化的杠杆里：销量杠杆（提成）→ 预算杠杆（分营销预算）→ 资本增值杠杆（合股/上市/分红）。

**Q10：什么是刘润给润宇的"三段教诲"？**
A：① **别死磕 C 端**（婚礼前的第一次）——信任在扩表阶段收 C 端割韭菜必反噬，一定要转 B 端；② **更贵的人的更贵问题**（第二次）——To B 不挣钱不是问题，是没找到更贵客户的更贵问题（战略咨询、营销咨询）；③ **牵动更大的资产**（婚礼上第三次）——你的报价不是靠德行，是靠你决策影响的资产规模：帮马化腾做决策牵动 8000 亿，收 500 万不算什么。这一路让润宇从"体力型 IP"跳到"杠杆型营销顾问"。

**Q11：我是零经验小白，最快的路径是什么？**
A：**打工是最快的**。因为你没有挑战，独立创业无法收获挑战的密度；跟着行业里"活最多的人"（比如斯斯做播客），你能借他的肉身接触到最丰富的挑战。想成为超级个体 = **驾驭杠杆 + 成为超级老板**，两层筛掉 90% 的人。所以完全零经验时不要浪漫化"超级个体"，先加入一个规则、把认知构建做完。

**Q12：迷茫了，找不到方向怎么办？**
A：**回归母体**。人生迷茫、公司迷茫、增长迷茫时，不要向外求，向内求，回到你的**客户**——因为客户是商业的母体（就像妈妈是生命的母体）。回忆当年别人为什么喜欢你，尽你所能地"尽（jìn）"，同时"敬（jìng）"畏用户。前者是竭尽全力，后者是内心的敬重。**"人之所以飘了，就是觉得看不上那东西了。"**

### 开场：分水岭之年，视频号红利终结

**S：** Hello Hello，欢迎回到《给女孩的商业第一课》。今天这些内容大家也期待了很久。此时此刻是 2025 年双十二，我们终于把润宇董事长请回了女生。希望他做一个整个 2025 年的盘点和 2026 年的展望。

今年很动荡，整个 IP 行业、知识付费行业经历了很多不可思议的事情，用你的话来说，**你认为 2025 年知识付费行业已死**。这话很绝对。你觉得今年是分水岭之年吗？

**Y：** 绝对是。第一个点，我对视频号最熟——我跟了 4 年的视频号红利。**我强烈地感觉，到今年 9 月份，这个红利就宣告一个段落**。我们一直在看大盘数据，规则收紧、存量活跃度够了、商家和创作者也够了，我要筛优质的人。规则一手紧，水下的白嫖玩家就不玩了——这说明什么？说明内容量、创作频率、用户活跃度基本都够了，我要提质了。**今天凭本事赚钱，它就不是红利，就是一个成熟行业。**

到最后其实没有所谓的抖音、视频号、小红书。平台的商业模式是 marketplace，撮合供给方和需求方，抽流水。它不可能再允许你从直播间把流量倒到私域口袋里——就像商场发达了、人挤人了，我怎么可能让你到门口地下室去成交？我希望所有交易都在监管下，一方面保护消费者利益，一方面每一单要在固定收银台开票，抽 3-7 个点技术服务费。**所有平台最后都是这个商业模式，流量红利一定有见顶的一天。**

小红书虽然是最后一个体量到 8 亿日活的平台，但它到今天在创作者眼里依然是种草平台，不是商业闭环。所以差不多今年 9 月，最后一个"关门的小弟"也转折了。**一旦这个转折发生，你就可以宣告一个时代节奏的结束。**

### 老叙事的绑架：搞流量 / 起号 / 100 万粉丝

**Y：** 但人很可怕，人会被自己的叙事绑架。我昨天在朋友直播间，下面的人下意识就问：**"如何快速做到 100 万粉丝？如何快速赚到 100 万？"** ——你看，人在公屏上打出来的一定是他脑子里觉得最重要的那句话。

100 万粉丝 = 钱？——这是过去 5 年的叙事。但在 2025-2026 这个分水岭，这个叙事完全要变。**"粉丝就是爱的号码牌，它证明你曾经努力过，但它对你的商业价值并不大。"**

刘思毅是聪明人，5 年前他喊"搞流量来群响"是对的——那是当下最值钱的资产。但今天他不喊了，从 9 月开始换成"陪跑年轻创业者、一人一年 100 万"的模型——因为他判断出当下第一你喊也搞不着，第二搞着了也不代表你有钱。

超级个体和艺人公司这波潮流是十年——从微博、公众号、短视频、直播、老板 IP。**"之所以一个个体能超级，是因为它有红利杠杆。红利杠杆结束了，个体就很难超级。"** 下一个可能能让个体超级的场，大概率是 AI。

### 私域 1.0 → 2.0 → 3.0 的演进

**S：** 我补充一个视角。过去十年大家做知识付费，都是以到私域为一个节点。私域是不是我判断"用户到底是我的还是平台的"的标志性节点？

**Y：** 我们要引出来一个特别颠覆性的话题——**这个观点也要作废了。**

刘润当年在跨年演讲上讲私域像打井、公域像自来水，那番话在当年非常正确，把大量公司发动起来去做私域。但今天，私域这件事的理解跟当年完全不一样。

- **私域 1.0（2010-2013 微商时代）**：扫码就能加，甚至送洋娃娃、免费称体脂率、拉三个人送本书。**"你家门前散步用这么烂的手法，居然没有城管管你，那当然应该鼓励大家画多远、加多少。"**
- **私域 2.0（自媒体年代）**：三个字——**领资料**。"想要 PPT 屏幕下方加我"，效果拔群。但今天这批人衰减越来越严重，甚至变成一个咨询课题叫"如何激活领资料的私域用户"——这不是选择问题，是趋势问题。
- **私域 3.0（现在）**：**加不加你差别不大**。我们从领资料加过来的用户删粉率 30%，自然加的删粉率 5%。**"以前我特别担心谁离我而去，我要大口地呼吸、大块地吃肉，一滴都不剩全部吃到肚子里。现在我不太关注谁离我而去，我关注的是谁留下来了。"**

我们卖 365 元一年的会员专区，就故意加"7 天无理由退款"——**"我宁愿让你占我便宜赶紧走。留下的人才是最有价值的，不适合的人要用极低的成本尽快筛掉。"**

私域和公域会越来越像，因为消费者麻了、通货膨胀了。加了微信也是"来看看你是什么货色"。**"欢迎大家加我们俩的微信，看看我们是什么货色。"**

### 消费者 5 层营销漏斗

**Y：** 营销漏斗从外到内是 5 层：**接触 → 理解 → 认同 → 买单 → 传播**。

- **接触**：点赞、加关注、加微信都算接触；
- **理解**：以前弄个体脂秤发报告根本不理解，只玩转化率不考虑人；
- **认同**：用户对大量商业形态能产生自己判断——**"爱与恨本质上都是有价值的，怕就怕冷漠。"** 用户能说"它是好的/它是垃圾/它是适合我的/它不适合我的"；
- **买单**：涉及支付能力、产品规格、同行比价；
- **传播**：奔走相告。

**"你觉得现在打仗打到哪一层？内卷卷到哪一层？"** 不同行业不一样，但整体已经卷到了人均精细化运营。公域和私域之间的差别越来越小，你要用打公域的精神打私域，要在私域里发大量公域的内容做区隔度。

**"流量都走到尽头，因为前 4 层大家都知道玩法了。5.2 元的课直播间免费就能加，闲鱼上更是白菜价。"** 当所有玩法都透明以后，还想赚钱怎么办？两条路：一是靠改善话术（离诈骗越来越近，缅北的本质就是"只有话术没有交付"）；二是**回去改善供给**。营销无底线化很简单，改善生产太难。所以我们才用整整两年**在社会上找优质供给**——这就是你看到我们现在的客户。

### 知识付费 = 流量红利的 B 面

**S：** 你的意思是知识付费不是一个产业？

**Y：** **知识付费本质上就是流量红利的 B 面。** 流量红利是 A 面，知识付费是 B 面。所以流量红利结束，它就该死。

知识付费历经三轮红利：
1. **公众号红利**（2013-2016）——罗振宇、10 点读书从这里起。当年张小龙看到罗胖在有赞卖套装书，主动问要不要接入微信支付。**"知识付费其实是 1 个渠道的流量红利。"**
2. **短视频红利**（2018-2020）——樊登、董宇辉从抖音切片起来。
3. **直播红利**（2020-2023）——直播间答疑，脸都能给你看。

**"三轮流量红利、三轮内容释放，本质都是让'空气'（课程/知识）在短时间内得到更多信任，替代了原来的面销。"** 新东方、学而思那个年代靠线下网点，公众号 1000 字/2000 字反复讲，短视频、直播都是在放大信任的规模。

**"但今天直播之后还有新的内容渠道出来吗？没有了。所以这个增长就停止了。"**

### 人不是靠上课成长，是靠挑战成长

**S：** 但你只讲了供给，没讲需求。人们想学习的心是真需求。

**Y：** 想进步、想成长的心是真需求，没问题。但**人不是靠上课成长，人是靠挑战成长**。你创业一路走过来，不是靠一本本书、一节节课，而是靠遇到的事、非解决不可的问题。

**"为什么我们身边负债的人做人 IP 都能做起来？因为他没有退路。"** 你告诉那 5 个负债的兄弟"你把钱打给我呀，你不就负债了"——这是玩笑，但背后有必然性：没有负债的人把知识付费/做 IP 当作 nice-to-have，负债的人把它当作唯一可以自救的方法。

大众最缺的不是知识，是**与财富疏远的心态**——总想跟确定性在一起，考公、进大厂。一旦你选择了确定性，你就没有挑战，一旦没有挑战，你就不成长。**"知识付费第一波洒下去，存量用户大量会转化过来，因为打的是他最基层的'想进步'的需求。第二波不复购了——学会的人不买了，没学会更不买了。"**

真正在做事、能挑战自己的人是少数，是社会的中间力量（得到抓的核心人群）。他们的需求变得更深：不再要"改命的鸡汤"，要**成事的逻辑**。所以罗振宇跨年演讲提"躬身入局"、"干事儿的人"、"一困惑就出门 / 一具体就深刻"——干过事的人才能理解他在倡导什么。

我给来做 IP 的人一个 4 步模型：① **构建认知**（IP 是什么）；② **构建执行框架**（分哪几部分）；③ **找一个最小切入点**（IP 的根本 = 内容；内容的根本 = 表达；表达的根本 = 活人感的思考。切入点 = 写朋友圈）；④ **持续干 100 遍，准时出摊**。

**"你发一天朋友圈很简单，发 100 天非常难。所有真实的挑战都是在你准时出摊的过程中一个一个被暴露出来。"** 准时出摊不是傻等，是**暴露自己缺陷的过程**。

**"知识从未过气，但是知识付费这种妄念，我觉得差不多随着流量红利的结束，它就结束了。下一轮该比方案，下一轮该比执行了。"**

### 知识付费用户四类地图

**S：** 我再补充一类人——2025 年知识付费的相对主流，是那些**想通过 IP 搞钱的人**。他们不是为了成长，是为了钱。

**Y：** 我强烈同意。应该先把钱搞到。这个在外面很少说，只敢在你这里说。让我把地图画全——知识最后卖给四类人：

- **① K12 学生**：学习是天职，学而思、新东方；
- **② 职业培训**：美甲、剪辑、火锅学校、蓝翔挖掘机——上岗培训是真需求；
- **③ 真正在经营的人**：商学院、创业者、企业中层、政府里干事的人——挑战驱动的真学习者，得到的核心；
- **④ 想搞钱但没业务的人**：过去 10 年知识付费最火最付钱的那波，但也是让整个行业短命的原因——他们赚不到就集体撤退，然后开始骂"你们都是镰刀"。

前 3 类是坚挺真需求，第 4 类是流量红利的短命金主。**"利币会驱逐良币——但凡好好讲话的反而穷死，但凡跟你说'上完课明天变现几百 W'的一下子能卖很多。"**

未来第 4 类的合理疏导口应该是**职业教育**：把"我想干"翻译成"我要去实习/打工"。**"没有就业经验的时候，你不应该自己搞自己。加入一个团队去干，就是最好的蓝翔。"**

### 从个体 → 老板 → 产业：三步进化

**S：** 那我是零经验小白，能不能干？怎么找蓝翔？

**Y：** **完全没能力时，打工是最快的。不要选别的，一定是最快的。**

如果你不想打工，你至少要把认知构建自己搞定——问出**有价值的问题**。方法：找 10 本这个话题的书，把每本目录抄下来，看重合点——那就是这个行业的第一性原理。带着看不懂的问题去见高手，你都不用花钱买课。**"买课是为了效率高，买课不是为了改命。"**

**S：** 那我以后一直做超级个体行不行？

**Y：** **真正的超级个体是属于老板的**。超级 = 驾驭超常人的杠杆（AI 杠杆、自媒体杠杆），第一层筛掉 90% 的人。第二层筛的是**你能不能从"以我为最重要的生产资料"转型为"把生产资料当生产资料"**——个人 IP 的最大问题是我以我肉身建元，公司离开老板一天就现金流断裂。老板的板 = 三个口，你的商品，门前摆商品。今天你把自己卖了，你是超级牛马，不是老板。

生煎铺子的例子最好懂：老板一开始只做 3 厘米直径的肉生煎，成了。生意大了下面员工建议加虾仁馅、鸭血粉丝汤、牛肉煎饺……最后你原来最核心的竞争力被稀释掉，变成一个平庸的早餐铺子。**"营收翻倍，利润减半"** 就是这么来的。

### IP 是中介，本质是情感情绪

**Y：** 消费者最后要的也不是 1 个 IP。他要吃穿住行。IP 本质上是 **中介、情绪中介、情感中介**——它提升的是交易效率。

**"所有 IP 都是中介，都是一种情感情绪。"** 我今天代表了你的品味，把瑞幸卖给你。以前你不会直接接触瑞幸的广告，但你觉得它跟库迪一样。

- **1 个 IP 这端连客户**，另一端应该连**产业**（行业 → 品牌 → 产品）；
- 消费者通过 IP 找到产品，IP 又帮品牌从产品到品类提升（Laifen 从吹风机到剃须刀、电动牙刷都靠叶洪新的老板 IP）；
- **IP 之所以在大家的误解当中是"产业末梢"，是因为知识付费短暂的黄袍加身让你以为一个晚上能搞多少 W。**

用户学完课希望能**上岗**，结果没有上岗，所以不复购。**"用户的需求没有被满足，这个行业就一定会塌陷。"**

### 蓝翔在哪里？从边缘发起创新

**S：** 那为什么这个行业没有 IP 蓝翔、IP 新东方？

**Y：** **所有的新行业都符合创新扩散理论——从边缘发起创新。** 短视频直播 IP 第一波进场的全是无业游民（社会边缘人物），既得利益者是不会参与这轮创新的。就像电商最早的人都是卖不掉货的。

今天第一轮红利结束，边缘创新已经打到了中心，全社会形成了共识。**"共识形成的年代，是真正让普通人再次回归普通的年代。"** 因为共识一形成，大佬（雷军、余承东、马云的阿里）就会带着两个亿冲进来。

**"确定性是大佬搞的，普通人搞什么确定性？"** 普通人的机会在旱地拔葱、大佬不来的时候。大佬来了以后，普通人的新机会是**服务大佬**——帮他烫西装、帮他架马车，进入他的分工。

未来蓝翔会是**垂直行业的蓝翔**：旅游行业的蓝翔专门教旅游 IP、服装行业的蓝翔专门教服装 IP。**"未来的操盘手不是面向算法/流量的操盘手，而是面向产业的操盘手。"** 这就是"人才结构洞"的位置——上游行业 know-how 和下游平台玩法之间断层的地方，谁能填上谁最稀缺。

**S：** 你这么一说我懂了。**沈梦辰杜海涛的服装品牌**先搞定了经纪公司、搞定了供应链，然后签小红书博主——不是为了带广告，是为了给他家的服装当主播。所以以前叫"面向流量做生意"，现在叫**面向生意做流量**。

**Y：** 对，完全变了。这就是分水岭。

### 高端品牌 = 引领需求

**Y：** 我这一年反复问自己：**什么叫高端品牌？给钱多的叫高端品牌吗？收费高的叫高端品牌吗？**

苹果、华为、小米的旗舰机价格并没有差很多，但为什么你下意识认为苹果是高端？**"持续在引领需求的、持续在创造用户需求的新供给的，它就叫高端品牌。"**

大部分中国品牌做不成高端，是因为老在折腾包装、价格、代言人、渠道。**"抄本身没问题，但抄很难高端。"** 用户会用你，但不会奔走相告，只把你放在性价比那个位置。

同样的道理放回做 IP：**"如果你认为你要持续做一个高端品牌，对于行业往前的洞察的这份努力你是一定要付的。"** 我每年跨年花这么大力气录预测，招到的线下课学生也不一定比别人多。但如果你只是靠商标而没有引领性，你就没有品牌溢价。

### 河床模型：未来营销的三板斧

**Y：** 我给你一个营销全图。**未来的线上新媒体营销三板斧是一个"河床模型"（合床模型）**：

```
    左堤坝：老板 IP / 员工 MCN（种草认同）
                     ↓
         │ 河床：日常营销界面（短视频/投放/日常直播 - 收货）│
                     ↑
    右堤坝：大厂直播（品牌高光 / 发布仪式）
```

- 两侧堤坝负责种草，中间河床负责收货；
- 用户像黄河的水，被沉淀在中间；
- 非标品比例越高，堤坝越厚；
- 中央河床永远势能最低，市场教育和渗透一定要靠两边堤坝拉起来。

**"这就是刘润说的枪口向左向右差 5 公分，中间成本差一个亿。"**

### 大厂直播为什么是切入产业的最佳入口？

**Y：** 我打这张牌比老板 IP 更快，原因有三：

1. **老板一年就憋这么一次**（年会 / 发布会 / 周年庆），一定用力过猛 100%；
2. **一把手工程，圈层壁垒 / 部门壁垒都会被打掉**，没人搞不清楚状况在刷存在感；
3. **企业服务当中最容易保证结果**——老板都亲自来了，怎么可能做不好？

外部以为我们在做流量转化，其实我们在做的是：从**大厂直播这一个入口**切进去，扫描客户的全景图（将/产品面/展示面/业务面/成交面），发现产品缺陷/差异化缺失，然后进入到**商业叙事构架**——起点是产品，终点是向往，中间用完整的叙事桥把用户从"意识到需求"引导到"选择你"。

我们服务的每个客户都是**打向往型**（不是打恐惧型）。恐惧好打（隔壁孩子已经全面超过你了），向往难打（让你看到你家孩子变成那个样子）。所以我们要陪客户调产品、写叙事、做视觉化——"干货的视觉化 / 道理的视觉化"是 2026 年操盘手的必备技能。

### 加拿大老奶奶的博物馆案例

**Y：** 举个例子，你要教文化旅游，你怎么让"何以为中国"这个话题不肉麻？

一个加拿大移一代的老奶奶，孙子已经完全不会讲中文了。她担心中华文脉在他这里断掉，觉得自己再活 5-10 年也要走了。她做了什么？**花钱让人把中国前 100 名最好的博物馆找最好的老师带他孙子逛一遍。** 博物馆就变成了中华文明的轮廓。

**"这肉麻吗？我也想买。"** 具象故事不是灌鸡汤：它的起点是产品（博物馆游），终点是向往（何以为中国），中间的桥是老奶奶怕孙子断了文脉的真实焦虑。**你不进入这个行业，你只知道道理。这就是 985/211 又会被拦在上面。**

### 挑客户四层：项目 → 代运营 → 外挂 CMO → 合伙人

**Y：** 我们做产品之前是**挑客户**。市面上四层客户：

- **年营收 1000 万以内（老板 = 主要牛马）**：老板一条命，靠自己揽客/转化/交付。给他配 **离前进的解决方案**（直播）就特别容易出单——因为他越焦虑越容易成交。
- **3000 万-1 亿的公司（组织已经裂变）**：老板成了合伙人，下面有 A/B/C 项目组，获客最难分出去、转化和交付已经分离。这时候 **老板 IP + 陪跑** 是最合适的。
- **1 亿-3 亿的公司（本身就有获客渠道）**：投放、APP、货架电商都会。他缺的是**内容营销的商业叙事**——从"触达→转换"的流量思维，升级为"触达→影响→转换"的内容思维。
- **5 亿以上的大厂**：他有 5000 万/一年的营销预算，需要一个懂 CMO 视角的合伙人来统筹这笔预算怎么花。这时候你就成为 **外挂 CMO**。

对应四种服务姿态（也是四种财务结构）：

| 层级 | 姿态 | 收益 | 责任 |
|---|---|---|---|
| ① 项目外包 | 拍 30 条视频 / 1 场直播 | 一笔项目费（30-100 万） | 最小 |
| ② 代运营 | 帮你干活但不进决策 | 服务费 | 中 |
| ③ 外挂 CMO | 相当于 200 万年薪 CMO 平移 | 年服务费 + 分成 | 大 |
| ④ 合伙人 | 合资公司 | 股权分红 | 承担全部成本 |

**"这本质上就是笔财务算账。你想要多少责任、承担多少成本、拿多少利润。"**

我们主动退出过一个"贼有名、贼多钱"的代运营项目——**因为进不了决策中心，我们的时间成本回收不了。"我不干不是因为高傲，是因为我认为我的未来更贵。"**

### 刘润三段教诲：一步步把我从体力型逼成杠杆型

**Y：** 我营销认知的三次跃迁，都靠一个贵人叫**刘润**——他给我开的三个小灶：

**第一段：别死磕 C 端**（C 端收得最猛的那个月，收了几百万）

刘润专门从上海飞过来请我吃饭，讲了很久我根本听不懂的道理。半年后我彻底懂了：**"知识付费本质是信任生意。信任圈子的钱可以赚，但一旦你的营收增长突破信任边界，人家就会说你割韭菜——而'割韭菜'从来不是由镰刀决定，是由韭菜判定的。"** 信任扩表 = 金融危机。要长活，就要清 C 端、上 To B。

**第二段：更贵的人的更贵问题**（To B 一年只有 C 端 1/3 时）

刘润给我打电话请教年度演讲标题，我趁机诉苦。他说：**"To B 的核心是找到更贵的人，持续解决他更贵的问题。"** 拿到得到这样的客户就是这段的产物。

**第三段：牵动更大的资产**（斯斯婚礼上第三次求救）

刘润说：**"你的模型错了。不是靠德行扛的。你今天做 5 万的决策牵动的是一个个体户；你如果给马化腾做咨询、他做的决定屁股后面是 8000 亿市值、10 亿成本——你收 500 万，其实不算什么。"**

举个例子：一家 200 亿营收公司为了新产品线在最后半年请三家咨询公司各出方案，每家 200 万，600 万买回来一个都不用。**"对小客户你交付确定性；对大客户你帮他排除小概率的不确定性。"** 华与华 1 个 PPT 卖 600 万，飞鹤 2 亿营销预算能提 10% 就是 2000 万，划 600 万还是赚。

**"就你还没下手，胜负一分。"**

### 三步收费模型 + IP 资本化三层杠杆

**Y：** 普通人怎么从零走到这里？**三步收费模型**：

1. **知识免费换流量**——**"知识本来就应该免费。"** 视频号第一天我就把值钱的东西免费讲，同行天天骂我，但换来的是流量。
2. **咨询免费挑客户**——**"欢迎大家白嫖我，因为只有你白嫖我，我才拥有拒绝的权利。"** 免费咨询筛选高价值客户。
3. **服务收费做深度**——对更贵的人的更贵问题，收更贵的价格。

但这一层也在内卷（老板 IP 陪跑从 50 万 60 条 → 10 万 60 条 → 快变红白喜事了）。所以**利润后移**，往 **IP 资本化** 上跳，三层杠杆：

- **销量杠杆**（GMV 提成，直播卡得最紧）；
- **预算杠杆**（分 3000-5000 万的营销预算，做外挂 CMO）；
- **资本增值杠杆**（合股 / 上市 / 分红）——**"未来流量也是一个生产要素，可以估价、可以资本化。"**

**"最终最终，你通过一个小小的 IP，前端收知识付费的钱→咨询的钱→服务费→资产的钱。只有最后那一段，别人没法替代你。"**

### 挑龙头 + 长尾：真正的杠杆点

**Y：** 刘润这句话我过去两个月才吃透：**"挑龙头能认可你（作为决策中枢认可你的地图和策略），长尾要够长够大（他的预算复杂够多）。"** 你用小小的龙头画龙点睛来控制后面长长的预算，这样才有杠杆。

我们的全年框架 80% 是别人也能干的，但真正超越别人的是前面 20% 的策略判断。**"你买我在买什么？① 视野，② 纠偏，③ 降低不确定性。"**

### IP 会短命化 + 碎片化：场景王者

**Y：** 每个 IP 都是圆周上的一个小片段。未来 14 亿人分成 1000 万种需求，1 个 IP 有 7 万粉丝就能做生意。**"IP 一定是碎片化的。"**

但矛盾论决定：**"用户被供给得越细分越体贴，需求变化就越快。"** ——你越有钱越换供应商，你越穷忠诚度越高。未来 IP：**越来越细分 + 越来越短命 + 方生方死**。一个刘德华散成了满天星。

但正因如此，IP 一定要绑定 **自己最擅长的产业**——IP 是入口，屁股后面的**产业**才是护城河。**"把根扎在价值里，把势做在趋势上。"**

### 原点用户三角：最小营销变现闭环

**Y：** 迷茫时怎么办？回到最小闭环——**原点用户三角**：

```
    原点用户 = 一个具体的人（不是"大部分人"）
        ↓
    原点任务 = 他遇到的一个具体问题
        ↓
    原点产品 = 你为这个问题做的稀缺性交付
```

- 大部分人说不清"原点用户是谁"——不够细节；
- 大部分人说不清用户遇到什么具体问题——总是很粗；
- 只给他卖一个产品，甚至白送。如果他想解决又找不到替代品——**你就有溢价**。

**"价值和价格之间差两个字叫稀缺。空气有价值但没有价格，因为不稀缺。你要把自己的稀缺性捏出来。这就是最小的营销变现闭环。"**

### 冰川消融隐喻：进产业，赚长钱

**S：** 我们 IP 行业每个人都是站在冰川上的小松鼠。冰河世纪结束了，温度上升，冰块越来越小。每只松鼠都想跳到更大的冰块，但作为生态观察者：**你的冰块一定会消失。**

**Y：** 冰面退去后是**大草原**（产业化的世界）——你要找到自己是什么动物、跟谁做结合、往哪个方向做演化。

我大学学生物+商业。**自然选择进化论就三个：变异 → 竞争 → 选择。** 商业上：变异=创新，竞争=内卷，选择=消费者买单（流量）。**"选择是结果，流量是结果——你在结果上用力永远改变不了原因。要在原因上用力，就是在创新上用力。"**

### 美居香水味：性价比洞穿了创新

**S：** 我们这两天住杭州美居，我在洗手时突然发现洗手液味道跟我以前住的丽思卡尔顿一模一样。**那一刻我洞穿了性价比、也洞穿了创新——研发出这个香味的品牌是放在五星酒店的；抄它的觉得味道好，用来做超高性价比。**

**Y：** 对，**赚钱不代表高端。没有引领是没有办法变成高端品牌的。**

### 灯光老师的最后一问：想不明白怎么突破？

**F（灯光老师）：** 老师你能把事情想那么明白、说那么明白，是极稀缺的能力。那你自己有想不明白的时候吗？怎么突破？

**Y：** 就一个词——**回归母体**。

我 2025 年状态其实不好，因为我们主动放弃了原来"顺风顺水"的码头（C 端收费），选择了一个从来没驻扎过的码头。人最难受的是不知道未来长什么样但又得坚定地努力，周围码头生意贼兴隆，你还不能回去。**"这个时候的状态非常糟糕。人深刻的认知来自于'熬当中的受苦受难'。"**

**"人生迷茫就回归母体。母体是谁？母体一定是客户。"** 妈妈是生命的母体，客户是商业的母体。人生越迷茫、越焦虑，越不要向外求——向内求，走进客户。

回归的方式有两层：

1. **尽（jìn）力的敬**——把能穷举的都穷举一遍。见大咖 / 看书 / 头脑风暴 / 闭关，能想的方法全部试过。
2. **尊敬（jìng）的敬**——敬畏用户。不能因为自己挣钱多了，就看不上小学生问的问题。用户是所有生意的根，妈妈到 100 岁仍是你妈——**"你越大，你越高级，就越容易看不上小学生。但你应该不断俯下身去理解当年你走过这段路时是什么心态。"**

**"其他所有你学到的知识、课程都不能帮你解决底层逻辑的问题。只有用户能。"**

### 富人 vs 穷人:社群团购的终局判断

**Y:** 两年前我在直播间里被反复问社群团购,当时我没敢明说,现在敢了——**社群团购只有一种活法:做高净值客户。**

沃尔玛能开在全世界,是因为它是**固化流量**——方圆 3 公里的物理排他。但社群团购的用户在微信里,平台一个动作就能被踢掉——**"你不是排他的复利,你就不配拥有利润。"**

品牌方一定要挣钱,所以只能塞白牌。可是终端消费者要的是**"多快好省"** ——你没有多、没有快、没有好、没有省,注定昙花一现。**唯一的例外是富人的社群团购**:

- 富人的时间成本高——一旦相信团长,愿意把吃穿住行全部托付
- 富人愿意为服务付溢价:"你应该挣点钱,你如果不挣钱,我给你 500 块" ——不是因为人品好,是因为他知道你跑了他要重新面试的成本更高
- 富人的需求是**稀缺供应链**(哪里的猕猴桃/哪里的牛油果/什么样的家政)

**"多块好省,只要占一个字,一个商业模式就能站起来。"**

### 商业模式收官:回到用户端

**Y:** 你把自己弄成客户,换到客户需求那一边——**"你到底有什么样增量的需求被满足了?"** 如果没有,别听他们瞎扯什么模式创新,那都是烟雾弹。**最好的模式就是能解决用户实际问题的模式。**

**S:** 好家伙,今天成功让 1 万个做内容电商的听众焦虑了。

**Y:** 但今天这件事已经是明牌——只有提供了差异化供给的活得下来。模式本身不是用户想要的,用户要的是"多快好省 / 解决问题拿到结果"。**你抓住这个点,所有的模式道具/链路模型都无所谓。**

### 需求-供给-差异化:立柱 0 到 1 的三阶

**Y:** 大部分人做不了生意,是**第一步没跨出去**——不知道别人想要什么,总在表述自己有什么。

三步是有严格顺序的:

1. **别人想要什么**(需求)——第一位;
2. **我有什么**(供给)——第二位,拿出自己的三观两枣对进去;
3. **为什么他选我不选隔壁**(差异化)——第三位,立柱 0 到 1 的最后一步。

大部分人只考虑第二个,那不是创业,是找工作逻辑——**"HR 会告诉你去这个车间,这个过程被很多人命名为'定位',其实那不是里斯特劳特的定位,是分配工作。"**

**"这两年有流量红利,大家能把饼卖出去。但今天开始饼不太卖得出去了,回归事情的本质。"**

### 语言决定认知的边界

**Y:** 我们今天花了 5 个小时,做的其实是**重新定义**几个词——知识付费 / IP / 产业 / 客户 / 洞察。**"提高认知本身就是很虚的词。真正的提高认知,就是重新理解这些词的含义,并把它做到自己的生意当中。"**

对词的定义不重要,重要的是你怎么理解他。**"不用太执迷于人家说'播客能不能做''普通人怎么做播客'。你怎么理解播客为老百姓解决的问题——这才重要。理解了再去请教思思。"**

### 抽象化收尾:赢过一次就可以赢无数次

**Y:** 我最想留给听众的两点:

1. **赢过一次就可以赢无数次**——我今天讲的洞察 C 端需求,跟我当年做游戏时是一模一样的。**手感一旦建立,可以无数次复用**——从个人 IP 到服务客户到做自己的生意,本质都是原点用户三角。
2. **微观 vs 宏观切换**——听完这一期不要焦虑,虽然我们讲了很多宏大的东西,但退回到微观:**"把一件小事做好,找到那个手感。"**

### 关于播客本身:稀缺嘉宾 × 稳定质量

**S:** 我想夸一下咱董事长,我觉得我们做的这个系列,短时间内别的播客相当难超越。

**Y:** 好在哪里我说一下:第一,我们以极高的频次、极深的洞察、极高的迭代频率,输出了一整套 IP 行业体系。**你每次都比大部分人多走了半步——所以你能持续输出框架、输出认知,回头告诉大家前面发生了什么。**

而做播客的本质,是**找到足够稀缺的嘉宾,让他高频输出、高频迭代。前提是你能跟他站在一起,你永远是他的最优备选。**

**"真正的高端交易就是不犯错,就是永久。因为成本太高了。"**

### 灯光老师最后一问:想不明白怎么突破?——完整回答

**F(灯光老师):** 你把事情想明白、说明白是极稀缺的能力。那你自己有想不明白问题的时候吗?你是怎么突破的?一本书?闭关?找大咖?头脑风暴?

**Y:** **回归母体。** 这是我带公司的方法论,每次都奏效。

- **母体是谁?** 一定是客户。妈妈是生命的母体,客户是商业的母体。人生越迷茫、越焦虑,越不要向外求——**向内求,走进客户。**
- **具体动作:** 不要跟老婆在一起、不要跟孩子在一起、不要跟同事在一起,在迷茫的这个时段他们没法给你答案——**去客户那里。**
- **原点:** 想想当年你怎么成功的、别人为什么喜欢你。理论上,只要你是一个真诚的人,人家对你的爱今天不会变——如果变了,大概率是你变了。

在技法层面还要做两件事:

- **尽(jìn)力**——所有能穷举的努力都穷举一遍。
- **敬(jìng)畏**——尊敬你的客户。**"我们人之所以飘了,就是觉得看不上那东西了。其实用户是所有生意的根。哪怕他今天是个小白,你也要反问自己:难道你没经历过那种状态吗?"**

一个非常好的 IP 的本质是**"人大代表"** ——代表他的人民,履行这个权利。你之所以不过气,是因为你**心中永远装着他们的苦恼**。你一旦大了、高级了,就会看不上小学生,这时候要**不断俯下身**去理解当年走过这段路的心态。**"否则你就会越来越脱离群众,脱离群众你就脱离市场,脱离市场你就越迷茫。"**

### 尾声:进一寸有一寸的欢喜

**S:** 和董事长聊的这一天,我几次都要昏厥。但回听的时候又觉得特别值。这一期算是我们 2025 年的收官之战,打得很漂亮。**衷心祝愿我们和每一位听众,都可以进产业、赚长钱,在 2026 年打一个漂亮的翻身仗。**

**Y:** 进一寸有一寸的欢喜。就这样了,拜拜。
