# 045 - 2023年终复盘：菩萨渡江后才发现原来只有一艘船

> 结构化说明：本笔记基于元数据与机器清洗稿整理，属于 L4 萃取成品；原始音频、原始转写、清洗稿应继续作为原料保留。清洗稿没有逐句说话人 diarization，`## 对话稿` 中的说话人按开场介绍、称呼和上下文推定。

## 一句话核心

2023 年的割裂感来自规模化旧秩序和圈层化新生意的冲撞；普通人不是没有赚钱机会，而是要从“我想做什么”转向“谁有具体需求，我能解决什么”，在个性化、高客单、私域和小组织里找到自己的新位置。

## 摘要

斯斯、润宇和全泉以 2023 年终复盘为入口，讨论经济冷清、职业偶像崩塌、董宇辉事件、圈层生意、私域回潮和普通人创业机会。润宇提出 2024 年 IP 稀缺、老板过剩，赚钱机会转向反规模化、高客单、非标准需求；斯斯则不断把宏大判断落回普通女孩如何先挣钱、再创业、再理解意义。

## 发言人

- **斯斯**：主播，负责把宏观趋势追问到普通人、普通女孩、IP 和小生意的具体选择上。
- **润宇**：嘉宾，元数据称其为公众号「润宇创业笔记」作者、视频号千万主播、IP 圈老师。本集主要输出圈层生意、私域、创业与进化论的判断。清洗稿中也被识别为“若云/任宇/润语”，本笔记统一为“润宇”。
- **全泉**：共同参与者，清洗稿中也出现“全权/权权”等识别。本集补充制造业、义乌小商品、IP 和广告生态观察，姓名待人工复核。

## 金句收藏

1. 从 2024 年开始，IP 是稀缺的，老板是过剩的。
2. IP 不是所有货架的注意力，而是一个圈层用户的注意力。
3. 规模化已死，个性化永存。
4. 普通人和钱之间差的第一步，是从自我叙事切换到他人叙事。
5. 热爱在起步时可能是赚钱最大的敌人，因为热爱本来是让你花钱的。
6. 真正好的老师一定是你的客户，客户的扭头就是最清晰的表达。
7. 创业的门槛降低了，不意味着创业的难度降低了。
8. 赚钱变得更容易了，但创业变得更难了。
9. 真正的创业失败不是没敲钟，而是放弃、退缩和随大流。
10. 穷则独善其身，达则兼济天下；先找到第一个订单，再谈宏大意义。

## 故事与场景

1. **董宇辉事件作为 IP 与组织的冲撞**：节目把东方甄选事件视为传统组织试图去个人化、粉丝坚持认人的冲突。润宇认为，上市公司希望把市值压在组织结构上，但结果显示圈层 IP 能影响消费决策，也能影响公司价值。这个案例说明，用户注意力正从品牌货架转向可信任的人。

2. **义乌工厂与小商品城的生机**：全泉去义乌纺织厂和小商品城，看到工人热火朝天地检查丝袜，也看到只卖铜关公、招财猫、婚纱照相框等极细分商品的店仍有生存空间。这个案例说明，只要能辐射足够大的范围，低频、小众、细分需求也能成立。

3. **欧莱雅和宝洁式货架逻辑**：润宇用欧莱雅和宝洁举例，过去规模化公司通过不同价位和品牌占满货架，覆盖所有人群和价格带。这个案例说明，旧时代的增长逻辑是把标准化供给铺满渠道，而不是深耕一个圈层。

4. **视频号和微信生态里的圈层生意**：润宇认为，抖音更像穿破圈层的推荐逻辑，微信同时有推荐和社交逻辑，适合律师、留学顾问、整理师等高客单、圈层化生意。这个案例说明，不一定要成为大 V，能在目标圈层里有含金量，也可以赚钱。

5. **婚礼摄影师想先拍 10 单免费**：斯斯提到有社群成员做婚礼摄影，想先免费拍 10 场。润宇判断，如果主产品一开始免费，后面很难再把价格做起来。这个案例说明，普通人做高客单服务不能照搬大公司“先低价引流”的逻辑。

6. **“老师，我想做整理师行不行”的提问方式**：润宇建议把问题从“我想做什么行不行”改成“我发现身边朋友有某个需求，我该如何帮她解决”。这个案例说明，赚钱的第一步不是证明自己热爱，而是找到真实具体的人和需求。

7. **生物学视角下的创业**：润宇用“变异、竞争、选择”解释创业，认为创业像生命中的新物种探索，大量失败不是无意义的，而是为社会留下经验和新可能。这个案例说明，本集并不只讨论赚钱，也把创业放回意义和社会多元里理解。

8. **线下服务店是否必须做 IP**：问答中，有听众问皮肤管理和普拉提小店是否必须做个人 IP。斯斯和润宇拆解为供需问题：如果本地需求明确，先用运营、KOC、私域和线下活动成交，不必用个人 IP 这种“轰炸机”解决到店这只“鸡”。这个案例说明，IP 是手段，不是目的。

## 核心概念

### 圈层生意

- **是什么**：一个人或账号代表一类人的注意力、品味和价值观，再影响这一圈层的消费决策。
- **为什么重要**：用户注意力越来越稀缺，大公司需要进入具体圈层，小个体也能靠信任和转发完成高客单转化。
- **原文里的例子**：润宇用董宇辉、视频号、私域和高端顾问类服务说明，圈层里 500 个有效点赞可能比泛流量里的 10 万播放更值钱。

### 规模化已死，个性化永存

- **是什么**：标准化、大货架、全价格带覆盖的增长方式变难，非标准、高客单、定制化和贴身型需求开始增加。
- **为什么重要**：普通人不该去和大公司正面打规模战，而要找大公司不屑于做、无法高效做的缝隙需求。
- **原文里的例子**：整理师、留学顾问、律师、直播场景布置、IP 私域助理等需求，都属于大公司不容易规模化承接的服务。

### 从自我叙事到他人叙事

- **是什么**：把问题从“我想做什么、我喜欢什么”切换成“谁遇到了什么问题，我能怎么解决”。
- **为什么重要**：打工逻辑容易让人活在自我叙事里，创业和赚钱要求先理解客户需求。
- **原文里的例子**：润宇反对新手只问“我想做整理师行不行”，建议改成“我身边朋友有收纳需求，我怎么帮她解决”。

### 热爱不是起步阶段的商业答案

- **是什么**：热爱可以支撑长期，但起步时不能替代需求、付费意愿和商业模型。
- **为什么重要**：很多人把成功者高阶阶段的热爱故事当成自己的起点，容易忽略他们前面多年能力、资源和市场验证的积累。
- **原文里的例子**：节目调侃“咖啡馆、瑜伽馆、花店”等女性创业三件套，指出如果只是因为自己爱，未必能赚钱。

### 私域回潮

- **是什么**：私域不只是早期粗暴加微信，而是围绕一个小圈层建立品味、利益和价值观共同体。
- **为什么重要**：圈层生意需要组织形式，私域能承载高信任、高客单和持续转化。
- **原文里的例子**：斯斯的股东群、区区大女人、学霸猫等案例被用来说明，有些私域项目在公域形象未必好看，但能在内部形成强关系和高复购。

### 创业是商业物种的探索

- **是什么**：创业不是只有敲钟和年入千万才算成功，也是在商业世界里验证自己是什么物种、能释放什么价值。
- **为什么重要**：如果只用金钱衡量，会忽略失败、探索和多元生态本身的价值。
- **原文里的例子**：润宇用生物进化、科研探索和“重新定一遍自己是什么样的人”解释创业意义。

## 可行动清单

- [ ] 把自己的创业提问从“我想做什么”改成“谁有具体问题，我能帮他解决什么”。
- [ ] 找到第一个真刀真枪表达需求的人，并尽量让对方付一笔小钱验证需求。
- [ ] 不用免费主产品作为默认起步方式，先判断免费是否会破坏未来定价。
- [ ] 选择高客单、定制化、非标准、贴身型需求，而不是和大公司争标准化低价生意。
- [ ] 如果做 IP，先明确自己代表哪个圈层，而不是只给自己贴“美妆/创业/宠物”类目标签。
- [ ] 高端服务优先考虑微信、视频号、转发和私域，不只追求泛平台爆款。
- [ ] 做线下门店时先判断 3 公里供需关系，不要把个人 IP 当成唯一解法。
- [ ] 先把房贷、车贷、家庭责任和现金流压力算清楚，再决定是否全职创业。
- [ ] 用客户反馈当老师，少沉迷课程和鸡汤，把钱花在真实试错上。
- [ ] 在能养活自己后，再去思考更大的社会价值和长期意义。

## 对话稿

**斯斯**：这一年大家过得怎么样？我听到的感受是冷清、分化、冲撞。年轻人原本以为 2023 会迎来快速爆发，结果很多人的结果低于预期。年底董宇辉和孟羽童的事件，也让传统企业主和个人 IP 的冲撞变得很明显。

**润宇**：我今年的感受是，2024 年开始 IP 是稀缺的，老板是过剩的。过去是货架逻辑，欧莱雅、宝洁从低价到高价把货架铺满。今天不一样，IP 代表一个圈层的注意力，它不是卖一个单品，而是影响一类人的心智和消费决策。

**全泉**：我今年跑了很多工厂和供应链，看到的不是一片凋敝。比如义乌的丝袜工厂，工人很热火朝天；小商品城里有只卖铜关公、招财猫、婚纱照相框的店。只要辐射范围足够大，很多非常细分的生意都有生存空间。

**斯斯**：那小是不是一种解法？现在大家好像不再想扩大规模，而是越做越小、越做越精。

**润宇**：我觉得是。未来更多是圈层生意，不是从 1 万元产品打到 19.9 元全链路都做，而是代表一个圈层，再把这个圈层的消费力变现。广告、带货、卖课，本质上都是把圈层组织好后完成交易。

**斯斯**：所以普通人赚钱机会是变少了吗？

**润宇**：对大公司变难，对小个体反而变简单。老百姓会越来越多为情绪价值、学习、爱好、情感这些非标准需求付费。非标准需求最适合个体，因为大公司擅长的是标准化需求。

**斯斯**：那普通人怎么进入这个模式？

**润宇**：第一步是把自我叙事换成他人叙事。不要问“我想做整理师行不行”，要问“我发现身边朋友有整理收纳需求，我怎么帮她解决”。离钱更近的句式，一定是从别人的问题开始。

**斯斯**：很多人会说，我想做自己热爱的事。

**润宇**：热爱在起步时可能是赚钱最大的敌人。热爱本来是让你花钱的，比如热爱旅行、热爱宠物。高阶的人可以把热爱、专业和用户视角融合，但新手不能直接拿成功者的高阶状态当起点。

**全泉**：你们刚才说个体创业比过去容易，但创业本身是不是仍然很难？

**润宇**：门槛降低不代表难度降低。音乐、创业、内容都一样，技术让更多人可以入场，但高端竞争只会更激烈。赚钱可能更容易，创业更难，因为你不能只停留在接单状态，还要创造新的需求和供给关系。

**斯斯**：那什么时候适合真正创业？

**斯斯**：从普通女孩的角度，我会更形而下地说：当你的 To C 接单量已经多到一个人干不过来，需要找小助手或合伙人时，再认真想创业。否则先把当下的钱挣到，不要用理想主义把房贷和车贷压到创业上。

**润宇**：但我也想补充，创业有意义，因为它是你对商业世界的一次表态。它像变异、竞争和选择，很多失败并不是没有意义，而是在帮社会探索可能性。真正的创业失败不是没有敲钟，而是放弃、退缩和随大流。

**斯斯**：最后我想把它落回到大家。单一打鸡血不对，单一躺平也不对。好的社会应该是多元的，有人站起来，有人躺下，有人躺着躺着又站起来。我们鼓励创业，但也鼓励先找订单、先养活自己，再谈更大的意义。
