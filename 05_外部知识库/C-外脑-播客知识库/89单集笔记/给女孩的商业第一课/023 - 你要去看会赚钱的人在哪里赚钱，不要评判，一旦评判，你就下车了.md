# 023 - 你要去看会赚钱的人在哪里赚钱，不要评判，一旦评判，你就下车了

普通人实现阶层跨越的唯一路径，是在新概念出现时“怀着清醒装糊涂”地凑热闹，闭嘴观察最会赚钱的人，找到核心技能练透，然后卖给既得利益者。

## 摘要

润宇和泉泉在2023年中深度剖析微信生态的剧变：私域地位正在被平台主动降权，公域推荐算法成为绝对主导，视频号红利窗口正在收窄。他们对比了微、抖、快、红、B五大平台的终局，认为微信正在重演整个互联网的演化史，走向“all in one”。润宇提出“私域是藏利润的地方，公域是走规模的地方”，并预言下半年私域地位将进一步下降。核心方法论是：普通人破圈要靠新概念出现时“凑热闹”，闭嘴观察，找到核心技能练一万小时，收集所有失败案例，然后打包卖给有钱人。最后，每个人应该把自己活成一家公司，对自己的终生经营负责。

## 故事与场景

1. **润宇整形故事**：润宇分享自己整形花了50万，做过颌面手术、肋骨隆鼻等大手术。他说自己不是因为有勇气，而是因为基础太差（下巴长、鼻孔外翻），nothing to lose，所以随便做提升都很大。以此类比创业，基础差反而是一种优势。

2. **泉泉与小学二年级小朋友**：泉泉参加朋友教英语的活动，一个小学二年级小朋友说业余爱好是发抖音，从小卖部买奥特曼玩具拍视频挂车，每月赚1000元零花钱。泉泉感叹，对00后来说抖音是出生就有的东西，不需要学。

3. **润宇挤公交车比喻**：润宇用春运排队买票比喻阶层跨越。排在最后的人最绝望，但旁边突然开一个新窗口时，一个箭步冲上去的肯定是排在最后的人，排在前面的人不会动。最惨的是排在中间的人，犹豫不决，最后变成垫底。

4. **润宇被政策“逼”上视频号**：润宇提到自己抓住视频号机会，是因为被一个全国皆知的教培政策改变所影响，穷则思变，痛定思痛。如果没有退路，人一定会冲上去。

5. **泉泉帮奶奶追回被骗款**：泉泉在公众号大V群看到有人爆料，朋友的奶奶在视频号珠宝直播间花1万多没收到货，加微信后被骗5万。泉泉帮忙联系视频号官方运营追人。此事发生后不久，珠宝类目整个被砍。

## 核心概念

1. **私域 vs 公域**
   - 是什么：私域是微信生态内可反复触达用户的场域（如个人微信、企业微信、社群）；公域是平台算法推荐的流量场（如视频号推荐流、抖音）。
   - 为什么重要：私域藏利润，公域走规模。平台正在主动降权私域，因为私域不好监管、平台收不到过路费。
   - 原文例子：润宇说“去抖音做规模，来视频号做利润”，但2023年下半年私域地位会进一步下降。

2. **算法分配**
   - 是什么：平台通过推荐算法分配流量，取代了过去的订阅关系和社交关系。
   - 为什么重要：算法是新的“爷”，所有人都是算法的“孙子”。粉丝数越来越虚幻，单条内容质量决定曝光。
   - 原文例子：润宇直播间70%流量来自推荐，30%来自私域。公众号订阅消息只剩一条，下面全是“看一看”推荐。

3. **知识付费是成年人的玩具**
   - 是什么：人们购买知识付费，本质不是想真正学会，而是满足“不想错过新鲜”和“不想错过未来”的人性。
   - 为什么重要：知识博主永远只能吃一轮红利，新东西变老东西后就得撤。
   - 原文例子：润宇说写作能力超过99.99%的人但很难教，因为大家觉得自己会写；GPT是新的，大家觉得自己不会，所以能卖。

4. **破圈方法论（凑热闹五步法）**
   - 是什么：润宇提出的五步法——①勇敢上车（新概念出现时挤进去）；②闭嘴观察，看最会赚钱的人在哪里赚钱，不评判；③找到核心技能；④花一万小时练透；⑤收集所有失败案例，成为专家。
   - 为什么重要：这是普通人实现阶层跨越的唯一路径，靠努力没用，要靠新概念洗牌。
   - 原文例子：润宇说自己成功凑了游戏、打车、视频号三趟热闹。

5. **供求关系变化（红利消失的信号）**
   - 是什么：平台红利要消失时，第一个信号是供求关系发生变化——从平台求你来，变成平台挑你来。
   - 为什么重要：判断红利窗口是否关闭的关键指标。
   - 原文例子：视频号早期平台给钱（视频号任务每月四五千）、给免费流量（500万），现在没有了，规则变严，开始封号。

6. **超级用户概念**
   - 是什么：延长单个用户的LTV（生命周期价值），而不是盲目追求粉丝量。
   - 为什么重要：流量内卷时代，粉丝量大但无法变现没有意义，找到愿意为你付高价的“榜一大哥”更有效。
   - 原文例子：润宇说“我为什么要搞定9999个给我1块钱的人？搞定一个给我200万的人就够了。”

7. **微信“all in one”与“反祖”**
   - 是什么：微信正在把自己变成一个操作系统，重演整个互联网的演化史（公众号→视频号→小绿书→问一问）。
   - 为什么重要：微信10.53亿月活等于中国移动互联网，所有存量差额都在微信里，谁挖出来谁赢。
   - 原文例子：泉泉用生物学“反祖”概念比喻，微信在胚胎期重演了互联网所有业态。

## 我的批注

> [!NOTE] 关于“不要评判”
> 润宇反复强调“不要评判，一旦评判你就下车了”，这是整集最核心的行动指南。普通人最大的障碍不是能力不足，而是带着已有的认知框架去评判新事物，从而错过上车机会。这解释了为什么很多“专业”人士反而抓不住新红利。

> [!NOTE] 关于“知识付费是成年人的玩具”
> 这个观点非常犀利但真实。它揭示了知识付费行业的底层逻辑：用户买的不是知识，是“不想错过未来”的情绪。知识博主本质上是在贩卖焦虑和希望，而不是在传授技能。这对从业者和消费者都有深刻的反思价值。

> [!QUESTION] 润宇说“素人没得选，什么做起来就做什么”，但现实中素人往往精力有限，同时尝试多个平台是否反而会分散资源导致一事无成？有没有更高效的“素人破局”策略？

## 可行动清单

- [ ] 停止评判任何新出现的平台或概念（如AI、新社交APP），先“上车”再说。
- [ ] 每天花30分钟观察一个你正在做的平台（如视频号、小红书）上最赚钱的账号，记录他们的核心技能。
- [ ] 选定一个核心技能（如直播、短视频剪辑、提示词工程），承诺花100小时刻意练习。
- [ ] 收集10个你在该技能领域看到的失败案例，分析原因并整理成文档。
- [ ] 检查你当前使用的微信生态功能（如公众号导流、直播间加企微），确认是否还有“元老权限”，珍惜并绑定。
- [ ] 重新评估你的粉丝价值：计算单个粉丝的LTV（生命周期价值），而不是只看粉丝总数。
- [ ] 如果你有流量但不会变现，立即开始尝试直播，或寻找有变现能力的操盘手合作。
- [ ] 如果你目前是打工人，每天问自己一次：我是在“攀附”老板，还是在为自己的“公司”积累能力？
- [ ] 写一篇“我有什么nothing to lose”的清单，找到自己可以all in的领域。
- [ ] 关注平台供求关系变化：如果平台开始给你补贴或免费流量，全力投入；如果开始收过路费、严管规则，说明红利窗口在关闭。
