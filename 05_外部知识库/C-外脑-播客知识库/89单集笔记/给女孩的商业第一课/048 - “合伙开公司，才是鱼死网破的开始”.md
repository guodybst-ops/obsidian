# 048 - “合伙开公司，才是鱼死网破的开始”

> 结构化说明：本笔记基于机器转写与清洗稿整理，属于 L4 萃取成品；原始音频、原始转写、清洗稿应继续作为原料保留。

## 一句话核心

IP 创业的第一件事，是把感情和商业分开，否则合伙开公司就是鱼死网破的开始。

## 摘要

本集从润宇老师亲身经历的1000万股权纠纷案切入，晓璐律师系统拆解了IP创业从注册公司、找合伙人、签MCN合约到融资、婚前财产隔离的全链条法律风险。核心观点是：好律师不是帮你赢官司，而是帮你避战；IP创业应先用个体户而非公司，把商标和著作权放在个人名下；合伙前必须想好怎么“拆”，而不是只想着怎么“合”。

## 故事与场景

1. **润宇老师的1000万股权纠纷**：润宇老师创业初期与合伙人随意分配股权（433比例），公司融资后估值1.5亿，合伙人按估值要求800万退出。润宇老师选择另起炉灶，却被合伙人起诉“掏空公司”。一审败诉后，公司账户被冻结，他把自己关在办公室流泪三天，最终自己写上诉状，二审翻盘，赔偿金额从800万降到约160万。
2. **晓璐律师的“三无”起点**：因父亲遭遇劳动仲裁而学法律，毕业后进小律所，整整接了两年电话。她用小本子记录各种离谱咨询，后来发现这些经历让她能半分钟内判断来电者是咨询、白嫖还是同行试探。
3. **MCN机构的“女朋友”模式**：晓璐律师直言，很多MCN机构老板有4个女朋友，就孵化4个达人，多签一个达人就是多一个女朋友。这种靠感情绑定的模式，最终往往被男运营带着女达人出去开夫妻店。
4. **直播间员工写错价格**：一个员工把200元商品写成2元，刷出去几万份，第二天就不来上班了。公司因层层绩效考核才减少损失，否则只能自认倒霉。
5. **妈妈拿着存折来执行**：晓璐律师帮MCN机构打赢官司，一个刚毕业的女孩背负20万违约金，她妈妈拿着家里存折来求情，说“可不可以少一点”。晓璐律师内心非常纠结。
6. **AI直播的刑事风险**：有客户找晓璐律师做AI无人直播的法律服务，技术已能绕过平台识别。晓璐律师评估后认为涉及“帮信罪”等刑事风险，拒绝了这笔6位数的单子。
7. **刑事辩护的最后一案**：晓璐律师办的最后一个刑事案子是杀妻案。丈夫因妻子拒绝拿出身份证给患眼疾的孩子贷款，用砖头拍死妻子。全村写求情信，但法官迫于女方家属压力，最终仍判死刑。从此她转做产业律师。

## 核心概念

1. **一人公司 vs 个体工商户**
   - **是什么**：一人公司只有一个股东，个体工商户是个人经营。
   - **为什么重要**：一人公司容易被“揭开公司面纱”，股东需自证财务独立，否则承担连带责任；个体工商户税负更低，且个人可以注册商标。
   - **原文例子**：晓璐律师建议IP创业先用个体户，把商标放在个体户里，等需要融资时再“个转企”。

2. **有限责任公司面纱（揭开公司面纱）**
   - **是什么**：公司股东仅以出资额为限承担责任，但如果股东与公司财务混同，法院可“揭开面纱”让股东个人承担连带责任。
   - **为什么重要**：润宇老师一审被判个人赔偿800万，就是因为法院认为他个人与公司财务未隔离。
   - **原文例子**：一人公司、夫妻店（视为一人公司）最容易触发此风险。

3. **公司章程**
   - **是什么**：公司的“宪法”，规定股东权利义务、决策机制、退出机制等。
   - **为什么重要**：大部分创业者不看章程，全由代办写，发生纠纷时才发现章程里什么都没约定。
   - **原文例子**：润宇老师的股权纠纷，根源就是章程里没有约定退出价格和机制。

4. **财产保全（冻结）**
   - **是什么**：诉讼中原告可申请法院冻结被告的银行账户、股权等资产。
   - **为什么重要**：立案本身就是武器，不需要赢你，冻你三个月公司就死了。
   - **原文例子**：润宇老师被起诉后，公司账户和股权被冻结，无法发工资、无法融资，被迫接受调解。

5. **对赌协议**
   - **是什么**：投资人与创始人约定，若公司未达业绩目标，创始人需回购股权或赔偿。
   - **为什么重要**：融资的钱是要还的，甚至要双倍吐出去。
   - **原文例子**：晓璐律师说，双倍赔偿是远远不够的，如果拿了钱过了三五年，要双倍也不算过分。

6. **婚前财产协议 / 婚内财产公证**
   - **是什么**：夫妻双方约定婚前及婚后财产归属的法律文件。
   - **为什么重要**：IP的账号、商标、著作权是核心资产，离婚时可能被分割。
   - **原文例子**：晓璐律师建议IP创业者做婚前背景调查，看看对方有没有刷爆信用卡、赌博等恶习。

7. **项目制公司**
   - **是什么**：为特定项目（如一个综艺、一个IP合作）成立的公司，有明确期限和使命。
   - **为什么重要**：可以快速拆和解，避免一个项目出问题拖垮整个公司。
   - **原文例子**：影视行业一个剧成立一个公司；晓璐律师建议IP创业者不要奢望公司百年基业，每个公司应有自己的使命。

## 我的批注

> [!NOTE] 法律是商业的底层操作系统
> 润宇老师的案例说明，不懂法不是“省了律师费”，而是把商业命脉交给对手。立案、财产保全、章程条款，每一个都是可以凌驾在商业之上的武器。IP创业者必须把法律认知提升到与内容创作同等重要的位置。

> [!NOTE] “好律师帮你避战”是极高的商业智慧
> 晓璐律师反复强调“不是帮你赢，而是帮你避战”，这与润宇老师“输也许是一个很好的策略”形成呼应。商业诉讼的本质是成本博弈，赢了官司输了时间、名誉、商业机会，是最大的失败。

> [!QUESTION] 个体户模式是否适用于所有IP创业者？
> 晓璐律师建议先用个体户，但个体户无法融资、无法给员工期权。当IP需要规模化、需要引入合伙人和资本时，个体户的局限性如何解决？是否有更优的过渡方案？

## 可行动清单

- [ ] 注册个体工商户，而非直接注册公司，把商标放在个体户名下。
- [ ] 找专业律师审查公司章程，重点约定退出机制、股权转让价格、决策机制。
- [ ] 建立个人资产与公司资产的隔离：独立银行账户、独立账目、不随意从公司拿钱。
- [ ] 所有重要沟通（尤其是涉及股权、利益分配）留痕：用文字而非语音，保存聊天记录。
- [ ] 签MCN合约前，明确合同目的（涨粉、接项目、破圈），并确保写在合同里。
- [ ] 区分成本分润和利润分润，要求MCN机构明确成本构成。
- [ ] 在MCN合约中争取“磨合期”或“考核期”，双方可在一定期限内任意解除。
- [ ] 融资时优先选择成熟机构投资人，谨慎接受自然人股东（尤其是熟人）。
- [ ] 给投资人看BP时，加水印、加保密声明，防止方案被抄袭。
- [ ] 婚前做背景调查：查征信、查负债、查是否有赌博等恶习；考虑签署婚前财产协议。
