# 030 - 范总再谈个人IP，如何把你的弱点变成你的特长，传播出去？

> 结构化说明：本笔记基于机器转写与清洗稿整理，属于 L4 萃取成品；原始音频、原始转写、清洗稿应继续作为原料保留。

## 一句话核心

做个人IP不要用冲刺打法，要日拱一卒，把弱点变成特点，基于真实的自己长期输出，等待胜利。

## 摘要

范卫锋（高樟资本创始人）在深圳线下分享自己5个月做播客的经验。他强调做IP不能冲刺，要像董宇辉那样日复一日打磨内容，相信量变到质变。他选择播客是因为投入时间成本低（每期2小时），且用户天然筛选过。他提出“有矿的人”更适合做知识付费——把日常工作积累的素材直接输出。定位IP要挖掘自己的真实热爱和人生低点，把弱点变成特点（如他喜欢聊干货、情商低，反而成为独特风格）。他还讨论了投资人做IP的难点、如何判断自己是否适合商业化、创始人需要直接面对客户而非依赖招聘等观点。

## 故事与场景

- **董宇辉出圈**：董宇辉在出圈前，已经用同样的话术卖牛排卖了3个月，每天重复50遍，他并不知道6月8号那天会出圈，也不知道这样的日子要存在多久。
- **范总的朋友做抖音**：一位前抖音员工、创业公司合伙人，辞职后做抖音教消费品公司做IP，拍了二十几期只涨了400个粉丝。范总看到这个数据后，意识到自己以前放弃得太早。
- **范总自己的播客起步**：第一期800粉丝（强推刷脸），第二期2000粉丝，然后停滞。他做好了心理建设，即使不成功也持续做下去，因为每期只花2小时。
- **知识星球创始人吴鲁佳**：范总做播客后，有听友加他，自称是知识星球创始人，后来两人见面，范总因此开了自己的知识星球。吴鲁佳说“有矿的人”才适合开知识星球。
- **范总投过的传统媒体主编**：一位很有水平的主编，很多媒体大佬曾是他下属，但他做的号没有做大，核心原因是他并不想挣那么多钱，不够“O”（商业导向）。
- **范总的人生低点**：他提到自己上一份工作在国有媒体，每天真正工作不超过2小时，有大量时间读书，积累了大量素材（笔记20万字）。
- **范总的小助理**：范总让小助理大胆剪辑，因为小助理有灵气，而他自己会舍不得剪掉对用户无价值的内容。

## 核心概念

- **日拱一卒**：不是冲刺打法，而是抱着信仰每天做一点，即使没有证据证明会成功也坚持。例子：董宇辉每天重复卖牛排3个月，不知道何时出圈。
- **击球区理论**（巴菲特）：只打击落在你最擅长的击球区的球。范总做选题只选自己熟悉的话题（如茅台瑞幸），越准备的内容效果越差，越不准备的内容效果越好。
- **道法自然**：做真实的自己，把优点和弱点都充分表达，自然吸引同频的人。范总用道德经的思维做IP，核心就是“道法自然”。
- **有矿的人**：指本身有长期积累的素材、经历、笔记等，可以直接输出而不需要专门为IP去学习新东西。例子：范总创业以来积累了20万字笔记，能发三年知识星球。
- **四气**（范总看创始人的框架）：杀气（胆子大）、灵气（同一事情能想到不同答案）、志气（想做大事）、正气（走得远）。
- **弱点变特点**：范总喜欢聊干货（流量天敌）、情商低、提问直接，这些弱点别人学不去，反而成为他的独特风格。
- **功利体系与非功利体系**：功利体系是社会给你明确评判标准（如奥赛获奖、北大清华）；非功利体系是纯粹兴趣驱动（如业余烹饪赢得家人认可）。两者都是你的“矿”。
- **红利**：社会变化红利（宠物、不婚、老龄化）、技术变化红利（平台红利如播客）、政策变化红利。范总提醒不要觉得“太晚了”，段永平说“敢为天下后”。

## 我的批注

> [!NOTE] 范总强调“读书对创业没什么用”这个观点很有冲击力，但需要结合上下文理解。他指的是不要依赖书本理论去创业，而应该直接面对客户、在实践中学习。他本人非常热爱读书，但认为创业需要的不是更多书，而是行动。

> [!NOTE] “把弱点变成特点”是一个很实用的IP定位策略。范总承认自己“喜欢聊干货”是流量天敌，但正因为这个弱点，他吸引的是真正想听干货的深度用户，反而形成了差异化。这提示我们不必强行模仿别人的优点，挖掘自己的独特之处（包括缺点）可能更有效。

> [!QUESTION] 对于普通人来说，如何找到自己的“击球区”？范总说“你越没准备的内容效果越好”，但前提是你真的熟悉那个话题。如果一个人没有明显的特长或积累，该如何开始挖掘自己的击球区？

## 可行动清单

- [ ] 每天固定花少量时间（如2小时）做内容，坚持至少3个月，不追求短期爆款。
- [ ] 列出自己的优点和弱点，思考如何把弱点转化为特点，并尝试在内容中呈现。
- [ ] 选择一个投入时间成本低的平台开始（如播客），降低放弃概率。
- [ ] 建立自己的“素材矿”：把日常工作、见人、读书的笔记积累起来，定期整理。
- [ ] 设定一个商业目标：第一次有人愿意给你钱（哪怕200元），作为IP商业化的第一个里程碑。
- [ ] 计算自己的收支平衡点（个人或小团队每月花费），以此作为收入目标。
- [ ] 直接面对客户/用户，在实践中学习商业，不要幻想招聘一个懂商业的合伙人。
- [ ] 每周复盘内容数据，关注微小进步（如从涨2个粉到涨20个粉），给自己正反馈。
- [ ] 找到自己“眼里有光”的话题，围绕它持续输出，不要追逐热点。
- [ ] 读德鲁克的一句话：“勇敢的将时间和长处集中到明天的机会和成果上”，并每天检查自己是否在这样做。

## 对话稿

**斯斯**：高樟已经不投IP了，您为什么自己出来做个人IP？

**范总**：原来是把IP变成一个商业公司，现在是把IP变成我的生存方式，相当于品牌直播。原来我们投资相当于赞助了媒体，现在要覆盖新的受众，就得自己做。

**斯斯**：做IP到底是变难了还是变容易了？

**范总**：不让上市就没有投资价值了，但可以做。最坏的结果就是花了一点时间，你没有东西可以失去。

**听众**：怎么判断自己选的IP路线对不对？什么时候该放弃？

**范总**：验证自己不行很快，一个月就能看到数据变化。董宇辉出圈前已经有明显的上升曲线了。你看到纹丝不动，但内部看可能是波澜壮阔的进步（从涨2个粉到涨20个粉）。

**听众**：一个人做IP，怎么设定合理目标？

**范总**：第一次有人愿意给你钱（哪怕200块）是很硬的标准。另外，算自己的收支平衡点，收入超过原来主业的一倍就说明可能行了，超过三倍就很行了。

**听众**：专业型人才想往创始人发展，需要什么商业思维？

**范总**：直接去面对客户、去挣钱，在实践中学习。不要幻想招聘一个懂商业的合伙人，早期你找不到。每个客户都是你的培训老师。

**斯斯**：范总，您说读书对创业没什么用，那创业者该读什么？

**范总**：鸡汤书有价值，在你泄气时打气。商业管理类看德鲁克就够了，记住一句话：勇敢的将时间和长处集中到明天的机会和成果上。

**斯斯**：您怎么看待“站着把钱挣了”这个说法？

**范总**：问这句话的人以为跪着就能赚到钱。事实上，这年头跪着也赚不到钱，很多时候你不但跪着，还得舔，而且舔的竞争还很激烈。

**听众**：投资人做IP和普通人做IP有什么不同？

**范总**：更难。投资人有抽象思维、逻辑强，这些是流量的天敌。他需要把抽象和具象结合起来，还要忘掉自己练的武功，很难。

**范总**：我投错的项目，大部分不是对才华的错判，而是这个人其实并不想挣那么多钱。你要挣钱就必须狠狠地想挣钱。
