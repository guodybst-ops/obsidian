### 001｜六层楼 从妇产科医生到科普大V：我没有当逃兵，只是去了更前线

- 来源：[[06-Library 资料/播客笔记/给女孩的商业第一课/001 - 六层楼 从妇产科医生到科普大V：我没有当逃兵，只是去了更前线|001 - 六层楼 从妇产科医生到科普大V：我没有当逃兵，只是去了更前线]]
- 主题：B08｜健康医美与消费品案例
- **第一次被妇产科手术震撼**：一台卵巢癌复发手术，肿瘤长到膀胱、肠道、肝脏，手术口巨大，从下午3点做到凌晨3点。术后患者恢复良好，能跟家属说话，六层楼说“那个成就感嗡一下就上来了，不行，我要干这个”。
- **第一个在手术台上离世的病人**：多年重复同一个噩梦——到处出血，所有血管都在流，麻醉机警报声，主刀喊“快去取血”，血压没了，心跳没了。患者早上9点28分或32分走。
- **辞职后在地铁上大哭**：拿到离职证明后坐地铁回家，跟大学同学说“我得当逃兵了”，哭得跟傻子一样，那时还不流行戴口罩。
- **导师算账**：导师说“我这辈子看的病人是有数的，做了多少台手术都有记录。你去做科普，能帮的人没数，统计不出来。而且你不写，就有人乱写。”
- **父母从不接受到同意**：父母在河南小城市，觉得儿子在北京三甲医院工作很光荣。六层楼先“灌迷魂汤”说心累、焦虑，然后让父母来北京住两个月，看到自己每天睡4小时、夫妻吵架，父母最终说“想辞就辞吧”。
- **白带照片咨询**：有人发内裤照片带滤镜，灯光不好，六层楼比喻像鉴宝节目“保友啊，给我拿近一点”。他提醒隐私安全，不建议发照片。
- **读者成长**：有读者说“我现在已经不看老六的东西了”，因为过了那个阶段。六层楼说“人生总要分别，这是好事”。
- **第一天当医生**：在6楼出门诊，兴奋，觉得新世界打开了。第一台手术领导递刀时，瞬间忘了怎么拿，但很快进入状态。缝伤口要缝得漂亮，针脚间距均匀，看着愈合好有成就感。

### 002｜荐见：普通人如何训练自己讲故事的能力

- 来源：[[06-Library 资料/播客笔记/给女孩的商业第一课/002 - 荐见：普通人如何训练自己讲故事的能力|002 - 荐见：普通人如何训练自己讲故事的能力]]
- 主题：B02｜内容 IP 与创作者商业化
- **荐见研二实习经历**：2001年山西运城发生贿选事件，荐见作为实习记者被派去采访，3天内联系所有当事人，完成报道。主编朱伟一个字没改就发了，并说“赶紧把这个人留下来”，荐见因此转正。
- **朱伟的评价**：朱伟说荐见的报道“空间感特别好”，荐见多年后才理解这个评价的含义。
- **昆山龙哥故事**：荐见写龙哥（昆山反杀案当事人）时，从龙哥进入北京的时代背景切入，展现小人物与时代的关系。
- **法子英与劳荣枝故事**：荐见选择从劳荣芝在出租屋的现场切入，而非法子英枪战的现场，因为这个空间包含了更多悬念、人物关系和事实冲突。
- **吴勇故事**：吴勇拒绝精神病鉴定，说“如果我承认自己是精神病的话，我前面所做的那一切还有什么意义呢？”荐见用这句话做结尾，并从废弃铁路上的命案场景开始讲述。
- **文强故事**：文强从业务能力到贪腐500万的过程，每一层冲突都环环相扣，展现人性中善与恶的斗争。
- **南丹矿难细节**：矿主黎东明喜欢闻花香，在床下挖地下室种花，管子连到床头。这个细节让读者在长文中“醒过来”。
- **凶宅故事**：一个女孩因父亲杀母成为老赖，所有线索都指向那套福利分房。荐见用“凶宅”作为标题和中心点，展现一代人的宿命。

### 003｜和知乎副总裁张宁聊一聊，内容的黄金10年和创作者的从0到1

- 来源：[[06-Library 资料/播客笔记/给女孩的商业第一课/003 - 和知乎副总裁张宁聊一聊，内容的黄金10年和创作者的从0到1|003 - 和知乎副总裁张宁聊一聊，内容的黄金10年和创作者的从0到1]]
- 主题：B02｜内容 IP 与创作者商业化
- **斯斯的论坛时代**：2012-2013年，斯斯每天用马甲切换器伪装成不同身份，在论坛做150次回复、发10个新帖，完全从传统论坛形式起步。
- **知乎邀请码改变命运**：2013年，斯斯通过知乎用户“仓思基”获得邀请码，认识了人人游戏副总裁郭亮，得以从北方小城来到北京。
- **斯斯在罗辑思维**：2014年，斯斯进入罗辑思维（当时已有500万关注），问罗胖为何露脸，罗胖回答“人脸是世界上最容易被记住的东西”。
- **张宁学车刷今日头条**：2014年，张宁在东方时尚学车时第一次用今日头条，发现算法精准推送最新交规（闯红灯扣6分），感到“汗毛倒立”。
- **半佛的起步路径**：半佛先做知乎积累粉丝，再做公众号，2019年底才开始做B站。第一个视频因B站不能传音频，用表情包怼出来，主要靠文案和梗密度取胜。
- **张宁在沙龙现场被误认**：张宁提前到达沙龙现场，工作人员问“请问您是谁”，他说“我是张宁”，对方才反应过来。斯斯认为这种“中年商务男混在漂亮妹子中”的冲突感本身就是“混剪”。
- **B站猛男版新宝岛**：B站第一条破亿视频，舞步和BGM节奏恰好对上，因极度违和而爆火，是“混剪”的典型案例。
- **巫师财经的“以我为准”**：该梗符合巫师财经“讲金融的霸道总裁”人设，成为其标志性表达。
- **斯斯邀请脱口秀女艺人被拒**：斯斯用心邀请一位脱口秀女艺人跟拍两天做纪录片，对方回复“你在跟我搞笑？现在影视化已经快餐到这种地步了”，说明对方根本没看过斯斯的内容。
- **YouTube游戏纪录片创作者**：两人自费飞到芬兰采访赛博朋克游戏公司，好几个月才出一个片子，靠用户每月订阅打赏维持，用户说“如果你们不支持，他们必须回大公司上班”。

### 006｜和Spenser一起聊聊内容型公司的变现密码

- 来源：[[06-Library 资料/播客笔记/给女孩的商业第一课/006 - 和Spenser一起聊聊内容型公司的变现密码|006 - 和Spenser一起聊聊内容型公司的变现密码]]
- 主题：B02｜内容 IP 与创作者商业化
- **Spenser的爆款文章经历**：2016年，Spenser写了《没事，别想不开去创业公司》，文章爆火，阅读量达500万，引发大量讨论和争议，甚至上了微博热搜。他通过这篇文章吸引了大量创业者和投资人关注，并因此结识了经纬创投的合伙人。
- **Spenser与黄有璨的互动**：三节课的黄有璨写了一篇批评Spenser价值观的文章。Spenser主动在后台留言，两人因此加微信认识，黄有璨说“大家都是流量”，体现了创业者之间的互相借力。
- **Spenser与蓝血奢牌的合作**：斯斯观察到，Spenser与某顶级蓝血奢牌合作时，与品牌负责人聊了一个多小时，不断收集信息，第二天就能与对方愉快攀谈。斯斯认为这是Spenser商业能力强的体现。
- **Spenser的“严肃买房”项目**：Spenser分享了一个商业路径设计案例：先收3999元会员费，招满1000人；然后找到各城市房产管家公司，收取20万代理费，将精准会员导流给它们；同时自己组织团购。半年内收入约1000万，且不承担交付成本。
- **斯斯卖货的困惑**：斯斯尝试带货时，发现卖1000-2000元的耳机卖得很好，但卖平价商品却卖不动。后来微博电商数据显示，她的用户画像中最多的是豪车用户，印证了Spenser的观点：用户画像必须精准，不能笼统概括。

### 007｜2年出了7本书，和吕白一起聊聊如何让钱为你打工

- 来源：[[06-Library 资料/播客笔记/给女孩的商业第一课/007 - 2年出了7本书，和吕白一起聊聊如何让钱为你打工|007 - 2年出了7本书，和吕白一起聊聊如何让钱为你打工]]
- 主题：B06｜职场组织与管理
- **吕白的暴富与挥霍**：19岁赚到人生第一个100万后，开始买各种带logo的东西（LV、Gucci），袜子都是爱马仕的，一年蹦迪花了40多万。后来发现凭运气赚到的钱留不住。
- **朋友圈展示技能**：吕白团队里有个PPT做得特别好的员工，入职3个月老板都不知道。另一个PPT做得没那么好的人，入职不久就发了一条朋友圈，老板就知道了。吕白自己每周至少发一条收获朋友圈，带来很多订单。
- **用更高欲望替代低欲望**：吕白想喝奶茶，但给自己定下“喝了奶茶就不能买苹果耳机”的规则，结果一个月没喝奶茶。朋友喜欢买口红，吕白建议她把买口红的钱攒下来做隐形眼镜手术，朋友真的做了。
- **会员积分改变生活**：吕白是万豪钛金会员，700元住套房，含免费早餐、下午茶、欢乐时光。他是南航金卡，花经济舱的钱享受优先登机、免费餐食。他用飞猪订票+联名信用卡+机票本身，实现“一个积分卖三次”，一年能换两张免费机票。
- **投资酒吧的洞察**：吕白之前蹦迪花了40多万，后来投了50万开酒吧。他利用对男性用户心理的理解（带妹子装逼），让25个朋友每人交1万会员卡，这些人又带朋友来消费，快速回笼资金。
- **投资烧烤店**：吕白投资了“柳叶刀”烧烤店，不是只出钱，而是用“技术+现金”的方式投进去——他能帮店家做抖音引流、写书，创始人觉得他能带来流量。
- **锦江之星 vs 万豪**：团队去上海拍片子，给吕白定了300块的锦江之星，没有桌子，他只能趴床上改稿。后来他算账，自己住万豪套房700元，含三餐，反而更划算且效率更高。
- **朋友买特斯拉股票**：吕白的朋友觉得马斯克特别牛逼，70美金买入特斯拉股票并 all in，拿到700多美金，翻了10倍，直接财富自由。吕白自己70美金买入，20%-40%就止盈了。

### 008｜什么样的老板值得跟随？

- 来源：[[06-Library 资料/播客笔记/给女孩的商业第一课/008 - 什么样的老板值得跟随？|008 - 什么样的老板值得跟随？]]
- 主题：B06｜职场组织与管理
- **1. 从产品经理到创业者：第一次失败不是结束**：连勋原本学计算机，正常路径可能是成为码农，但他后来成了产品经理。大学期间，他在宝洁做过 marketing，也在微信做过产品经理实习。毕业时，他没有接受大厂 offer，而是直接创业做社交产品。 这次创业很快失败。投资人劝他说“公司别做了，你过来做投资吧”，但连勋当时不愿意接受，因为他觉得创业这件事还没有做完。后来，他遇到另一位连续创业者，两个人一起做了一家 To B 的 SaaS 公司。 这段经历给他的结论是：创业会迅速拆掉人的幻觉。它会让你发现世界没那么美好，自己也没那么厉害，人会在过程中撞得头破血流。
- **2. To B 与 To C：成就感来源不一样**：连勋做 SaaS 公司两年后，公司其实并不差，也拿到了后续融资。但他意识到，自己的性格并不适合长期做 To B。他可以签单、服务客户、获得客户信任，但这件事并不能持续给他成就感。 他把 To B 和 To C 的差异拆开看：适合 To B 的人，往往能从成就客户、服务客户里获得很大满足；而他自己更喜欢创造产品，让大量消费者因为产品本身好而开心、认可、喜欢。 这不是说 To B 不好，而是每个人的成就感来源不同。对他来说，征服高端客户不如让每一个小 C 产生真实反馈更让他兴奋。
- **3. 不要为了钱选择不相信的事情**：连勋讲到，很多人在职业选择上会因为薪资、平台、热门程度等因素去做一件自己并不相信的事。但工作每天至少占八小时，如果长期处在不认可的事情里，工资本质上就变成了精神损失费。 他举例说，有些人明明喜欢互联网，却因为当时互联网薪资没有那么高，去了外企或消费品公司。短期看可能也不错，但未来某一天可能会意识到，自己真正想做的其实不是那条路。 他的建议是：至少选择一个自己做起来开心、认可、愿意投入的赛道。公司可以有好有坏，团队可以有各种问题，但人要先站在一个自己愿意长期投入的方向上。
- **4. 看行业：从上下游和话语权开始**：在聊到如何看行业时，连勋以电竞行业为例做拆解。电竞行业的上游是游戏公司，因为有游戏才有电竞；中游是赛事组织，游戏方授权赛事方组织比赛；下游是俱乐部和选手，他们参加联赛、形成竞技内容；更终端则是粉丝、玩家和消费者。 这个例子说明，看行业不能只看表面热度，而要看产业链的上下游关系，以及谁真正拥有话语权。不同产业里，主导权可能在上游，也可能在下游，要具体分析。 他也提到自己理解行业的方式是聊天：找行业里的人聊，再把信息抽象、归纳成自己的判断。刚开始不懂没关系，可以先聊一圈，反复验证不同人的说法，慢慢就会知道谁专业、谁不专
- **5. 看创始人：眼里有没有光**：连勋认为，判断一个创始人，最重要的方式仍然是聊天。好的创始人会对自己做的事有信念。他不是只想忽悠你加入，而是真的相信这件事有价值。 他观察到，优秀创始人往往带着一种“因为相信所以看见”的气质。很多后来成功的项目，在早期都没有先例，也会被人质疑“没人这么做过”。但真正的创始人会反问：凭什么没人做过就不能做？凭什么消费者不会为好东西买单？ 对于消费品公司，除了看创始人，还可以看消费者反馈。如果消费者对品牌有热情，愿意支持它、接受它成长中的不完美，这家公司就有可能正在建立真实关系。
- **6. 看老板：愿不愿意在你身上花时间**：在“什么样的老板值得跟随”这个问题上，连勋给出的标准很朴素：老板首先要相信自己做的事，其次要愿意在你身上花时间。 他回忆自己刚开始做投资时，连 Excel 都做不好，是老板手把手教他。他认为，如果工作中有人愿意指出你的不足，是很幸运的事情。年轻人不应该太玻璃心，也不应该把所有严格反馈都理解成 PUA。 他强调，人要客观看待工作里的对错。错了就认，快速吸收新的东西，而不是为了自尊心死扛。一个能让你看见问题、提升判断、不断成长的老板，比一个只让你舒服的老板更值得跟随。
