# 066 - 和冷爱求道：野心、能量与重新成为老板
> 结构化说明：本笔记基于机器转写与清洗稿整理，属于 L4 萃取成品；原始音频、原始转写、清洗稿应继续作为原料保留。

## 一句话核心
2025年的野心不再是横向扩张，而是向内纵深“提频”，通过建立秩序、边界和“自己人”体系，重新成为真正的老板。

## 摘要
斯斯因目睹过去采访的野心女孩纷纷陷入低谷而困惑，与冷爱探讨2025年野心的新方向。冷爱提出“大转型”比喻，认为野心应从扩张转向纵深，通过“提频”连接内在高频能量。他们讨论了失序与秩序、如何成为老板（区分创始人与CEO）、培养自己人、处理背叛、金钱容器等。核心是：女孩需要拥有自己的空间，建立边界，发展本能，用菩萨心肠加霹雳手段。

## 核心概念
- **大转型**：从海洋到陆地的比喻。过去扩张型野心（像鲸鱼）不再适用，需要敏捷灵活（像人类）。例子：鲸鱼在海洋大，陆地恐龙灭绝。
- **提频**：不是升阶（向外发展），而是向内连接本有的高频能量。例子：观察者自我（全频道运行）与喜怒哀乐自我的区分。
- **秩序与边界**：通过拥有独立空间（院子、房间、身体）建立边界，避免被消耗。例子：冷爱的院子，斯斯拉黑消耗的人。
- **创始人与CEO**：创始人向外（钱、事、人），CEO向内（管理、财务）。例子：冷爱管投融资，合伙人管财务。
- **自己人**：超越对错，本能跟随，关键时刻能处理脏事。例子：兄弟团，猎手老师去和解用户。
- **金钱容器**：每个人能承载的财富有限，通过体验（租院子、坐公务舱）扩大容器。例子：冷爱建议先借势体验，提升配得感。
- **一司两制**：对兄弟姐妹讲义气，对员工讲契约。例子：冷爱有兄弟团，其他员工按制度管理。

## 我的批注
> [!NOTE] 冷爱提出的“提频”概念非常实用，不是向外追求更高，而是向内连接本自具足的能量。这为焦虑的创业者提供了新的心法，尤其适合在“失序”中寻找稳定感。

> [!NOTE] 关于“自己人”和“一司两制”的论述，揭示了创业中人情与制度的平衡。很多女性创业者容易陷入“好人”陷阱，需要学会区分兄弟姐妹和员工，避免混为一谈。

> [!QUESTION] 冷爱说“老板的格局不是靠委屈变大的”，但现实中很多老板确实经历了委屈。如何区分“委屈”和“必要的忍耐”？是否有可操作的判断标准？

## 可行动清单
- [ ] 每天花5分钟练习“观察者”状态：观察自己的情绪和念头，不陷入其中。
- [ ] 为自己创造一个独立空间（一个角落、一个房间），每天固定时间待在那里。
- [ ] 列出消耗你能量的人，考虑拉黑或减少接触。
- [ ] 重新审视公司角色：明确自己是创始人还是CEO，或者需要找一个互补的合伙人。
- [ ] 识别团队中的“自己人”：那些在你困难时依然跟随的人，给予更多信任和培养。
- [ ] 对“有才无德”的人采用“一把一利索”的交易模式，不投入情感。
- [ ] 尝试一次高价值体验（如好的spa、课程），提升配得感。
- [ ] 学习基础逻辑学，提升理性决策能力。
- [ ] 组织一次核心团队的聚餐，聊一些不能播的话题，加深连接。
- [ ] 制定公司规章制度，并确保创始人带头遵守（或让CEO执行）。

## 对话稿
- **斯斯**：我拍过那些最风光的女孩，今天大家纷纷走到谷底，我想知道为什么。
- **冷爱**：这是一个大转型，从海洋到陆地，需要进化出新的能力。
- **斯斯**：2025年野心已经不流行了吗？
- **冷爱**：野心要越来越往下沉，不是横向扩张，而是纵向探索。
- **斯斯**：提频跟升阶有什么区别？
- **冷爱**：升阶是向外发展，提频是向内连接你本来就有的频率。
- **斯斯**：怎么建立不被消耗的秩序？
- **冷爱**：你需要一个自己的空间，哪怕是一个角落，这就是边界。
- **斯斯**：我和我的朋友都不会当老板，怎么重新学习？
- **冷爱**：先区分你是创始人还是CEO。创始人管钱、事、人（向外），CEO管内部管理。
- **斯斯**：怎么识别自己人？
- **冷爱**：在你最困难发不起工资时还跟着你干的人，就是自己人。
- **斯斯**：怎么处理背叛？
- **冷爱**：背叛是必然，维度提升后你会理解对方的情非得已。
- **斯斯**：怎么扩大金钱容器？
- **冷爱**：先借势体验，比如租院子、坐公务舱，提升配得感。
- **斯斯**：菩萨心肠和霹雳手段怎么平衡？
