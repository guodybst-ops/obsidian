# 147 - 10倍增长比2倍更容易？新年一起告别无效努力！

## 一句话摘要

凯丽鹏对谈：10x是杠杆思维虚指，用4C公式、三句话拆解、收获思维告别无效努力，让热爱赚钱。

> "我直播再多次，我一天24小时都直播，我可能也达不到10倍的增长。那我就得想想看我这个方是不是要变化。"

> "10倍增长是一个虚指，两倍增长是线性增长，10倍增长可以理解为指数型增长或者创新型增长。"

> "厉害的人是因为相信所以看见。但是我们其实很多人还是因为看见，所以相信。"

> "在这个时代，有了自媒体，没有怀才不遇。"

> "把热爱变成事业解决的是从0到1启动的问题，10倍增长解决的是从1到100的问题。"

> "变损失为收获才是一个人真正的成长。每一次10倍增长中的20%，都是建立在上一次10倍增长的20%之上。"

## 要点提炼

### 10x = 杠杆思维虚指，不是死盯数字

- 10倍是虚指，本质是"用更少的时间赚更多的钱"的效率倍数。
- 两倍增长是线性增长（100W→200W→300W），10倍增长是指数型/创新型增长。
- 直播拉时长可以拉高 GMV，但不一定拉高利润；一天24小时都直播也达不到10倍。
- 关键不是频率、量的堆叠，而是"这个方向要不要变、这个产品要不要变、其他杠杆能不能用上"。
- 每个人的10倍周期不一样：有人两年，有人十年；巴菲特90%的财富是60岁以后才拿到的复利。

### 4C 公式（10倍增长节点的四大要素）

- **Commitment（承诺）**：我承诺去改变、去做什么、拿到什么结果。
- **Courage（勇气）**：我有勇气做出改变。
- **Capability（能力）**：我有能力做出改变。
- **Confidence（信心）**：我相信我能做成。
- 凯丽鹏亲身案例：2017-2018 数据分析师→数据科学家（收入两倍以上跃迁）；2022 裸辞→内容创业（一分钱不赚起步→年入百万+跃迁）。

### 因为看见所以相信（vs 马云"因为相信所以看见"）

- 马云版信念感对大多数人过高，普通人是"因为看见所以相信"。
- 信心从两处来：**过去的自己**（小事累积的正反馈）+ **外部参照系**（榜样、身边同频的人做成了这件事）。
- 凯丽的榜样：Lenny（前 Airbnb 同事，现全球科技领域第一名 Podcast，Substack 排第一，团队<10人全外包，每年放几周长假）。
- 小辉的看见：小红书上"搞钱女孩"标签本身就是她"看见"的产物。

### 自媒体两派：创作者派 vs 商人派

- **发传单派/商人派**：狗皮膏药式高频铺量，不管质量，靠曝光和产品变现。
- **精雕细琢派/创作者派**：影视飓风、Links、MrBeast，一部作品打磨一个月以上，作品实现破圈。
- 中间派/组合派：影视飓风、全息西（内容+直播带货搭档），但需要战略搭档在商业侧操盘。
- 起点是"发传单"（日更快速测试、找标签、MVP），阶段稳定后转向"精雕细琢"。
- **不要一起步就找合伙人搭团队**——是大坑。

### 三句话公式：停止—开始—寻找

- **停止做什么**（80% 低效率的事情）：停止低客单价社群、停止低价商单、停止靠时间堆量的直播。
- **开始做什么**（20% 高杠杆的事情）：做深度私董会式产品、做穿越时间的爆款、找助理接管琐事。
- **寻找什么关键人物/资源**：优质嘉宾、高杠杆的合作伙伴、能补自己短板的专业助理。
- 凯丽的助理杠杆：找了一个"相当于全职"的兼职助理，解放大量不想做的时间→做高杠杆思考。

### 差距思维 vs 收获思维（面对负反馈）

- **差距思维**：拿了95分只看剩下5分，永远不够好，指标外部化。
- **收获思维**：只看瓶子里的水而不是空着的部分，每次搞砸都提炼收获。
- 凯丽的负反馈案例：2023 全息西"睡衣事件"站在大众情绪反面发视频→爆但都是骂。**收获**：不要站在大众情绪反面（除非那少数是你想吸引的人）、修炼强大内心。
- 小辉的年底 KPI 焦虑："今年小宇宙订阅80W→100W差20W"→凯丽提醒：涨粉是不可控目标，方向对了迟早会到，动作不必变形。

### 时间三分法：专注日 / 自由日 / 缓冲日

- **专注日**：进入心流状态，高效能创作/深度工作。
- **自由日**：探索、玩耍、解锁不同状态，比如朋友"每周一天学 AI"。
- **缓冲日**：领导角色下抽离琐碎事务，思考战略、给团队空间。
- 王潇趁早分5种时间（好看时间、好玩时间…）都属于 J 人极致分类。凯丽是 P 人：不硬分，只知道"哪几件事对我最重要"，其他交给助理。
- **关键点**：不管怎么分，你要知道自己在什么状态下效率最高。

### 睡前1小时用来规划（不刷手机）

- 睡前半到一小时刷手机→蓝光影响睡眠→第二天状态差→事情搞砸→情绪内耗→再失眠 → 恶性循环。
- 正确做法：写下今天复盘/明天最重要的三件事，让睡眠为第二天正循环做准备。

### 找热爱方法论：海量测试 → 心流 → 高光时刻

- 极少数幸运儿（Taylor Swift 8-9 岁学音乐、谷爱凌小时候学各种球、易烊千玺妈妈带上各种兴趣班）——爸妈提供了"海量测试"。
- 大多数人（东亚教育体制非此即彼）：要靠自己主动测试。
- 具体方法：性格测试（MBTI 基本操作）+ 副业项目尝试 + 观察哪个正反馈来得快 + 观察哪个容易进入心流 + 记录高光时刻（斯坦福《人生设计课》框架）。
- 尝试过程本身就痛苦（花钱花时间还不一定成），所以很多人到 60-70 岁都没找到，只好自我安慰"工作只是谋生"。

### 硅谷 vs 国内：创业者气质对比

- **硅谷**：更多热爱驱动、失败包容度高、长期主义视角更普遍。
- **国内**：更搞钱驱动、短周期视角、AI 风口下不乏投机形态。
- 搞钱创业者共性：**执行力/行动力强**（当天想当天落地）+ **翻篇能力强**（不内耗、不困在情绪里）+ **从人身上学**（找高人聊天而不是死读书，圈子杠杆）。

### 混子哥案例：热爱变事业的规模化范本

- 边画边讲历史→2019 全国作家榜第三（第一刘慈欣、第二余华），版税年入千万级。
- 起点：从小非常爱画画→用画画技能嫁接讲历史。
- 现在：漫画科普只是其中一版，还给中信银行等企业做定制商业插画。

## 关键问答

**Q1：10倍增长这个"10倍"是实指吗？如何理解？**
A：虚指，本质是杠杆思维。两倍增长是线性（日复一日堆量），10倍增长是指数型/创新型（换方向、换产品、换杠杆）。不要盯着数字，要盯着"更高的目标+对的战略方向"。

**Q2：目标定太高会不会像空想立 flag？信心从哪来？**
A：信心不是凭空来。①**内证**——过去自己在小事上做成过，累积对能力的笃定。②**外证**——因为看见（榜样、身边同频人做成），所以相信。凯丽用 Lenny 做榜样，小辉用小红书"搞钱女孩"标签流量做外部参照。

**Q3：日更 vs 精雕细琢，到底哪个对？**
A：分阶段。**起步 0→1**：日更、MVP、快速测试市场反馈，找自己的标签（杨天真"Plus size 女装""高情商"标签都是日更测出来的）。**稳定后 1→10**：停止用平庸作品糊弄自己，追求作品质量，一个爆款穿越时间。

**Q4：既想要好作品又焦虑停下来（东亚小孩内卷）怎么办？**
A：先厘清"你想成为谁"——创作者派 / 商人派 / 混合派？定义清了动作才对得上。凯丽自我定义：内容创作者优先，商业变现只是谋生。同时接受"内卷是对自己有要求"不等于"不接纳自己"，是全然接纳后想探索潜力极限。

**Q5：热爱不赚钱怎么办？**
A：这个时代有了自媒体，没有怀才不遇。就算是收藏盲盒的爱好，也能吸引到几万几十万同好。**热爱变事业解决从0到1（起步敢迈出+相信能卖出去）**，**10倍增长解决从1到100（选更大的赛道、搭对的产品）**——两本书要组合看。

**Q6：具体动作上怎么用"三句话公式"拆解目标？**
A：①**停止做什么**（80% 低效）——低客单社群、低价商单、时间堆量的直播；②**开始做什么**（20% 高杠杆）——找助理、做深度会员产品、打磨爆款；③**寻找什么资源**——优质嘉宾、能补短板的合作伙伴、可以借用的行业专家。

## 可复用方法

1. **10x 目标设定法**：不盯数字，盯"更高目标+对的方向+杠杆"。用一句自检——我这个方向要不要变？我这个产品要不要变？我还能撬动什么杠杆？

2. **4C 决策清单**：面对重大转型/目标时依次自检——我承诺了吗？我有勇气吗？我有能力吗？我有信心吗？四项都过关才是10x 节点。

3. **三句话拆解模板**：每季度做一次——①我要停止做的80%低效事情是___；②我要开始做的20%高杠杆事情是___；③我要寻找的关键人物和资源是___。

4. **时间三分模板**：把一周切成专注日（心流创作）+ 自由日（探索玩耍）+ 缓冲日（战略思考）。J 人硬分类，P 人只需知道"哪几件最重要"。

5. **睡前1小时规划仪式**：睡前放下手机→写下今天复盘/明天最重要三件事→为第二天正循环做准备（睡眠好→状态好→事情做对→情绪稳→再睡好）。

## 本集适合谁听

- **从0到1的自媒体新手**：想知道该日更铺量还是精雕细琢——分阶段答案在此。
- **卡在1→10的超级个体/一人公司**：营收/影响力增长瓶颈期，需要跳出"两倍思维"的人。
- **纠结热爱与赚钱的打工人**：不敢裸辞、觉得热爱不赚钱、找不到方向的人。
- **内卷型东亚小孩**：停不下来一停就慌、想学"更好地成为自己"而不是"成为更好的自己"的人。
