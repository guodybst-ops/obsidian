# 166 - 何一：我的野心，是去更大的世界看看！

## 一句话摘要

四川宜宾农村单亲家庭的老二女孩，靠"认知×执行力×勇气×运气"四支柱，从旅游卫视外景主持跃迁至币安联席 CEO，用"要么得到要么学到"的心态把每一次翻篇都变成资本积累。

## 金句 Top10

1. 我需要一个配得上我的世界——这是**原始野心**，不是模仿欲望。
2. **认知×执行力×勇气×运气**，四个角其中一角做到极致，其他会被顺势推起来。
3. 杀人偿命，欠债还钱，愿赌服输，自负盈亏——李碧华十六字箴言，一辈子够用。
4. **要么得到，要么学到**，人生没有失败这个选项。
5. 直觉不是玄学，是**认知知识图谱**沉淀后的快速处理系统（杨振宁语）。
6. 主动的人**先享受世界**。
7. **心硬对己，心软对人**——天上落刀子也扛过去。
8. 别人说我是"雄尽中的雄尽"、也有人解读我是"词敬中的词敬"，都是**别人的解读**，重要的是我自己知道我是谁。
9. 目标和动作要匹配——**知行合一**才是真的走在路上。
10. 我做老师**才可惜了**——农村小孩摘野花的反骨，比顺从更值钱。

## 要点提炼

### 老二定律与主体性觉醒（4岁吵上学的农村小孩）

- **老二定律**：老大照书养、老二放羊、老三宝贝——老二天然缺关注，反而**长出主体性**。
- 何一出生在四川宜宾农村单亲家庭，**4 岁自己吵着上学**（哥哥去上学她想跟着去），从最小的行动里争取选择权。
- 农村小孩的日常是**摘野花、爬树、上房揭瓦**——反骨与野性是童年伏笔，而不是需要被规训的缺点。
- 10 岁与大孩子赌博输了 5 元，母亲**竹笋炒肉暴打一顿**、勒令换对象继续赌把债还完——这一顿打让她一辈子记住"**愿赌服输、自负盈亏**"。

### 李碧华十六字箴言：一辈子的底层操作系统

- 童年阅读启蒙来自**村里废品站 + 租书店**——一分钱一本，什么都读。
- 李碧华 + 一书武侠给了她十六个字："**杀人偿命，欠债还钱，愿赌服输，自负盈亏**"。
- 这十六个字是**成年世界的通行证**：不奢求他人替你兜底，也不逃避自己犯下的错。
- 与"要么得到要么学到"合流——**没有失败**，只有认账和翻篇。

### 拒做老师：模仿欲望 vs 原始野心

- 宜宾师范毕业本该做小学老师，但她拒绝了："**我做老师才可惜了**"——这不是清高，是**原始野心**在讲话。
- **模仿欲望**（Girard）：想要的东西是因为别人也想要——绝大多数人的"野心"是模仿来的。
- **原始野心**：不参考任何人，"**我需要一个配得上我的世界**"——是内生的、无法伪造的驱动力。
- 识别方法：**把身边所有参照物拿掉**——如果你还想要，那就是原始的；如果你不想要，那是模仿。

### 认知×执行力×勇气×运气：四支柱人生方程

- 何一给成就归因四个变量：**认知、执行力、勇气、运气**——四个角。
- **不用四角都极致**——其中一角做到极致，会**顺势推起其他三角**。
- 认知是天花板、执行力是地板、勇气是发射器、运气是加速度。
- 应用：盘点自己四角的**当前分位**，把资源集中砸在最有优势的那一角，先破局再补齐。

### 从主持人到币安联席 CEO：13 年的认知重塑

- 职业跳跃路径：**宜宾师范 → 拒做老师 → 影楼平面模特 → 旅游卫视外景主持**（走遍中国景区）**→ 2013 年末研究比特币、写文章 → 2014 加入区块链公司当"客服小何" → 2015 离开 → 一下科技/小咖秀（经历千播大战）→ 2017 CZ 找去做顾问 → all in 币安**。
- 关键动作：**2013 年就开始写比特币文章**——她对新事物的**认知渗透期**比大多数人早了 5-8 年。
- 每一段看似"降维"的跳跃（外景主持→客服）其实是**重新采集认知素材**——积累到 2017 CZ 相中时，她已经是圈内少有的既懂互联网又懂币圈的复合型选手。
- 底层信念：**主动的人先享受世界**——不等风来，去造风。

### 直觉与第一性原理：认知的两种表达

- 引用杨振宁："**直觉不是神秘主义，是过往经验和认知在瞬间的高速处理**。"
- 每个人的直觉不一样，是因为**认知知识图谱**不一样——想让直觉更准，先把图谱补厚。
- **第一性原理**（马斯克造火箭案例）：**先射一条线，再倒推每一段成本与工艺**——绕开行业惯性，回到问题最本源。
- **推拉门决策**：能反悔的决定就大胆试；不能反悔的决定（推门只能推、拉门只能拉）要**慢想快做**。

### "雄尽中的雄尽" vs "词敬中的词敬"：别人的解读不重要

- 生意场上合作方评价她"**雄尽中的雄尽**"（不服软、能扛事）。
- 情感主播解读她"**词敬中的词敬**"（对自己的女性叙事很有主体性）。
- 何一态度：**都是别人的解读**——重要的是**我自己知道我是谁**。
- 女性叙事的陷阱是：不断被贴标签、不断被要求"站队"（够不够独立、够不够温柔）——**拒绝被定义**就是最强的女性主义。

### 心硬对己，心软对人：屠龙少年的立场选择

- **心硬对己**：天上落刀子也扛过去——不给自己任何"我做不到"的借口。
- **心软对人**：对下属、朋友、行业新人——**保留温度**，让自己在赢的过程中不成为屠龙少年。
- 屠龙少年悖论：打怪打到最后，容易活成自己讨厌的样子——**立场选择比能力选择更重要**。
- 何一的立场：**上帝会把资源给承担更多社会责任的人**——赢家的责任是**把梯子留下来**。

### 收官：要么得到，要么学到

- 面对翻篇：**没有失败这个选项**——赢了就是得到，输了就是学到。
- 面对不确定：**目标和动作匹配**——知行合一才是真的走在路上，光有目标是自我感动。
- 面对自己：**主动的人先享受世界**——世界不会等你准备好，去抢、去试、去承担。

## 关键问答（3-6 组）

**Q1：如何区分"原始野心"和"模仿欲望"？**
A：把身边所有参照物拿掉，如果你还想要，那就是原始的。何一说她想去更大的世界看看，这个渴望在四川宜宾农村时就有，不是任何人给她的。

**Q2：认知×执行力×勇气×运气，普通人如何入手？**
A：**先盘点四角的当前分位**——找出最有优势的一角，集中砸资源做到极致，再顺势推起其他三角。不需要四角都平均发展。

**Q3：李碧华十六字箴言对现代生活有什么用？**
A：它是**成年世界的通行证**——不奢求兜底、不逃避责任。用在合作里就是契约精神，用在感情里就是不做怨妇，用在事业里就是**愿赌服输**。

**Q4：面对"雄尽"、"词敬"这类外部标签怎么办？**
A：**都是别人的解读**——重要的是你自己知道你是谁。拒绝被定义比争辩"我不是"更有力量。

**Q5：屠龙少年怎么不变成龙？**
A：**心硬对己、心软对人**——把责任感留给下一代，把资源留给行业新人，让自己赢的路径也是别人可以复制的路径。

**Q6：如何用"要么得到，要么学到"面对失败？**
A：**取消"失败"这个词**——赢了是得到，输了是学到。人生不是单局游戏，是**长期主义的复利游戏**。

## 可复用方法（1-5 个）

### 方法 1：四支柱自检表（认知/执行力/勇气/运气）

- **步骤 1**：为自己四角各打 0-10 分，标出最高分和最低分。
- **步骤 2**：最高分那一角**加码到极致**——书、圈子、项目、时间预算全部倾斜。
- **步骤 3**：最低分那一角**只做底线管理**——不追求极致，只避免拖后腿。
- **步骤 4**：每 3 个月重新评估——最高分会顺势推起其他三角，评分格局会变。

### 方法 2：原始野心识别练习

- 拿出一张纸，写下你"想要的东西"清单。
- 逐项问：**如果没有任何人知道我拥有这个，我还想要吗？**
- 答"是"的留下（原始野心），答"否"的划掉（模仿欲望）。
- 把留下的原始野心作为**未来 3 年的资源分配核心**。

### 方法 3：推拉门决策法

- 每次做决定前，先问：**这个决定能反悔吗？**
- **能反悔（拉门可以变推门）**：**快做慢想**——直接试，边做边调。
- **不能反悔（生孩子、婚姻、辞掉稳定工作 all in 创业）**：**慢做快想**——想清楚再动手，动手就不回头。
- 应用：绝大多数决定都是"能反悔"的，人生停滞往往因为把太多决定当成了"不能反悔"。

### 方法 4：雄尽/词敬心态构建（拒绝被定义）

- 建立**自我叙事日记**——每天写 3 句"我今天证明了我是谁"。
- 当别人贴标签时，**在心里默念**"这是他的解读、不是我的定义"。
- 定期**清理反馈源**——远离总是给你贴标签的人，靠近能看见你本质的人。

### 方法 5：李碧华十六字应用清单

| 场景 | 十六字对应 | 具体动作 |
|---|---|---|
| 合作违约 | 欠债还钱 | 直接追责、不做圣母 |
| 投资亏损 | 愿赌服输 | 认账翻篇、不埋怨市场 |
| 感情结束 | 自负盈亏 | 复盘自己、不咒骂对方 |
| 职场冲突 | 杀人偿命 | 该刚就刚、不忍气吞声 |
