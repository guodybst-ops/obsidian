# 138 祝潇颖：30 岁逃离大厂开"假装上班公司"，搞钱让我绽放自己

## 一句话摘要

祝潇颖 30 岁从腾讯公关经理离职，做"大厂离职访谈"短视频串联深圳个体创业者，靠 8000 好友朋友圈 + 一张群二维码 60 元/首次的低门槛，在 100 平办公室开出"假装上班公司"，两个月吸引 500+ 大厂人；用低粉变现三梯度产品（10 元课/299 会员群/9000 陪跑）+ 讲师经济分成 + 人才推荐 + AI 副业尝试跑通闭环，验证了"你是什么样的人吸引什么样的人""解决像自己一样的人的需求""内容 + 圈子 + 服务闭环"的个体创业公式。

## 金句

> 当你自己是什么样的人，就会吸引到什么样的人。

> 最好的创业起点，就是解决像你一样有需求或者有困难的人。

> 我第一天假装上班什么都没有，公务椅子都没买完，就建了一个群、发了个朋友圈。

> 你有准备的创业，比一头热血冲出来靠谱得多。

> 我以前是一个花骨朵，现在我正在绽放。

> 我不用去证明我是不是腾讯的——真正需要我的人不会问这种低级问题。

> 低粉变现的核心是先跑闭环，不是先追爆款。

> 我从来不觉得自己聪明，我是笨鸟先飞，我只是愿意花更多时间。

> 每一种选择都是我当下最好的选择，所以我不后悔。

> 打不过的困难就先切割它——不破不立你才能有新的活法。

## 要点

### 假装上班公司：一张群二维码 + 100 平办公室的圈子生意

- 产品定义：100+ 平办公室对外开放，首次 60 元/天、续费 30 元/天
- 目标用户：大厂离职员工、暂时失业过渡者、大学生实习探路者、各行业个体创业者
- 供给：Wi-Fi / 空调 / 水 / 啤酒 / 红枣茶 / 跳棋围棋象棋
- 核心价值：不是工位，是"高浓度同频圈子"
- 两个月成绩：500+ 累计付费用户 + 陈鲁豫来采访 + 深圳晚报专访 + 南方人物周刊北京飞来体验

### 从 0 到 1 的第一天：一张海报都没有

- 建群"假装上班排队群"
- 发朋友圈（8000 好友）附二维码，没拍照片就发出去
- 首批 100+ 人进群
- 精髓：不要等准备好，先开门让人进来

### 大厂离职访谈博主起号路径

- 前置身份：腾讯公关经理，控制预算方，投过大量 KOL
- 切入定位：30 岁大厂人的去向——不做泛大众话题，专做"大厂人离职去哪儿"
- 内容形式：访谈类短视频
- 粉丝量：几万，未破 10 万，但沉淀 10+ 个大厂社群
- 精准度：大厂人内部互相转发，导师给下属推荐

### 内容天然低红心高转发的秘密

- 大厂人不敢点赞：微信生态是熟人社交，点赞会被领导看到判断"想离职"
- 但转发很高，通过熟人链路传播
- 反常识：点赞低不代表内容不受欢迎，只是用户身份决定了互动姿势

### 低粉变现三梯度产品

- 梯度 1（十几元）：AI 公司行动指南小课程 → 引流
- 梯度 2（299 元）：大厂会员群，300+ 大厂人 + 创业者 + 投资人 → 主力现金流
- 梯度 3（9000 元）：私教 2 个月 IP 打造陪跑 → 高毛利
- 突发产品（699）：临时开的线上剪辑课 → 需求驱动上架
- 额外服务：人才推荐 + 个体咨询（999 元/时）

### 讲师经济分成模式

- 供给端：AI / AIGC / 云计算 / 具身智能等领域讲师（1000 元/小时起）
- 需求端：企业培训方
- 玩法：讲师填模板 → 匹配项目 → 打款给个人 + 包差旅
- 单场经济账：3 小时 3000 元 + 包差旅 = 半天赚 3000+
- 她的角色：链接者/中介，不重资产，纯撮合

### 大厂会员群的复利效应

- 1000 万融资：会员群里一人拿到另一位群友公司 1000 万融资（她不抽成）
- UI 项目对接：新来的假装上班用户当天就接到几万块 UI 设计单
- 律师函服务：群内律师帮群友写律师函
- 本质：平台价值 = 用户之间自然发生的化学反应

### 圈子生意的商业逻辑

- 相比自己做课程：不用搭建运营/客服/交付团队，轻资产
- 相比重产品：不用做 UI/开发/小程序，聚焦擅长的内容
- 杠杆：一次筛选 → 长期化学反应 → 群外部溢价服务
- 限制：不能标准化、不能规模连锁

### 假装上班不能全国连锁的深层原因

- 表面：核心是社交场域 + 主理人的照护感，前台无法替代
- 本质：流量都在主理人手上，加盟合伙人会另起炉灶
- 结论：流量型主理人生意本质上无法规模连锁

### 先小范围测试起号方法论

- 测试原则：任何新产品先发朋友圈 + 建群 → 有人来就干 → 没人来就删
- 不怕丢脸：司董会海报做完后被朋友否掉直接停
- 听劝：几个人反馈不行就不硬推

### 从大厂到创业的心态转变

- 大厂人是花骨朵：收着的、低调的、职场小透明、蜗牛式往上爬
- 创业者是绽放：主动展示、自己定义、内核稳定
- 反脆弱：面对恶评（如"你根本不是腾讯的"），选择相信真正被内容打动的私信，而不是自证低级问题

### 30 岁离职的三个信号

1. 身体信号：心跳异常，血液指标异常，凌晨 5 点惊醒
2. 绩效信号：连续 5 星，但仍无法解决"下一个项目再只睡 2 小时"的宿命
3. 心态信号：不破不立才能有新的活法

### 富豪谷底求翻身的启示

- 美国纪录片：把千亿富豪丢到陌生城市，1000 美金启动金
- 翻身思路：先用第三方身份切入（"二手车中介"卖报废车）→ 用信息差 + 撮合能力先赚小钱
- 对照假装上班：用"造梦 + 圈子 + 撮合"就能起盘

## 关键问答

**Q：为什么假装上班基地能吸引到大厂人和创业者？**
A：三个原因——① 主理人 IP 精准（腾讯离职访谈博主本身自带筛选）② 价格低门槛（60 元/首次 vs 咖啡厅一天）③ 场域承载"想认识同频人但不知道去哪"的社交需求。

**Q：低粉变现的核心是什么？**
A：先跑闭环。她的内容注定小众（大厂不是全民话题），但一开始就设计了 10 元/299/9000 三梯度产品——粉丝几千也能有稳定收入，不用等 10 万粉才接商单。

**Q：从大厂离职最重要的准备是什么？**
A：有准备的离职——先在职时盘点自己 ① 有什么一技之长 ② 有什么兴趣爱好 ③ 有什么可用人脉。三条盘点清楚了，再出来才是合理状态。

**Q：怎么处理"低点赞高转发"的账号？**
A：别追点赞追加微信——判断标准是"这周加了多少大厂微信"，而不是"这条视频点赞多少"。变现路径是私域社群，不是公域商单。

**Q：假装上班公司未来会做加盟吗？**
A：不会。① 核心是主理人的照护感，前台代替不了 ② 一旦规模化，加盟合伙人会另起炉灶把流量带走 ③ 她本人聚焦创作，不想搭平台。

**Q：讲师经济为什么能做起来？**
A：客户不缺，讲师稀缺——账号自然吸引企业培训方询问，反而 AI 领域讲师供给不足。她做的是"识别稀缺侧 + 建立供给池"。

**Q：面对恶评怎么办？**
A：不为低级问题自证。真正需要她的人不会质疑她是不是腾讯的；愿意花时间来质疑的人不是目标用户，不必浪费情绪。

**Q：AI 副业如何做低成本探索？**
A：她用 AI 生成宠物短视频（猫的 meme 视频）发油管，还没变现但先试水。要点：不 all in、先跑最小闭环、跑通再放大。

## 可复用方法

1. **一张群二维码起盘法**：任何新产品第一天不要等海报/装修/官网——建一个群 + 发朋友圈 + 附二维码，看有没有人进来。有人 = 需求存在，可以继续；没人 = 静默删掉重新想。
2. **低粉变现三梯度产品线**：设计 10 元引流课 + 299 会员群 + 9000 陪跑三档，粉丝几千也能有稳定现金流；不追爆款，先跑闭环。
3. **讲师经济撮合 SOP**：识别一个稀缺供给侧（AI/AIGC 讲师），建供给池（讲师填模板存档）→ 需求方找你时快速匹配 → 打款给个人 + 包差旅 → 抽 10-20% 撮合费。
4. **有准备离职三盘点**：离职前 6 个月完成——① 一技之长清单 ② 兴趣爱好清单 ③ 可用人脉清单。三条都能拿出内容 → 可离职；有一条空 → 继续在职积累。
5. **恶评过滤两问**：遇到恶评先问 ① 这人是我的目标用户吗？② 回应他能带来订单吗？两问都是"不"，一律不回应，把时间投给真正被打动的私信用户。
