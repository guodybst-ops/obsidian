# 116 - CEO裸辞摆摊半年变现50W，以小博大的搞钱思路学起来！

## 一句话摘要

前互联网营销公司 CEO 依依 34 岁裸辞后连续摆烂 6 个月，被前同事小北推着"与其摆烂不如摆摊"上路，从演唱会门口小野摊 → 义乌拼拼团 → 新中式饰品市集 → 原创品牌 unive 半年跑通 50W 变现路径。本集完整拆解 CEO 视角下的摆摊选品/选址/主办方谈判/陈列/客群/引流品-利润品搭配等 20+ 个可复用门道，并给出"摆摊是创业的最小单位、正反馈才是宇宙信号、既设百万大目标又脚踏最小一步"的以小博大方法论。

## 要点提炼

### 嘉宾档案
- **依依**：教育行业销售起家 → 互联网营销公司总助 → CEO；34 岁裸辞；大学时代摆摊老兵（贴膜/奶茶/手抓饼/代购/微商月入 5W）；ENTJ 表面 / ENFP 内核；小红书 4-5K 粉，靠"CEO 辞职摆摊"爆文出圈。
- **小北**：与依依同为互联网创业公司同事；旅行公司领队 / 播客主 / 舞蹈课；先离职半年，靠副业矩阵支撑；ENTJ 计划型。
- **合作关系**：小北推动 + 依依执行 → 幕后操盘手 + 前台主理人；已注册公司；原创新中式饰品品牌 **unive**（含义：宇宙 / 独特 / 每一步都被推着走）。

### 时间线（半年跑通 50W）
1. 义乌游学：抱着"办列旗"心态第一次去义乌，交学费、种念头。
2. 演唱会门口小野摊：客单 100-200，一小时收入 1000+，遇城管、突破孔乙己长衫。
3. 义乌拼拼团（微信私域 20-50 人）：每次去义乌顺便直播式选货，2 天营业额 3-4W；单人复购最高 2000+/期。
4. 新中式偶然爆发：随手拍供应商博物馆式陈列 → 群里疯狂圈货 → 一场 2W+，垂直切入。
5. 集市试水：从小野摊进化到报名中高端市集，客单 400+，第一场 700 → 第二场 1W。
6. 建立 unive 原创品牌 × 5 位独立设计师；线下集市 + 线上私域社群 + 定期活动。
7. 现在同周最多 3 摊并行（依依 1 + 小北 1 + 兼职 1）。

### 摆摊 = 创业最小单位（三层论证）
- **反馈快**：当天成交、当场夸赞就是正反馈，不需要等电商流量。
- **成本小**：2000 元起步试货、不囤货、亏得起。
- **决策轻**：走不出来的心态负担 > 具体金额亏损。

### 选品 · 被市场反推的方法
- 心态：不用自己的审美当客户审美——"你愿意花钱不代表你的客户愿意花钱"。
- 测评而非选品：测两件事——① 市场水花 ② 供应商能否长期小量合作。
- 拼团群 2 人验证法：群内两人对同一款有意向 → 无脑拿；拿货 3 根、前两人订单 cover 成本，自己那根几乎零库存风险。
- 拒绝一打起订：只留能"少拿一点、跑设计不跑量"的供应商；跑量款默认放弃。
- 文化基因判定：新中式 = 中国 DNA 里已刻入的审美，无需教育、议价空间大；亚克力/金属需要卷设计+品牌，投入不同量级。

### 供应商谈判 · 真诚 + 即时验证
- 现场直播式验证：拍照发群 → 群内即时下单 → 供应商见"哦你还真能卖"→ 信任建立。
- 画大饼 + 讲故事：合作先讲长期规划、混批、少量拿货。
- 借势小红书人设：依依已有几篇爆文，供应商刷到过 → 反向对老板娘背书。
- 门槛口诀：设计款 > 跑量款；愿意谈政策的老板娘 > 冷脸拒绝的。

### 新中式为什么值得押注（不逆势而行）
- 顶级中古老板娘也在开新中式复线，占比虽低但是信号。
- 国潮 / 汉服 / 文化自信复兴大势推动。
- 石头 / 银 / 水晶 / 珍珠 = 保值 / 不挑人 / 潮流会回来。
- 上班族版新中式 ≠ 汉服圈"文玩级"极致还原，反而受众更广。

### 红海 vs 蓝海（普通人版）
- 普通人不是玩资本游戏，红蓝海不是判断关键。
- 关键是"能不能长期稳定做下去"——只要坚持做，红海也能变蓝海。
- 客户的信任背书 + 私域复购 = 小生意的护城河，不是流量竞价。
- 想赢电商靠低价 + 退货率是普通人拼不过的。

### 选址三件套 · 依依血泪版
1. 大众点评 / 高德地图查周边：老小区 vs 年轻聚集地，是否有网红餐厅排队人流。
2. 主办方口碑：小红书搜差评 / 避雷贴、找已参加过的摊主口耳相传。
3. 亲自跑现场：工作日 + 周末各一次实地考察，问已在摆的摊主真实感受。
- 三条铁律：不迷恋传统旺地（如衡山路已老化）、餐厅无排队默认无人流、越是知名主办方越强势要小心押金陷阱。

### 主办方沟通五问
1. 是否主动问你需要几张桌子 / 品类。
2. 是否愿意为你调整位置（你要主动争取）。
3. 是否接受你提出的赠品 / 助力 / 引流方案。
4. 是否愿意谈两场连报优惠 / 混批。
5. 是否接受"下雨 / 不好可以补场"的兜底条款。
- 只要对方懒得理你 / 全条件不谈 → 立即预警，很可能是坑摊。

### 摊位陈列 · 从 0 到 1 完整方法
- 灵感库：小红书搜风格关键词看 100 张图。
- 复刻供应商的博物馆陈列：直接买他的展示盒、快递到自己摊上。
- 家里预演：按 1.8m × 2m 摊位实际尺寸预摆一次。
- 层次—纵深—吸睛符号三层递进；不追求一步到位。
- 吸睛招牌："永远要相信老祖宗的审美"横幅（蓝底金字）：路人念一遍就停下来拍照。
- 视线点动线测试：戴好客户视角走一遍，主打品必须落在第一视线点。
- 明码标价 vs 不标价：
  - 精准客户多的场地 → 标价（吸引精准/劝退非精准）
  - 大人流场地 / 高客单 / 设计款 → 不标价（用故事讲溢价）

### 引流品 × 利润品搭配术
- 摊位必须要有 1-2 个引流品：69/79 元区间，能拦住所有路人。
- 案例："灵隐寺同款猫挂件"（灵隐寺卖 88，摊上卖 59-79）：颜色可爱、门槛低、女性小朋友都喜欢、可送人。
- 引流品作用：① 拉人停留 ② 打开原本客群（新中式 + 女性 → +小朋友 +男性）③ 未开单时先出小单立信心。
- 客单结构：引流品 69-79 → 中间款 200-300 → 利润款 399+；一天平均客单 400-500。

### 摊主圈子网 · 别关起门做生意
- 每次摆摊必加相邻摊主微信，共享主办方口碑 + 场地建议。
- 案例：卖葫芦大哥（外表冷门 → 一天 2-3W）教会他们"男性市场毫无抵抗力于剑葫芦"。
- 男性客群拓展：黑悟空银曜手串 399 直接付款；情侣 / 夫妻同来时男买单场景多。
- 圈子建议筛选：卖低客单跑量的摊主评价的"好位置"未必适合高客单摊。

### 逛街组合成交率排名（现场统计）
1. **闺蜜组合**：互相怂恿，最好卖；一定要设"两只不一样的闺蜜款"（如白蛇青蛇），避免撞款焦虑。
2. **情侣组合**：女生问"好看吗"→ 男生说"你不是有很多了吗"→ 拆散成交；反例较多。
3. **夫妻组合**：常见"我给我老婆买一个 / 一人一个"；成交率高。
4. **独逛女性**：靠故事和陈列拉住，客单高。
5. **父子 / 母子**：靠引流品猫挂件破冰。

### 里程碑复盘 · 两个"起死回生"时刻
- **第一次商场市集**：还没摆好，第一位女生撞进来试戴全款 700 元一次成交 → 定价 / 陈列被市场认可。
- **代理挂蛋事件**：某位客户主动申请做代理但连续几天挂蛋，依依 & 小北自己上就出单 → 验证"人 = 产品的一部分"；周日重新调陈列 → 一天出 1W → 从此坚定"市集 + 私域"而非电商路线。

### 电商为什么不做
- 直播 suffer：每次能出 1-2K 但极度耗能量，反馈延迟。
- 卷价格 / 卷退货率玩不过大盘。
- unive 的独家设计款单件孤品，跑量逻辑不成立。
- 结论：普通人做小生意，市集 + 私域比电商更可控、更可复利。

### 心态与身份转变（打工人 → 主理人）
- 打工路径依赖：等别人告诉自己做什么、拿业绩自证。
- 现在的自证只对自己 —— "我赚 1w 还是 2w，只要满足自己的平衡点就够了"。
- 最坏兜底：真不行就再回去拿百万年薪 offer → 一想到又要循环那种痛苦，反而更有动力干成当下这件事。

### 合伙人 & 大目标
- 一个人搞事太孤独 —— 有人一起商量、互相反馈能量补给。
- 分工：小北=幕后操盘手/推进者；依依=前台主理人/销售+设计对接。
- 大目标：第一年 100W，摆野摊阶段就定了；半年已完成过半。
- 大目标 × 小步骤：不冲突——小步骤是数值靠近，大目标是方向锚定。

### 搞钱女孩 · 两种解释
- **自己搞钱女孩**：独立做小生意，摆摊即最小尝试。
- **帮别人搞钱女孩**：职场里替公司创造价值、拿分成、当"最高级打工人"（依依前身）。
- 二者没有高低，只有内心自由度差异；越早开始搞钱越好，从女孩开始。

### 迷茫 30+ 职场人 · 三步建议
1. 把 5 年后想要的生活状态具象化（城市 / 工时 / 收入下限 / 生活方式）。
2. 完成一次最小买卖（闲鱼卖闲置 / 撸滴滴拼车 / 摆一次夜市 / 帮人手打柠檬茶）。
3. 找到已经在做这件事的人聊 20 分钟，蹭他的摊、蹭他的圈、蹭他的经验，不要求带带、要找机会点。

## 关键问答

**Q1：为什么摆摊是普通人创业最好的起点？**
A：三个原因——① 反馈快，当天成交、当场夸赞就是正反馈；② 成本小，2000 元就能起步试货；③ 心理门槛低，摆摊不用像开店/电商那样先押重资产。适合从"我做对了什么"的正反馈里一步步放大。

**Q2：不知道卖什么怎么办？靠什么选品？**
A：不要正推——不要以自己的审美硬选。改用"被市场反推"：小规模试货 → 投到朋友圈 / 拼团群 / 摆一次摊 → 看两人以上下单的款无脑拿。三条硬门槛：① 拒绝一打起订 ② 选设计款不选跑量款 ③ 供应商愿意谈少量拿货 + 混批。

**Q3：新中式赛道到底还能不能进？**
A：能，判断依据不是"是否已经火"而是"有没有逆势"。信号包括：顶级中古老板娘也在开新中式复线、国潮/文化自信/汉服复兴大势、石头银水晶珍珠自带保值 + 不挑人。上班族版新中式 ≠ 文玩级极致还原，受众其实更广。

**Q4：选址踩过什么坑？给一个 checklist。**
A：三条铁律 + 亲自跑现场——① 用大众点评 / 高德查周边社区结构 + 网红餐厅是否排队；② 主办方口碑必须小红书 + 摊主圈子双向验证；③ 亲自工作日 + 周末各去一次实地。餐厅高峰没人排队 = 默认无人流。

**Q5：主办方谈判要看哪几个信号？**
A：五问——① 主动问桌子 / 品类；② 允许调位置；③ 接受赠品 / 助力；④ 谈两场连报优惠；⑤ 有兜底补场条款。全条件不谈 = 立即预警，尤其押金陷阱要小心。

**Q6：陈列的核心方法论是什么？**
A：五步 —— ① 小红书 100 张灵感图；② 直接复刻供应商展示盒；③ 家里 1:1 预演；④ 层次-纵深-吸睛符号三层递进；⑤ 客户视角走一遍动线，主打品落在第一视线点。别忘了一句吸睛招牌（如"永远要相信老祖宗的审美"）。

**Q7：明码标价还是不标？**
A：分场地——精准客户多的场地建议标价（劝退非精准客户）；大人流场 / 高客单 / 设计款不标价，用故事讲溢价。unive 的实操是"标料子 + 寓意 + 设计师故事，但不写价格"。

**Q8：一个摊位应该有哪几种价位的品？**
A：至少三段——① 引流品 69-79（如猫挂件）：拉人停留 + 打开客群 + 立信心；② 中间款 200-300：主销区；③ 利润品 399+：高端设计款。日均客单目标 400-500。

**Q9：跟摊主 / 供应商 / 客户建立信任的必杀技？**
A：真诚 + 即时验证。真诚 = 讲清楚自己是谁、能提供什么；即时验证 = 现场拍照发群立刻成交，让对方亲眼看见你的销售能力。信任建立后再谈政策/合作。

**Q10：30+ 职场人迷茫怎么办？**
A：三步 —— ① 把 5 年后的生活状态具象化（城市 / 工时 / 收入下限）；② 完成一次最小买卖（闲鱼 / 拼车 / 夜市 / 手打柠檬茶）；③ 找一位已在做的人聊 20 分钟，蹭摊 / 蹭圈 / 蹭经验，不要求带带、要找机会点。

## 可复用方法

### 方法一：拼团群 2 人验证 + 3 根拿货法
1. 群内发图，看是否 2 人以上圈同一款。
2. 达标即拿 3 根（供应商最低起订，能谈到更少更好）。
3. 前 2 根订单 cover 成本 → 剩下 1 根几乎零风险 → 卖出即净利润。
4. 关键动作：拒绝一打起订、只选设计款、每期限量文案增强抢购感。

### 方法二：选址三查
- 大众点评 / 高德查周边社区结构 + 网红餐厅排队情况。
- 小红书搜主办方口碑 / 避雷贴 + 询问已参加摊主。
- 亲自跑现场：工作日 + 周末各一次，实地看动线。

### 方法三：主办方五问筛选
1. 是否主动问品类 / 桌子。
2. 是否允许调位置。
3. 是否接受赠品 / 助力方案。
4. 是否谈两场连报优惠。
5. 是否有下雨补场条款。
- 三条以上不谈 → 立即预警。

### 方法四：陈列五步
1. 小红书 100 张风格图建灵感库。
2. 复刻供应商博物馆式陈列（直接买他的盒子）。
3. 家里 1:1 尺寸预演一次。
4. 层次 → 纵深 → 吸睛符号三层递进。
5. 客户视角走动线，第一视线点必须落在主打品。

### 方法五：引流品 × 利润品搭配公式
- 摊位品类结构：1-2 个引流品（69-79 元）+ 3-5 个中间款（200-300）+ 2-3 个利润款（399+）。
- 引流品三要求：颜色抓眼、门槛低、可送人（宠物 / IP 联名 / 吉祥物）。
- 引流品 ≠ 客群偏离：必须能带出主客群 + 潜在客群（如猫挂件带出小朋友 + 男性）。

### 方法六：明码标价决策矩阵
| 场地类型 | 客单水平 | 建议 |
|---|---|---|
| 精准客户多 | 中低 | 标价（劝退非精准） |
| 大人流 | 高 | 不标价 + 讲料子 + 讲故事 |
| 大人流 | 中低 | 部分标价（引流品标、利润品不标） |
| 精准客户多 | 高 | 视 SKU 数量，孤品建议不标 |

### 方法七：正反馈利用最大化（unive 心法）
- 亏损 / 做错 → 记账即可，不做情绪反刍。
- 做对的事 → 立刻放大：谁 / 什么时候 / 什么场景成交 → 复刻场景、加码投入。
- 每一个正反馈拿来重构决策，不只是庆祝。

### 方法八：最小买卖清单（迷茫症解方）
- 闲鱼卖 3 件家里闲置物品。
- 撸滴滴拼车 / 顺风车 1 周。
- 帮人手打柠檬茶 / 摆一次夜市。
- 帮人代购 / 代做作业 / 代跑步。
- 目标不是赚钱额，而是"完成一次交易"作为最小反馈。

### 方法九：大目标 + 脚踏实地双轨
- 大目标：第一年 100W 或半年 50W，写下时间点。
- 小步骤：每天 / 每场市集只要有正反馈就是靠近目标。
- 判定标准：方向对 = 数值靠近；方向错 = 数值再高也不可持续。

### 方法十：合伙人组合公式
- 幕后操盘手（推进 / 战略 / 资源整合） + 前台主理人（销售 / 客户 / 设计对接）。
- 关键共识：这件事做不做 / 值不值得由两人共同拍板。
- 能量补给：孤单 / 沮丧时刻的第一响应人。
- 分工不重叠但强互补，才不会内卷。
