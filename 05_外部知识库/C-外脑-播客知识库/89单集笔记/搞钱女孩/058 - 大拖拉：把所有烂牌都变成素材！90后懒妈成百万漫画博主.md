# 058 - 大拖拉：把所有烂牌都变成素材！90后懒妈成百万漫画博主

## 一句话摘要

三本毕业不会画画的90后懒妈，用「缺点最大化」野路子把烂牌全打成漫画素材，三年做到7位数变现。

## 金句

> 大家都在说你的优势是什么？你的天分是什么？你要把你的优势放到最大化。但是我的这个野路子就是缺点最大化。

> 我的产后抑郁是被钱治好的。

> 九年义务没有教你们去赚钱，但是你们活下来，你们生活在这个社会上，你们的义务要变成去赚钱。

> 你们遇到了什么样艰难险境也好，钱永远都是能够最快的解决的。

> 我的视频数据为什么这么好？就是因为我演的就是正常的家庭里的妈妈最喜欢看的爽剧，老公会带孩子，婆婆对我有边界感。

> 我的开局就是一坨屎。

> 情绪价值就是那种"老子当下做的就是对的、就是好的"的心安理得的舒适。

> 你要有一个爆款之后立刻承接那个爆款，而不是"这个数据不错、我下一条发新的"。

> 起号阶段，去挖掘自己的缺点足够了。

> 反差是我的技巧——数字放在最前，共鸣一针扎在大动脉上。

> 赚钱这件事情如果很重的话，就赚不到钱。

> 状态决定命运，状态好了钱就会来。

## 要点提炼

### 起号野路子：缺点最大化 vs 优势最大化

主流建议是"放大优势"，大拖拉反其道行之——**把缺点写在纸上**，从"拖拉、爱吃、不会带孩子、丑普通、不会画画"里挖内容。她的账号名"大拖拉"、"90后懒逼妈妈"都是明面上的缺点。选题公式：正话反说 + 反差 + 数字前置。

### 三张关键手牌：吐槽力 × 文案积累 × 好搭档

从三本毕业到90万粉的破局是三张牌的组合：① 天赋——吐槽力/搞笑女属性 ② 前七份工作打磨的策划文案功底（无提成销售→PPT→活动策划→品牌策划→熬夜熬出手速）③ 会画画的弟弟当搭档，画面全权外包。**看手上有什么牌，而不是想缺什么牌**。

### 情绪价值全网独家定义

不是"提供解决方案"，而是"提供心安理得的舒适"——反向抵消东亚小孩长期承受的"贬低/否定/打压/阴阳怪气/贴标签/道德绑架/指责/焦虑"。三条铁律：① 不埋怨自己不责怪他人 ② 做好倾听者 ③ 放下身段（家长里短、婚姻三观、婆婆妈妈、孩子友情职场都可说）。

### 起号技巧四件套

1. **数字前置**：「两年接了89个广告，全网90万粉丝漫画博主到底有多赚钱」——数字最直观。
2. **反差感**：「33岁还尿裤子是一种什么体验」——把脱毛后尿液分叉包装成反差题。
3. **正话反说 / 反向操作**：「90后育儿反向操作」被澎湃新闻采访；小孩粘你 → 你更疯狂粘他。
4. **发疯永远有流量**：「我老公月薪3000」「发疯式和婆婆沟通」——数据都好，被反复投中。

### 爆款承接法则：不睡觉也要接住

大拖拉抖音期最大的坑——爆款出来后立刻发新选题，导致流量断层。**正确姿势**：爆款出现后，密集用同一话题连发几条把流量吃满，再去做"高于观众期待"的新题。别老想着超越自己，也不必每条都爆——不爆的内容为人设服务。

### 品牌广告分层逻辑（腰部博主怎么被挑中）

广告主的 brief 会把内容分3-4类："精致类 / 测评类 / 共鸣类 / 干货类"。大拖拉自认「共鸣类新时代妈妈」——不测成分不做精致，就做流量。**腰部性价比困境**：粉丝多了广告费涨，客户会开始铺新博主（几百到几千就能起量），头部因认证效应会持续拿单，腰部反而被卡在中间。

### 女生做 IP 的三段商业曲线

① 打工时期薪酬曲线：1800（客服）→ 几千（活动策划）→ 15000（品牌推广，2017 昆明高薪）——积累的都是策划/文案基本功。② 账号变现：广告为主 + 出书（版税几万，卖出 4000 本主要靠身份感）+ 代运营起号服务。③ 未来第二曲线：表情包（累计使用 174 万次，破圈路径）+ 直播带货 + IP 授权。

### 起号协作分工：不管是不是兄弟姐妹，看性格技能是否互补

大拖拉与弟弟 5:5 分成，弟弟画风简笔画+单色填充，但极其较真——一个周边改十几稿。**关键心态**：跪下来求他哄他都行，自尊心不重要；先把 IP 做起来有数据了再说，其他都是屁话。

### 冒牌者综合症与"被看见"的正反馈

从"灰扑扑透明人"到"大老师"的位移中最大的收获不是钱，是"被看见"——上澎湃、出版策划找上门、广告不用自己出门。冒牌者综合症的解法不是靠外部夸奖，是靠**做成一件件事给自己实证**——账号是即时反馈的试卷，当天发当天出成绩，比播客快。

### 显化法则：向宇宙下具体订单

不用否定句（"我不要熬夜"是匮乏），用肯定句 + 具体画面（"一年后年入百万、住100平面朝大海的房子、每月接8个广告"）。狠狠许愿、认真许愿，工作时一边写文案一边许。

## 关键问答

**Q1：起号第一步，不知道做什么怎么办？**
拿一张纸把自己的缺点全写下来——所有东西都从缺点开始。别看什么火做什么，先回看你自己有什么、别人有什么可以交换。缺点即赛道：拖拉、爱吃、不会带孩子都能变成账号定位。

**Q2：什么是"情绪价值"，怎么写脚本才有?**
情绪价值就是让受众获得"我当下做的就是对的、我就是最棒的"的心安理得。写脚本三招：数字前置 → 反差感 → 正话反说。示例："33岁还尿裤子" / "怎么把一个女人养废——让她睡觉、我把早餐做好、让她连家务都没时间做"。

**Q3：数据低谷期怎么撑过去（2023年几个月没广告）？**
不要每一条都要求是爆款——有些内容为人设服务。开辟多个变现方式：接不到广告可以做私域、直播带货、IP 授权、卖表情包。**死磕数据就会更焦虑做不好**，放开点反而数据更好。

**Q4：普通人怎么做漫画号入局？**
① 不需要科班——一个 iPad + 简笔画 + 单色填充就够 ② 放下"高雅艺术家"身段，让画面高雅、内容接地气 ③ 母婴/情绪共鸣是漫画在小红书起号最快的赛道 ④ 挖自己的经历——出生到现在经历过的所有痛，都是宝贵素材。

**Q5：起号后如何链接到"贵人"？**
她的操作：交会员费进小红书上的"IP 授权干货群" → 每个人挨个加名片 → 发自己的 IP 手册 → 全程主动跟进反馈数据。**"我追男人都没这么主动过"**。链接大佬另一个前提：先做出数据、被大佬看见 → 用「流量 + 内容 + 情绪价值」做资源互换。

**Q6：宝妈想做自媒体怎么起步（避坑指南）？**
宝妈最容易被骗——因为手里刚好有3-30万想证明自己。**先不要交钱**，先看很多账号、每天用小本子记宝宝的日常（甚至扁扁拉多少克/什么颜色都行）→ 记录三个月 → 再考虑内容化。宝妈做账号务必先不着急、先看、先记。

## 可复用方法

### 起号缺点最大化模型

```
Step 1  一张纸 / 一支笔，写下所有缺点（外貌、性格、家庭、专业、身体、婚恋…）
Step 2  找出「最公开、最难改、最日常」的三条 → 变成账号人设标签
Step 3  用「正话反说 + 数字前置 + 反差」把每条缺点包装成选题
Step 4  发出后看反馈，反馈好的沉淀成素材库，反馈差的丢弃
```

### 内容脚本三件套模板

| 技巧 | 反例 | 大拖拉版 |
|---|---|---|
| 数字前置 | 我做博主两年赚了不少 | 两年接了89个广告，全网90万粉丝 |
| 反差感  | 我脱毛后有点难受 | 33岁还尿裤子是一种什么体验 |
| 正话反说 | 让妈妈休息一下 | 怎么把一个女人养废——让她睡觉 |

### 爆款承接 SOP

1. 爆款出现的 24-72 小时内，**立即用同一话题+人设+情绪，连发同类内容 3-5 条**。
2. 承接期不睡觉也要接完，直到数据自然回落。
3. 承接期结束后，再发"高于观众期待"的进阶新题（不发同类，避免观众腻）。
4. 严禁：爆款次日直接发全新话题——会导致流量断层。

### 显化法则许愿模板

- 时态：现在完成时（"我已经…"）而非未来时（"我要…"）
- 结构：肯定句（避免"不要 XX"这种否定式匮乏）
- 细节：金额 + 时间点 + 空间画面（"面朝大海的100平房子"）+ 生活方式
- 频次：认真许愿，工作时可反复许（"我要一个月接8个广告"→ 半年做到）
