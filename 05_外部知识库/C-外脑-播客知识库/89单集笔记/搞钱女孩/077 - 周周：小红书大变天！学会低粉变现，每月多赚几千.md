## 一句话摘要

孵化过 4000+ 博主的闪亮猫 CEO 周周，把小红书目前的三个变现角色（买手 / 商家 / 个人 IP）、"从变现倒推做号"的定位公式、低粉爆单赛道选择、黑马笔记法、以及从设计师 → 双向情感障碍 → 100 万粉丝矩阵的重生路径，一次性讲透——这是普通女生"每月多赚几千"最完整的一份 SOP。

## 要点

### 1. 周周背景板：设计 → 双向情感障碍 → 小红书 CEO

温州人，设计专业毕业到杭州做电商设计，男友入职知识付费公司让她第一次接触无迪课程——通宵学完的兴奋恰好被精神卫生科医生诊断为**双向情感障碍**（画了一条抛物线：之前在最底、现在在最高）。西湖边住院一周想通了方向，从闪亮猫 3000 兼职做起，到 23 年 3 月吴迪邀请她当 CEO。

### 2. 养生花茶个人号的启动全过程

她的第一个赛道自证：1688 拿散装花茶货源 → 复刻爆款笔记 → 小区快递店谈 5 块全国通票 → 半个月开始出爆文 → 高峰一周赚 1 万多——最后主动退出，因为**天花板不够高 + 心态不适合再度个体户创业**。

### 3. 小红书平台两大官方主推方向

（1）**视频笔记优先**——流量倾斜给视频；（2）**直播带货 + 买手平台**——把博主粉丝直接变现。核心动作：**从被动接广告 → 主动带货 / 直播**。

### 4. "停更潮"背后的两个真相

（1）**创作瓶颈**——只会写爆文接广告的模式走到头；（2）**大环境预算下滑**——品牌预算变少、市场部裁员甚至卖货化。**"10W 投一个大博主，不如 10W 投 100 个中小博主"**——大博主性价比走低。

### 5. 有流量 ≠ 有商机：粉丝量的正确读法

小几千粉却广告很多的账号 → 大概率是**商家号**（一篇爆款带来的都是精准粉，可直接爆单）。**做纯博主 / 买手 = 必须先涨粉**（80% 直播购买来自粉丝）；**做商家号 = 可以不涨粉、不露脸**（卖珍珠 / 卖水果 / 卖资料两篇笔记 10W+ 都发生过）。

### 6. 小红书三角色区别（买手 / 商家 / 个人 IP）

- **买手**：会选品 + 有自己调性，通过利他分享 + 直播卖别人的货
- **商家**：卖自己产品（自有货源 / 特产 / 代购 / 虚拟资料）——变现最快
- **个人 IP / 纯博主**：靠接广告被动变现，开小清单 / 直播后同时拥有买手身份
- **主理人**：小红书 2024 新推身份——鼓励品牌创始人站到台前做内容 + 直播

### 7. 推荐赛道 / 不推荐赛道（2024 版）

**推荐**：家居（客单价高）/ 教培资料（虚拟无售后）/ 健康养生（人群刚需）。
**不推荐**：宠物科普（早两年已卷）/ 母婴（今年治理低质搬运）。
**避坑判断法**：**去看爆文集中在哪一年——如果都是 22-23 年的老爆文，说明已经拥挤。**

### 8. 选赛道 SOP：先自身出发 + 数据倒推

（1）确认走**卖货路线 or 纯博主路线**；（2）卖货 → 从**身边资源（特产 / 代购 / 1688 可拿货）**出发；（3）纯博主 → 排出小红书主流 10+ 赛道，选**喜欢 + 能输出**的；（4）**灰豚看涨粉榜**——目标赛道近 1-2 个月涨粉最快的账号；（5）看这些账号的内容是不是你能做的。

### 9. 从变现倒推做号：先找品，再做号

周周最鲜明的立场：**先做账号会没有人群方向；先找品会有清晰的人群和内容规划**。反面案例：账号先涨了粉才发现商业定位没想好、粉丝白做。正面案例："糖糖 2 号"卖便利贴——先看见品、要授权、开号带货、两月 3W+ 营业额。

### 10. 城市代购起号法（杭州 & 上海双案例）

杭州学员：**灵隐寺手串 + 各种糕点 + 网红店食物**；上海学员从山姆代购升级到**国际大饭店蝴蝶酥 + 凯司琳蛋糕 + 红宝石蛋糕**——因为打上"城市标签"，很快有本地餐厅主动请他探店，**两条腿：代购 + 探店**同时跑起来。

### 11. 养生赛道的坑：伪科学 = 违规

10 个咨询养生的学员 7-8 个被判违规——原因是**功效词就是敏感词**。做养生的正确姿势：确定人群（如 25-35 岁职场女性）→ 拆痛点 → 按**养生方式细分**（健康饮食 / 减脂餐 / 运动健身 / 环境养生）→ 分享个性化解决方案，别去拼常识堆砌。

### 12. 疗愈 / 水晶赛道的选品门槛

水晶偏颜值审美 → **对拍照能力要求极高**（不能让厂家统一图，会撞图）；艾灸锤 / 养生梳等对拍照要求低但功能属性重。**大原则：拍照差的选拍照要求低的品；有审美的可以做水晶等颜值疗愈品。**

### 13. 灰豚"低粉爆单榜"：新手选品最快法

灰豚数据网**免费试用 15 天可申**（周周赠码）——直接看"近期低粉爆单榜"，这类爆单**说明产品本身有需求，而不是账号流量带来**。这是普通人低粉冷启动最靠谱的选品情报源。

### 14. 学习资料赛道的隐藏红利

好处：（1）**虚拟品无成本**；（2）**几乎无售后**；（3）**赛道极广**（幼升小 / 小升初 / 大学生 / 商务英语 / 成人考证都可做）。**心理学案例学员**从"随喜 8.8 / 十几块"卖到几百块首单 → 后来在小红书店铺卖小学资料**9.9 块 × 上万份**。

### 15. AI 剪播客做讲义卖法

**周周现场亲口鼓励**：把《搞钱女孩》各期播客上传 AI（通义 / 豆包 / kimi / 夸克）提炼干货 → 整理成 word / PDF / 打印讲义 → 定价 39-49 卖出去。**风险提示：不能出现机构名 / 老师人像照——那属于侵权。**

### 16. 起号周期与判断标准

两种起号定义：
- **权重出新手区**：笔记小眼睛 200+ → 一般 2 周（一周三篇更新）
- **初步商业价值**：破 1000 粉 / 开蒲公英 / 卖出首单 → 1-3 个月正常范围

周周做家政企业号极端案例：**一天发 3 篇 → 一周破 1W 粉**；孵化画画老师个人号 → **第 7 篇笔记小眼睛破 1W + 一周涨 1000 粉**。

### 17. 更新频率红线：一周 3 篇

**低于 3 篇 / 周账号权重会掉**——基础流量减少。视频推优阶段，其中至少 1 篇要是视频。

### 18. 千粉 / 万粉冲刺任务红利

小红书**千粉、万粉冲刺任务**——每期要求 2 篇里至少 1 篇视频 + 小眼睛达标 → 平台送流量。**新号务必去创作者中心成长任务领任务。**

### 19. 账号定位公式：内容形式 × 人群 × 问题

**"你的账号是用什么样的内容形式，给什么人，解决什么问题。"** 例：视频口播 × 刚毕业大学生 × 找工作 → 定位就落在"面试技巧 / 职业成长"方向。

### 20. 痛点脑图爆款矩阵法（起号必做）

（1）列出目标人群**所有痛点 + 问题**；（2）每个痛点去小红书搜爆款笔记；（3）把爆款收进思维导图；（4）像素级模仿封面 / 标题 / 结构。**这套脑图会变成你未来 3 个月的选题池——永远不会没灵感。**

### 21. 黑马笔记法（可复制性最强的技巧）

家教赛道爸爸学员传授的独门筛选："**找那些首图很丑但内容爆掉的笔记**——你把首图重新做一版更好看，再发出去，你的数据大概率比原爆款还好。" **人无我有，人有我优。**

### 22. 封面与标题原则

大原则："**封面文案能不能简单粗暴概括笔记主题 + 覆盖用户痛点**。" 很多爆文首图很丑但标题选题精准 → 反过来也印证黑马笔记法。

### 23. 大小号组合的真相

周周自己也有大小号：**大号讲小红书运营** 2K+ 粉 / **小号养生花茶** 1K+ 粉但赚最多。大博主开小号原因是 **大号商业属性远（观点 / 知识 / 娱乐 / 唱歌），小号才能好物种草**。**结论：不推荐普通人做大小号——精力有限，前期把商业化设计好，一个账号就够。**

### 24. 商家号最适合"想快点赚钱"的人

周周对焦虑学员的固定处方：**"想快就做商家，第一篇笔记就能赚钱。"** 卖珍珠、便利贴、水果、青稞包子、牛肉干、蝴蝶酥都可直接爆单。**关键提示：水果是食品类目里唯一不需要营业执照的品**——冷启最快通道。

### 25. 从"必须有办公室"到"1000 块钱创业"

周周第一次创业半年蹭舅舅公司，之后自己搬办公室：80 平 → 300+ 平，员工从 10 几个到 50 多个——**表面辉煌，实际最后自己不拿工资填坑**。转折：接触自媒体后意识到"**只要能独立卖东西产生收入就是创业**"，1000 块可启动，首个目标就是把这 1000 赚回来。

### 26. 成本意识与算账的必修课

CEO 视角最大转变：**每天做表格盯所有支出**——公积金 / 底薪 / 社保 / HR 全是成本，员工回家被父母催回也是运营成本。**"你想搞到钱，商业认知、成本意识、财务意识全部得到位。"**

### 27. 焦虑不可消除，只能接受

以往把无迪视为目标；成为合伙人后发现**每一个更厉害的人都在焦虑，只是焦虑的点不同**。周周现在焦虑时立刻**买张杭州→上海高铁去当面找无迪**——聊完 90% 是"这就是小事你可以怎么做"，慢慢内化为自己的过滤器。

### 28. 从女性 friendly 招聘到开放男生的现实

原本坚持只招女生，团队 2 年经历 3-4 次"磨合好的女员工被父母叫回老家" → 公积金社保交接 HR 全是硬成本 → 被迫开放男生招聘。**结构性观察：女生更容易被"回家结婚"的原生家庭指令拉回，男生的束缚小。这不是个案，是系统性问题。**

### 29. 世俗的成功给人自由

张青云纪录片那句"世俗的成功给人自由"是周周的觉醒时刻。**赚到钱后妈妈不再催回家 / 朋友主动约见 / 家里有话语权** → 这才是"财富健康"最真实的底层价值。**女生不需要被这套洗脑，可以先赚到自由。**

### 30. 起步建议：先干再说

"很多学员定位犹豫、首篇发不出去。**既然想做，考虑好就直接开始干。第一个账号大概率会失败，但排除了一个方向 + 积累了经验。**"

## 关键问答

### Q1：先涨粉还是先变现？

A：**看你是什么类型的账号**。买手 / 纯博主必须先涨粉（80% 直播购买来自粉丝）；商家号完全不需要涨粉，一篇爆单就赚钱——所以从变现倒推做号最优。

### Q2：普通人 2024 做小红书还有机会吗？

A：**有**。3 大推荐赛道：家居 / 教培资料 / 健康养生；避开：宠物科普 / 母婴（治理搬运重灾区）。判断标准：**爆文集中在哪一年**——都是 22-23 年的说明已经卷透，新入局没红利。

### Q3：起号多久算成功？

A：两种标准。**权重出新手区**（小眼睛 200+）2 周内；**破 1000 粉 / 开蒲公英 / 卖出首单** 1-3 个月正常。前提：**一周至少 3 篇，其中 1 篇视频**。

### Q4：怎么找到自己的定位？

A：**账号定位公式 = 内容形式 × 人群 × 问题**。想清楚"用什么形式、给什么人、解决什么问题"——一句话说得清就是好定位。

### Q5：没有钱能做小红书吗？

A：**1000 块就能开局**（花茶货源 + 打印标签 + 包装 + 快递）——比其他任何创业都便宜。前提是先接受"这 1000 是投入，第一目标是赚回它"。

### Q6：能不能真的用 AI 剪播客做讲义卖？

A：**可以，周周现场鼓励**——把干货整理成 word / PDF / 打印册子 39-49 卖出去。**注意规避侵权：不能出现机构名 / 老师人像照。**

### Q7：大小号组合适合普通人吗？

A：**不适合**——大小号是"没提前想好商业化"的后补救。**普通人前期就把商业化设计好，一个账号搞定。**
