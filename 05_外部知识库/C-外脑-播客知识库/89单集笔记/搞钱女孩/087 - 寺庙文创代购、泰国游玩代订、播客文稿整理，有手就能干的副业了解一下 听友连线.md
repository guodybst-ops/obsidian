# 087 - 寺庙文创代购、泰国游玩代订、播客文稿整理，有手就能干的副业了解一下 听友连线

## 一句话摘要

三位「有手就能干」的普通打工人副业样本：Joanna 上海寺庙文创代购、Chelsy 曼谷宝妈接单帮国内客户预订泰国行程、Vincy 把《搞钱女孩》文字稿加工成 9.9-29.9 元电子资料，三条路径共同指向同一条公式——**观察小需求信号 → 4-5 篇同选题赛马 → 用"人味"承接私信 → 迁到闭环工具（微信/店铺/群）→ 请协作降低时间成本**。

## 要点提炼

### 1. Joanna · 上海寺庙文创代购的三号矩阵

- **主业**：垂直零售酒业采购。**副业**：小红书 3 个号，6 个月 5 位数变现。
- **切入路径**：先做上海本地土特产代购（青团/粽子/月饼），发现节庆空档期后，看到"寺庙文创"这个新兴细分赛道且上海几乎没人做（雍和宫、灵隐寺已有代购矩阵），立刻切进玉佛寺。
- **规模变化**：单账号纯土特产 3-4 千 / 月 → 加上寺庙文创后翻倍到 7-8 千 / 月。
- **三号占比**：新起号（100+ 粉）+ 老号（1200 粉）+ 600 多粉号，其中新号贡献 40% 转化——低粉高转，符合周周老师"低粉变现"预测。

### 2. Joanna 选品与合作的四步方法

1. **看柜台主打款**：走进寺庙先扫柜台哪些是"陈列多、可直接手拿"的品——手串、车挂、上上签、香包香囊。
2. **对着柜台咔咔咔拍**：一开始没资源就直接拍陈列品，被问就说"我是同行/竞调"再走开挑另一柜。
3. **让上游主动来找**：垂直笔记发几篇后，柜台/品牌方会主动加你谈折扣；由被动进货变成被动供货。
4. **谈折扣与限定款**：15%-20% 代购服务费 + 团购价 + 独家货源，把"帮忙上香"这个情绪价值也打包进去。

### 3. Joanna 的小红书红线与破解

- **禁忌关键词**：不能写"封建迷信/宣传性"文案；被判过 2 次禁言、封号一周、被扣过"抄袭搬运"。
- **破解 1**：用谐音、拼音（招米 = 招财）+ emoji 表情替代敏感字。
- **破解 2**：视频比图文松，功效说明用口述而非在图片文字上铺陈。
- **破解 3**：文字功效不能明说 → 材质（天然水晶）+ 表情（招米招桃花）+ 谐音三件套组合。

### 4. Joanna 的低粉起号赛马制

- 一个产品至少写 **4-5 篇不同风格**推荐：合集 vs 单品、多场景 vs 单场景、拍照角度不同。
- 让小红书算法给每篇打分，**哪篇点赞率突出就顺着这个模板持续输出**。
- 老号被封 → 新号复用旧爆文选题二创（图片改、选题不变），因为"账号被算法记住的选题会持续爆"。
- **首图大字标题**同样被搜索索引 → 每张封面都加关键词大字报。

### 5. Joanna 关于是否转正的判断标准

- 副业收入 ≥ 主业 or 达到 2 倍主业 → 才考虑转正。
- 关键判断：如果加人加投入能把生意做大 → 值得。仅靠廉价劳动力堆规模 → 不值得（多个代购号 = 变成美团跑腿）。
- 下一步方向：从代购 → 建自己品牌（学写商业计划书），因为品牌方主动上门要联名的机会已出现。

### 6. 西西 · 泰国曼谷宝妈的代订生意

- **主业**：国际学校中文老师，周一到周五 8 小时工作 + 周末夫妻带娃。
- **副业窗口**：孩子哄睡后每天 1-2 小时。**变现**：旺季 2-3 万 / 月，淡季 5000 / 月，10 个月累计 10 万+。
- **触发**：看到国际学校家长有钱、担心孩子长大心理落差 → 小红书搜"搞钱"→ 听搞钱女孩 → 从"发日常小红书"启动。
- **第一篇爆款**：《带娃去泰国浮潜》——精准命中宝妈客群，第一单转 1000 元定金给完全陌生的博主，因为博主自己也带过 2 岁孩子浮潜（"信任感来自真实同类"）。

### 7. 西西的"从窄到宽"业务扩展路径

- **第 1 版**：只带团去芭提雅附近的一个小众岛（浮潜/海钓）。
- **第 2 版**：客人追问 → 加订网红餐厅、日落餐厅、人妖秀（自己没体验过就现搜现问）。
- **第 3 版**：把常见问题整理成《注意事项文档》—— 客人下单后自动发送，覆盖沐浴露/救生衣/接送/语言等 90% 疑问。
- **第 4 版**：找 2 名会中文的泰国朋友当"小助理"，负责重复性沟通（司机-船家-客人对接），每单分佣，把自己时间腾出来上课。

### 8. 西西对付信任危机的三招

- **咸鱼担保交易**：客人怕被骗 → 主动把生意迁到咸鱼开链接，行程结束再确认收货。
- **微信朋友圈养号**：孩子照片、旅拍照片、真实日常持续更新，让"人的味道"支撑购买决策。
- **主动补贴弥补失误**：司机私自加 200 泰铢 → 她自掏腰包退给客人，宁愿亏也不辩，保住品牌口碑。

### 9. 西西的"新词汇启蒙"—— 搞钱思维带来的认知变化

- 新学到的词：引流、推广、私域、成交、成本、赛道。
- 买东西的行为变了：从「贵不贵能买就买」→「这个东西成本是多少 / 它是怎么被我知道的 / 我能不能把它拿去泰国卖」。
- 一切消费都被转译成搞钱线索——从消费者视角切换到商家视角。

### 10. Vincy · 搞钱女孩逐字稿电子商品

- **主业**：帮小老板做 IP 陪跑。**副业**：小红书卖电子资料，1 个月卖 100+ 单、1000+ 元。
- **前置经验**：闲鱼卖过一本 88 元的小众翻译书（成本 2 元，卖十几本）+ 200 元买回的色彩心理线上课，闲鱼卖 400+。
- **切入信号**：看到搞钱女孩节目下方评论区反复出现"想要文字稿"—— 用户主动喊出需求。
- **AI 工具**：通义听悟 / 通义效率，几分钟生成一集文字稿。

### 11. Vincy 的启动测试法

1. **先发 5 条测试**：不同封面、标题、时间发同选题，看哪条最爆。
2. **同选题隔月复投**：200 赞的贴，两个月后重发 → 4000 赞。因为算法权重在变、搜索意图在变。
3. **爆文承接群**：私信集中的时候建小红书群，减少沟通成本，也为未来卖其他电子资料铺客源。
4. **0 元开店**：小红书 0 元开店 + 商品类目选"数字作品/艺术周边/成人教育-技能培训"，避免虚拟商品发货违规罚款。

### 12. Vincy 男友的运营视角 · 三个关键点

- **发现真实需求**：一整期文字稿一次给全 → 与"零散笔记"完全不同的爆点。
- **真实感 > 营销感**：笔记有"人的味道"才穿透流量。
- **借势博主报道**：其他博主把此账号做成"副业案例"报道后，账号流量再进一波 → 新建"副业交流群"承接。

### 13. Vincy 关于"电子资料店"可持续性的判断

- **文字稿本身**已到天花板（100+ 单 / 1000+ 元）。
- **人群留存**是真资产：粉丝 = 对"搞钱案例拆解"感兴趣的人，可复用到卖读书笔记 / 备考笔记 / 思维导图 / 案例拆解服务。
- **金句**："没有任何一个产品是永远可以做的，只能不断思考新产品跟用户接触—— 终究还是做人生意，不是做产品的生意。"

## 关键问答

**Q1：普通打工人下班后只有一两个小时，能做副业吗？**
A：能。西西证明"孩子睡后 1-2 小时"就能撑起旺季月入 2-3 万。前提是选一个不需要长时间在场的场景（代订/代购/电子资料），把重复性沟通模板化 + 请助理协作。

**Q2：小红书低粉能变现吗？**
A：能。Joanna 100 多粉的号贡献 40% 转化，Vincy 113 粉的号 1 个月卖 100+ 单。关键是垂直细分 + 4-5 篇赛马 + 首图关键词 + 主动加群承接。

**Q3：小红书敏感话题（寺庙/宗教）怎么发？**
A：文字不明说功效，用谐音（招米 = 招财）+ emoji + 材质说明代替；口述视频比图文安全；用"文创"框架而非"法物"框架。

**Q4：怎么选副业赛道？**
A：三个信号：① 自己喜好（能持续输出）；② 竞品少（本地/垂直有空档）；③ 需求有信号（评论区/私信重复出现同一问题）。三者叠加 = 可立刻上。

**Q5：电子资料店怎么规避封号？**
A：一开始就 0 元开店，把交易迁进店铺；商品类目避开需要发货的实物类，选"数字作品/艺术周边/成人教育-技能培训"这类无货源类目。

**Q6：副业能不能转正？**
A：Joanna 版判断——副业 ≥ 主业或达到主业 2 倍，且加人加投入能规模化，才转正；单纯堆规模变廉价劳动力就不值得。

## 可复用方法

### A. 副业赛道筛选 · 三信号法

1. **喜好信号**：这件事你做的时候是不是没有情绪成本？
2. **空档信号**：本地/垂直搜索同行数量、发文频率——同行少 = 有窗口。
3. **需求信号**：评论区/私信/群里是否重复出现同一个"没被满足"的问题？三个都亮绿灯，立刻上。

### B. 小红书低粉起号 · 赛马制 4 步

1. 选 1 个具体产品/主题。
2. 写 4-5 篇不同风格笔记（合集 vs 单品、多场景 vs 单场景、图文 vs 视频）。
3. 观察 3-7 天数据，找出点赞率最高的模板。
4. 顺着爆款模板持续输出 10+ 篇；每次微调封面/标题做 A/B。

### C. 关键词部署三层法（寺庙代购版可迁移）

- **标题层**：直接可搜索关键词（如"上海玉佛寺 手串"）。
- **正文层**：主关键词 + 长尾词自然穿插。
- **首图层**：大字报 + 材质词 + 表情替代功效（招米💰、招桃花🌸）—— 因为首图 OCR 也会被算法索引。

### D. 客服沟通模板化 · 5 步（西西版）

1. 收集 10+ 单常见问题（沐浴露/救生衣/接送/语言/加价）。
2. 整理成《注意事项 PDF/图片》。
3. 客人确认下单 → 一次性发送。
4. 遇新问题 → 补进模板。
5. 客服上限时段（如晚 10:30 后不加人）用小号或备注声明。

### E. 电子资料店 · 0 元开店 SOP

1. 小红书开个人店（0 元）。
2. 商品类目避开实物类，选"数字作品-艺术周边"或"成人教育-技能培训"。
3. 挂链接（9.9 元起测试价，见需求量后阶梯提价至 29.9）。
4. 附赠社群 → 未来复用卖新品。
5. 授权问题必须先向源作者/节目确认，避免侵权下架。

### F. 收入结构三段（听友连线共识）

- 主业稳态维持基本盘。
- 副业 ≥ 主业 → 才动"转正"念头。
- 副业不追求"多号铺规模"，要追求"人群沉淀 + 品牌自立"—— 否则只是廉价劳动力叠加。
