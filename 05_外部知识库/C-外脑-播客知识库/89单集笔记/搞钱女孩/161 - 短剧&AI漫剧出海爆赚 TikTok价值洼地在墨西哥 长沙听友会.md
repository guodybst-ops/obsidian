# 161 - 短剧&AI漫剧出海爆赚 TikTok价值洼地在墨西哥 长沙听友会

> 处理方式：短集 · 听友会简化流程（附录 A），保留三位嘉宾的核心搞钱路径与可复用要点，弱化寒暄与现场互动。

## 一句话摘要

长沙听友会现场，苹果（TikTok 墨西哥美妆 + MCN）、贾思明（短剧 + AI 漫剧出海）、鱼仔（芒果职员塔罗副业）三位嘉宾分别拆解「出海选新市场」「短剧海外 4 亿美金爆发」「主副业穿插月入 1 万」三条路径，共同结论：TK / 短剧 / AI 漫剧都是普通人还能上桌的低门槛新风口，成本、内容和执行力比资本更重要。

- 「选一个市场就是选你的对手」——苹果谈墨西哥为什么值得做。

- 「文化有壁垒，但人性是相通的，全世界都需要多巴胺」——贾思明谈短剧出海底层。

- 「副业不是背着老板搞，而是让副业帮你把主业社群拉近」——鱼仔谈塔罗副业心法。

## 要点

### 苹果 · TikTok 墨西哥美妆 + MCN

- 大厂内容出身（搜狐 / 马蜂窝 / 字节）→ 国企消费品打通交易闭环 → 小红书离职赛道博主（4.5 万粉，一条广告 13800 元）→ 押注 TK 出海第二增长曲线。
- 选市场三步：① 汇率差 + 消费力（美国已卷）；② 中国人少（避欧盟合规和日本近距离）；③ 人口结构（墨西哥中位年龄 29 岁 / 1.32 亿人口 / 电商渗透率低预计 10-15 年高速期）。
- 选品：美妆有 COFEPRIS 认证门槛，天然屏蔽 90% 竞争者。
- 直播现状：上架就出单，头场几百人以上；痛点是墨西哥「Payday」周结/双周结工资，一到发薪日下单飙升，一过又只加购。
- 物流实战：中国→美国→墨西哥卡车派送，淡季 2 个月旺季 3 个月起，货代分散 + 少量分批次是刚需。
- 支付坑：墨西哥人习惯现金，OXXO 便利店代收电商支付，本地化流程要理解到位。
- 升级路径：卖家 → MCN + TSP 机构，官方推商家给你带货（墨西哥全国只有十几二十家 MCN 资质）。
- 普通人入局建议：预算 ≥ 5 万开店（毛利 30-40%）；预算不足做达人短视频带货（佣金 8-15%，AI 生成视频占比已 50%）。

### 贾思明 · 短剧 + AI 漫剧出海

- 12 年内容人（相亲综艺 / 户外直播 / PGC / 自媒体 4000 万播放起号）→ 短剧行业。
- 短剧本质：C 端付费 → 红果免费化 → B 端广告付费（品牌不接受下沉）→ 内卷同质化，99% 亏钱，只有听花家（咪蒙）拿保底赚钱。
- 海外短剧 2024 年 45% 收入来自美国，客单价 100+ 美金/部，2024 年海外 APP 下载 12 亿次超过中国。
- 出海国家判断两大要素：① 阶级分化 + 网络普及；② 支付系统（非洲信用卡不足、东南亚要现金充话费）。
- 海外爆款题材：北美都市情感 / 东南亚校园伦理 / 日韩穿越复仇 / 中东豪门宗教家族仇。
- 海外「霸总」宽泛化：黑帮老大、吸血鬼、狼人、总统都能是霸总；女主是弱势 → 男主强势的两性权力才符合欧美国情。
- 海外剧本单价：几千美金到 1.5-2 万美金/部，是国内数倍。
- AI 漫剧：2025 年赛道流水破千亿，AI 加入后单日上映 1000 部（原 100 部），单部成本从 30-200 万降到 5-10 万，赛道极度内卷。
- AI 不会替代的四类人：内容/编剧、导演（画面呈现）、策划（AI 创意应用）、运营（多平台变现）。
- AI 定位金句：AI 解决画面问题，人掌控节奏和情感；用自己的优势加工具。
- 中国出海优势：产能大国 + 人力便宜 + 内容成本低（老外拍 1 个月我们 7 天拍完 2 天剪完）。

### 鱼仔 · 芒果职员 → 塔罗副业月入 1 万

- 21 年找塔罗师算自己事业 → 23 年自学抽牌 → 24 年 2 月朋友圈发起「我准不准」测试，一周接近 60 单。
- 引流三层：前端（小宇宙播客「魔女小鱼」+ 朋友圈）→ 中端（复购 + 朋友推荐）→ 后端（周边商品 + 沙龙课程）。
- 主副业穿插：网易/B站/芒果三年主业都告知过，午休+下班时段接单，公司集市/周年庆反而给摊位和推荐。
- 塔罗定位：不是给绝对答案，而是心理疗愈 + 深度解析 + 深度对话；准不准不是唯一 KPI，尘埃落定的确定感才是价值。
- 副业心法：不藏着掖着 + 拉近同事关系 + 主页找副业机会（芒果导演找她算「短剧能不能爆」「金榜奖能不能拿」）。

## 可复用方法

### 方法 1：出海市场四筛法（苹果版）

- 汇率差 → 消费力 → 中国人少 → 人口/年龄/渗透率增长空间；再看类目是否有天然认证门槛。

### 方法 2：短剧/内容出海两问

- 阶级分化+人性相通性够不够（决定爽剧是否成立）？
- 支付系统能否闭环（决定用户能不能付得出钱）？

### 方法 3：AI 时代职业防替代三选一

- 你能做「内容/编剧/导演/策划/运营」中的任何一环，AI 就是工具而不是威胁。
- 不要恐慌失业，要考虑用 AI 做「不可替代的审美 + IP + 商业目的」。

### 方法 4：副业穿插主业「不藏三步」

- 明确告知同事/老板（不影响主业前提）→ 用碎片时段做转化 → 反向借主业场景（活动 / 集市 / 周年庆）扩张私域。
