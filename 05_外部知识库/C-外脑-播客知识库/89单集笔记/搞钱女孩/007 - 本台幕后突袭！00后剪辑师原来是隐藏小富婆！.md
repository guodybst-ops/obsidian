# 007 - 本台幕后突袭！00后剪辑师原来是隐藏小富婆！

## 摘要

《搞钱女孩》007 集是本台的一次**幕后突袭**——主播抱抱把节目的两位 00 后剪辑师请到台前：**小巴**（浙传软工大四、金牛座、云南昆明人）和 **vivian**（首师大科德学院新媒体编导大四、01 年双鱼座、专职塔罗师）。这一集不聊嘉宾故事，而是围绕**"剪了这么多期搞钱女孩之后，00 后自己的金钱观发生了什么变化"** 展开。

主线是两位剪辑师的**金钱观演化史**。小巴从"初中因为穷/朴素被同学嘲笑 → 我要特别有钱让别人看得起我"的证明式金钱观，慢慢转向"当内在有力量时不需要用钱证明自己、钱是能量交换的介质"——她开始觉察每一笔消费换来的到底是快乐还是欲望满足。vivian 则用剪辑女孩故事+塔罗师视角，得出"金钱是流动的水"——不敢花的人会像"打野压游戏里一直抓着球的人"被踢出去。子线是**两位 00 后的实际搞钱轨迹**：小巴大一起摄影、婚礼督导、时装周兼职，累积存款小几万；vivian 从初高中做网络主播（打赏一个月过万）到大学做公众号撰写、二次元代购、塔罗、片场现场导演，积蓄约 10 万。

这一集最值得记的其实不是钱数，而是几个 00 后带出来的**软心法**：钱是流动的水不能捏在手里；内在有力量就不用花钱证明自己；20 岁犯错好过 50 岁犯错；青春就是用来被浪费的；被低估价格是学生身份的默认坑，得敢往高了报；gap year 很重要——不要毕业就冲进工作。它同时也是节目组自己的一次内部对齐——把"搞钱女孩要找什么样的人"讲了一遍：**心中有力量感、外在有野心、内心有秩序，赚正道上的钱，Go help girls**。适合正在读大学的女生、正在被"要不要考公/考研/找一份稳定工作"逼婚的年轻人，以及所有想给自己一个"是否要 gap"的许可的人。

## 核心要点

### 1. 证明式金钱观 → 内在有力量就不用花钱证明自己

小巴的金钱观进化史很典型：初中因为读私立、同学都穿名牌而自己朴素被嘲笑，形成了**"我要特别特别特别有钱，让别人看得起我"** 的证明式金钱观——名牌背后其实是"渴望被认可"。

剪了半年多搞钱女孩之后，她发现：**当自己内在有力量的时候，就不再需要用钱去证明自己**——真正内在稳的人会有很多人主动来找她。金钱这时候变成"能量交换的介质"：花出去每一笔钱，她会自问换回来的是快乐、是欲望的满足、还是虚荣的补偿？

**这个觉察本身，是消费习惯升级的第一步**。

### 2. 钱是流动的水——不敢花的人会被游戏踢出去

vivian 学塔罗时听到老师的一个比喻：**金钱是流动的**，你不敢花它，就像**打野压游戏里一个人一直抓着球不传出去**——你会被这个游戏系统直接踢出局。

这个比喻同时对应两种极端：
- 一味节俭抠搜的人 → 钱不流动 → 没有钱感、也没有商业感
- 冲动花钱不觉察的人 → 钱流出去没有回来 → 变穷

**核心心法**：钱要花出去，但要有觉察地花。不要把"节俭"当美德，也不要把"花钱"当叛逆。让钱流动 = 让能量循环，而不是让钱一直被你握死。

### 3. 你永远赚不到认知范围外的钱——听不同女孩故事在补认知

vivian 剪节目的一个直接收益是**"看到了更多可能性"**。她本来的默认路径是"考公 / 考研 / 认真找工作 / 循规蹈矩"，剪完不同嘉宾之后她意识到：

- 兼职也可以赚到钱
- 正职之外做副业也可以过得很好
- 不断换工作找自己喜欢的事，一样能搞到钱
- 直接创业也可以

**给了她"很大的底气"**——底气不是钱变多，而是**"路径变多"**。她开始知道：父母/学校给出的路只是无数条路里的一条，选或不选都可以，一切开始变成主动的选择而不是默认的落入。

### 4. 别怕出错——错误发生在 20 岁好过 50 岁

侃侃的一句话对小巴影响很大：**"别怕出错，错误发生在 20 岁，好过发生在 50 岁。"** 她坦白自己的金钱观过去"有点怂有点保守"，加上疫情影响，很多事她没敢放手去做，快毕业时才发现留了很多遗憾。

**推论**：大学 = 试错的修炼厂，这一句话不能只挂在墙上，得真的去用——趁 20 岁多试几次。20 岁试错的沉没成本极低（时间、面子、机会），50 岁再试错才是真正的赌博（家庭、房贷、稳定收入、社会角色）。

### 5. 学生身份的默认坑：不自信 → 报低价 → 被压榨

小巴自己走过一个典型的"学生被爆低薪"路径。老板问她"你想要多少月薪"，她心里想的是"我是学生嘛，我不配、我能力还没到"，报了 3500——干起来发现自己什么活都能接、干得比想象中好。后来她把这份工介绍给学妹，学妹报 4000，老板一口答应。她这才反思："我这么厉害，为什么当时只说 3500 呢？我应该往高了喊啊。"

**教训**：
- 学生身份不是自动的"我不配"信号，很多情况下是**默认自我压价的心魔**
- 报价时要按"活值多少"来喊，不是按"我是学生所以我应该少一点"
- 老板一口答应 = 你报低了；老板要砍一下 = 你报的差不多在合理区间

### 6. 双卡策略：一张存钱、一张花钱，兼职收入进存钱卡

小巴的金牛座理财底层策略：**两张银行卡**——
- 花的那张：生活费、日常开支、月内流水
- 存的那张：压岁钱、兼职收入、想买什么额外攒的钱

**推论**：这不是"存钱 vs 花钱"的对立，而是**给钱做分类**。日常开支不动存款，副业/兼职/意外之财自动进"投资未来"的账户，这样每个月都能看到"净积累"的数字。大学生一个月 2500 生活费不多，但严格双卡分离下，几年也能累出小几万。

### 7. 副业构成：从摄影到婚礼督导到时装周的"多点开花"

两位剪辑师的兼职图谱非常"新一代大学生"：

**小巴**（浙传背景，学校资源丰富）：
- 大一 APP 公司策划（差点创业）
- 大二自学摄影 → 微博 / 小红书接活动摄影单，200–300/单
- 大四加入搞钱女孩剪辑
- 尝试婚礼督导、上海时装周兼职

**vivian**（新媒体编导，线上型选手）：
- 初高中做游戏主播（打赏月入过万）
- 大学做公众号撰写、公众号排版
- 二次元代购、片场现场导演
- 塔罗占卜（专职方向）

**共性**：都不追求单一副业赚大钱，而是"多点开花积累经验+存款"。**思路 = 只要有输入信号，就伸手试一下**，试完积攒经验，再看下一步。

### 8. 玄学的正确用法：不是搞钱工具，是价值交换介质

vivian 是节目组内部的塔罗师，但她对"用玄学赚钱"有清晰边界。她引用抱抱早前给小灰的表态：**"玄学不是搞钱的工具，而是一种技能，帮助他人是价值交换关系。多传递一些道，不要过度侧重在术上。"**

配套观点：所谓"犯太岁必须花 1235 来破"是过度商业化的话术。太岁在专业占星里对应土星——它是"老教授"，代表课题和挑战，处理方式不对/内在没力量 → 觉得困难；完成课题 → 高光时刻。**"危机危机，有危才有机。"** 不需要花钱破解，需要向内深挖。

### 9. 学生跑单最容易踩坑：全部走二手平台

vivian 大一混二次元时买"谷子"（徽章周边）被跑过单，后来的经验：**所有交易走二手平台**。这条经验完全可迁移：

- 二手平台的**担保交易机制**帮你兜底
- 私下微信/QQ 交易 = 全靠对方良心，出问题维权成本极高
- 越是熟人越要走平台——熟人跑单更难开口追

**通用规则**：陌生人交易/兼职私活，第一诉求是**"有平台兜底"**，第二诉求才是"价格合适"。

### 10. gap year 是奢侈品，但值得偷偷给自己一个

抱抱和两位剪辑师达成共识：**国内没有 gap year 概念，但你可以偷偷给自己一段**。抱抱自己 20 多岁一直在"看月亮还是拾六便士"之间摇摆，浪费过很多时间，读完研 28 岁了才开始做纪录片。但她 30 岁不后悔那些浪费的时间——"**这就是我该过的人生，如果再让我过一遍，我可能还是这样子。**"

配套的判断：**毕业不要那么快进入工作状态**。之后你还要工作几十年，光是想想就头疼——不如趁毕业这段真空期，好好想清楚"我到底想做什么、擅长做什么"，多做几种尝试。

**心法**：**该浪费的时间它可能注定就会浪费**，与其不甘不愿地"节省时间进工作"，不如坦然承认这段时间必须留给自己。

### 11. 计划要"体验"而不是"成为"

小巴引用 Jamie 的话："**很多事情不是计划要去做的，而是计划去体验的。**" 这跟她自己性格契合——她没有"我一定要成为什么样的人"的执念，她更接受"在体验中如果顺便能搞到钱，那就很厉害"的柔性设定。

**推论**：
- **计划成为某个身份 = 用未来困住自己**——万一没成为就会崩溃
- **计划去体验某件事 = 用当下解锁自己**——不管成不成，你都获得了体验本身

对刚入社会的年轻人尤其重要：**先允许自己去体验很多种可能，再收敛到一个方向**，比"20 岁就选定方向 all in"更符合真实的人生轨迹。

### 12. 一切都是最好的安排——但要用"经历观"去看它

vivian 谈玄学时讲到"一切都是最好的安排"这句话经常被误用——大家常觉得"我为什么这么痛苦？如果一开始就避开就好了。"

正确的用法应该是：**把"当下的坏事"抽离出来，当成一段经历去看**——无论当下是好是坏，它都会成为人生中一笔很重要的财富和经验。抱抱在结尾也印证了同一件事：**"我毕业时对人生有很多规划，一点都没做到，但我现在仍然活成了想成为的样子。"**

**心法**：**"规划失效 ≠ 人生失败"**。真正塑造你的不是规划，是你在过程中被消耗、被推着走、被浪费的那些时间——它们最后都在你身上留下痕迹。

### 13. 搞钱女孩想找的人：心中有力量、外在有野心、内心有秩序

抱抱在这一集顺带对齐了节目组的选人标准：**心中有力量感、外在有野心、内心有秩序**。三条并存——只有力量没有野心 = 温柔但不进取；只有野心没有秩序 = 拼命但混乱；只有秩序没有力量 = 稳定但麻木。

配套底线：**赚正道上的钱**。快钱、投机、损害他人利益换来的钱，只是**短期财富**，不会积累，也不会助你未来发展。真正会积累的是**在过程中发现自己、提升自己**的钱，即使当下没搞到，未来也一定回来。

**Go help girls**——女生在社会上的机遇和压力肯定比男生多，所以要专挑"女孩"这个词。

### 14. 20 多岁的摇摆：看月亮 vs 拾六便士

抱抱回忆自己 20 多岁一直在两者之间摇摆，浪费了很多时间。25 岁工作两三年后发现"我还是想做纪录片"，28 岁读完研究生才真正入行。但她 30 岁回望，不觉得那些摇摆时间是浪费。

**核心判断**：**摇摆本身不是问题，问题是不接受自己在摇摆**。你越想"我 22 岁就该定下方向"，摇摆时就越焦虑；你允许自己在两侧摇摆，反而每一次摆动都在校准。

**推论**：如果你现在也在"月亮 vs 六便士"之间摇摆，不用逼自己立刻选边——**摇摆是一种校准方式**。它会让你把两侧都试到、都疼过，最后知道哪个方向自己真的能扎下去。

## 关键问答

**Q：我一直不敢花钱，觉得存下来才安心，这是不是坏习惯？**
A：**不是不敢花钱本身坏，而是"钱不流动"坏**。钱像打野压游戏的球，一直握在手里会被踢出局。正确做法是给钱做分类：生活基础支出账户 + 存款账户 + 值得花的花，让钱有出有进、有觉察地花。

**Q：我是学生/实习生，报价老是被压低怎么办？**
A：这大概率是**你自己在心里"因为学生身份"打了折**。规则：报价按"活本身值多少钱"来喊，不是按"我是不是学生"打折。老板一口答应 = 你报低了；被砍一刀 = 你报的差不多合理。学妹后来报 4000 一口同意，就是最好的证据。

**Q：兼职被跑单/被骗怎么办？**
A：**全部走二手平台或第三方担保交易**。微信/QQ 私下转账 = 全靠对方良心；越熟越走平台，熟人跑单更难追。价格合适是第二诉求，**平台兜底是第一诉求**。

**Q：临近毕业，我到底该考公考研还是自己去闯？**
A：**允许自己给自己一段 gap 时间**——不要一毕业就冲进工作状态。之后要工作几十年，光想都头疼。用这段空窗期做几件事：（1）尝试不同工作/兼职；（2）搞清楚自己擅长什么、想做什么；（3）如果读书，一边读一边接触真实市场。**"该浪费的时间它注定要浪费"，与其不甘愿地节省，不如坦然给自己一段。**

**Q：玄学能不能作为副业赚钱？**
A：**玄学是技能，不是搞钱工具**。它的正确定位是"帮助他人 = 价值交换介质"，不是"用信息差割韭菜"。所以慎重对待"必须花钱破解 XXX"这类营销话术——真正的解决方法是向内深挖，因为**危机 = 有危才有机**。

**Q：金钱观从什么时候可以开始训练？**
A：越早越好，但**关键动作是"觉察"**。每一笔钱花出去时问自己：换来了什么？是快乐、欲望满足、还是虚荣补偿？光记账没用，觉察消费背后的情绪才有用。这个训练同时在训练你未来的商业感——一个日常对钱不敏感的人，创业时也很难对成本、定价、投入产出比有真感觉。

**Q：我 22 岁了对未来还很迷茫怎么办？**
A：**迷茫不是坏事**。它意味着你没被单一选项绑架、还在留可能性。抱抱的话是最好答案："**我毕业时对人生有很多规划，一点都没做到，但我现在仍然活成了想成为的样子。**" 计划去体验，而不是计划去成为——你会在体验中知道自己该去哪。
