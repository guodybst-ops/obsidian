# 000 - 姐妹们注意啦！想搞钱的看过来！

## 摘要

这是《搞钱女孩》从《主动交代》人气系列独立出来后的第 0 期，相当于节目宣言。小辉、抱抱、雪姨三位主播解释为什么要把“搞钱女孩”单独做成一档节目：她们希望持续展示女性通过搞钱改变生活、扩展眼界、改善他人生活的多种可能性，也希望把“有野心、想赚钱、敢折腾”的女孩形象从负面标签里解放出来。

三位主播分别交代自己的背景。雪姨从广告行业走向自由职业和女性社群，用信息差与项目经验帮助更多人副业掘金；抱抱从纪录片导演和创业者身份出发，强调“搞钱就是搞钱”，要放下知识分子式的标签感，把专业当工具而不是枷锁；小辉从哲学和公益背景讲到自己对“生活多种可能性”的兴趣，说明节目想做的是一组积极、独立、有目标感的搞钱女性群像。

这期不适合作为普通访谈集强拆 01/02/03。它的主要价值是确立节目母题、筛选嘉宾标准和主播共同立场：不以财富绝对值作为唯一标准，而看嘉宾是否提供“原来这也能搞钱”的启发，以及是否有向上、折腾、不服输的能量。

## 核心要点

### 1. 节目定位：把“搞钱女孩”从系列做成长期样本库

《搞钱女孩》原本是《主动交代》中的一个高反馈系列。小辉看到这个主题的数据和听众反馈后，决定和雪姨、抱抱把它独立成节目，持续讨论更聚焦的女性搞钱经验。节目不是只展示“赚了很多钱”的结果，而是展示普通人可借鉴的路径、样本和能量。

### 2. 主播共同立场：搞钱不是负面标签

三位主播都提到，女性一旦表现出野心、目标感或攻击性，容易被贴上“功利”“钻到钱眼里”的负面标签。但她们接触到的搞钱女孩并不是单纯逐利的人，而是积极、独立、聪明、有目标感，并且能改变自己和影响他人的一群人。

### 3. 抱抱的创业反思：放下专业标签，把专业当工具

抱抱从纪录片工作者和创业者身份出发，反思自己过去容易被“纪录片”“知识分子”“专业身份”限制。创业后她意识到，如果目标是搞钱，就要围绕这个目标展开行动；纪录片不一定是身份本身，也可以成为接触行业、服务客户、拓展眼界的工具。

### 4. 雪姨的路径反思：纵向职业路径之外还有很多可能性

雪姨讲到自己曾经把广告公司视为唯一向上路径，后来发现行业内部跳槽和接活只是很窄的选择。如果更早看到更多搞钱案例，她的人生选择会丰富很多。因此节目要提供“纵向之外”的样本，让听众看见点子如何被放大、被掘金。

### 5. 小辉的发起动机：用群像打破旧标签

小辉强调自己想呈现的是一群积极向上、有目标感、有闯劲的人。节目长期做下去，可能形成一个搞钱女性群像：它最终不只关于性别，而是关于普通人如何从不同路径里找到自己的行动方式。
