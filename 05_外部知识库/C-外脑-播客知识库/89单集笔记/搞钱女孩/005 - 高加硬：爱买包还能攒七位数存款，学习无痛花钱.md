# 005 - 高加硬：爱买包还能攒七位数存款，学习无痛花钱

## 摘要

《搞钱女孩》第 005 期请到了主持人的老朋友高加硬（佳印）——一个把"斜杠"活成日常的女生。她的主业是广告公关，副业先后做过摄影、设计、活动策划、整理师，最近和男朋友合开了小红书风水 CP 号"吉星高照"（小红书 2 万粉、B 站 1 万粉），账号变现的主要来源是周边（靠腰、台历、年历）+ 偶发广告 + seeding。她的搞钱起点非常早：**高中卖班服赚到第一桶金（一件抽 1-2 块）**、大学摄影协会会长开始接毕业照写真、毕业进广告公司发现主业工资"扣完税交完房租就没了"，于是副业收入长期超过主业。她给自己的原则一直是——**不找会消耗自己精力的正职**，把主业当固定盘、把副业当"另一种充电"。

金钱观是本集另一条主线：**她攒下 7 位数存款不是因为爱钱，而是因为怕没钱**——原生家庭长年灌输"家里没钱"（其实是把钱拿去买房 / 车），让她大二就开始拍照赚钱、形成"极度理性消费"的习惯。她的省钱路径极端：衣服可以是二手 / 淘宝同款，但**包一定要是保值的正牌爆款**——因为包是她"唯一允许自己花钱的口子"，她甚至去做过心理咨询，学着把"用完再赚就好"变成对自己的许可。她给妈妈买包 / 不给妈妈买包，被自己承认是"心理学层面对原生家庭的报复"——但**"我爽了"**。

节目也给出了她的方法论——**先做，再挂**：她做整理师、做风水博主、做粉丝群，都是先动起来才有资格告诉别人"我有这个"；她非常喜欢用甲方 PR 的工作把公司资源沉淀成自己的名 + 利；她认同"手停口停"是自己此刻的心理状态，所以要**继续把收入多元化 → 抗风险**。她的收尾金句借自 TVB：*"当我开始放下面子去赚钱的时候，就代表我懂事；当我开始用钱赚到面子的时候，就代表我成功；当我开始用面子赚到钱的时候，我已经是一个人物。"* 她把自己钉在中间那一段。

## 金句

> 我攒钱不是因为我喜欢钱，是因为我怕没钱而已。

> 我不敢花钱，这个事情其实不是那么的健康，买包相对来说又可以让自己开心，又慢慢的去让自己学习花钱。

> 我可以给我妈买包，我可以就不给她买包。其实你说到底，心理学层面上他是一个报复。对，但是我爽了。

> 搞钱的第一步，要主动的推销自己。

> 你不告诉别人你能做什么，别人就不知道你会做什么。

> 我不会去找一些让自己会精力下降的一个主业。

> 你要先动起来，先做了，你才可以知道你自己是一个什么样子的东西。

> 我先做了社群，才跟别人说我有社群。

> 你有了经济独立这个东西，你才可以有话语权，这个是没有办法改变这个现实。

> 当我开始放下面子去赚钱的时候，就代表我懂事；当我开始用钱赚到面子的时候，就代表我成功；但是当我开始用面子赚到钱的时候，我已经是一个人物。

## 核心要点

### 1. 收入结构：主业稳定 + 副业为主 + 风水 CP 号周边

- **主业**：甲方广告公关（PR 岗）——她刻意选一份"不那么消耗"的正职。
- **副业组合**：摄影（去年只接了两三单但仍是暴利单价）+ 设计 + 广告策划 + 整理师 + 小红书 / B 站风水 CP 号"吉星高照"。
- **风水账号变现**：周边（靠腰、台历、年历）+ 偶发广告 + seeding；男朋友的个人风水咨询独立结算不归她。
- **按年结算**：副业占比长期超过主业收入的一半，"主业太少了"。

### 2. 搞钱起点：高中卖班服 + 大学摄影协会会长

- **发家史不在拍照，在卖班服**：高中每年校运会每班定制班服，她找到工厂——厂价 40 元一件，班里 40-50 元一件卖，一件抽 1-2 块，一个班几十件，接了不少班。
- 这段经历让她第一次形成"原来赚钱是这个样子"的直观认知。
- 大学做摄影协会会长 → 拍毕业照 / 个人写真 → 开始"疯狂告诉别人我能拍照，欢迎大家来找我"——她把这一步概括为**"搞钱的第一步，要主动推销自己"**。

### 3. 主副业配比原则：不找消耗自己的正职

- 她拒绝互联网大厂那种"年薪百万但只有一种模式"的高强度正职，因为要给副业留精力。
- 主业换到甲方（广告公司 → 甲方地产 → 现在的大甲方）——**主业越稳定 / 越不消耗，越能持续副业**。
- 她把副业当"输入 / 另一种充电"，而不是消耗：**"除了主业以外都是我喜欢的事情，不是消耗，是充电。"**

### 4. 攒到 7 位数的底层：不是喜欢钱，是怕没钱

- 家里长年灌输"家里没钱"（其实钱去了买房 / 买车），让她大二大三就开始拍照、实习、赚钱——习惯一旦形成就再没放下。
- 她把"攒下 7 位数存款"的原因简化为——**"我不敢花钱"**：极度理性消费、住便宜的、吃便宜的、衣服可以二手 / 淘宝同款。
- 但她自己承认这不是健康的状态——是"巨大的安全感缺失"和"对没钱的原始恐惧"。

### 5. 理财观：先保住，不冒险

- 前几年跟风买过基金（花了十几万，两三年前那波大涨割韭菜）——疫情后开始亏，之后减到两个。
- 现在做过保险、定期、长期理财、股票——她把自己的理财目标定在**"让钱不亏"**，而不是让钱翻倍。
- 心态：**"关于钱的东西，我一点都不敢冒险。"**——买保险的收益是十几年之后的事，她也 OK。

### 6. 唯一允许自己花钱的口子：买保值款包

- 衣服 / 家具 / 日常 → 全部便宜或二手；包 → 必须正牌、必须爆款、必须保值。
- 她甚至排除独立设计师包——"因为我知道那些不值得（保值）"；只买"最保值的款"。
- 她自嘲这是**"把钱花在刀刃上，我的刀刃就是包"**——男朋友的刀刃是家里的桌子、木质、房子质感。
- **心态转变**：以前完全不敢花钱（每一次买包都要经过很久的思考 + 负罪感）→ 男朋友 + 心理咨询帮她练习"用完再赚就好"——买包成了她**"学习无痛花钱"**的训练场。

### 7. 主动经营 + 强化个人标签

- 她做整理师、做风水博主的启动方式都是——**发很多条朋友圈 + 主动告诉每一个人**"我在做这个"。
- 她给出的社交观察：**"为什么很多微商这么容易提车？因为他们所谓被看不起的营销方式其实是最直接的——他们非常勇敢地告诉别人自己在做什么。"**
- 打个人 IP 的先决条件不是找到定位，而是——**"你要先动起来。做了你才知道自己是一个什么样子的东西。"** 每一个能立得住的标签，背后都是这个方向已经积累过、验证 work 过、能变现过。

### 8. 风水博主的偶然启动 + 周边变现

- "吉星高照"这个风水 CP 号是**偶然启动**的：她原本想做整理师博主，跟朋友聊到"整理和风水能不能结合"，朋友把她男朋友（专业风水师）介绍给她。
- 合作从一条**"宜家风水好物"**的视频火起来，之后就顺势持续更新。
- 变现拆解：① 周边（靠腰、台历、年历——粉丝群"呼声很高"逼着她加印）② 偶发广告 ③ Seeding ④ 男朋友个人风水咨询（不算她这边收入）。
- 关键动作：**"我先做了社群，才跟别人说我有社群"**——她的一贯逻辑是先做出来才有资格挂。

### 9. 个人 PR：把公司资源沉淀到自己名下

- 她非常喜欢之前在商业地产做 PR 的那份工作——因为工种就是"不断搜手（build 关系）"，可以活用手上所有资源，同时给公司带来利益也把资源积到自己身上。
- 她的观察：客户来跟你聊生意时，同时会知道你是一个怎么样的人——**名、利、副业机会、媒体采访都是那段时间攒下的。**
- 结论：**"哪怕你不是真的一个 PR 岗，你想要搞钱的时候，还是要去做一个个人所谓的 PR。"**

### 10. 手停口停 + 收入多元化

- 她被上一期做保险的嘉宾一句话戳到——**"很多人处于一种手停口停的状态"**：要么是现实上手停口停，要么是心理上害怕不做事就没收入、被淘汰。
- 她坦承："我就是这种人"——所以今年更关注**把收入多元化 → 抗风险能力更高**。
- 但她也承认自己至今没法真正松弛："哪怕玩橄榄球，我的目的都是保持联系、拓展潜在客户"——生活即人设、社交即副业渠道。

### 11. 家里没钱 vs 经济独立 = 家庭话语权

- 她的搞钱原始动机，是因为**在原生家庭里没有话语权**：家里从小说"没钱"、不供她出国、姐姐是"传统广东女生"、她是叛逆的那个。
- 后来爸妈发现她在上海站稳脚跟、比他们有钱——**这件事她自认"很爽，但不健康"**——因为她终于可以对抗、可以选择给妈妈买包也可以选择不给。
- 她把结论说得很直接：**"你有了经济独立，你才可以有话语权，这是没有办法改变的现实。"**

### 12. 提前退休 vs 争上去：给自己留一个未定答案

- 她原本想过 35 岁退休（副业留后路），但换到新甲方之后，观念开始动摇：职场是"不进则退"，她开始学甲方的生存法则、开始考虑要不要往上冲。
- 她没有给自己一个定论——**"我给自己留个问题，可能到那时候我会变成想争上去的人。前提是钱先给我这份选择的权利。"**

### 13. TVB 收尾金句：懂事 / 成功 / 人物

- 引自 TVB 剧的三段式：
  - 当我开始**放下面子去赚钱** → 我懂事；
  - 当我开始**用钱赚到面子** → 我成功；
  - 当我开始**用面子赚到钱** → 我已经是一个人物。
- 她把自己钉在"中间段"——已经用钱换到了一些面子，但还没到用面子换钱的段位。
- 主持人补一句：**"我们其实不是为了那个成功，而是为了那份自由。"**

## 关键问答

**Q1：为什么攒得下 7 位数？**
A：不是因为爱钱，是因为怕没钱——"我不敢花钱"。极度理性消费、二手 / 淘宝同款 / 不吃贵的、住便宜的；副业收入长期稳定 + 主业稳定 + 男朋友这边省下房租——所以钱累计得下来。但她也承认这是"巨大的安全感缺失"，不是健康状态。

**Q2：怎么"学习无痛花钱"？**
A：她给自己开了一个允许花钱的口子——**买保值款的正牌爆款包**。买之前会经过很久思考 + 有负罪感，但通过反复练习 + 男朋友"用完再赚就好"的鼓励 + 心理咨询，一点点松开这个口子。她的方法核心是——**把"花钱"这件事本身当技能来练**。

**Q3：怎么处理主副业的关系？**
A：**主业选不消耗自己的**（拒绝互联网大厂那种年薪百万但只有一种模式的岗位），把主业当稳定盘 + 甲方 PR 资源沉淀渠道；副业当"另一种充电"、当收入多元化 + 抗风险的武器。按年结算副业占比长期超过主业的一半。

**Q4：如何启动一个新的副业 / 博主账号？**
A：**"先做，再挂"**。她做整理师、做风水博主、做粉丝群，全部是先动起来 → 有了成品才发朋友圈告诉别人。她也观察到微商的营销方式"最直接"值得学习——**"你不告诉别人你能做什么，别人就不知道你会做什么。"** 打个人 IP 的先决条件不是先找定位，而是先动起来，做了才知道自己是什么样子。

**Q5：钱对你来说意味着什么？**
A：**安全**——而且是"负面的安全感"。她坦承哪怕拥有 7 位数，"这跟以前完全没有分别，也没让我更安全"，因为在上海根本不够。所以她的搞钱不会停下——**"财富自由"是无穷远的方向，"经济独立 = 家庭话语权"是她今天已经拿到的现实红利。**

## 小彩蛋 · 三条风水开运小贴士（男朋友赵宝慈老师）

- **每天早上刮眉毛**：睁开眼后，双手合十用食指第一节从眉头刮到眉尾，左三下右三下——把"人的手/思绪"捋顺，做事就会顺一点。
- **扫地不要往门外扫**：从门外往里扫，灰积完了再倒出去。往外扫（含吐水、泼废水）= 把运气一起扫出去 = 散财行为。
- **不要在自己空间叹气**：要叹去外面叹。家里 / 工位是自己的运气场，不停在里面叹气 = 把机遇一起丧掉。心念反过来会影响身体的激素 + 炎症水平——积极阳光的意识，其实是身心科学。
