# 013 - 道理都懂，可我为什么还是穷（结尾有彩蛋）

## 摘要

《搞钱女孩》013 集是三位主播**雪姨、小灰（小辉）、抱抱**在杭州抱抱家客厅的一次线下三人圆桌集，也是节目开设"香帅老师《钱从哪里来 4：岛链化经济》共读营"的推介集。全集围绕**"道理我都懂，可我为什么还是穷"**这个自嘲式主题展开——用三位主播近期的实操 / 亏损 / 顿悟，反思一件事：**片面的道理为什么救不了个人财务**。

主线拆成三条子线：一是**主播近况分享 + 关于"定位理论"的现场辩论**——抱抱室友是花艺定制博主，一开始就把定位打到中高端做 B 端；雪姨反驳"如果一开始你没有存款、没作品、没名气，谈高定位是不负责的表述"，引出**"道理成立要看使用者的前提条件"**这个核心议题；二是**小灰的 520 摆摊实录**——两天半市集赚 8000 多、垃圾桶旁的位置怎么争到主舞台边、"想象自己正在录《富豪谷底求翻身》"的心态练习；三是**共读香帅老师《钱从哪里来 4》**——聊"岛链化经济"这个关键概念、房子沉重、疤痕经济、技能比专业更重要，最后落到**"钱要看到自己和社会的关系、不只看兜里揣着的钱"**。

这一集的独特价值在于——**没有一个单一嘉宾的成功样本**，而是**三位主播以"我也在踩坑 / 我也在亏钱"的姿态和读者一起反思**。适合正在**盲信某本书 / 某个博主 / 某句金句 / 某个定位建议**并因此亏钱或迷茫的读者；也是理解**"道理不能盲目复制"、"跨越周期"、"宏观 vs 微观"、"疤痕经济"、"技能创造流动性"**这几条底层认知的入门集。

## 金句收藏

> 因为我们拿到的信息量是片面的，是不能盲目地去复制的。就像大家会觉得看搞钱女孩，也不要以为听了我们节目就会搞到钱。

> 我们赚钱同时，其实不能只看到自己兜里揣着的钱，更多的是我们还要看到一个社会大环境是怎么样的。

> 没有必要对着打翻的牛奶哭泣，因为宇宙中的所有力量都要一心将它打翻。

> 只要你把事情做好，钱就自然会来的——我觉得这也是一个伪鸡汤。就算你把事情做得再好，如果没有人知道你，你就是赚不到钱。酒香也怕巷子深。

> 当你想做一件事情的时候，全世界都会来帮你——但其实没有人在帮你，是你自己争取。

> 当你每天可以赚 2 万块钱的时候，你就会突然发现勤奋不是致富最重要的点。

> 我不给自己很大的压力，一个月读一本、一星期读一本，而是我一天只读一页。

> 从全球化到岛链化：现在我们都强调要有安全的底线，寻求和我们价值观一致的人。

> 我们赚钱同时，不能只看到自己兜里揣着的钱，其实更多是要看到自己和这个社会的关系。

> 穷并不可怕，可怕的是一直穷，可怕的是认命了。

> 搞钱女孩是陪伴型养成型的播客，大家千万不要觉得听了搞钱女孩就能获得什么具体的方向。我们只提供人生样本。

## 核心要点

### 1. 定位理论之争：中高端定位需要"存款 + 作品 + IP"作为前提

抱抱分享室友（花艺博主）的做法——**从广告公司辞职创业第一天就把自己定位在中高端 B 端客户**，理由是"一开始定便宜就永远升级不了"。

**雪姨的反驳（这一段是本集的第一个核心辩论）**：
- 这个道理**在使用者已经有前提条件时**才成立
- 那位博主辞职前**有几十万存款 + 已经有 IP + 有作品积累**
- 如果新人 freelancer 没有这些底子就直接定高价，**没有人会为你付款**
- 手艺人的正确路径是**"小案子建立信任 → 层层加码 → 走高"**
- **"做生意的核心是信任和人品"**

**推论**：**"看起来对的方法论"往往有它没说出口的前提**。看到一个成功者说"我一开始就定位高端"时，第一问是——**这个人在'一开始'那一刻手里有什么资源？** 复制他不难，前提是先复制他的前提条件。

### 2. 富豪谷底求翻身 → 摆摊实操：心态换位是最强的执行加速器

小灰安利《富豪谷底求翻身》这部纪录片——富豪被扔到偏僻小镇、只给一部手机+一点零钱、3 个月赚 100 万美金；富豪从睡车里、倒卖轮胎、卖气球起步，最后在市级烤肉节上打出招牌。

**小灰把这套心态直接套用到自己 520 杭州摆摊**：
- 场地实际到才发现摊位后面是垃圾站
- 磨豆机没带 + 对面摊主一上来点了 4 杯
- 第一天手忙脚乱，销量几百块
- **触发心态切换**：**"如果我是格伦（片中主角），我会怎么办？"**

**关键动作**：
- 情绪管理，我不能失控，要给团队信心
- 像格伦一样把整个市集从入口到活动场地全部走一遍，观察人流路线
- 瞄准主舞台边的空位
- 找主办方各种交涉——**"这个位置必须给我，我不能在垃圾桶前卖咖啡"**
- 最后达成妥协：白天占位、晚上收摊挪走、方便垃圾清运

**结果**：第一天几百块 → 第二天 4000+ → **两天半共 8000+**。

**推论**：**"想象我正在录一个综艺"这套换位视角，是最便宜、最强、最能立即使用的执行加速器**。它把"差不多就行"逼成"我一定要拿到"。

### 3. 该争就要争：温和型人格的搞钱破局点

小灰坦承她本人**"是一个很挨的人，不擅长跟别人提要求"**，大部分时候会"差不多就行"。但那次摆摊——她第一次真的**"逼着自己去要"**：

- 要主办方给她换位置
- 要搭建公司给她连夜加搭帐篷（因为原本只给了一个普通伞）
- 反复推理"我付了同样摊位费，凭什么给我最差的"

**她的一段自白**：**"来都来了、准备了这么多物料和食材，如果浪费了，浪费的是我的成本、浪费的是我的时间。"**

**推论**：温和型 / 讨好型人格搞钱最关键的一次破局，就是**在具体某一次实操中被逼着"要一次"**——一旦体验过"我要了 → 我拿到了 → 销量翻十倍"这个正向反馈，"该争就要争"就会内化成默认动作。

### 4. 只要把事情做好钱就会来 = 伪鸡汤

三位主播共同否认一条流传最广的鸡汤——**"只要把事情做好钱就会来"**。

**她们的反驳**：
- **酒香也怕巷子深**
- 就算你把事情做得再好，如果没有人知道你，你就是赚不到钱
- 我们做自己的事情时会觉得"没有人发现"，然后陷入"差不多得了、得过且过"
- **"被看到"是搞钱链路的必经环节**，不是可选项

**呼应鸡汤 #2 也是伪的**：**"当你想做一件事情的时候，全世界都会来帮你"**——其实没有人在帮你，是你自己争取。

**推论**：**做好 + 被看到 + 主动争取，三者缺一不可**。省略任何一环都是"做了很多但赚不到钱"。

### 5. 道理为什么救不了你：信息片面 + 缺前因后果

三位主播花了较大篇幅回应一个粉丝的困惑——"我看了某本长期看好指数基金的书买了基金，收益还不如无脑买股票，你们怎么看？"

**她们的反思框架**：
1. **信息片面**：书 / 建议 / 金句都是"某个特定环境下"的产物，没有完整前因后果
2. **每个人的理解力 / 解读能力不一样**：同一本书不同人看到不同东西
3. **不能自欺**：看了就能搞到钱——**"大兄弟哦"**
4. **宏观 vs 微观错位**：书上是宏观理论，你却用它做个人微观投资决策

**推论**：读书 / 听道理不是无用，是**要判断这道理适用的语境 + 前提 + 使用者条件**。不加条件的复制 = 大概率亏钱。

### 6. 跨越周期：付出了不等于当下就有反馈

三人共同强调——**"我们总想付出了就马上有收益"**是当下最普遍的错觉。

**她们提到几个具象场景**：
- 听消息炒股 → 听到就买 → 大概率赔
- 看了一本书 → 马上去买基金 → 几个月内亏了 → 归咎书
- 学了理财 → 期待当下反馈

**正确姿势**：长线操作要有**跨越周期的耐心**——3 到 5 年甚至更久、1 年以上。

**背景补充**：小灰说自己 16 年毕业赶上互联网大厂鼎盛期，形成"只要你冲你就会有好结果"的路径依赖。**"当你每天可以赚 2 万块钱的时候，你就会突然发现勤奋不是致富最重要的点"** ——月入 60、年入七八百万的人，一定不是靠勤奋赚钱的。

**推论**：**跨越周期能力 = 当下亏损时不认输 + 不删仓 + 不换方向**。这是所有长线搞钱者最难修的一门课。

### 7. 微观建议 vs 宏观趋势：你不能只看具体操作

三人反思自己一个共同问题——**"很喜欢看微观的、具体的实操建议，很少看宏观层面的经济报告"**。

**为什么会这样**：
- 微观爽、马上能做
- 宏观枯燥、看了没意义、谁爱看
- **但**：不了解自己所处的经济环境，做的所有微观操作效果都不好

**推荐**：《激荡三十年》、B 站《激荡四十年》系列。**看这些是为了理解"改革开放这 30 年赚到钱的人，抓到了什么时机 / 做对了什么事"**。

**推论**：**"想学道理，不能只读微观的，还是要了解一些宏观的市场背景"**。搞钱心态取决于对大环境的认知——下行周期就求稳、上行周期可预期高一点。

### 8. 岛链化经济：钱要看到自己和社会的关系

三人推介的核心概念（来自香帅《钱从哪里来 4：岛链化经济》）——**从全球化到岛链化**：

**全球化时代**（2008 年往后）：世界扁平；强调增长、比较优势、互利合作；全球产业链分工。

**岛链化时代**（2018 贸易战 → 2020 疫情 → 2022 俄乌战争之后）：**重新结盟 + 各自为政**；强调安全底线；寻求和自己价值观一致的人；本土保护主义抬头。

**在这个大趋势下作为个体怎么搞钱**：不能只看到自己兜里揣着的钱，**要看到自己和这个社会的关系**——在这种关系下怎么自洽、怎么赚到钱。

**推论**：未来 3-5 年的个人财富策略，锚点是"社会关系"而不是"个人技巧"。**跟对趋势 + 跟对结盟对象，比努力多几倍更重要**。

### 9. 沉重的房子：抱抱 5 年前买房装逼、如今被拖住

抱抱的真实亏损故事——毕业 5 年时手里一大笔钱**"不知道该干嘛"（普通奢侈品已满足不了膨胀的欲望）**，就在杭州买了房。3 年过去房价疲软 + 阿里裁员抛售，"买了就跌，49 年加入国民党"。

**当下的困境**：想搬家（养狗、想要带院子的小别墅），但**沉没成本**（装修 + 布置）+ **不动产难变现**（"卖也卖不掉"）+ **市场下行**（"卖肯定亏铁亏"）。结论——**"住的其实也没有很习惯，也没有很喜欢，老说有点鸡肋"**。

**给刚需朋友的两条提醒**：
1. **预算不要打满**、**杠杆不要拉太高**
2. **能不能接受最大回撤**——你能不能接受它亏多少？

**推论**：**房子是刚需时买 = 消费了"住"这个服务**，就别指望投资回报；**房子是投资时买 = 必须精算最大回撤 + 变现能力**。**"最贵的资产 = 最难变现 + 最容易被拖住"**——很多人是买了才知道这一层。

### 10. 疤痕经济：经历过封控后消费的自然降级

**疤痕经济**——经历疫情 / 战乱 / 大震荡后，人们内心需要一段时间才能恢复对经济的信心和消费积极性。

抱抱、雪姨的自我印证：
- 从"断舍离"变成"能囤就囤"
- 拼多多、淘宝的量大打折
- 咸鱼淘二手家具（中介的二手交换群）
- 基金套住 → 心态转保守 → **"不会再买什么基金了"**

**推论**：**疤痕不是消费降级、是消费心态永久性偏保守**。经历过封控 3 个月的这一代人，未来 5-10 年的默认购物动作都会不一样。

### 11. 技能比专业更重要：技能创造流动性

雪姨的自我印证——她花了 3 年考研拿到 985 硕士。回看这 3 年——**是她本该赚钱的 3 年，全部拖产在复习 + 临时工**。

书里的关键判断：**"技能比专业更重要 / 技能创造流动性"**。

**雪姨归纳自己在市场上真正靠的技能**：快速归纳信息 + 与人沟通 + 调度拍摄。**这些不是学校教的，是社会上重新学的**。

**关键分离**：**学习 → 提升自己**；**赚钱 → 技能变现**；这两件事情不对等。**好好学习 ≠ 一定挣大钱**。

**推论**：读书不是无用，但要意识到"学位 / 专业"和"能变现的技能"是两条平行的线。真正决定收入的是后者。搞钱期要有意识在专业外攒"能创造流动性的技能"——沟通、归纳、项目管理、销售。

### 12. 一天一页共读营：极低门槛坚持读书的方法

小灰分享自己去年发起的"一天一夜"读书项目——**不是一个月一本 / 一星期一本，是一天只读一页**。

**关键机制**：不给自己压力；每天起床、睡前、空隙时间抽一点；**只做"读一页"这一件事**。结果：坚持了 200 多天。

**副作用（非常正向）**：发现"我原来是可以坚持读书的"；开始尝试啃大块头；每个月至少读完一本。

**推论**：**任何"看起来要靠意志力坚持的事"，都可以通过把最小单位切到极小（一页、一分钟、一个 push-up）来实现习惯化**。执行力问题 90% 是目标设置问题、不是意志力问题。

### 13. 搞钱女孩定位：陪伴型养成型 + 只提供样本

节目最后三位主播的自我定位澄清——**"搞钱女孩是陪伴型养成型的播客"**：不要以为听了节目就会搞到钱（"大兄弟哦"）；不提供具体建议；**只提供人生样本**；分享的都是自己**阶段性的感悟**——包括亏钱、亏基金、买房被套的失败感悟；是**跟大家一起在研究怎么搞钱、一步步在学习**的姿态。

**推论**：**"陪伴型养成型"意味着单集不承诺变现，但长期陪伴中会内化一套多元的人生样本**。这与"道理都懂为什么还是穷"的主题闭环。

### 14. 打翻的牛奶：宏观 buff 亏损时的心理松绑

节目结尾借用书中引用的一句金句——**"没有必要对着打翻的牛奶哭泣，因为宇宙中的所有力量都要一心将它打翻。"**

**这句话的完整含义**：对宏观局势和大趋势有了了解之后，心态会更理性客观——**可以接纳自己亏钱这件事，也可以接纳自己穷这件事**；**哪怕没搞到钱，也不要全怪你自己——全宇宙有问题**。

**收尾金句**：**"穷并不可怕，可怕的是一直穷，可怕的是认命了"**。

**推论**：**宏观视角在个人财富中最实用的价值，不是让你踩准每一步，是让你在踩错时能"松绑"**——不把"我这轮亏了"内化成"我这个人不行"。搞钱是长跑，情绪账户比资金账户更重要。

## 关键问答

**Q：一个成功者说"你必须从一开始就定位高端"，我该不该照做？**
A：**先问他"一开始"手里有什么**。抱抱室友能一开始就定高端，是因为辞职前有几十万存款 + IP + 作品积累。新人 freelancer 没有这些底子直接定高价，没人会付款。**手艺人的正确路径是"小案子建立信任 → 层层加码 → 走高"**。

**Q：性格温和、不擅长争取，怎么破？**
A：**用"我正在录综艺 / 纪录片"这个心态换位**。想象有摄影机在录你——你还会"差不多就行"吗？小灰摆摊时问自己"如果我是格伦，我会怎么办"，结果销量翻十倍。

**Q：只要把事情做好，钱会不会自然来？**
A：**不会**。这是伪鸡汤。酒香也怕巷子深。**做好 + 被看到 + 主动争取，三者缺一不可**。

**Q：我看了某本书买了基金但亏了，是不是书骗我？**
A：**不是书骗你，是"跨越周期"错位**。长期看涨的东西不代表你买了几个月就涨。**跨越周期能力 = 亏损时不认输 + 不换方向**。

**Q：宏观经济那么枯燥，普通人真的要看吗？**
A：**要**。因为不了解自己所处的经济环境，做的所有微观操作效果都不好。推荐：《激荡三十年》、B 站《激荡四十年》、香帅《钱从哪里来 4》。

**Q：跟风买了房、现在觉得沉重、想搬家又走不掉，怎么办？**
A：**接受"沉没成本已经沉没"**。刚需就把它定义为"消费而不是投资"。准备买刚需房——**预算不要打满、杠杆不要拉太高、精算最大回撤**。

**Q：技能和专业哪个更重要？**
A：**技能。因为技能创造流动性**。学位 / 专业和"能变现的技能"是两条平行的线。搞钱期要有意识在专业外攒沟通、归纳、项目管理、销售等技能。

**Q：想坚持读书但坚持不下来？**
A：**把最小单位切到极小——一天只读一页**。做到之后你会发现"我原来是可以坚持读书的"，然后自然长出啃大块头的能力。
