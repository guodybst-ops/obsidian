# 027 - 七天路过：敢要就有转机！从450元北漂公寓到独立买房的人气作家

## 摘要

《搞钱女孩》第 27 期是杭州听友会的追更专场，把 026 集里已经露面的嘉宾七天路过单拎出来做深度访谈。她是一位典型的"折腾型普通女孩"：河北二本毕业、22 岁揣钱北漂，从月租 450 元的青年公寓（8 人合住、公共卫生间）一步步租到 3000 多元的主卧带猫小家；一边做出版社小编辑，一边下班晚上写 2 小时公众号，凭爆款文章在人民日报、十点读书被转载，最终反向被出版公司找上门签下第一本书《大大的城市小小的我》。

对谈按"北漂 1.0 → 北漂 2.0 → 杭漂 1.0 → 杭漂 2.0"四段路径推进。**北漂 1.0** 是"从普通编辑到出书作者"：靠对同行作者的追问祛魅"出书这件事"，用晚上 2 小时 + 人民日报级平台杠杆撬开曝光；**北漂 2.0** 是"合作对手变机会"：因为主动联系了 50 多家蓝威合作方，被网易云阅读的合作方看中、内推进网易，再在网易做书发布时以"三方斡旋"（书店-出版社-畅销书作者）撬起 798 首发 300 人现场；**杭漂 1.0** 是进阿里——她在晚点公众号留言区捡到一个师兄的邮箱内推、二话不说投简历过面试；**杭漂 2.0** 是从阿里离开、回到"自由职业 + 我想开了社群"、再回归打工做冥想公司，用工资兜底、用副业和小报童做长线积累、用占星做第三条腿。

这集的独特价值在于——它是搞钱女孩迄今为止最完整的一份"普通女孩十年折腾路线图"：既有月租数字（450 → 800 → 1000 → 3000）、职业跳板（出版小编辑 → 网易 → 阿里 → 我想开了社群 → 冥想公司），也有关键"敢要"动作（投稿 50 家公众号、留言区加师兄内推、买房时用公积金 + 大厂无息借款做杠杆）。适合"觉得自己没有起点、只有普通牌"的年轻女生反复听——七天路过反复强调的核心不是天赋，而是**"敢要 + 长期主义 + 用优势打牌 + 把每件事的衍生空间做大"**。

## 核心要点

### 1. 北漂 1.0 · 从小编辑到出书作者：给作者祛魅是第一个动作

七天路过大学毕业后进出版社做小编辑，第一步不是"我想出书"，而是"我作为编辑天天接触作者，那我去追问他们出书到底难不难"。她通过邀稿、聊合约细节，把"作家"从神坛拉回地面：**先在自媒体写爆款 → 各平台编辑找过来邀约 → 谈版税谈协议 → 撰写十几万字 → 出版**。她判断"没那么难，第一步就是写"。于是她把下班后每天多熬 2 小时用来写公众号，投稿被人民日报、十点读书等大号转载后，反向被出版公司找上门做"北漂散文集"——因为她自己就在挤地铁、每天通勤三四小时、住着无独立卫生间的房子，共鸣天然自带。**祛魅 → 写 → 被看见**这一套是她后来所有杠杆的起点。

### 2. 450 元青年公寓 → 3000 元主卧：租房故事作为北漂主线

北漂三年的自我叙事，七天路过用"租房故事"串联：**450 元的 8 人青年公寓**（没有独立生活，煮蛋器在地上拖线、公共淋浴晚高峰要等很久、水漫到临时厨房）→ **传媒大学附近 800-900 元村里带暖气房**（没有公共卫生间，冬天要拿热水壶烧水洗脸）→ **北四环 1000 多的合租房**（跟老乡合租）→ **1000 多元自己单独一间**→ **3000 多元的主卧**（因为养猫）。这条线不是抒情，是**行动的账本**——每一次搬家都对应一次涨薪或一次收入结构改善。一次自如"隔断房 3 天内搬离"的通知让她在平安夜从北四环走到东二环找房，那一晚她下定决心买房：**"我再也不想受这种搬家租房子的苦了。"**

### 3. 三年北漂心路：适应孤独 → 互相成全 → 自我接纳

她在《大大的城市小小的我》里用三句话概括北漂三年——**第一年适应孤独、习惯孤独；第二年"我不爱北京，北京也不爱我，但我们可以互相成全"；第三年"北漂给一个女孩最大的礼物是真正的自我接纳"**。她给"自我接纳"的定义不是"接受现状躺平"，而是三层递进：**① 接纳北京的光怪陆离和冷漠无情——它就是渣男，你来他没欢迎、你走他没挽留；② 接纳这份苦对应的机会溢价——你比家乡辛苦，但你能拿到的也更多；③ 接纳"我可以不做贤妻良母"的独立女性叙事**——正是因为在北京看到那些开大 G 带她穿北四环的姐姐、那些擅长发现下属优势的女主管，她第一次相信"女性的成功有多种可能，不是只有嫁得好一种。"

### 4. 北漂 2.0 · 合作对手 → 内推伯乐：50 家蓝威联动里跳出来的机会

在文学小说出版公司做书时，七天路过主动联系了 50 多家蓝威合作方（网易云阅读、百度阅读等）。其中网易云阅读的合作方觉得"这个小姑娘挺灵活"，就把她的微信推给了 HR，网易正好在招运营。她线上面试通过，从北京出版公司直接跳进了网易（总部在杭州）。她自己反复强调这段：**"我很擅长在工作合作里，把对面变成潜在机会"**——不是把每天接触的合作方视为对方公司的人，而是视为"潜在雇主、潜在伯乐、潜在客户"。这就是她后来能反复被"贵人"接住的底层动作。

### 5. 三方斡旋做书发布会：把 798 变成自己的舞台

第一本书 2018 年 10 月上市，她想搞一场发布会。参考施瓦辛格竞选州长的"三方斡旋"故事，她自己跑：**先对 798 那家大书店说"我们会有畅销书作家来站台" → 再对出版社说"我找到了 798 的场地" → 再对畅销书作者说"我们会在 798 做发布会而且有媒体来"**——三方各拿一半、都愿意加入，最终活动 300 多人到场，梨视频、新华网记者也来了，首印卖完加印，半年内卖出台湾版权。**这段是她"敢要"的最完整示范**：每一环都不是白手起家，而是把已经握在手里的模糊承诺，包装成对下一环有价值的筹码。

### 6. 从北漂到杭漂：为什么在收入曲线上扬时反而离开

外人看她"人脉、资源、收入都在上扬"，但她主动去杭州的两条理由很硬——**① 北京北六环 30 平米也要 200 万，"这个城市没有一盏灯是为你留的"，她留不下来；② 网易总部在杭州、公司给了她过去的机会**。她给"要不要在收益期离开"的判断框架是"**沉没成本会越滚越大，勇气只在年轻时便宜**"。她也很坦白地承认，杭州让她的"创作力在减弱"——浙商务实，见面第一句是"你最近有什么业务没有"，很少像北京那样有天桥艺术中心和南锣鼓巷的文化演出。但这份"接地气"反过来让她开始真正学会算搞钱的账。

### 7. 杭漂 1.0 · 阿里内推：公众号留言区捡到的师兄邮箱

进阿里的过程更"路人"。她关注"晚点"公众号，看到一篇报道阿里海外业务的文章，评论区有位师兄挂了自己的邮箱和微信"感兴趣可以找我内推"，她直接加、直接说"感兴趣、把简历给你"、直接被内推、直接电话面试通过。她自己也感慨"讲出来像编的"——但她的解释很朴素：**"如果你特别想去一家公司，任何一种机会都可以尝试。"** 更进一步：她之所以能接住这个机会，是因为之前已经积累了写作者/前网易运营的背书。**"敢要"要有"要的资本"在手，两者互相供血。**

### 8. 阿里三年：大厂给的钱与拿走的东西

阿里三年是"苦乐参半"。快乐的部分是薪资、体检、饭补、公积金和绩效奖金；痛苦的部分是**"在一群清北+海归+好学生里，你不再是那个第一"**——排名和"我是不是优秀"绑在一起，产生严重的自我怀疑，她当时出现了睡眠障碍、开始吃药、陷入昏昏沉沉的循环。她给自己的关键推翻是"**算实际时薪**"：大厂看起来薪资高，但周末也在为业务焦虑、几乎所有非睡眠时间都被切走。**"计算这份工作值不值得去，不是看月包/年包，而是看时薪，以及生活和工作能不能相对隔离。"**

### 9. 杭州买房：用大厂无息借款 + 公积金 + 稿酬做杠杆

2020 年她在杭州买了房。故事结构是标准的"敢想 → 拆解 → 借力"：**① 判断"我在阿里至少还能稳定工作 2 年"** → 建立可预测的现金流基线；**② 手里的钱 = 北京存款 + 夜里勤恳写稿的稿酬 + 大厂无息借款**；**③ 关键 tip：公积金可以直接抵扣房款**（不用等买房后再取，很多人不知道）。买完后离职一段确实压力巨大，月供近 1 万，但她给"资产 vs 禁锢"的翻译很实用——**"你为你要的安全感付出代价，反过来它就是鞭策你继续搞钱的动力，让你到 30 岁躺不平。"**

### 10. 杭漂 2.0 · 三条腿模型：工资兜底 + 副业探索 + 差异化技能

现阶段的七天路过给出了她的个人商业模式："**人只有一条腿是不稳的，三条腿才稳。**" 现在她的收入结构大致是——**80% 工资**（在冥想公司做市场兜底日常生活）+ **20% 副业**（小报童专栏 + 零散咨询）+ 正在积累但暂时不赚钱的**第三条腿：占星**（拥有差异化技能后，别人有需求会找到"哎，七天懂这个"）。她强调不必执着于"某一刻的比例"，而要瞄准最终想达到的比例，中间不同阶段的重心必然会流动。**"你走的每一步都是在为这栋房子变漂亮做工。"**

### 11. 写书作为杠杆：从 4 万稿酬到"专家背书"的正确算法

七天路过对"写书能不能赚钱"的算法很清醒——40 元定价、10% 版税，作者到手 4 块钱一本，印 1 万册就是 4 万。写书本身不赚钱。但**它是杠杆**：**① 领域专家背书**（她能进阿里做内容运营，很大一部分原因是"这个人出过书"）；**② 写作能力反哺主业**；**③ 别人拿去做副业延伸**：她有朋友出了六七本书 → 做写作课和陪跑营；有朋友写言情 → 卖影视版权 → 与光线传媒合作，年入百万+并在重庆买房。**"不要看这件事的单一价值，要看它衍生空间的想象力。"**

### 12. 谨慎性是女性优势：不是所有信念都要学男性冲

七天路过也直白地评价了性别差异——男生更敢冲，但也常常"特别主观、过度信任自己的判断"；女生的一个天然优势是**谨慎性**。她给"敢冲 + 谨慎"的组合规则是——**看客观规律**：这个领域有没有过成功案例？如果有，你大概率能赚到；如果没有，你大概率会难。而且要拆解：**"这个赚钱路径里，有没有需要特殊资质、特殊关系、特殊技能"**（比如四五线城市开烟酒店赚钱，但资质本身可能是难关卡）——如果有，这个案例对普通人无效，得排除。**女生的谨慎不是软弱，是筛选杠杆的能力。**

### 13. 反思读书会/我想开了社群：兴趣不是复利

她诚实地反思了"我想开了"社群阶段——线下读书分享会等活动，好的时候能月入 1 万，但**"跟上班比差远了"**。核心失败在于两点：**① 读书本身不具备商业性**（一本书几十块钱，只能加社交属性拉动）；**② 每次做活动都想不一样、自己嗨**——从商业角度这是最不聪明的玩法，"按道理你做一次，让这个动作不停滚动、带来复利。"**创意型人格的搞钱陷阱就是"每次都变"**——用小报童这种做长专栏、把差异化技能变成沉淀，比"每期活动主题都变"要更接近复利。

### 14. 敢要方法论：50% 成功率 vs 100% 失败率

她把"敢要"总结成一个非常反常识的算法——**"你去做这件事情，最坏也就是 50% 的失败率；你不去做，就是 100% 的失败率。"** 支撑她这一底气的是大学两个小故事——**① 50 块进货的小饰品在楼道口卖，两三天赚 200 元**（做生意的初体验）；**② 兼职销售被雇主临时压价一半，她怕但仍然冲出去说"你这样我们就打维权电话"，把钱要回来**。她自己承认"当时特别害怕"，但敢站出来这件事本身，是后来敢在公众号留言区找师兄内推、敢投稿 50 家大号、敢做三方斡旋发布会的心理肌肉。**"你不去做，就没有 50% 成功。"**

### 15. 不要着急舔贵人：先让自己成为"能给贵人价值"的人

七天路过对小红书上流行的"向上社交"提出了反面提醒——**"不要轻易加一个人的微信"**。因为如果你加了对方却没有可以输出给他的东西，就浪费了一次会晤机会。她给"向上社交"的正确姿势是**先想清楚"我能给他带来什么价值"**——不一定是钱，可能是**"我在杭州生活了十几年，任何时候可以带你去你想去的地方"**这样非常具体的价值点。**"当你能跟贵人产生链接的时候，一定是你对贵人也是有价值的。"** 学习观察别人的需求并以此为乐，就是最好的搞钱前置动作。

### 16. 未来图景：像李银河一样，"专业上有建树、生活上有真诚"

关于愿景，七天路过说得很清楚——她的偶像是李银河，"专业领域有所建树 + 生活领域足够丰富、足够真诚"。她想通过内容表达和自己做成的事情**"让 1 万个女孩看到自我的可能性、勇敢争取自己想要的东西"**。她也提醒自己不要为了做榜样而做榜样——**"如果你的动作只是为了做给别人看，动作会变形。"** 她的下一本书主题预告是"我想开了"——关于自我疗愈。收尾主播用了摘星阁创始人侃侃的话来概括她——**"用爱影响人，用影响力爱人。"**

## 关键问答

**Q1｜命运齿轮转动的关键节点是哪几个？**
A：三个——**① 开始写作**（表达 → 被看见 → 出书 → 进大厂全打通）；**② 进大厂**（既知道自己可以赚更好的钱、也知道自己不适合大厂）；**③ 从大厂离开、从轨道回到旷野**（意识到能不能赚到钱不取决于抬头，取决于是不是发挥自己的优势）。写作是入口，大厂是试金石，离开是回到自我。

**Q2｜北漂到杭漂的迁移，怎么判断是不是舍不得？**
A：她的判断框架是**"沉没成本会越滚越大、勇气只在年轻时便宜"**。北京客观留不下来（30 平米北六环也要 200 万），杭州能不能留下来虽然也是未知，但**"大不了再回北京"**——她把选择框在"可撤销"里，就敢跳。以及要"多在年轻时到边角张望"，不要早早锁定。

**Q3｜写书真的能赚钱吗？**
A：单本书作者拿到手大概 4 万，本身不赚钱。**赚钱的是它作为杠杆的三层衍生**——领域专家背书（换更好的工作机会）、写作课/陪跑营等延伸产品、影视 IP 版权（有朋友靠言情小说卖版权年入百万）。所以判断一件事值不值得做，不看它单点值多少钱，看它未来衍生空间有多大。

**Q4｜普通女孩想搞钱，最应该培养的心态是什么？**
A：**敢要**。先敢，再要——投稿也是投出去才有 50% 成功，不投就 100% 失败；内推邮箱在公众号评论区也是加了才有机会；发布会 300 人也是三方斡旋斡出来的。**"你不去做，就是百分之百的失败率。"** 加上一条女性谨慎性的优势——**看有没有客观成功案例、拆解案例里的门槛（资质/关系/技能），别硬冲不适合自己的领域**。
