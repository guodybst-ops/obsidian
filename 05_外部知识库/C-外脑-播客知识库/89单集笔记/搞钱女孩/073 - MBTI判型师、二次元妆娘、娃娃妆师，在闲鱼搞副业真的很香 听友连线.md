## 一句话摘要

这是搞钱女孩与闲鱼合作的听友连线专场，四位听友九然（211 硕士 · MBTI 判型师）、陈东君（长春大客户经理 · 配音包工头）、阿珍（新传硕士 · 二次元妆娘）、汤圆（全职宝妈 · 小布娃娃妆娘）分别演示了「把兴趣 / 主业 / 全职带娃场景变成闲鱼可交付服务」的四条路径，共同验证了闲鱼「兴趣电商 + 内容自媒体 + 时间型服务」的三位一体属性，以及「把一份时间售卖多次」的杠杆化搞钱心法（Naval《纳瓦尔宝典》为共同底层书目）。

## 要点提炼

### 九然｜南京 211 硕士 · MBTI 判型师 + 闲鱼副业课程主理人

- **人设与起点**：ENFP，本科人力资源管理，辅修心理学与 ACCA。因自己"学得会但做不到顶尖"发现 MBTI，四年荣格类型学研究者、一年猎头顾问、累计判型 200+ 人次。
- **闲鱼服务定价**：早期 40 元/小时 → 涨到 50 元/人；6 月流水 3000 元，7 月因转做课程降至 2000 元；固定复购客户 5 人，每周咨询 1-2 小时。
- **服务链条**：闲鱼下单 → 收集用户背景（年龄/身份/困扰领域）→ 借 Kimi 生成 40 题量表 → 用户答题 → 对模糊维度做补充量表 → 出 MBTI 类型 + 各维度倾向比例 + 书籍/榜样推荐（如给 INFJ 管理者推查理·芒格、德鲁克）。
- **服务本质**：判型只占 10%，情绪价值 + 深度对话 + 书单/榜样推荐占 90%，接近 coaching。
- **升级路径**：把「一份时间卖一次的咨询」升级为「小红书笔记 → 微信引流 → 199/299 元付费课程」；一篇 15000 点击笔记转 150 人微信、38 人付费，实现「一份时间售卖多次 + 后续成本趋零」。
- **底层书籍**：《纳瓦尔宝典》→ 三大杠杆（自媒体 / 劳动力 / 资本）。
- **社会关怀**：定位「家族第一代大学生」这个群体（本人也是），用 MBTI 减少试错、用闲鱼积累原始资金，链接更多社会资源。
- **闲鱼玩法总结**：
  - 闲鱼 = 兴趣电商 + 内容自媒体
  - 用官方「闲鱼简历」功能包装人设
  - 打破千人千面魔咒：先去小红书搜「闲鱼上有哪些技能副业」，带关键词回闲鱼验证
  - 找需求：看爆款笔记评论区「点赞最多的未解决问题」
  - 强化搞钱信念，潜意识才会捕捉到搞钱信息

### 陈东君｜长春大客户经理 · 定制配音「包工头」

- **人设与起点**：吉林长春，主业高新技术企业大客户经理，副业配音从 2021 年 6 月起做。主业合同单张上百万，客户服务能力天然复用。
- **原始技能**：大学广播站积累 + 自媒体做视频时接触配音平台 → 报名 → 通过审核 → 第一单银行 60 字 60 元，手机录制。
- **配音行业变现地图**：
  - 有声书：小时 300 元起，头部吃肉、尾部靠分成（VI 发电）
  - 游戏：单价最高，按句计价，几十到 200 元/句（王者、原神类）
  - 短视频文案：按百字符计价，市场价 40-100 元
  - 广告：需求量大但竞争激烈
- **副业模式升级**：从「自己接单」→「配音圈中介 / 包工头」。
  - 手上资源：约 20 多个配音圈行业群、共 1 万+ 配音演员
  - 客户在闲鱼下单 → 自己在群内发单 → 演员接单后按 5%-15% 服务费返给他（多数自愿付 10% 以上）
  - 询单转化率约 33%（三询一成）
  - 单月副业收入约 2000+，转型包工头后收入变多、时间自由度也高
- **闲鱼获客要诀**：
  - 关键词做优化，能接的方向全部铺进去
  - 优先视频 > 图片 > 文字；尽量露脸（面部记忆特殊）
  - 用好闲鱼简历新功能，浏览量与曝光量倍增
- **口碑与边界**：不接反音付费、不打价格战、免费重录；识破「打字赚钱 / 兼职剧拍」等骗局，凡加 QQ / 企鹅、发图片藏微信号的一律拉黑。
- **才艺展示**：现场演示章鱼哥、海绵宝宝、熊大等模仿秀，并读了乙女向游戏「虚拟男友」的晚安 / 早安语音（客单 60 元一段的产品）。

### 阿珍｜大连新传研三 · 二次元 cos 妆娘（10 年从业）

- **人设与起点**：01 年生，2015 年（初中毕业）开始给朋友化 cos 妆，从 15 元/单起步，至今整整 10 年从业。
- **单场收益**：一场漫展一天接约 10 人，两天 20 人，客单 60-80 元，保底 1200 元/场；大连一个月保底 2 场漫展，稳定月入 2500 左右，国庆等长假可到 3000。
- **成本结构**：低保 900 + 副业 2500 完全覆盖 1500 元/月生活费。
- **平台演变**：QQ 空间 / 贴吧 → 闲鱼；闲鱼提供定金 + 尾款走单担保，替代过去的口头约定。
- **客源结构**：本地圈层口口相传为主；建了 QQ 群 200 人 + 微信群 100 人做私域承接。
- **未来分工**：想请「打底娘」帮忙打底妆，自己专注细化妆面，两人二八或七三分成；想把接单规模再抬一档。
- **对标 IP**：卡琳娜的化妆师云泽（系统学过化妆、走嘉宾妆路线，单价上千）；上海 CP 漫展的头部妆娘从凌晨 1 点排到下午 4 点，一场收入极高，双人档能做到月入 2-3 万。
- **天花板认知**：二次元妆娘的核心消费者是未成年，客单低，本质上是"传统技师、师带徒"；想突破必须转「三次元新娘妆」或「二次元美妆博主」个人 IP。
- **正在做的事**：
  - 开始运营小红书号（新传专业背景加成），准备切「二次元美妆」蓝海赛道
  - 论文选题是女性主义，把「搞钱」视为女性对抗厌女环境的一种方式
- **关于「大女主爽文」的独立思考**：所谓大女主只是把男性形象套在女性身上、去女性化，真正的女性力量应该是用女孩的方式实现女孩想要的东西。

### 汤圆｜全职宝妈 · 小布（Blythe）娃娃妆娘

- **人设与起点**：两娃全职宝妈，前财务，副业 3 年（前两年做软陶娃娃、近一年转小布 Blythe）。
- **收入**：一开始练习头 99 元/个，第一个月做到近 3000 元；如今单价 3000 元左右，月入约 1 万；有一位「王妈」在她这里累计买 10+ 娃、消费约 3 万。
- **业务本质**："壮饰 / 装饰"——对原厂小布娃娃做魔改：雕刻五官、化妆、换发换衣，把流水线半成品做成可爱的成品。
- **平台组合**：闲鱼（成交主场）+ 小红书 + 抖音（引流 + 蹲娃粉运营）；粉丝群约 1000-2000 忠粉。
- **闲鱼玩法**：
  - 同一链接可反复上架 → 反复吃曝光
  - 必须写「现货」两字命中买家搜索意图
  - 视频比图片重要，图片比文字重要；必须 360° 展示、不打滤镜
  - 发货前再补 360° 实物视频规避纠纷
  - 用闲鱼「帖子 / 状态」功能锁粉，粉丝可第一时间看到新链接
- **两个平台的差异**：
  - 闲鱼买家：看视频秒决，要现货
  - 小红书买家：接受「蹲娃」等待半年到一年，享受养成系过程
- **门槛策略**：主动从软陶娃娃（低门槛、卷）迁往小布娃娃（雕刻工艺门槛高），用门槛护价。
- **副业与家庭**：
  - 每天用 4-6 小时碎片时间做娃
  - 副业带来情绪调和：思考安静、变现有成就感，反过来带娃更有耐心
- **给宝妈的搞钱建议**：从自身兴趣 + 动手能力出发；不要盲目追和自己能力不匹配的方向；小心受骗（尤其宝妈群体）。

## 关键问答

- **Q1：MBTI 咨询和网上免费测试的差别是什么？**
  A（九然）：网上给结论、我给情绪价值 + 深度对话 + 书单/榜样推荐；病人找医生 90% 也是要情绪价值，不是要冰冷结果。
- **Q2：MBTI 被贴标签、被曲解，你怎么看？**
  A（九然）：任何工具进入大众传播都会被曲解；关键是把它当认识自己的工具、而不是逃避责任的借口——不能因为「我是 P 人」就逃避。
- **Q3：闲鱼上怎么发现「我不知道自己能做什么副业」？**
  A（九然）：**跨平台反查法**——先去小红书搜「闲鱼上有哪些技能副业」，再带关键词回闲鱼作为买家咨询同行，把整条服务链学会；再看爆款笔记评论区点赞最多的未解决问题。
- **Q4：配音副业从「自己接单」到「包工头」有什么心得？**
  A（陈东君）：主业客户经理的服务能力比配音本身更稀缺，配音演员群里发单不需要额外流量，5-15% 服务费自愿给（多数给 10% 以上），既服务客户又服务同行。
- **Q5：闲鱼流量的入口在哪儿？**
  A（陈东君 + 汤圆共识）：搜索为主 → 关键词优化 + 视频 > 图片 > 文字 + 露脸；反复上架同一链接吃曝光；用闲鱼简历 / 帖子锁粉。
- **Q6：二次元妆娘的天花板是什么？**
  A（阿珍）：核心客群是未成年 → 客单低 → 传统「师徒作坊」难成规模；想突破得转三次元（新娘妆客单 300-1000+）或做二次元美妆博主个人 IP。
- **Q7：全职宝妈怎么找到自己的擅长？**
  A（汤圆）：她自己也困扰了几年——路径是「刷手机看到喜欢的娃娃 → 买抖音教程学 → 挂闲鱼卖掉一次尝到甜头 → 一步一步走出来」。信念：每个人都有过人之处，善于发现，不要盲目追远。
- **Q8：搞钱女孩节目里唯一男性主持人小辉的合理性？**
  A（阿珍）：论迹不论心，男性从女性视角出发去传播「女孩也可以搞钱」，这件事本身就有利于女性主义；不必陷入二元对立的内耗。

## 可复用方法

### 方法 1｜闲鱼副业赛道选择四步法（九然复用 · 通用）

1. **确认闲鱼三重属性**：二手 + 兴趣电商 + 内容自媒体，别再只把它当二手平台。
2. **闲鱼简历包装**：官方新功能，把技能积累、专业背书、成绩量化全部放进去；不会写就学同行、模仿同行。
3. **跨平台反查赛道**（破千人千面）：小红书搜「闲鱼上有哪些技能副业」→ 得到关键词 → 回闲鱼作为买家咨询同行 → 学服务链条。
4. **需求侦查**：小红书 / 抖音爆款笔记评论区，点赞最多但没被回答的问题 = 未被满足的需求 = 你的切入点。

### 方法 2｜MBTI 咨询服务化流程（九然复用）

1. **前端**：闲鱼简历打人设关键词 + 具体从业年限 + 判型数量。
2. **收单**：让客户先提供背景（年龄、身份、工作年限、想解决的具体问题）。
3. **量表**：Kimi 生成 40 题基础量表 + 客户答题后对模糊维度做补充量表。
4. **判型输出**：MBTI 类型 + 各维度倾向比例 + 针对性书单和榜样。
5. **升级为课程**：把 SOP 沉淀成小红书笔记 → 微信引流 → 199-299 元付费课，实现「一份时间售卖多次」。
6. **信任建立**：不用技巧，做自己 + 直播输出 + 客户真实反馈。

### 方法 3｜圈层化技能副业「转包工头」路径（陈东君复用）

1. **积累专业圈子资源**（配音 / 剪辑 / 设计 / 翻译）：加行业群、加发单人。
2. **在闲鱼上做「客户端」营销**：客户经理式话术、露脸、承诺服务标准。
3. **形成撮合闭环**：客户下单 → 群内发单 → 5-15% 服务费自愿给。
4. **口碑护城河**：不打价格战、免费重录、不吃差价明说、拒接骗子（识别「打字赚钱」「兼职剧拍」「加 QQ」等信号）。
5. **询单转化率约 1/3**，把询单量做上去是关键。

### 方法 4｜二次元妆娘 → 三次元 / 个人 IP 升级路径（阿珍复用）

1. **本地圈层深耕**：QQ 空间 → 贴吧 → 闲鱼下单担保 → 建 QQ/微信群做私域。
2. **产能扩张**：培养「打底娘」搭档，两人分成七三或二八，接单量翻倍。
3. **突破天花板路线 A**：转三次元新娘妆（客单 300-1000）。
4. **突破天花板路线 B**：小红书运营个人 IP「二次元美妆博主」蓝海赛道。
5. **异地增长**：上海 CP 漫展等一线城市的漫展密度和客单价远高于二线，双人档月入 2-3 万可及。

### 方法 5｜宝妈 · 手作副业闲鱼三板斧（汤圆复用）

1. **门槛策略**：主动往「工艺门槛更高」的品类迁徙（软陶娃娃 → 小布娃娃）用门槛护价。
2. **闲鱼上架 SOP**：
   - 标题必带「现货」两字命中搜索
   - 视频 > 图片 > 文字，360° 展示、不打滤镜
   - 同一链接反复上架吃曝光
   - 发货前再发一次 360° 实物视频防退货
3. **双平台组合**：闲鱼负责成交，小红书 / 抖音负责蹲娃粉与内容沉淀。
4. **碎片时间管理**：4-6 小时/天，避开孩子活动高峰；用副业做情绪调和剂。

- **闲鱼商业化色彩**：本集为闲鱼冠名赞助专场，四位嘉宾都在闲鱼吃到红利，节目对「闲鱼是蓝海」的判断需打折——反例（失败率、店铺被封、纠纷率）没有出现。

- **家族第一代大学生框架**：九然的价值主张真诚，但把 MBTI 咨询等同于「阶层跃迁工具」，逻辑链条较长，可能过度承诺。

- **总体样本偏差**：四位嘉宾都是"已跑通"的样本，闲鱼上更常见的滞销 / 骗局 / 售后纠纷未被展示。
