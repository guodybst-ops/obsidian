# 159 - 金价狂跌快顶不住？一次搞懂黄金底层逻辑，不惧波动！

## 一句话摘要

CFA 金融分析师、播客《截胡不劫财》主播 Jeff 再度做客，复盘金价从 1180 元/g 高位跌至 960 元/g（一个月内缩水近 20%）的多重成因：前期获利盘泡沫 + 美伊战争推高油价 + 强美元流动性抽血 + 鲍威尔"不降息甚至可能加息"的鹰派预期。Jeff 把黄金拆成一句话跷跷板："本质上买黄金是看空法币的信用，卖黄金是看多法币的利率"；给出普通人 5%-10% 流动资产配置比例、菲波纳切黄金分割支撑位（4750/4500/4400-4500/4000）、"看空即持有实物金压舱、ETF 做波段"的分层策略；并纠正三个常见误区：黄金不是避险资产是高波动风险资产（波动率 40% >> 沪深 300 的 20%）、高收益 ≠ 高风险（高收益来自高安全边际）、看似分散的金银铜其实一条裤子上会一起挂。

## 要点

### 1. 这轮金价 20% 跳水的行情基本盘

- 一个多月前国内金价飙到 1180 元/g，最近跌到 960 元/g，缩水近 20%。
- 国际金价从 5600 美元/盎司高点回调到 4300 美元/盎司区间，最大回撤逼近历史级别（历史上黄金最大回撤从高位下来接近 70%）。
- Jeff 1 月 29 日 5200 美元上方分批清仓 ETF，仅保留实物金；后续在 4700 / 4500 / 4300 分批加仓，属"预设支撑位、按纪律执行"的标准操作。

### 2. 跳水四大因素叠加

1. **获利盘泡沫**：25 年黄金投资需求增加 800 吨（占年需求 5000 吨的 20% 增量），机构+散户都在追涨列车上，宇宙大行实物金一度断货售罄。
2. **美伊战争 + 油价冲破 100**：短期避险冲高 3-5 天就 price in，随后霍尔木兹海峡封锁→油价飙至 100+→日本等对油依存度 90% 的国家紧急抛日元资产换美元买油→强美元→黄金相对变贵。
3. **流动性抽血**：黄金是全世界流动性最好的资产之一，且过去一年利润盆满钵满，被机构和散户第一个抛出变现（散户"盈利卖掉，亏损装死"心理）。
4. **鲍威尔鹰派表态**：3 月 20 日议息会议后不但没降息预期，部分票委甚至表态"不排除加息"。加息 → 实际利率上升 → 黄金作为无息资产机会成本上升 → 国内华安黄金 ETF 跌停（收 -9%+）。

### 3. 长期上涨主逻辑：黄金 = 法币的镜像

- 1971 布林顿森林体系解体前，黄金和美元是"孪生兄弟"（1:35 美元/盎司挂钩）；解体后转为完全镜像的竞争对手。
- 全世界央行目标都是"温和通胀"（美联储 2% 通胀目标）→ 法币印钱速度无限，黄金储量有限 → **只要温和通胀存在，黄金永无声息地涨下去**。
- 参照：1971 年美债 4000 亿 / 黄金 30+美元 → 现在美债 39 万亿（每年 5-7% 失控增长）/ 黄金 4500 美元。100 倍美债对应 100 多倍金价，高度正相关。

### 4. 三大长期动能：抗通胀 / 避险 / 信用

- **抗通胀**（长期主导）：1970 年代滞胀期黄金一骑绝尘，房产股票被按在地上摩擦一年不动。
- **避险**（当前弱化）：地缘战争已见怪不怪，price in 速度以毫秒计，短期避险溢价越来越低。
- **信用（当前主导）**：22 年封俄罗斯外储后美元信用一落千丈；央行去年买入 800 吨，24/23 年均超 1000 吨——**这才是长期支撑金价的核心引擎**。

### 5. 短中期核心变量：实际利率跷跷板

- 实际利率上升 → 定存/美债/中债都比黄金更优 → 用脚投票 → 黄金短期承压（22 年加息周期跌了 20% 左右）。
- 实际利率下降 → 黄金重拾涨势。
- 但美债 39 万亿的天量债务决定"利率长期无法维持在高位"（利息会把政府拖垮）→ **短期实际利率上行 = 黄金跌，跌完必反弹**。

### 6. 内在价值 vs 价格：围绕价值曲线做波段

- 价值是一条平坦曲线，价格因情绪围绕价值上下波动：贪婪时价格>价值，恐惧时价格<价值。
- Jeff 的自测锚：4500 美元上方是"内在价值上方"→ 分批减仓；4700/4500/4300 三个技术支撑位越跌越买。
- 这不是投资建议，是个人交易纪律的具象化——**每个人都要有自己的"看不懂就卖，够便宜就买"的分层清单**。

### 7. 菲波纳切黄金分割支撑位

- 从 2024 年 8 月底突破箱体到 2025 年 1 月 29 日见顶 5600 的这一波涨势，用菲波纳切数列（1、2、3、5、8……前两项之和为下一项）做黄金分割 61.8%。
- 得到四条支撑位：4750（第一）/ 4500（第二）/ 4400-4500（次强）/ 4000（末位）；再下方就是灾难级的 3400 起步低位。
- 逻辑："走的人多了自然成了路"——机构和量化都在盯这几条线，越多人看就越有效。

### 8. 三大误区纠正

- **误区一**：黄金是避险资产 → **实为高波动风险资产**，隐含波动率一度到 40%，沪深 300 才 20%，近两周直接跌 20%。
- **误区二**：高收益 = 高风险 → **真正的高收益来自高安全边际**（霍华德·马克斯《周期》）：买得够便宜，下跌空间有限，上涨天花板高。
- **误区三**：金/银/铜/铂/钯多资产组合分散风险 → **一条裤子上一起挂**。金铜比、金银比是所有交易员共用的比值锚，联动性极强；真正低相关是农产品/稀土。

### 9. 普通人配置比例：5-10% 流动资产上限

- 刨除自住房，可投资流动资产的 5%-10% 配黄金。
- Jeff 自己 3% 出头（<5%），偏轻仓。
- 反例：跌 20% 后段子——"油价国家控制了觉得心里安慰，回家一看房子跌没了，省了一点其实亏了一大堆"。
- 单一资产超过 50% 就是危险——**任何一个大决策不要压住超过半个身位**。

### 10. 实物金 vs ETF 的分层用法

- **实物金 = 房子逻辑**：不因为半年涨 10% 就卖自住房；实物金是"压舱石"，长期持有不惧涨跌，避免频繁交易。
- **ETF = 交易仓位**：这是拿来做波段的部分，触及技术阻力位就减仓/清仓。
- Jeff 的操作：1 月 29 日 5200 上方把 ETF 全部平掉，实物金一直留着。

### 11. 买入时机：媒体不聊的时候才买

- "身边聊黄金的人不多的时候，你去买入一个金条塞在床底下，你一定赚钱。最好不要在我小灰都跟你聊黄金的时候你去买。"
- 媒体热议 = 动荡期或亢奋期 = 顶部信号；采访录制到发出的一段时间差本身就是"安全边际"的一种。

### 12. 情绪与预期管理：跟不上就别追

- 短期波动别看（除非到几个核心支撑位 + 波动率极值 + 成交量共振）；跟得上时机构已 price in，你去就是接盘。
- **预期管理**：买入前先想"如果不符合预期，跌 20-30% 我能不能扛"，扛不住就减仓。
- 5600 冲进去的人在 4400 时已经 -20%——历史上黄金最大回撤 70%，任何时候都别 all in。

### 13. 三种情景下的一年展望

- **加息**：黄金必然继续跌，第一支撑 4000，跌破后 3400-3000 危险区间。
- **利率不变**：只要油价回落至 80 美元/桶以下，黄金在 4300-4800 宽体震荡一年。
- **降息**：重拾涨势；5000 是关键阻力位，冲破后目标 5600 → 大行预测 6000-6200。
- Jeff 结论：**不预测只应对**，用仓位管理和支撑位分层。

### 14. 除黄金外的配置建议：红利/现金流 vs 讲故事

- **看好板块**：红利+现金流类（中国移动 / 长江电力 / 中海油 / 工商银行 / 全球大能源公司 / 农产品种子公司 / 高速公路 / 稳健食品）——大而不能倒 + 门槛/垄断。
- **谨慎板块**：讲故事的少买——航空航天、无盈利小公司、AI/机器人赛道被炒到 P/E 几百倍的。美联储万一加息，科技股 DCF 折现率会杀估值，七姐妹已经在跌，英伟达最近 -15% 到 20%。
- **持有现金也未尝不可**：今年全球高波动 + 中期选举 + 地缘战争，去年 A/日/韩/美/黄金全涨积累获利盘，现金是有效的降波仓位。

### 15. 黄金关联品种一览：真正的低相关在哪

- **白银**：放大版黄金 + 工业属性，跟金高度同涨同跌。
- **铜**：正相关，工业属性更强。
- **铂金/钯金**：小众但同链，最终一起挂。
- **稀土**：与金关联度低一档。
- **农产品**：关联更低，但依然受油价传导（化肥+物流成本上行→餐桌农产品涨）。
- **金铜比 / 金银比 / 金油比**：所有交易员共同盯的比值锚，任一端偏离另一端会联动。

## 关键问答

**Q1：美伊战争打得火热，为什么"乱世买黄金"这次不灵？**
A：短期避险冲高只维持了 3-5 天就 price in。战争带来的真正影响链是：油价冲破 100 → 各国紧急囤油需要美元 → 强美元 → 黄金相对变贵 → 加上前期获利盘密集抛售 + 鲍威尔"不排除加息"表态叠加，导致过去一周十五六个点跌幅。**避险不是单向机械触发，要看后续油价/美元/利率的传导链**。

**Q2：普通人应该配多少黄金？什么时候买？**
A：可投资流动资产的 5-10%（刨除自住房）。买入时机不是看跌到哪个价，而是看"身边聊黄金的人少不少"——媒体热议时不追，媒体降温后 + 到达菲波纳切支撑位（4750/4500/4400/4000）分批入场。Jeff 自己 3% 出头，属偏轻仓的稳健配置。

**Q3：实物金和 ETF 应该怎么分？**
A：**实物金 = 压舱石**（房子逻辑，不因短期波动买卖，长期抗通胀）；**ETF = 交易仓位**（拿来做波段，触及阻力位就减仓）。Jeff 1 月 29 日 5200 上方 ETF 全平仓、实物金一直留着，就是这个策略的实操——把"抗通胀"和"择时"分层管理。

**Q4：为什么"高收益 = 高风险"是错的？**
A：这是霍华德·马克斯《周期》里的纠错——如果高收益一定伴随高风险，那就不叫风险了，是确定事件。**真正的高收益来自高安全边际**：买得够便宜，下跌空间已经很有限，但上涨天花板未被封顶。黄金 4500 以下之所以敢加仓，不是赌它会涨，是赌"再跌也跌不到哪去"。

**Q5：金/银/铜/铂/钯多品种配置能真正分散黄金风险吗？**
A：不能。**一条裤子上一起挂**——白银是放大版黄金，铜是工业属性更强的正相关品，铂/钯是小众同链。金铜比、金银比是所有交易员共用的比值锚，联动性极强。真正低相关是稀土、农产品——但农产品又受油价传导（化肥/物流→餐桌）。**想真正对冲要跨大类：股票/债券/黄金/现金/商品**。

**Q6：短期波动这么多，普通人应该怎么应对？**
A：**跟不上就别追**。机构量化以毫秒 price in，你看新闻的时候价格已经反映完了，去了就是接盘。三条纪律：① 5-10% 上限不破；② 预设支撑位 + 分批买入清单；③ 买前预期管理（跌 20-30% 我扛不扛得住？扛不住直接减仓）。

**Q7：一年内金价怎么看？**
A：三种情景——**加息**跌破 4000 到 3400/3000 危险区；**利率不变** + 油价回落 80 美元/桶以下 → 4300-4800 宽体震荡一年；**降息** → 冲 5000 阻力位，破了就看 5600、大行喊 6000-6200。Jeff 的原则是**不预测只应对**，只在拐点用仓位管理响应。

**Q8：除了黄金，现在还有什么板块值得看？什么要避开？**
A：**看好**——红利+现金流（中国移动/长江电力/中海油/工商银行 + 全球大能源/农产品种子/高速公路/稳健食品，大而不能倒 + 门槛/垄断）；**避开**——讲故事无盈利小公司、AI/机器人炒到 P/E 几百倍的、七姐妹科技股（美联储加息 DCF 折现率会杀估值，英伟达已经 -15% 到 -20%）；**持有现金也 OK**——今年高波动 + 地缘战争 + 中期选举，降波仓位比无脑投资更稳。

## 可复用方法

### 方法 1：黄金 5-10% 配置 + 实物金/ETF 分层法

1. **上限锚定**：可投资流动资产（刨自住房）的 5-10%，Jeff 自己 3% 出头偏保守。
2. **实物金 = 压舱石**：占黄金仓位的 50-70%，长期持有不做频繁交易。
3. **ETF = 交易仓位**：占黄金仓位的 30-50%，只在触及支撑位/阻力位时动。
4. **调仓时机**：媒体不聊黄金的时候买，媒体热议时减；不追高不 all in。

### 方法 2：菲波纳切支撑位分批买入清单

- **锚定波段**：从上一轮突破箱体起点（2024/8 底）到高点（2025/1/29 冲高 5600）画黄金分割 61.8%。
- **四条支撑**：4750（第一）/ 4500（第二）/ 4400-4500（次强）/ 4000（末位）；4500 内在价值线，4000 以下极端安全边际。
- **纪律动作**：不是价格连续下跌就买，而是**到达支撑位后先观望，撑不住再往下一档买**。
- **止盈镜像**：上方对应 5200 阻力（Jeff 减仓点）、5000 关键位、5600 前高、6000-6200 大行乐观锚。

### 方法 3：预期管理三步问答

买入任何单一资产前先自问三题：
1. 如果这个资产跌 20-30%，我扛得住吗？（黄金历史最大回撤 70%）
2. 如果这个资产不涨甚至横盘 1-2 年（滞胀期股票/房产就是被按在地上摩擦一年），我持仓仓位会不会拖垮我的现金流？
3. 我买入的理由是"看到大家在买"还是"我看得懂它的价值曲线在哪"？

### 方法 4：跷跷板决策框架（利率 vs 信用）

- **买黄金 = 看空法币的信用**（法币无限印钱 → 黄金作为镜像永无声息涨）。
- **卖黄金 = 看多法币的利率**（实际利率高 → 定存/美债机会成本更划算）。
- 当"信用崩坏 + 利率高企"同时发生时（如现在），黄金会**长期涨 + 短期承压**，用波段策略应对。
- 当"信用稳定 + 利率下行"时，黄金加速涨，加仓即可。

### 方法 5：高安全边际 > 高收益的选股心法（引霍华德·马克斯《周期》）

- 不再迷信"高收益 = 高风险"这句被误用的话。
- 真正的高收益 = 高安全边际：买得够便宜（下跌空间已经被市场消化完），上涨天花板尚未被封顶。
- 应用场景：红利股 + 大而不倒的公用事业 + 极端超卖时的黄金 4300 以下 + 熊市末期的宽基指数。
