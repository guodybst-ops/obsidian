# 099 - Monica：从月薪4K到月入百万，96年二奢店主的人生起飞思维

## 一句话摘要

96 年江西姑娘 Monica 以"从月薪 4K 到月营收过亿"的二奢中古店案例，拆解一整套从选行业、选公司、算成本、扛意外、扩团队、做客源到花钱观的实战路径；核心心法是"选择大于努力、行业天花板 + 个人天花板双维度决策、亏得起再上桌、边做边学"，并对普通女生给出"人生容错率其实很高"的通关式鼓励。

## 金句

- **"创业很重要的一点不是你有多少钱去投，而是这个钱亏了你亏不亏得起。"** —— Monica 谈风险边界
- **"世间是草台班子——我在毕业那年发现的最重要的事。"** —— Monica 谈第一份创业的顿悟
- **"我的原则是有多少钱办多大的事，没钱的时候干没钱该干的事，很正常。"** —— Monica 谈消费观

## 要点提炼

### 1. 嘉宾档案

- Monica，1996 年，江西人，ESTP。上海二奢中古店店主，创业 5 年，40 人团队，独栋钟古店，年营收过亿，月净利润峰值百万。
- 教育背景：服装设计专业，实习后进深圳马斯菲尔（服装大公司），4 个月转正前裸辞。
- 内容矩阵：小红书 @只说真话的莫妮卡。

### 2. 关键决策 1：从大公司到二奢——3-5 年天花板法

- 大公司干十年也买不起深圳的房→天花板可预见→不干。
- 咖啡师 / Vintage 服装 / 二奢中古 / 专柜四条 offer 中选二奢：**"我看重的是 3-5 年以后的成果，不是当下工资。"**
- 双维度决策：**行业天花板 + 自己在行业里的个人天花板**——专柜的天花板是店长，二奢的天花板是老板。

### 3. 二奢生意模型（Monica 口径）

- **利润率演变**：2020 年入行时 30-50%（暴利）；现在 ≈10%（存量期）。
- **资金结构**：年营收过亿 → 平均月流水千万；大量沉在货品滚动。房租 20+ 万 / 月，人力 70+ 万 / 月，隐性成本极高。
- **收入组成**：卖包（主）+ 直播 GMV + 寄卖 / 回收 + 售后（清洁 / 保养）。
- **利润节奏**：好月净赚百万，平月打平，行业里亏损同行不少。

### 4. 关键决策 2：入行选"小而全"而不是"大公司螺丝钉"

- 大店给的是螺丝钉岗；小店"什么都要你做"，学习速度快 10 倍。
- 老板让直播就直播——**"他让我干，我就应该能干"** 的行动派心态是入行前 6 个月最大的资本增值。

### 5. 关键决策 3：被推着创业——从合伙到独立

- 起点：好朋友辞职冲动拉合伙，Monica 不好意思拒绝，找爸爸要 50-100 万，本以为爸妈会否决，结果通过。
- 一个月即散伙（合伙人只求"想上就上"的自由，Monica 想把事情做好）。
- 散伙后 Monica 想退，爸爸补一句"赚了算你的，亏了算我的"——第二次续命。
- **心得：家庭安全网降低了创业启动风险；亏得起才敢上桌。**

### 6. 关键决策 4：老洋房违规被叫停——被迫扩店

- 上海老洋房不可营业，警察上门当天关店；一周内被迫租下 200 平商住店铺（愚园路 1221 弄 401）。
- **被迫扩大成本 → 被迫更努力 → 反而做大。**
- 结论：**约束条件常常反过来推着你走向下一个 level。**

### 7. 关键决策 5：疫情后店长离职——事业心觉醒

- 店长（好朋友）离职理由："在小公司没有安全感"。
- Monica："全身冰冷"——第一次真正下决心把公司做大。
- 由此转入愚园路网红街独栋 200-500 平大店，跨过小红书取消二手扶持的行业淘汰周期。

### 8. 保值品牌与流通性法则

- **保值第一梯队**：Hermès、Chanel、LV；珠宝里 Bvlgari、VCA、Buccellati。
- 判定因子：**品牌 > 单品爆款度 > 流行程度 >>> 设计师**（设计师影响几乎为 0）。
- 香奈儿 CF / 2.55 是常年通吃；沙滩包（1-2 万入门级）年年好卖；带手柄款近两年吃流行红利。
- **反例**：香奈儿冷门托特 5 万入手 → 二手 1 万，冷门 = 流通性差 = 折价惨烈。

### 9. 客源结构

- **新客**：小红书（十几万粉官号）+ 抖音 + 大众点评 + 门店路边客；小红书 2023 起取消二手扶持后，路边店 > 居民楼店。
- **老客**：核心是"价格、成色、服务、售后"四要素。特色售后：**即买回收 + 每年清洁保养**，做成对标专柜的稳态服务。
- **销售理念**：先做朋友，再做销售。

### 10. 收包与真假问题

- **收包翻车率最高的两类**：朋友代购、对象送的（≈50% 是假）。
- **专业鉴定的三重误区**：① 找专柜验包（销售不具备鉴定资格 + 没有义务）；② 网上发帖问真假（评论区没有权威）；③ 店家自出的"鉴定报告"无司法效力。
- **正解**：找持证鉴定师或权威机构（中检、中鉴）送检；正规二奢商家愿意承担送检费用。

### 11. 消费降级 vs 二奢需求

- 结论：**没有消费降级，只是渠道转移**——专柜下滑，二奢流通性上升，因为奢侈品的核心是社交价值。
- 圈层观察：背 LV / Dior / Chanel 的人往往在同一圈子；背 Hermès 的自成圈层，无法融入。

### 12. 花钱模型（Monica 自述）

- **50%+** 继续投资生意（前提是生意还在赚钱）。
- **10-20%** 强制储蓄（避免"做这么久没赚到自己钱"的心理塌方）。
- **月消费 5-10 万** 上限；超过就停。参考"郭襄式"松弛但不放纵。
- **持续自投**：健身私教 / 皮肤管理 + 英语课 + 心理学课 + 每天 1-2 小时"新鲜知识"输入。
- **穷时投资样本**：月薪 7-8K 时依然每月 2K 上华尔街英语——**"你学不一定有反馈，但你不学一定没反馈。"**

### 13. 入局二奢的建议

- **想进来打工**：行业缺人，小白也接受。销售 / 主播 / 中控 / 库管都可入门；一线销售 / 主播 1 万底薪 + GMV 提成，月收 2-5 万常见。
- **想进来创业**：先在行业里打 6-12 个月工，摸清老板真实赚钱情况；启动资金**最少 100-200 万**，1000 万级更有竞争力；做好亏钱心理准备。
- **看店靠谱度**：① 开店时长（>1 年更稳）；② 门店体量（>百平不易跑路）；③ 敢让你送检再付款的商家更靠谱。

### 14. 心态转变（创业 5 年）

- 情绪从坐过山车 → 宠辱不惊，"能解决的问题就不是问题，不能解决的就别管"。
- **失败观**：没有失败，只有认知不够；对付法是持续学习提升认知。
- **对年轻人**：人生只有 3 万天，人生容错率远高于想象；害怕的不是丢工作，而是别人怎么看你——**别人只是把你当茶余饭后的话题**。

## 关键问答

### Q1：为什么放弃大公司深圳马斯菲尔？

看了带自己的领导——干十年买不起深圳的房。天花板可预见即等于不值得再花两三年。

### Q2：4 份 offer 里为什么选二奢？

咖啡师工资太低（4-5K）；专柜天花板止于店长；Vintage 服装当时看到有店主 3-5 年做出成果；二奢是当时的蓝海 + 老板亲测暴利，天花板高。

### Q3：50-100 万启动资金是怎么算的？

对标上海小型二奢店的囤货量 100-200 万，两人合伙各出 50%。核心不是"我有多少"，是"我亏得起多少"。

### Q4：面对老洋房被叫停 / 店长离职这种"灭顶之灾"，怎么想？

**"能解决就解决，不能解决就随它去。"** 关键是不抱怨——抱怨对创业者是零收益。

### Q5：现在还能不能入局二奢？

打工可以（行业缺人）；创业门槛已高（存量期利润 10%，起步 100-200 万只是水花），进来必须先打工摸行情。

### Q6：给害怕犯错的年轻人一句话？

**你根本没什么可失去的。**"落后一步"是错觉；休息几个月甚至一年不会改变你的人生走向。别人不在乎你，你只是他茶余饭后的话题。

## 可复用方法

### A. "3-5 年天花板双维度"选行 / 选公司法

1. 想象自己在这个行业干满 3-5 年后，行业本身能长到多大（**行业天花板**）。
2. 想象在这个行业里"你能爬到的最高职级"（**个人天花板**）。
3. 两个天花板同时打得够高才值得进——比工资高低更重要。

### B. 亏得起测试（Loss-First Test）

- 上桌前先问自己"最多能亏多少钱？"→ 计算真实可承受额度（不是全副身家）。
- 只投入这个额度以内的钱，其余不动。
- Monica 的估算："我的第一家店最多亏 20-30 万，在承受范围内，问题不大。"

### C. 小店入行学习法

- 入门优先选**什么都要你做**的小店，快速覆盖 5-10 种岗位。
- 6-12 个月足以摸清行业赚钱真相 + 老板运营真实情况。
- 用打工的成本换创业的信息差。

### D. 二奢消费者防坑清单（可发给朋友）

1. 认牌：香奈儿 / 爱马仕 / LV / 珠宝头部品牌保值性最高。
2. 认款：只买该品牌爆款（CF、2.55、沙滩包、手柄款）；冷门款折价惨烈。
3. 认价：低于行情价的一律警惕（业内铁律）。
4. 认店：门店 >1 年 + 体量 >百平 + 敢送检再付款。
5. 认证：只信持证鉴定师 / 权威机构（中检 / 中鉴）出证。
6. 忌信：朋友代购 / 对象送的 / 网上问真假 / 专柜验货 / 店家自出报告。

### E. 花钱三档模型（Monica 版）

- **50% 生意再投资**（前提：生意仍在赚钱，否则清零）。
- **10-20% 强制储蓄**（不做储蓄的创业者容易产生"辛苦白干"心理塌方）。
- **月消费上限 5-10 万**：超出即停；月内没花完的可以顺延允许下月多花。
- **持续自投**：健康（健身 / 皮肤管理）+ 认知（英语课 / 心理学课 / 每天 1-2h 输入）+ 人脉（高段位饭局）。

### F. 学习性投资的最小可行版本

- 收入低时不是不学，而是找**匹配预算的输入源**——B 站免费课 / 播客 / 图书馆 / 二手书。
- 判定：**学不一定有反馈，不学一定没反馈**。
- Monica 月薪 7-8K 时坚持每月 2K 上华尔街英语——"最穷时段的自投是最贵资产"。
