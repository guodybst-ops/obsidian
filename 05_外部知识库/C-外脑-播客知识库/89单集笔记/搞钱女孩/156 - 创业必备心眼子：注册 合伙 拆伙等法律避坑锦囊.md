## 核心要点

### 一、创业前置：离职拿失业补助金冷知识

前一家公司正常交社保情况下，离职时**必须让公司开一份"解除劳动关系证明"**，凭这个可以去社保部门申请**最长 2 年的失业保证金**。很多创业者不知道，白白错过。

### 二、公司类型 5 选 1，个体工商户最被低估

| 类型 | 组织架构 | 免税 | 推荐场景 |
|---|---|---|---|
| 个体工商户 | 无 | 季度 <30 万免税 | 单人 studio/主理人/自媒体 |
| 个人独资 | 无 | 有 | 单人合规化经营 |
| 有限合伙 | 简 | - | 多人无外部资方 |
| 有限责任公司 | 复杂（章程/股东会/监事） | 一般纳税人 | 5 年规划清晰、要引资方 |
| 股份有限公司 | 极复杂 | - | 拟上市规模 |

**个体户被低估**：能开票、能免税、注册注销简单、不用章程股东会，本质就是给主理人的 studio。**唯一劣势**：没有股东纠纷时的公司法兜底，一旦合伙必翻车。

### 三、有限责任公司三大隐藏地雷

**① 注册资本实缴的三步动作**（很多老板以为缴完了其实没有）
1. 股东用**自己名下银行卡**向公司开户行打款
2. 打款时**注明"注册资本"**
3. 会计**在名册登记为注册资本**，并**交印花税**

三步齐全才叫实缴。否则你股权转 3 手、公司注销 8 年，债权人依然可以**纵向穿透追责**要求所有历史股东连带赔偿。

**② 认缴制新规：最长 3 年必须实缴**
之前认缴允许"我 50 年后再交"，出现虚构注册资本引起市场混乱。国家规定认缴金额最长 3 年内必须实缴——注册资本**宁小勿大**，后续可增资，减资的法务税务成本极高。

**③ 一人公司/个体户的财产混同风险**
必须证明**公司财产完全独立于个人生活**——没用公司钱买私车、买生活用品。财产一混同，"有限责任"变"无限连带"。

### 四、合伙的黄金原则：想清楚怎么分家再结婚

**判断人是否适合合伙的唯一试金石**：**把最狠的话摆在他面前**——"公司亏损你退出，能不能净身出户？"能接受可以合，不能接受继续做朋友。

**冷知识：股份 / 分红权 / 表决权三权分离**
- 股份按出资算
- 分红权可以另行约定（10% 股份可以拿 30% 分红）
- 表决权可以集中到 1 人（众筹小店常见 80% 表决权归 1 人）

**结构底线**：出钱不干活/干活不出钱，不要平权（两人 5:5、三人 33:33:33 全是雷）

### 五、退出机制：5 年股份成熟期是好设计

- **亏钱状态退出**：走人还要按比例把亏损部分补给公司，不是公司还钱
- **赚钱状态退出**：股份卖给现有股东，避免抽干现金流
- **5 年股份成熟期**（餐饮朋友做法）：每年成熟 20%，第一年就走只能拿 20%
- **分期兑付**：约定第一年不给、后续 3-5 年分期，或 50%-30%-20% 递减

### 六、财务透明化 4 件套（新公司法 2024 修订加强）

1. **中立第三方做账** 或 **内部财务 + 小股东知情权**
2. 章程/合伙协议直接约定**每月固定查账日期**
3. **新公司法**：小股东不仅能查财务账簿，还能查**财务凭证**（票据原始单据）
4. **违约罚则写股东协议**（章程内没法写）：每逾期一日**罚款 5000 元**给到大股东个人

### 七、如何辨别真律师 vs 法务公司

- 律师身份受法律严惩：**冒充律师轻罚重拘留，甚至涉诈骗**
- **警惕信号**：短视频对接后微信群里齐刷刷正装头像 logo、都叫"XX 老师"没人自称律师——多半是**法务公司/法律咨询公司≠律师事务所**
- **辨识动作**：要求看**律师证**、到**律师事务所**签约、看合同章是不是"XX 律师事务所"
- 民间碰瓷案例："律帅事务所"（康帅傅式命名）

### 八、乙方合同 3 大重点条款

**免责声明 / 甲方违约 / 乙方违约** 是乙方必看三段。

- **违约金往高写没关系**——法院有上限救济条款，写高不违法且高就是筹码
- **修改次数≤3 次**，超过退部分款并**收回成果使用权**
- **知识产权归属**：产品归甲方，但乙方保留**案例展示权**（可参赛、可放进 portfolio）
- **付款方式不分期**（变动多产生在甲方——公司没了、老板换了、项目黄了）

### 九、初创弱势方的谈判 3 个心法

1. **利他心理**：告诉对方选择你能带来什么、时间成本 vs 收益、软硬兼施
2. **多跑几次**：一诚感动人，上位者天然愿意帮真诚的落势方
3. **勇敢说 no**：不合理条款该拒就拒，同时给替代方案（不包过就退部分）

### 十、危机变商机：真诚兜底 3 步

冉小冉团队某周年庆项目 5 位策划轮番做客户不满意，最后老板亲自下场：
1. **道歉 + 承担**："这一单我亲自做"
2. **兜底赔付承诺**：不满意全额退款 + 额外赔偿
3. **给最后一个 offer**：不放心可以换乙方，**下家费用我出一半**

结果：项目做成、客户成挚友、后续源源不断介绍生意。

### 十一、隐形合伙人不签合同一样成立

法院起诉案由是"**合伙合同纠纷**"——书面/口头/事实全都算。微信聊天、日常财务分账、业务归属都能作为证据。

### 十二、一通电话省 300 万：接盘侠陷阱

冉小冉差点用几十万入股一位甲方主理人的门店。王艳律师提醒："**你们的第一职业是收费的乙方——凭什么把服务费转成给对方投资？**"——技术/资源入股需要评估作价，"我说值 500 万就值 500 万"不成立。原有股东找乙方接盘 = **低价接盘还倒贴钱**。

## 关键问答

**Q1：注册什么类型的公司最经济？**
A：单人/初创/未定型强烈推荐**个体工商户**——季度 <30 万免税、无章程股东会、注销简单。5 年梦想清晰或需引资再升级有限责任公司。

**Q2：有限责任公司注册资本填多少？**
A：**宁小勿大**。新规最长 3 年必须实缴，减资极复杂，增资简单。先小额启动，业务扩大再增资。

**Q3：怎么判断合伙人？**
A：**把最狠的话说前头**——"亏损你退净身出户，能不能接受？"能接受可合，不能接受继续做朋友。

**Q4：合伙人分股权怎么设计？**
A：股份按出资、分红权可另议、表决权可集中。**出钱不干活、干活不出钱、不要平权。**

**Q5：退出怎么谈才不撕破脸？**
A：**5 年股份成熟期** + **分期兑付** + **区分亏损 vs 盈利状态退出**。

**Q6：怎么辨别真律师？**
A：看律师证、去律师事务所签约、认准"XX 律师事务所"公章。任何"包银包过"承诺都值得怀疑。

**Q7：乙方合同违约金写多少？**
A：往高写。法院上限救济条款兜底，写高不违法，**上限就是你的筹码**。

## 可复用方法

### 方法一：合伙前 4 问筛选清单
1. 亏损退出你能不能净身出户？
2. 出钱和干活谁多谁少怎么定？
3. 三权（股份/分红/表决）分离你接不接受？
4. 每月几号查账 + 迟一天罚多少你签不签？

### 方法二：注册资本实缴 3 步动作
个人卡向公司开户行打款 → 注明"注册资本" → 会计名册登记 + 印花税

### 方法三：股份成熟期设计
5 年成熟、每年 20%、亏损退按比例赔、盈利退分 3 年支付

### 方法四：财务透明化 4 件套
中立第三方做账 + 章程约定查账日期 + 财务凭证查阅权 + 股东协议违约罚款

### 方法五：乙方合同 5 项自检
免责声明 / 甲方违约 / 乙方违约 / 修改上限 3 次 / 案例展示权保留
