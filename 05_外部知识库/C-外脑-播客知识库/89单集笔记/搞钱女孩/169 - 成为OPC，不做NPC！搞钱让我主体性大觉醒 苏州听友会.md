# 169 - 成为OPC，不做NPC！搞钱让我主体性大觉醒 苏州听友会

## 一句话摘要

四位苏州嘉宾（15 年 1500 月薪起步做到年入千万的阿奇、38 岁小红书 5 个月 10 万粉的徐若木、副业做 3D 打印哪吒 IP 授权的露露、元起创想 OPC 社区代表 Sherry）围绕"从 NPC 到 OPC"的主体性觉醒讲各自的搞钱路径与心态转变——搞钱最重要的不是钱，是把自己从工具人（NPC）活成有名字的主角（OPC）。

## 金句一字不改

> "搞钱最重要的不是搞钱，是搞的这种主体性——从 NPC 变成有名字的主角，从工具人变成 OPC。"

> "我 15 年月薪 1500 起步，用 5 年一节奏——第一个 5 年做到 10 万，第二个 5 年到 100 万，第三个 5 年到 1000 万。"

> "副业不是拉一个新赛道，副业是把你主业里被忽略掉的能力单独拎出来卖。"

> "38 岁未婚未育、江南大学设计研究生、百度 5 年离职——这三条在传统叙事里都是减分项，在小红书里全是加分项。"

> "一个人 20 多种变现方式，但突破不了年入百万——问题不是方式不够多，是没长成 OPC。"

> "3D 打印做同行护城河，不是靠打得多，是靠打得准——高精度是别人抄不走的门槛。"

> "NPC 是等剧本，OPC 是写剧本；打工是等奖金，搞钱是自己给自己发。"

## 要点

### 阿奇（阿七/林强七）· 15 年 1500 月薪到年入千万的三段五年论

- **0-10 万积累期（15-20 年）**：转化妆品闲置副业起步，把大学同学的美妆囤货二手卖出去，练手供应链和成交话术
- **10 万-100 万进攻期（20-23 年）**：跳槽苏宁做运营总监拿到主业底薪；副业做 TFboys 粉丝会活动运营，2 万下载量验证私域组织力
- **100 万-1000 万构建系统期（23-25 年）**：港股打新每月稳拿手续费差 + 可转债低风险套利 + 半导体重仓 3 倍收益 + 自建"阿奇和他的小富婆们"付费社群做认知复利
- **打法本质**：主业撑现金流 + 副业练技能 + 投资吃时代红利 + 社群做认知复利，四条腿走路互相不塌

### 徐若木 · 38 岁小红书 5 个月 10 万粉的减分项转加分项

- **传统叙事的减分项**：38 岁未婚未育、江南大学设计研究生、百度 5 年离职
- **小红书里的加分项**：真实、非标、有故事、有反差、有勇气自曝——正是内容平台缺的
- **变现清单 20+ 种**：商单从 3000 到 3 万单价 + 私教陪跑 + 训练营 + 咨询 + 出书 + 讲座 + 培训 + 版权分成 + 品牌联名 + 电商带货 + 直播打赏 + 知识付费 + 广告分成 + 会员订阅 + 精选联盟 + 团购 + 分销 + 加盟 + 授权 + 内容合作
- **卡在年入百万的原因**：方式多而不深、身份仍是"接活的人"而非"输出品牌的人"——需要从"小写 opc"（多个副业执行者）升级到"大写 OPC"（有主体性的品牌人）

### 露露 · 苏州本地 3D 打印哪吒 IP 授权的护城河打法

- **前世**：电器工程师 + 大学期间做蓝田玉印章代理练供应链
- **今生**：24 年入 3D 打印赛道 → 黑悟空建模爆火 → 哪吒 IP 商业授权 → 高精度打印技术护城河
- **护城河来源**：不是打得多，是打得准——高精度设备门槛 + 建模能力 + IP 授权资源三合一，同行抄不走
- **本地化打法**：苏州小圈子 + 苏州线下活动做流量 + 精选定制客户，不追全网大而全

### Sherry / OPC 主题 · 从 NPC 到 OPC 的五步觉醒

1. **命名**：先给自己起一个"作品名"，不再叫工号
2. **确权**：把自己产出的每一份内容/服务打上"我的"标签，不再匿名交付
3. **定价**：自己给自己定价，不等公司/平台给
4. **筛人**：主动筛选客户/合作方，不再来者不拒
5. **写剧本**：从执行别人的方案，变成给自己写规划——真正意义上的 OPC

### 横切要点 · 听友会共识

- **搞钱不是钱本身**：4 位嘉宾共识——搞钱是练主体性、练能力、练心态、练系统的副产品，不是终点
- **五年是最小周期**：阿奇明确讲，两三年看不出复利，五年才能真的把一个方向做出复利结构
- **副业筛选原则**：从主业中拎能力，不要另起炉灶；从熟悉圈子起步，不要盲目破圈

## 关键问答

**Q1：15 年 1500 月薪起步的普通人，怎么熬过第一个 5 年？**
A（阿奇）：不要想着一步做到 100 万，先设 10 万目标。10 万可以通过副业闲置转卖 + 兼职攒下来，关键是逼自己有第二份现金流，哪怕每月多 500，也算走出打工者思维。

**Q2：38 岁做小红书是不是太晚？**
A（徐若木）：38 岁不是减分项，是差异化。20 岁做小红书要拼颜值/勤奋/流量玩法，38 岁做小红书拼故事密度和判断力——一条内容抵别人十条。

**Q3：一个人做 20 多种变现方式，为什么反而卡住？**
A（徐若木）：因为身份还是"多技能打工人"，不是"品牌人"。变现方式多不代表主体性强——把 20 种收敛到 3 种主打赛道 + 1 个人设 IP，才能突破年入百万天花板。

**Q4：3D 打印这种重设备副业普通人能做吗？**
A（露露）：不建议一上来重设备。先做建模服务（云端出图）验证市场需求，跑出稳定订单再上设备；先做小订单跑通全链路，再做 IP 授权谈判。

**Q5：NPC 和 OPC 最本质的差别在哪？**
A（Sherry）：NPC 等剧本、被指派、被定价、被筛选；OPC 写剧本、主动出击、自己定价、主动筛人。差别不在能力，在身份认知的切换。

**Q6：听友会现场对搞钱最反常识的一句话是什么？**
A（全场共识）：搞钱最重要的不是钱，是搞的这种主体性——钱只是主体性觉醒后自然滋生的副产品。

## 可复用方法

1. **五年一节奏财富阶梯法（阿奇）**：把长期目标拆成 5 年一节，每节聚焦一个能级——10 万级练现金流、100 万级练进攻力、1000 万级练系统力；不跨节跳，跨节必崩
2. **减分项转加分项内容法（徐若木）**：把传统叙事里的减分项（大龄/未婚未育/离职/学历）列出来，逐个改写为差异化叙事——不美化，做真实自曝
3. **20 种变现收敛为 3 主打赛道**：先做加法验证需求，再做减法聚焦——保留最高单价 + 最强复利 + 最合人设的 3 个方向，其他停掉
4. **护城河三合一（露露）**：单点做不出壁垒，找**设备/技术 + 能力/建模 + 资源/IP 授权**三合一的复合能力，同行抄不走
5. **OPC 五步觉醒法**：命名 → 确权 → 定价 → 筛人 → 写剧本，每一步都可以在主业里同步练
