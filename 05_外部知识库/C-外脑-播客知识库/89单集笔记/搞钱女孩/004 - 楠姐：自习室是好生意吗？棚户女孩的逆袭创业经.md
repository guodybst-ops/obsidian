# 004 - 楠姐：自习室是好生意吗？棚户女孩的逆袭创业经

## 摘要

《搞钱女孩》第 004 期请到了 90 后线下实体连锁创业者楠姐——王艳楠，一位拥有 5 套房、全国 76 家自习室的十八线小城逆袭女孩。她的搞钱线索大致是：从"石破烂"家庭 → 初中毕业进入职场 → 靠加班和不抱怨拿到活动策划公司股份 → 24 岁靠创业买房 → 疫情三年活动策划公司全军覆没 → 转行做书店踩坑亏 7 位数 → 从书店里那批考研学生身上洞察到"自习室"需求 → 一个月内开出第一家自习室 → 迅速复制到全国 76 家 → 同时把开店经验做成培训业务，教学员开店。

节目的另一半承担实操价值——楠姐把"自习室生意"的边界画得非常清楚：**不适合想暴富的人、不适合急功近利的人、不适合追求零风险的人**；**最欢迎高知分子入场**（有学识、有胆量、有经济基础）。她公开了自习室的四条营收线（座位费/仪式感 + 文具饮品 + 衍生业务如职业规划/留学/考研咨询 + 本地商家广告）、二线以下城市不含房租 3-6 万可以开一家店的成本区间、以及三种运营模型（有人值守 / 半无人 / 无人值守——一个客服可以远程管 5-10 家店）。

后半段是她的成长自述——**"苦难不值得被歌颂"**是她开场唯一的题眼。楠姐把自己的家庭底色摊开：城中村大通间、露天厨房、24 岁前一家人的房租靠她一份工资付；她坚持"结婚要在自己买的房子里结婚"、"父母的脸面是你给的"这两个动机，把野心具体成了买房、给父母做偶像。她给搞钱女孩的收尾金句是——**"路虽远，行则将至；事虽难，做则必成。"** 她的行动信条更直接：**"一个人最不能做的事情就是拧吧。既想要锦绣前程，又不想俯身干活，那你注定一事无成。"**

## 核心要点

### 1. 起点：从石破烂之家到用工资养一家四口的城中村

楠姐第一段自述就把"苦难不值得歌颂"这句话摆在前面，然后才展开：她家以前是拾破烂的、老家的厨房一半是露天大棚。父母从农村进城但没有一技之长、无法回去也没扎下根，24 岁之前她一家四口（爸、妈、她、妹妹）住在城中村大通间、上公共卫生间，房租由她一份工资支付。她初中毕业没再读书，靠自学、靠早出晚归的加班、靠不抱怨去把活干出来。这段家庭底色的意义是——她非常早就把"结婚要在自己买的房子里结婚 + 给父母买房让他们不用低人一等"具体成了动机，日后的每一次搞钱选择都是回到这个动机上做的。

### 2. 活动策划三年 → 疫情全军覆没

进入职场后她做的是活动策划执行——**"跟人打交道、拿到项目、组织人马做、然后无穷无尽地要账"**。她描述这门生意的痛点非常真实：甲方一句"最近资金紧张能不能缓一缓"就一直缓下去，她大部分时间在打官司要账；高峰期同时用过 500 多名员工，天天处理"某员工不干了 / 工伤 / 仲裁"这类狗血情节。三年疫情来了，"墙三座大山压死死的"——**这门业务不是断崖式下跌，是全军覆没**，直接把她逼到必须转型的悬崖。这段经历给她三条内化的原则：**不做需要垫资 + 要账 + 走后门的生意；不做需要雇很多员工的生意；不做完全靠人际关系的生意。**

### 3. 书店踩坑：亏 7 位数的"福利款 + 利润款"错觉

她转型的第一个尝试是书店。她的逻辑很漂亮——**"一楼卖潮品做利润，二楼开书店做引流；电影院客群和书店客群天衣无缝。"**她那时以为下个月自己就要冲上福布斯排行榜、马上要搞连锁和加盟。但她忽略了一件事——**电影院是防疫管控项目之一，不让开门就断电**。9 个月里她的书店没有空调、没有电梯、影城黑洞洞的，她在里面身心俱疲。这 9 个月零收入直接击穿了她的自信，让她第一次"对命运感到惶恐"。这次踩坑给她的核心教训是——**"创业不能创自己喜欢的事情，创的是需求"**；**书店类"福利款"不是不能做，是你要知道自己在做需求外的浪漫**。

### 4. 灵感转折：书店里那批 7 点钟排队的考研学生

书店快撑不下去时，她注意到一个反常识现象——**每天早上 7-8 点她店门口开始排队等她开门**，她一个创业者被这些学生逼成了上班族。她凑上去聊：小孩说姐，我不是图你环境好，是我在家学不进去。她再往下问就发现——**这些学生互相都认识、他们要的是"氛围 + 与人同行"**。她妹妹（同龄人）提醒她："咱们小时候看《请回答1988》里德善姐姐就在自习室学习。"她当天上网查国内自习室情况——发现三四线城市完全没有这个业态、只有一线和郑州西安等省会已经出现。她第二天直接买高铁票去郑州、西安，**每一家自习室都拿小本本记满一整半本**：为什么选这个位置、这个楼、这个户型、这个布局、这套设备、这个成本结构、这个客单价、这个投资回报率、这些关键节点是什么。

### 5. 第一家自习室：3 天煎熬 + 一个月开出 + 立刻提价

回到本地后她做了完整的市场调研和数据分析，估算第一家店 7-8 万（含全年房租）能撑得起来。她给自己 3 天时间做决断，问自己"王艳楠这些钱全亏完你能接受吗？"最终决定——**当作少买一辆车**。**不到一个月就把第一家店开起来**，紧接着做了一个关键动作——**提价**：之前书店会员费 365 元/年，新店直接提到 3600-4800 元/月。她把老会员一个一个沟通、把差价换算成新会员卡时间转过来，用这 20 多个种子会员启动了新业务；之后靠营销手段把店做上正轨。这套完整闭环——**观察痛点 → 城际调研 → 数据建模 → 心理测算最大亏损 → 快速开出 → 老客转化 + 营销扩张**——就是她之后被复制 76 次的模板。

### 6. 自习室的四条营收结构

楠姐把自习室的收入拆得非常清楚：

- **① 座位费（占大头）**：本质上卖的不是座位而是"学习的仪式感"，卖的是"锦绣前程"、"良好氛围与高质量圈子"。
- **② 自动售卖**：文具、饮品等。
- **③ 衍生业务**：职业规划、留学咨询、考研咨询、资料售卖、副业创业圈子——**做用户的二次转化**。
- **④ 本地商家广告**：奶茶店 / 咖啡店 / 西餐店的店内广告位。

三条主营 + 一条附加。这套结构的关键洞察是——**"卖学习的仪式感"这一句直接把这门生意的心智重新定义了**，让"日租多少一个座"的低利润产品，升级成"愿意花几千一个月买锦绣前程"的高利润产品。

### 7. 三种运营模型：从有人值守到 5-10 家店 1 个远程客服

**① 有人值守**：书店 + 情旅 / 便利店 + 情旅 / 咖啡店 + 情旅——需要现场人力。
**② 半无人**：小程序下单 + 加微信 + 值守人员偶尔到店。
**③ 无人值守**：小程序全程管控——按门开门、按座亮灯、结算走人。

她自己的连锁体系以半无人 + 无人值守为主——**一个客服可以远程管 5-10 家店，人效非常高**——这让她可以在异地开店、不用被人力拖住。这也是她做完活动策划后有意识做的选择——**"我特别不喜欢跟员工打交道，宁可少赚也要赚到自己兜里。"**

### 8. 谁适合开自习室：五种劝退 + 一种最欢迎

**不适合的人**：
- 想暴富的人（今晚开店、明天就要 10-20-30 万营业额）
- 急功近利、拒绝做市场调研的人（"我不管、我直觉告诉我这个地方能开"）
- 开完店不做引流、不做宣传就等半月回本的人
- 觉得"什么都晚了"、没法踏踏实实做事的人
- 追求零风险的人（这种人建议直接去上班——上班也是很好的选择）

**最欢迎的人**：**高知分子**——有学识、有胆量、有能力、有一定经济基础。楠姐给的理由是——**"他们心态很稳定、有素养，跟客户也有共鸣和沟通点。"** 也非常适合有主业、想要副业收入的人。她给这门生意的总结定义是——**"确定性"是它的代名词**：赚钱有数、赔钱有数，一切都在你的控制之内。

### 9. 会算账 = 实体创业第一课

楠姐把自习室培训课上第一课明确定为——**"会算账"**。算什么？算投资回报率——**开店前你今年最多能赚多少、最多能赔多少，都要清清楚楚**。她把这条经验推广到所有实体创业：以前朋友问"咱们一起开个奶茶店 / 饭店行不行"她会答"行 / 不行"，现在她一律回"我们先算账——投资多少、盈利多少、投资回报率是多少、中间现金流能维持多久、用钱成本是多少"。 **不能算账 = 没资格开店。**

### 10. 实体创业的四个避坑法则

除"会算账"外，楠姐给了完整的四个避坑金句：

- **① 会算账**：投资回报率、现金流、用钱成本、最大亏损承受度。
- **② 以需求为导向，不以创始人爱好为导向**：创业创的不是情怀，是"在什么情况下用什么办法解决什么人的什么需求"。
- **③ 不做需要很多员工的生意**：不喜欢协调、仲裁、工伤、心情不好突然辞职这类狗血；宁可少赚也要人少。
- **④ 克制：不能既要又要**：既想赚钱又想钱多事少离家近、既想躺赚又不肯前期调研——**"什么都想要的结果，就是什么都没有。"**

她加了两条延伸——**保存好现金流、有多少能力做多少事；不要相信任何"无上限"的生意**（因为无上限的生意都是千军万马过独木桥，普通人挤不上去）。

### 11. 野心配得上才华：分清"才华咖"还是"商务咖"

楠姐的搞钱底层逻辑是——**"有野心是对的，怕的是野心配不上才华"**。她把配得上野心的方法拆成两个赛道：

- **才华咖**：如果你的野心是靠专业能力，就玩命修炼技能。
- **商务咖**：如果你的野心是靠人际关系，就练情商 + 沟通能力 + 靠近能量高的人。

她非常直接地说——**"如果你不会没关系，靠近那些会的人、用尽一切办法成为那些人的忠实粉丝，让他们带你"** ——这是普通人可行的第二条路。她之所以要写下这条，是因为她自己在职场就是靠"会加班、不下班"但不会搞人际关系，24 岁还没买房——**光有野心不修炼配套技能，野心就自己撞墙**。

### 12. 贵人有两种：帮你的人 + 让你痛苦的人

楠姐把她这一路的贵人分成两类。**帮你的贵人**是显而易见的——提升认知、提升技能、给机会。**让你痛苦的贵人**是她着重讲的——她在活动公司上班时，因为跟财务经理（也是股东）不合被打压、因为老板女朋友不喜欢她被打压——这些打压让她意识到"上班无法实现她的梦想"，才逼出了创业的契机。**她的解释是——"没那么松弛感的女生不会招人喜欢，大家只会喜欢强者不会喜欢弱者。"** 让她痛苦的人是把她挤出舒适区的人，同样是贵人。第三种贵人是"生财有术"社群——把她从十八线小生意人的圈层拉到全国、并认识了她现在的合伙人杨涛哥。

### 13. 用能力做父母的偶像：搞钱女孩最动人的落点

节目最动人的一段是楠姐讲她现在的骄傲——**"我终于可以凭借自己的能力成为我父母、我妹妹、我爷爷奶奶的偶像。"** 她举了几个具体场景：爷爷生病，她能直接给爸爸转钱说"没关系，继续治"；爷爷出院直接住到她的复式楼里；妈妈现在朋友圈里"美容、逛街、遛狗、跟着女儿旅游"、每天靠她用互联网思维导流做的小事业赚 1000 块，爸爸每天赚五六百块；妹妹的大学同学对妹妹说"你就不用愁工作了，你家有家族企业等着你继承"。她给这段的收束句是——**"钱是人的胆，子是父的威。父母老了之后的脸面都是我们给的。"**

### 14. 未来目标：今年保底 1000 家，冲刺 10000 家

楠姐给自己的短期目标非常具象——**今年保底 1000 家自习室，冲刺 10000 家，成为中国自习室行业的头部品牌**。她的方法论也很清晰——**专心专注**：虽然圈层变好之后各种项目找上门，但她依然只做自习室和自助空间领域。她的收尾寄语是——**"你一定要敢想，具象到买什么车、住哪里、想跟谁成为朋友；你要能承受争议；你要愿意为完成梦想付出时间和精力。金子不发光就是缺让自己发光的技能，贵人不提醒你就是你缺让贵人信任的技能，没发现好项目就是你没修炼出发现好项目的眼光——这些都是可以修炼的。"**

## 关键问答

**Q1｜自习室能不能赚大钱？**
A：**不能**。楠姐一开始就把这门生意定为"确定性生意"——赚钱有数、赔钱有数。她直接劝退三类人：想暴富的、急功近利的、追求零风险的。这门生意最欢迎"有学识+胆量+经济基础"的高知分子，也非常适合"主业稳定，想有副业"的人。她把生意的天花板算得清清楚楚——**"普通人赚普通钱就可以了，不要嫌苍蝇腿上的肉。"**

**Q2｜开一家店要多少钱？**
A：**二线以下城市不含房租 3-6 万可以开一家**。房租根据当地和面积单算。楠姐团队因为规模大，能拿到桌椅、预约小程序等全网最低渠道价，学员开店成本可以再压。她建议开店前必修的第一课——**"会算账"**：算最大亏损你能不能接受，能才开。

**Q3｜自习室怎么赚钱？**
A：**四条营收**——① 座位费（卖的是"仪式感"和"锦绣前程"，不是座位）；② 自动售卖（文具饮品）；③ 衍生业务（职业规划 / 留学 / 考研咨询 / 资料 / 副业圈子）；④ 本地商家广告位。

**Q4｜你是怎么从十八线走出来的？**
A：**因为读书**。楠姐说她的家庭底色让所有同龄女性都默认"结婚生子、留守儿童、南方电子厂打工"是理所当然的人生路径。但她"读了书、书本告诉我世界有多大"，就再也不愿意过那种生活。她的动机具体化到——**"结婚要在自己买的房子里"、"我要养父母、让妈妈对娘家好没有心理压力"**。有了具体动机，剩下的就是修炼配得上野心的技能。

**Q5｜实体创业最重要的一课是什么？**
A：**克制**。**"我们既想赚钱，又想钱多事少、离家近；既想不费事，又不想花精力；既想后期躺赚，又不想前期调研——什么都想要的结果，就是什么都没有。"** 加上"会算账 + 以需求为导向 + 少雇员工 + 保住现金流"——五条一起构成她的实体创业铁律。
