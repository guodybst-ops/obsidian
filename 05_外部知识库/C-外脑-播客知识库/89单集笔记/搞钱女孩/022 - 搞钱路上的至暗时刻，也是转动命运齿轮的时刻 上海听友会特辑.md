# 022 - 姐妹，搞钱路上的至暗时刻，也是转动命运齿轮的时刻 上海听友会特辑

## 摘要

《搞钱女孩》022 集是节目**首场上海听友会**的现场记录，也是台史上最长的一期。开场由主播小灰复盘节目从 0 到 1 的全过程——一个男生为什么做"搞钱女孩"、如何从月更佛系博客切换到周更、五个月做到全网 110 万播放、订阅破万；主播雪怡则把 20 期采访抽象成"搞钱女孩三大特质"——**爱折腾、执行力、不内耗**。

中后段是两轮圆桌：**"命运齿轮开始转动"** 和 **"搞钱路上的至暗时刻"**，邀请嘉印（广告人 + 副业玩家）、王雅楠（Euroraka 联合创始人、前女性程序员社区创业失败）、谢无迪（闪亮猫传媒创始人）、王菲嘿（大厂离职 → 出海 + 小红书）四位嘉宾轮流拆自己的转折点与低谷。中间穿插多位听友即兴分享，涉及"离职考量、玄学之于决策、副业选择、销售转化"等大量真实场景。

这一集的独特价值在于它是一档**样本密度极高、题材极散、情绪极真实的合集**——正职 + 副业双轨、女性合伙人拆伙、公益人转商业、大厂离职后送外卖起号、玄学与身体作为决策工具、大学生做小红书接广告的具体操作，每一段都能独立提炼成短集。适合已经听完节目前 20 期、想看一场"横切多样本"的听友，也适合被"我该不该辞职、我副业能不能做起来、我为什么被质疑"卡住的搞钱女孩。**关键 takeaways**：**没有轰烈的至暗时刻，只有一段等待和一群解决问题的人**；**遇到问题就解决问题，情绪停留期越短，命运齿轮转得越快**。

## 金句收藏

> 女的搞钱就行了。

> 不要始于谈钱，钱和爱是人类的两大共识，爱不好量化，但是钱可以。

> 赚钱的本质就是你帮助别人之后获得善意的回报。

> 当你持续地给这个世界创造价值的时候，其实很难搞不到钱。

> 用爱影响人，用影响力爱人。

> 没有不行的项目，不行的是人。

> 每一个行动其实都是一个所谓的命运齿轮在转动的一个时刻。

> 活下来还是比较大的道德。

> 当你觉得你的产品很好，但是市场没有给你任何的正向反馈的时候，你不要执着，市场是非常非常诚实的。

> 山顶的人不要去嘲笑山下的人，山下的人也不要去嘲笑山顶的人。

> 想做一件事情的时候，不用太在意这个事情当下能给你带来什么样的结果，也不用太在意它是不是跟你的人设、跟你未来长期规划有什么强关联。

> 遇到问题解决问题，不抱怨。

## 核心要点

### 1. "搞钱女孩"是怎么来的：一个男生 + 一个胡开的主播

节目发起人小辉是**福建家庭里"必须再生一个男孩传宗接代"**才出生的男生，从小和两个姐姐、妈妈一起长大，家里典型"爸爸去哪儿了"结构。这段成长经历让他天然关注女性议题。

他自己有一档播客《主动交代》做了两年多，一直卡在两三百播放，为了破局起了"搞钱女孩"这个系列名——**"搞钱 + 女孩"本身就是流量密码**。第一期是 22 年 5 月找雪怡聊"怎么靠卖信息差赚到人生第一个 100 万"，直接把数据打到 1700 播放，打破他一直以来的播放黑洞。

**推论**：起一个系列 / 项目名的时候，**先做社交媒体搜索验证"这个词有没有讨论热度"**，是最低成本的洞察。

### 2. 从月更到周更：中间那次差点散伙的一个半月

首期爆了之后，团队开了个线上会，小辉本来只想月更（他有正职），**雪怡当场把节奏拉到周更**——她扔出一个目标"采访 100 个搞钱女孩"，如果月更算下来要好多年，只有周更两年多才能到。

**关键节点**：第一期和第二期之间隔了一个半月，就是三个人达成共识的过程——**要不要接受周更挑战 / 敢不敢连做 10 期 / 敢不敢更新下去**。小辉最后跟自己 say yes——"我可以试一下"，才有了后来的故事。

**推论**：项目起步阶段最大的分水岭不是"要不要做"，而是**"敢不敢定一个让你不舒服的节奏"**。舒适节奏保住的是心情，痛苦节奏保住的是可能性。

### 3. 节目从 0 到 15000 订阅的三步经验

小灰把节目做起来的三条自结经验拎给全场：

1. **准确的洞察**：搞钱 + 女孩双重流量密码，起名前做过社交媒体功课
2. **目标感和信念感**：4 月那次一个半月的停更纠结，本质是"敢不敢接下 100 期目标"，最后自我说 yes
3. **持续的行动**：不停改细节——优化片头、剪辑 SOP、更新节奏、保周更，慢慢形成风格

**推论**：这三条**是任何一个项目从 0 起步都可以套的模型**。项目死不了并不难，难的是"节奏能不能扛住 + 迭代能不能持续"。

### 4. 搞钱女孩三大特质：爱折腾 / 执行力 / 不内耗

主播雪怡在做完 20 期后抽出**"什么样的女孩才是搞钱女孩"** 的三大特质，也是这档节目的选题标准：

- **爱折腾**：现在的结果绝不是一蹴而就的。侃侃成为摘星阁 CEO 前是摄影师、上学时租手机给同学；让爱琴成为奇葩说社员前发起过"出租女友"和"陌生人接吻挑战"
- **执行力**：想到就做、马上做。楠姐前公司破产后听说自习室这门生意，立刻跑郑州考察、小本本记细节，最低成本开第一家，现在做到全国 80 家
- **不内耗**：无敌那句**"该出手时就出手"** 治好了主播雪怡的精神内耗——决定的后果没那么严重，别人怎么看不重要

**推论**：这三条也可以直接当自检——**如果一件事你三个月还没开始行动，八成不是"没想清楚"，而是这三条特质里缺了一条**。

### 5. 搞钱的"搞"字才是重点：探索 + 诚实 + 帮人

雪怡把"搞钱"拆字讲：**"搞"是折腾、是行动、是路上的探索**。搞钱本质是三层：

- **诚实面对自己的真实需求**（不要金钱羞耻）——来自香帅老师"不要耻于谈钱，钱是可量化的目标"
- **赚钱的本质是帮助别人之后获得善意的回报**——来自闪亮猫谢无迪
- **当你持续给世界创造价值的时候，其实很难搞不到钱**——来自数字游民 Jamie

**推论**：不要陷入"我要做哪个项目"的选择焦虑；先回到"我在给谁提供了什么价值 / 我提供的价值是不是可持续放大的"。项目是价值的载体，不是价值本身。

### 6. 命运齿轮第一种打开方式：高中夕阳下的一次自我发奋

嘉宾嘉印分享的第一个齿轮时刻是**高一寒假某天在阳台上看着夕阳哭了一场**——中二年代式的自我觉醒。从那天起从年级中下爬到全班第一，考上"家里那边算不错"的 211。

第二个齿轮是大三——她对广州学校不满意，想去上海做广告，**主动托人联系一位不认识的学长，打电话把自己"推销"过去**才拿到上海的实习。

**推论**：命运齿轮不一定是被时代推动的大事件，很多时候就是**"某天你决定不再默认现状"**的一个小瞬间——夕阳下的哭、一通打给陌生学长的电话。

### 7. 命运齿轮第二种打开方式：公益人对商业开窍

嘉宾王雅楠（Euroraka 联合创始人）**30 岁前是公益人**——做非盘产品创业时，坚持用最环保的再生塑料、请空气动力学老师、请专家做认证。**结果她做 100 分的产品，市场对她的回报还不如别人做 60 分的产品**。

**关键顿悟**：以前她觉得"回扣 = 肮脏"，创业后她开始理解**"商业不是非黑即白，中间有灰色地带，活下来是较大的道德"**。她仍然不认同这些行为，但对商业的认知从"非黑即白"变得"更有弹性"。

**推论**：**公益人 / 理想主义者创业最大的坎不是执行力，是对"灰色地带"的接受度**。不接受，市场会用真金白银教训你；接受，才能活下来。

### 8. 命运齿轮第三种打开方式：三次转折的组织进化

嘉宾谢无迪（闪亮猫传媒创始人）的齿轮转了三次：

1. **21 年 3 月做小红书**：家里几家红星美凯龙实体店客流跌到月不足 200 人，她考察抖音 / 小红书 / 一豆糖后选小红书；做了一年做出成绩，直接辞掉月薪 2 万+ 的正职创业
2. **去年 4-5 月合伙人拆分**：主外的她 vs 主内的合伙人，付费用户已到 1000+，合伙人因为"你在抛头露面而我没有机会"提出退出。她重构团队，引入闪亮猫合伙人制度，一次性引入了周周（周一直播）和喵喵（周五直播）两位新对外合伙人
3. **今年 3 月引入组织外脑 + 团队搬迁**：花 8 万请了生财里做组织管理的刘明培老师，把架构 / 薪酬体系 / 业务扩张全捋一遍，随后把线上团队全部聚集到线下、7 月把团队搬到杭州

**核心避坑经验**："想创业先做小人再做君子——先把该谈的协议、股权、分工全部谈好，再开始起步。"这是她**吃过亏之后总结的第一号忠告**。

### 9. 命运齿轮第四种打开方式：疫情送外卖撬开的自媒体线

嘉宾王菲嘿的齿轮转动是从**上海封控前夕她去送外卖**这个"看似很傻"的动作开始的：
- 她大学时就想过送外卖，正好有电瓶车，就想去看看不一样的上海
- 封控开始后她成为**为数不多可以出入自己小区**的人，随手拍视频发小红书，几条视频爆了
- 陆续接到私信求帮送药 / 水果 / 猫粮，两次上电视机会 + 若干采访
- 她开始写公众号，正向反馈很多，**从此确认自己喜欢做自媒体**
- 后来换工作 → 做副业 → 从副业出发去创业 → 现在起了 20 万粉的 TikTok 账号

**关键心法**：**"想做一件事情的时候，不用太在意它当下能给你带来什么结果，也不用太在意它跟你的人设、跟你未来长期规划有什么强关联。你就是去做就好了。"**

**推论**：**很多重要的机会都是"看起来不相关的小动作"意外撬开的**。判据是"我想不想做 + 做了坏结果能承受"，而不是"这符不符合我的规划"。

### 10. 至暗时刻的第一种：被质疑 + 等待

嘉印的至暗时刻不是失败，而是**"选择走一条安全但慢的路"** 带来的煎熬：
- 她坚持保留正职 + 副业组合（心理安全感需求高），所以不 all in 任何一条
- 结果：**所有事情都发展得相对缓慢**
- 上个月她被裁——她之前所有副业本来是为 35 岁中年危机准备的，"结果这个危机提前来了"
- 附加压力：男朋友不理解，质疑"你搞那么多事情又不赚钱有什么意义"

**心法**：**"要选择忠于自己的、适合你的那个选择，不要听别人说什么就去做什么。"**

**推论**：安全牌不是没有代价的，代价就是"等待期特别难熬 + 被身边人质疑"。**接受这个代价是走安全牌的前置条件**——扛不住等待就别走这条。

### 11. 至暗时刻的第二种：产品自嗨但市场不给反馈

王雅楠的第一个至暗时刻是**女性程序员社区创业失败**：
- 全职 all in、社群 + 教育产品双线，"帮助女生做编程"这件事她自己觉得"太好了"
- 但**市场没有给任何正向反馈**
- 她一度自嗨"是我东西太好了，市场还没准备好，需要再等一个时机"

**关键顿悟**：**"市场是非常诚实的，不要执着，该放下就放下。"**

**推论**：**"我的产品其实很好，只是市场还没懂"** 是所有创业者最容易掉进去的自我安慰陷阱。**你就是在拿"我一定对"去骗自己**。放下比坚持更难，但活得下来的都是懂得放下的。

### 12. 至暗时刻的第三种：赌上工厂接不完美的大单

王雅楠的第二个至暗时刻是**接非盘 30 万大单时产品还有技术点没解决**：
- 非盘市场爆火，客户 30 万开口
- 工厂研发未完成 100%——她是"完美主义 / 道德洁癖"，本能想拒绝
- 合伙人更冒险，直接说"接，我们相信这个月能解决"
- 她每晚睡不好，"就担心明天客户就来投诉"
- 好在研发跟上来，进展蛮顺利

**心法**：她玩德扑保守、合伙人激进——**性格决定了做决策的偏好，两种性格都能成功**。关键是**知道自己是哪种，然后做符合自己的决策**。

**推论**：**过度追求 100 分的完美主义 = 错过订单**。商业的常态是"70 分能交付、路上迭代到 90 分"。

### 13. 至暗时刻的第四种：流量号被封 → 组织结构调整

谢无迪的至暗时刻是**今年 4-5 月小红书严打引流**：
- 30 多个上海本地流量号，一半收违规提醒
- 违规 = 7 天不推荐，甚至永久不推荐 → 客源锐减 → 线下经营困难
- 她的三个动作：① 让部分流量团队成员走人 ② 削减一半账号只做深耕的 ③ 把流量好的账号从个人号转成企业专业号 + 开聚光投放合规化

**衍生方法论**（做流量业务的 3 类关键角色）：
1. **流量运营**：负责公域流量
2. **私域运营 / 销售转化**：把流量转化成付费
3. **社群运营**：包括社群活动执行 + 付费用户内容交付

**推论**：**平台政策变化是所有做流量业务的人的常态风险**。合规化不是可选项，是保命项。

### 14. 至暗时刻的第五种：第一个客户白嫖走了

王菲嘿今年 3 月离职创业，最至暗的瞬间是**第一个客户白嫖**：
- 她原本做跨境电商代运营，一个客户前期一直热情，聊了一个月合同都拟好
- 到签约那刻，客户各种要"承诺销售额 / 承诺 ROI"，就是不签
- 她认清了——**"他不想签，他就是想要我给他做一个方案，他就想白嫖"**
- 她躺了一个礼拜，男朋友一句**"你觉得你谈的每一个客户都会上来就给你送钱吗？"** 把她拽起来
- 教训：**除了做内容以外，要花时间锻炼口才、在私域里营建信任感、把销售当成必修课**

**推论**：**知识付费 / 服务业务被白嫖是常态而不是意外**。**"第一个客户 = 我的创业生涯"** 这种自我加压最容易崩掉自己——第一个只是练手用的。

### 15. 心态法则：忠于自己 vs 遇到问题解决问题

主播雪怡把四位嘉宾的至暗时刻抽象成**两条心态路径**：

**路径 A：忠于自己的选择**
- 嘉印必须"正职 + 副业"、王雅楠必须交付近乎完美的产品——都是**在忠于自己的过程中调整自洽**
- 关键不是选哪种，是**选完了自洽**

**路径 B：遇到问题解决问题**
- 谢无迪 / 王菲嘿是这种——**不陷在情绪里、赶紧想解决方案**
- 王菲嘿一个礼拜情绪就结束了，谢无迪当天就调整流量策略

**推论**：**别把这两条路径混着用**——两条都能通到终点，但混用就成了原地打转。

### 16. 玄学、身体、心理咨询：真正的决策工具是哪个

一位听友分享她去找玄学大师算卦的经历，主播讨论中给出**决策工具的优先级**：

- **玄学 / 命理**：本质是**心理安慰**——答案对不对不重要，重要的是你借此下定了决心
- **心理咨询 / 内心建设**：**比玄学更可靠**——不逃避真实问题，直接处理
- **身体反应 = 最诚实的风水**：王雅楠引一位地产风水师的话——**"你的身体是最好的风水验证工具，觉得舒服就风水好，不舒服就风水不好"**
- **决策原则**：**非涉及生死或严格科学问题的决定，就走心不走脑**——身体感受 + 情绪判断，比理性算账更靠谱

**推论**：玄学不是不能信，但**要意识到你信它的真正原因是"你在等一个理由拍板"**。真正的杠杆是**"我身体的感受、我情绪的反应"**。

## 关键问答

**Q：小灰一个男生为什么要做"搞钱女孩"？**
A：他是福建家庭里"再生一个男孩才有你"的成长背景，从小和姐姐、妈妈一起长大，看到很多女性的束缚和困境；他做媒体内容，就想把身边优秀女生的声音放大出来。他不是女性，但可以做**传声筒和连接者**。

**Q：一个月更佛系博客怎么变成周更 15000 订阅？**
A：三步——**准确洞察 + 目标感与信念感 + 持续行动**。关键节点是一个半月的停更纠结，雪怡把节奏从月更拉到周更，小辉跟自己 say yes。

**Q：什么样的女孩才算"搞钱女孩"？**
A：不看资产也不看头衔。三大特质：**爱折腾 + 执行力 + 不内耗**。

**Q：命运齿轮的转动时刻长什么样？**
A：不一定要有戏剧性的大事件。可以是**高一夕阳下发奋、给陌生学长打电话、公益人第一次接受商业灰色地带、疫情送外卖时随手拍的一条视频**——**"每一个行动其实都是命运齿轮转动的时刻"**。

**Q：辞职 / 换轨道到底该不该跟随身体感受？**
A：**非涉及生死或严格科学问题的决定，就走心不走脑**——身体不舒服的地方就是最诚实的风水。玄学 / 大师是"你在等一个拍板理由"的心理安慰，真答案在你自己的身体反应里。

**Q：产品好但市场不给反馈，该坚持还是放弃？**
A：**放弃**。市场诚实。"东西太好只是市场没准备好"是最典型的创业自嗨陷阱——你在拿"我一定对"骗自己。

**Q：合伙人 / 股权 / 分工的教训是什么？**
A：谢无迪总结："**先做小人再做君子——先把该谈的协议、股权、分工全部谈好再起步**"。合伙人拆分是所有内部动荡里最惨的一种，能提前设计的都要提前设计。

**Q：普通打工人想做小红书副业，怎么切入？**
A：三条方向必须交集——**平台热门方向 × 你自己长期喜欢做的 × 有清晰的变现路径**。**变现路径要在起步前就想清楚**，是接广告 / 卖货 / 卖知识付费；否则数据一冷就撑不住。

**Q：第一个客户就跑了 / 白嫖了，是不是我不适合创业？**
A：不是。**第一个客户只是练手的**。真正做销售靠的是私域信任感 + 口才 + 大量练习——不管卖 10 块还是 10 万，都是必修。**"第一个客户等于我的创业生涯"这个自我加压是最容易崩掉自己的错误框架**。
