# 069 - 摆摊卖手串、写英文短剧、塔罗占卜，这届年轻人的副业有多野 听友连线

## 一句话摘要

四位普通打工人（大学老师白白、出版社编辑小西、大厂运营于仔、外企物流 Grace）用摆摊卖手串、写英文短剧、算塔罗、开淘宝拼多多小店的方式亲测出：副业不是玄学，而是「下场干+复盘」的手艺活，只要选品/定位/执行到位，普通人每月多挣 6000-20000 完全可复制。

## 金句

- **「不要听别人说太多，或者你自己想太多，只有下场干，然后去复盘才是真的实战经验。」——白白**
- **「你越觉得自己不值钱，别人也觉得你不值钱；你把时薪设成 1000 美金，能力会慢慢往那儿靠。」——小西（引用《纳瓦尔宝典》）**
- **「赚钱一定要有配得感——塔罗牌是用灵力交换，一定要收钱，挂不走空。」——于仔**
- **「有单进账你就会释放多巴胺，眼睛一睁哇好几单，今天又可以吃榴莲了。」——Grace**
- **「万物皆商品，你的经历和经验就是你可以去赚钱的商品。」——白白**
- **「不要出卖自己的时间，去 mine and multiply 自己的生产力。」——小西**
- **「要看蓝海不能看红海；不能只做自己喜欢的，十个女生跟风做美甲九个亏。」——Grace**

## 要点提炼

### 一号听友·白白（大学法律老师 · 摆摊卖手串）

- **副业矩阵**：兼职律师 + 考研机构讲师 + 考研咨询/资料 + 摆摊卖手串，累计六位数；讲师和考研辅导性价比最高，但只有摆摊是「有手有脚就能抄」的通用打法。
- **偶然入局**：端午去义乌商贸城给朋友代购，发现拿货必须一打起，剩下的货就地摆摊清货，第一天在武汉大学宿舍楼卖了 600+，五天累计 2000+。
- **氛围感六件套**：中国风摊布 + 书法台灯 + 展示架/展示盘 + 寓意贴纸（节节高升/心想事成/逢凶化吉）+ 试戴镜子 + 消毒器具，把「饰品之外的情感价值」补齐。
- **选品结构**（全部按价位分层）：
  - 9.9 引流款（进货 1-3 元）
  - 15.9 双串（进货 4-6 元）
  - 19.9 独家定制款（在阿里巴巴/淘宝反查确认「全网无同款」）
  - 25.9 / 29.9 常规
  - 35+ 水晶/南红等高客单（对标淘宝定价可 100-200）
- **地点校准**：地铁口卖不动（下班行色匆匆 + 竞品街 + 城管），宿舍楼反而炸单——**要匹配客群支付意愿而不是绝对人流量**；商场亲子人流对手串无效。
- **心法**：万物皆商品；预算最坏亏 1-2 千可承受就大胆开干；「光脚不怕穿鞋」；小钱撬大钱。
- **下一站**：已「借势」湖北麻城中老年小商品供应商的验证过的模式，直接复制并叠加自己的销售技巧。

### 二号听友·小西（图书公司新媒体 · 海外短剧英文编剧）

- **单价演进**：第一本狼人吸血鬼奇幻 60 集报价 1000 美金（含被压价，一年前入行）；因首本意外爆款，现每本 2000-3000 美金，一年写了 6 本，月外快 1-2 万。
- **行业底图**：追蜜、Reelshort、Carlo 等海外短剧 APP 背后大量国人投资/团队降维打击；核心变现在 APP 内充值，头流公司最赚，编剧是牛马。
- **爽点标准件**（可套的固定模因）：
  - 重生打脸（穷小子重生亿万富翁反虐前任）
  - 追妻火葬场
  - 甜宠霸道总裁（女频最热）
  - 都市战狼 / 飞车抢劫 / 救美（男频）
  - 女频忌讳纯复仇——必须夹爱情夹甜
- **英文门槛破除**：好莱坞剧本格式极简（网搜两份即懂）→ 不需要心理和场景描写，全是动作+台词 → 一般现在时 → DeepL/ChatGPT 兜底。
- **入门方法**：拿平台参考剧集，逐集用一句话拉结构表（60 集就写 60 行），再往里填肉；先写故事再谈格式。
- **搭子模型**（Naval《纳瓦尔宝典》）：找互补短板的搭子——自己会掌控节奏和台词，对方脑洞多且熟男频/仙侠桥段，产能翻倍。
- **获客渠道**：弱关系（几百人的行业大群、共同同学）+ 小红书评论区「举手：我是编剧」被反向勾搭。
- **自信补丁**：不再免费第一本；给自己设定时薪 1000 美金锚点。
- **对客户的原则性拒绝**：拒写家庭暴力/虐女——「我是女的我看不爽，我不接」。

### 三号听友·于仔（大厂音频公司运营 · 塔罗师）

- **收费结构**：88 元/1 题、150 元/2 题；每天 3-4 题，每月 6000-1 万；4 个月共 3 万+，第一个月最多因为熟人集中变现。
- **入门契机**：自己被朋友推荐去算塔罗解职场瓶颈 → 得知「塔罗是工具，抽牌反映潜意识」祛魅 → 用自己/朋友做验证抽牌 → 发现结果准 → 开始收费。
- **塔罗 vs 星座心法**：塔罗是**定制化事件**（老板会不会保她、房子选哪个圈）而不是星座式模糊描述——所以不是「巴纳姆效应」的对号入座。
- **解牌能力观**：牌面 + 客观经验 + 心理疏导，「塔罗师是更适合中国宝宝的心理咨询师」，功力靠读书、案例积累和归纳问题。
- **平台策略与代价**：小红书情感号 8k 粉，蒲公英能接广告，一发塔罗笔记被封号；改隐晦（只晒牌面）仍会被封。**播客成为新蓄水池**：两期播客各带来数十到 100+ 私信。
- **获客三层**：熟人验证 → 口碑推荐 → 播客/朋友圈裸奔（老板都知道，公司文化宽松）。
- **配得感原理**：以前给同事免费改简历/内推 → 塔罗是「灵力交换」→ 天然理直气壮收费，还成为社交货币（机场、午休随地大小算）。
- **副业韧性感**：不同于写稿/写脚本的一次性收入，塔罗是「越算越从容」的**吃资历的技能资产**——书越读越多、案例越攒越厚、单价和客源越滚越大。
- **潜在跳板**：面试测测 APP 玄学岗、探店线下塔罗馆（半小时 500 元/家），观察职业化天花板。

### 四号听友·Grace（无锡外企物流策划负责人 · 淘宝/拼多多多店铺）

- **入局史**：大学开奶茶店亏 5 万 → 外卖健身餐亏 20 万（欠债倒逼副业）→ 闲鱼卖莆田高仿鞋（大学生 100+，纯利/月 1 万）→ 淘宝高尔夫鞋（一双利润 200-300、月入 2 万）→ 全面弃暗投明做长期主义副业。
- **当前 3 店结构**（月总 8000+）：
  - 淘宝女鞋（25-40 岁稳定收入群体，纯挂店）
  - 淘宝**医美工服**（韩国面料、150-170 客单、复购强、香港客户/医美机构 40 套起订）
  - 拼多多**水晶手作 WHISKY 杯**（对标日本江户切子 5000-10000 元，自家 300-1200，月 1500-2000）
  - 另分销萌宠猫砂厕所（客单 1500-2000）
- **反直觉认知**：
  - 淘宝并没死，只是流量结构变了——**做小众品反而客群精准**（3 人进店成交 1 单）
  - 拼多多不等于低价——见过中监级领导用拼多多买高端品，从此立志「在低价平台卖高端」
  - 差异化的核心：**看蓝海不看红海，不能选自己喜欢的品**（女生跟风做美甲 9/10 亏）
- **副业时间成本**：一天回复几条消息，接近零维护，「和刷抖音时间没差」，甚至开会交手机也不耽误。
- **门槛意识**：一点门槛都没有的谁都能做的赛道赚不了大钱——医美工服要营业执照/资质，宠物疫苗 To B 卖给医院，都因为**门槛=护城河**。
- **踩坑品类库**（100+ 种测过）：作业打字机、宝藏探测器、新能源汽车充电桩（4000 → 网上 1200-1800，被卷得快）、大宇/贝拉多功能锅（李佳琦带火一年后死）等。
- **心法**：跟风口、快试快撤、迭代认知；被动收入 = 每天几百块进账的多巴胺自我强化循环；女生一定要留小金库。

## 关键问答

- **Q：普通人搞副业到底怎么选项目？**
  A：白白说观察生活，万物皆商品；小西说先问自己「不给钱也愿意做的是什么」；于仔说兴趣 × 擅长 × 风口三者相交；Grace 说选蓝海小众品、不选自己喜欢的品、快速试错快速换赛道。

- **Q：地铁口人流量大为什么反而卖不出去？**
  A：白白的经验——匹配「客群支付意愿」优先于「人流量绝对值」：下班行人赶路、隔壁一条竞品街、下雨天等因素直接归零；反而校园宿舍楼虽人少，客群时间充裕、消费冲动高。

- **Q：不懂英文、没学过编剧能写海外短剧吗？**
  A：小西说完全可以。剧本格式两份剧本就看懂、几乎不需要心理场景描写、一般现在时、DeepL/GPT 兜底翻译，最大门槛不是英文而是「不给自己设限的第一步动作」。

- **Q：塔罗算不算「巴纳姆效应」骗术？**
  A：于仔的回应——塔罗牌不同于星座泛化解读，问的是**具体人的具体事件**（如「我老板会不会保住我」），结果是明确二值，且解牌深度依赖塔罗师的经验积累和心理疏导能力，本质是「更适合中国宝宝的心理咨询」。

- **Q：淘宝流量枯竭了、拼多多只能卖低价，还有机会吗？**
  A：Grace 直接反驳两条刻板印象。淘宝小众品→客群更精准（3 人进 1 单）；拼多多可以卖 300-1200 高端水晶杯，因为高消费人群也在用拼多多。**关键不在平台，在选品差异化 + 门槛（营业执照/资质/供应链）**。

- **Q：副业会不会分散主业精力被老板不满？**
  A：于仔说心大公开，老板还让她算绩效；Grace 说自动化店铺一天回几条消息不影响；小西说副业反而倒逼上班时间更专注（想早点下班回家写剧本）。

## 可复用方法

### 「小西式」海外短剧编剧入门法

1. **拉结构表**：找 1-2 部同类型爆款，逐集用一句话写下发生的核心事件（60 行）。
2. **套爽点模因**：从「重生打脸/追妻火葬场/甜宠霸总/都市战狼」中挑一到二个作骨架。
3. **格式与语法**：网搜两份英文剧本套格式；用一般现在时；DeepL 双向翻译润稿。
4. **找互补搭子**：自己擅长节奏/台词 → 找一个「桥段脑洞王」搭档，产能翻 2 倍。
5. **接单渠道**：弱关系群 + 小红书评论区主动亮身份「我是编剧」。
6. **价格锚点**：Naval 时薪法则——设定 1000 美金/小时的目标锚，慢慢往上靠。

### 「于仔式」塔罗副业冷启动

1. **自我验证期**（1-2 个月）：熟人免费/低价测试，用真实反馈校准准度和归纳问题能力。
2. **收费定价**：88 元/1 题、150 元/2 题（中端定价降门槛，走量+回头客）。
3. **获客三段式**：熟人 → 朋友圈裸奔 → 播客/小红书内容矩阵（注意小红书封号红线，牌面隐晦发）。
4. **产品化**：每人 30 分钟 = 1 小时接 2 人，晚 8-10 点固定接单窗口。
5. **配得感训练**：从「不好意思收朋友钱」→「灵力交换必须收钱」的心理认知升级。

### 「Grace 式」多店副业矩阵法

1. **蓝海选品**：一个店只做 1-3 个小众高毛利 SKU（医美工服/水晶杯/宠物疫苗）。
2. **对标日本/欧美高端品牌**：找 1/10 价的国内平替供应链，做「性价比高端」定位。
3. **反刻板印象跨平台**：淘宝挂精准客群品、拼多多卖高端品、闲鱼避坑（客服重）。
4. **门槛=护城河**：优先做需要「营业执照/资质/供应链关系」的品类。
5. **快速试错**：100+ 品类里每个试 1-3 个月，不行立刻换赛道，「不迷恋沉没成本」。
6. **被动收入循环**：日几百块进账 → 多巴胺正反馈 → 心态稳 → 继续测新品。

### 副业选品共识清单（跨四位听友交叉验证）

- **不选**：跟风红海（美甲/摆摊卖水/健身餐实体）、无门槛全民赛道、自己单纯「喜欢」但没市场的品。
- **必选**：结合个人擅长 × 兴趣 × 当前风口；能形成「资历-经验-单价」正循环的技能型副业更抗周期。
- **必备**：先小额亏得起的成本预算；下场干+快速复盘；找互补搭子放大产能。
