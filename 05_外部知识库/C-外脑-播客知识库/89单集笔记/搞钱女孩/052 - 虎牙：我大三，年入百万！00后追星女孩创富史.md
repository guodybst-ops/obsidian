# 052 - 虎牙：我大三，年入百万！00后追星女孩创富史

## 一句话摘要

03 年大三女生虎牙，追王俊凯 QQ 空间起家卖水晶，7 年累计千万，讲透养成系 IP + 私域 + 知识付费的全套打法。

## 金句

> "我把搞钱当做一个兴趣爱好——身边同学的消遣是打游戏 KTV 购物，我的消遣就是赚钱。"（虎牙讲搞钱心态）

> "早期 QQ 空间做流量真的就是非常简单，1 块 2 块上一个扩列车，遍地都是流量，而且都是追星女孩。"（虎牙讲第一波流量红利）

> "该玩玩该学学——玩的时候很玩，学的时候很学，这就是拎得清。"（虎牙讲学生党兼顾学业与搞钱）

> "你判定你是不是真正喜欢一个东西，就是看你过了几个月是否还惦记着它。"（虎牙讲第一颗水晶的种草）

> "很多时候我们不敢迈出那一步，是因为没有想好能承受的最坏情况——如果你想清楚了，最坏就这样了我也能接受，那个勇气就出来了。"（虎牙讲转型知识付费）

> "不够强大的时候会发现身边全是坏人，红了以后身边都是——本质还是回到圈子问题。"（虎牙讲向上链接）

> "招贵人体质不是天生的，一定是你自己去找那些贵人、或者自己提升价值吸引到贵人。"（虎牙讲主动求助）

> "钱可以解决 99% 的烦恼——妈妈因为几百块钱和爸爸吵架的时候，我会觉得赚钱还是有意义的。"（虎牙讲金钱观转折）

> "不完美主义背后的逻辑是不那么在意条件和结果，而关心眼前具体怎么做，才能掌控自己的身份和人生。"（引自《如何成为不完美主义者》）

> "我可能会用价值筛选，而不是用结果筛选——那些冲着房和车来的人，是想跟你一样赚快钱的人。"（虎牙讲流量筛选）

> "自己就是自己最大的贵人——你要么花钱进圈子，要么靠价值吸引。"（虎牙讲向上社交心法）

> "跟别人比是没有尽头的，只能跟过去的自己比——拉一条自己的成长时间线。"（小灰给旁边 01 年女生的建议）

## 要点提炼

### 1. 从追王俊凯开始的第一桶金：初中卖 Hello Kitty 到卖水晶

虎牙的搞钱起点是初三追王俊凯，同好圈子在 QQ 上极度活跃，她先给追星女孩卖 Hello Kitty 小首饰，后转到卖水晶（第一颗草莓晶 200 多，攒了很久终于买下——"过几个月还惦记着"是真喜欢的信号）。找货路径也非常朴素：从买家问"招不招代理"→ 付代理费 → 变成二三手代理 → 有单子后追溯到江西源头工厂。这条链路强化了一个反直觉判断：**大部分 00 后创业不是从「商业模式」开始，而是从「消费入口」开始**——你先是那件商品的重度用户，再是分销者。

### 2. QQ 空间"扩列车"的野蛮流量红利

虎牙详细还原了 2017-2021 年 QQ 空间的流量玩法，这段材料对研究"社交平台早期红利期"极有价值。**"扩列车" = 1-2 元 = 1 个二维码位**：车主组一张多人二维码大图，用户上车即被推流全网追星女孩，图上写明"追王俊凯的妹、恋爱美食穿搭博主、跳舞爵士 7 年、佛系店家不刷屏"等多维标签让人对号入座。她靠这一波积累 2-3 万粉，一条 QQ 空间转发能到几十万——**QQ 空间的裂变机制远比朋友圈猛烈（朋友圈只能截图不能转发，QQ 空间可裂变转发）**。这条经验直接可迁移到今天的小红书早期账号——**给用户一个"链接点"清单，让他决定为哪一条来加你**。

### 3. QQ 空间到微信的一次"简单粗暴"转化

有了 QQ 空间流量后，虎牙转到微信的动作只有一个：**发一条 QQ 空间"加我微信抽奖 X 名"**。她的判断：**追星女孩从粉圈加你的微商号不是天然行为，必须给一个动机——要么获利（抽奖），要么价值认可**。这条操作简单到"没有技术含量"，但恰好是当时的关键一跳——**冷启动的第一波私域，永远不是靠"内容价值观"来的，是靠一个动机勾子**。

### 4. "该玩玩该学学"——搞钱当兴趣的学生党策略

虎牙特别强调：**"我从来不会为了搞钱不学习"**。她把搞钱当成消遣、当解压方式（相当于别人打游戏、KTV），最忙的高三阶段直接把号交给妈妈托管做基础售后。她给学生党划了一条清晰的线——**"该玩玩该学学"这 6 个字**——玩的时候玩狠，学的时候学狠。她也发过公告向粉丝告知"要停一年高考"——**很有职业思维，因为不发公告一年后没人记得你**。这一条对所有担心"在校搞副业会不会耽误学业"的学生党，是最直接的可复制答案。

### 5. 家庭氛围：创业之家 + 潜意识节俭教育的复杂动力

虎牙家不缺钱（哥哥已在上海买房），爸妈是白手起家的创业者。爸爸的原话：**"我教不了女儿学习上的东西，但社会大学她已经在我这里毕业了"**。同时妈妈的节俭教育让她从小"不舍得给自己花钱"——所以她后期用赚到的钱"重新养自己一遍"（想什么买什么），并明确金钱观的价值：**看到妈妈因为几百块加价而不去张学友演唱会时觉得可惜，主动出钱送她第二排内场——那一刻真的意识到赚钱有意义**。

### 6. 业务演进四段论：入职 → 探索 → 进化 → 转型

虎牙把自己的搞钱路径归纳为：**入职（水晶微商起步）→ 探索（代理团队壮大）→ 进化（同行都来学，出现教学需求）→ 转型（知识付费）**。转型两个触发点：1）水晶零售+代理商业模式趋于稳定 = 摸到天花板；2）追星支撑不了动力 → 需要"更大的成就感"供给新能量。她在同行答疑中练出"输出手感"，用 To C 语言优势和多年练出的用户观察能力，切进"知识付费导师"新赛道。这条转型逻辑可迁移到所有"业务遇到天花板"的老板——**答案往往就在你已经在无偿输出的那件事里**。

### 7. 转型阵痛：3-4 个月的至暗时刻

转型不是丝滑的——虎牙原账号有 5-6 千好友（水晶顾客+同行），她做了一个高风险动作：**把水晶业务全部搬副号，主号清零重做知识付费**。原因是"朋友圈显得你什么都做，还不如不做"。代价立即出现：新号导流有流失、水晶业绩下滑、知识付费几个月不开单、同行小人抹黑（"你业绩没那么好，你就是割韭菜"），加上大一室友背后议论"做微商最土了"——她在寝室哭过。3-4 个月才熬出来。**关键复盘：这些谩骂在她强大时根本形不成威胁，只是在转型这个薄弱点上成了"最后一根稻草"**——转型点必须自己筛选噪音，否则任何小压力都会被放大。

### 8. 养成系 IP 方法论：真实 + 一路见证 + 陪伴变量

虎牙的 IP 定位是**养成系 IP**——不是专家人设，是"跟观众一起成长的人"。她的 IP 演进：**卖水晶陪女生变幸运 → 知识付费陪女生变独立、变有钱、变聪明**。这个演进本身就是她生命节奏的映射，观众看着她高考、进大学、赚到第一个 6 位数、8 位数……**"小白更容易被养成系 IP 打动，因为可以看到一路成长的完整链路"**。这条方法论直接对标 034 废话小梦（也是养成系），二者共同证明——**养成系 IP 的关键不是"输出干货"，是"输出你此刻真实的困惑和进步"**。

### 9. 朋友圈三分法：广告圈 / 生活圈 / 认知圈

虎牙给做私域的听友一套朋友圈分类系统：
- **广告圈**：硬广、软广、产品体验、顾客反馈；
- **生活圈**：你专业之外的另一面（人都有窥私欲，仰慕你的人想了解你的生活）；
- **认知圈**：所思所想、感悟、价值观 → 吸引同频。

**判断法则**：把"我发这个别人爱看吗"改成"我发挥优势 + 表达想表达的内容，就能吸引同频者，不同频的自然离开列表"——**朋友圈本来就是你的，不需要为不同频的人调整**。她给学员的具体动作：**列出你所有的喜好、兴趣、缺点、生活细节 → 每一项都是生产资料**（连负面情绪都可以，只要你写"冷静下来学到了什么"）。

### 10. 无学历、无专家背景的普通人怎么做 IP：一技之长 + 真实成长

小灰追问"如果听众不觉得自己特别怎么办"——虎牙直击本质：**你不需要是专家，你只需要有一技之长 + 展示学习过程**。观众爱看的不是完美结论，是"他跟我一样是普通人，为什么能做到"。她给的动作：**问身边朋友"你觉得我特别在哪里、我有什么优点缺点"——如果自己不清楚自己的优势，朋友是最好的镜子**。小灰补充了昨天遇到的听友"大拖拉"作为案例（漫画 + 育儿吐槽人设）——**普通人做 IP 的公式：性格 + 表达风格 + 领域三要素相乘**。

### 11. 微商模式科普 + 反跳单的价值留人策略

虎牙给微商正名：**微商就是分销 + 直接对消费者的商业模式**。她自己的水晶：找江西源头工作室拿货 → 工作室代发。**代理制度只有一级**（588 元），拿货价 + 培训 + 引流福利打包在一起。跳过她直接去源头拿货防不住（差价二三十）——**她的反跳单策略是用价值留人**：拿货价之外提供"引流培训、朋友圈文案教学、代理陪跑福利"这些工作室不给的东西。她提到市面上很多微商设计到三级代理都很正常，她故意保持一级——**信息差已经没了，只能靠价值差**。

### 12. 金钱观转折 + "重新养自己一遍"

虎牙用两条锚点讲金钱观的转折——1）**看到父母因几百块吵架**，意识到钱是解决 99% 烦恼的工具；2）**主动送妈妈第二排内场看张学友（补上被黄牛加价 200 元的差额）**——那一刻她定义了赚钱的意义。她也很坦诚地承认，从"节俭教育下不敢花"到"想什么买什么"的过渡就是一次"重新养自己一遍"——**这个跨集族在搞钱女孩里高频出现（Gloria/Claire/王喜儿都有）**，虎牙是"未经过重大挫折就完成这个跨越"的少数样本，所以她的启示更偏"消费即回流"的商业思维——**"钱花出去，它会用成倍的形式给你回流回来"**。

### 13. 存钱的爽感 + 目标绑定消费法

虎牙有一套自己的存钱-花钱耦合系统：**"这个月想买包 → 支付宝超过 70 万才买 → 赚不到就不动这笔钱"**。她拒绝了爸爸帮她理财（"我天天打开余额看，我会有赚钱的动力"）。她自称**零风险主义**——不投任何有风险的东西，"自己就是自己最大的投资，自己就是理财产品"。这一条给了不少年轻搞钱者一个反直觉的锚：**存钱不是省钱，是给自己攒游戏道具的爽感——目标绑定消费法把消费欲变成搞钱动力**。

### 14. 向上社交筛选圈子三原则

虎牙每年花 5-6 位数进圈子，她的筛选法三原则：
- **原则 1：从价格筛**——行业排名靠前的高客单圈子（生财 2000 = 普通门票，8000 多 = 航海家；航海家质量明显更高）；
- **原则 2：从 IP 筛**——因为喜欢这个人所以为他的产品和圈子付费；
- **原则 3：从需求筛**——现阶段我需要什么，就去哪个圈子。

配套动作：**要"稳赚不赔"，就花钱换那些"你的困惑他已经经历过"的经验**。她初做知识付费花 7000 找了一位路径相似的导师做长期陪跑；后期做团队时又找有超级团队的导师去看他们怎么组建团队——**永远找"我下一步会遇到什么"已经经历过的人**。

### 15. 招贵人体质 = 花钱进圈子 + 靠价值吸引 + 会给正反馈

虎牙特别强调：**"招贵人体质不是天生的"**——你要么花钱进圈子，要么靠价值吸引。**关键动作是"给正反馈"**——大佬不缺礼物，缺的是"你听了我的建议真的去做了，然后回来告诉我做出了什么结果"的正反馈。她的案例：生财见面会等车的空档听大佬说"想要大佬帮你，一定要给反馈"，她之后每周给一位天使投资人（艺人老师）写复盘：**"这周我听了大佬什么话 → 我做了什么 → 得到什么反馈 → 下一步计划 → 有什么困惑"**——大佬会很认真地二次输入，形成"一个信息差多值钱"的复利循环。**这条正反馈闭环是本集给听友最可操作的社交升级动作**。

### 16. IP 筛选客户的秘诀：用价值筛不用结果筛

虎牙做知识付费遇到过被抄袭且骗钱的恶劣情况——被害者拿着盗版海报来找她维权。这件事让她想清楚：**"你展现什么，就吸引什么"**。她主动选择"用价值筛"而不是"晒房晒车晒结果"：**"晒结果吸引来的都是想赚快钱的人；用你的思考、过程、真实感受吸引来的才是真正认可你的人"**。配套动作：**售前把学员权益一条条列清楚 → 用户如果连权益说明都不愿看，就是对自己不负责，他不成交更好**——这是双向筛选的成本节约动作。

### 17. 时间管理：想清楚眼前该做什么 + 碎片时间叠加

虎牙的时间管理只有一句话：**"想清楚眼下这个时间节点该做什么，然后放下其他一切心无旁骛去做"**。她一周只有周一满课，每天早上先回复零售+代理消息、收单，一天一个小循环，训练营和课程都由 4 个助理承接。她本来想请生活助理，最后发现"最好的生活助理还是我自己"。小灰用一个具体例子补充：**check-in 到房间分配的 30 分钟空档 → 40 分钟写完一份采访提纲**。虎牙也补充：**上海到杭州高铁的一个多小时 → 大概写完当晚采访提纲**——**碎片时间叠加的关键是「利用等待时间做重要但不紧急的事」**。

### 18. 大学生要不要在校搞钱的辩证答案

对"大学生该不该在校搞钱"的分歧，虎牙的答案不是二选一：
- **能力条件**：时间精力管理做得好 + 能平衡学业和搞钱 → 可以搞；
- **心态条件**：把在校搞钱当"经历的积累 + 试错"而非"一定要成事"，赚到当然好，赚不到当学习经历；
- **对赌条件**：想清楚"最坏就这样"能否接受；
- **禁忌**：不要跟风别人做什么你就做什么（大部分人跟风做副业都做不成）。

小灰承认自己大学时不搞钱只做社团实习，毕业后被现实毒打才补上"关注钱"这课——**两条路都对，但每个阶段最焦虑的问题不一样**。

### 19. 焦虑对治 + 拉自己的时间线

虎牙对焦虑的第一直接反应是**"直接屏蔽"**——如果一段时间被某个人比对得很难受，就切断来源，专注自己。小灰补充给旁边 01 年女生的建议：**"跟别人比是没有尽头的，只能跟过去的自己比 → 拉一条自己的成长时间线"**。虎牙从编导的角度补充：**英雄成长曲线一定是先下再上，你此刻在波动都很正常**。这套"跟过去比"的判据在 041 携隐 Melody 的"燃料积累期"和"我会死吗"心态自问法里都有对应，是搞钱女孩系列非常一致的心态方法论。

### 20. 毕业规划：主业追梦 + 副业托底 = 冲的勇气

虎牙毕业的规划：**主业进影视传媒行业做综艺/电视剧/电影 + 副业保留知识付费和水晶**。她清楚承认：**"如果我没有这个副业，我现在也会焦虑考研还是就业"**。副业不是要变成主业，副业是"锦上添花的托底 + 加分项"——**让你有勇气冲一个还没有把握的梦想**。这个视角对于所有"想追梦却怕没饭吃"的年轻人是非常关键的锚——**副业的最高价值不是钱，是给主业冒险的勇气**。

## 关键问答

### Q1：初中/高中生怎么在 QQ 空间做流量？

虎牙：**QQ 空间的红利期已经错过**，但当年可复用的方法论仍然生效——1）**扩列车花小钱上墙**（1-2 元买流量位）；2）**多维标签让人对号入座**（追星身份 + 专业 + 兴趣 + 地域 + 生活状态；3）**利用平台裂变机制**（QQ 空间当年可转发裂变，朋友圈只能截图）。放到今天的迁移：**小红书/抖音早期账号做人设图 + 多标签也能吃到类似红利**。

### Q2：怎么从 QQ 空间粉丝转化到微信私域？

虎牙：**给动机 + 抽奖是最简单粗暴的转化钩子**。不要指望粉丝天然愿意加你的微商号——你需要一个"我为什么加你"的动机。她当年就是发一条 QQ 空间"加我微信抽 X 名礼物"，这就是她第一波私域的雏形。

### Q3：学生党搞钱怎么不耽误学业？

虎牙：**该玩玩该学学 6 个字 + 高考期间发公告停更 + 交给助理托管**。核心是**把搞钱当消遣/兴趣爱好，不是当主业**——这个心态本身就避免了"为搞钱不学习"。真的忙就把号交出去（找助理或家人代管），发公告告知粉丝停更周期，回来时大家还记得你。

### Q4：老账号转型新业务，怎么处理老粉？

虎牙的经历给答案：**把主号清空重做新业务 + 老业务搬副号**。她认为"朋友圈显得你什么都做，还不如不做"——但要允许 3-4 个月的至暗时刻（新号导流失、旧业务下滑、几个月不开单）。**关键是提前把最坏结果想清楚**（"最坏就是回去继续做原来的"）。她自己转型时发了一封深情长文公告，坦诚原因，老粉大部分理解——**老粉不能立刻转化就留着养，你在演进他们也在演进**。

### Q5：想被大佬带，具体怎么操作？

虎牙：**主动给正反馈是唯一秘诀**。1）**大佬给你的建议一定要真的去做**；2）**做完之后回来汇报进度 + 结果 + 下一步计划 + 困惑**（可以是每周复盘）；3）**大佬不缺礼物，缺的是"这小孩听得进去、值得带"的成就感**。她自己给天使投资人艺人老师的做法就是最好模板。**"招贵人体质"的实质就是这套正反馈闭环**。

### Q6：怎么筛选付费圈子？

虎牙三原则：**从价格筛（同行业排名靠前的高客单）+ 从 IP 筛（因为喜欢这个人）+ 从需求筛（我现阶段需要什么）**。要"稳赚不赔"，就找"你困惑的这一步他刚经历过"的导师。

### Q7：焦虑怎么办？

虎牙+小灰：**直接屏蔽 + 拉自己的时间线跟过去比**。跟别人比没有尽头（比你有钱、比你漂亮的人永远有），跟过去的自己比才有主线。英雄的成长曲线一定是先下再上，你波动的当下也是曲线的一部分。

### Q8：副业该不该变主业？

虎牙的判断反直觉：**副业最好一直是副业**。她主业追影视传媒的梦想，副业保留知识付费+水晶做托底——副业的最高价值不是钱，是"让主业敢冒险的勇气"。副业变成主业往往意味着这个副业不再有兴趣的支撑，动力反而会耗掉。

## 可复用方法

- **消费入口起步法**：从自己是重度消费者的产品切入 → 分销 → 反向找源头，比"先想商业模式"更适合学生党。
- **多维标签自介图**：一张图上写清楚"我追谁 + 什么专业 + 什么兴趣 + 什么身份 + 能提供什么价值"，让不同人对号入座。
- **动机勾子转化法**：跨平台/跨渠道的第一波私域，一定要给一个具体动机（抽奖、福利、独家资源），别指望内容感染力。
- **朋友圈三分法**：广告圈 / 生活圈 / 认知圈，各占 1/3 比例。
- **一级代理 + 价值差留人**：拒绝多级分销，用培训/引流/陪跑福利做反跳单护城河。
- **业务演进四段论**：入职 → 探索 → 进化 → 转型（自问自己在哪一段 + 下一段的核心动作是什么）。
- **目标绑定消费法**：想买某物 → 设定支付宝达到 X 才允许买 → 存钱变游戏道具。
- **零风险主义**：自己就是最好的投资，任何有风险的钱都不动。
- **付费圈子三筛法**：价格筛（行业头部）+ IP 筛（喜欢这个人）+ 需求筛（现阶段要什么）。
- **给大佬正反馈闭环**：听建议 → 真做 → 每周汇报（做了什么 + 结果 + 下一步 + 困惑）→ 大佬更愿意继续带你。
- **价值筛选客户法**：不用"结果晒"（房、车、月入）吸引客户，用"过程 + 认知"吸引；权益售前一次列清做筛选。
- **副业托底冒险法**：副业不追求变主业，只作为"主业敢追梦"的托底。
- **碎片时间锁定重要不紧急任务**：check-in 空档、高铁时间锁定用来写提纲、复盘、健身等积压任务。
- **英雄成长曲线自问法**：焦虑时问"我在英雄曲线的哪一段"，先下再上是必然。
