# 100 - 林蔷七：害怕手停口停？教你打造个人赚钱系统

## 一句话摘要

畅销书《财富哪里来》作者林蔷七（阿七）以自己 15 年"每 5 年收入翻 10 倍"的实盘，拆解**自由人生公式 = 主业 + 副业 + 投资 + 套利 + 个人影响力**五要素模型；给出化妆品小样起家、可转债 / 宽基指数 / 港美股 / 黄金的操盘思路、京东家政券和飞天茅台的套利实操、以及"从口碑到融资"的个人影响力放大器路径，是搞钱女孩节目至今最系统的一份"个人赚钱系统"操作手册。

## 金句

- **"自由人生 = 主业 + 副业 + 投资 + 套利 + 个人影响力。"** —— 阿七版自由人生公式
- **"从你自己的需求出发，满足自己后再把解决方案卖给同类人；供需匹配就能赚到钱。"** —— 副业底层逻辑
- **"波动本身不是风险，人才是风险，你的人性才是风险。"** —— 阿七谈投资风险
- **"你所有的财富都是你认知的变现，你赚多少就跟你的认知挂钩。"** —— 阿七的核心信条
- **"我以前花了 3 年攒 10 万才敢学投资，这 3 年是被浪费掉的 3 年。"** —— 学投资越早越好
- **"人生是有起起伏伏、有风浪的，但是我们要学会冲浪。"** —— 面对市场周期
- **"信息差第一层是知不知道，第二层是知不知道原因，第三层是别人也知道但懒得做，第四层是同时握住 B 端和 C 端。"** —— 阿七的四层套利模型
- **"个人影响力是自由人生公式里的指数放大器，不是品牌，是别人怎么描述你。"** —— 定义个人影响力
- **"永远不要觉得自己只有一条路，你永远都有所有的可能性。"** —— 给姐妹们的话

## 要点提炼

### 1. 嘉宾档案：阿七的 15 年财富曲线

- **10-11**：普通编辑，月薪 1500-3500，年入 ~4 万，只有主业。
- **11-13**：时尚杂志流程编辑 / 化妆品公司市场经理，主业 + 卖化妆品小样副业，年入 ~8 万。
- **13-15**：女评内容主编，年入 ~10 万（第一个 5 年→ 0 到 10 万）。
- **15-18**：苏宁做运营（普通运营 → 运营总监），主业 + 副业年入 ~18-19 万。
- **18-20**：阅读 app 运营总监 + 兼职创业理财教育；2020 年裸辞卖股份，主业 60-100 万 + 副业 30-100 万 + 投资 >100 万（第一次投资单项破百万）。
- **21-22**：独立创业 + 做个人 IP，年入 400-500 万（含投资）。
- **23-24**：个人 IP 稳定期，年入 500-600 万 + 投资 150-200 万，**2024 年总收入 800+ 万**（投资占 1/3，预计 2025 年占 50%）。
- 目标：**每 5 年收入翻 10 倍**（实际通常在第 3-4 年就达成）。

### 2. 自由人生公式：五要素模型

- **主业**：不仅是温饱，更是**专业知识 / 解决问题能力 / 思维 / 人脉**的原始积累。
- **副业**：主业不能独扛，副业是"润滑剂 + 增长曲线的转向点"。
- **投资**：让财富脱离时间的线性绑定；同时训练"看透本质"的能力。
- **套利**：确定性收入 + 最小成本变现——一种赚钱的操作模式，不只是黄牛。
- **个人影响力**：指数级放大器，把前四项的效果乘上 3-10 倍。

- **五指推球比喻**：任一根手指都难推动球；五指合力时轻松推动——五要素分阶段叠加而非同时。

### 3. 副业清单（阿七过去做过的 20+）

- 初中：给杂志写稿子，初三第一次收 60 元稿费。
- 大学：给杂志写稿撑学费 + 卖莆田系风的什么货。
- 工作后：**卖化妆品大牌小样（4 年攒下第一桶金 10 万）** / 扎卡风店员 / 微博美妆博主（140 字 300 元）/ 股票课老师 / KOL 课程开发 / 版权 / 影视 IP 策划 / 企业增长咨询 / 简历面试辅导 / 职业规划咨询 / 上市公司增长咨询（单 case 30-50 万）等。
- **最赚**：上市公司 B 端咨询，2020 年一个项目 80 万。
- **最爽**：资源链接型副业（居间费 / 中介费）。
- **最香**：财商教育（学员生命状态改变带来成就感）。

### 4. 副业底层逻辑：从"利己"到"利他"

- **第一步**：识别自己的真实需求（阿七想用大牌又没钱 → 撬动小样赛道）。
- **第二步**：找到解决方案。
- **第三步**：把解决方案卖给同类人（同类痛点体感强 → 天然精准营销）。
- **副业不仅赚钱**：反哺主业（面试上化妆品公司市场经理）+ 拓展身份（被 PR 看到 → 成为美妆博主）+ 积累资源与人脉。
- 副业 = 财富流的润滑剂，让主业车头卡壳时依然能转动。

### 5. 化妆品小样副业实操（现在依然可做）

- **信息源**：品牌 H5 / 大众点评 / 品牌 App / 地铁小样机（品牌为柜台引流留手机号）。
- **供货节奏**：夏推防晒 / 粉底；秋冬推精华 / 面霜 / 粉饼；重大节点集中放量。
- **利润链**：0 元领 → 家庭分掉一部分 → 剩余在西祠 / 闲鱼 / 社区群转卖。
- **稳定性**：客户忠诚度高，阿七 4 年积累的老客不干了还来追单。
- **进阶**：阿七带的学员一年赚 5000-15 万不等，门槛极低。

### 6. 投资的三大战略价值

- **认知反哺主业**：看透商业模式后能与老板"三轮对答"，被技术总监直接夸"公司唯一能做到的科室"。
- **不被迫做短视选择**：副业 + 投资的现金流让你可以拒绝错误的"多一点点工资"的 offer。
- **看透人性 / 世界真相**：think big think long，格局与视野双升。

### 7. 10 万小资金的投资策略（阿七版）

- 先配齐重疾 / 医疗 / 意外三险（人身风险优先转移）。
- 相对集中，不用分散：可转债"上市 3D / 强赎 / 到期博弈"策略——年化 20-30%。
- 不想学 → 直接买**宽基指数**（沪深 300 / 创业板 / 科创 50）。
- 熊市加仓法：上证指数 2950 / 2850 / 2750 / 2650 分别以 **1:2:4:8** 份额买沪深 300——越跌越买摊低成本。
- 3200 点以下（2025Q1 口径）可介入宽基；牛市中后期抛。

### 8. 100 万资金的资产配置模板

- **20% 货币基金**（余额宝 / 招银朝朝盈类）：应急 + 预留买入机会窗口。
- **20% 债券基金 / 储蓄险**：年化 3-7%，作为压舱石。
- **60% 博取超额收益**（可根据风险偏好下调）：
  - **20%** 港美股 / 海外新兴市场 / 美元存款 / 美债；
  - **40%** A 股 / 港股打新 / 可转债打新 / 指数基金。
- **稳的部分**：港股打新 / A 股打新 / 可转债打新 / 可转债——最大回撤 10% 以内，收益 20%+。
- **激进的部分**：行业指数 / 个股——高波动高回报。
- **执行细节**：券商买基金费率约支付宝 1/10，是被普遍忽略的信息差。

### 9. 黄金操盘（2025Q1 口径）

- **两大驱动**：地缘政治避险 + 全球央行去美元化购金（美国 47 州拟将黄金列为法定货币）。
- **观察工具**：直接看**伦敦金价**。
- **中国央行节奏**：24/4 前巨额购入（2300→2800 美元），5-10 月暂停（后回撤至 2250），11 月起再度买入。
- **买点**：金价高位回撤 8-9% 起稳 → 介入。
- **目标位**：3100-3300 美元（国外投行预估）。
- **警告**：不建议为保值买黄金首饰（含品牌溢价）；金条 / 黄金 ETF 更佳。
- 黄金 ETF 优于实物：变现容易 + 无溢价。

### 10. 套利的四层信息差模型

1. **知道 A、B 市场价差**（最浅层 → 一次性红利）。
2. **知道差价的原因**（切入上游 / 源头厂 / 白牌）——拼多多打法。
3. **别人也知道但懒得做**（执行力套利）——阿七 9.9 元 DeepSeek 指令 PDF 卖 1000+ 份。
4. **同时握住 B 端与 C 端**（服务定制 + 生命周期变现）——从卖 9 块到卖 1000/10000 的自然升级。

### 11. 套利真实案例

- **京东家政券**：买洗护送 2 小时家政 → 闲鱼卖 40 元；量大可代收其他账户货源。
- **飞天茅台抽奖**：多号 + 多平台 + 秒表悬浮 + 放量地址情报 → 一年 ~15 万套利。
- **网下打新债** 21 年：短时窗口筹 600 万现金流（详见"个人影响力"章节）。
- **闲鱼低价复用**：MacBook 教育优惠券 3600 折扣 / 肯德基 / 棒约翰 / 海底捞券。

### 12. 个人影响力 vs 个人 IP

- **个人 IP** = 自媒体上呈现的形象、故事、标签、产品，是**局部**。
- **个人影响力** = **加上**日常生活 / 工作 / 亲友对你的评价、口碑、可信度——**整体的 reputation**。
- 场景 1：阿七空降运营总监 → 靠帮邻部门解题、下午茶、不推锅 → HR 背调 20 人一致好评，关键词"靠谱 + 扛责任"。
- 场景 2：网下打新债一天筹 600 万现金流 → 助理 / 学员 / 朋友几十万几万各出一部分——**融资能力 = 个人影响力的显化**。
- 场景 3：小富婆星球学员续费到 2027 年（人为封顶，否则续到 2030-2035）——信任变现最直接的形态。

### 13. 面对市场"黑天鹅"的心态

- 2018 年中兴通讯被制裁停牌，复牌后 10 连跌停亏 50-60%——阿七的答案是接受"黑天鹅不可避免"，把重心放在**长期系统**而非单笔操盘。
- **口诀**：无法平息风浪，但可以学会冲浪。

### 14. 富人 vs 穷人的现金流结构

- **穷人**：工资 → 消费（死循环、无正向复利）。
- **富人**：资产 → 资产收益 → 消费（收益养生活，本金持续增值）。
- 阿七实操：投资赚到的钱不落地消费，全部滚入下一批赚钱效应最强的资产池（每阶段主赛道不同：20 中概/港科 → 21-22 可转债+蓝筹 → 25Q1 AI/芯片+黄金）。

## 关键问答

### Q1：为什么副业是自由公式里最重要的一环？

三个理由：① 副业技能反哺主业增长；② 让你有底气拒绝错误 offer / 不做短视选择；③ 副业几乎都从"兴趣所向"起步，帮你找到值得做一辈子的方向。

### Q2：我要有 10 万才去学投资吗？

反过来。**越少钱越早学**——试错成本低，1 万全亏也就 1 万；1000 万时才折腾 50%，那是 500 万，赚回来极难。市场学费该交的都得交，钱少时交更便宜。

### Q3：波动 = 风险吗？

**不等于。**波动是资产价格的中性属性，风险是"你的人性 + 认知"。同一份股票，对懂的人是可控风险，对不懂的人是巨大风险。

### Q4：套利和黄牛是一回事吗？

黄牛是套利的一种（A/B 市场倒卖）。更完整的套利定义是"最小成本 + 短期确定性收入"，包括新股新债的破发套利、宽渠道信息差、京东家政券转卖等。

### Q5：我不做博主，个人影响力跟我有关系吗？

有。**别人怎么描述你，就是你的个人影响力。**同事口中"靠谱扛责任"、朋友介绍时"很会搞钱"、亲戚谈及时"靠得住"，都是。个人 IP 只是显性输出的一角。

### Q6：25Q1 普通人可以配什么？

宽基（沪深 300 / 创业板 / 科创 50）+ 可转债 + 黄金 ETF 是相对稳的三块；港股科技 + A 股 AI/ 芯片是弹性方向；打新债 / 打新股是接近零风险的稳定加分项。

## 可复用方法

### A. 自由人生公式落地清单

对照阿七 5 个模块给自己做一次年度对齐：
1. 主业：本年最想沉淀的可迁移能力是什么？（1 条）
2. 副业：本年选 1 个匹配"自己需求 + 兴趣"的方向，季度节奏投入。
3. 投资：≥ 1 个学习月投入（可转债 / 宽基 / 打新任一入门）。
4. 套利：≥ 3 次"最小成本换确定性收入"的动作。
5. 个人影响力：本年争取 3 位可信推荐人愿意用一句话描述你。

### B. 副业选题法（利己—利他闭环）

1. 列出自己过去半年反复搜索 / 花钱解决的 3 个真实需求。
2. 从中选 1 个自己已找到解决方案的问题。
3. 把解决方案打包成产品（信息 / 服务 / 商品）。
4. 定位同类人群（同痛点体感强 = 精准）。
5. 用最轻的渠道试卖（闲鱼 / 小红书 / 社群 / 朋友圈）。
6. 达到稳定后再考虑标准化 / 上游化。

### C. 10 万小资金"傻瓜稳态包"

- 三险打底（重疾 + 医疗 + 意外）。
- 60-80% 宽基指数（沪深 300 / 创业板 / 科创 50）在 3200 点以下分批介入。
- 20-40% 可转债策略池（3D / 强赎 / 到期博弈），有余力再学 A 股打新。
- 熊市按 1:2:4:8 加仓法（2950 / 2850 / 2750 / 2650）。

### D. 100 万资金三段配置

- **20% 流动性**（货币基金） / **20% 压舱石**（债基 / 储蓄险 3-7%） / **60% 博超额**：
  - 20% 港美股 / 美元 / 美债 / 新兴市场；
  - 40% A 股 + 港股 + 可转债，含打新债 + 打新股 + 指数。
- 定期（季度）再平衡；每年至少读一次全球央行黄金 / 汇率 / 利率动向。

### E. 阿七版套利检查表（每周做一次）

- 京东 / 拼多多 / 抖音 / 天猫 / 闲鱼是否有可转卖资源？
- 品牌小样 / 化妆品官方推广 H5 是否放量？
- 打新债 / 打新股本周有几只？破发概率？
- 是否有可搭桥的"资源 A ↔ 需求 B"居间机会？
- 是否可以做"9.9 元执行力型信息差产品"？

### F. 个人影响力四类信托建设

1. **专业信托**：在一个专业标签下持续可见（如"很会搞钱"）。
2. **靠谱信托**：不推锅、扛责、及时反馈——同事级口碑。
3. **利他信托**：主动帮邻居部门 / 同行解题，不谈短期回报。
4. **兑现信托**：说到做到；对学员 / 客户的承诺一件不掉。
- 一年做一次"20 人背调想象练习"：假如 HR 现在去问 20 个人对我的评价，Top 3 关键词会是什么？

### G. 熊市加仓 1:2:4:8 法（阿七版）

- 以上证指数为锚，设四道台阶（例：2950 / 2850 / 2750 / 2650）。
- 每破一道台阶，加仓额度按 1、2、4、8 倍递增，摊薄成本。
- 需事先备好足额现金流（配合 20% 流动性仓位使用）。
- 强纪律：不看情绪、不看短期新闻，只看点位触发。
