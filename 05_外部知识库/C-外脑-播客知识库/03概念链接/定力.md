# 定力

## 一句话

有所为有所不为，控制自己这颗心——膨胀时收住，悲观时保持长期思考，在高频世界中主动降低自己的信息处理频率。

## 定义

定力是张津剑提出「生命力四维度模型」（[[02方法流程/生命力四维度评估模型]]）的第二个维度。不只是一种性格特质，而是一种可训练的「降频」能力——在高频世界中主动把自身频率降到和长期核心问题相匹配的水平。

**三个核心场景**：

1. **膨胀时的定力**：当聚光灯打下来、无数人捧着你、所有指标都是向上的——那一丝内心的骄傲和自豪，你能不能收住？张津剑举了一个唐朝和尚的故事：给几万众生讲完佛法后，众生起立鼓掌，他感受到一丝骄傲，下一秒所有神通都消失了。创业者在这个时刻最容易把自己搞死。 [归纳] — [[42章经]] 001

2. **悲观时的定力**：当市场下行、所有人都说没路了、过去的成功方法论不 work——你能不能不被这种悲观吞噬，保持长期思考？张津剑说「悲观是一种带着过去的 burden 上路」——你带着过去所有的方法论和荣耀，看上去是荣耀，其实全是 burden。 [归纳] — [[42章经]] 001

3. **高频世界中的定力（022 新增）**：定力不是一天做十件事，而是十年坚持做一件事。有定力的人是一个比没有定力的人频率更低的人——频率更低，能耗更低，穿透力更强。面对世界频率跃迁（AI 会让世界频率再拉高一量级），创业者的选择不是更快更敏感，而是更定：回到产业最核心的问题和自身最核心的能力上。 [归纳] — [[42章经]] 022

## 定力的新维度：注意力管理（043 补充）

在 043 集中，张津剑从注意力角度重新阐释了定力：

- 定力本质上是注意力管理能力——在信息过载时代，能否保护自己的注意力不被外部牵引
- 注意力的本质是基于目的：你关注什么取决于你到底要什么。很多人不敢承认自己的真实目标（如想赚钱），于是注意力被虚假目标牵引
- 「抓重点取决于目的，没有绝对的重点」——目的越清晰，注意力越聚焦，能耗越低
- 培养定力的关键是重建自己的注意力机制：先丢掉大家都在关注的地方，再看哪些是你真正喜欢和有审美的 [归纳] — [[42章经]] 043

## 为什么很多人没有定力

张津剑的诊断：因为「活在过去」。美元基金投了那么多千亿美金项目，为什么今天很多东西不 work？因为那是过去。你今天创业不成功，不是因为你不够努力，是因为你带着过去的方法论在做今天的事。 [归纳] — [[42章经]] 001

022 进一步补充：世界频率跃迁后，大多数人依赖别人的行动而不是自己的感知——不再问「你怎么看趋势和逻辑」，而是直接问「你买了什么」。这种偷懒导致热点自我增强（反馈啸叫），真实机会无人问津。有定力的人抵御了这种偷懒。 [归纳] — [[42章经]] 022

## 与相近概念的区别

| | 定力 | 自我净化 |
|---|---|---|
| 场景 | 外部环境剧烈波动时 | 旧方法论失效时 |
| 行为 | 控制心不动摇，降低自身频率 | 放下 ego，放弃旧路径 |
| 方向 | 保持（不被外在动摇） | 放弃（不被自己绑架） |

定力是「不被外界动摇」，自我净化是「不被自己绑架」。两者互补。

| | 定力 | 注意力 |
|---|---|---|
| 关系 | 定力需要注意力来维持 | 注意力是定力的工具——有定力的人更会管理注意力 |
| 场景 | 应用于长期坚持 | 应用于信息筛选和决策 |
| 来源 | 心力的产物 | 认知的资源 |

定力是目的，注意力是手段。
