# 流量入股三个陷阱

## 一句话
MCN / IP / 达人合伙谈判里最诱人的诱饵是"以流量入股当合伙人"——听起来诱人，但**流量是最容易被稀释的股份**。三个致命陷阱：**估值虚（无第三方定价）· 退出难（无变现渠道）· 主动权丧失（法律责任被绑定）**。更稳的替代方案 = **保底工资 + 项目分成（10-30%）+ 期权（3-5%，4 年 vesting）**。

## 为什么需要这个概念
015 集 MCN 商务被达人邀请以流量入股当合伙人，斯斯给出**《富女孩》体系里第一次系统拆解"流量入股"这种合伙形式**。这种合伙比 VC 期权、股权融资更常见于 IP/MCN/自媒体行业——但也是所有合伙形式里**最不稳的**：流量随平台波动、账户估值无第三方基准、股东责任捆绑法律风险。这条 stub 是 IP 时代必读的**合伙人谈判护身符**。

## 定义
- **陷阱 1 · 估值虚**：达人可能给你的账号估值 500 万，但**没有第三方定价机制** → 你手里的股份纸面价值可信度极低
- **陷阱 2 · 退出难**：流量今天 100 万、明天平台限流一文不值 → **退出时如何变现？** 找不到接盘方
- **陷阱 3 · 主动权丧失/法律责任绑定**：一旦你是股东，公司出问题（虚假宣传、平台封号、税务）你要一起承担 —— **上限没保障，下限敞开**
- **更稳方案 · 保底+分成+期权三件套**：
  - **保底工资**：不低于当前收入的月薪 → 现金流保障
  - **项目分成**：10-30%，按具体项目/客户/收入抽 → 看得见摸得着
  - **期权/虚拟股**：3-5%，分 4 年归属（vesting） → 长期上行留住你也保护你
- **谈判心法**：**你不是在要东西，你是在交换** —— 先列清单（他真正需要你带来什么）、再算价值（你贡献占毛利多少）、最后要对等回报
