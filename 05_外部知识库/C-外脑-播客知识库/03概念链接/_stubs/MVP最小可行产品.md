# MVP最小可行产品

## 一句话

MVP 是用最小可行产品验证一个真实问题：先拿到用户、消费和正反馈，再决定是否继续迭代。

## 016 集语境

杨涛把 MVP 用在 App、小程序、网站、电商、社群、知识付费、课程和微信群中。它反对早期大而全，强调先解决一个最小问题。

## 判断标准

- 是否只验证一个核心需求？
- 是否能让用户真实使用或付费？
- 是否能产生正反馈、复购、转介绍或改进线索？
- 是否避免了过度自研和过度完美主义？
