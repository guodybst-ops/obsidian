# Maker-User-Designer 三角关系

## 一句话

工业时代之前，做东西的人和用东西的人是同一个人；工业化让他们分离；现代设计又让 designer 成为独立角色。AI 时代这个三角会被重组——服务可能更精准地面向单个用户，而非抽象画像。

## 定义

范皓宇在英国设计博物馆看到 maker、user、designer 三个词循环出现，由此产生这个框架：

- **Maker（制造者）**：把东西做出来的人。早期和 user 是同一个人。
- **User（使用者）**：使用东西的人。工业化后被从 maker 中分离出来。
- **Designer（设计师）**：为 user 设计、指导 maker 生产的人。现代设计专业的产物。

三者关系不断演化：
- **第一段**：m/u/d 是同一个人（手工业时代，自己做的自己用）
- **第二段**：maker ≠ user（工业化，批量生产给不知道的人用）
- **第三段**：designer 独立（设计专业诞生，为一类 user 找最大公约数）
- **第四段（AI 时代）**：可能出现新的代理角色——用户专属的连接者、协作者和代理人

## 为什么需要这个概念

多数产品人只关注 user 端，但范皓宇提醒：产品设计的本质是在 maker（生产/成本/技术）、user（需求/体验/情感）和 designer（判断/品味/压缩）三者之间「既要又要也要」。AI 时代可能消解传统 designer 角色——因为服务可精准面向单个用户，不再需要为「一类用户」找最大公约数。

## 辨析

- vs **用户中心设计**：用户中心设计强调 user 端。Maker-User-Designer 强调三端平衡。
- 关联概念：[[有用 vs 有趣]]——maker 关注有用，designer 关注有趣，user 两者都需要。
- AI 时代的推论：可能出现一个 AI agent 角色，既是用户的专属代理人（代理 user），也是服务提供方的接口（代理 maker），取代传统设计为群体找最大公约数的角色。
