# 能力溢出

## 一句话

大厂给你的**超高溢价**买的不是某一项技能，是**"把你扔到哪个孤岛都能快速建立政权"的能力集**——项目管理、沟通协调、资源调度、复杂问题拆解、情商 / 抗压 / 学习速度全套打包。**副业 = 这套能力集在公司平台上装不下，溢出到外部**——溢出之前搞副业，只是拿短板换钱。

## 为什么需要这个概念

- 解释了为什么"大厂 P7 出来做副业"比"县城公务员做副业"轻松——不是聪明，是**能力集溢出**
- 解释了 35 岁焦虑打工人"该深耕还是搞副业"——**答案取决于能力是否已经溢出**，没溢出的先补短板
- 解释了乔布斯范式"科技 × 艺术"为什么值钱——**交叉领域的能力集溢出比单点 Top 更稀缺**
- 破除"我会 PS/写作/剪辑"就能做副业的幻觉——**单点技能不是能力集**

## 定义

- **能力集（capability suite）**：一个人身上多项能力的稳定组合，不是单点技能，能扛得住新环境的挑战
- **能力溢出**：你能操盘 1000 万的案子，但公司只给你 300 万的项目——中间那 700 万的能力就是溢出，可以对外变现
- **判据**："扔到一个孤岛，你能不能快速建立政权？"——建不起来说明能力集还不完整

## 大厂给的能力集 = 五件套

| 能力 | 具体 |
|---|---|
| 项目管理 | 拆项目、排优先级、做甘特图、写周报 |
| 沟通协调 | 跨部门 / 跨层级 / 甲乙方 |
| 资源调度 | 争取好线索、争取延期、找到关键人 |
| 复杂问题拆解 | 把一个模糊需求拆到可执行的最小单元 |
| 抗压 / 情商 / 学习速度 | 三件底层软实力 |

**关键判据**：**副业收入 > 主业时**才叫"能力已经溢出"；此前的副业收入都是"用主业的边角料换钱"，不是资产。
