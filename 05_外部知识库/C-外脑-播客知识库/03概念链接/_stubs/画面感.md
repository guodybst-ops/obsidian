# 画面感

## 一句话

画面感是把想要的终局、现状落差、资源拼图和进度条看清楚的能力。

## 构成

| 构成 | 含义 |
|---|---|
| 终局画面 | 能用数字、时间、场景和状态描述理想生活或业务结果 |
| 进度条 | 知道什么阶段做什么、做到什么程度 |
| 拼图 | 知道需要凑齐哪些要素 |
| 场景 | 能想象人在现场如何行动 |
| 提问 | 能问出缺哪块、卡在哪、下一步是什么 |

## 在创业里的表现

一件事要跑通，通常要把这些拼图看清：

- 流量。
- 产品。
- 渠道。
- 供应链。
- 资金。
- 团队。
- 转化。
- 交付。
