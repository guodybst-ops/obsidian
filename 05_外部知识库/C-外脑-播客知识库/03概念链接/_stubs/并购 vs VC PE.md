# 并购 vs VC/PE

## 一句话

VC/PE 是少数股权投资，投资人坐在副驾驶支持创始人实现梦想；并购基金是控制权投资，投资人要以东家身份对企业最终负责。两者在风险偏好、回报模型、工作方式和组织意义上截然不同。

## 定义

- **VC/PE（少数股权投资）**：买入 5%-20% 股份，企业仍由创始人驾驶。投资人有优先股、回购、清算优先等保护，靠少数项目的高倍回报覆盖风险。
- **并购（控制权投资）**：买入超过 51% 股权或取得实际控制权。投资人任命管理层、决定战略和退出时机，赔率低但概率高、单笔金额大。

## 为什么需要这个区分

很多人用 VC 的思维理解并购，以为并购就是"更便宜的 PE"。立阳认为两者是两种不同的生意模型：VC 是「押注梦想」的赔率游戏，并购是「经营生意」的工程。

## 辨析

| 维度 | VC/PE | 并购基金 |
|---|---|---|
| 控制权 | 少数股权，创始人主导 | 控制权，基金最终负责 |
| 回报模型 | 高赔率、低概率 | 低赔率（2-3 倍）、高概率 |
| 单笔资金 | 相对小（几百万到几千万） | 大（数亿到数十亿美金） |
| 工作方式 | 看赛道、看人、下注 | 看现金流、算杠杆、调资本结构 |
| 投后角色 | 副驾驶：建议、资源、偶尔救火 | 东家：战略、治理、激励、退出 |
| 风险保护 | 优先股、回购、清算优先 | 买的是控制权，不行就是不行 |

- vs **企业并购 vs 基金并购**：企业并购看业务协同（补市场/品类/能力），基金并购看财务回报。
- 核心公式：并购 = 通过改变生产关系，解放生产力（股东结构变化 → 决策机制变化 → 管理层行为变化 → 企业效率提升）
