# 菜鸡互卓局

## 一句话
大神已经跑了、剩下的都是差不多水平的人在互相消耗的**停滞局**——这个时候好的生存策略不是跳，是**"卓完"**：闭环项目 + 抱助理/leader 大腿 + 手抄财富与社交名课。**停滞局是命运的保护**——外部环境不给你大项目，其实是保护你在能力没到位时不被祭天。

## 为什么需要这个概念
010 与 014 集的大厂 AI 产品经理连续两次上麦，斯斯反复强调：**判断自己现在是顺风局、逆风局还是停滞局**是所有职场决策的前置动作。停滞时最容易做的错事是"跳出去找机会"——但换个公司、新关系、能力没真提升 → 直接祭天。停滞时要做的是"卓完"——把自己修好，等真的大机会来时才上得了桌。

## 定义
- **三种局面**：
  - **顺风局**：环境好 + 自己也棒 → 被抬着走
  - **停滞局**：大神跑了 + 你也没到位 → 命运不给你大项目
  - **逆风局**：换厂/换项目/换关系 → 从头再来 + 无根基
- **停滞局的三件事（卓完）**：
  1. **闭环项目**：让简历上有可包装的东西——不是"出圈"，是"我和 CEO 一起搞了这个小事儿"
  2. **抱助理/leader 大腿**：主动自荐、别拒橄榄枝、修 GR 面
  3. **修情商**：手抄名课 + 让身边有高情商榜样 + 主动使用
- **关键判据**：**"什么时候都不能这时候跳"**——项目 cycle 没跑完、简历不完整、你的价值没兑现
