# 世界模型

## 一句话

AI Agent 真正缺的不是更大的语言模型，而是一个能够理解物理世界和业务运作规律的「世界模型」——预训练大模型是「文科生」，只能从文本语料里学经验，无法获取语言之外的真实世界知识。

## 为什么需要这个概念

当前 AI Agent 落地受阻，很多人归因于模型不够大或工程不够好。但周健指出，真正的瓶颈是架构性的——预训练模型只能从语料里学经验，而世界上的大量知识（如数值经验、物理规律、业务流程中的隐知识）无法通过文本获取。提出「世界模型」这个概念，是为了指出 AI Agent 必须补上这个结构性缺失。

## 定义

周健的核心论断：

1. **预训练模型是「文科生」**：只能从文本和视频中学习，但「你只通过文本和视频是学不会游泳的」。
2. **世界模型缺失的具体表现**：企业内部的数值经验（如「武汉地区 Java 工程师薪酬空间是多少」）预训练大模型解决不了——这是大数据和统计知识，不是语言知识。
3. **Agent 需要两样东西**：
   - 环境感知：能感知数据变更、文档替换、流程变化，作为上下文
   - 跟传统数值大数据结合：让 Agent 既能读文本也能调数值经验

## 辨析

- vs **大语言模型**：大语言模型解决语言理解和生成，世界模型解决真实世界的物理/业务/数值规律理解。前者像文科生，后者像理科生。两者需要结合才能做出真智能 Agent。
- vs **具身智能**：具身智能是在物理世界行动的 AI（机器人），需要世界模型；但世界模型不限于具身智能——即使纯信息化的 Agent（如 HR Agent、财务 Agent）也需要世界模型来理解业务数值和流程。
- 关联概念：LeCun 也认为 Transformer 不是通向 AGI 的路径，需要世界模型。
