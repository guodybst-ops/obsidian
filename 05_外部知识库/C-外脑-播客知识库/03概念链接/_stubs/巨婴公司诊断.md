# 巨婴公司诊断

## 一句话

**把广告收入抽掉，公司持续亏钱 = 巨婴公司**。靠广告和流量养活主业 → 广告一断就崩 → 单位经济模型（unit economics）不成立。

## 定义

斯斯在跟醉鹅娘对谈时的诊断框架：

- **健康公司**：主业本身赚钱，广告收入是锦上添花
- **巨婴公司**：主业本身亏钱，广告收入填补主业 → 广告依赖 → 广告市场波动 = 公司死亡风险

## 诊断步骤

1. 拉出财务报表
2. 把"广告 / 品牌合作 / 流量收入"这条线**归零**
3. 看剩下的业务是否还能覆盖成本
4. 不能覆盖 = 巨婴公司

## 案例：醉鹅娘公司

- 醉鹅娘公司主业：红酒销售
- 广告收入：接品牌种草 + 抖音直播分成
- 抽掉广告后：主业**持续亏损**（毛利低 + 复购低 + 获客高，[[品类三角]]全糟）
- 结论：巨婴公司 → 靠广告持续输血 → 广告市场变冷 = 债务爆炸

## 辨析

- vs **unit economics 单元经济不成立**：本条更通俗，指整个公司层面而非单个客户层面
- vs **交叉补贴**：交叉补贴是主动策略（用赚钱业务养战略业务）；巨婴是被动依赖
