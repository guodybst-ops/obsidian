# TCO 总体拥有成本

## 一句话

TCO（Total Cost of Ownership，总体拥有成本）不是只看买入价格，而是计算一个生产要素在完整生命周期里的真实成本，包括折旧、维修、效率、残值、替代方案、时间和心力消耗。

## 定义

在 012 集语境中，TCO 用来提醒创业者：设备、工具、办公用品、系统、员工岗位和资源选择，都不能只看“买它花多少钱”，还要看“拥有和使用它到底花掉多少”。

## 成本构成

| 成本项 | 解释 | 012 集例子 |
|---|---|---|
| 买入成本 | 初始购买、部署或启用成本 | 锅炉、电脑、办公设备 |
| 折旧成本 | 使用过程中价值下降 | 设备年限、残值 |
| 维修成本 | 维护、故障、停机和更换 | 锅炉维修、设备维护 |
| 效率成本 | 不同工具带来的工作效率差异 | 苹果电脑 vs Windows 电脑 |
| 替代成本 | 租赁、外包、共享等替代方案 | 租赁办公设备 |
| 心力成本 | 管理、处理、担心和协调带来的精神消耗 | 自己持有设备带来的心力加成 |
| 机会成本 | 同样的钱和时间可以投入哪里 | 是否占用更高价值动作 |

## 使用方法

做决策前问四个问题：

1. 买入价之外，长期折旧、维修和效率成本是多少？
2. 如果租赁、外包或借用，成本结构会不会更好？
3. 它会节省我的时间和心力，还是制造更多管理负担？
4. 它在业务链路里能否创造高于 TCO 的回报？

只有显性成本低，不代表真实成本低；只有买得起，也不代表值得拥有。

## 辨析

- vs 表面价格：表面价格只看一次性支出，TCO 看完整生命周期。
- vs ROI：ROI 是回报比，TCO 是计算回报前要先弄清楚的总成本。
- vs 沉没成本：沉没成本是已经发生且不可回收的成本，TCO 更偏向决策前和决策中的完整预估。
