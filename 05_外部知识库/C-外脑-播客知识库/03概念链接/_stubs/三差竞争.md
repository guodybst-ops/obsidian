# 三差竞争

## 一句话

**"这个市场上先赚认知差的钱，然后赚信息差的钱，然后赚执行差的钱，最后拼资源差。"** 一个赛道随着时间推移，竞争维度会按四个阶段依次下移，越到后期越拼真金白银的产业资源。

## 为什么需要这个概念

创业者常常错判自己所在赛道的**当前竞争阶段**：把一个已经拼资源的成熟赛道，当作还能"讲个新故事就能赢"的认知差阶段来打；或者一头扎进已经拼执行差的红海，却以为自己占了信息差便宜。**看清楚"这个市场现在拼的是哪个差"，比选择赛道更重要。**

## 四阶段定义

```
时间 →
[认知差] → [信息差] → [执行差] → [资源差]
最舒服            最卷            最难
```

### 阶段 1：认知差（早期，最舒服的钱）

- **谁能看见**：只有极少数人能看到某个新趋势/新机会
- **怎么赚**：把新认知讲给大众听——**"你比别人早看见 3 年。"**
- **典型场景**：AI 早期讲 GPT、私域早期讲社群、直播早期讲达人矩阵
- **窗口期**：6-18 个月

### 阶段 2：信息差（红利期）

- **谁能看见**：认知已扩散，但**具体操作路径**还不透明
- **怎么赚**：卖"How To"——课程、方法论、SOP、案例拆解
- **典型场景**：私域运营 2020-2022，短视频 2019-2021
- **窗口期**：1-3 年

### 阶段 3：执行差（红海期）

- **谁能看见**：路径完全公开，人人都知道怎么做
- **怎么赚**：拼团队、拼流程、拼精细化、拼节奏
- **典型场景**：抖音电商 2022 至今，公众号中后期
- **窗口期**：3-5 年，拼耐力

### 阶段 4：资源差（成熟期）

- **谁能看见**：连执行差都被拉平，进入资源门槛竞争
- **怎么赚**：拼资金、拼渠道、拼供应链、拼牌照、拼产业资源
- **典型场景**：传统消费品、成熟 SaaS、地产
- **窗口期**：进入者需要**真金白银的产业资本**

## 三个直接推论

1. **早期赚的是差价，晚期赚的是资源**——个人能力天花板在执行差，资源差需要产业结盟
2. **同一个赛道，不同阶段需要不同的人**——早期是敢闯的先知，中期是勤奋的操盘手，后期是有钱的资本
3. **卡位判断的核心问题**：**"我现在做的这件事，市场处于哪个阶段？我的优势匹配这个阶段吗？"**

## 辨析

- vs **降维打击**：降维打击是"用高维认知碾压低维执行"，属于**跨阶段套利**
- vs **红利期**：红利期是"信息差 → 执行差"的中段窗口
- vs **市场周期**：市场周期是**产品视角**，三差是**竞争维度视角**

## 概念关系

- 与 [[IP中介本质]] 相关：IP 的价值随三差演进递减——早期 IP 卖认知，后期 IP 只能绑产业
- 与 [[边缘发起创新]] 相关：新的三差循环总是从边缘开始
- 与 [[知识付费已死]] 因果：知识付费是**信息差红利的副产品**，信息差消失，知识付费就死

## 应用启发

- **自我审计**：写下"我现在赚的钱主要靠哪个差？" — 认知差 3-4 个月过期，要主动挪窝
- **合伙人配置**：早期期需要"先知型"合伙人，中期需要"运营型"合伙人，后期需要"资本型"合伙人
- **判断赛道**：新赛道优先看"是否还处在认知差 → 信息差阶段"，成熟赛道优先看"我有没有资源差层面的护城河"
