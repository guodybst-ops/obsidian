# [对比] 传统 chatbot 黑盒记忆 vs Cursor 白盒精准调取

## 一句话

传统 chatbot 黑盒记忆 和 Cursor 白盒精准调取 的区别，关键在适用场景、判断信号和行动后果。

## 各自定义（简版）

**传统 chatbot 黑盒记忆**：第 044 集中被强调的一侧，用来说明一种选择、姿态或判断方式。

**Cursor 白盒精准调取**：与 传统 chatbot 黑盒记忆 相对的一侧，用来帮助读者避免把两个概念混为一谈。

## 对比表

| 维度 | 传统 chatbot 黑盒记忆 | Cursor 白盒精准调取 |
|---|---|---|
| 定义 | 更接近本集主张的一侧 | 更接近需要被辨析的一侧 |
| 适用场景 | 对象、价值、时机较清楚时 | 信息不足或容易误判时 |
| 行动后果 | 导向具体选择或动作 | 提醒补信息或重新判断 |

## 什么时候选 传统 chatbot 黑盒记忆 / 选 Cursor 白盒精准调取

**选 传统 chatbot 黑盒记忆 的信号**：
- 你能说清对象是谁。
- 你能说清为什么这一侧更能解释本集案例。

**选 Cursor 白盒精准调取 的信号**：
- 你发现自己把两个词混着用。
- 你还没有足够证据支持 传统 chatbot 黑盒记忆。
