# [概念] IP vs 产品

## 一句话
产品卖功能和参数，IP 卖人的专业、情感和信任。

## 为什么需要这个概念

专家型创业者常把“做 IP”误解成“给产品做宣传”。文成在 002 集中把 IP 与产品分开：IP 的核心载体是人，能承载情感、价值观、长期信任和不可复制性。

## 定义

产品通常以功能、参数、价格和交付物为核心；IP 则以人的经验、审美、判断、价值观和持续表达为核心。产品容易被复制和替换，IP 的壁垒来自用户和这个人的长期关系。

这并不意味着 IP 不需要产品。更准确地说，IP 是产品溢价和信任转化的上层杠杆；没有真实产品或服务承接，IP 会变成空壳。

## 辨析

- vs **品牌**：品牌可以是组织资产，IP 更强绑定具体的人。
- vs **流量账号**：流量账号只解决曝光，IP 要解决信任和成交。
- vs **产品宣传**：产品宣传围绕卖点，IP 建设围绕人的长期可信度。
