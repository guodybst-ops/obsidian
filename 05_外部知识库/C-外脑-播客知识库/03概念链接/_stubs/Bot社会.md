# Bot社会

## 一句话

未来数字世界的基本单位不是「人」或「DAU」，而是大量 bot——它们承担交易、沟通、偏好表达等任务，形成全新的社会结构和基础设施需求。人是 bot 存在的环境，而不是主角。

## 定义

Bot 社会是张津剑对 AI Native 世界的核心想象。它的核心主张是：

1. **原住民迁移**：消费时代的原住民是「人」，移动互联网时代的原住民是「DAU」（对人在特定时空的切分），AI Native 时代的原住民是「bot」
2. **人是环境**：bot 来源于人，但 bot 不是人——就像 DAU 来源于人但不是人。人类是 bot 存在的物理环境，而不是数字世界的直接参与者
3. **从应用到协议**：服务 bot 的东西可能不再叫「应用」，而叫「协议」或「价值网络」。因为每个 bot 代表人的一个特定侧面（爱贪小便宜的 bot、严谨交账单的 bot、激进争取利益的 bot），它们需要的是不同层次的基础设施

## 为什么 DAU 不够用了

张津剑的论证链：
- 同一个你需要两个应用（携程和美团），是因为你产生了两个不同时空的 DAU
- 移动互联网的革新本质是把「人」切割成了「此情此景中的你」
- AI Native 的革新是把这种切割推到极限：你被切成 100 个 bot，每个 bot 代表你一个特定侧面
- 100 个 bot 之间可能相互矛盾（帮你省钱的 bot vs 帮你抢最后一瓶酒的 bot），它们在你内部就有「内斗」

## 实际案例（红酒购买）

完整的六层推理（详见 [[02方法流程/_stubs/Bot社会六层推理]]）：
1. Bot 在全球帮你找酒 → 2. 越过所有平台直接联系酒庄 → 3. 倒逼酒庄建 bot → 4. Bot 间需要新协议 → 5. Bot 的伦理和边界 → 6. Bot 社会的治理
