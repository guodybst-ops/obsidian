# 比特币是茅台酒不是茅台股票

## 一句话

不要用股票/DCF 思路给比特币估值——它不生息、无现金流、无法折现。比特币是茅台酒本身：总量固定+时间越久价值变化越显著+持有者一直是赢家。把它当家里囤女儿红——1%-5% 流动资产当保险。

## 为什么需要这个概念

传统投资者用股票框架看比特币——"这东西到底是什么公司的股票？它的每股收益是多少？"——这是核心误解。比特币背后没有公司、没有现金流、没有收益，它更像一个商品（黄金/茅台酒）而不是证券。

## 定义

| | 茅台公司股票 | 茅台酒（比特币类比） |
|---|---|---|
| 估值方式 | DCF/PE（可折现未来现金流） | 不适用（无现金流） |
| 价值来源 | 公司经营业绩 | 稀缺性 + 时间 + 共识 |
| 持有方式 | 交易、分红 | 长期囤积 |
| 配置逻辑 | "这家公司值多少钱" | "放 20 年看看会发生什么" |

两个核心假设支撑囤茅台逻辑：
1. **总量固定**：2100 万个，且很多人丢密钥（实际流通量持续下降），通缩性与时间正比
2. **世界唯一**：唯一一个流动性好、转账方便、又是"数字黄金"、又是支付手段的资产

前提假设：如果你长期相信"美元/法币购买力因货币超发和债务危机不断下降"，那比特币跟黄金一样是保险——甚至比黄金更好（可拆分、可全球转账、几分钟到账）。

## 辨析

- vs **DCF 估值框架**：DCF 要求可预测的现金流——比特币没有。两者是不同框架，不能套用。
- vs **黄金**：黄金是实物商品（物理稀缺+工业用途+首饰需求），比特币是数字商品（数学稀缺+抗审查支付+无工业用途）。两者都是"非生息价值储存"。
- 与 [[价值=可被交易的共识]] 的关系：茅台酒共识框架直接解释了比特币的价值来源——来自共识（持有的人相信它值钱）而非现金流。
