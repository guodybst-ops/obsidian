# 高端品牌 = 引领需求

## 一句话

**"什么叫高端品牌?持续在引领需求的、持续在创造用户在需求上的新供给的,就叫高端品牌。"** 不是价格高就叫高端(苹果和小米旗舰机价格并没有差多少);不是包装/代言人做得贵就叫高端。**高端 = 持续引领 = 抄不出来。**

## 为什么需要这个概念

大部分中国品牌做不成高端,是因为老在折腾**包装/价格/代言人/渠道** ——这些都是"抄"能做的事。**"抄本身没问题,但抄很难高端。"** 用户会用你(性价比位),但不会奔走相告,也不会给你溢价。没有这个概念,老板会以为**"把价格调高、请个更贵的代言人"** 就能升级为高端品牌。

## 定义

**高端品牌的两个必要条件:**

1. **持续引领需求** — 不是响应用户已经在说的需求,而是主动创造用户还没有说出来的需求
2. **创造需求侧的新供给** — 提供市场上不存在的新东西,让用户"看到"之后才发现自己想要

**"抄可以填性价比位、降低决策成本,但要溢价必须引领。"**

## 苹果 vs 小米的启示

- 苹果和小米旗舰机**价格并没有差很多**
- 但用户下意识认为苹果是高端 —— 因为苹果**在引领**(iPhone / iPad / Vision Pro 每一代都创造新的产品品类)
- 小米**在抄**(每一代对标苹果 + 各种性价比升级)——所以小米可以卖 8000 块,但很难被叫做高端

## 应用到做 IP

**"如果你认为你要持续做一个高端品牌,对于行业往前的洞察的这份努力你是一定要付的。"**

- 每年跨年花大力气录预测——**没有直接商业回报,但是引领的必要成本**
- 招到的线下课学生**不一定比别人多**——但如果你只靠商标而没有引领性,你就没有品牌溢价

## 反例:美居香水味的启示

- 斯斯观察:住杭州美居时闻到的洗手液味道**跟丽思卡尔顿一模一样**
- **研发这个香味的品牌放在五星酒店,抄它的觉得味道好就用来做超高性价比**
- **"赚钱不代表高端。没有引领是没有办法变成高端品牌的。"**

## 辨析

- vs **贵 = 高端**:贵不等于高端,劳斯莱斯很贵但如果只是硬件贵、没有品牌引领,也可能是"贵的抄"
- vs **奢侈品**:奢侈品是品牌溢价的极致,但奢侈品的溢价基础也是引领(爱马仕引领手工皮具工艺;LV 引领 monogram 图案文化)
- vs **性价比**:性价比是"抄得好"的最高境界,但天花板是明确的——**永远进不了溢价空间**

## 概念关系

- 与 [[边缘发起创新]] 相关:引领意味着做别人不做的事,通常从边缘起步
- 与 [[IP中介本质]] 相关:IP 想成为高端品牌,必须绑定引领性的产业
- 与 [[知识付费已死]] 相关:知识付费 IP 卡在"抄课"层面,无法进入引领,所以无法高端化
- 与 [[生成打败推荐]] 相关:引领性内容打败被动推荐

## 判断一个品牌是否高端(3 问)

1. **它引领了什么?** — 举一个具体例子:创造了什么产品品类 / 用户习惯 / 消费场景
2. **它引领的东西被抄了吗?** — 被抄证明它引领过
3. **它是否还在引领下一波?** — 如果只吃过去引领的红利,已经开始下坠
