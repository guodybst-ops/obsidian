# 内容数字资产

## 一句话

内容数字资产是创作者在全网留下的可搜索、可复用、可分发、可长期获客的内容痕迹。

## 构成

- 全网同名：降低搜索和识别成本。
- 全网分发：同一份内容多平台占位。
- 长尾路口：长期承接搜索流量。
- 素材沉淀：文字、视频、直播、问答、案例和电子书。
- 确定性：内容越多，未来被找到和被信任的概率越高。

## 关键判断

- 内容从生产出来那一秒开始，继续分发的编辑成本接近 0。
- 只发一个平台，是对内容资产的浪费。
- 搜索型内容比短期爆款更容易吃长期长尾。
- 内容可继续转成书、电子书、PDF、课程、社群和客户获取材料。
