# 影响力势能

## 一句话

影响力势能是一个人通过可见度、正面声量、价值输出和信任积累，调动人财物的能力。

## 定义

杨涛在 008 中把影响力定义为调动人、财、物的能力，也是一种用他人乐于接受的方式影响思想、行为和决策的能力。

势能不是静态名声，它会持续消耗。要维持势能，就必须持续做功。

## 构成

| 构成 | 含义 |
|---|---|
| 可见度 | 你在人们视野里的频次和可及度 |
| 正面声量 | 人们提到你时产生的正向联想 |
| 价值输出 | 你持续提供实际价值或情绪价值 |
| 信任 | 前三者转化后的信用纯度和体量 |
| 够用指数 | 你的认知、信息源和判断对目标人群是否“刚好有用” |

## 关键判断

- 信任本身已经接近钱。
- IP 是结果，不是先验目标。
- 做 IP 的真实诉求往往是便宜流量和更轻松转化。
- 转化本身如果提供真实价值，就能从消耗势能变成新的做功。
- 为钱推荐自己不认可的东西，会触发影响力崩坏点。

## 辨析

- vs 粉丝数：粉丝数是显性规模，影响力势能看能否调动人财物。
- vs [[03概念链接/_stubs/结构洞]]：结构洞看你处在什么连接位置；影响力势能看你在位置里有多少分量。
- vs 品牌：品牌是更大范围的认知资产；个人影响力可以在较小圈层里先成立。
- vs [[03概念链接/_stubs/流量驱动商业模式]]：流量驱动偏获取注意力，影响力势能偏把注意力转成信任。
