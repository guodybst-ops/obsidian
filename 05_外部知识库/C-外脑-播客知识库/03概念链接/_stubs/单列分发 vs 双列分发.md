# 单列分发 vs 双列分发

## 一句话

单列全屏上滑追求消费效率和快速泛化，双列封面选择追求社区公平和中长尾生态。分发容器不是 UI 选择，而是决定平台天花板和生态结构的战略选择。

## 定义

- **单列分发**：用户看到全屏内容，不需要选择，上滑即可继续消费。代表：抖音、TikTok。
- **双列分发**：用户看到内容封面缩略图，需要主动选择点开观看。代表：快手早期、小红书、B 站（部分）。

## 为什么需要这个概念

很多产品团队在选分发方式时只看短期转化数据，忽略了分发容器对创作者生态、用户心智和内容供给结构的长期塑造。于北川强调：AB test 可以测消费行为变化，但测不出新创作者是否愿意来、6 个月后用户是否还把平台当社区。

## 辨析

| 维度 | 单列 | 双列 |
|---|---|---|
| 消费效率 | 极高，适合碎片时间 | 中低，需要主动选择 |
| 创作者公平 | 头部更占优 | 中长尾获得更多曝光 |
| 商业化 | 广告可自然插入 | 广告打断感更强 |
| 泛化能力 | 容易泛化到新内容类型 | 需要更强的社区引导 |
| 适合内容 | 短视频、娱乐 | 图文、攻略、深度视频 |
| 用户心智 | "打开就刷" | "打开再看看" |

- vs 长视频平台的分发逻辑（B 站）：既用双列推荐也用单列竖屏，混合策略可能兼顾两类内容
