# 行为改变付费

## 一句话

行为改变付费卖的不是知识本身，而是用户想让自己发生改变的愿望和环境。

## 定义

在 010 的语境里，知识付费的升华版是行为改变付费。用户付钱，不只是为了知道某个知识点，而是为了让自己跑步、背单词、减肥、读书、打卡、行动或完成某种改变。

## 典型形态

| 形态 | 用户买的是什么 |
|---|---|
| 跑步群 | 监督、氛围、路径截图、装备建议、退款承诺 |
| 读书会 | 立 flag、群体认同、书单、陪伴、低门槛进入 |
| 减肥营 | 打卡、反馈、同伴压力、结果想象 |
| 背单词/学习营 | 计划、提醒、完成感、持续性 |
| 副业训练营 | 任务拆解、作业、点评、案例和转化路径 |

## 关键机制

- 用户在立 flag 时，会高估自己的执行力。
- 群体里别人晒成果，会形成持续刺激。
- 交互、提醒和 push 让用户感到有人在看见自己。
- 即使没有完全坚持下来，用户仍可能因为愿望未完成而继续付费。
- 最终卖的是环境、监督、身份和改变期待。
- 060 补充了减肥监督类训练营的社群运营逻辑：用户坚持率低时，要用打卡、反馈、红包、真实案例、问题互动和前端流量基数来提高行动氛围。

## 辨析

- vs 普通知识付费：普通知识付费偏“知道”；行为改变付费偏“做到”。
- vs [[02方法流程/_stubs/平民创业手册/[SOP] 卖课就是卖海报知识付费法]]：卖课海报解决购买第一关，行为改变付费解决为什么用户愿意持续留在交付场。
- vs [[03概念链接/_stubs/价值创造 vs 出卖时间]]：行为改变付费把单次讲课转成可复用的环境和机制。

## 风险边界

- 不能只利用用户立 flag 心理，却不提供真实监督、内容和反馈。
- 涉及健康、运动、减肥时，需要明确安全边界，不能做医疗承诺。
- 退款承诺、打卡规则和奖励机制必须清楚，避免后续争议。
