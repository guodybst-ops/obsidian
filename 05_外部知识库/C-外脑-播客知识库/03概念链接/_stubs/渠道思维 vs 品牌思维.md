# 渠道思维 vs 品牌思维

## 一句话

**渠道**做多 SKU + 加法 + 比同类便宜 + 良心商人；**品牌**做少 SKU + 心智占位 + 高毛利支撑上下游一起赚钱。**假装做品牌其实在做渠道 = 醉鹅娘 12 年亏出 5600 万的最痛认知**。

## 定义

醉鹅娘经曾明教授（湖畔）点拨后的反思框架：

### 渠道思维
- 多 SKU：什么都卖一点，靠丰富度做流量
- **加法**：每年新增品类线
- 对标：**我要比同类便宜**
- 用户评价："良心商人"
- 结果：**低毛利 → 无法养品牌 → 变成流量搬运工**

### 品牌思维
- 少 SKU：一件事做到心智占位
- **减法**：砍 90% 只留一件
- 定价：**高毛利支撑上下游一起赚钱**
- 用户评价：清楚"你在干嘛"
- 结果：**心智资产沉淀 → 反脆弱**

## 诊断信号

用户圆桌反馈"不知道醉鹅娘在干嘛" + "醉鹅娘是良心酒商" = **良心 ≈ 毛利低 = 品牌心智失败**
