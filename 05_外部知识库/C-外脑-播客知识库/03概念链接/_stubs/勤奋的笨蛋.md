# 勤奋的笨蛋

## 一句话

勤奋的笨蛋是很努力但产能、判断或协同质量不足，反而拖累团队的人。

## 定义

杨涛提醒，创业者不能因为感情留下明显不合适的人。A 级人才和 C 级人才长期共处，会拖累整体人效。
