# 组局逻辑

## 一句话

顶级大学招生、公司招人、创业组队、私董组群、圈层运营，本质上运行的都是同一个逻辑——**招的不是"最好的人"，招的是"能补齐这张盘子的人"**。你要拼一整张披萨，需要有肉、有青椒、有香肠、有北京烤鸭；一张披萨全是知识分子，会腻死。

## 为什么需要这个概念

绝大多数人应聘/申请/找合作时的默认逻辑是"堆属性"——把自己所有荣誉、成绩、经历堆到最高。但**盘子的组建者要的不是最高属性值，是缺的那一格**。用组局逻辑看世界，能立即回答三个困惑：

1. 为什么某个能力平平的人反而被录取（他补了盘子里缺的位置）
2. 为什么全是同类嘉宾的社群会失败（团队 ENFP 完了，没生态）
3. 为什么"堆推荐信属性值"没用（组局者要的是你的位置感）

## 定义

- **组局者**：有权力决定盘子最终长什么样的人（招生官/HR 一号位/私董主理人/合伙人）
- **盘子**：一个有内部生态、需要角色互补的集合（一届学生、一个团队、一个社群、一场晚宴、一部电影）
- **组局逻辑**：**评估每个候选人时，看的是"他进来后盘子长什么样"，而不是"他自己有多好"**

## 招生盘子的六种"缺"

从 094 集拆解：

| 缺什么 | 典型录取 | 逻辑 |
|---|---|---|
| 缺代表能源产业的 | 美孚高管的孩子 | 未来 class 里能开能源议题 |
| 缺代表零售连锁的 | 沃尔玛/Target 高管的孩子 | 补上零售视角 |
| 缺代表 IP 内容的 | 迪士尼高管的孩子 | 拼产业上下游 |
| 缺代表少数族裔 | 黑人/拉美裔 | 平衡性别/族裔 |
| 缺捐赠人 | 白人二代 | 出钱一档 |
| 缺技术天才 | 全奖录取的普通家庭学霸 | 出未来诺奖 |

**"这个 class 好，同学 can help each other"——招生官的核心 KPI 是让一届学生一辈子互帮互助**，不是让每个学生都是学霸。

## 应用场景

1. **升学**：家长找教育规划师前先问"这个盘里我孩子能补哪一格"，而不是"我孩子分够上什么学校"
2. **招聘**：一号位招人先画团队盘子的现状缺口，而不是列岗位 JD
3. **组社群**：私董 / IP 圈子要主动组"生态"——上下游、多行业、买家卖家都齐
4. **组家庭**：老外把婚姻当"人生业务阶段的合伙人"——每个阶段的盘子缺哪一格找什么样的人
5. **组剧本**：像写电影选角——不要都是主角，要有配角、反派、丑角

## 反直觉点

- ❌ 组局逻辑 = 讲关系 / 走后门 —— 错。组局者本人自己有 KPI（生态、捐赠、就业率、诺奖），走后门反而破坏他的盘子
- ❌ 组局对小人物没用 —— 错。**小人物才更需要用组局逻辑找自己的位置**——你不是全能选手，但你可能是那格缺的人
- ❌ 组局意味着人是工具 —— 错。组局者知道**只有生态自然涌现的盘子才活得长**，硬拉进来的位置会脱落
