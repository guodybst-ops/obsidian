# 注意力

## 一句话

注意力是人类主动建立的认知滤波器——在信息输入远超处理能力的情况下，决定哪些信息进入意识、哪些被丢弃。AI 时代中注意力成为最稀缺的资源，管理注意力就是管理自己的世界。

## 为什么需要这个概念

在信息过载时代，如果没有「注意力」这个主动概念，人们容易产生一种错觉：信息越多越好、看得越多越聪明。但恰恰相反——没有筛选的信息只会消耗能量而不创造价值。人在输入、处理和输出三个环节严重不匹配（输入 >> 处理 >> 输出），注意力就是为解决这个结构性不匹配而进化出来的能力。

## 定义

张津剑从信号处理的角度定义注意力：一个主动滤波器。你的注意力放在哪里，你的世界就会在哪里显化；注意力被什么牵引，你的认知和行动就会被什么塑造。 [归纳] — [[42章经]] 043

**两层含义**：

1. **作为滤波器**：人类的所有感官输入中，只有被注意力选中的部分进入大脑处理。你刻意关注某个合伙人的缺点 → 大脑不断强化「这个人很差」 → 对方的优点和对业务的贡献被过滤掉。注意力决定了你的主观现实。 [归纳] — [[42章经]] 043

2. **作为可消耗资源**：注意力是有限的——世界频率不断升高后，高频信息（短视频、热点、即时通讯）消耗注意力的速度远超低频信息（深度阅读、长期思考）。高频消耗后人会疲劳，疲劳后人会偷懒——不再自己感知和分析，转而依赖别人的行动。「你买了什么」替代了「你怎么看趋势」。 [归纳] — [[42章经]] 022

## 为什么 AI 时代注意力更稀缺

1. **AI 让内容可以无限生成**：过去关注一个人或主题信息有边界，AI 可以持续生成视频、图像、分析让人看不完。注意力变得远比生产信息的能力更稀缺。
2. **AI agent 和 Vision Pro 会消除边界**：过去离开电脑/放下手机可以降频；未来 agent 实时伴随、智能设备持续交互——信息和决策随时进入注意力，边界感消失。
3. **分化加剧**：有注意力管理能力的人更安静、更全面、更能抓住信号；没有的人可能逐渐失去独立判断、观点变得极端或碎片化。 [归纳] — [[42章经]] 043

## 辨析

- vs **定力**：定力是「在膨胀和悲观中不被外界动摇」，需要注意力作为工具来实现。定力是目的，注意力是手段。没有注意力管理能力的人很难有定力。
- vs **心力**：心力是驱动注意力的能源。当注意力失焦时（即无法集中到该集中的地方），人会感觉「心很累」。心力不足 → 注意力涣散 → 认知混乱。
- vs **信息**：信息是外部的输入，注意力是内部的筛选。大多数人混淆两者——以为在处理信息，其实只是被信息处理。
