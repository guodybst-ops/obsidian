# [概念] 026-命运齿轮转动

## 一句话

因不满或看到风口而主动做出的第一个具体动作。

## 定义

**命运齿轮转动** = 一个人从"想变"到"做出第一个可被外部感知的动作"的时刻。判据不是被外部选中，而是自己启动了"缺钱/受够/看到风口 → 想要 → 做动作"的三段链。

三个要素同时具备才算齿轮开始转动：

1. **触发器**：具体的不满 or 看到具体的机会（不是抽象的"想改变")。
2. **念头**：意识到"我可以做点什么"（不是"应该有人来救我"）。
3. **动作**：一个已经离开你的手、进入别人视野的具体动作（投稿、拨电话、发大纲、扑大佬）。

### 026 集三个人的齿轮时刻

- **七天路过（缺钱型）**：廊坊被放假一个月无薪 → 意识到小城天花板 → 3000 块包车去北京 → 翻 50+ 公众号邮箱投稿。
- **陈雪（受够型）**：成都公益 3 年月薪只涨 1000 → "想走又觉得不负责任" → 接住上海社群经理的邀请电话 → "脑子啪啪，发条开始转动"。
- **黄小刀（风口型）**：2023-02-12 生财风向标看到 ChatGPT 讨论 → 意识到"大佬都在讲这是革命" → 群里发问"我教 ChatGPT 有没有人付费" → 第一个正反馈就位。

## 辨析

- vs **心想事成**：心想事成强调信念+观察+调动手里的牌（亦仁小狗钱钱模型）；命运齿轮转动强调**已经发出的第一个动作**——念头 + 动作，不是纯念头。
- vs **风口红利**：风口是外部环境；齿轮是内部启动。看见风口不等于齿轮转动，还要发生动作。
- vs **主动举手**：主动举手是"每次都举"的持续动作；齿轮转动是"第一次咬合"的启动瞬间。举手是齿轮转动之后持续咬合的方式。
