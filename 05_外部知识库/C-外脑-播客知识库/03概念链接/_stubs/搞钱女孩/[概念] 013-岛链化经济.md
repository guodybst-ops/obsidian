# [概念] 岛链化经济

## 一句话

全球化退潮后，经济关系从效率优先转向安全底线和价值观结盟。

## 定义

**岛链化经济**是香帅《钱从哪里来 4：岛链化经济》提出的宏观判断——2018 年贸易战 → 2020 疫情 → 2022 年俄乌战争之后，世界从"扁平化的全球化"转入"重新结盟 + 各自为政"的岛链化格局。

- **全球化时代**（2008 年往后）：世界扁平；强调增长、比较优势、互利合作；全球产业链分工；谁便宜谁供给。
- **岛链化时代**（2018 之后）：重新结盟 + 各自为政；强调安全底线；寻求和自己价值观一致的人；本土保护主义抬头；谁可信谁进入链条。

对个体的核心含义：**赚钱同时，不能只看到自己兜里揣着的钱，更多是要看到自己和这个社会的关系。**

## 关键区分

| 维度 | 全球化 | 岛链化 |
|---|---|---|
| 核心目标 | 效率、增长、比较优势 | 安全、底线、可控关系 |
| 关系逻辑 | 谁便宜谁供给 | 谁可信谁进入链条 |
| 个体感受 | 机会外溢、快速增长 | 保守、结盟、风险意识增强 |
| 财富策略 | 抓增长红利 | 看趋势、看关系、看安全边界 |
| 资产偏好 | 高流动性、高杠杆、追热点 | 低回撤、高流动性、跟对结盟 |
| 技能价值 | 单点专业深度 | 沟通、信任、跨领域流动性 |

## 这一集的例子

- **抱抱买房被套**：5 年前手里一笔钱不知道该干嘛就在杭州买房，3 年后房价疲软 + 阿里裁员抛售，"买了就跌"。**沉重的房子**恰是岛链化时代高价资产流动性风险的具象——最贵的资产 = 最难变现 + 最容易被拖住。
- **疤痕经济**：疫情后，从"断舍离"变成"能囤就囤"，拼多多量大打折、闲鱼二手家具、基金套住后再也不买——**不是消费降级，是消费心态永久性偏保守**。
- **香帅家保姆周阿姨案例**：手里 50 万要不要回县城买房，答案不是套用一线城市的经验，而是要看她自己和当地社会关系的锚点。
- **技能创造流动性**：雪姨反思自己 3 年考研拿硕士学位，回头看真正能变现的是快速归纳信息 + 与人沟通 + 调度拍摄——**学历不能创造流动性，技能才能**，这在岛链化时代尤其关键。

## 常见误解

- ❌ 岛链化不等于完全封闭，而是**开放关系更看安全、信任和阵营**。
- ❌ 宏观不是用来预测明天涨跌，而是**帮助个人理解风险和周期**。
- ❌ 看懂宏观不保证赚快钱，但能**减少错误归因和情绪崩盘**——亏钱时能"松绑"，不把"我这轮亏了"内化成"我这个人不行"。
- ❌ 不是"以后都别买房 / 别买基金"，而是"精算最大回撤 + 判断变现能力后再决定"。
