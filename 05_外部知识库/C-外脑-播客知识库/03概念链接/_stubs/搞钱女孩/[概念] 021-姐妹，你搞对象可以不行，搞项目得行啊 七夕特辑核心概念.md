# [概念] 想做 × 能做 × 可做 + 65 分项目

## 一句话

好项目 = 想做 × 能做 × 可做的交集；先接受 65 分，用做 65 分项目的经历长出判断力。

## 定义

021 集是《搞钱女孩》七夕特辑，两位单身主播的核心判断是：**没有不能做的项目，不行的是人；抛开个人情况谈项目都是耍流氓。** 由此推出两条互补的核心概念——

**第一条：想做 × 能做 × 可做 的三圈模型**
- **想做**：热情所在，愿意持续投入
- **能做**：技能 + 能力 + 资源三者合一，你做起来比别人轻松（隐藏第四维：时间/精力带宽）
- **可做**：行业趋势顺风、合规、有跑通样本
- **三圈的交集** = 好项目；缺一角都会有麻烦。

**第二条：65 分项目**
- 大部分选项目的迷茫来自"想找 100 分项目"这一错误预设。
- 主播的替换预设：**先接受"没有满分项目"，标准降到 65 分**；然后用"算账 / 拆生意模型 / 看大盘 / 卡合规"四把尺量。
- 就像找对象——**没有完美恋人，但要多谈恋爱来提升识别好恋人的能力**——项目也一样，多做几个 65 分项目，才长出"什么是好项目"的判断力。

## 关键区分

| 提问方式 | 底层预设 | 结果 |
|---|---|---|
| "小红书能不能做？" | 项目存在客观"能/不能"答案 | 无法回答，任何回答都不负责任 |
| "小红书对现在的我适不适合做？" | 项目适配性 = 项目属性 × 我的属性 | 可用三圈模型 + 四把尺展开 |
| "我要找一个百分百的完美项目" | 存在满分项目 | 永远选不出、永远停在观望 |
| "先做一个 65 分项目试试" | 判断力靠做出来 | 迭代出好项目 |

**认知层的元判据**："**你无法赚到你认知以外的钱**"——找不到"想做"、副业选不出，本质原因和亏钱一样：花在这件事上的时间太少、探得不够深。

## 这一集的例子

**正例（三圈全交集）**：
- **搞钱女孩本身**：雪怡有热情、有《主动交代》两年基础、播客本身适合上班族。
- **超哥（018 集）做茶**：自己爱喝茶 + 身边人爱喝 + 有做茶资源 + 中国茶文化赛道向上。

**反例（三圈全崩）**：
- **雪怡去年跟风炒股亏钱**：想做很浅（听消息就买）、能做完全不满足（不懂行业/买卖时机/收入）、时间投入不够。**亏钱是必然，不是运气差**。

**隐藏第四维（时间/精力带宽）**：
- **小辉的快团团航海**：想做/能做/可做都过关，但正职+快团团重运营 → 果断放弃。理性认赔——"试错成本低、回报高"。

## 常见误解

- ❌ **想做 = 一时热血** → 想做是"一个月不逼自己也在琢磨"，不是"看到别人赚钱就眼红"。
- ❌ **能做 = 我学过 / 我懂** → 能做要能比同龄人快 3 个月拿到第一笔钱。
- ❌ **可做 = 现在很火** → 可做要看是**朝阳/结构性利好**还是"KOL 口嗨的短期风口"；教培就是被打压后的反例。
- ❌ **65 分 = 凑合** → 65 分是放弃"完美主义"，主动迭代出好项目的方法论。
- ❌ **付了钱学社群就是搞钱** → 想真改变要走完"支付代价 → 培养意识 → 持续轻行动 → 养成思维"四步，缺一步链条断掉。
