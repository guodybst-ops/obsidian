# 额度党 vs 羊毛党

## 一句话

额度党靠拆东行补信行套用总额度，羊毛党靠权益/里程/积分套利。

## 各自定义（简版）

**额度党**：通过持有多张信用卡、真实消费+按时还款把银行给予的**总授信额度**推到极限（Claire 案例：8 家银行 40+ 万），用这个额度来**支付超出当前收入的消费**，本质是把未来收入借出来花。收益是"提前享受"，代价是**利息 + 心理压力 + 潜在负债风险**。

**羊毛党**：通过研究信用卡的**权益体系**（免费机票、酒店积分、里程兑换、贵宾厅、接送机、消费返现），用最低消费成本换取最大权益回报。资金流可以很小，但需要投入大量精力研究规则、算收益比、协调转账。**套利产业链已被银行严打**（转让接送机等），普通人可玩空间越来越小。

## 对比表

| 维度 | 额度党 | 羊毛党 |
|---|---|---|
| 核心机制 | 拆东行补信行、循环借新还旧 | 研究权益规则、精算收益比、套利 |
| 收益来源 | 提前消费带来的"当下满足" | 权益折现（机票、酒店、里程） |
| 资金流规模 | 大（单人每月可操盘 30 万流水） | 小（关键是"收益/时间"比而非总额度） |
| 主要风险 | 负债失控、征信崩、心理压力 | 时间沉没、被银行严打、账户被封 |
| 时间成本 | 记忆多张卡的账单日/还款日 | 研究规则 + 转账 + 联络下游用户 |
| 上限 | 银行给的授信额度 | 权益规则细节 + 转让市场深度 |
| 收益本质 | 借未来的钱花，需要还 | 真金白银的服务/机票 |
| 心理状态 | 表面 hold 住实则每天压力 | 精打细算但收益已被严打压低 |
| 极端玩法 | 8 卡 40 万额度、月操盘 30 万流水 | 团队作战、下级用户网络 |
| 现代空间 | 依然可玩但反噬极大 | 严打后普通人时薪已低于最低工资 |

## 什么时候选额度党 / 选羊毛党（判据）

**选额度党的信号**：
- 你有明确的**短期高确定性回报**（如：花 3 万参加培训能升职涨薪 10 万）
- 你已经建立了严格的**三条边界纪律**（见 [[02方法流程/_stubs/搞钱女孩/[心法] 025-信用卡三条边界使用法|[心法] 信用卡三条边界使用法]]）
- 你有**稳定且高于消费额的月收入**
- **红线**：如果这三条不同时成立，额度党就会变成潘多拉魔盒

**选羊毛党的信号**：
- 你时间充裕、乐于研究细节规则
- 你有**大量高频出差需求**（机票、贵宾厅等权益能真实用上）
- 你的时薪较低（研究规则的机会成本可以接受）
- **红线**：如果你已经年薪 50 万+，把时间花在羊毛党等于在亏钱

**混合形态 / 光谱位置**：Claire 明确表态**两者都不建议普通人玩**——额度党会滑向潘多拉魔盒式消费，羊毛党被严打后收益已被打到极低。**现实中最理想的中间形态**：只留 1 张工具卡，主要用于确定报销的公司垫款，附带薅一点确定收益的里程。

## 常见误区

- ❌ 认为额度党利息可控就没问题——利息可控不代表消费惯性可控，Claire 就是最好反例
- ❌ 认为羊毛党零成本——时间成本极高，收益率算下来往往低于最低工资
- ❌ 认为两者可以同时玩——精力有限，同时玩往往两头都做不好

## 附录：原文素材

Claire 原话（额度党机制）："银行怎么判定你是一个优质客户，就是你都是真实的消费。比如说数量多，但是信用卡到账期到了，你怎么还呢？拆东墙补西墙，就是拆东行补信场，通过不同的卡里面来回倒的，所以我就很大胆的去多开了 N 张卡，我当时最高持有的时候有8个行，总额都40多万。"

Claire 原话（羊毛党机制）："权益就是一般来说都是要交年费的卡才会有很好的权益。如果你有人想要找权益的话，其实已经有很多聪明的中国人把这个路子给你走，但早就不能走了，你这一定会验证你是本人的，所以你很难去找这个钱。玩卡界有两种模式，一种是羊毛党，一种是额度党。"

Claire 原话（羊毛党收益极低）："他们那种套利的其实是底下掌握了很多很多卡，他是相当于有下级的。那我们这种就是自己套利…你转了以后，你首先你这个卡年费是有成本的。你把那个成本扣出去以后，你根本没有赚太多东西，就是他们是一个特别消耗你的精力，然后其实收益已经被打的很低的一个东西。"
