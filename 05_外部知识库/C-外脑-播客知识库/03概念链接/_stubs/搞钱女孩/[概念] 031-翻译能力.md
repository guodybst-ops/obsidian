# [概念] 031-翻译能力

## 一句话

把信息 / 趋势 / 手里的牌翻译成"能变现的具体产品或动作"的综合基本功。

## 定义

在 031 集昊天的语境里，**翻译能力**是他判断"你能不能真的靠信息差赚钱"的唯一门槛。

它包含三层意思：

1. **看到 ≠ 能用**：信息差永远都在，只是挪了地方；但绝大多数人**"就算有信息差，也翻译不成钱"**——问题不在信息，在翻译。
2. **翻译是综合素质，不是单一技能**：工具使用、问题拆解、组合调度、对趋势的敏感度都算进去；本质上是**底层能力 / 基本功**，"基本功决定一个人的高度"。
3. **翻译能力是主动的好奇心的下游产物**：能不能跟保安聊起来、能不能从别人身上看到"我想了解的东西"，是翻译能力的底层驱动。

## 这一集的证据

- **原话锚点**："就算有信息差，你能翻译成钱吗？这很重要，大多数人没有这个翻译能力。"
- **同一张图的差异**：有的人能用 PS/PPT/美图秀秀多路径把图还原出来；有的人给他工具也翻译不出来——差的是翻译能力，不是工具。
- **瑞幸酱香拿铁月销 50 万卖券**：翻译的动作 = 看见"疯狂下单" → 翻译成"我在淘宝上卖券"这个具体产品。
- **金融市场例子**：A 股一年能给出 100 个"上级"（涨停/机会）；问题是你怎么获取优质信息，并**翻译**成能下注的判断——这两步任何一步掉链子，信息差就变成"我知道但我赚不到"。
- **保安小例子**：深圳保安可能炒股炒过几百万甚至千万，四季/柏悦保安见过的世界比很多人有意思；从他身上翻译出信息的动作 = 主动好奇心的下游。

## 辨析

- vs **信息差**：信息差是"外部世界有没有落差"，翻译能力是"你能不能把落差换算成动作"。二者独立——有信息差没翻译能力 = 白瞎；有翻译能力没信息差 = 找不到入口。
- vs **认知差**：认知差是**判断层**的落差（同一个事看得深不深）；翻译能力是**动作层**的落差（看懂了能不能拆成钱）。认知差在前，翻译能力在后。
- vs **执行力**：执行力偏"给了 SOP 我能推动完成"；翻译能力偏"没 SOP 我能从趋势里造 SOP"——**执行力是下游，翻译能力是上游**。
