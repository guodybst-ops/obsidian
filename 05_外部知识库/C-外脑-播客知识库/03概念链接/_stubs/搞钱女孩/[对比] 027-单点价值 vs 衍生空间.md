# [对比] 027-单点价值 vs 衍生空间

## 一句话

判断一件事该不该做，不看它单点值多少钱，看它能撬起多少衍生的可能。

## 各自定义（简版）

**单点价值**：一件事完成后**直接、一次性**得到的现金收益。可算术、可估价、可比较。例：写一本书拿 4 万稿费。

**衍生空间**：一件事完成后**间接、可能长期**带来的收益的**可能性范围**。不可精确估价，只能估分布。例：写一本书带来的领域背书、写作课/陪跑营、影视 IP 版权、社会关系。

## 对比表

| 维度 | 单点价值 | 衍生空间 |
|---|---|---|
| 直接回报 | 明确可算（4 万稿费） | 不明确（也许 0，也许 100 万） |
| 时间周期 | 短（做完就得到） | 长（3-10 年慢慢兑现） |
| 身份/背书 | 无 | **有**——变成"XX 作家 / XX 领域专家" |
| 复利可能性 | 无 | 高（背书能被反复调用） |
| 失败代价 | 时间成本 + 机会成本 | 时间成本 + 机会成本（同一件事） |
| 判断难度 | 低（拿计算器就能算） | 高（要判断"这件事有没有衍生结构"） |
| 常见误判 | 觉得"值 4 万也太少了不做" | 觉得"未来什么都可能，不切实际" |

## 什么时候看单点价值 / 什么时候看衍生空间

**看单点价值的信号**：

- 你**极其缺现金流**，下个月房租要交（先做单点值 4 万的活）。
- 这件事**没有背书性质**（普通打零工型工作）。
- 你**已经拥有充足身份/背书**，不需要通过做这件事累加。

**看衍生空间的信号**：

- 这件事**能给你外部可识别的身份**（作家、专家、创始人、某领域从业者）。
- 你**处于职业/身份转型期**，需要"新身份"作为下一跳的敲门砖。
- 这件事**能积累复利资产**（内容、案例、客户名单、IP）。
- 有**同类型成功案例**存在（例：其他作家已经跑通"书→写作课→影视 IP"路径）。

**核心判据**：如果两个信号都不明显，**默认看衍生空间**——因为单点算法本身是保守的，只有它压倒性明显（真的缺钱）时才应该抢先。

## 反例 / 常见陷阱

- ❌ 把"没有任何衍生空间的重复劳动"当成"未来有可能"——例：日更一年没积累任何内容资产的短视频号。**衍生空间要求案例存在**，不是心愿。
- ❌ 把"衍生空间"当成不做单点核算的借口——衍生空间不否认单点算法，是**在单点算法之上加一层**。
- ❌ 忽略**衍生空间需要具体路径**——衍生不是"随便想象"，要有 1-2 条**能验证的路径**（例：书 → 陪跑营，已经有朋友跑通）。
