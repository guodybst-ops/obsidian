# [概念] 3. 二奢生意模型

## 一句话
96 年江西姑娘 Monica 以"从月薪 4K 到月营收过亿"的二奢中古店案…

## 定义

96 年江西姑娘 Monica 以"从月薪 4K 到月营收过亿"的二奢中古店案例，拆解一整套从选行业、选公司、算成本、扛意外、扩团队、做客源到花钱观的实战路径；核心心法是"选择大于努力、行业天花板 + 个人天花板双维度决策、亏得起再上桌、边做边学"，并对普通女生给出"人生容错率其实很高"的通关式鼓励。在这集里，它不是抽象口号，而是通过真实案例、动作顺序和结果反馈被反复验证的一种认知抓手。

## 这一集的证据

- 1. 嘉宾档案
- 2. 关键决策 1：从大公司到二奢——3-5 年天花板法
- 3. 二奢生意模型
- 4. 关键决策 2：入行选"小而全"而不是"大公司螺丝钉"
