# [概念] 029-能力圈原则

## 一句话

"你是什么就做什么"——只做你和团队真实生活/擅长的品类。

## 定义

"**能力圈原则**"在 029 集张一芃的语境里，特指小店/独立品牌创业者的一条**自我识别 + 品类筛选**戒律：只做你日常生活中就在使用/擅长的品类，不做能力圈范围之外的事。

它包含两层意思：

1. **能力圈 ≠ 你会的技能**——能力圈是你**日常审美 + 使用习惯 + 团队真实擅长**的领域集合，比"我学过 XX"要严格。
2. **判据是"日常一致性"**——你现在是不是就生活在这个品类里？如果不是，无论它多火，都不要进。

## 这一集的证据

- **一鹏原话**："我觉得整个创业过程中，一定要遵循——你是什么就做什么，你不要去做你能力圈范围之外的事情。"
- **反例**：有人问一鹏"美式复古风很火，是不是该开个美式复古咖啡馆"，一鹏问他"你日常生活中有这些东西吗？"——对方说没有，只是觉得火。一鹏判断"必死无疑"。
- **他自己的应用**：
  - **拒绝快生意**：瑞幸、Manner 那种效率生意能力大小不具备 → 不做加盟、不做连锁扩张。
  - **拒绝冻干粉 / 咖啡豆电商**：这是别人建议的赛道，不是大小能做的。
  - **拒绝上海开店**："上海太卷，我们未必有勇气来"——承认自己在陌生高卷市场的能力不足。
- **金融专业反例**：他自己学的是金融，第一家店开的时候"跟绝大多数人一样，是大脑一片空白"——学的专业不等于能力圈。

## 与巴菲特 / 芒格能力圈原则的关系

- **共性**：都强调"只在你真正懂的地方下重注"。
- **差异**：巴菲特的能力圈更偏"我能不能看懂这个生意的现金流"，一鹏的能力圈更偏"我是不是就是这个品类日常使用者"——更 personal、更消费型。
- **对小店创业者更实用**：不需要读财报、不需要行业分析，反问"我日常生活中就在用它吗"就能判断。

## 使用边界

- 当前为单一来源 stub，特指 029 集张一芃语境。
- 与巴菲特/芒格能力圈原则可以互相参考但不完全等同——后续跨节目再出现时可升级为父级概念。
- 能力圈会随长期习惯扩展，但**不能靠短期投入一步扩到"用短板打别人长板"的量级**。
