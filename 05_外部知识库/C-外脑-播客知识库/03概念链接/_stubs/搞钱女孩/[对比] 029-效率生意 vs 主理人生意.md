# [对比] 029-效率生意 vs 主理人生意

## 一句话

效率生意靠供应链/数字化/开店速度赢，主理人生意靠内容 + 到店体验赢——两者不能混着做。

## 各自定义（简版）

**效率生意**：核心是"用更低成本 + 更高数字化能力，快速铺很多店把价格打下来"。典型代表：瑞幸、Manner、库迪。9.9 元咖啡、8.8 元咖啡都是这个赛道的表现。

**主理人生意**：核心是"用创始人个人特征 + 内容 + 到店体验，让用户'不选连锁而选你'"。典型代表：大小咖啡、独立胡同社区咖啡馆。杯量小，但用户来了有认知有感情。

## 对比表

| 维度 | 效率生意 | 主理人生意 |
|---|---|---|
| 核心能力 | 供应链 + 数字化 + 开店渠道 | 内容 + 体验 + 主理人特征 |
| 竞争壁垒 | 规模效应、单杯成本、算法定价 | 认知 + 感情 + "去这里才有的东西" |
| 单店经济 | 小店高坪效 + 低人工，能赚 3-5% | 大店低坪效 + 高人工，需要 5-10% 净利润 |
| 品牌厚度 | 品牌 = LOGO + 一致体验 | 品牌 = 内容矩阵（播客/展览/市集） |
| 增长逻辑 | 加盟 / 直营铺店，年增几百家 | 内容出圈 + 老客留存，一年 1-2 家 |
| 天花板 | 高，但需要资本和团队 | 有限，但止损速度快 |
| 止损速度 | 慢——决策流程长 | 快——一看势头不好就刹车 |
| 主要风险 | 单杯成本被卷 + 门店密度过饱和 | 主理人依赖性 + 复制困难 |
| 客单价目标 | 8.8 - 15 元 | 25 - 40 元 |
| 张一芃判断 | "我和团队都不具备做这个的能力" | "大小 7 年活着，靠的就是这个" |

## 什么时候站效率 / 什么时候站主理人

**站效率生意的信号**：

- 有大规模集采能力 / 自建供应链
- 有算法/自建数字化系统
- 有一年开数十家的开店团队
- 目标是覆盖大众客群、做低价高频

**站主理人生意的信号**：

- 你和团队本身生活在这个品类里（能力圈匹配）
- 有稳定内容能力（可以是播客/展览/公众号）
- 客户来店里是"来见你"、不是"来喝咖啡"
- 目标是长期活着、慢慢发展

**危险区（分裂）**：

- 想做主理人但不做内容——你就是一个没护城河的小店
- 想做效率但没有供应链和数字化——你只是用短板打别人长板

## 常见误区

- ❌ 觉得"我又懂内容又懂供应链"——大部分人两边都是 3 分，双弱等于危险。
- ❌ 主理人生意做着做着开始羡慕效率生意的"日出杯量"——路径依赖不同，别拿开店速度衡量自己。
- ❌ 效率生意冒充主理人生意——加盟连锁做"品牌故事"，用户很快识破。
- ❌ 认为"9.9 元咖啡战会永远"——是当前阶段的表现，但主理人赛道也必须建足护城河。
