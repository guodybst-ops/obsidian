# 金钱 vs 财富

## 一句话

金钱是一个数字；财富是躺着不做事仍能带来收益的东西（复利 + 长期）。

## 各自定义（简版）

**金钱**：账户里的一个数字，本质是一次性劳动或交易的结算结果。停止劳动/交易，数字停止增长；甚至因为通胀而缩水。典型形态：工资、单次咨询费、单篇稿费。

**财富**：具备两个属性——**复利**（能滚起来）+ **长期**（不依赖本人置身其中）。你现在躺着任何事情都不做，它依然可以源源不断为你带来收益。典型形态：AI 工具出海（网页/App/站点/小程序放上线自己跑）、可持续版税、被动型资产。

## 对比表

| 维度 | 金钱 | 财富 |
|---|---|---|
| 属性 | 单一数字 | 有复利结构的资产 |
| 时间性质 | 一次性 / 线性 | 长期 / 非线性 |
| 是否需要本人下场 | 需要，本人不动就没有 | 不需要，本人躺着照样有 |
| 是否复利 | 否 | 是 |
| 典型形态 | 工资 / 单次咨询费 / 单篇稿费 | AI 出海工具 / 版税 / 被动型资产 |
| 停摆代价 | 立即断供 | 长期滚动 |
| 累的程度 | 非常累（要不断置身其中找机会） | 相对轻（首次投入后自跑） |

## 什么时候选金钱 / 选财富

**选"先赚金钱"的信号**：
- 当下现金流告急，需要立刻回血。
- 还没找到"复利 + 长期"的可靠载体。
- 处于验证期，先跑通再谈规模化。

**选"直接搭财富"的信号**：
- 现金流有安全垫。
- 已识别到一个可跑复利的载体（工具/内容资产/版税/被动分成）。
- 已经受够"今天更文今天赚钱、明天不更就没钱"的累。

**混合形态 / 光谱位置**：多数人是**先赚金钱→有安全垫→再逐步转向财富**的过渡态；不必二选一。副业像选伴侣，需要多试多测才能找到长期热爱且复利的载体。

## 常见误区

- ❌ 把"高单价一次性咨询"当财富——它只是高价金钱，本人不动就没有。
- ❌ 觉得"财富"必须是投资——被动分成、可持续版税、AI 工具出海都属于财富。
