# [概念] 香植调气

## 一句话
以中国植物原料 + 古香方为骨、以现代萃取工艺为壳的西苔品牌研发链路。

## 定义

"香植调气"是西苔香薰 2023 年花半年时间打磨出的品牌策略与研发链路，同时是西苔区别于其他香薰品牌的核心壁垒。四字分别对应：

- **香**：自敬中国植物——不做古风焚香/檀香偏路，做适合新中产青年的舒适、健康、有一定疗愈功能的香
- **植**：植物原料——从 184 味中国古香方中提炼出 42 种中国植物香料（桂花、月季、梅花、牡丹等）
- **调**：调香——由西苔实验室联合古香方研究老师、四大香精公司调香师"金鼻子"、中科院教授共同调制
- **气**：香本身的气味/气韵——器型上刻意不做过多设计，为衬托香本身，只找对使用体验最友好的器皿

四步研发链条：**184 味中国古香方 → 42 种中国植物香料 → 19 处种植基地（预约种植 + 直接采购）→ 3D 锁鲜萃取技术**。

底层的历史坐标：中国香文化早在公元前 4500 年即广泛使用，南北宋盛极，后因战乱衰落；西苔的定位是"重新把香接回来"，但去掉宗教/仪式感，落回日常生活场景。

## 辨析

- vs **古风焚香/檀香**："香植调气"骨子里有传统精华，但去仪式感，落到日常生活场景
- vs **进口精油品牌**：以中国植物原料 + 中国古香方为差异化，不走欧美精油路径
- vs **通用 DTC 香薰品牌**：多数 DTC 品牌卷器型/包装/情绪营销；香植调气把壁垒建在原料 + 香方 + 工艺 + 专家团这条"重投入研发链"
