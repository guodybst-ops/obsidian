# [概念] 行业空白 = 建标准

## 一句话
行业调研三件套缺席的品类不是没机会，是最大的机会——谁先入场谁定义品类。

## 定义

"行业空白 = 建标准"是 Willa 在选择西苔香薰赛道时给出的底层判断。它把"没有独立行业调研报告 / 咨询报告 / 白皮书 / 国标 / 行业标准"这类**基础设施缺席**信号，反过来解读成一个更大的机会：

- 有报告和标准 → 行业成熟 → 已有玩家瓜分定义权 → 你只能卷价格 / 卷投流
- 没有报告和标准 → 空白 → 谁先入场 + 具备建标准能力，谁就拿到**品类定义权**这个壁垒

配套的量化锚点：Willa 判断国内香薰"科普认知普及度只有 5%，还有 95% 的进度条可以来"。5% 是她给"空白"设的经验阈值。

"建标准"的落地路径通常包括：
- 联合行业协会/学术机构做行业白皮书
- 联合原料基地做原料图谱
- 联合权威专家做工艺/成分标准
- 用品牌策略把上面几条封装成消费者可理解的口号（例：西苔"香植调气"）

## 辨析

- vs **信息差生意**：信息差利用的是"消费者不知道"，行业空白利用的是"整个供给端都不知道"，比信息差更底层
- vs **蓝海策略**：蓝海策略强调"绕开红海竞争"；行业空白强调"进空白的同时主动去建标准"，是加强版
- vs **早期红利**：早期红利是搭平台顺风车；行业空白是自己造平台/造标准
