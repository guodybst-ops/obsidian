# [概念] 手停口停

## 一句话
一旦停止工作收入就停，现实或心理上都没有安全垫的状态。

## 定义

005 集里，高加硬被“手停口停”戳中：即便现实收入还在，心理上也会害怕不持续做事就被淘汰。因此她强调收入多元化和抗风险。

这个概念有两层：

1. **现实层**：收入完全依赖当下劳动，没有资产、合同、团队、复购或系统，一停工就断收入。
2. **心理层**：即便有存款和收入，也长期担心“不做就被淘汰”，因此很难真正休息。

## 多源表述

- **高加硬的样本**：七位数存款并没有自动带来松弛，她仍然通过主业、副业、社群和个人标签降低不安全感。
- **知识库归纳**：手停口停不是单纯收入低，而是收入结构和心理安全垫都太依赖“持续用力”。

## 辨析

| 容易混淆 | 区别 |
|---|---|
| 努力工作 | 努力可以是主动选择；手停口停是停下来就焦虑或断粮。 |
| 自由职业 | 自由职业不必然手停口停，关键看是否有复购、资产、团队或长期合约。 |
| 收入多元化 | 多元化可以降风险，也可能变成多元内耗；要看每条收入是否可持续。 |
| 安全感缺失 | 安全感缺失是心理原因之一，但手停口停还包括现实收入结构问题。 |

## 使用场景

- 评估自己的收入结构是不是过度依赖单一劳动时间。
- 设计副业时，判断它能否沉淀成复购、社群、作品、客户关系或品牌资产。
- 复盘“为什么有存款还焦虑”，把问题拆成现实现金流和心理安全感两部分。
