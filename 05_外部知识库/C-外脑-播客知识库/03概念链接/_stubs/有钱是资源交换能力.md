# 有钱是资源交换能力

## 一句话

“有钱”不是固定数字，而是在具体环境和周期里，用财富交换生活品质、选择权、拒绝权和关键资源的能力。

## 定义

杨涛在 022 中把“有钱”讲成相对、主观、多态、动态的状态。同一笔钱在不同城市、周期和资产价格里，能换到的房子、办公室、人力、时间和安全感都不同。

## 组成

| 维度 | 含义 |
|---|---|
| 资源交换 | 钱能换到人、物、空间、时间、服务和机会 |
| 生活品质 | 钱能提高日常体验和选择余地 |
| 选择权 | 钱让人更容易选择城市、工作、关系和生活方式 |
| 拒绝权 | 钱让人能拒绝低质量工作、关系或条件 |
| 周期能力 | 真正重要的是财富能否穿越周期 |

## 辨析

- vs 账户余额：余额是静态数，资源交换能力看它在当下能换来什么。
- vs 炫耀性消费：有钱不等于消费符号，而是选择空间扩大。
- vs 提前恐惧：普通人先合理合法赚到足以让自己感到“危险”的钱，再考虑财富保护。
