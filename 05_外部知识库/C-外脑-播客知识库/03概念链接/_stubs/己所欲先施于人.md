# 己所欲，先施于人

## 一句话

《能断金刚》25 周年再版新书名封底的核心原则——**想要什么，先把它给出去给别人**。它是种子法则的实操版口号，也是儒家"己所不欲勿施于人"的**反向、主动**版本：不是"我不想要的就不给你"（消极），而是"**我想要的就先给你**"（积极）。

## 为什么需要这个概念

传统"己所不欲勿施于人"是**消极黄金律**——**避免**造成他人不想要的。它守护关系的下限，但不生长任何东西。

**己所欲先施于人**是**积极黄金律**——**主动**给出你自己想要的。它是**种子法则的第一动作**：种什么长什么。

- 想要客户 → 先帮别人找客户
- 想要伴侣 → 先给出"有承诺的稳定陪伴"给最缺陪伴的人（老人院里的孤单老人）
- 想要健康 → 先给别人送健康
- 想要笔 → 别人没笔时把自己的给出去

## 与「己所不欲勿施于人」的辨析

| 维度 | 己所不欲勿施于人（消极） | 己所欲，先施于人（积极） |
|---|---|---|
| 动作方向 | 避免/停止 | 主动/给出 |
| 结果 | 关系不变坏 | 关系变好+种下新种子 |
| 时间尺度 | 立即 | 数月-数年 |
| 底层逻辑 | 换位思考 | 种子法则 |
| 适用范围 | 所有关系的下限 | 你**主动想要**的东西 |
| 局限 | 不生长任何东西 | 需要长周期实证 |

**两者不冲突，是"下限守护 + 上限种植"的组合**：不做别人不想要的（保底），同时主动给出你想要的（增长）。

## 内在张力

- **不可实证**：你无法反复验证"我给出去的种子在什么时候通过什么方式回来"
- **反直觉时间差**：**回馈不一定从这个人回来，可能从第三方回来，而且有时间差**——普通人心态很难承受这种延迟
- **易被误用为"付出型人格"**：把"施"简化为"讨好"——但陈唐的口径不是讨好，是**种子**（有边界、可退出、不期待即时回报）
