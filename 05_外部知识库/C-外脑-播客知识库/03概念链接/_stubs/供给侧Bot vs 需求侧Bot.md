# 供给侧 Bot vs 需求侧 Bot

## 一句话

未来 bot 世界中最重要的分野：供给侧 bot 代表服务/内容/软件/企业（为你提供东西），需求侧/身份型 bot 代表「你本人」（发起需求、整合需求）。陶芳波认为，最重要的 bot 是后者——一个代表你自己的 AI。

## 为什么需要这个概念

很多人讨论「AI 是下一代软件」时，默认把现有软件和服务 bot化（供给侧 bot）。但陶芳波指出，这种理解忽略了一个更关键的环节：如果没有一个代表「我」来发起需求、整合需求、与供给侧 bot 互动的 bot，bot 网络就会变成一个杂乱无序的工具箱。需求侧 bot 是整个 bot 网络的「用户代理」。

## 定义

| 维度 | 供给侧 Bot | 需求侧/身份型 Bot |
|---|---|---|
| 代表谁 | 服务、内容、软件、企业 | 个人、主体、「我」 |
| 做什么 | 提供服务、回答、交付 | 理解需求、发起需求、整合需求 |
| 例子 | 红酒厂商 bot、编程 bot、HR bot、客服 bot | Mebot、个人模型、你的数字分身 |
| 互动对象 | 需求侧 bot / 传统用户 | 供给侧 bot / 其他 bot / 服务 |
| 核心能力 | 专业知识、服务执行 | 记忆、理解、预测、对齐 |
| 类比 | 卖家、服务员 | 买家、消费者代理 |

## 辨析

- vs **供给侧 Bot**：供给侧 bot 是更自然的延续——把现有软件和服务变成 AI 形态。但需求侧 bot 是全新的物种：以前软件从来没有过「一个动态的我」。传统互联网上「需求侧」主要是静态身份（Facebook）或被动工具（email），没有能持续学习、对齐并主动发起需求的代理人。
- vs **智能助手**：Siri/Alexa 是供给侧思维的产物——它们是被动等待指令然后从供给侧找答案。需求侧 bot 应该能预测需求、主动发起、代表你与其他 bot 协商。
- vs **Her（电影中的AI）**：Her 是陪伴型 AI，关系是「你是你，它是它」。需求侧 bot 是「me」——它是你自己的延伸，信任基础不同。
