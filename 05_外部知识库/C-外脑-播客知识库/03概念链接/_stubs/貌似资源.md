# 貌似资源

## 一句话

貌似资源是看起来能帮创业者打开局面，但真正落地时未必可用、不可控、不可持续，也不一定能转化为订单、供应、渠道或现金流的资源。

## 典型形态

013 集中提到的貌似资源包括：

- 一批客户资料。
- 一个朋友关系。
- 亲戚的工厂。
- 学校里的产品或项目。
- 某个渠道承诺。
- 专家、机构或熟人背书。
- 看似不少的公众号粉丝、微信群、朋友圈存量用户。
- 点赞很多、聊得来但从未付过费的“泛泛之交”。

它们的问题不是一定没用，而是创业者容易在没有验证前，把“可能有用”误判为“已经可用”。

## 判断问题

使用资源前先问：

1. 这个资源凭什么轮到我？
2. 谁拥有最终控制权？
3. 对方是否有真实动力配合？
4. 能否稳定转化为收入或关键能力？
5. 如果资源断掉，业务是否立刻停摆？
6. 是否有合同、交付、结算和边界说明？
7. 这个存量用户是否真的能被再次触达、唤醒和付费？

## 风险

- 放大创业幻觉：误以为自己已经有客户、渠道或供应链。
- 延迟真实验证：不去陌生市场里寻找真实需求。
- 形成单点依赖：资源一断，业务立刻受伤。
- 破坏现金流：围绕不可控资源提前投入成本。
