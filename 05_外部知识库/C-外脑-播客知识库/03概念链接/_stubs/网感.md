# 网感

## 一句话

网感是对互联网商业信息的敏感度：能判断信息真假、识别需求、找到渠道、理解平台、拆转化链路、设计包装和变现，并在合适路口等到用户。

## 组成

- 工具思维：平台只是流量、销售、展示、品宣或舆情工具。
- 信息源库：知道某类信息去哪里找最精准。
- 搜索能力：会用主词、前缀、后缀、清单词和过程词。
- 需求辨别：区分真实需求和伪需求。
- 流量理解：理解公域、私域、商域和买量。
- 长尾占位：提前占住用户会经过的关键词路口。
- 包装判断：能按人群审美调整产品、海报、手册和开箱体验。
- 变现敏感：知道何时保护私域，何时用 CPS 放大销售。
- 拆解拼装：能拆完整转化路径，再按自身资源重组。
- 组织效率：知道何时用云团队、兼职团队或外包释放高价值时间。
- 防御意识：用 IP、影响力、私域和正面内容占住注意力高地。
- 学习流训练：主动训练算法、拆广告、拆直播、观察销售漏斗，把别人花钱验证的商业系统当学习样本。
- 好奇心与武器库：看到反常、眼前一亮或商业味很重的信息时，不急着划走，而是追进落地页、私域、物料、话术和账号网络，把它沉淀成自己的谈资库与工具库。
