# 财务语言的显化

## 一句话

**把愿景隐约化，把财务语言显化**——判据是能否严格按财务报表规划团队、支出、费用；做不到 = 你没想明白。

## 定义

兔头妈妈刘楠对醉鹅娘的建议（醉鹅娘转述）：

### 愿景语言（应隐约化）
- "我们要成为最懂中国女性的红酒品牌"
- "我们要重新定义酒饮消费"
- **问题**：不可测量 → 不能约束支出 → 不能对齐团队 → 只能凝聚情绪不能凝聚决策

### 财务语言（应显化）
- 明年目标毛利 X → 客单价 Y × 单量 Z → 营销预算 A → 团队编制 B
- **判据**：**每一笔支出 / 每一个新雇员 / 每一条新业务线 → 严格贴合财务报表**
- 做不到 = 你的愿景没想明白（真正想明白的愿景可以翻译为财务假设）

## 使用姿势

- **对外**：愿景语言（对用户 / 媒体 / 情感认同）
- **对内**：财务语言（对合伙人 / 团队 / 决策）
- **两者混用会毁掉团队**：内部还用愿景语言 = 每个人凭情怀决策 = 没人对财务负责

## 辨析

- vs **OKR / KPI 拆解**：本条更侧重"语言层面的显化"——不只是把数字写出来，是让财务成为组织默认沟通语言
- vs **[[战略算账目标公式倒推法]]**：那是"怎么算"的方法；本条是"用哪种语言"的选择
- 关联：[[不负债 vs 想赚钱]]、[[巨婴公司诊断]]

## 局限性

- 早期探索期公司（PMF 前）财务假设本身不成立 → 强推财务语言 = 假精确 = 自我欺骗
- 部分行业（如艺术 / 学术 / 长周期研发）需要愿景语言维持士气
