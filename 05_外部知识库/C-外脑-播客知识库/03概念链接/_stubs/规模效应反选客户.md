# 规模效应反选客户

## 一句话
手艺人涨价的关键不是"我值多少钱"，而是**通过涨价 / 内容曝光 / 平台规模反向筛掉不匹配客户、集中服务高价值客户**。1200 → 3000 的酒吧驻唱费不是靠说服酒吧老板，是靠"网红酒吧歌手"这个身份被市场识别 → 客户主动跑上来 → 报价自然涨。

## 为什么需要这个概念
013 集酒吧歌手（1200-1500/场、粉丝 1.4W）问怎么涨到 3000。斯斯的答案不是谈判技巧、不是升级作品，而是**"把自己当工具，兢兢业业开直播、兢兢业业做短视频，规模效应反选客户"**——**当你的曝光量足够大，客户会自己筛掉低价的**。这条心法也解释了摄影师从 1500 涨到 3000-5000、豪宅经纪只服务 10 个金主的底层逻辑。

## 定义
- **传统涨价路径**：升级作品 → 说服客户 → 谈判 → 涨价 —— **累且慢**
- **规模效应涨价路径**：
  1. 铺规模化曝光（直播 + 短视频切片 + 私域）
  2. 让市场把你和"网红级"身份挂钩
  3. 更高预算的客户 / 平台自己跑上来
  4. 低价客户自动流失（他们付不起 / 排不上你）
- **反选原则**：**"现在还认为博主赚多少由粉丝量决定，你就活在 2018 年"**——粉丝质量、内容标签、身份识别度才是决定客户单价的
- **关键动作**：主页把身份定死（"网红酒吧歌手，每场必直播"、"帮网红/爱豆做叙事的摄影师"）—— 别人从一堆选择里就会点你
