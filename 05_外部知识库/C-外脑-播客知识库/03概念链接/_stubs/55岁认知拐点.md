# 55 岁认知拐点

## 一句话

男性 55 岁前后是投资认知的悬崖式下滑期——认知下降 + 固执 + 不允许自己失败 + 手上钱最多，构成中国最大诈骗富矿。

## 定义

杨天南从业经验归纳：

- **55 岁前**：男性投资认知相对较高（在职、信息更新、同事间校准）
- **55 岁后**（临近退休/退休后）：认知**下滑非常厉害** + **固执 + 不允许自己失败**
- **性别差异**：男性 90%+ 死扛不告知配偶 → 骗局持续时间长 + 单个损失大
- **地理密度**：上海 600 万退休老人 = 永续现金流富矿

## 局限性

- 从业经验归纳，非严格统计
- 存在幸存者偏差（他见到的都是被骗的样本）
- 女性长者相对不易被骗但不代表没有——只是骗局形态不同（保健品/情感 vs 金融）
