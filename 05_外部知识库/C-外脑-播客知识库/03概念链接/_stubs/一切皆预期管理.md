# 一切皆预期管理

## 一句话
你想要 30% 加薪，不是市场对你的预期，只是**你的想象**。**预期压得低一点，反而能让别人在合作里感受到惊喜**——这才是"顺风局"的秘密。选秀里那些"祭天剧本"（一上来吹很高）总是最先滑坡，真正得民心的是前几期甚至是槽点、后期热度慢慢起来的选手。

## 为什么需要这个概念
预期管理是斯斯《富女孩》体系里被反复引用的一条底层交易观：跳槽 30% 加薪、副业月入 5 万、创业半年上市——**这些都是自己给自己开的祭天剧本**。真正持续赢的关系（老板对下属、客户对乙方、伴侣对伴侣）都是**"合作者对我的预期低于我实际能给"**——预期反向定义了关系寿命。

## 定义
- **预期错位诊断**：**"我想要 X"** ≠ **"市场对我的预期是 X"**——第一件事是问自己"是我的想象还是对方的实际预期"
- **顺风局公式**：预期 = 6，交付 = 8 → 惊喜 = +2 → 关系加分
- **祭天局公式**：预期 = 10，交付 = 8 → 落差 = -2 → 关系扣分
- **反向应用**：不要一上来把简历/身价/能力吹到顶，主动把预期压低半格；用**"下限稳、上限惊喜"**的结构建立长期信任
- **决定关系寿命**：一段关系为什么散？大概率是"预期一次次高于交付"；一段关系为什么长？大概率是"交付一次次高于预期"
