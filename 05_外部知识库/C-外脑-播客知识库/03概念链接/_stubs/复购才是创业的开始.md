# 复购才是创业的开始

## 一句话
创业完整链路 = **获客 + 交付 + 复购**。只有获客+交付 = 30%（能做出单但客户不回头），加上复购 = 70%（商业模式初步验证），加上推荐 = 100%（进入自增长）。**前 30% 只是入场券，复购才是创业真正的开始**——很多人以为拿到入场券就赢了，其实赛跑还没开始。

## 为什么需要这个概念
斯斯 004 集给北京 38 岁景观设计师默默拆艺人公司三个方向（To C 教练/游学、To B 品牌联名、资源型销售）时抛出的核心方法论：**按复购潜力排序** —— 只有一次性生意的方向都要放弃。012 集里也反复回响：宠物蛋糕**"没有复购、心理不顺、需要持续拉新"**就是硬伤。**判断一门生意能不能做，最硬的指标不是能不能出单，是能不能第二次来**。

## 定义
- **创业完成度四段**：
  - **只有获客** = 10%（会营销，但产品可能不行）
  - **获客 + 交付** = 30%（能出单，但客户不回头）
  - **获客 + 交付 + 复购** = 70%（商业模式初步验证）
  - **获客 + 交付 + 复购 + 推荐** = 100%（进入自增长）
- **判据推论**：多个方向选择时，**按复购潜力排序**——复购潜力低的方向直接砍
- **反面硬伤**：宠物蛋糕（做成宠物形状让它吃掉、心理不顺）、纯资源型销售（一单结束就归零）→ 都是入场券但跑不到 70%
- **正面样本**：To B 品牌联名（合作过一次觉得好，下次自然找你） / 主持人自己的 10 年老房产经纪人复购关系
