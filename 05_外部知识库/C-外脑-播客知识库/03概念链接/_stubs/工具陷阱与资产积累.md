# 工具陷阱与资产积累

## 一句话

移动互联网最终立得住的十几个应用没有一个是纯工具——微信靠关系资产、抖音靠内容资产、美团靠线下商户资产。纯工具供给端 100% 由代码提供，大家拼代码相似度会拉平 Royalty，最终没有壁垒。

## 为什么需要这个概念

AI 创业当前最危险的陷阱：做出一个"好用的 AI 工具"就以为有了产品。但纯工具拼代码——大模型 API 一样、prompt 调优水平差不多、产品形态趋同，最终大家回到同一起跑线。必须从一开始就思考：工具做出来以后，你积累了什么别人积累不了的资产？

## 定义

**工具**：供给端 100% 由代码提供，用户用完就走，没有持续沉淀。
**资产**：用户越用越多、越沉越厚的不可替代资源。分为三类：
- **关系资产**：微信（好友关系锁死了用户迁移成本）
- **内容资产**：抖音/快手（内容越多推荐越准→创作者越多→内容越多）
- **线下/商户资产**：美团/拼多多（商户关系、供应链、物流网络）

## 历史案例

快手是先做工具（GIF 制作）再痛苦转型做内容社区。如果一开始就想清楚，"索性直接跨过工具去做资产"。很多 AI 产品也一样——先做了个好用的 AI 写作/图片/总结工具，然后发现"用户用完就走了，不沉淀任何东西"。

## 辨析

- vs **技术壁垒**：工具靠代码（技术优势容易被追平），资产靠沉淀（越用越厚，难以复制）
- vs **网络效应**：资产积累是网络效应的一种——但不完全是，内容资产和商户资产不一定依赖用户间网络
- 判断标准：如果把产品代码开源，竞争对手能做到一样吗？能 → 你没资产，是工具。不能 → 你有资产。

## 概念关系

- 与 [[AI Native 半步退]] 有关——只做半步退还不够，还要在退半步时想好资产积累方向
- 与 [[AI应用四类机会]] 有关——第二类（汤姆猫）是典型的工具陷阱，第四类（抖音/美团）是积累了资产
