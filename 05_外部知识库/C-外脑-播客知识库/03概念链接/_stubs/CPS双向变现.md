# CPS双向变现

## 一句话

CPS 双向变现是指既能让别人为自己的产品带销售，也能替交付可靠的产品拿佣金；关键不是佣金高低，而是是否保护自己的私域和信任。

## 关键判断

- 自己有产品时，要敢给佣金，用利润换销售额、客户和传播。
- 帮别人卖产品时，要看交付、口碑、用户匹配和是否伤粉。
- 私域不是临时佣金池，不能为了小钱把用户注意力迁移给别人。
- CPS 能放大销售，也可能消耗影响力势能。

## 风险边界

| 风险 | 表现 | 修正 |
|---|---|---|
| 为佣金乱推 | 产品交付差，粉丝受伤 | 先试用、核交付、看售后 |
| 私域外流 | 用户被引到别人池子 | 控制跳转路径，保留服务关系 |
| 佣金过低 | 帮别人做嫁衣 | 计算成交、售后和信任成本 |
| 只拿 CPS | 自己没有产品 | 同时建设自有产品或服务 |
