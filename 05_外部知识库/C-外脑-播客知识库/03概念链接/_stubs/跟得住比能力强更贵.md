# 跟得住比能力强更贵

## 一句话

**IP / 老板招人时，比"你多能干"更看重"你能跟多久、多稳"**——因为能立刻出活的能人早跳槽了，你能招到的高即战力大多有更好的 offer 在等；反过来**跟得住的人**——认同你、愿意熬、替代方案少——**可以慢慢学能力**，隐性知识 / 默契 / 信任是花几年才能长出来的稀缺资源。

## 为什么需要这个概念

- 解释了为什么 IP / 自媒体博主总"招不到合适的助理"——**能人跳槽了，剩下的都是没那么急着走的人**
- 解释了金星新氧 CMO 为什么是 13 年入职的女孩——"我真的是等着她一点点长起来"
- 解释了为什么"高薪招 P7 空降"经常翻车——**能力可能匹配，但跟不住老板节奏**
- 破除"招人要招最强的"这种默认设置——**对小团队和 IP 来说，稳定性比即战力更贵**

## 定义

- **能力**：可训练、可衡量、可标准化的技能——文案、剪辑、数据、拓客等
- **跟得住 =（动机 + 耐性 + 价值观 + 替代方案少）四项综合**：
  - **动机**：她为什么来你这儿？（不是奔即战力，是奔一个方向或一个人）
  - **耐性**：能不能忍前 3-4 年的"看似没进步"？
  - **价值观**：跟你合不合拍——别人往东她往西，就算能力顶天也留不住
  - **替代方案少**：她有没有更好的 offer？没有 → 她真的可能跟你走完
- **筛选顺序**：**动机 → 耐性 → 价值观 → 替代方案 → 能力**（能力放最后）

## 四层筛选表（招 IP 助理 / 小团队核心的顺序）

| 层 | 问题 | 淘汰信号 |
|---|---|---|
| 1 · 动机 | 你为什么想来我这儿？ | "想看你的商业模式"、"给自己积累经验" → 淘汰 |
| 2 · 耐性 | 前 3 年只做琐碎事、看不到明确晋升，能不能接受？ | 眼神犹豫 / 追问具体路径 → 谨慎 |
| 3 · 价值观 | 举例聊三观 / 消费观 / 时间观 | 差异过大 → 淘汰 |
| 4 · 替代方案 | 你手上有没有别的 offer？ | 有更好选择 → 大概率跟不完 |
| 5 · 能力 | 最后测能力 | 不合格但前四层合格 → 慢慢练 |

**核心心法**：**跟得住 + 能培养 > 即战力 + 随时会飞**。**能力可以练，跟得住不能练**。
