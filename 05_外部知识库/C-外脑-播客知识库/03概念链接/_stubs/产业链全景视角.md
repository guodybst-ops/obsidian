# 产业链全景视角

## 一句话
从**"这个岗位挣多少"**跃迁到**"这条产业链上下游全景图 → 我在哪一端"**的视角切换。选择 = 位置的选择——**收入不是努力的函数，是位置的函数**。同样是短视频：品牌方 vs 代运营，中间隔的是整条价值链。

## 为什么需要这个概念
006 金星讲：**"上市公司老板思考问题时，会把产业分为上中下游"**——这句话让斯斯自己都觉得被击中。013 集里她把这个视角落到 4 位连麦者身上：短视频代运营小胖天天通宵还不赚钱、就是因为他一直在下游执行位。**你困惑是因为你只在产业链平视——看不清；升到俯视，路径立刻浮现**。

## 定义
- **产业链三层**：
  - **上游**：品牌方 / 投放方 / 供应链（毛利最高，抗风险最强，稀缺资源）
  - **中游**：代理商 / MCN / 达人（毛利中等，依赖流量）
  - **下游**：执行方 / 剪辑 / 拍摄 / 代运营（毛利最低，同质化严重）
- **俯视分析法**：把行业上中下游拆成 20-30 个环节，标注每个环节的
  - **盘子多大**
  - **玩家数量**
  - **玩家数量近 3 年变多还是变少**
- **最优选择判据**：**盘子在增长 + 玩家数量在减少** = 壁垒变高、剩者为王
- **最差选择判据**：盘子在缩水 + 玩家数量激增 = 红海必输
- **推论**：位置比努力重要——**"选择比努力更重要，因为趋势就是红利"**
