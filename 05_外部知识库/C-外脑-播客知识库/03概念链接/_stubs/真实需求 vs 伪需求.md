# 真实需求 vs 伪需求

## 一句话

真实需求能持续驱动购买、复购和转化，并凝结成明确指标；伪需求依赖包装、噱头和高教育成本，短期能卖，长期容易被流量成本和市场反馈纠偏。

## 020 集例子

- 电动牙刷：真实需求是刷得更干净，不只是更方便。
- 咖啡馆：真实需求更多是空间服务，不只是咖啡。
- 生日蛋糕：真实需求可能是好看、能出片，不只是好吃。
- 名烟名酒名茶：真实需求常常是社交、送礼和待客，不只是自己用。
- K12：客户付费核心常常是提分，而不是花哨噱头。

## 判断问题

1. 用户会不会持续为它付费？
2. 它是否对应明确指标，比如提分、时长、频次、转化、购买？
3. 用户是否会用关键词主动搜索这个问题？
4. 如果不继续教育用户，它还会不会自然成立？
5. 获客成本是否越来越贵，说明市场在纠偏？
