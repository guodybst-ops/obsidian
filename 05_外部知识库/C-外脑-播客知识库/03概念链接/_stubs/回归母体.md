# 回归母体

## 一句话

润宇给"想不明白怎么突破"的创业者的心法层解:**"人生迷茫就回归母体。母体不是老婆孩子同事,母体是客户。"** 妈妈是生命的母体,客户是商业的母体。**人生越迷茫、越焦虑,越不要向外求;向内求就是走进客户。**

## 为什么需要这个概念

创业者迷茫时的典型反应:见大咖、看书、闭关、头脑风暴——**向外求**。但这些都是"知识层解",不解决底层逻辑问题。**"其他所有你学到的知识、课程都不能帮你解决底层逻辑的问题。只有用户能。"** 这个概念给出一个明确的心法层锚点:**方向是"向内向下向客户",不是"向外向上向名师"。**

## 定义

**回归母体 = 迷茫时向客户回归的心法 + 两个技法**

### 心法层

- **母体是谁?** — 一定是客户(不是同事/家人/合伙人)
- **为什么是客户?** — 妈妈是生命的母体,客户是商业的母体;客户是"你当年成功的原点"
- **具体动作** — 不要跟老婆/孩子/同事讨论,直接去客户身边

### 技法层(两个"敬")

同音不同字,但相互支撑:

| 敬 | 拼音 | 含义 | 动作 |
|---|---|---|---|
| **敬** | jìn(尽) | 尽力 | 把能穷举的都穷举一遍(见大咖 / 看书 / 头脑风暴 / 闭关) |
| **敬** | jìng(敬畏) | 尊敬 | 敬畏客户,不因自己挣钱多就看不上小学生问的问题 |

**"我尊敬我的客户,我不能因为自己今天挣钱多了,觉得你们这帮人啊都是这么小白。"**

## 三个具体动作

### 1. 停止和"非客户"讨论

- 不要跟合伙人开头脑风暴会
- 不要跟老婆诉苦
- 不要跟名师约"闭关咨询"

### 2. 回到客户场景

- 直接约客户吃饭
- 走进客户使用你产品的物理场景
- 看客户一天怎么用你的产品

### 3. 回忆你为什么被喜欢

- **"理论上,只要你是一个真诚的人,人家对你的爱今天不会变。"**
- 如果客户对你的态度变了 → **"大概率是你变了"**——不是市场变了,是你变了
- 找回当年的真诚

## 深层原理

**人之所以会迷茫,是因为脱离了客户;脱离客户 → 脱离市场 → 越迷茫**

```
脱离客户
    ↓
脱离市场
    ↓
更迷茫
    ↓
向外求(见大咖/看书/闭关)
    ↓
更加脱离客户 ←──────┐
    ↓             │
恶性循环 ───────────┘

回归母体切断这个循环
```

## IP 的本质补充:人大代表

**"一个非常好的 IP 的本质是'人大代表'——代表他的人民,履行这个权利。"**

- 你之所以不过气,是因为**心中永远装着他们的苦恼**
- 你一旦大了、高级了,就会看不上小学生
- 这时候要**不断俯下身**去理解当年走过这段路的心态

## 辨析

- vs **闭关思考**:闭关是向内独处,回归母体是向外走进客户
- vs **用户访谈**:用户访谈是获取信息,回归母体是重新校准心态
- vs **禅修/正念**:禅修是"关注自己",回归母体是"关注他人"——方向相反

## 概念关系

- 与 [[原点用户三角]](02 层)在同一心法轴上:一个讲心法,一个讲操作
- 与 [[IP中介本质]] 相关:IP 之所以能存在,是因为服务客户;脱离客户的 IP 就是空气
- 与 [[敬畏客户]](未来可能升级)的心法互补
- 与 [[高端品牌等于引领需求]] 相关:引领的前提是深入理解客户,不是拍脑袋

## 应用启发

- 迷茫来袭时的第一反应:**问自己"我上一次和客户吃饭是什么时候?"** 如果超过 1 个月,你已经开始飘了
- 团队讨论卡壳时的第一动作:**"我们去客户那里吧"** —— 不要在会议室里继续讨论
- 产品经理迷茫时:**去客服后台听 3 个电话** — 比听 3 个大咖的直播有用得多

## 与"熬当中受苦受难"的关系

润宇在 096 里同时讲了另一个心法:**"人深刻的认知来自于熬当中的受苦受难。"** 主动放弃顺风顺水的旧码头(C 端知识付费),选择没人到过的新码头(To B 营销服务)——**受苦本身是先行者必付的代价**。

回归母体 + 受苦受难 = 创业者精神的两面:
- **心法**(回归母体):方向不要错
- **意志**(熬受苦难):代价要付得起
