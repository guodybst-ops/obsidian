# 平视去魅

## 一句话

平视去魅不是否定强者，而是把大佬、上位者和先进者放回阶段、权责和工具的位置：学习他们，使用资源，但不神化、不盲从、不自困。

## 三个关键词

| 关键词 | 含义 |
|---|---|
| 阶段 | 大佬只是处在更靠前人生阶段的人 |
| 权责 | 上位者时间更贵、责任更大，是效率安排的一部分 |
| 工具 | 先进者也可以成为后进者提效降本的工具 |

## 关键判断

- 向结果致敬和保留判断可以同时存在。
- 靠近势能不必羞耻，前提是提供价值交换。
- 问题不在于靠近大佬，而在于因为崇拜而盲从，或因为自卑而自困。
- 平视之后，经验和资源才能为自己所用。

## 概念关系

- 与 [[03概念链接/_stubs/影响力势能]] 相关：靠近势能是资源策略。
- 与 [[03概念链接/_stubs/有钱是资源交换能力]] 相关：社会协作中大量关系都包含交换。
