# AI Coding Agent

## 一句话

一种能独立接收编程任务、自主规划、编写、运行、调试并交付代码结果的数字劳动力，与辅助人类编程的Copilot有根本不同。

## 定义

AI Coding Agent是指能异步完成软件工程任务的AI系统。它不只帮人写代码，而是替代人执行完整的编程工作流：

1. 接收任务描述
2. 理解代码上下文（业务上下文+工程上下文）
3. 自主规划执行路径
4. 编写代码
5. 运行和调试
6. 提交结果

与Copilot的核心区别：Copilot是同步工具（人在场时辅助补全和编辑），Agent是异步劳动力（人下达任务后可以离开）。

## 为什么需要这个概念

过去开发者工具全部围绕"帮人更快写代码"设计。但AI Coding Agent提出了一个新范式：不需要人一直盯着，AI可以像数字员工一样独立完成一部分软件工程工作。这改变了产品形态、商业模式和组织方式。

## 关键特征

**当前阶段判断（张海龙）**：
- Agent还没有跑通PMF——产品形态、场景、定价、所需模型能力都不清楚
- "什么都能干"的Agent无法实现——当前更现实的路径是找窄任务切入（如unit test）
- Agent最重要的品质是可靠而非聪明

**窄任务切入的优势**：
- 任务有套路、结果可衡量
- 人不愿意干的活（如写unit test）
- 对业务上下文依赖相对低
- 准确率更容易做高

## 辨析

- vs [[Copilot]]：Copilot是同步辅助工具（人在场），Agent是异步独立劳动力（人不在）
- vs 通用Agent：AI Coding Agent聚焦软件工程场景，环境定义更清晰（IDE/代码库），反馈信号更明确（代码是否可运行/测试是否通过）
- 张海龙提出：Copilot = 电钻（帮人更快干活），Agent = 小弟（替人独立干活）
