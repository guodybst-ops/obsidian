# 流量能力与产品能力

## 一句话

0 到 1 的核心，是能获取新增用户并有东西可卖。

## 定义

流量能力是持续获取增量、把用户从公域带到可交互场景的能力；产品能力是有可收费的服务、商品、咨询、社群、带货或陪跑承接需求。只有流量没有产品，或只有产品没有增量，都难以完成 0 到 1。

## 辨析

- vs **存量粉丝**：存量粉丝不等于流量能力，能新增才算。
- vs **内容能力**：内容能力只是流量能力的一种入口。
