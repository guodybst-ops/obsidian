# 社群场域续费

## 一句话

用户因为专业而付费，因为服务而续费；付费社群真正留住人的，是价值观相近的人一起行动、被服务、被陪伴的场域。

## 构成

| 构成 | 作用 |
|---|---|
| 专业内容 | 让用户愿意第一次付费 |
| 服务体验 | 让用户愿意继续留下 |
| 情绪价值 | 让用户感到被看见、被鼓励 |
| 共同目标 | 让社群不只是资料仓库 |
| 行动机制 | 打卡、作业、活动、共读、线下 |
| 场域关系 | 用户在社群里认识人、形成归属 |

## 关键判断

- 海报利益点影响付费率，兑现承诺影响续费率。
- 社群是人的生意，不只是知识的生意。
- 星主在场域里像内燃机，持续提供情绪价值和内驱力。
- 线上聊很多次，不如线下见一次；小局 8 人以内更容易聊透。
