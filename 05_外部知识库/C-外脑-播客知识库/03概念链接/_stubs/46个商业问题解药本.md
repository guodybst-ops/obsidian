# 46 个商业问题解药本

## 一句话

《能断金刚》**第七章《黑暗森林中的英雄果》**列出 46 个典型商业问题（合伙人内耗 / 财务不稳定 / 员工流失 / 客户流失 / 家人不理解 / 关系疏离 / …）及其对应的**种子解药**。它是种子法则在商业场景里最落地的一份 "**症状 → 处方**" 查表。

## 为什么需要这个概念

传统商业教科书遇到"我合伙人内耗"、"我财务不稳定"时给的是**行为层解法**（重新签协议 / 融资 / 裁员）。但很多问题在行为层反复修补依然复发——**因为根源在种子层**。

**46 题解药本的作用是：把复杂人际/财务/组织问题从"行为层"翻译到"种子层"**，让你不再问"我要怎么做才能解决"，而问"**我在种什么种子导致这个问题反复发生？**"

## 章名解读

- **黑暗森林**：人际关系 / 商业环境的复杂性、不可见性、充满风险的属性
- **英雄果**：只要你知道每个问题背后的**种子解药**——就像在黑暗森林里找到日光——**问题就变成有解药的了**

## 46 题的结构（每一题都是这个模式）

```
症状（Symptom）
   ↓
书里给的"为什么普通解释错了"（Reframe）
   ↓
种子解药（Seed Antidote）
   ↓
可执行动作（Actionable）
```

## 陈唐现场示范：第 1 题

**症状**：公司财务状况不稳定，长期处于支出的状态

**Reframe**：不是"你不够会赚钱"

**解药**：
1. 把利润分享给帮你创造利润的人
2. 哪怕一分一毫，绝对不取不义之财
3. **切记：分享的多寡不决定种子强度，分享的意愿才是关键**

## 陈唐现场示范：第 7 题（合伙人内耗）

**症状**：你老是对合伙人心生不满，无论你怎么改变他，你们中间总是一再发生争执

**Reframe**：**不是**因为你们背景 / 思想不一致——现实里也有风格差异很大却不冲突的合伙人，也有风格一致却天天吵架的合伙人。**真正的原因是你自己在种"挑拨离间"的种子**——即使你不说出口，只是心里想。

**解药**：**永远不要发表任何挑明或暗示的挑拨离间言论**，无论真假；反过来多说撮合、肯定、支持的真话。

**陈唐实证**：上海时期实践一段时间后——**一位合伙人成了终身好朋友，另外两位自然离开生活**。

## 使用建议

**读法**：详见 [[02方法流程/_stubs/46个商业问题查表法]]。核心是——
- **只选一题**（当下最痛的那个）
- **反查**：找到最接近你问题的一题
- **见好就收**：读完这一段就不要看了
- **2-4 周实践**：不换题
- **不要从头读到尾**（99% 的人卡在第一章）

## 内在张力

- **不可实证**：每一题的解药都是长周期（几个月-几年）的因果链，无法反复验证
- **主观诊断**：**你怎么判断你"对应的是哪一题"**——本身依赖你自己的觉察力
- **易被抽空**：如果只当"打鸡血"读，46 题会退化成一份"心灵鸡汤集锦"
