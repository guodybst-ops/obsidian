# AI时代用户输入放大

## 一句话

LLM 时代最大的变化不是模型能力有多强，而是用户的输入意愿和输入量前所未有地放大——用户第一次愿意写"小作文级 prompt"并持续追问。这是人机交互史上输入量最大的一次范式转移。

## 为什么需要这个概念

过去产品设计的核心假设是"用户输入极少"——推荐吃 action（上滑下滑）、搜索吃关键词（3-5 个字）、社交吃发布（一句话+一张图）。产品设计的优化方向全是"怎么在用户几乎不输入的情况下做对推荐"。AI 第一次让用户愿意大量输入——这意味着产品设计逻辑要彻底重写。

## 定义

| 历史阶段 | 用户输入形式 | 输入量级 |
|---|---|---|
| 搜索时代 | 关键词（3-5 个字） | 极低 |
| 推荐时代 | Action（上滑/下滑/点赞/停留） | 低 |
| 社交时代 | 发布（一句话+图） | 中等 |
| LLM 时代 | 小作文级 prompt + 持续追问 | **高**（历史最高） |

三个重要推论：
1. **下一代推荐引擎会准非常多**——能吃用户的长 prompt（信息量比 action 大一个量级）
2. **用户参与创作门槛崩塌**——"一句人话 = 一段可消费内容"，不需要复杂输入体系
3. **AI 产品设计核心命题变了**——不是"怎么堆功能"，而是"怎么更好激发用户输入 + 把输入用起来"

## 辨析

- vs **推荐引擎的 action 输入**：action 是被动行为信号（用户看到内容后的反应），prompt 是主动意图表达（用户想要什么）。意图信号的信息量远超行为信号。
- vs **搜索引擎的关键词**：关键词是被训练的"压缩表达"（人已经学会了搜索引擎怎么用），prompt 是自然语言表达——更接近人类真实思维。
- 核心变化：不是技术进步允许了更多输入，而是**用户被模型激发出了输入意愿**——这是人机关系的根本变化。
