# [概念] 060-访与谈

## 一句话
采访的两大分类。“访”是刻意设计问题，靠问题被人记住（如美国脱口秀主持人）；“谈”是聊天，靠大量练习和成片率取胜（如鲁豫）。李翔认为两者都需要，但目的不同。
