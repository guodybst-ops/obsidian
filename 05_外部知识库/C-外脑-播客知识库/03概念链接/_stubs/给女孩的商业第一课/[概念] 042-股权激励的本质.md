# [概念] 042-股权激励的本质

## 一句话
是服务于公司薪酬体系的长期薪酬，核心目的是换取员工的“忠诚”，通过利益绑定让员工在做决策时也站在公司角度。原文例子：倪修智用“代练打王者”的比喻，说明高管可能为了短期业绩达标而砍掉研发、营销费用，损害公司长期利益，因此需要股权激励来绑定。
