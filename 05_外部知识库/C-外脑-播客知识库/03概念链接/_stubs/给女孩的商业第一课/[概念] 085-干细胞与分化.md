# [概念] 085-干细胞与分化

## 一句话
老板是干细胞，什么都会；助理是功能细胞，只能承担一个专门功能。分化不是分裂（复制一个自己），而是长出独立功能。一人公司到团队，就是干细胞分化出功能细胞的过程。
