# [概念] 057-是什么

## 一句话
事物本身不具备固定的属性，它是什么取决于观察者。笔在人的眼里是笔，在小狗眼里是磨牙玩具。当人和狗都不在时，它什么都不是，只是一种纯粹的潜能。
