# [概念] 033-超分子控缓释技术

## 一句话
一种专利运载体系，能缓慢释放水杨酸等成分，增效减负。原文例子：吕绍祥博士发明的超分子水杨酸，30%浓度可商品化，而普通水杨酸在酒精中只能配到10%。
