# 门当户对招聘

## 一句话

招聘的本质是**门当户对**——**同类型公司 + 同频老板 + 涮过大厂水**。既不要过高期望（找超出公司体量的人），也不要过低期望（凑合用）。

## 为什么需要这个概念

创业者最常见的招聘幻觉：
- 幻觉 A：**"给我找个阿里 / 字节 / 大厂来的**"（迷信光环）
- 幻觉 B：**"给我找个能力可迁移的**"（迷信学习能力）
- 幻觉 C：**"未来我们要做得很大，先招大厂的**"（超前配置）

**门当户对**打掉这三种幻觉——**招合适的，不是招最优秀的**。

## 定义

"门当户对"由三层匹配构成：

### 层 1：同行（客观市场匹配）

- 候选人过往公司**规模、行业、业务模型**与你相似
- 几十人的公司只找几十人公司出来的人

### 层 2：同频（主观情感匹配）

- 候选人**愿意跟着你老板**（不是被薪酬吸引，是被人吸引）
- 老板文化 = 公司文化（50 人以下），性格是否兼容决定长期能不能干下去

### 层 3：涮过大厂水（生命力匹配）

- 候选人有大厂背景 + 现在在一个更小的公司 + 想回大厂但回不去
- 已经**被抽过嘴巴**，落差期短，能快速融入

## 辨析

- vs **单点匹配（学历 / 大厂标签）**：单点匹配是"名片式招聘"——只看简历标签，不看业务契合；门当户对是"多点耦合"
- vs **能力匹配**：能力是"能做什么"，门当户对是"愿不愿意做 + 能不能在这个环境做"
- vs **文化匹配**：文化匹配是门当户对的"同频"层，但门当户对还多了"同行 + 涮过大厂水"两层
