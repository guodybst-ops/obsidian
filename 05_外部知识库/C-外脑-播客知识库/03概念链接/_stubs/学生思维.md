# 学生思维

## 一句话

期待**标准答案**、期待**被安排**、期待"努力就有回报"、期待"匀速努力→匀速收获"——这是从学校延续到职场的思维模式。反面不是"叛逆思维"，是**市场思维 / 资本视角**：**市场没有标准答案，只有你能给客户提供什么价值**。

## 为什么需要这个概念

- 解释了为什么很多"高学历打工人"出来做副业总卡在 50-100 之间——他们在等一份"副业攻略"
- 解释了法考女孩考五年不过——**用考试逃避市场，因为考试有标准答案，市场没有**
- 解释了摆摊女孩把 60 万年目标"平均分配给两个账号"——用月薪的加法算生意的乘法
- 破除"我练一练就能超越专业选手"、"忽然获得机会"、"万一呢"这类幻想

## 定义

- **学生思维四特征**：
  1. 期待标准答案（"教教我该怎么做"）
  2. 期待被安排（"老板/老师应该告诉我下一步"）
  3. 期待匀速回报（"我努力更新，粉丝应该匀速涨"）
  4. 期待被培养（"公司应该给我机会"）
- **平民创业手册补充特征**：
  1. 把上课、听讲、考试、复盘当成唯一学习路径
  2. 付费后期待别人推着自己学
  3. 用“先系统学习”推迟真实下场
  4. 仍然相信付出一定有回报、对错有标准答案
- **反面（市场思维 / 资本视角 / 专业选手）**：主动扒赛道、主动做用户调研、主动赌爆款、主动进圈子、主动交换

## 学生思维的六种伪装

| 伪装 | 实质 |
|---|---|
| "我先学一学再开始" | 用学习逃避下场 |
| "等我拿到 XX 证书" | 用考试逃避市场 |
| "先给我一个 SOP" | 期待标准答案 |
| "我一直很努力啊" | 用匀速努力替代赌爆款 |
| "我的老板不培养我" | 期待被安排 |
| "万一呢" / "梭哈一下" | 用赌运气替代职业化 |
| "我都交钱了，你还要求我学习" | 把付费当成掌握 |
| "等进入状态再写" | 用状态要求逃避开始 |
