# 换脚本 找杠杆 借力打力

## 一句话

**财富跃迁三件套**：**换脚本**（100→500→1000 万不是月薪加减法，是脚本变了才能跳出打工人剧本）+ **找杠杆**（把一份时间放大 N 倍产生价值，最小杠杆 = 买别人的时间 / GPT）+ **借力打力**（自己得先有力，才能借上别人的力；靠山硬扛实权就是"分不清大小王"）。**没这三样，你只是在同一个脚本里更努力。**

## 为什么需要这个概念

- 解释了为什么"月薪 5 万涨到 10 万"是加法思维——脚本没换，天花板不动
- 解释了为什么"直播商务年入 40 万想上 100 万"该"换客群 / 换杠杆 / 换脚本"，而不是"更卖力"
- 解释了为什么"借刀杀人后没得到利"是段位不够——**借力打力必须自己有力**
- 破除"梭哈 / 豁出去 / 少年心气一把梭"式的伪跃迁——**那不是商业，那是往火坑里跳**

## 定义

- **换脚本**：换客群（To C 无复购 → To B 长期客户）/ 换定位（信息差品 → IP 品牌）/ 换商业模式（一份卖一次 → 一份卖 N 次）
- **找杠杆**：把自己 16 小时的天花板打破的所有工具——买别人的时间 / AI / 平台 / 内容资产 / 关系网络 / 资本
- **借力打力**：借老板的力、借圈子的力、借平台的力、借客户的力；**前提是自己有牌可换**，手里没牌硬借就是空转

## 三段财富跃迁的脚本变化

| 阶段 | 客户数 | 脚本 | 关键动作 |
|---|:---:|---|---|
| **100 万** | 5 个客户 | 靠加减法：月薪 + 副业 | 把每小时投入产出比算清楚 |
| **500 万** | 几个大客户 | 换客群：To B 稳定几十万单 | 加杠杆、买别人的时间 |
| **1000 万** | 1-3 个 To B 大客户 | 完全换脚本：从服务者变成资源方 | 靠护城河（IP/独家/规模） |

**核心红线**：**每一段跳跃 = 换脚本 / 变杠杆 / 换客群 三选一或三个都要动**，不是"再努力一点点"。
