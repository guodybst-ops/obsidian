# 五高法则

## 一句话

用五个“高”判断一个项目是否值得长期投入：高客单、高利润、高粘性、高复购、高转介绍。

## 定义

五高法则是普通人筛选项目和产品的一个检查表。它不负责证明项目一定成功，而是帮助创业者避免进入“看起来热闹，但长期很苦”的低价值项目。

| 维度 | 含义 | 观测信号 |
|---|---|---|
| 高客单 | 单次成交金额足以覆盖获客、交付和沟通成本 | 用户愿意为解决问题支付较高价格 |
| 高利润 | 扣除产品、履约、渠道和服务成本后仍有空间 | 毛利能支撑增长和试错 |
| 高粘性 | 用户解决问题时愿意持续跟随你 | 离不开服务、内容、关系或系统 |
| 高复购 | 同一客户会反复购买 | 需求高频、周期长或可延展 |
| 高转介绍 | 客户愿意主动推荐同类人 | 问题有圈层传播，效果容易被看见 |

## 怎么用

1. 先用 [[02方法流程/_stubs/平民创业手册/[框架] 场景-需求-产品三层选项目框架]] 过一遍场景和需求。
2. 再用五高检查产品层是否值得长期承接。
3. 不要把五高写成固定数值阈值；不同品类的客单、利润和复购标准不同。
4. 如果一个项目只有一两个维度强，要把它当成短期流量项目或练手项目，不要误判成长期事业。

## 辨析

- vs [[03概念链接/_stubs/客户价值 vs 流量价值]]：五高里的高复购、高转介绍更偏客户价值；高客单和高利润帮助判断单客价值是否足够。
- vs [[03概念链接/_stubs/流量驱动商业模式]]：流量驱动项目可以赚钱，但通常更依赖流量供给；五高越多，越有机会沉淀长期客户资产。
- vs 单次爆款：爆款强调某次传播或成交，五高强调一个项目能不能长期投入。
