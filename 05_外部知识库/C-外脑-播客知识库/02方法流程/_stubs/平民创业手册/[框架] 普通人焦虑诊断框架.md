# 普通人焦虑诊断框架

## 一句话

用三类信号判断焦虑来自自我设限、断续挫败还是错误对标。

## 什么时候用

- 感到焦虑、自卑、停滞，但说不清原因。
- 一想到开始做事就想找借口。
- 总拿自己和跨层级对象比较。
- **红线**：如果已经严重影响睡眠、饮食或安全，先寻求专业帮助。

## 评估对象

- 一个具体焦虑场景，而不是整个人生。

## 维度定义

### 维度 1：自我设限

| ✅ 命中信号 | ❌ 未命中信号 |
|---|---|
| 常说“我没学过”“我不是这块料” | 能把不会拆成可学习动作 |
| 还没开始就预设失败 | 已经做过小测试 |
| 用身份标签替代行动 | 用具体能力缺口描述问题 |

→ **怎么观察**：记录自己最近 3 次开口找借口的话。

### 维度 2：断续挫败

| ✅ 命中信号 | ❌ 未命中信号 |
|---|---|
| 做几天就被一次失败打断 | 有连续的小结果记录 |
| 成功经验太少，失败记忆太强 | 能回忆起近期 3 个小胜利 |
| 每次重新开始都很重 | 有心理安全屋任务可以回到正循环 |

→ **怎么观察**：看过去 30 天有没有可视化成果物。

### 维度 3：错误对标

| ✅ 命中信号 | ❌ 未命中信号 |
|---|---|
| 拿自己和大佬终局成果对比 | 只和同阶段的自己比较 |
| 目标遥不可及，行动触手不可及 | 目标拆到今天能做 |
| 看到别人厉害就否定自己 | 能找同阶段样本模仿 |

→ **怎么观察**：写下对标对象和自己当前阶段是否相同。

|---|---|---|---|---|---|
|  | 高/中/低 | 高/中/低 | 高/中/低 |  |  |

## 打完分怎么用

- 自我设限高：先跑 [[02方法流程/_stubs/平民创业手册/[心法] 言出法随自我暗示法]] 或最低动作。
- 断续挫败高：跑 [[02方法流程/_stubs/平民创业手册/[SOP] 心理安全屋小任务法]]。
- 错误对标高：把目标降级到触手可及，并用 [[02方法流程/_stubs/平民创业手册/[SOP] 小事庆祝重塑惯性法]] 找正反馈。

## 常见坑

- 不要把焦虑整体归因为“我不行”。
- 不要跨层级对标后再要求自己马上追上。
- 不要只做情绪安慰，要把焦虑落到具体动作。
