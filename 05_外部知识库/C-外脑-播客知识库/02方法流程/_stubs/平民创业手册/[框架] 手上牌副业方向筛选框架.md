# 手上牌副业方向筛选框架

## 一句话

先盘存款、技能、时间、人脉和本地信息，再选副业路径。

## 什么时候用

- 主业还在，但缺钱，需要找新增收入。
- 不知道副业从本地小店、流量、分销还是人脉带路开始。
- 手里有技能和资源，但没有形成项目判断。
- **红线**：不适用于高杠杆、大投资、自己看不懂的项目。

## 评估对象

- 一个普通人的副业方向或小项目机会。
- 颗粒度要具体到“本周能测试什么”。

## 维度定义

### 维度 1：手上牌

| ✅ 好信号 | ❌ 坏信号 |
|---|---|
| 存款、技能、时间、人脉能列清 | 只说“我想赚钱” |
| 技能能连接到具体客户 | 技能停在自我评价 |
| 有可支配时间 | 每天完全不可控 |

### 维度 2：风险和回本

| ✅ 好信号 | ❌ 坏信号 |
|---|---|
| 投入低、回本周期能估算 | 一上来重资产 |
| 可以小规模试错 | 必须一次性押大钱 |
| 亏损上限可承受 | 失败会影响生活底盘 |

### 维度 3：本地和人脉入口

| ✅ 好信号 | ❌ 坏信号 |
|---|---|
| 本地有同城需求、商家、夜校或小店模型 | 完全脱离自己城市 |
| 人脉中有人在同类生意里 | 只看网上案例 |
| 自己能帮对方解决一个小问题 | 只想让别人带自己赚钱 |

### 维度 4：流量变现速度

| ✅ 好信号 | ❌ 坏信号 |
|---|---|
| 能把人加到微信并转化 | 只有浏览量没有承接 |
| 有明确产品或分销对象 | 只发内容不成交 |
| 目标金额和时间窗口明确 | “赚快钱”没有数字 |

## 打分卡

| 方向 | 手上牌 | 风险回本 | 本地/人脉 | 流量速度 | 结论 |
|---|---|---|---|---|---|
| 低投入小店 | 高/中/低 | 高/中/低 | 高/中/低 | 高/中/低 | 试/补信息/放弃 |
| 本地生活服务 |  |  |  |  |  |
| 流量生意 |  |  |  |  |  |
| 分销 |  |  |  |  |  |

## 打完分怎么用

- 本地和风险分高：先跑一个低投入本地测试。
- 流量速度高：进入 [[02方法流程/_stubs/平民创业手册/[SOP] 四小时流量高手速成法]]。
- 人脉分高：进入 [[02方法流程/_stubs/平民创业手册/[SOP] 工具人混圈法]]。
- 全部低分：先补资源盘点，不急着选项目。

## 常见坑

- 不要一上来追“高大上创业项目”。
- 不要把快钱当成没有风险的钱。
- 不要忽略身边的小店、本地服务和人脉线索。
- 不要只看项目热度，不看自己的手上牌。
