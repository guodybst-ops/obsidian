# 下拉词需求挖掘法

## 一句话

热词是假流量，**下拉词才是真需求**——用主词 + 前缀 + 后缀在各平台搜索框拉出海量下拉词，就能把用户「下单前的犹豫」全部暴露出来。是免费的、可复制的、可穷尽的用户需求调研 SOP。

## 怎么用

### Stage 1：确定主词

主词是你的核心业务/品类（如养生茶、川菜馆、玉林路酒吧、代购山姆、AI 陪跑）。

### Stage 2：三阶段扫描

按用户决策深度扫三遍：

**阶段 1：有需求（模糊）**
- 前缀：什么 / 哪里有 / 有什么 / 什么可以
- 输：`有什么 + 主词`、`什么 + 主词 + 好`
- 例：有什么养生茶推荐、有什么养生茶可以天天喝

**阶段 2：有可选（对比）**
- 前缀：哪个 / 哪家 / 有没有 / 推荐
- 输：`哪家 + 主词 + 好`、`推荐 + 主词`
- 例：哪家川菜馆有兔腿、推荐玉林路酒吧

**阶段 3：要决策（临门一脚）**
- 前缀：能不能 / 可以 / 怎么 / 什么时候 / 最好
- 输：`主词 + 可以 + 场景吗`、`主词 + 最有效`
- 例：养生茶可以天天喝吗、烧烤怎么拍出片

### Stage 3：字母穷举法

对同一主词穷举字母：`西藏旅行 A` → 出现所有 A 开头下拉词，`B` `C` `D` …… 拉出平台完整下拉词库。

### Stage 4：田野调查 + 大数据调查

- **大数据**：闲鱼租一天专业调研工具（3-5 元/天），比自己包月省钱
- **田野**：工作日 + 非工作日各去一次目标商圈，带秒表和笔记本记人流

### Stage 5：分类用户心理

按下拉词的语义把用户心理归类：
- 担心健康 / 担心风险 / 找附加值 / 探索可行性 / 找选项 / 找权威 / 找性价比 / 找操作指南

### Stage 6：内容/产品双向应用

- **内容**：围绕高价值下拉词做标题（3000 词 × 一条 30 人/天 = 10 万精准流量）
- **产品**：把下拉词高频出现的痛点做进产品卖点/FAQ

## 完整示例

某养生茶品牌：
- 主词 = 养生茶
- 三阶段扫描出下拉词 800+：养肝 / 视力 / 天天喝 / 月经 / 备孕 / 皮肤 / 咽喉 / 减肥 / 会不会胖……
- 分类得 6 大用户心理：养生 / 女性周期 / 备孕 / 外貌 / 风险担忧 / 便携
- 内容：每个心理各出 5 条短视频占位 top 3 下拉词
- 产品：`备孕养生茶 / 月经养生茶` 两个 SKU 直接从下拉词命名

## 适用场景与边界

- **适用**：SEO/内容流量项目、本地生活、产品/SKU 命名、FAQ 设计
- **不适用**：品牌型高客单产品（人家不搜关键词搜品牌）、B2B 复杂决策产品
- **已知局限**：小红书 2025 之后开始压制大量下拉词工作室，直接抄下拉词做笔记的账号被限流；下拉词代表流量入口不代表转化——转化还要看内容质量和信任
