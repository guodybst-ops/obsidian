# 狡辩抱怨提醒法

## 一句话

在被质疑和想抱怨时，先识别下一句话是不是在保护面子或传递负能量。

## 什么时候用

- 被别人指出问题后，马上想解释。
- 团队、关系或客户沟通里想抱怨环境。
- 发现自己说完话后场面变冷。
- **红线**：不是要求压抑真实问题，而是先把情绪和事实分开。

## 主流程

### Step 1：被质疑后停 3 秒

问自己：

```text
我下一句话是在澄清事实，还是在保住面子？
```

### Step 2：如果已经狡辩，直接承认

可用句：

```text
不好意思，刚才我在狡辩。
我重新说一下事实和下一步处理。
```

### Step 3：抱怨前先转成问题

把“这个太烂了”改成：

```text
现在卡点是____，我能先处理的是____。
```

### Step 4：记录高频抱怨主题

连续出现 3 次的抱怨，不再当情绪处理，而要进入问题清单。
