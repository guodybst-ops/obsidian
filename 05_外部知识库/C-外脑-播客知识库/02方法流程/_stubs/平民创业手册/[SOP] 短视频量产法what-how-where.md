# [SOP] 短视频量产法what-how-where

## 一句话

用内容库、低成本拍摄和多平台分发，把短视频从灵感创作变成稳定量产。

## 什么时候用

- 想做短视频获客，但不知道发什么。
- 有行业知识或服务能力，但表达和拍摄迟迟启动不了。
- 已经能做内容，但只发一个平台，内容边际收益没有放大。
- 需要把一个选题改造成短视频、图文、问答、长文、PDF 等多种形态。

## 输入与输出

| 类型 | 内容 |
|---|---|
| 输入 | 一个行业或业务方向、同行爆款样本、行业百科/问答/大 V 关注列表、可用拍摄设备 |
| 输出 | 可持续更新的选题库、口语化脚本库、低成本拍摄流程、多平台分发清单 |
| 完成标准 | 能持续日更或多更，并能根据数据保留有效标题、选题、表达和平台 |

## 怎么用

### Step 1：先选“有用且与用户有关”的内容

把内容先分成“有趣”和“有用”。如果目标是赚钱和获客，优先选有用内容：教程、讲解、测评、科普、搭配、避坑、案例拆解。

判断一句话：用户看到时会不会觉得“这和我有关”。

### Step 2：建立被市场验证过的内容库

从这些地方找选题，不从空白灵感开始：

| 来源 | 怎么找 | 使用方式 |
|---|---|---|
| 行业百科/行业网站 | 看基础概念、常见问题、热门词条 | 变成白话讲解 |
| 同行爆款 | 看标题、节奏、道具、场景、评论区 | 学结构，不机械照搬 |
| 跨平台内容 | 把 A 平台成熟内容改成 B 平台表达 | 做形式迁移 |
| 观测号 | 用新号搜索领域关键词，持续校准推荐流 | 找新鲜选题 |
| 大 V 关注列表 | 从一个大 V 顺藤摸瓜找一批行业节点 | 建行业信息源 |

### Step 3：把成熟内容转成自己的口语脚本

用“边听边复述”的方式提高脚本生产效率：一台设备播放成熟内容，另一台设备语音转文字，自己用能讲明白的方式复述。

要求：

- 用大白话，不用行业黑话堆砌。
- 能扛住追问，自己没理解的内容不要硬讲。
- 可参考选题、结构和表达节奏，不直接搬运他人的完整稿件、素材和版权内容。
- 标题和脚本一起沉淀，便于后续检索和复用。

### Step 4：用低成本设备先开拍

不要把设备升级当成开拍前置条件。新手阶段可用手机、三脚架、云台支架、纽扣麦、物理提词器完成第一版。

拍摄时假设镜头对面坐着一个十三四岁的小外甥：讲大白话，有耐心，带着愿意把事情讲清楚的状态。

### Step 5：用小稿反复拍，跨过镜头恐惧

先选一段 160 字左右的稿子背熟，连续拍 30-50 次。很多“镜头恐惧”本质是“台词恐惧”，先把稿子熟到能自然说出来。

拍摄时尽量咬字清晰、节奏慢一点；剪辑时可适度加速，例如 1.2 倍速，让成片更紧凑。

### Step 6：用统一规格降低后期成本

优先采用易复用的画幅和模板。原文建议用 1:1 画幅拍摄，后续可适配竖屏和横屏，降低一条内容多平台分发的改造成本。

可复用的后期模板包括：

- 开头直接进入主题或精华，不寒暄。
- 标题序列化，让用户进入主页继续看。
- 固定服装、饰品、封面、视觉锤或听觉锤，形成辨识度。
- 一份内容同步沉淀为短视频、图文、问答、长文、卡片等形态。

### Step 7：多平台分发，用数量覆盖概率

内容一旦生产出来，边际成本接近 0。只要分发成本足够低，就把内容发到适合的平台，而不是只守一个入口。

核心判断：

- 短视频的关键是稳定供给和日更。
- 爆款不是纯技术，而是概率。
- 矩阵号是单号跑通后的放大结果，不是新手一开始逃避基本功的捷径。

## 常见坑

| 坑 | 表现 | 修正 |
|---|---|---|
| 把 what-how-where 误解成脚本三段式 | 每条视频都硬套“是什么/怎么做/在哪用” | 回到原意：发什么、怎么发、发哪里 |
| 原创洁癖 | 什么都想自己凭空创造 | 先用被市场验证过的内容库训练表达 |
| 设备焦虑 | 买器材、搭棚、等完美条件 | 先用手机和提词器开拍 |
| 机械搬运 | 直接复制别人的稿件和素材 | 学结构和选题，改成自己能负责的表达 |
| 矩阵迷信 | 一个号没跑通就开很多号 | 先跑通单号，再扩展矩阵 |
| 只发一个平台 | 内容生产后只投一个入口 | 把内容改造成多形态、多平台 |

## 适用边界

- 适合知识型、服务型、教程型、测评型、本地生活和个人 IP 的低成本获客。
- 不适合必须严审合规、不能轻易改编表达的内容，例如医疗诊断、金融承诺、法律结论等。
- “日产 200 条”更像量产方向和效率要求，不是每个个体必须照抄的硬指标。
- 涉及大学生分发、兼职、矩阵协作时，应明确劳动报酬、授权边界和平台规则，不能只把“便宜”当优势。
