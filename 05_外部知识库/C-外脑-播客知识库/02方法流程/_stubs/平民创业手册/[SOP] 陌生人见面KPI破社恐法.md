# 陌生人见面KPI破社恐法

## 一句话

把“见人很消耗”改写成可训练技能，用每月 8 个陌生人见面实验验证自己是否真的不适合高社交。

## 什么时候用

- 自认为社恐、宅、i 人，不愿见人。
- 想提高社会关系建立与维护能力。
- 需要找对象、做销售、做创业或扩大信息面。
- **红线**：如果连续两个月完成后仍明显痛苦，应承认边界，不要硬把自己压坏。

## 主流程

### Step 1：先重写指令

把“见人很消耗”改成：

```text
见人让我获得别人的经历、道理和社会切片。
```

### Step 2：设定 1 个月 KPI

每月见 8 个陌生人。

可以来自：

- 线下活动。
- 社群饭局。
- 朋友介绍。
- 同城兴趣局。
- 业务拜访。

### Step 3：每次只记录三件事

| 问题 | 记录 |
|---|---|
| 我从对方身上学到什么？ |  |
| 哪个瞬间让我消耗/滋养？ |  |
| 下次怎么更舒服？ |  |

### Step 4：连续两个月复盘

如果两个月都完成，但仍异常难受，没有快感或成就感，可以降低社交强度。

如果开始出现滋养感，再逐步加量。
