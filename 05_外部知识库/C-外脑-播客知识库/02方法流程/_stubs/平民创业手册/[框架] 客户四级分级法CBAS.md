# 客户四级分级法 C B A S

## 一句话

按客户已经发生的交互深度，把微信客户动态分为 C、B、A、S 四级，用来决定谁优先跟进、谁降级、谁放生。

## 什么时候用

- 你做的是高客单、高利润、长周期、强信任的私域生意。
- 微信客户数量多，销售/客服产能有限，不可能人人高频跟进。
- 节日、上新、促销、邀约到店等节点来临，需要快速判断应该先联系谁。

不适合：低客单快消、纯平台即时成交、没有长期私域关系沉淀的业务。

## 评估对象

每一个已经加到微信或进入私域的潜在客户。

## 四级定义

| 等级 | 原始判断 | 行为信号 | 跟进重点 |
|---|---|---|---|
| C 级 | 刚加上，还没有有效交互 | 通过好友、看过朋友圈、轻微点赞，但没有实质咨询 | 让他继续看内容，等待需求信号 |
| B 级 | 已经聊过一定轮次 | 聊过多句，表达兴趣，问过基础问题 | 用案例、问答、轻触达推进到明确需求 |
| A 级 | 已经问到报价、细节、服务或产品方案 | 要报价表、问操作细节、问服务流程、问产品细节 | 优先跟进，解决顾虑，推动预约或下一步 |
| S 级 | 已经约见面、约到店或约具体成交动作 | 约时间、约到店、约面谈、约方案沟通 | 最高优先级，确保承接和到场 |

## 怎么用

### Step 1：新客户默认 C 级

所有刚加上的客户先标 C。不要因为头像、职业、朋友圈看起来“有钱”就直接升高等级，分级依据是行为，而不是想象。

### Step 2：按交互推进升级

客户从 C 到 S 的升级路径是：

```text
C：刚加上
-> B：聊过较多内容
-> A：问报价、问细节、问服务/产品方案
-> S：约见面、约到店、约具体成交动作
```

### Step 3：节点触达先找 A/S

当中秋、促销、上新、活动、档期开放时，先筛 S 和 A，再看 B，最后才是 C。这个顺序的目的不是“势利”，而是让销售产能先服务高意向客户。

### Step 4：长期无进展要降级

如果 A 级客户连续多次邀约不到店，先降为 B；再无反馈，降为 C；继续无反馈，就进入放生。

### Step 5：放生不是删除

放生的意思是停止高频主动跟进，把客户留在朋友圈里长期被内容触达。旧稿里“半年无互动就删除”的写法偏离原文，本轮已回源修正。

## 打分卡

| 问题 | 是 | 否 |
|---|---|---|
| 是否已经加上微信/私域？ | C 起步 | 暂不分级 |
| 是否聊过多轮有效内容？ | B | 留在 C |
| 是否问报价、细节、服务或方案？ | A | 留在 B/C |
| 是否约见面、约到店或约下一步成交动作？ | S | 留在 A/B/C |
| 是否连续多次邀约无反馈？ | 降级/放生 | 维持当前等级 |

## 完整示例

一个高客单医美客户刚从小红书加到微信，标记为 C。她连续询问恢复期、医生、价格区间，升级为 B；随后要了报价表，并追问项目细节，升级为 A；最后约了周六到店面诊，升级为 S。若她之后连续两个月约不到店，则从 A/S 降级到 B；再无反馈则降 C，并停止高频私聊，只保留朋友圈内容触达。

## 常见误判

- 把 S 级误写成“转介绍/圈层背书”。003 原文中 S 的定义是约见面、约到店，不是转介绍。
- 把 A 级误写成“复购客户”。003 原文中 A 的定义是问报价、问细节、问服务或产品方案。
- 只升级不降级。分级是动态的，客户行为变冷就要把产能释放出来。
- 把放生等于删除。原文里的放生是停止主动骚扰，让客户继续在朋友圈里慢慢发育。
