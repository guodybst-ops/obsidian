# 观测号网感训练法

## 一句话

把账号训练成行业观察器，持续拆广告、内容和转化链路。

## 什么时候用

- 想快速进入一个新行业或新赛道。
- 刷到广告、同行内容、落地页时想练网感。
- 需要理解一个项目从公域到私域再到成交的完整链路。
- **红线**：不要用主账号乱点无关内容，避免污染推荐流。

## 输入与输出

| 类型 | 内容 |
|---|---|
| 输入 | 一个观测号、目标行业关键词、3-5 个对标博主或广告 |
| 输出 | 行业内容库、广告链路拆解、私域转化观察记录 |
| 完成标准 | 3 小时内能说清这个行业常见入口、话术、转化物料和群运营方式 |

## 主流程

### Step 1：设定观测身份

- 给账号只喂目标行业内容。
- 无关内容一律点“不感兴趣”。
- 目标内容看完、收藏、点赞或评论，让系统继续推送同类信息。

### Step 2：拆广告落地页

- 看到广告先不要关，点进落地页。
- 记录标题、承诺、表单、按钮、价格、福利和信任背书。
- 如果可承受，留一次观察手机号，看对方如何跟进。

### Step 3：进入私域链路

- 加对方微信、群或资料包入口。
- 看朋友圈、海报、报价单、招商手册、群公告。
- 记录转化频次、话术顺序、托的存在感和放弃节点。

### Step 4：沿关注列表追一窝

- 找到一个目标博主，继续看他关注谁、互动谁、评论区谁出现。
- 3-4 小时内整理一组同赛道账号。
- 用相同表格记录各账号的内容、产品、成交方式。

### Step 5：输出拆解卡

每个观察对象写一张卡：

```text
入口：
承诺：
信任背书：
转化动作：
私域承接：
我能复用的结构：
我不能直接抄的素材：
```

## 常见坑

- 不要只看爆款，要看从曝光到成交的完整链路。
- 不要只截图收藏，必须写成拆解卡。
- 不要把无关娱乐内容喂给观测号。
- 不要直接盗用同行素材，只复用结构和节奏。
