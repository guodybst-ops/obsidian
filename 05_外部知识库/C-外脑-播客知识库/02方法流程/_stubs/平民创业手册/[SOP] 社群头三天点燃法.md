# [SOP] 社群头三天点燃法

## 适用场景

新群刚建立，必须让成员相信这个群值得置顶和参与时使用。

## 操作步骤

1. 建群前准备群规、交付内容、欢迎话术和互动主题。
2. 头三天高密度分享与主题相关的高价值内容。
3. 每天用问题、案例、资料和红包制造参与。
4. 发现歪楼及时拉回主题。
5. 三天内让核心成员被看见，让成员有第一次互动记忆。
