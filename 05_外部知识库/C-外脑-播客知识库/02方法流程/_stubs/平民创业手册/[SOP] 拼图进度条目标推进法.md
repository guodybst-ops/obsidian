# 拼图进度条目标推进法

## 一句话

把目标拆成拼图，把每块拼图标上完成度，让每一步都算数。

## 什么时候用

- 已经写出目标，但不知道怎么推进。
- 目标太大，行动反馈太慢。
- 想让成长过程具备可见进度。
- **红线**：不要只靠意志力硬撑长期目标。

## 输入与输出

| 类型 | 内容 |
|---|---|
| 输入 | 一个具体目标、当前状态、可拆分要素 |
| 输出 | 拼图清单、每块进度条、下一步动作 |
| 完成标准 | 每一块拼图都有负责人、动作、资源和完成度 |

## 怎么用

### Step 1：写目标句

模板：

```text
谁，要通过什么方式，在未来多少年内，实现什么结果。
```

### Step 2：列拼图

用问题拆：

- What：要做哪些事？
- When：什么时候做？
- Where：在哪里做？
- Who：需要谁协作？
- Why：为什么做？
- How：怎么做？
- How long：做多久？
- How much：需要多少资源？

### Step 3：给每块拼图标进度

格式：

```text
拼图名称：当前完成度 0%-100%
缺口：
下一步：
```

### Step 4：把进度放到每天能看到的位置

可以做成：

- 手机屏保。
- 桌面清单。
- 纸质看板。
- 周复盘表。

### Step 5：每周更新一次进度条

只问：

- 哪块推进了？
- 哪块卡住了？
- 下一步最小动作是什么？
