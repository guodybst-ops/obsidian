# [SOP] 最小指令超额完成法

## 适用场景

当任务太大导致拖延、不启动、不敢承诺时使用。

## 操作步骤

1. 把任务压到小得离谱，例如 5 个俯卧撑、2 分钟电话、100 字。
2. 只要求自己完成这个最低指令。
3. 一旦开始，允许身体和惯性自然超额完成。
4. 记录超额完成带来的爽感，把它变成下一次启动的证据。
