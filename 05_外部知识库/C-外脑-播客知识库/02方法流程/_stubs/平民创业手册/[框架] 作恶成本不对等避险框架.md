# [框架] 作恶成本不对等避险框架

## 适用场景

当你和陌生人、服务者、底层从业者、情绪失控者、离职员工、路怒对象发生摩擦时使用。

## 判断口径

1. 先判断双方要守护的东西是否对等。
2. 如果对方牵挂少、沉没成本低、情绪濒临崩溃，就不要升级冲突。
3. 不在路上、餐馆、停车、公共场合争输赢。
4. 对合作和员工关系提前设计权限、补偿、交接和退出机制。
5. 把“少树敌”当成经营修养，而不是软弱。
