# [框架] 50加1000社群资产框架

## 适用场景

个人 IP、超级个体或创业者想把长期人脉和铁杆粉丝沉淀成可运营资产时使用。

## 资产结构

1. 50 人群：用 10 年筛出良师益友，标准是能放心把后背交给他。
2. 1000 人群：两个 500 人群，沉淀铁杆粉丝、老客户、长期互动者。
3. 50 人群负责高质量信息、资源和长期关系。
4. 1000 人群负责稳定传播、转化、反馈和低成本启动。
