# [SOP] 付费社群从拉群开始法

## 适用场景

普通人想从最小商业闭环开始，测试付费、交付、关系和私域转化时使用。

## 操作步骤

1. 没想清楚交付前不要轻易建群。
2. 明确群的目的：收费交付、好物转化、行业连接、陪伴打卡或客户池。
3. 设计进群门槛和退出机制。
4. 头三天集中交付价值和互动。
5. 持续维护信噪比、话题方向和核心成员。
