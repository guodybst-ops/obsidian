# 指标目标分离框架

## 一句话

指标是量化刻度，目标是你真正想改变的状态。

## 什么时候用

- 被体重、分数、天数、数量绑架。
- 完成很多指标却没变好。
- 因为漏掉一天就否定长期成果。
- **红线**：不要用“目标更大”逃避指标，指标仍然需要跟踪。

## 对照表

| 指标 | 目标 |
|---|---|
| 减几斤 | 变美、健康、自信 |
| 考几分 | 发现问题、提升学习效率 |
| 读几本书 | 学技能、寻求知识、满足好奇 |
| 连续日更 | 形成表达和自律 |

## 主流程

### Step 1：写下指标

明确可量化的刻度。

### Step 2：追问目标

问：

```text
我真正想通过这个指标获得什么？
```

### Step 3：允许指标服务目标

如果目标一直实现中，不要因为指标偶尔中断过度惩罚自己。
