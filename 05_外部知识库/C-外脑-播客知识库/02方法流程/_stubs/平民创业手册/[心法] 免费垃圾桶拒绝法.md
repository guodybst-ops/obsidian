# [心法] 免费垃圾桶拒绝法

## 适用场景

当别人持续向你倾倒负能量，却并不想解决问题时使用。

## 操作口径

1. 区分“求助”与“情绪倾倒”。
2. 对方只是要发泄时，不急着给建议。
3. 不把免费倾听误当成善良和责任。
4. 如果这本就是你的职业服务，要明确付费边界。
5. 对无法承接的情绪，直接缩短对话、转移场景或退出关系。
