# [框架] 增长窗口All-in框架

## 适用场景

一个项目已经验证赚钱，但创业者犹豫要不要小富即安、分散精力或继续放大时使用。

## 判断口径

1. 判断是否已经有真实赚钱结果，而不是只有感觉。
2. 判断时间窗口是否正在缩短，是否存在信息差、平台口子、风口或流量红利。
3. 如果窗口短且结果真，集中人力、财力、资源和精力放大。
4. 不在窗口期过度分散鸡蛋。
5. 警惕红利尾声卖信息差的人，不做最后上桌的人。
