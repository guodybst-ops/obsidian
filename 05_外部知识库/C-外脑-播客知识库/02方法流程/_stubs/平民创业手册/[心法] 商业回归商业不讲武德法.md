# [心法] 商业回归商业不讲武德法

## 适用场景

普通人因为觉得项目 low、微商 low、快团团 low、追热点 low，而迟迟不下场赚钱时使用。

## 操作口径

1. 先判断是否合法。
2. 再判断是否真实赚钱、真实交付、真实满足需求。
3. 不用情怀、价值观、使命愿景去提前否定商业本身。
4. 价值观是自我约束，不是判断别人项目上限的唯一标准。
5. 先解决吃饭、家庭、现金流，再谈阳春白雪。
