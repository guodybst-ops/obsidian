# [SOP] Yes-and销售法与临门一脚

## 一句话

先相信产品、识别真客户、用案例和具体跟进推动成交，不和客户争输赢。

## 什么时候用

- To B 或高客单销售遇到客户说“再想想”“太贵”“过几天”。
- 客户需求不清楚，销售不知道该讲产品、讲案例还是讲优惠。
- 销售容易和客户争论，或者一遇到异议就降价。
- 想把“临门一脚”从玄学话术变成可复盘动作。

## 输入与输出

| 类型 | 内容 |
|---|---|
| 输入 | 目标客户资料、接触人身份、客户需求、产品价值、同行案例、可给出的服务或优惠 |
| 输出 | 客户判断、需求说明、案例证明、下一次跟进时间、可成交的付钱理由 |
| 完成标准 | 能判断对方是真客户还是敷衍；跟进动作具体；优惠不破坏产品价值 |

## 怎么用

### Step 1：先做到“900% 相信产品”

销售基本法的第一条，是自己先相信产品能解决问题。这里不是盲目自嗨，而是要能讲清：

- 产品或服务解决什么问题。
- 能为客户带来什么效益。
- 典型客户为什么选择你。
- 产品有哪些边界，哪些客户不适合。

如果自己都说不清价值，临门一脚只会变成硬推。

### Step 2：判断客户和决策链

先了解目标客户，不要一上来就讲产品。

| 判断项 | 要问清楚 |
|---|---|
| 企业基本面 | 规模、组织架构、行业地位、竞争对手、融资情况 |
| 接触人角色 | 是否是关键人物、决策人、影响人或信息传递人 |
| 真实需求 | 效率提升、成本控制、自动化、信息化、品宣声量，还是随大流 |
| 付费能力 | 是否有预算、是否有钱、是否有真实采购动机 |

如果“明月不是对的人”，再努力也可能只是错配。

### Step 3：把价值说具体

把产品价值翻译成客户能听懂的效益，例如：

- 降低流量成本。
- 提高销售额。
- 优化人力资源。
- 控制物流或运营成本。
- 提升品牌声量。

越具体，客户越容易判断值不值。

### Step 4：用案例撬动案例

当严肃科普和产品说明不够时，用相邻案例降低客户决策成本。

优先准备：

- 同行业案例。
- 同规模案例。
- 同区域案例。
- 竞品或相似客户案例。

案例的作用不是炫耀，而是让客户产生“别人已经验证过”的安全感。

### Step 5：用 Yes-and 承接异议

客户说贵、风险大、想再看时，不要硬刚，也不要马上降价。

句式：

> 是的，您谨慎是对的；同时这件事真正要看的不是单次价格，而是维护成本、风险成本和长期收益。

要点：

- 先承认客户感受。
- 再补充你能提供的事实、服务、配置和风险防护。
- 不用“但是”把客户推到对立面。
- 不争论对错，让客户在沟通里保留体面。

### Step 6：把“再想想”变成明确跟进

客户说“过几天”“再看看”时，不停在模糊状态。

可操作动作：

1. 约定下一次跟进时间。
2. 带一个时效性理由回来，例如优惠截止、名额、档期、方案更新。
3. 如果再次推脱，判断是没需求、没钱，还是不是关键人。
4. 拿不到结果也是结果，把精力转向更大的流量池。

### Step 7：给客户更多付钱理由

临门一脚不是无底线降价，而是增加成交理由。

可用方式：

- 不影响价值的价格优势。
- 时效性强的优惠政策。
- 有实际意义的赠品。
- 同行没有、你能提供的服务。
- 更明确的交付保障。

原文的判断是：同行都有的叫义务，同行没有的才叫服务。

## 常见坑

| 坑 | 表现 | 修正 |
|---|---|---|
| 把临门一脚当神话术 | 想靠一句话成交 | 回到客户、需求、案例、服务和跟进 |
| 客户说贵就降价 | 先自降身价 | 先承认感受，再解释价值和风险 |
| 和客户争论 | 赢了道理，输了关系 | 让客户赢，才可能双赢 |
| 只有几个客户 | 看谁都像在犹豫 | 做大流量池，别把假客户当真客户 |
| 案例不匹配 | 拿不相关大客户压人 | 用行业、规模、场景相邻案例 |
