# 穿搭服务MVP验证法

## 一句话

用低价穿搭服务先拿一手需求，再决定产品化方向。

## 什么时候用

- 有穿搭、审美、摄影、视频或社群基础。
- 手里有粉丝或读者，但不知道卖什么产品。
- 想把内容能力转成服务收入。
- **红线**：不要先做大课、复杂社群或重交付产品。

## 输入与输出

| 类型 | 内容 |
|---|---|
| 输入 | 存量用户、穿搭能力、服务海报、100 个试错名额 |
| 输出 | 付费用户、真实需求、服务案例和产品价格区间 |
| 完成标准 | 完成 10-30 个付费服务并知道用户真正买什么 |

## 主流程

### Step 1：列可卖服务

从轻到重列：

- 带货推荐。
- 穿搭咨询。
- 衣橱整理。
- 商场陪买。
- 风格改造。
- 穿搭社群。

### Step 2：先做一张海报

海报写清：

```text
适合谁：
解决什么问题：
怎么服务：
价格：
名额：
案例/信任背书：
```

### Step 3：在存量里低价测试

- 前 100 个用户可以便宜。
- 目标不是利润最大化，而是一线体感。
- 每次服务后收集问题、照片、反馈和复购意愿。

### Step 5：升级正式产品

- 需求稳定后，提高价格。
- 把重复问题做成清单、课程或社群。
- 保留高客单一对一服务。

## 常见坑

- 不要把存量点赞当成付费意愿。
- 不要一开始追求高端定位，先拿需求。
- 不要只做带货，忽略咨询和服务利润。
- 不要用低价服务长期消耗自己，验证后要涨价或产品化。
