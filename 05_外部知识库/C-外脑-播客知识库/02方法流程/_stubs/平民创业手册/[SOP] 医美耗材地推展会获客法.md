# [SOP] 医美耗材地推展会获客法

## 适用场景

代理医美外科耗材、品牌弱、竞品强、线上 To B 转化慢时使用。

## 操作步骤

1. 先判断能否刹车，方向错了停下来就是前进。
2. 如果不能退，先跑完本地所有可能采购机构。
3. 参加医美、器械、行业沙龙、展会，把微信加满。
4. 备注好机构、角色、采购可能性和痛点。
5. 回去后按分组发仅对其可见的朋友圈做精细化触达。
6. 线上先做品牌关键词和品宣占位，不急着指望直接转化。
