# T字技能项目匹配法

## 一句话

左边写技能，右边写项目/资源/兴趣，再筛到各 3 个，找出当前最适合试的方向。

## 什么时候用

- 已经盘点出几个技能，但不知道接什么项目。
- 机会太多，想先做一次低成本匹配。
- 想避免只凭热情选项目。
- **红线**：匹配结果只是候选，不等于市场验证。

## 主流程

### Step 1：画 T 字表

左边写技能，右边写项目、资源和兴趣。

| 左：技能 | 右：项目/资源/兴趣 |
|---|---|
|  |  |

右边可以包括：

- 听说过的项目。
- 身边有人做的生意。
- 自己喜欢的产品或领域。
- 自己能触达的人群。

### Step 2：两边各筛到 3 个

左边保留最有把握的 3 个技能。

右边保留最想做、最容易触达、试错成本最低的 3 个方向。

### Step 3：做 3×3 组合

把每个技能和每个方向连线，写出一个可试动作。

例如：

```text
写作 × 健身 = 本地私教体验测评账号
销售 × 房产 = 同城小区买房避坑号
搜索 × AI = AI 热点日报搬运筛选号
```

### Step 4：选一个 7 天实验

优先选最容易拿到反馈的一组，做 7 天小实验。

实验只看是否出现真实反馈，不看幻想空间。
