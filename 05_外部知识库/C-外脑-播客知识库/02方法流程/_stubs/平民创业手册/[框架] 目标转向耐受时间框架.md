# 目标转向耐受时间框架

## 一句话

用证据、时间和成本判断该坚持还是转向。

## 什么时候用

- 裸辞后项目推进不顺，怀疑方向错了。
- 一边想相信涌现，一边担心自己在畏难。
- 小项目已经试了一段时间，但没有结果。
- **红线**：不要把频繁换方向包装成灵活。

## 评估对象

一个正在执行但结果不明的项目、职业选择或副业方向。

## 维度定义

| 维度 | 好信号 | 坏信号 |
|---|---|---|
| 方向证据 | 有真实反馈和进展 | 只有自我安慰 |
| 耐受时间 | 事前设了观察周期 | 不舒服就立刻放弃 |
| 转向成本 | 转向后损失可控 | 已经绑死高固定成本 |

## 决策树

```text
有反馈但慢 -> 继续到耐受时间结束
没反馈且已过耐受时间 -> 停下来复盘或转向
方向明显错且成本低 -> 停下来就是前进
只是畏难 -> 缩小动作，不立刻换方向
```

## 打完分怎么用

- 大船：先降低固定成本，再考虑转向。
- 小船：保留机动性，快速测试新方向。
- 拿不到结果：也当作结果，记录为什么拿不到。
