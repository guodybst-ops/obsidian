# 平民卖货供应链三步框架

## 一句话

用代发试错、选品找货、供应商筛选三步判断卖货机会。

## 什么时候用

- 准备从内容、流量或私域切到卖货。
- 手里有产品线索，但不知道先囤货还是代发。
- 想判断一个品类是否值得继续找供应商。
- **红线**：不用于绕过授权、侵权卖货或违反平台规则。

## 评估对象

- 一个具体品类、产品或货源机会。
- 颗粒度要到“可以找货、询价、拿样”的程度。

## 三步维度

### 维度 1：代发起步可行性

| ✅ 好信号 | ❌ 坏信号 |
|---|---|
| 支持一件代发或小单试发 | 必须大额起订 |
| 订单系统、电子面单、密文下单可配合 | 只能人工低效对接 |
| 售后和退货责任能讲清 | 退货、破损、超时责任含糊 |
| 素材可差异化 | 只有全网通用图 |

### 维度 2：选品和供给地图

| ✅ 好信号 | ❌ 坏信号 |
|---|---|
| 能在 1688、淘宝、拼多多找到多家对照 | 只有单一渠道 |
| 能定位产业带或类目圈子 | 不知道源头供给在哪里 |
| 有品牌授权或素材原文件 | 授权链路缺失 |
| 小众但有明确需求 | 只是自己觉得新奇 |

### 维度 3：供应商和成本结构

| ✅ 好信号 | ❌ 坏信号 |
|---|---|
| 价格、账期、退货、快递费能拆开谈 | 只给一个含糊报价 |
| 老板能沟通，朋友圈显示长期做本行 | 账号新、信息少、口气飘 |
| 小单交付稳定 | 样品好，大货差 |
| 有备选供应商 | 命脉完全握在一家手里 |

### 维度 4：仓储和履约控制

| ✅ 好信号 | ❌ 坏信号 |
|---|---|
| 自有仓、代发仓、云仓或厂家代发的边界清楚 | 只知道“能发货” |
| 快递、退货、补货、账期和错发责任已谈清 | 高峰期掉链子才发现问题 |
| 产品重量体积适合长期履约 | 抛货、重货、异形件成本未算 |

## 打分卡

| 产品/品类 | 代发可行性 | 供给地图 | 供应商稳定性 | 成本理解 | 综合结论 |
|---|---|---|---|---|---|
|  | 高/中/低 | 高/中/低 | 高/中/低 | 高/中/低 | 试卖/补信息/放弃 |

## 打完分怎么用

- 代发可行性高、供给地图清楚、供应商稳定：进入 [[02方法流程/_stubs/平民创业手册/[SOP] 一件代发起步风控法]]。
- 供给地图不清楚：先做 [[02方法流程/_stubs/平民创业手册/[SOP] 1688选品找货法]]。
- 成本和供应商不清楚：进入 [[02方法流程/_stubs/平民创业手册/[SOP] 供应商筛选与成本拆解法]]。
- 多项低分：不要囤货，先停止或换品类。
- 仓储履约低分：先进入 [[02方法流程/_stubs/平民创业手册/[框架] 仓储形态选择框架]]，不要只优化前端销售。

## 常见坑

- 不要把“能代发”误认为“有优势”。
- 不要一开始就执着绕过贸易公司找工厂。
- 不要只看表面价格，不拆快递、退货、账期和补贴。
- 不要把单一供应商当长期护城河。
