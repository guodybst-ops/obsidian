# 信息增量争论识别法

## 一句话

判断一段争论有没有价值，就看它是否提供事实、依据、机制或可验证变量。

## 什么时候用

- 开会、评论区、家庭沟通或业务争论陷入情绪。
- 分不清对方是在反驳，还是在转移话题。
- 想识别没有信息量的抬杠。
- **红线**：不要用“你没信息量”压人，先回到事实和问题。

## 判断表

| 类型 | 信息增量 |
|---|---|
| 人身攻击 | 无 |
| 情绪标签 | 低 |
| 历史惯例 | 低到中 |
| 具体事实 | 高 |
| 数据/案例/机制 | 高 |
| 可执行方案 | 高 |

## 主流程

### Step 1：找对方新增了什么

如果只有“幼稚、不可理喻、你不懂”，信息增量很低。

### Step 2：识别转移话题

把“你也不咋地”拉回原问题。

### Step 3：要求补依据

问：

```text
你这个判断的依据是什么？
取消/执行后会具体影响哪一块？
有没有案例或数据？
```
