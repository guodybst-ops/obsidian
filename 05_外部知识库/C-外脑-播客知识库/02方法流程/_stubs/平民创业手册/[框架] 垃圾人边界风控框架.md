# [框架] 垃圾人边界风控框架

## 适用场景

当你必须和情绪不稳、作恶成本低、长期抱怨、损人不利己的人打交道时使用。

## 判断口径

1. 先给基本尊重，避免无意义激怒。
2. 不过度客气，避免对方丧失边界感。
3. 不参与争执，不在低价值场景证明自己。
4. 不让对方进入你的核心业务、家庭、私域或项目权限。
5. 一旦发现低级报复、长期负能量、无解抱怨，快速拉开距离。
