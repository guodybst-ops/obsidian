# [框架] 摩托车保养式健康资产框架

## 适用场景

当一个人为了赚钱、运动、工作或情绪爽感持续透支身体，却还觉得“现在没事”时使用。

## 判断口径

1. 把身体当成一辆需要按说明书保养的车。
2. 区分“还能跑”和“优质寿命被缩短”。
3. 检查高糖、熬夜、久坐、烟酒、过度运动、情绪内耗等长期磨损。
4. 先停止继续损耗，再谈修复和提高效率。
