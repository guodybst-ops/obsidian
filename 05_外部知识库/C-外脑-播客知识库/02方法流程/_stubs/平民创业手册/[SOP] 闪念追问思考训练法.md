# 闪念追问思考训练法

## 一句话

抓住刚冒出来的念头，连续追问为什么和然后呢，直到写成可复用判断。

## 什么时候用

- 突然觉得自己“抓到了什么”，但说不清楚。
- 想训练思考能力，不想只背思维模型术语。
- 观察到一个现象，想把它拆成商业、心理或成本判断。
- **红线**：不要只记一句灵感就放着不管。

## 输入与输出

| 类型 | 内容 |
|---|---|
| 输入 | 一个闪念、一个现象或一个问题 |
| 输出 | 一组为什么、然后呢、联想、反例和结论 |
| 完成标准 | 闪念能被写成一段可解释、可复用的话 |

## 怎么用

### Step 1：立刻记录闪念

只要出现“仿佛捕捉到了什么”的感觉，先写下来。

格式：

```text
我刚刚想到：
触发它的场景：
```

### Step 2：连续问为什么

至少问 5 次：

- 为什么会这样？
- 为什么不是另一种？
- 谁因此受益？
- 它解决了什么问题？
- 它背后的成本、流量、体验或心理是什么？

### Step 3：继续问然后呢

把结论往后推：

- 如果这个判断成立，然后会发生什么？
- 它能迁移到哪个场景？
- 它能变成什么方法或概念？

### Step 4：穷举联想并写下来

把所有联想先写出来，不急着筛选。

包括：

- 案例。
- 类比。
- 反例。
- 可能的商业解释。
- 可能的人性解释。

### Step 5：回头雕琢成一条判断

最后压缩成：

```text
现象 -> 原因 -> 可复用判断 -> 适用边界
```

## 常见坑

| 坑 | 表现 | 修正 |
|---|---|---|
| 只收藏灵感 | 过后想不起来 | 立刻追问并写出推导 |
| 只问一次为什么 | 停在表层解释 | 至少连续追问 5 次 |
| 只讲玄 | 没有可落地判断 | 写到成本、流量、体验、转化 |
| 追求模型名 | 先背发散思维、逆向思维 | 先做高频观察和推理 |
