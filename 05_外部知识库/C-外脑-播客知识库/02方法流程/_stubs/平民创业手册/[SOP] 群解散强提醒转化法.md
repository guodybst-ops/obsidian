# [SOP] 群解散强提醒转化法

## 适用场景

临时群、发售群、文字直播群、快闪群需要最后一次强触达时使用。

## 操作步骤

1. 在群内完成核心交付、答疑或发售说明。
2. 最后发付款码、新群二维码或下一步动作。
3. 用群管理里的“解散该群聊”，不要逐个踢人。
4. 解散提醒会让成员点回群内容查看。
5. 最后一段话必须清楚放置行动入口。
