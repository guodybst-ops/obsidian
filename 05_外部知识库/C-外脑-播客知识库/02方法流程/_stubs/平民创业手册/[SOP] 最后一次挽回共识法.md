# 最后一次挽回共识法

## 一句话

把最后一次挽回变成一场面对面的共识会议，而不是微信里的拉扯。

## 什么时候用

- 关系还没彻底结束，但已经在冷战、吵架或分手边缘。
- 双方还有感情，只是卡在某几个不能接受的点。
- 想用最后一次正式沟通决定继续还是分开。
- **红线**：不要在微信里反复争吵、试探和追问。

## 输入与输出

| 类型 | 内容 |
|---|---|
| 输入 | 最介意的问题、愿意改的点、不能接受的底线 |
| 输出 | 继续关系的交换条件，或体面分开的共识 |
| 完成标准 | 当晚形成明确结论，不继续无期限拉扯 |

## 怎么用

### Step 1：选对场景

尽量满足：

- 晚上。
- 一对一。
- 安静、有氛围。
- 不被朋友、工作、手机打断。

### Step 2：先承接情绪

先让对方感到被看见：

- 我知道你这段时间很难受。
- 我理解你为什么会失望。
- 这件事我确实有责任。

### Step 3：道歉和承诺分开讲

道歉回答“过去哪里错了”。

承诺回答“以后怎么变”。

不要把“我错了”直接当成解决方案。

### Step 4：写出最介意的点

双方各写最不能接受的 1-3 个点。

只谈最关键的，不翻旧账。

### Step 5：做极限一换一

格式：

```text
我愿意为你改 A。
你能不能为我改 B？
```

如果双方都愿意交换，进入试行期；如果一方完全不愿意，这就是分开的证据。

### Step 6：当场形成结论

结论只有三类：

- 继续，但有明确试行规则。
- 暂缓，但约定下次复盘时间。
- 分开，进入 [[02方法流程/_stubs/平民创业手册/[SOP] 体面分手闭环法]]。

## 常见坑

| 坑 | 表现 | 修正 |
|---|---|---|
| 微信挽回 | 表情和文字被反复咀嚼 | 改成面对面沟通 |
| 只道歉不改法 | 当下感动，之后复发 | 写成可观察动作 |
| 翻旧账 | 一次沟通变成清算大会 | 只谈最关键 1-3 个点 |
| 无限试行 | 没有结果，继续消耗 | 设复盘时间和退出条件 |
