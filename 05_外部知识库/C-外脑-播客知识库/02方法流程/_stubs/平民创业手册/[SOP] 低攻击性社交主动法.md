# 低攻击性社交主动法

## 一句话

用细节赞美、追问和救场表达善意，降低社交攻击性。

## 什么时候用

- 想向上链接、认识新朋友或维护关系，但害怕显得油腻。
- 参加饭局、活动、社群、商务局，需要释放善意。
- 想主动，但分不清主动和“舔”的边界。
- **红线**：不用于操控、骚扰、越界索取或虚假讨好。

## 输入与输出

| 类型 | 内容 |
|---|---|
| 输入 | 对方公开信息、当前场景、自己的真实诉求 |
| 输出 | 一次低压社交互动、一个清晰请求、一次后续连接 |
| 完成标准 | 对方感到被尊重，你也没有透支尊严或制造负担 |

## 主流程

### Step 1：先研究公开信息

互动前先看：

- 对方最近在做什么。
- 对方公开表达过什么观点。
- 对方擅长什么。
- 当前场合里对方和谁有关系。

没有研究就开口，容易把主动变成冒犯。

### Step 2：用细节化赞美开场

赞美必须落到细节：

| 泛泛夸法 | 细节夸法 |
|---|---|
| 你很厉害 | 你刚才把 A 和 B 的区别讲清楚了 |
| 你内容很好 | 你那篇关于 X 的例子让我立刻能用 |
| 你人脉很强 | 你刚才帮大家补台的方式很舒服 |

### Step 3：用追问和附和延长连接

听到对方表达后，用三类回应：

- 追问：这个判断最早是怎么来的？
- 复述：我理解你是说 A 比 B 更关键。
- 附和：这个点我之前没意识到，但能对上我的场景。

### Step 4：主动救场，不抢话

场面冷掉或对方被误解时，可以轻轻接一手：

- 帮对方补一个背景。
- 把话题接回对方擅长处。
- 给沉默的人一个台阶。
- 不在公共场合纠错、指正、抢话。

### Step 5：直说诉求和边界

如果要借流量、合作、请教或求引荐，把条件讲清楚：

- 我想做什么。
- 会不会伤你的粉。
- 是否付费合作。
- 是否事后分成。
- 对方拒绝也完全可以。

## 判断点

| 信号 | 处理 |
|---|---|
| 自己略微不适但没有越界 | 可以主动一点 |
| 对方明显回避或敷衍 | 及时收住 |
| 诉求说不清 | 暂缓，不要硬蹭 |
| 需要对方承担风险 | 先把风险和补偿讲清楚 |

## 常见坑

- 不要把纠错当真诚。
- 不要把抢话当表现。
- 不要把频繁摸手机当自然。
- 不要偷偷蹭流量，能摆上台面谈就摆上台面。
