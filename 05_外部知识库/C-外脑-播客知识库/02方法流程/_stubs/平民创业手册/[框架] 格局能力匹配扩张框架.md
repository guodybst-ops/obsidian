# [框架] 格局能力匹配扩张框架

## 适用场景

创业者个人能力强，想快速招人、冲风口、做赛道第一时使用。

## 判断口径

1. 格局要大，但必须匹配当前组织能力。
2. 先保证账上现金流健康，再扩张。
3. 自己忙不过来时招第一个人，前几个人忙不过来时再招第五个人。
4. 每招一个人，都要带来可感知的正向变化。
5. 不能让个人能力长期替团队兜底。
