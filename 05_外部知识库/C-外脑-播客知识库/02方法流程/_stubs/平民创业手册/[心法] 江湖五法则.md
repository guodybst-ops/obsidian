# 江湖五法则

## 一句话

用五个低成本社交动作，让对方获得体面、爽感和被尊重的体验。

## 五法则

| 法则 | 动作 | 目的 |
|---|---|---|
| 逢物增价 | 看到对方买的东西，价格往高处猜 | 给对方“买得值/会生活”的爽感 |
| 逢人减龄 | 聊年龄时往年轻处猜 | 给对方体面 |
| 购物可砍 | 购物场景可以谈价格 | 让交易双方都获得博弈感 |
| 用人加钱 | 服务类尽量别砍，必要时加钱 | 换更认真、更少折扣的服务 |
| 用好奇不用赞扬 | 面对高手，多问细节和来路 | 让对方讲自己的得意处 |

## 使用边界

- 只用于释放善意，不用于欺骗。
- 不要对所有场合机械套话。
- 服务业砍价和购物砍价要分开看。
- 用好奇提问时，不要直接索取渠道、利润、资源和商业秘密。
