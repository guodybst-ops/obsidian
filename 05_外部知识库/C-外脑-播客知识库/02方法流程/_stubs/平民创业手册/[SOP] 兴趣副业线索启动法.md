# 兴趣副业线索启动法

## 一句话

不用先找到热爱，从偏爱、不讨厌和已有线索开始以战养战。

## 什么时候用

- 想从兴趣发展副业，但不知道自己适合生产型还是输出型。
- 有爱好，但还没有交易场景。
- 主业之外想找第二曲线，不急着马上赚大钱。
- **红线**：不要用“热爱”掩盖持续亏损和不复盘。

## 输入与输出

| 类型 | 内容 |
|---|---|
| 输入 | 兴趣清单、已有技能、身边资源、可接触人群 |
| 输出 | 一条副业线索、一个最小交易场景、一轮以战养战测试 |
| 完成标准 | 能在 7 天内发出一个产品、社群、服务或交易测试 |

## 主流程

### Step 1：把热爱降级成线索

先列三类：

- 喜欢的事。
- 不讨厌的事。
- 已经长期接触的事。

不要先追求“终身热爱”。偏爱拿到正反馈后，才可能长成热爱。

### Step 2：找交易场景

把兴趣接到交易：

| 兴趣 | 可能线索 |
|---|---|
| 台球 | 二手球杆、器械、球友社群 |
| 写作 | 日更群、陪伴群、改稿服务 |
| 读书 | 读书群、共读打卡 |
| 运动 | 打卡群、装备、陪练 |
| 健身 | 营养、康复、训练陪伴 |
| 穿搭/审美 | 咨询、衣橱整理、陪买、带货 |
| 手办/二次元 | 渠道、社群、周边、定制 |

### Step 3：设计最小可卖形态

7 天内只做一个：

- 一个闲鱼商品。
- 一个微信群。
- 一次陪跑。
- 一份清单。
- 一次小课。
- 一个打卡活动。

### Step 4：用收入或反馈养下一轮

如果赚到钱，用这笔钱买工具、课程、装备或流量；如果没赚到钱，至少拿到反馈。

原则：

```text
边做边学，边卖边改，边反馈边升级。
```

### Step 5：每周判断是否继续

复盘：

- 我愿不愿意继续做？
- 有没有真实用户反馈？
- 有没有可重复交付动作？
- 有没有比上周更清晰的产品形态？

## 常见坑

- 不要把消费型兴趣直接当副业。
- 不要先租店、囤货、重装修。
- 不要只问“我热爱什么”，要问“谁会为这个付钱”。
- 不要亏钱还不复盘，用爱发电也要看边界。
