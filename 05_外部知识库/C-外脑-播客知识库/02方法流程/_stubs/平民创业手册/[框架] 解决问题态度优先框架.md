# 解决问题态度优先框架

## 一句话

遇到问题先问 how to do，而不是先追责、甩锅、抱怨大环境。

## 什么时候用

- 团队复盘、项目失败、投放不达预期。
- 个人遇到困难时总是外部归因。
- 想提高持续成长能力。
- **红线**：向内归因不是替别人背锅，而是先找到自己可改进的部分。

## 判断表

| 反应 | 方向 |
|---|---|
| 追责 | 低效 |
| 抱怨环境 | 低效 |
| 纠结问题本身 | 低效 |
| 问怎么解决 | 高效 |
| 找自己可优化部分 | 高效 |

## 主流程

### Step 1：先停住甩锅

外部变量可以记录，但不先讨论。

### Step 2：问 how to do

把问题改写成可解决动作。

### Step 3：向内找一个改进点

先找自己、团队流程、SOP、标准化可改的地方。
