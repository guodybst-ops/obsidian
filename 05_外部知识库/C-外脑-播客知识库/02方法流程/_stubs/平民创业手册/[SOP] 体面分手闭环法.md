# 体面分手闭环法

## 一句话

用清晰现状、问题本质、分开共识和边界处理，完成不二次伤害的告别。

## 什么时候用

- 关系已经走到分开边缘，需要正式告别。
- 想分手但怕拖泥带水、反复拉扯。
- 需要处理共同朋友、礼物、隐私和后续联系。
- **红线**：不要用对方曾经交出的隐私、弱点或影像资料攻击对方。

## 输入与输出

| 类型 | 内容 |
|---|---|
| 输入 | 分手原因、底线冲突、共同财物/礼物/隐私资料、告知范围 |
| 输出 | 分开共识、后续联系边界、共同圈子处理方式 |
| 完成标准 | 双方知道关系已经结束，减少误解、期待和二次伤害 |

## 怎么用

### Step 1：先做 T 字图自查

左边写对方的好，右边写对方的问题。

观察自己在补哪边：

- 如果一直补“好”，可能还有爱和不甘。
- 如果一直补“坏”，可能是在说服自己离开。
- 如果涉及背叛、三观高压线、家庭羁绊，要单独处理。

### Step 2：讲清现状和问题本质

用直接表达替代编理由。

可以说：

- 我们现在已经无法继续。
- 我不爱了。
- 这个问题对我来说不能再消耗。

不要用“父母不同意”“最近太忙”“异地太累”等假理由给对方留下继续争取的误区。

### Step 3：明确分开方案

说清：

- 从什么时候开始分开。
- 共同物品怎么处理。
- 贵重礼物是否归还。
- 共同朋友知道到什么程度。
- 以后是否互删、是否不再窥探生活。

### Step 4：达成分开共识

确认双方至少知道：

```text
这段关系结束了。
之后不再用暧昧、冷战、试探延长痛苦。
```

### Step 5：处理安全和隐私红线

- 对方情绪不稳定时，优先保证人身安全，再沟通。
- 亲密影像资料一刀切处理，不留长期风险。
- 不在共同圈子公开示众，不把隐私变成攻击材料。

## 常见坑

| 坑 | 表现 | 修正 |
|---|---|---|
| 编温柔理由 | 给对方留下继续争取空间 | 真诚说清不能继续 |
| 分手后做朋友 | 反复窥探生活、重新拉扯 | 讲清后互删或降到最低接触 |
| 共同圈子示众 | 让分手变成羞辱 | 只告知必要相关方 |
| 忽略安全 | 面对极端情绪还当面硬谈 | 先保护自己，再沟通 |
