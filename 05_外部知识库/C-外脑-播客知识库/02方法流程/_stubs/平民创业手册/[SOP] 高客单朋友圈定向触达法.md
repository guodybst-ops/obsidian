# 高客单朋友圈定向触达法

## 一句话

对高价值客户，不靠全员刷屏，而是基于客户真实线索发分组/仅他可见内容，并记录反应、更新跟进等级。

## 什么时候用

- 业务满足高客单、高利润、长周期、强信任，客户价值足够高。
- 客户已经在微信或私域里，朋友圈是重要的信任触点。
- 你需要让某些重要客户看到特定内容，但不想对全体好友无差别刷屏。

不适合：低客单快消、即时转化、没有私域沉淀、或产品本身经不起长期信任检验的业务。

## 输入

- 一批 A/S 或高潜 B 级客户。
- 客户最近公开表达过的生活方式、需求、顾虑或兴趣信号。
- 真实可发布的内容素材：案例、服务过程、知识、活动、生活方式内容。
- 客户标签表或备注系统。

## 输出

- 一条定向朋友圈或分组朋友圈。
- 一条客户互动记录。
- 一个下一步动作：升级、维持、降级、邀约或放生。

## 操作流程

### Step 1：先筛高价值客户

优先从 [[02方法流程/_stubs/平民创业手册/[框架] 客户四级分级法CBAS]] 里的 A/S 客户开始。不要把这个方法用在全体客户身上，否则会变成低效刷屏。

### Step 2：捕捉客户刚释放的信号

观察客户最近朋友圈、聊天或咨询里的信号：兴趣、场景、顾虑、消费偏好、时间窗口。信号越新，触达越容易被看见。

### Step 3：选择真实且相关的内容

内容要和客户信号相关，但不要伪造身份、伪造经历或盗用不可授权图片。可以发布真实案例、服务知识、活动现场、主理人真实生活、客户常见问题答复。

### Step 4：设置可见范围

根据目标选择：

- 单个客户：仅他可见。
- 同类客户：标签分组可见。
- 重要通知：多分组分次发布，避免一条内容被系统曝光稀释。

### Step 5：记录反应

记录客户是否查看后互动、点赞、评论、私聊、问价、预约。朋友圈触达不是结束，记录才是后续跟进的依据。

### Step 6：决定下一步

- 有互动：顺势轻沟通，推进到报价、细节或预约。
- 无互动：不要马上追问，保留内容触达，降低主动打扰。
- 多次无反馈：降级或放生，把客服产能留给更高意向客户。

## 可复用记录表

| 日期 | 客户 | 当前等级 | 客户信号 | 发布内容 | 可见范围 | 反应 | 下一步 |
|---|---|---|---|---|---|---|---|
|  |  | A/B/S |  |  | 仅他可见/分组 | 点赞/评论/私聊/无 |  |

## 完整示例

一个高端服务客户最近连续发高尔夫活动。你手里刚好有真实的企业家高尔夫活动案例，或者主理人确实参与过相关场景。你可以发一条仅该客户或同类客户可见的内容，主题不是硬广，而是“高端客户在决策前最关心的三个服务细节”。如果客户点赞或私聊，再进入轻沟通；如果无反应，记录一次触达，不立刻追问。

## 判断分支

| 现象 | 下一步 |
|---|---|
| 客户点赞但不私聊 | 隔一段时间用相关话题轻触达，不急着成交 |
| 客户私聊问细节 | 升级为 A，给案例、报价或服务说明 |
| 客户约时间/到店 | 升级为 S，优先承接 |
| 连续多次无反馈 | 降级或放生 |

## 常见坑

- 把“仅他可见”用成虚假表演。长期私域依赖信任，造假会反噬。
- 对低价值客户过度精细化，浪费客服产能。
- 只发布不记录，最后不知道谁该跟进。
- 抽奖、二次评论等动作不透明。若使用抽奖，规则和履约必须清楚。
