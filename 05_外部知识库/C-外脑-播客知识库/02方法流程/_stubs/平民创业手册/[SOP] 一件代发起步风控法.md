# 一件代发起步风控法

## 一句话

用一件代发低成本试卖，同时提前管住素材、售后和断供风险。

## 什么时候用

- 刚开始卖货，不想先压库存。
- 有流量或内容能力，想测试某个产品。
- 供应链能力弱，需要先用代发跑通链路。
- **红线**：不适用于平台规则、授权或售后责任说不清的货。

## 输入与输出

| 类型 | 内容 |
|---|---|
| 输入 | 候选产品、供应商、平台规则、素材、退货方案 |
| 输出 | 一份代发风控表、2-3 个备选供应商、一次小单测试 |
| 完成标准 | 能下单、能发货、能售后，且知道命脉风险在哪里 |

## 主流程

### Step 1：确认代发基础条件

逐项确认：

- 是否支持一件代发。
- 是否支持电子面单、虚拟号码、密文下单或 ERP。
- 发货时效如何计算。
- 超时、破损、错发由谁承担。
- 是否包退换货。

### Step 2：拆清成本和现金流

至少问三种价格：

| 价格类型 | 要问什么 |
|---|---|
| 预付款 | 先打款能便宜多少 |
| 现金 | 现结价格是多少 |
| 账期 | 账期多久，价格上浮多少 |

再问快递费、包装费、退货费、二次发货费是否另算。

### Step 3：改造素材差异化

不要直接用厂家通用图。先做：

- 主图背景改造。
- 配色和透明度调整。
- 自己拍摄或做专属素材。
- 保留原图、源文件和拍摄文件。
- 确认平台原创保护规则。

### Step 4：小单试卖，不盲目补库存

先用小单验证：

- 发货是否准时。
- 用户是否投诉。
- 退货率是否异常。
- 供应商响应是否稳定。
- 素材是否带来自然流量。

宁愿短期没货卖，也不要在没验证前压大量库存。

### Step 5：准备 2-3 个备份供应商

同一产品至少准备：

- 主供应商。
- 价格备份供应商。
- 发货备份供应商。

如果可能，把布料、原料或核心材料备份到不同厂，降低单点断供。

## 判断点

| 风险 | 处理 |
|---|---|
| 素材同质化 | 先改图或自拍，不直接铺货 |
| 发货不可控 | 暂缓放量 |
| 退货责任不清 | 不上架或改合同 |
| 供应商涨价/收权 | 启动备份供应商 |

## 常见坑

- 不要有无货源鄙视链，但也不要把无货源当护城河。
- 不要只看拿货价，不看售后和快递成本。
- 不要让厂家通用图决定你的流量命运。
- 不要等卖爆后才准备备份供应商。
