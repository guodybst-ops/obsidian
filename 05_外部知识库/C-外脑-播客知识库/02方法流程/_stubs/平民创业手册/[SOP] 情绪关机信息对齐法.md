# [SOP] 情绪关机信息对齐法

## 适用场景

当亲密关系、朋友关系或合作关系进入争执、指责、撂狠话、翻旧账状态时使用。

## 操作步骤

1. 识别自己是否处在“懵逼”“上头”“不甘心”“凭什么”的状态。
2. 先暂停输出，不追问、不定性、不放狠话。
3. 等情绪下降后，把双方不知道的信息补齐。
4. 用“我可能不知道你的状态，你也不知道我的状态”作为对齐开场。
5. 只解决当前信息差，不把旧账一起搬出来。
