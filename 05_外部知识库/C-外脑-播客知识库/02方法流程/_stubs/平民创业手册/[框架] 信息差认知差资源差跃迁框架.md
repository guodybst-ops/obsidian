# [框架] 信息差认知差资源差跃迁框架

## 适用场景

普通人想从执行型赚钱，逐渐升级到更高杠杆赚钱时使用。

## 跃迁顺序

1. 先靠信息差和执行力赚到第一批钱。
2. 把赚钱案例、作品和结果变成敲门砖。
3. 再靠认知差判断更大机会。
4. 最后进入资源差赚钱，靠关系、分发、合作和资本效率放大。
5. 不跳级幻想资源差，要先有可验证的结果。
