# [框架] 耐受周期开挂按钮框架

## 适用场景

做短视频、直播、电商、写作或新项目时，几天没结果就想放弃。

## 判断口径

1. 先看自己是不是只坚持了 3 到 8 天。
2. 把耐受周期拉长到 1 个月，观察真实反馈。
3. 选择一件过去认为自己完成不了的困难事做完。
4. 完成一次后，把它当成“我能战胜自己”的证据。
5. 后续再遇到困难，调用这次证据提高行动阈值。
