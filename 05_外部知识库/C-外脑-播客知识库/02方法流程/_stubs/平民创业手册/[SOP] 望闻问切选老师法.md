# 望闻问切选老师法

## 一句话

用公开信息、表达味道、互动反馈和交付场域筛选老师。

## 什么时候用

- 准备购买课程、社群、陪跑或咨询。
- 不知道一个老师是否值得信任。
- 同一个领域有多个老师可选。
- 想找大腿、找榜样，但不知道谁适合自己。
- **红线**：不要只因情绪上头或大佬推荐就重仓付费。

## 输入与输出

| 类型 | 内容 |
|---|---|
| 输入 | 老师公开内容、过往结果、用户反馈、一次直接互动 |
| 输出 | 是否付费、付费到哪个层级、需要观察什么 |
| 完成标准 | 能写出“为什么选/不选”的 4 条证据 |

## 主流程

### Step 1：望，看公开信息

- 看他是否凭空出现。
- 看过去内容有没有料、有没有结果。
- 看结果轨迹是否连续，是否能解释他怎么走到现在。
- 看公开案例是否和你要解决的问题相关。

### Step 2：闻，闻表达味道

- 看文章、直播、课程试听是否接地气。
- 判断你能不能听懂、能不能照做。
- 警惕只讲大词、概念和情绪动员的表达。

### Step 3：问，直接互动

- 直接提出一个真实问题。
- 看对方是否有耐心。
- 看对方能不能抓到你的具体问题，而不是只讲 why。
- 看一次低价产品或公开互动是否同频；5000 以内可视为试错成本，但不要上头重仓。

### Step 4：切，看交互和交付

- 看社群是否有同行场域。
- 看学员是否真的在执行。
- 看老师是否能把你按到行动里，而不是只给资料。

### Step 5：做付费分层决定

```text
4 项都强 -> 可付费进入核心产品
2-3 项强 -> 先买低价产品或短期体验
1 项以下 -> 继续观察，不重仓
```

## 常见坑

- 不要把“很能打”自动等同于“很会教”。
- 不要被电子资料堆迷住，资料不等于交付。
- 不要只看老师说什么，要看他持续做什么。
- 不要把信任外包给别人，至少自己跑完四步。
