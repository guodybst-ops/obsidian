# 世上磨技能内化法

## 一句话

把信息变成知识，再用真实行动、犯错、复盘和传授磨成技能。

## 什么时候用

- 听了很多课、看了很多书，但行为没有变化。
- 已经知道一个道理，却不知道怎么练成能力。
- 暂时没有真实项目可练，需要找替代练习场。
- **红线**：不适用于只想收藏信息、不准备行动的场景。

## 输入与输出

| 类型 | 内容 |
|---|---|
| 输入 | 一条想掌握的知识、一个可执行场景、一个反馈对象 |
| 输出 | 一次真实练习、一次犯错记录、一次复盘改法 |
| 完成标准 | 下次遇到同类场景时，行为能发生具体改变 |

## 主流程

### Step 1：把信息改写成行为句

把听到的信息写成：

```text
当我遇到____场景时，我要做____动作。
```

如果写不出动作，它还只是信息，不是知识。

### Step 2：找一个真实场景去用

优先找正在发生的项目、客户、社交、表达或交付场景。

如果没有真实场景，就用替代场景：

- 给别人讲一遍。
- 写一份教学笔记。
- 做一次模拟演练。
- 找一个朋友提问反馈。

### Step 3：刻意模仿一个可观察动作

不要模仿抽象气质，只模仿动作：

- 对方怎么开场。
- 怎么提问。
- 怎么收尾。
- 怎么处理异议。
- 怎么把复杂问题讲清楚。

### Step 4：记录犯错和卡点

每次练完只记三件事：

| 问题 | 记录 |
|---|---|
| 我哪里没做到？ |  |
| 为什么卡住？ |  |
| 下次改一个什么动作？ |  |

### Step 5：把解决问题纳入下一轮练习

下一轮只修一个点，不要同时改十个点。连续三轮能稳定做到，才算开始从知识变成技能。

### Step 6：用传授检验是否真的掌握

假设下周要把这个技能讲给新人，先写一版讲解稿或百问百答。

讲给别人时重点观察：

- 哪些地方自己说不顺。
- 哪些问题被追问后答不上来。
- 哪些例子太空，需要补真实案例。
- 哪些动作听众照着做不了。

讲不清楚的地方，就是下一轮要回炉练习的地方。

## 判断点

| 状态 | 处理 |
|---|---|
| 只能复述道理 | 回到 Step 1，改写成行为句 |
| 找不到真实场景 | 先教别人或模拟演练 |
| 练习中犯错 | 记录错误，不停止练习 |
| 连续三次能做到 | 进入下一个技能点 |
| 能讲但经不起追问 | 回到案例和练习记录补证据 |

## 常见坑

- 不要把收藏、划线、转发当成掌握。
- 不要等完全准备好才开始练。
- 不要因为一次犯错就停止使用。
- 不要同时练太多抽象能力。
- 不要把“会讲”误认为“会做”，传授只是检验和强化，不替代真实上手。
