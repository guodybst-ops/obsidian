# [SOP] 工具人混圈法

## 一句话

用低攻击性、可靠交付和相对优势，成为不同圈层之间可信的工具人。

## 什么时候用

- 想进入更高质量的圈层，但没有强资源和强背书。
- 想让别人愿意推荐你、带你、找你办事。
- 已有技能或时间优势，但不知道怎么换成机会。
- 社交中容易显得攻击性强、表达过量或不靠谱。

## 输入与输出

| 类型 | 内容 |
|---|---|
| 输入 | 当前技能、可交换资源、目标圈层、已认识的关键节点、个人简介素材 |
| 输出 | 结构洞清单、工具人定位、个人简介、提问模板、跟进和回音机制 |
| 完成标准 | 别人能快速理解你是谁、能做什么、为什么找你，并愿意把你推荐给下一位 |

## 怎么用

### Step 1：建立结构洞清单

每个行业或类目，先尽量认识平台方、代理方、资源方、渠道方、服务商等关键节点。

初期不用完美，先列出当前能接触到的三个人；后续认识更强的人，再替换清单，保持当前最优解。

### Step 2：定义自己的工具人定位

工具人不是贬义。它指的是：当上一个圈层的人需要办一件琐碎、低性价比或自己不适合做的事时，你能可靠地接住。

定位句：

> 我能为哪类人，解决哪类具体问题，交付到什么标准。

### Step 3：用相对优势换机会

普通人未必有绝对优势，但通常有相对优势：

- 年轻。
- 便宜。
- 有时间。
- 有冲劲。
- 在某个小圈子里最懂某件事。
- 愿意做细活、苦活、杂活。

把相对优势用在可见的交付上，才可能换来背书和推荐。

### Step 4：降低攻击性

攻击性来自越界和压迫感。常见表现包括炫富、炫技、满口术语、表达欲太旺、当面追问收入或账号、抢话、争论、替别人做决定。

替代动作：

- 倾听。
- 夸赞。
- 微笑。
- 说人话。
- 少争论。
- 不随便问敏感问题。

### Step 5：优化每个社交触点

可优化的触点包括：

- 昵称、头像、群昵称。
- 微信备注和标签。
- 聊天排版。
- 朋友圈置顶、签名、评论区第一条。
- 个人简介、海报、PDF、H5。
- 点赞、评论、转发后的感谢。

这些不是花活，而是在降低别人理解你和信任你的成本。

### Step 6：准备半屏个人简介

文字版个人简介遵循半屏法则。

商务场景讲清三件事：

1. 我是谁。
2. 我卖什么或能解决什么问题。
3. 为什么非我不可。

进阶版本准备三套载体：一图盖之的介绍图、PDF、H5 链接。

### Step 7：提问前补足上下文

不要问“我想推广产品怎么搞”。好问题至少提供：

- 产品属性。
- 用户画像。
- 当前尝试。
- 已有结果。
- 想拿到的目标。
- 希望对方回答的具体问题。

准备问题的过程，本身会倒逼你思考。

### Step 8：事事有回音

接了就交代进展，做不到就果断拒绝。

原则：

- 想拒绝，尽早拒绝。
- 想帮忙，也要让对方知道你的付出。
- 被邀请去玩，想去就痛快同意；不想去也留足体面。
- 面谈时尽量不看手机，微信沟通尽量用文字。

### Step 9：读完圈内自我介绍

进到一个新圈子，先把成员自我介绍全部看一遍，标记三类信息：

- 他有什么资源、技能、渠道或需求。
- 他正在找什么、缺什么、卡什么。
- 我能帮他做什么小事，或者能把谁介绍给他。

人脉不是“谁能帮我”，而是“我能帮谁”。先能被使用，才可能被带着走。

## 常见坑

| 坑 | 表现 | 修正 |
|---|---|---|
| 把混圈当攀附 | 只想认识大佬 | 先成为能办事的人 |
| 只向上有用 | 对同层和下游冷漠 | 背书常来自同层信任 |
| 个人简介过长 | 一屏写不完，没人看 | 半屏讲清三件事 |
| 提问不给背景 | 让对方猜你的业务 | 先给上下文 |
| 没有回音 | 事情接了却不反馈 | 成与不成都要回 |
| 伪装真诚 | 话术感太重 | 诚实是更低耗能的策略 |
| 只想索取人脉 | 进圈后只问别人能不能帮我 | 先读介绍，找自己能帮上的小点 |
