# [心法] 适度卖惨闷声发财法

## 适用场景

当赚钱后面对亲戚、同学、老家关系、无效聚会和借钱求助时使用。

## 操作口径

1. 不在无关场合展示收入和资产。
2. 对老同学、发小、远亲旧友适度卖惨，降低被攀附、眼红和道德绑架的概率。
3. 真正需要展示实力时，在客户、项目、合作方和结果场景里展示。
4. 不把“义气”和“露财”混为一谈。
