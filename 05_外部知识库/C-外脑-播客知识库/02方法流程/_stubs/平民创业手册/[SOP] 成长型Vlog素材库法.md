# [SOP] 成长型Vlog素材库法

## 适用场景

大学生、职场人或普通人想做成长型 Vlog，但不知道如何稳定日更时使用。

## 操作步骤

1. 先确定全网同名账号，昵称要有显著性、辨识度和搜索唯一性。
2. 养成日常随手拍素材的习惯：宿舍、地铁、课堂、咖啡厅、操场、旅行、工作现场。
3. 把素材上传网盘并按场景命名。
4. 每条内容只需配旁白、观点和成长线。
5. 发完后减少反复看数据，把注意力放回下一条。
