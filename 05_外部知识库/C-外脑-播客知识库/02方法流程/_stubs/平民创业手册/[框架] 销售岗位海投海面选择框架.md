# [框架] 销售岗位海投海面选择框架

## 适用场景

准备进入销售行业，不知道选哪个行业、公司和岗位时使用。

## 判断步骤

1. 海量投简历并完成至少 30 场面试，摸清城市销售岗位供给。
2. 选择底薪高、抽成高、做有钱人生意的平台。
3. 查公司、团队和城市销冠收入，判断岗位天花板。
4. 找愿意带你的直属领导或引渡人。
5. 入岗前半个月整理行业百问百答和竞品对比。
