# 问心局技能穷举筛选法

## 一句话

把自己所有能做、常用、有信心的能力穷尽写出，再筛到 5 个相对优势技能。

## 什么时候用

- 不知道自己擅长什么。
- 想找副业、职业方向或项目入口。
- 感到焦虑但问题太抽象。
- **红线**：不要用一次盘点给人生盖棺定论，只用于找到当前阶段的行动入口。

## 输入与输出

| 类型 | 内容 |
|---|---|
| 输入 | 一张纸、30 分钟安静时间、自己所有会做的事 |
| 输出 | 5 个候选技能、每个技能的相对优势评分 |
| 完成标准 | 能说出“我当前最能靠哪几个能力去试事” |

## 主流程

### Step 1：不评判地穷尽

把所有你觉得“自己有”的能力写下来。

可以包括：

- 能说、能写、能唱、声音好听。
- 会吃、会穿搭、会聊天、会组织局。
- 会做图、会剪辑、会销售、会搜索。
- 长得高、长得帅、体力好、审美好。

不要一边写一边否定，先凑到 30-50 个。

### Step 2：划掉不用和没信心的

每划掉一个，问一句：

```text
这个能力过去 6 个月是否真实被我用过？
我是否愿意拿它去帮别人解决问题？
```

不常用、不想用、不敢交付的先划掉。

### Step 3：保留 5 个左右常用技能

最后留下 5 个左右“删这个也不是、删那个也不是”的能力。

这些大概率是你常用、有信心、已经形成路径依赖的技能。

### Step 4：做相对优势评分

不要和全世界比，先和身边圈层比：

| 技能 | 圈层里最强的人 | 我的位置 | 分数 |
|---|---|---|---|
|  |  |  |  |

如果在公司、朋友圈、社群或家族里已经排前列，它就能提高当前确定性。

### Step 5：接到一个真实场景

每个技能补一句：

```text
我可以用这个能力帮____人解决____问题。
```

写不出服务对象和问题的技能，暂时只是自我标签。

## 常见坑

- 不要只写“学习能力强”这类空标签。
- 不要拿自己的短板去和专业选手比。
- 不要因为测评结果不好就否定真实经验。
- 不要把兴趣直接等同于可交付技能。
