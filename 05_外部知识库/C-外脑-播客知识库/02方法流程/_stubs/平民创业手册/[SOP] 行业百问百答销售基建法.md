# 行业百问百答销售基建法

## 一句话

用 3 天整理客户最常问的 100 个问题，再通过销冠访谈、角色扮演和真实客户追问迭代成销售底气。

## 什么时候用

- 刚做销售，客户问题答不稳。
- 想做竞品调研、培训新人或升级业务手册。
- 需要把行业理解变成随时可调用的话术资产。
- 刚进入新行业，需要在短时间内补齐行业常识和客户问答。
- 做内容或个人 IP，需要把领域问题回答成可搜索资产。
- **红线**：百问百答不能机械复制粘贴，要符合自己的口吻。

## 输入与输出

| 类型 | 内容 |
|---|---|
| 输入 | 客户常问问题、公司资料、前辈经验、同行回答 |
| 输出 | 当前最优版行业百问百答、可迭代销售手册 |
| 完成标准 | 90% 客户常见问题都能自然回答 |

## 怎么用

### Step 1：花 3 天穷尽问题

来源包括：

- 自己遇到的问题。
- 公司历史资料。
- 前辈和领导经验。
- 客户反复问的问题。
- 同行回复。
- 同城/同业内容账号的评论区和私信问题。

### Step 2：找 2-3 个高手访谈补洞

带着初稿去请教销冠或老业务员，只问三类问题：

- 哪些问题漏了。
- 哪些回答客户不信。
- 哪些异议最容易卡住新人。

访谈后不要只收藏聊天记录，要当天改进百问百答。

### Step 3：写成自己的口吻

每个回答要：

- 分段。
- 口语化。
- 不太长。
- 有称呼和情绪温度。
- 适合聊天场景。

### Step 4：放进快捷输入

可以存在输入法或话术库里。

发出前要根据客户情况调整，不要直接 Ctrl C / Ctrl V。

### Step 5：每月迭代一次

把新问题、新案例、新同行话术补进去。

3 个月后形成行业圣经。

如果是内容/IP 场景，可以把 100 问扩展成 200 问，回答完后形成短视频、图文、直播选题和私域 FAQ。

### Step 6：用于培训和筛人

让新人互相扮演客户和业务员，用百问百答互相刁难。

谁能调用，谁能继续；谁完全接不住，尽早筛掉。
