# 供应商筛选与成本拆解法

## 一句话

先按价格撒网，再用稳定性、现金流和风险责任筛供应商。

## 什么时候用

- 已找到一批候选供应商，需要决定先和谁合作。
- 发现别人售价低于自己的成本，想拆清对方优势。
- 准备从代发、小单试货切到更稳定合作。
- **红线**：不要用压榨供应商、侵权或拖欠款项换短期低价。

## 输入与输出

| 类型 | 内容 |
|---|---|
| 输入 | 候选供应商名单、报价、样品、付款方式、退货规则 |
| 输出 | 供应商筛选表、成本拆解表、小单试货计划 |
| 完成标准 | 能选出主供应商和备选供应商，并知道低价来自哪一段成本 |

## 主流程

### Step 1：先用价格撒网

起步阶段先收集足够报价：

- 预付款价格。
- 现金价格。
- 账期价格。
- 是否包退换货。
- 快递费、包装费、人工费是否另算。

普通人起步量小，第一标准先看价格，第二标准再看稳定性。

### Step 2：打电话判断沟通底气

不要只在线聊天。打电话问：

- 老板在不在。
- 这个品类做了几年。
- 最近哪些款卖得好。
- 最低起订量是多少。
- 退货和破损怎么处理。

电话里听对方是否懂货、是否敢给边界、是否一直回避关键问题。

### Step 3：加微信看行业沉淀

看朋友圈：

- 账号使用年限。
- 是否长期发本行业内容。
- 是否有工厂、发货、客户、展会、打样痕迹。
- 是否频繁换品类、换身份。

这不是绝对证明，但能辅助判断稳定性。

### Step 4：小单试错并验货

先拿样，再小单：

- 样品和大货是否一致。
- 包装是否稳定。
- 发货是否准时。
- 售后响应是否及时。
- 退货流程是否真的跑得通。

### Step 5：拆低价背后的成本来源

看到极低价，不先下结论亏钱，先拆：

| 低价来源 | 要问的问题 |
|---|---|
| 促销/权重 | 是不是为人气、搜索权重或 SKU 服务 |
| 快递优势 | 快递费是否远低于你的价格 |
| 人力优势 | 客服、直播、代播是否在低成本城市 |
| 补贴 | 是否有平台、地方、农业或产业补贴 |
| 尾货/特殊渠道 | 是否来自尾货改造、取消订单、库存处理 |
| 账期/现金流 | 是否靠付款方式换价格 |

### Step 6：达到量级后再谈厂家和产能

当单量持续增长，并达到厂家最低起订量，再谈：

- 直接找厂家。
- 包产能。
- 包工厂。
- 改包装或打样。
- 更低价格或更稳账期。

不要起步就幻想绕过所有中间商。数量决定价格。

## 常见坑

- 不要只看样品，不看大货稳定性。
- 不要只问最低价，不问风险由谁承担。
- 不要忽略账期对价格的影响。
- 不要在量级不够时强行绕过中间商。
