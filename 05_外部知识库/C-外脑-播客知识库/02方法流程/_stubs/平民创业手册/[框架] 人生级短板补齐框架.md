# 人生级短板补齐框架

## 一句话

先把写作、沟通、逻辑、网感等人生级短板补到及格，再去放大长板。

## 什么时候用

- 自己有一项明显长板，但总被其他能力拖住。
- 觉得“扬长避短”能解决一切。
- 想提高个人上限和系统稳定性。
- **红线**：不是要求每项都顶尖，而是关键能力不能低于标准线。

## 判断表

| 能力 | 是否人生级短板 | 为什么 |
|---|---|---|
| 写作表达 | 是 | 影响输出、销售、影响力 |
| 沟通协同 | 是 | 影响合作和管理 |
| 逻辑思考 | 是 | 影响判断和解决问题 |
| 网感/流量 | 视业务而定 | 影响获客和内容 |
| 跳舞打球 | 多数不是 | 通常不影响主业 |

## 主流程

### Step 1：找最拖后腿的一项

不要补所有短板，先补最影响目标的一项。

### Step 2：只补到及格

目标不是成为顶尖，而是不再制造系统风险。

### Step 3：再兑现长板

短板到平均水平后，长板才能更稳定地兑现价值。
