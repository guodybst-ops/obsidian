# [框架] 周期吃尸体进化框架

## 适用场景

长期赛道进入低谷、同行退场、利润下滑、价格战加剧时使用。

## 判断口径

1. 先判断赛道是不是长期刚需，而不是短期泡沫。
2. 承认项目有波动周期，不把波动直接等同于死亡。
3. 在低谷期通过产品、流量、投放、团队和成本结构进化。
4. 同行退场时承接空出来的便宜流量、客户和供应。
5. 不进化就会被后进者干掉。
