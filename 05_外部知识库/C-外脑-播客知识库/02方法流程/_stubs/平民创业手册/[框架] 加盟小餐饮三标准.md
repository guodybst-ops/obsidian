# [框架] 加盟小餐饮三标准

## 适用场景

餐饮小白准备加盟小餐饮项目时使用。

## 判断标准

1. 去后厨化：出品稳定，不被厨师强绑定。
2. 低损耗或零损耗：库存和备料压力低。
3. 符合传统饮食习惯：粉面、米饭、包子、云吞、饺子、本地特色等可以长期复购。
4. 选址只看是否捡漏，转让费和高估流水要谨慎。
