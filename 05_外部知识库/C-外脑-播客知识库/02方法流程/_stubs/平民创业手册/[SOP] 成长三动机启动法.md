# 成长三动机启动法

## 一句话

用信息、利益和羞耻心三种动机把成长从想法推到行动。

## 什么时候用

- 明知道要成长，但启动不了。
- 对现状不满，却只有焦虑没有行动。
- 需要从外部信息、欲望和羞耻感里借力。
- **红线**：不要把羞耻心用成自我攻击。

## 输入与输出

| 类型 | 内容 |
|---|---|
| 输入 | 优质信息环境、想要的具体生活、一个可承受的羞耻触发 |
| 输出 | 一组启动动作和持续提醒 |
| 完成标准 | 今天能完成一个成长动作，而不是只想通 |

## 主流程

### Step 1：晓之以理

- 主动靠近优质信息环境。
- 多看好内容、好书、有结果的人。
- 把“我为什么要做”写成 3 条理性原因。

### Step 2：诱之以利

- 写出成长带来的具体好处。
- 具体到父母、伴侣、居住、饮食、旅行、体验。
- 把欲望写成一句能刺激自己的话。

### Step 3：破之以耻

- 找一个能推动自己的羞耻触发。
- 问自己：同阶段的人已经做到什么？
- 把羞耻转成今天的行动，不转成自我否定。

### Step 4：落成一个最小动作

```text
今天我为了理做：
今天我为了利做：
今天我为了不再羞耻做：
```

### Step 5：每晚记录启动证据

- 今天哪一种动机最有效？
- 明天继续保留哪一个触发？
- 有没有把羞耻用过头？

## 常见坑

- 不要只看信息不行动。
- 不要只想赚钱却没有具体动作。
- 不要把羞耻心变成“我很差”的自我催眠。
