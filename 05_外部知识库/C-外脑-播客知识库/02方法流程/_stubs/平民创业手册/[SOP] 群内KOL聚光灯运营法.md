# [SOP] 群内KOL聚光灯运营法

## 适用场景

群主想让核心成员、活跃成员和行业高手持续贡献内容时使用。

## 操作步骤

1. 识别群内能输出、能答疑、能连接资源的人。
2. 主动 Q 他，让话题和注意力照到他身上。
3. 转发他的成果并当众认可。
4. 线下见面或重要节点给礼物和感谢。
5. 不让一个人长期白白输出，持续补充情绪价值和实际收益。
