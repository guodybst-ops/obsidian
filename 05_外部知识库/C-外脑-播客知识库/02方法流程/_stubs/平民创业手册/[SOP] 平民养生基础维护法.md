# 平民养生基础维护法

## 一句话

先维护吃饭、睡眠、运动和关系，再用环境设计降低损耗。

## 什么时候用

- 工作节奏乱，经常熬夜、久坐、饮食不规律。
- 想改善身体状态，但不想陷入复杂养生玄学。
- 需要一张普通人能执行的生活维护清单。
- **红线**：这是生活习惯笔记，不替代医生诊断或治疗建议。

## 输入与输出

| 类型 | 内容 |
|---|---|
| 输入 | 当前作息、饮食、运动、关系与工作环境 |
| 输出 | 一份基础维护清单、一套久坐打断机制、一次补损计划 |
| 完成标准 | 今天能改 1-3 个环境设置，并连续一周执行 |

## 主流程

### Step 1：先查四件底座

每周给四件事打勾：

| 底座 | 本周最低动作 |
|---|---|
| 吃饭 | 早餐稳定，晚餐不过量 |
| 睡觉 | 上床不带电子产品，尽快拉回作息 |
| 运动 | 每天走路或做一组自重动作 |
| 关系 | 维护同事、朋友、家人或伴侣的基本沟通 |

### Step 2：熬夜后只做补损

熬夜不是“科学”，只能降低损耗：

- 多喝水。
- 宵夜清淡。
- 白天不要无限补睡。
- 尽快把生物钟拉回晚上。
- 第二天减少高压决策和重体力透支。

### Step 3：用环境打断久坐

把“不得不起身”做进环境：

- 垃圾桶放远。
- 饮水机放远。
- 用小水杯或只倒半杯水。
- 番茄钟结束后站起来提踵或走一圈。
- 走路时有意识收紧臀部和核心。

### Step 4：维护高频接触物

优先投入每天都接触的东西：

- 牙齿：电动牙刷、牙线、漱口水。
- 防晒：脸、脖子、手臂和头皮。
- 睡眠：床品、枕头、遮光、室温。
- 健身：热身、拉伸、护具、泡沫轴。

### Step 5：用小机制启动早起

如果早起困难，可以设计外部机制：

```text
睡前转钱给伴侣或朋友 -> 按时起床后拿回奖励 -> 迟到则损失
```

重点不是惩罚自己，而是借损失厌恶和获得感降低启动阻力。

## 常见坑

- 不要把熬夜合理化成“科学熬夜”。
- 不要靠意志力对抗环境，先改摆放和流程。
- 不要把体检、牙齿和防晒无限后置。
- 出现疾病、疼痛或异常指标时，优先就医。
