# [SOP] 主动求助不要脸法

## 适用场景

遇到困难时习惯闭门造车，不愿主动问人、付费、勾搭资源和寻求帮助。

## 操作步骤

1. 先承认大多数问题都有现成答案。
2. 找到已经会的人，直接请教或付费。
3. 主动给对方提供价值、情绪价值或实际回报。
4. 不把趋近更大势能的人误解为可耻。
5. 把主动性当作销售、合作、求职、恋爱和创业的通用能力。
