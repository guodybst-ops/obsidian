# [SOP] 社群信噪比维护法

## 适用场景

群开始出现斗图、闲聊、开车、引战、广告和低质量刷屏时使用。

## 操作步骤

1. 群规提前写清楚禁止事项和移出机制。
2. 不夸群主、不开车、不引战、不聊高风险敏感话题。
3. 群内吵架不论对错先移出，防止公共场合被占用。
4. 分享外部内容时附一句结论或一个问题。
5. 广告、群码、低价值刷屏快速处理。
