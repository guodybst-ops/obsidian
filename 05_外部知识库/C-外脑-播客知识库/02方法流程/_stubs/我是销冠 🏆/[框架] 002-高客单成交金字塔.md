# [框架] 高客单成交金字塔

## 一句话（≤ 40 字）
用三层判断高客单成交证据是否够。

## 什么时候用（触发条件，3-5 条 bullet）

- 你在卖咨询、私教、训练营、顾问服务。
- 客户觉得贵、怕没效果、怕不适合自己。
- 你想诊断高客单产品为什么没人买。
- 你需要设计成交页、私域话术或销售材料。
- **红线**：没有真实结果案例时，不要伪造第一层。

## 评估对象（这个框架用来打分的是什么）

- 一个高客单产品/服务的成交材料与销售链路。
- 颗粒度：单个产品、单次私域转化、一个专家型 IP 的成交闭环。

## 维度定义（框架的骨）

### 维度 1：结果可视化——客户能看到别人拿到过什么

**观测信号**：

| 好信号（这方面强） | 坏信号（这方面弱） |
|---|---|
| 有具体客户案例、数字、截图或前后对比 | 只说“我很专业”“我做了很多年” |
| 结果能被目标客户理解和验证 | 案例模糊，无法判断是否真实 |
| 能说明你的介入贡献了什么 | 结果看起来像偶然或客户自己厉害 |

→ **怎么问出来 / 怎么观察出来**：问“客户付费前能不能在 30 秒内看懂别人具体得到了什么”。

### 维度 2：身份认同——客户觉得你服务过同类人

**观测信号**：

| 好信号（这方面强） | 坏信号（这方面弱） |
|---|---|
| 案例人群与目标客户高度相似 | 拿不相关行业案例硬背书 |
| 能说清这类人的共同困境 | 只说泛泛的“适合所有人” |
| 客户能产生“这就是我”的感觉 | 客户觉得你不懂他的处境 |

→ **怎么问出来 / 怎么观察出来**：问“目标客户看到案例时，会不会觉得你处理过他的同类问题”。

### 维度 3：稀缺名额——限量服务于交付质量

**观测信号**：

| 好信号（这方面强） | 坏信号（这方面弱） |
|---|---|
| 限量原因与交付深度有关 | 只说“名额有限”制造焦虑 |
| 筛选机制能保护结果 | 来者不拒，但包装成稀缺 |
| 客户理解等待是为了结果 | 客户觉得你在玩饥饿营销 |

→ **怎么问出来 / 怎么观察出来**：问“如果放开名额，结果率会不会明显下降”。

## 打分卡 / 分级表（可复制粘贴）

| 产品/服务 | 结果可视化 | 身份认同 | 稀缺名额 | 综合结论 |
|---|---|---|---|---|
|  | 低/中/高 | 低/中/高 | 低/中/高 |  |

- **A 级**：三项都高 → 可进入高客单成交。
- **B 级**：结果强、身份弱 → 补同类客户案例。
- **C 级**：结果弱 → 先交付小样本，不急着卖高客单。

## 打完分怎么用（决策后果）

- 结果可视化低 → 先做小规模案例和可验证交付。
- 身份认同低 → 重写案例分类，按目标客户身份展示。
- 稀缺名额低 → 明确交付边界，删掉虚假稀缺话术。

## 常见坑（3-5 条）

- 不要把资历当结果。
- 不要拿不相关行业案例证明同类能力。
- 不要没有交付边界却强行限量。
- 不要只讲“贵有贵的道理”，要讲回报大于成本。

## 附录：实例（1 个跑通的例子）

一个专家型 IP 私教产品一年只收 5 个名额。成交材料不是先讲老师履历，而是展示“去年三位老师从 0 做到月销 5 万”的具体结果，再说明学员多为专家型人士，最后解释限量是因为一对一辅导需要保证每个人拿到结果。
