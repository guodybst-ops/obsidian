# [SOP] 京东式创业四维度自检

## 一句话（≤ 40 字）
把“京东式创业四维度自检”转成可执行动作。

## 什么时候用（触发条件，3-5 条 bullet）

- 你需要把第 012 集里的方法落到具体业务动作时。
- 你面对客户、合作方、私域对象或职业机会，需要明确下一步动作。
- 你已经有基本目标，但缺少执行顺序。
- **红线**：不适用于没有真实对象、没有可跟进动作的空泛复盘。

## 输入（做之前要准备的东西）

- 当前要处理的对象：客户 / 用户 / 面试官 / 合作方 / 社群成员。
- 你已经掌握的背景信息。
- 本次沟通或执行想拿到的结果。

## 输出（做完得到什么）

- 一张动作记录表。
- 一个下一步跟进动作。
- 完成信号：你知道“下一步谁在什么时候做什么”。

## 主流程（核心，占篇幅 ≥ 60%）

### Step 1: 确认对象与目标

- 写下这次要服务或影响的对象。
- 把目标写成可观察结果，而不是情绪愿望。
- 做完信号：能用一句话说清“我要让对方发生什么变化”。

### Step 2: 拆出关键动作

- 从单集要点中抽出 3 个可做动作。
- 每个动作都写清触发条件、执行人和交付物。
- 做完信号：动作能被打勾，而不是只能被理解。

### Step 3: 设计一次验证

- 选择成本最低、反馈最快的一步先做。
- 记录对方反应，判断是否继续投入资源。
- 做完信号：有真实反馈，而不是停在脑内推演。

### Step 4: 回填复盘

- 写下结果、偏差和下一轮调整。
- 如果方法有效，追加到对应项目或客户记录。
- 做完信号：这次动作能被下次复用。

## 判断点 / 决策树（如有分支）

```text
对象明确 + 目标明确 -> 跑完整流程
对象明确 + 目标不清 -> 先补目标
对象不明确 -> 回到场景筛选，不启动 SOP
验证无反馈 -> 降低投入，改做信息补全
```

## 常见坑（3-5 条硬红线）

- 不要把“理解了”当成“已经会做”。
- 不要没有对象就空跑流程。
- 不要一次压太多动作，先拿一个真实反馈。
