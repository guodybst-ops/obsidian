# [SOP] 爆款文案五步公式

## 一句话（≤ 40 字）
按五步写出能推动行动的转化文案。

## 什么时候用（触发条件，3-5 条 bullet）

- 写小红书、朋友圈、销售页、私域成交文案。
- 用户看了内容但没有行动。
- 你有产品/服务，但说不清它和用户有什么关系。
- 你需要把抽象价值翻译成具体场景。
- **红线**：不适用于没有真实产品价值的焦虑营销。

## 输入（做之前要准备的东西）

- 一个明确目标用户。
- 一个具体产品/服务。
- 用户常见场景、担忧和想要的结果。
- 至少一个可信案例或背书。

## 输出（做完得到什么）

- 一段完整转化文案。
- 一条明确行动指令。
- 完成信号：用户知道“我为什么现在要做这件事”。

## 主流程（核心，占篇幅 ≥ 60%）

### Step 1: 唤醒具体场景

- 用时间、地点、动作、感受写出用户熟悉的场景。
- 避免“很多人都焦虑”这类抽象句。
- 做完信号：目标用户能说“这不就是我吗”。

### Step 2: 放大后果

- 写出这个问题不解决会影响什么：工作、关系、钱、时间、自我认同。
- 不夸大恐吓，只呈现真实损失。
- 做完信号：用户理解拖延的代价。

### Step 3: 植入方案

- 把产品/服务作为针对当前问题的解法出现。
- 只讲和场景相关的卖点。
- 做完信号：用户知道这个方案为什么适合他。

### Step 4: 放入信任背书

- 加入案例、数据、截图、客户反馈或专家身份。
- 背书要具体可查，不写空泛大词。
- 做完信号：用户的“它真的有用吗”被回应。

### Step 5: 给出行动指令

- 明确告诉用户下一步做什么：预约、评论、私信、下单、填写表单。
- 给出现在行动的合理理由。
- 做完信号：用户不需要自己猜下一步。

## 判断点 / 决策树（如有分支）

```text
用户看不懂 -> 回到 Step 1，用更具体场景
用户不紧迫 -> 回到 Step 2，补真实后果
用户不信 -> 回到 Step 4，补可验证背书
用户不行动 -> 回到 Step 5，简化指令
```

## 模板 / 清单 / 打分卡（可复制粘贴）

```text
我发现你是不是经常在【具体场景】里遇到【具体问题】。
如果它一直不解决，最容易带来【真实后果】。
所以我建议你先用【方案/产品】，它能帮你【对应结果】。
之前【同类人/案例】用它拿到了【可验证结果】。
如果你也想解决这个问题，现在【行动指令】。
```

## 常见坑（3-5 条硬红线）

- 不要用抽象痛点代替具体场景。
- 不要把无关产品硬塞进方案植入。
- 不要用虚假案例做信任背书。
- 不要让用户“回去想想”却不给下一步。

## 附录：实例（1 个跑通的例子，与主流程分开）

护肤产品不写“现代女性很忙也要爱自己”，而写“每天加班到凌晨，想护肤但连敷面膜时间都挤不出来”。再写长期不处理会影响皮肤状态和社交信心，植入快速护理方案，补上同类用户反馈，最后给出当晚即可购买/领取试用的指令。
