# [框架] 时代平台自己三重力量归因

## 一句话（≤ 40 字）
拆清成功来自时代、平台还是自己。

## 什么时候用（触发条件，3-5 条 bullet）

- 你想从大平台离开做独立顾问。
- 你觉得过去业绩主要靠自己。
- 你准备转型超级个体、一人公司或小团队。
- 你要判断客户、人脉、背书离开平台后还在不在。
- **红线**：不要在情绪化离职当天做这个判断。

## 评估对象（这个框架用来打分的是什么）

- 一段过去成功经历、一个职业阶段、一个业务能力。
- 颗粒度：具体项目或业务结果，不评估抽象“我厉不厉害”。

## 维度定义（框架的骨）

### 维度 1：时代——外部浪潮给了多少顺风

**观测信号**：

| 好信号（时代贡献高） | 坏信号（时代贡献低） |
|---|---|
| 行业整体快速增长 | 逆势仍能稳定获客 |
| 客户预算天然增加 | 预算需要你主动创造 |
| 同赛道多数人都变好了 | 只有你明显跑出来 |

→ **怎么问出来 / 怎么观察出来**：看没有你的同行是否也在同一时期普遍受益。

### 维度 2：平台——组织背书给了多少资源

**观测信号**：

| 好信号（平台贡献高） | 坏信号（平台贡献低） |
|---|---|
| 客户因公司品牌愿意见你 | 客户因你个人愿意复购 |
| 项目依赖公司交付团队 | 你能独立组织交付 |
| 大客户需要平台资质背书 | 小团队/个人也可成交 |

→ **怎么问出来 / 怎么观察出来**：问“如果名片上的公司名消失，客户还会不会回我消息”。

### 维度 3：自己——可迁移能力有多少

**观测信号**：

| 好信号（个人贡献高） | 坏信号（个人贡献低） |
|---|---|
| 客户点名找你 | 客户只认平台 |
| 你能独立获客、成交、交付 | 只负责平台流程中的一段 |
| 离开后仍有人转介绍 | 离开平台后线索断崖 |

→ **怎么问出来 / 怎么观察出来**：看过去客户是否愿意在你换平台或单干后继续合作。

## 打分卡 / 分级表（可复制粘贴）

| 成功经历/项目 | 时代贡献 | 平台贡献 | 自己贡献 | 结论 |
|---|---|---|---|---|
|  | 高/中/低 | 高/中/低 | 高/中/低 |  |

- **时代高 + 平台高 + 自己低** → 不建议贸然单干。
- **平台高 + 自己中** → 可考虑小平台/合伙，不急着完全独立。
- **自己高 + 平台中低** → 可测试独立获客与小规模交付。

## 打完分怎么用（决策后果）

- 自己贡献不足 → 先补个人品牌、客户转介绍和独立交付样本。
- 平台贡献过高 → 离开前设计替代背书：合伙人、案例、联盟、顾问网络。
- 时代贡献过高 → 判断新周期是否还在，不用旧红利推演未来。

## 常见坑（3-5 条）

- 不要把平台信用误认成个人魅力。
- 不要把行业红利误认成销售能力。
- 不要只凭“我感觉客户喜欢我”做决策。
- 不要独立后才发现自己没有完整交付链。

## 附录：实例（1 个跑通的例子）

一个大咨询公司合伙人想单干。先拆过去客户为什么买单：是行业数字化预算上升、公司品牌背书，还是他个人被信任。若客户主要因为大公司品牌与完整团队而签约，单干前就要先建立合作方网络、案例背书和可独立成交的小项目。
