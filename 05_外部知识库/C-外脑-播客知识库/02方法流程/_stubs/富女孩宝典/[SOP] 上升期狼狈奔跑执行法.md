# 上升期狼狈奔跑执行法

## 一句话

**新手女宝上升期就是很狼狈的——把"我还没准备好"改成"我先跑起来让溢出的先流出去"，接住每一次机会而不是先修剪自己。**

## 什么时候用

- ✅ **突然被推到不熟悉的位置**：接了一个远超能力的项目 / 客户
- ✅ **收入 / 影响力短期跳档**：小红书突然爆了、公司突然升职
- ✅ **对外扩张但内在还没准备好**：想上但又觉得自己"不配"
- **红线**：不适用于账面已经现金流断裂（先止损）；不适用于持续 6 个月+ 无进展的伪上升期（那是原地打转）

## 输入

- **过去 30 天新出现的 3 个"我不熟"场景**（甲方 / 平台 / 关系）
- **你目前的"应付底线"**（能撑几天不睡觉 / 几笔现金流备用）
- **你能立刻求助的 3 个人**（他们能给你临时补位）

## 输出

- 一份**溢出管理清单**（模板 A）
- **完成信号**：**上升期结束时你没崩、没自我否定、没错失机会**——三条同时成立

## 主流程

### Step 1：承认"狼狈是上升期的特征，不是 bug"

- 拿纸写：*"我现在狼狈，是因为我在上升，不是因为我不行。"*
- 上升期 = 需求 > 能力，所以一切都会漏出来（做不完 / 说错话 / 关系失衡）
- 思思金句："**新手女宝上升期就是很狼狈的**——不要因为狼狈就停下来修边幅，狼狈是奖章不是伤口。"
- **判断信号**：能一字一句念完不反驳自己

### Step 2：识别"溢出"——哪些是必须扔出去的

- 列出你正在同时做的所有事，标出：
  - **核心圈**：只有你能做 / 不能出错的（例：客户当面交付、合同）
  - **溢出圈**：能被别人做 / 出错也可控的（例：排期、通讯、素材整理）
- 溢出圈一律**外溢**：请人、给钱、给资源、给分成
- **判断信号**：核心圈事项 ≤ 你一天能干的最大量

### Step 3：花钱买时间——不是投资是止损

- 上升期最贵的是**你自己的时间**，不是钱
- 3 种立即外溢：
  - **助理**（月 5000-8000）接线、排期、素材
  - **专业顾问**（单次 1000-3000）法务 / 财务 / 医疗
  - **陪跑教练**（月 3-8 千）你上一阶跑通的人
- 思思金句："**上升期最不该省的就是让你少走弯路的钱**——你省的这 5000 会让你后面赔 5 万。"
- **判断信号**：本月已花至少 1 笔"买时间"的钱

### Step 4：允许"当下丑陋"——只保 60 分交付

- 每一件事只做**60 分**（够用 / 不出事 / 能收钱）
- 客户觉得不完美——**先交付，收到钱再迭代**
- 拒绝完美主义——**完美主义在上升期等同于自杀**
- **判断信号**：过去一周内至少 3 件事你只做到 60 分并放手了

### Step 5：每周 30 分钟复盘——溢出 vs 崩塌

- 每周问自己 3 问：
  - 上周有没有**接住新机会**？
  - 上周有没有**外溢**至少 3 件事？
  - 上周有没有**至少一件事只做 60 分**放手？
- 三条都 ✅ → 上升期健康推进
- 有 ≥ 1 条 ❌ → 你在原地卷不是在上升
- **判断信号**：连续 4 周三条都 ✅ → 上升期跑通

## 判断点：上升期 vs 假上升

```
一个月新增 3+ 陌生机会 ────→ 真上升期
每周仍在原来客户圈内 ─────→ 假上升期（在卷不在升）
一个月无新增合作 ─────────→ 停滞期（换脚本，不是狼狈奔跑）
狼狈但账面持续增长 ───────→ 健康
狼狈但账面持续下降 ───────→ 止损而非奔跑
```

## 模板 A：溢出管理清单

```
━━━━━ 溢出管理清单 ━━━━━
本周待办事项（全部列出）：
1. __________ □核心 □溢出 → 交给谁：__
2. __________ □核心 □溢出 → 交给谁：__
3. __________ □核心 □溢出 → 交给谁：__
...

本周买时间投入：￥______
本周只做 60 分事项：__________
本周新增机会 / 陌生人：___ 个

3 问自检：
□ 接住新机会
□ 至少 3 件外溢
□ 至少 1 件 60 分放手
━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 常见坑

- ❌ **上升期还想 100% 交付** → 全部拖延，机会全跑
- ❌ **不肯外溢** → 想省 5000 结果三个月后崩溃
- ❌ **只跟老朋友说话** → 上升期需要新关系，老关系承不住新剧本
- ❌ **狼狈变自我否定** → 把"我在上升"读成"我不配"，直接掉下去
- ❌ **停下来"先修好自己再上"** → 修完就没热度了
- ❌ **炫耀狼狈** → 狼狈是私下事，公开只讲结果

## 附录：实例（011 集提问者"小红书突然爆了不知咋接"）

**背景**：一位听众小红书一夜涨粉 3 万，甲方私信爆炸，她慌了。

- Step 1 承认狼狈：思思让她写"我现在狼狈是因为在上升"
- Step 2 识别溢出：她把"回私信 + 报价 + 合同"外溢给一位付费助理
- Step 3 花钱：花 5000/月招助理 + 1500 咨询一位法务解决合作合同模板
- Step 4 60 分：不再逐条精修回复，用标准报价单发给对方
- Step 5 复盘：第一周接了 4 单 = 8 万元，助理成本回本 16 倍

**思思点评**："**你上升期敢外溢，一年抵三年**——舍不得溢出的人一辈子在原地打磨自己。"
