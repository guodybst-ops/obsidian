# 情商三大岗位识人法

## 一句话

**用"前端 / 后端 / 管理端"三个岗位表把陌生人的情商快速分类——谁能顶到前面见客户，谁只能藏在后面做交付，谁能站在中间做协调，一眼看穿。**

## 什么时候用

- ✅ **组队 / 合伙前识别对方定位**：判断能给他哪个位置
- ✅ **招人时快速分岗位**：不要用一份 JD 招所有人
- ✅ **自我诊断**：搞清楚自己天然适合哪一岗位，不要硬做不适合的
- **红线**：不适用于纯技术极客型独角戏（他不需要三岗位）；不适用于短期项目 1-2 单合作（用不上此模型）

## 输入

- **候选人 / 合伙人的 3 个过往协作案例**（他做过什么类型的事）
- **他遇到冲突时的一次真实反应**（有没有原话最好）
- **他被别人评价最多的 1 个关键词**

## 输出

- 一张**三岗位定位卡**（模板 A）
- **完成信号**：候选人被稳定归入 1 个主岗位 + 至多 1 个次岗位——**不能是三个都行**（那是没定位）

## 主流程

### Step 1：观察"前端相"——见人说话是不是天然舒服

- 让候选人跟一个**他不熟的第三方**聊 15 分钟
- 观察指标：
  - 主动开话题 / 找共同点 / 让对方笑
  - 语言里"你"多于"我"
  - 结束时对方主动加联系方式
- 思思金句："**前端要的不是好看，是让人愿意付钱和你继续聊**——这是天赋不是训练。"
- **判断信号**：三条都对 → 前端相；只对 1 条 → 训练也难成前端

### Step 2：观察"后端相"——接住的能力

- 让候选人拿一个模糊需求做 24 小时闭环交付（不给标准答案）
- 观察指标：
  - 自动澄清需求边界
  - 交付时**颗粒度比预期更细**
  - 主动罗列 3 个后续风险
- 思思金句："**后端要的不是勤奋，是把糊的需求做清晰**——你把火车零件给他，他能装出车头。"
- **判断信号**：三条都对 → 后端相；能兼有前端相 → **稀缺双料**

### Step 3：观察"管理端相"——冲突里的中枢反应

- 抛一个**真实冲突场景**：两个同事因利益分配吵起来，问候选人怎么处理
- 观察指标：
  - 先问"发生了什么"而不是"谁对谁错"
  - 提出的方案里能同时说到**双方的痛**
  - 允许"暂时不给答案"，先约下一次协调
- 思思金句："**管理端要的不是威严，是让所有人愿意继续跟他玩下去**——是黏合剂，不是仲裁官。"
- **判断信号**：三条都对 → 管理端相；只对 1-2 条 → 一线管理可以，高级管理不够

### Step 4：交叉验证——三张相是否互斥

- 一个健康候选人应该：
  - 有 1 个**主岗位相**（明显强）
  - 有 1 个**次岗位相**（能接住）
  - 有 1 个**弱岗位相**（会被消耗）
- 三个都强 → 通常是包装或者时间还没到
- 三个都弱 → 情商基本盘不足，不适合协作型岗位
- **判断信号**：主 + 次 + 弱结构清晰

### Step 5：按岗匹配任务，避免错配

- 前端强的人 → 客户对接 / 招商 / 演讲 / 谈判
- 后端强的人 → 交付 / 品控 / 数据 / 内容深度加工
- 管理端强的人 → 项目协调 / HR / 合伙人间沟通 / 客户成功
- **不要**把前端相的人扔进后端 → 他会自我怀疑并离职
- **不要**把后端相的人推到前端 → 他会被客户吃掉又拿不到订单
- **判断信号**：分岗后 3 个月内**协作复购 / 内部投诉率**下降

## 判断点：三岗位快速识别

```
让人愿意继续聊+主动加你 ──→ 前端
把糊需求做出清晰交付 ────→ 后端
冲突里让双方都愿意谈 ────→ 管理端
以上都无 ────────────────→ 不进核心协作圈
```

  □ 澄清需求   □ 颗粒度细       □ 主动风险

  □ 先问事实   □ 说到双方痛     □ 允许缓释

## 常见坑

- ❌ **只看能力不看岗位相** → 招一个高能力后端去谈客户，交付质量崩
- ❌ **把"看起来外向"当前端相** → 外向 ≠ 让人付钱
- ❌ **让管理端相的人上前端** → 他会做调停但拿不到订单
- ❌ **一个岗位两个前端相合伙** → 都想露脸没人交付
- ❌ **合伙团队全后端相** → 没客户，产品做到破产也没人卖
- ❌ **用一次直觉判断岗位** → 至少三次不同场景验证

## 附录：实例（010 集"大厂菜鸡互卓"的团队复盘）

**背景**：一位大厂裸辞的女生跟另外 2 个前同事合伙做私域，3 个月散伙。

- 复盘发现：**3 个人都是后端相**（都在大厂做过运营/数据）——没人愿意出去谈客户，交付堆得再好也没订单
- 思思点评："**你们不是不努力，是三个后端凑不出一个前端**——这是识人错配，不是能力错配。"
- 反面案例：另一组听众 3 人合伙，前端 / 后端 / 管理端各一，半年跑到月流水 30 万——**同样的赛道，只因岗位相齐全**

**思思总结**："**看人不看能力，看岗位相**——能力可以磨，岗位相是天赋。"
