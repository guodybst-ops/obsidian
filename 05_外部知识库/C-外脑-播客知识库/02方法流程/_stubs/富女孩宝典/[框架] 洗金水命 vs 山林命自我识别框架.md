# [框架] 洗金水命 vs 山林命自我识别框架

## 一句话
斯斯 004 原创二分法——**你放假一周会主动去哪里？是往城市/人群/局里冲（洗金水命），还是往山里/村里/独处躲（山林命）？** 两种命都能挣钱，但选错生意形态就是内耗。

## 什么时候用
- 高敏感 / 社恐 / MBTI I 人纠结要不要做\"要见人\"的生意时；
- 判断自己适合前端 IP 还是后端交付时；
- 判断自己应该做 B 端咨询还是 C 端内容电商时。

## 判断标准（004 原话）
> **\"你放假一周主动去哪里？你去外滩、去局子、去 party，你就是洗金水命；你去山里、去村里、去闭关，你就是山林命。\"**

## 四个维度对照

| 维度 | 洗金水命 | 山林命 |
|---|---|---|
| **能量恢复源** | 从人群/信息/局中回血 | 从独处/自然/深度思考回血 |
| **社交倾向** | 主动加微信、拉群、见人 | 一对一深聊 / 文字沟通 |
| **决策速度** | 现场拍板、气氛决定 | 事后复盘、数据决定 |
| **生意形态适配** | 前端 IP / 直播 / 商务 / BD | 后端交付 / 研发 / 咨询 / 深度内容 |

## 打分卡（每题选 A=洗金 B=山林）

1. 放假一周主动想去哪：A 城市/局 / B 山/村；
2. 一个陌生人加你微信你的第一反应：A 太好了 / B 有事说事；
3. 连续开会 5 场后你的状态：A 亢奋 / B 想死；
4. 你最讨厌的动作：A 独自面对空白文档 / B 陌生人 20 人饭局；
5. 你收入最高的月份，是靠：A 见了很多人 / B 一件事做到极致。

- **≥4 个 A**：洗金水命。
- **≥4 个 B**：山林命。
- **各 2-3 个**：混合命——**建议选 3 山林命的生意形态 + 2 洗金水的对外接口**，别硬扭。

## 打完分怎么用

### 洗金水命
- **上舞台**（004 原话推导）——去做前端 IP / 直播主播 / 商务合伙人；
- 010 情商三大岗位：**产品经理 / 商务销售 / 老板助理**天然适合；
- 别做的：一个人在家写代码、闷头做深度研究。

### 山林命
- **上货架**——做后端交付 / 独立咨询 / 深度内容 / 手艺人；
- 013 案例：**招 2-3 个类似风格摄影师做后端交付**——山林命做后端一顶三；
- 别做的：直播、连开 5 场业务饭局、每天见陌生人。

## 常见坑
- **山林命强扭洗金**：内耗、掉头发、心气被磨光（004 金句 8 呼应\"心气不可再生\"）；
- **洗金命闷在山里**：能量低、抑郁、说自己\"最近没状态\"；
- **误判**：把\"社恐\"当\"山林命\"——很多人是**社恐但洗金水命**（想见人但害怕），这种要先破木马程序（[心法]木马程序破除四步法），不是选\"山林\"；
- **忽略混合命**：非黑即白强行分类，反而丢掉自己两栖优势。

## 附录：三种典型混合命人设

- **80% 山林 + 20% 洗金**：独立咨询师，1v1 深聊为主，每季 1 场线下沙龙；
- **50/50**：主业山林命交付（研发/设计），副业洗金命 IP（周更小红书）；
- **80% 洗金 + 20% 山林**：主播 / BD，每周留 1 天闭关做内容策划。
