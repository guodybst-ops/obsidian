# GPT当项目经理协作法

## 一句话

**把 GPT 当"最便宜的项目经理"——把所有沟通 / 资料 / 任务喂进去，让它帮你拆项目 / 排优先级 / 做甘特图 / 写周报，人只做执行 + 审阅，从执行者升级为项目经理。**

## 什么时候用

- ✅ **打工人卡在"执行者"位**：等派活、只会做单点任务、看不到项目全局
- ✅ **副业 / 咨询同时开多个项目**：每天忙但产出乱
- ✅ **想升职但没管过项目**：缺少项目管理经验证据
- **红线**：不适用于强保密 / 合规行业不允许把资料喂 AI 的（先做合规再谈）；不适用于**已经是资深 PM** 的（你需要的是团队而不是 GPT）

## 输入

- **你正在做 / 想主导的一个具体项目名字**
- **相关的所有资料**（会议纪要 / 沟通记录 / 需求文档 / 客户材料）
- **你的执行时间约束**（一周能投入多少小时）

## 输出

- 一份**GPT 项目经理工作台**（模板 A）
- **完成信号**：3 个月后你能拿出该项目的**完整项目档案**（拆解 + 甘特 + 周报），足以跟老板 / 客户展示"我在管这个项目"

## 主流程

### Step 1：把项目"喂饱" GPT

- 把**所有相关资料**喂进 GPT 的**同一个对话 / 项目 / GPTs 里**：
  - 会议录音转写
  - 微信 / 邮件沟通片段
  - 客户 / 领导需求描述
  - 相关行业资料 / 竞品资料
- **不要**分散在多个对话里 —— 项目上下文必须集中
- 思思金句："**GPT 是最便宜的项目经理**——喂得越饱，输出越靠谱。"
- **判断信号**：GPT 能复述项目的**关键人 / 关键动作 / 关键时间点**

### Step 2：让 GPT 拆项目——WBS 工作分解结构

- Prompt 模板：*"请把这个项目拆成 3 级 WBS，第 1 级 3-5 项，第 2 级每项 3-5 项，第 3 级到具体动作。"*
- 拿到 WBS 后**自己审阅一遍**——加你了解但 GPT 不知道的信息
- **判断信号**：你能一眼看出 WBS 里 ≤ 20% 是错的（错太多说明喂料不够，回 Step 1）

### Step 3：让 GPT 排优先级 + 做甘特图

- Prompt 模板：*"基于 WBS，请为每一项估算工时并按依赖关系排出 4 周甘特图，用 Markdown 表格输出。"*
- 输出后自己划**关键路径**——哪一条最容易 delay
- **判断信号**：甘特图能落到具体一天做具体一件事

### Step 4：让 GPT 写周报 / 周会脚本

- 每周把当周做完的、还没做的、卡壳的喂给 GPT
- Prompt 模板：*"根据这周进度更新和之前的甘特图，写一份 200 字周报，包含完成事项 / 待办事项 / 风险点，给我的老板 / 客户看。"*
- **判断信号**：周报能直接发出去（改 < 10% 即可）

### Step 5：假装"我在管项目"——3-6 个月做实

- 一开始**不告诉别人**你用 GPT
- 每周开会 / 汇报时你**用 GPT 生成的资料**
- 3-6 个月后，老板 / 客户会真的把项目管理权给你——**你已经用 GPT 训练成了真项目经理**
- 思思金句："**一开始假装自己是项目经理，暗地里用 GPT 规划**——3-6 个月后交付质量升级，导师会真的把项目管理权给你。"
- **判断信号**：老板 / 客户开始主动找你要项目状态而不是你追着报

## 判断点：GPT 能替代 vs 不能替代

```
项目拆解 / 甘特 / 周报 ─────→ GPT 全替代（省 80% 时间）
需求澄清 / 关系判断 ────────→ 人做（GPT 辅助）
决策 / 拍板 ───────────────→ 人做（GPT 不参与）
向客户 / 老板汇报 ──────────→ 你自己讲（GPT 做备忘）
```

## 常见坑

- ❌ **把资料分散在多个对话里** → GPT 上下文断层，输出错乱
- ❌ **只让 GPT 生成一次就用** → 项目在变，喂料要每周更新
- ❌ **不审阅 GPT 输出直接发** → 会有幻觉信息，砸招牌
- ❌ **让 GPT 替你做决策** → 决策必须人做，GPT 只做备选方案
- ❌ **公开吹嘘"我用 GPT"** → 老板会觉得你在偷懒；先做实再讲
- ❌ **喂敏感 / 保密资料** → 走公司合规审查通道
- ❌ **不做 3-6 个月连续训练** → GPT 是长跑工具，1 次上手无效

## 附录：实例（015 集提问者"一一"—— 智库咨询打工人升级项目经理）

**背景**：一位省级智库咨询打工人（一一），一直在执行别人派下来的项目片段，天花板月薪 3 万。

- 诊断：不是能力不行，是**没把自己当项目经理**——一直在等派活
- 用 GPT 方案：
  - 把过去 6 个月项目的所有邮件 / 会议 / 客户资料喂进一个 GPT 项目
  - 让 GPT 生成完整 WBS + 甘特图 + 周报
  - 每周会议她用 GPT 的产物做汇报
- 3 个月后：导师主动把一个新项目的**项目管理权**交给她，年薪谈判从 3 万月薪 → 60 万年薪对话
- 思思点评："**执行者月薪 3 万封顶，项目经理年薪 100 万起——差的不是能力，是视角**。GPT 是最便宜的视角升级器。"

**上、中、下策定位**：一一这一步走的是**上策**——从执行者向上跃迁到项目经理层。
