# 换脚本找杠杆借力打力三步法

## 一句话

**普通人财富跃迁不是靠更努力，是靠"换一个脚本 → 找一个杠杆 → 借一个已有力量"的三步跳，一步都不能省。**

## 什么时候用

- ✅ **收入到达能力上限**：你已经很拼，但收入不动
- ✅ **同龄人开始拉开身位**：别人跃迁了你原地
- ✅ **换工作换城市但没换命运**：换了三份工作还在同一个薪资档
- **红线**：不适用于当下有稳定复利路径且不想颠覆的（复利本身也是路径）；不适用于纯情绪型逃离（先解决情绪）

## 输入

- **你过去 3 年的收入曲线**（列表：月/季度/年）
- **你身边 5 个"跃迁过"的人的完整跃迁路径**（他们从做什么切到做什么）
- **你目前所在赛道的天花板估算**（这赛道 top 10% 的人赚多少）

## 输出

- 一份**跃迁三段路径卡**（模板 A）
- **完成信号**：能填出**新脚本、目标杠杆、借力对象**三个具体名词——填不出说明还在原脚本里

## 主流程

### Step 1：看清"你现在的脚本"

- 写下你现在赚钱的一句话逻辑：*"我通过 _____ 得到 _____ 的收入"*
- 判断这个脚本的**天花板**：你所在行业 top 10% 一年能到多少
- 思思金句："**你想要的东西不在你现在的脚本里**——继续跑，你的终点就是那个天花板。"
- **判断信号**：你能承认"就算我干到 top 10%，也拿不到我想要的数字"

### Step 2：换一个"新脚本"——从终局倒推

- 反过来：**你想要的年收入数字** → 什么脚本能到这个数字？
- 列出 3 条已被人跑通的脚本（不用创新，找现成的）
- 例：从"设计师按稿收费"→ 换成"设计师做 SaaS 工具 / 培训 / 顾问"
- **判断信号**：新脚本的天花板 ≥ 你想要数字的 3 倍（留 3 倍余量才能中位跃迁）

### Step 3：找"杠杆"——一个人干十个人的活

- 杠杆四种：
  - **人的杠杆**：团队 / 助手 / 学员
  - **钱的杠杆**：投资 / 借贷 / 分成
  - **产品的杠杆**：软件 / 课程 / 书 / 模板
  - **平台的杠杆**：小红书 / 抖音 / 私域
- 选 1 个**你能立刻起步的**杠杆
- 思思金句："**换脚本之后一定要找杠杆**——没有杠杆的新脚本还是打工。"
- **判断信号**：这个杠杆能让你**一次投入 → 多次收益**

### Step 4：借"已有力量"——不要从 0 起步

- 找一个**已经跑通新脚本的人**，跟他借力：
  - 借他的用户（付佣金 / 分成合作）
  - 借他的方法论（付学费 / 拜师 / 合伙）
  - 借他的品牌（联名 / 挂名 / 徒弟）
- 思思金句："**借力打力比自己发力便宜 10 倍**——你没时间自己趟一遍所有坑。"
- **判断信号**：能报出**具体一个人的名字 + 借力方式**

### Step 5：小闭环跑 90 天，回头修正

- **90 天**内跑一个小闭环：新脚本 + 杠杆 + 借力，产生**第一份可结算收入**
- 复盘：哪个环节最卡？换脚本卡（跑错方向）还是杠杆卡（工具错）还是借力卡（关系没到）？
- **判断信号**：90 天有 ≥ 1 单真实付费；没有 → 回 Step 1 换脚本

## 判断点：三段哪一段卡住

```
新脚本天花板 < 你想要 ────→ 卡在换脚本（重选）
新脚本对但没杠杆 ──────→ 卡在杠杆（补工具/团队/产品化）
杠杆有但收入还是慢 ────→ 卡在借力（找一个已跑通的人合作）
90 天有第一单 ─────────→ 三段跑通，规模化
```

## 模板 A：跃迁三段路径卡

```
━━━━━ 跃迁三段路径卡 ━━━━━
【现脚本】我通过___得到___的收入
现天花板：__________
【目标数字】____ 万 / 年

【新脚本】我通过___得到___的收入
新脚本天花板：__________（≥ 目标 × 3）

【杠杆】□人 □钱 □产品 □平台
具体杠杆：__________

【借力对象】__________
借力方式：□分成 □拜师 □联名 □合伙

90 天小闭环目标：____ 单 / ____ 元
━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 常见坑

- ❌ **只换脚本不找杠杆** → 换了赛道还是按时间卖钱，天花板照样
- ❌ **找杠杆不借力** → 从 0 造轮子 3 年，别人已经跑三圈
- ❌ **借力不换脚本** → 帮别人打工升级版，收入被抽血
- ❌ **90 天不出小闭环仍继续加大投入** → 方向错，越用力越远
- ❌ **迷信"跨界必成"** → 换脚本要**离原能力半径 1-2 步**，跨太远无杠杆可搭
- ❌ **借力时不给对方明确好处** → 白嫖式借力谁都不理你

## 附录：实例（008 集听众"设计师收入停滞"案例）

**背景**：一位平面设计师，月入 1.5 万干了 4 年不动。行业 top 10% 月入 4-5 万——**天花板明确**。

- Step 1 看清脚本：她的脚本是"按稿收费"，天花板 60 万/年
- Step 2 换脚本：改成"设计师内训 / 陪跑咨询"——天花板可到 200-300 万/年
- Step 3 找杠杆：**用小红书做课程 + 陪跑分销** （平台 × 产品杠杆）
- Step 4 借力：找已跑通的**设计教练"某某老师"付学费拜师 + 分成合作**
- Step 5 结果：90 天卖出 12 单，单价 3980，跑通闭环

**思思点评**："**换脚本找杠杆借力打力，是普通人财富跃迁最便宜的路径**——不需要天赋，不需要背景，只需要不再原地卷。"
