# 高敏感沟通三段论落地法

## 一句话

**把"我不敢说"的场景拆成"观察—感受—需求"三段，一次只讲一段，让高敏感人也能开口谈钱、谈边界、谈合作。**

## 什么时候用

- ✅ **谈钱/涨价/催款**：客户拖尾款、老板压价，你想开口但张不开
- ✅ **拒绝不合理需求**：亲戚借钱、朋友白嫖、老板加不合理任务
- ✅ **合伙人/伴侣冲突**：想表达不满但怕关系破裂
- **红线**：不适用于对方明确恶意/PUA场景（该走则走，不谈）；不适用于纯商务议价（那是筹码题不是沟通题）

## 输入

- **一件让你堵心的具体事**（含时间、地点、对方原话）
- **你目前的回避动作**（拖着不回、装没看见、假装同意）
- **你真正想要的结果**（一句话，白纸黑字写下来）

## 输出

- **一段 3 句话的表达文本**：观察句 + 感受句 + 需求句
- **完成信号**：讲完对方没有立刻爆炸，且给出了具体回应（拒绝也算成功——至少事推动了）

## 主流程

### Step 1：写"观察句"——只描述事实，不评价

- 只写**看得见摸得着**的动作/数字/时间点，不加形容词
- ❌ "你总是拖延" → ✅ "上周三我发了尾款单，到今天还没收到"
- **判断信号**：一句话读给第三方听，对方能复述回来同样的事实

### Step 2：写"感受句"——只讲自己，不指控对方

- 用**"我感觉…"**开头，绝不用"你让我…"
- ❌ "你让我很失望" → ✅ "我感觉很不安，因为下周我要交房租"
- **判断信号**：这句话删掉后对方仍能理解你的处境（说明你讲的是你自己）

### Step 3：写"需求句"——具体到动作和时间

- 提**一个动作 + 一个截止时间**，不要多个
- ❌ "你能不能重视一下" → ✅ "能否本周五前把尾款打过来？"
- **判断信号**：对方能直接回答"能"或"不能"

### Step 4：一次只发一段，等回应

- 三句话可以合在一起说，但**不要再补充第四句**——多说必输
- 发出去后**离开对话框 10 分钟**，防止自己脑补对方情绪追加解释
- **判断信号**：对方回应后你能就着他的话继续，而不是重新组织语言

## 判断点：什么时候用三段论 vs 直接走

```
关系还想留 + 事情还想推 ──→ 用三段论（Step 1-4）
关系不重要 + 事情能推 ────→ 直接给最后通牒（发律师函/走流程）
关系重要 + 事情已成沉没成本 ─→ 不谈，止损离场
```

## 模板：三段论填空

```
【观察】上_____（时间），你_____（具体动作/原话）
【感受】我感觉_____（一个情绪词），因为_____（你的处境）
【需求】能否在_____（截止时间）前_____（一个具体动作）？
```

## 常见坑

- ❌ **观察句里带评价**（"你总是""你从来"）→ 对方立刻防御，谈崩
- ❌ **感受句变成指控**（"你让我失望"）→ 三句话瞬间失效
- ❌ **需求句提"重视一下""上心一点"** → 对方无从回应
- ❌ **一次讲三件事** → 火力分散，一件也推不动
- ❌ **发完立刻追加解释** → 显得心虚，对方拿捏节奏

## 附录：实例（004 集听众"社恐设计师"的复购谈判）

**背景**：高敏感设计师给客户交完稿，客户想白嫖后续修改。原本回避两周不敢开口。

- 观察：*"上周四交付初稿后，你提了 6 版修改，超出合同约定的 2 版。"*
- 感受：*"我感觉压力比较大，因为超出的部分挤掉了我下一个项目的时间。"*
- 需求：*"能否按合同报价的 30% 追加超版费，本周内确认？"*

**结果**：客户没砍价，直接付了追加费——**"复购"节奏走通**，思思在节目里点评："**创业不需要 100% 准备好，30% 就可以开始沟通了。**"
