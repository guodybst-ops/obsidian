# [心法] 打不赢就走打得赢才打

## 核心原则

> **[原话]** "打不赢就走，打得赢才打 —— 教员一生只打过 4 次败仗，因为败的仗他都不打。"（014 单集金句 + 收尾锚点）

> **[原话]** "你觉得一个有钱人是靠赌的，真的不是，都是靠算的、算的很清楚。"（014 收尾）

> **[原话]** "如果你的运气不好，你就好好打牌 —— 你的牌技提上来也可以。"（014 斯斯爸爸留下的话）

- 一生打过多少败仗**不是能力问题、是选择问题**——教员一生 4 次败仗，因为**败的仗他都不打**；
- 真正赚过上亿的人**没有一个是靠赌的**，都是**算得很清楚**才动手；
- 运气不好不是借口——**修牌技依然可以扭局**；
- 打得一拳开、免得百拳来——**该打的仗必须打赢**，输不起的仗必须走；
- 判据：**"这一仗我能不能算清赢面？"** 算不清就先撤，算清了才动。

## 触发场景

- 场景 1：**考虑跳槽 / 辞职 / 梭哈**——想 all in 大项目、想赌一次翻身；
- 场景 2：**觉得"这仗我一定要打"**——情绪上头认定必须证明什么；
- 场景 3：**想赌一次**——把身家投进不确定的机会（微商梭哈、辞职创业、押注单一项目）；
- 场景 4：**觉得自己只是运气不好**——把结果归因给运气而不修牌技；
- 场景 5：**想通过一次大动作证明自己**——少年心气式的"豁出去梭哈一下"（014 教培女孩案例）。

## 反例警示

- 反例 1：**"我不豁出去梭哈一下就没机会了"** → 014 直接反驳："那不是商业，那是往火坑里跳"；
- 反例 2：**"人要冒险要拼一把"** → 014 修正："人要冒险，不是拿主业全盘去冒险 —— 是拿可支配的时间去试"；
- 反例 3：**"我运气不好所以做不成"** → 斯斯爸爸原话反驳："运气不好就修牌技"；
- 反例 4：**"我算不了，感觉就是对的"** → 014 原话："你不愿意为思考付出时间、不愿意为提高认知获得时间——你觉得有钱人是靠赌的，真的不是"；
- 反例 5：**"教员当年也是敢打敢冲的"** → 014 原话反驳："教员一生只打过 4 次败仗，因为败的仗他都不打"——他是选战场的高手。

## 常见误用

- **变成"永远不打"**：过度谨慎、错失所有窗口——判据是"**打得赢才打**"，不是"什么都不打"；
- **只算物理算不了心理**：账本能算，但情绪不能算——**情绪账要先给平静下来 24 小时再拍板**；
- **算了但不撤**：算清了打不赢还硬打——**沉没成本不是理由**；
- **误把"走"当逃避**：走是**换战场重新算账**，不是永远不面对；
- **把"打得赢"标准定得太低**：只算眼前 30% 胜率就打——教员的标准是"**能算清楚这一仗必然赢**"。

## 判据

- 判据 A：**这一仗如果输了，我会怎样？** 输不起就必须先撤；
- 判据 B：**这一仗有没有跑过账本？** 收入怎么来 / 成本怎么去 / 客户从哪来 / 复购几次 —— 4 问答不出来就是没算；
- 判据 C：**我在赌还是在算？** 情绪推着走 = 赌；纸上算 3 遍还是赢 = 算；
- 判据 D：**教员会打这仗吗？** 用"这仗如果败的话教员会打吗"反问自己。

## 判断动作

1. **列出这一仗的账本**：收入 / 成本 / 时间 / 胜率四栏摊开；
2. **算不清就先撤**：不打不代表放弃，是**换战场重新算**；
3. **算清赢面才动手**：**≥80% 胜率的仗才是"打得赢才打"的标准**——不是 50%；
4. **运气不好就修牌技**：把注意力从"运气"移到"能力"——早开会晚复盘、颗粒度做小；
5. **打得一拳开、免得百拳来**：该打的仗一次打赢、一次打透，避免陷入长期消耗。

## 附录：与其他心法的关系

- 命运出难题就说 OK：**OK 不是硬扛**——是"我接下来判断该走还是该打"；
- 上升期狼狈奔跑：**狼狈不是打输**——狼狈是"边跑边算"的过程，跑不代表在赌；
- 心气不可再生：**心气是选战场的燃料**——心气死了没能力算账；
- 老板思维 vs 打工思维（概念）：**选战场是老板思维的核心**；
- 资本视角看世界：**资本视角就是"这一仗谁赚谁亏我算得清"**；打不赢的仗 = 资本视角能提前看到不赚的仗。
