# 产业链全景视角调研法

## 一句话

**入行一个新赛道之前，先把这条产业链的"上游 - 中游 - 下游 - 中台"四段全部画出来，找到中间**"看不见的赚钱位"**再动手，而不是从末端最卷的那一格开始。**

## 什么时候用

- ✅ **准备切一个新赛道**：跨界 / 换行 / 新副业
- ✅ **已在某赛道但卡住**：想换个位置继续做
- ✅ **看到大机会想抓**：热门赛道值不值得进
- **红线**：不适用于纯个人服务闭环（美甲 / 直播）无产业链结构；不适用于已经跑通只想放大的（那是规模问题不是调研问题）

## 输入

- **目标赛道名字**（例：宠物 / AI 应用 / 短剧 / 咖啡）
- **你能连续投入 3-5 天**（每天 4-6 小时）
- **可用于访谈的 5-10 个内部人**（有的话最好，没有也能补上）

## 输出

- 一张**产业链全景图**（模板 A）——四段每段写清楚 3 家代表公司 + 毛利估算
- **完成信号**：能在 30 秒内跟陌生人讲清这条产业链**中间赚钱位**在哪 + 你要切哪一格

## 主流程

### Step 1：画出四段——上游 / 中游 / 下游 / 中台

- **上游**：原料 / 技术 / IP 提供方（例：AI 应用赛道的上游是模型商）
- **中游**：产品 / 服务的组装方
- **下游**：面向终端客户的销售 / 渠道
- **中台**：为所有环节提供工具 / 数据 / 培训的第三方（例：SaaS / MCN）
- 思思金句："**产业链看不见的赚钱位往往在中台**——上下游打得头破血流，中台稳定抽水。"
- **判断信号**：能画出四段各 ≥ 3 家代表公司名

### Step 2：算每段毛利——找超额利润的位置

- 每段用**资本 4 问**（见 [SOP] 资本视角看世界拆解法）算毛利
- 用不同颜色标出：
  - 红：毛利 > 50%（超额利润，可能进不去）
  - 黄：毛利 20-50%（正常商业）
  - 灰：毛利 < 20%（苦力）
- **判断信号**：能给四段各标一个颜色

### Step 3：找"链式漏斗"——上下游谁被谁卡脖子

- 找出**谁掌握了下一段的入场券**：
  - 上游卡中游？（模型公司卡应用公司的 token 价格）
  - 中台卡下游？（MCN 卡内容电商的达人分配）
  - 下游卡上游？（渠道话事人卡上游账期）
- 思思金句："**卡脖子的那一段是产业链的水龙头**——不是最赚钱的，但最抗风险。"
- **判断信号**：能指出至少 2 处卡脖子节点

### Step 4：确定"我能切"的一格——3 个筛选

- 三个问题：
  - 你的**基本能力半径**能覆盖哪几格？（不熟的一格直接删）
  - 剩下的格子里**哪格毛利最高 / 最抗风险**？
  - 你的**初始筹码** 6-12 个月能撑到跑通吗？（撑不到就选门槛更低的）
- **判断信号**：3 关过完锁定 1-2 格

### Step 5：链式验证——找该格 3-5 位内部人对话

- 用 15 分钟脚本跟真实内部人聊：
  - 你上下游的钱怎么走 / 谁欠谁账
  - 你毛利率区间 / 一年多少客户 / 复购率
  - 最近 6-12 个月最大变化是什么
- **判断信号**：3-5 位内部人的答案能相互印证 / 差异合理

## 判断点：产业链切法快速判定

```
上下游都超额利润 + 中间是苦力 ─→ 切上游或下游
中台是超额利润 ─────────────→ 切中台（若能建）
你能拿到卡脖子节点资源 ──────→ 切卡脖子那格
你只能做红海末端一格 ────────→ 换赛道
```

## 常见坑

- ❌ **只画上下游没画中台** → 错过最赚钱位置
- ❌ **只在小红书看爆款不看毛利** → 爆款不等于赚钱
- ❌ **不做内部人访谈** → 网络信息全是包装，真实钱怎么走看不到
- ❌ **上来就切最热门那一格** → 那格早就红了
- ❌ **画图后不落地** → 全景图变成漂亮 PPT，没进一步动作
- ❌ **一次画完就不迭代** → 产业链 6-12 个月大变一次，必须重画

## 附录：实例（006 集金星"连锁餐饮的中台位"+ 013 集"MCN 中台位"）

**案例 A（006 集 金星）**：金星做连锁餐饮时不做门店（下游苦力），也不做食材供应（上游资本战），她做**"连锁中台"**——为品牌方提供选品 / 加盟培训 / 供应链管理 SaaS。毛利 60%+ 且抗风险，因为下游门店多死几家不影响中台。

- 上游：食材工厂（毛利 10-20% 灰）
- 中游：品牌方（毛利 20-30% 黄）
- 下游：加盟门店（毛利 5-15% 灰）
- **中台：连锁服务商（毛利 50-70% 红）** ← 金星切这格

**案例 B（013 集 MCN 中台）**：思思拆 MCN 行业——上游达人苦（要养号）、下游品牌方苦（要投放），**MCN 作为中台稳定抽 20-40%**。所以聪明玩家不做达人不做品牌方，做**中台数据/工具/结算平台**。

**共同结论**："**产业链画出来的第一天，你就知道你原来在最卷的那一格**——搬到中台，同样的努力回报翻 5 倍。"
