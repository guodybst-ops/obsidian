# [框架] 火车统战价值分层框架

## 一句话
把你自己的产品/服务/人脉像火车一样分成\"车头 / 车厢 / 车尾\"三节——**信息差品（引流入口）→ 咨询筛选品（低价筛人）→ 品牌 IP 品（高价复购）**，每一节功能不同、定价不同、生命周期不同，不能倒装。

## 什么时候用
- 有副业但被同行抄袭、复购上不来时；
- 只有单品爆款、没有产品线时；
- 想从\"信息搬运工\"升级为\"IP\"但不知道怎么过渡时。

## 三节车厢

### 车头｜信息差品（Freemium/低价引流）
- 定义（010 原话）：\"**如果你抄了我的简介、标题、头图、详情页，你卖跟我卖没差别，这就是信息差品**\"。
- 定价：60 元课程降到 39.9 元，或直接免费引流；
- 功能：**降价扩流量**——不是靠它赚钱，是靠它获客；
- 生命周期：**极短**（60 元课程门槛极低），010 案例珠海女孩两个爆品被抄袭到月收从 3-5 万砍到 1 万；
- 好信号：CTR 高、加微信率高；
- 坏信号：抄袭者出现后你还想提价（010 Q3\"信息差品降价当引流入口\"）。

### 车身｜咨询筛选品（199-299）
- 定价：单次 199-299 元；
- 功能（010 原话）：\"**低价 = 大量样本、快速调研**，不是通过咨询本身赚大钱\"；\"产品不是拍脑袋定的，是从用户咨询里长出来的\"；
- 好信号：能问出用户真正的付费点、真实场景、真实预算；
- 坏信号：把咨询当成主收入去卖客单价（会挤掉筛选功能）。

### 车尾｜品牌 IP 品（高价复购）
- 定义：社群、陪跑、私教、高价咨询、线下年费——**\"先靠品牌人设 IP\"**（010 价值链图右端）；
- 定价：3000-30000 元；
- 生命周期：**长**——IP 品牌不可替代、复购持续；
- 好信号：客户主动介绍朋友进；
- 坏信号：一个人如果买了信息差产品都不看，他就不会往下转（010 反例\"我默认我每次看到你想到的是我花了钱白花，我大概率就不会再往下转\"）。

## 判断打分卡

| 检查项 | 是 | 否 |
|---|---|---|
| 我有明确的 60 元引流品？ | 1 | 0 |
| 我有 199-299 的筛选品？ | 1 | 0 |
| 我有 3000+ 的复购/陪跑品？ | 1 | 0 |
| 三节车厢有转化路径（不是三个独立生意）？ | 1 | 0 |
| 我的车厢时间分配是 1-3 / 3-6 / 6-12 月？ | 1 | 0 |

## 打完分怎么用
- 5 分：完整火车头，专注跑量；
- 3-4 分：缺哪节补哪节，别急着提价；
- ≤2 分：还在\"单品爆款\"阶段，先把车头做出来（010 阶段拆解\"1 到 3 个月解决团队、3 到 6 个月解决私域、6 到 12 个月解决线上 IP\"）。

## 常见坑
- **倒装**：一开始就卖 3000 的社群，没有引流车头 → 没人；
- **卡车头**：只有引流品，被抄了就死；
- **两节脱钩**：车头和车尾没有转化路径（用户从 39.9 → 3000 中间没有咨询筛选环节）；
- **误把\"车头收入\"当成主收入**：珠海女孩把信息差品当主业，被抄袭后崩盘。
