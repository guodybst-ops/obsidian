# [框架] 情商三大岗位分工框架

## 一句话
斯斯 010 + 014 反复强调——**大厂里最需要情商的三个岗位是：产品经理 / 商务销售 / 老板助理**。这框架用来判断\"你的情商到底应该往哪个方向卖\"，别把善良和体贴当成情商到处送。

## 什么时候用
- 高敏感 / 高共情 / 讨好型人格找职业方向时；
- 大厂员工判断转岗方向时；
- 想从技术岗转\"能上桌\"的岗位时；
- 014 集\"屁股决定脑袋反着修\"——想升到某个岗位前，先按这个岗位修情商。

## 三大岗位对比

### 岗位 1｜产品经理（PM）
- **核心能力**：**协调资源 + 平衡多方诉求**；
- **情商用法**：\"我不下水但让所有人都下水\"——对开发说话 / 对运营说话 / 对老板说话，是三套话；
- **上升路径**：普通 PM → 高级 PM → 总监 → CPO / VP → 联合创始人；
- 001 集补充：**PM 四步（价值发现 → 价值验证 → 价值创造 → 价值分配）**；
- **危险信号**：只会做需求文档、不会协调人；被开发怼一次就退让。

### 岗位 2｜商务销售 / BD
- **核心能力**：**建立信任 + 谈判成交**；
- **情商用法**：**\"我懂你但我不同意你\"**——共情但不让步；
- **上升路径**：BD → 大客户 KA → 行业负责人 → 事业部总经理；
- 010 补充：**\"取一舍九得一\"**——不见 100 个客户，把重要的 10 个见 10 次；
- **危险信号**：太爱客户 → 变客服；太拿捏客户 → 变骗子。

### 岗位 3｜老板助理 / 秘书 / CoS
- **核心能力**：**读心 + 边界感 + 决策代偿**；
- **情商用法**：**\"我猜到了但我等他说\"**——预判需求但保留主动权在老板；
- **上升路径**：助理 → 特别助理 → CoS（Chief of Staff）→ COO / 联创；
- 014 补充：**\"屁股决定脑袋——我今天想得到某个岗位，最好去修炼关于这个岗位的所有能力\"**；
- **危险信号**：越权 / 情感依赖老板 / 用助理身份代行决策不担责。

## 岗位匹配打分卡（每题 3 选 1）

| 场景 | 选 A | 选 B | 选 C |
|---|---|---|---|
| 老板 5 个诉求打架，你的反应 | 协调开会（PM） | 直接谈单成交（BD） | 帮老板过滤优先级（助理） |
| 陌生人给你难题 | 拆需求（PM） | 谈条件（BD） | 判断该不该给老板（助理） |
| 你最讨厌 | 反复扯皮 | 被拒绝 | 被质疑越权 |
| 你的高光时刻 | 项目上线 | 签单 | 老板一个眼神你懂 |

- **多 A**：PM 系；
- **多 B**：BD 系；
- **多 C**：助理系；
- **均匀**：先按现在岗位补齐短板，再决定转向。

## 打完分怎么用
- 匹配到岗位后，用 **014 屁股决定脑袋反着修**——先按这个岗位的画像修能力、修着装、修说话方式；
- 三个岗位都**天然适合洗金水命**（004）——山林命慎选，除非做\"技术型 PM\"/\"内容型 BD\"这种偏后端的分支；
- 003 圈子分布补充：这三个岗位都是**极端化圈**里的跃迁跳板——从助理跳 COO、从 BD 跳事业部、从 PM 跳联创。

## 常见坑
- **把讨好当情商**：三大岗位都要\"有边界的情商\"——不是好人卡；
- **把冷漠当边界**：三大岗位也不是冰冷执行者——PM 要暖、BD 要热、助理要贴；
- **错位使用**：山林命做 BD 强撑三个月内耗（004 心气不可再生）；
- **忽略岗位差异**：把 PM 情商用在助理岗（越权）、把 BD 情商用在 PM 岗（承诺过多）。

## 附录：三大岗位共同底色

| 共同底色 | 内涵 |
|---|---|
| 对上会\"翻译\" | 把复杂情况翻成老板能听懂的三句话 |
| 对下会\"背锅\" | 用自己名义扛压力、给团队护空间 |
| 对外会\"给面子\" | 不当场戳穿别人、留后路 |
| 对己会\"止损\" | 不牺牲心气（对照 004 / 011 心气不可再生） |
