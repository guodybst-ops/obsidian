# [心法] 贵人不帮弱者，财神不渡怨妇

## 核心原则

> **\"贵人不帮弱者，财神不渡怨妇。\"**（010 单集主题金句原话）

- 贵人只帮\"举重若轻\"的人——你自己已经在跑，他推你一把才有意义；
- 财神只渡\"举一反三\"的人——你自己已经在赚，他给你机会才放大；
- **高能量吸引贵人，怨气排斥财神**；
- **举重若轻的人容易被贵人青睐，抱怨归因外部的人被财神跳过**（010 概念定义原话）；
- 求助 ≠ 弱者——弱者的定义是**心态弱**，不是资源弱。

## 触发场景

- 场景 1：**想找师傅带**——先问自己\"我给他能带来什么\"，再谈他能给你什么；
- 场景 2：**想找投资人**——你已经跑通 30% 完成度（004）之后，投资人才是加速器；
- 场景 3：**求助前**——先做完自己能做的，再求助；
- 场景 4：**抱怨归因外部**——\"老板不行 / 平台不行 / 市场不行\"三连之后没人会救你；
- 场景 5：**卖惨求关注**——短期能博同情、长期贵人和财神绕道。

## 反例警示

- 反例 1：\"我这么惨你怎么不帮我\"→ 010 原话直接反驳，**卖惨排斥贵人**；
- 反例 2：\"我什么都不会但我很努力\"→ 努力不是被帮的理由，**能力才是**（006\"赚钱只跟能力相关\"）；
- 反例 3：\"这不是我的错、这是……\"→ 归因外部第一句就把财神赶走；
- 反例 4：\"我先躺一躺，等贵人来了再起来\"→ 贵人永远只看到已经在跑的人。

## 常见误用

- **当成\"势利眼\"**：不是叫你嫌贫爱富，是叫你**先自渡**；
- **当成\"永远不能求助\"**：可以求助，但要**举重若轻的姿态**求助——\"我在做 X，卡在 Y，能否请你指一个方向\" vs \"我什么都不行你救救我\"；
- **误解为\"必须成功才能求助\"**：不是——**是必须在跑的姿态**才能求助；
- **忽略\"怨妇 vs 抱怨\"的区别**：偶尔抱怨没事、长期怨气才是问题；
- **拿这句去教育别人**：这是**修自己**的心法，不是评判别人的尺子。

## 判据

- 求助前 3 分钟：如果你说的话里\"我 / 我 / 我\"占 80% → 停 → 改成\"我做了什么 + 我卡在哪 + 我能给你带来什么\"；
- 复盘上周找过的人：**你给他带来了什么 vs 他给你带来了什么**——如果只有单向索取超过 3 次 → 关系会断；
- 010 原话判据：**\"你的求助是不是让对方觉得'这个人值得推一把'？\"**

## 判断动作

1. 每次求助前写 3 行草稿：**我做了什么 / 我卡在哪 / 我能贡献什么**；
2. 抱怨的话缩到每天 ≤3 句、且不面向能帮你的人；
3. 每月主动**给别人价值** ≥3 次（帮朋友、写公开笔记、答问）——**先当别人的贵人**；
4. 如果连续 3 个月没有任何主动价值输出 → 就是\"怨妇\"预警。

## 附录：与其他心法的关系

- 004 心气不可再生：怨气就是心气的负流出——两条心法互为因果；
- 011 上升期狼狈奔跑：**\"狼狈但在跑\"就是贵人愿意帮的姿态**；
- 007 用更大世界稀释痛苦：**痛苦被稀释 → 怨气就自动消散**；
- 013 取一舍九得一：**贵人只帮值得的 1，不帮泛泛的 9**。
