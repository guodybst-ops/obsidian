# [心法] 心气不可再生

## 核心原则

> **\"少年心气是不可再生的资源——20 岁不出去闯，30 岁再出去就带不动了。\"**（004 金句 8 原话）

- 心气是**一次性资源**——用完就没有；
- 心气**不能靠休息补回来**——只能靠使用增值（在上升期越用越旺）；
- 心气**只有时间窗口**——20 岁的心气 ≠ 30 岁的心气 ≠ 40 岁的心气；
- **保护心气 > 保护钱**——钱能挣回来、心气挣不回来；
- 011 呼应：**\"新手女宝，上升期就是很狼狈的，千万不要停\"**——心气就是上升期的燃料。

## 触发场景

- 场景 1：**NPD 领导穿小鞋**（002）——想着\"再忍一年攒钱\"→ 忍的成本是心气而不是时间；
- 场景 2：**上升期累到想歇**（011）——一停下来心气就散、再启动比第一次难 10 倍；
- 场景 3：**为面子扛下不该扛的**（002、004）——同事嫉妒 / 老板画饼 / 家人期待，硬扛就是消耗；
- 场景 4：**陷入无意义的社交/恋爱**——情绪价值负值的关系每次都在抽你的心气；
- 场景 5：**做\"看起来该做但不想做\"的事**——违背身体感觉的\"应该\"，每一次都在扣心气。

## 反例警示

- 反例 1：\"我 30 岁再出去闯也可以吧？\"→ 斯斯 004 原话直接反驳：\"**30 岁再出去就带不动了**\"；
- 反例 2：\"我先攒 3 年钱，把心气存起来再用\"→ 心气不是钱，**存不住、还会缩水**；
- 反例 3：\"我上升期太狼狈了、先歇 3 个月\"→ 011 原话\"**上升期就是很狼狈的，千万不要停**\"；
- 反例 4：\"我不喜欢这份工作但收入稳\"→ 用现金流换心气 = 用金子换草，越换越亏。

## 常见误用

- **和\"努力\"混淆**：心气不是喊口号硬撑——山林命硬做洗金水生意就是滥用心气；
- **当作\"情绪高涨\"**：心气是**做事的内驱能量密度**，不是亢奋、也不是打鸡血；
- **当\"运气\"用**：心气可以让你抓住机会，但不能替代能力（006\"赚钱只跟能力相关\"）；
- **透支和保护混淆**：保护心气 ≠ 什么都不做——心气在**做\"值得的事\"时会增值，做\"不值得的事\"时会耗损**；
- **用\"该做\"绑架\"想做\"**：真正的\"想做\"是心气的自然指向，长期违背 → 心气归零。

## 判据（用来判断你今天在增值还是耗损）

- 今天做完事之后你**兴奋 / 想继续** → 增值；
- 今天做完事之后你**累到只想刷手机 / 睡不好** → 耗损；
- 连续 3 周耗损 → **立即撤退**（辞职 / 拒接 / 断关系）；
- 连续 3 周增值 → **加大投入**（哪怕现在还没赚钱）。

## 判断动作

1. 每周日晚上打一次心气分（1-10）；
2. 心气 ≤5 分维持 3 周 → 强制换环境（换公司 / 换圈子 / 换项目）；
3. 心气 ≥7 分维持 3 周 → 加大投入 / all-in 副业方向；
4. 心气**绝对红线**：出现\"我配不上 / 我不行 / 反正我也……\"这类语句 3 次 → 立即找 007 集\"用更大世界稀释痛苦\"介入。
