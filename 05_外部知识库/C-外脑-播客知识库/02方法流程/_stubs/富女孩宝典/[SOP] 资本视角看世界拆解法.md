# 资本视角看世界拆解法

## 一句话

**看一个爆款/项目/公司，不要问"它好不好用"——用资本 4 问（谁买单 / 复购几次 / 毛利多少 / 谁在抽水）把世界的每一件事翻成一张损益表。**

## 什么时候用

- ✅ **看到爆款想模仿**：小红书 / 抖音 / 淘宝爆款项目
- ✅ **看到大 V 想合作 / 加入**：判断对方本质模式
- ✅ **选择加入哪家公司 / 项目**：从员工视角转投资人视角
- **红线**：不适用于纯个人生活消费判断（那用不上此模型）；不适用于极短周期热点（噪音太大）

## 输入

- **目标对象**（产品 / 公司 / IP 项目名）
- **可搜集的 3 类公开信息**：售价 / 用户量级 / 供应链侧
- **1 小时不被打断的时间**

## 输出

- 一份**资本 4 问拆解表**（模板 A）
- **完成信号**：能一句话讲出对方**真实赚钱模式**——不是它对外讲的故事，是它账上的钱

## 主流程

### Step 1：第 1 问——**谁在买单？**

- 找出**真实付费方**（不是用户，是付钱的人）
- 例：抖音的用户是免费用，广告主才是付钱方
- 3 类付费方：C 端个人 / B 端企业 / P 端平台（补贴）
- 思思金句："**你搞错了付费方，你搞错了一切**——用户不等于客户。"
- **判断信号**：能报出至少一个真实付费方名字 / 类型 + 大概金额

### Step 2：第 2 问——**复购几次？**

- 一年内**同一客户会不会再买**？
- 三种模型：
  - 一次性（婚纱照 / 一次性咨询）→ 天花板低
  - 频次型（美甲 / SaaS 订阅）→ 中等
  - 复利型（会员制 / IP 圈子 / 学习平台）→ 高天花板
- 思思金句："**一次性生意做到累死也就那样**——复购才是复利。"
- **判断信号**：能给出**年复购率**估算（0%、30%、80%）

### Step 3：第 3 问——**毛利多少？**

- 售价 - 成本（含流量成本）= 毛利
- **不要**只看售价，流量成本 / 交付成本要算进去
- 3 档：
  - < 20% → 苦力活（除非规模巨大）
  - 20-50% → 正常商业
  - > 50% → **有超额利润**，值得深挖
- **判断信号**：能给出**毛利率区间**估算

### Step 4：第 4 问——**谁在抽水？**

- 沿着钱的走向找出**利润被谁截留**：
  - 平台抽（抖音 / 小红书 / 淘宝抽 20-50%）
  - 房东抽（线下租金）
  - 上游供应链抽（原料 / SaaS）
  - 大 V / KOL 抽（渠道分佣）
- 找到抽水最多的一方——**那才是这条链上最赚钱的位置**
- 思思金句："**不要做卖水人的下游，要做卖铲子的人**——抽水位置比努力更值钱。"
- **判断信号**：能指出这条链上**最大抽水方 + 抽水比例**

### Step 5：反问自己——**我在这张表里能坐哪个位置？**

- 用你的资源看：你能不能进到"抽水位"或"高复购位"或"高毛利位"？
- 三种回答：
  - 能直接进 → 立刻切入
  - 需要 6-12 个月准备 → 走"换脚本"路径进去
  - 完全够不着 → 换一张表拆
- **判断信号**：能给自己填一个具体位置 + 3 个月内下一步动作

## 判断点：值不值得进这门生意

```
付费方模糊 ──────────→ 立刻放弃
复购 < 10% + 毛利 < 20% → 卖苦力，除非有巨大规模优势
复购 > 30% + 毛利 > 40% → 值得深挖
你能进抽水位 ─────────→ 优先切入
你只能站被抽水位 ─────→ 想清楚是否用它做跳板
```

## 模板 A：资本 4 问拆解表

```
━━━━━ 资本 4 问拆解表 ━━━━━

Q1 谁买单：____________________
    付费金额：______ / 单

Q2 复购几次：______ 次 / 年
    复购率：______ %

Q3 毛利：______ %
    大头成本：__________

Q4 谁在抽水：__________
    抽水比例：______ %

【我能坐的位置】
□ 抽水位  □ 高复购位  □ 高毛利位  □ 被抽位
下一步动作（3 个月内）：__________
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 常见坑

- ❌ **把用户当客户** → 你的产品好用没用，付钱的人不满意你就死
- ❌ **只算售价不算流量成本** → 好像 60% 毛利实际 5%
- ❌ **看不见抽水方** → 你以为自己是主角，实际只是给别人抬轿
- ❌ **爆款出现 3 天就想切** → 让子弹飞 30-90 天再看复购率
- ❌ **不问自己在表里坐哪** → 拆完只增长了信息量没变成动作
- ❌ **只拆一次不迭代** → 商业模式 6 个月一变，一张表最多用半年

## 附录：实例（013 集拆"MBTI 心理测评爆款"）

**背景**：2024 年小红书 MBTI 相关内容爆炸。思思现场拆解。

- Q1 谁买单：**主要是 20-30 岁女性 + 婚恋公司 B 端**。C 端 39 元 / 次
- Q2 复购几次：**同一测评复购 < 5%**，但会衍生"星盘 / 塔罗 / MBTI 咨询" → 组合品复购 30%
- Q3 毛利：C 端测评毛利 60%+（0 边际成本）；深度咨询毛利 40%
- Q4 谁在抽水：**小红书流量 + 组合品渠道分佣 30-40%**——**平台是最大抽水方**
- 我能坐哪：思思判断"如果你没内容能力，只能做被抽方；如果你能做深度咨询产品，可以站在**组合品渠道分佣**位——**比平台更靠上**"

**结论**："**爆款好看，但你必须知道自己坐哪一格**——坐错格子就是给别人的复利抬轿。"
