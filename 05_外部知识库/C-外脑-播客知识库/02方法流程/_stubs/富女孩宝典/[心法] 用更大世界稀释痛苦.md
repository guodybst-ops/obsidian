# [心法] 用更大世界稀释痛苦

## 核心原则

> **\"改命的唯一原则，用更大的世界去稀释痛苦。\"**（007 单集主题金句原话）

- 痛苦**不能被消灭**——只能被稀释；
- 稀释的方式**不是想通、不是解决**——是**换更大的容器**（更大的世界、更多的人、更远的视野）；
- **世界越大 → 同一件痛苦的浓度越低**；
- **卡在小世界里 → 想再多也出不来**——原地想 = 原地泡；
- 这是**改命的唯一原则**——不是之一，是唯一。

## 触发场景

- 场景 1：**陷在小情绪里出不来**——反复复盘、反复截图、反复问朋友，都无效；
- 场景 2：**家庭/感情/职场三角关系痛苦**——小圈子内旋，越搅越黑；
- 场景 3：**觉得没救了**——世界观塌方、看什么都灰色；
- 场景 4：**反复咀嚼同一件事**——脑子空转、事情却没变；
- 场景 5：**想通过报复/证明/复仇解决痛苦**——把小世界的痛苦再往小里锁。

## 反例警示

- 反例 1：\"我先解决完这件事再看世界\"→ 007 原话直接反驳，**你解决不了的事只能被稀释**；
- 反例 2：\"我世界够大了、还是痛\"→ 你在\"信息更大\"但**没在\"体验更大\"**——刷抖音不算见世界；
- 反例 3：\"痛苦是宝贵财富\"→ 财富的前提是**被稀释**，浓的痛苦是毒；
- 反例 4：\"我小世界里的问题就得在小世界里解决\"→ **小世界解决不了小世界产生的问题**——只有更大的世界才能解决。

## 常见误用

- **当\"逃避\"用**：不是逃避——是**主动扩容器**；旅行 3 天回来还是原地打转 = 没扩容器；
- **当\"看开\"用**：不是叫你想开、也不是叫你放下——是**换维度重新感受**；
- **误解为\"多刷信息\"**：**信息不等于世界**——大量刷负面新闻只会让世界看起来更压抑；
- **只做一次**：世界扩容是**长期动作**——一次见 1 个大佬不够，是长期结构性调整；
- **忽略身体**：世界扩容必须包含\"身体在场\"（旅行 / 上课 / 见人 / 换城市）——纯脑内世界扩不动。

## 判据

- 你说\"我痛苦\"——问自己：**我这周见的最大的世界是什么？**
- 判据 A：这周有没有见过**你以前没见过的人 / 空间 / 场景**？——没有则容器没扩；
- 判据 B：三个月后回看今天的痛苦，**它的浓度会不会自动降低**？会 → 说明你在扩容器；不会 → 你在原地打转；
- 判据 C：007 原话反问——**\"你的世界够大吗？\"**

## 判断动作

1. 痛苦爆发时，**立即打断当前空间**——出门 / 换城市 / 见新人 3 个（物理换容器）；
2. 每季度做一次**结构性扩容**：一次远途 / 一次陌生行业局 / 一次跨代人对话；
3. 建立\"世界扩容清单\"：**未去过的地方 10 个 / 未见过的人 10 类 / 未尝试的事 10 件**；
4. 痛苦浓度 = 痛苦事件 ÷ 世界容量——**分母做大，分子自动缩小**。

## 附录：与其他心法的关系

- 004 心气不可再生：**心气 = 世界扩容的原动力**——心气死了扩不动；
- 010 贵人不帮弱者：**扩容器过程里就会撞到贵人**——你不出门贵人认不出你；
- 013 取一舍九得一：**世界够大后你才能看清\"哪 9 个可以舍\"**；
- 011 上升期狼狈奔跑：**扩容器的过程本身就是狼狈的**——别嫌不体面。
