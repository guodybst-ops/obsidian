# [框架] 前端流量 vs 后端交付分工框架

## 一句话
一门生意可以拆成\"前端流量\"和\"后端交付\"两个团队——**前端做爆款 + 引流 + IP，后端做产品 + 履约 + 复购**。013 集摄影师案例的原话——**\"卖得更多：前端在小红书做爆款流量，招 2-3 个类似风格摄影师做后端交付\"**——是这条框架的黄金样板。

## 什么时候用
- 单人跑通生意后要\"从 1 到 10\"扩规模时；
- 打工人判断自己所在岗位的分成结构（002 NPD 领导穿小鞋的破解）；
- 团队合伙人分工前的定位；
- 副业招第一个人前想清\"招前端还是招后端\"。

## 两端职能对照

### 前端｜流量 / IP / 内容
- 核心动作：出爆款、涨粉、直播、写文案、加私域；
- 好信号：**\"一个爆款胜似 1000 个日常\"**（013）；
- 坏信号：只有前端没后端 → 用户来了没人接、口碑崩；
- 关键岗位画像：**洗金水命 + BD/PM 情商**（004、010）。

### 后端｜产品 / 履约 / 复购
- 核心动作：做产品 / SOP / 客服 / 售后 / 复购召回；
- 好信号：**换个人也能交付**——SOP 化、可复制（006 金星连锁标准化）；
- 坏信号：只有后端没前端 → 好东西没人买；
- 关键岗位画像：**山林命 + 手艺人 / 深度研发者**（004）。

## 分成结构模型（002 集素材）

002 集斯斯拆分：**打工时你的收入 = 前端分成 + 后端分成**——
- 如果你在前端做爆款、公司只按后端底薪结算 → **你被薅羊毛**；
- 破解：**要求前端流量分成**——按你带来的 UV / GMV 抽点。

## 打分卡（前端 vs 后端匹配自测）

| 观察项 | 你偏前端 | 你偏后端 |
|---|---|---|
| 一场直播 3 小时你的状态 | 亢奋 | 想死 |
| 复杂产品你的动作 | 简化成 3 句金句 | 深挖细节 |
| 别人夸你 | 会讲、有气场 | 靠谱、能兜底 |
| 你受不了 | 天天做重复交付 | 天天见陌生人 |
| 你的分成偏好 | 分成 + 期权 | 保底 + 奖金 |

- **≥4 前端**：走 013 前端路径 —— 主号做 IP + 小号做私域；
- **≥4 后端**：走 013 后端路径 —— 招前端人合伙 / 授权别人做 IP；
- **≥4 混合**：先做前端 3-6 个月建立冷启动，再往后端授权。

## 打完分怎么用

### 你是前端型
- 013 榜样：小红书爆款 → 私域引流 → 后端招摄影师团队；
- 招人顺序：**先招后端履约（客服 + 交付）**，让你能空出手做 IP；
- 分成结构：**前端 IP 拿分成 + 期权**，履约团队拿保底 + 奖金（015 结构）。

### 你是后端型
- 013 榜样：授权 IP 合伙人做前端、你专注做产品/供应链；
- 招人顺序：**先招前端 IP 合伙人（内容 / BD）**；
- 分成结构：**IP 合伙人拿分成、你拿股权 + 分红**——这是 013\"一个爆款胜似 1000 个日常\"的规模化打法。

## 常见坑
- **前后端不分，一个人硬扛**：007 集心气素材呼应——两头都干 → 心气烧完；
- **前端不肯让权**：怕 IP 合伙人跑路 → 结果自己被卡住扩不了；
- **后端不肯让分成**：好前端流失 → 生意就是长不大；
- **分成结构错配**：前端只给底薪 = 002 NPD 老板穿小鞋（把爆款的收益吞了）；
- **两端撕裂**：前端爆款和后端产品调性不一致 → 用户投诉率暴涨。
