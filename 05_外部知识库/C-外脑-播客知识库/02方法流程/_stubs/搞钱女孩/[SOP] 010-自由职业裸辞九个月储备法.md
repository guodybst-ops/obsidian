# [SOP] 自由职业裸辞九个月储备法

## 一句话（≤ 40 字）
裸辞前先备九个月收入和目标。

## 什么时候用

- 想从上班转自由职业。
- 已有副业或信息差生意，但收入不稳定。
- 想给自己一年试错窗口。
- **红线**：不适用于没有任何收入来源验证的人。

## 输入

- 当前月收入和月支出。
- 至少 9 个月收入储备。
- 年度赚钱目标和停手线。

## 输出

- 一张裸辞准备表。
- 一个阶段性自由职业计划。

## 主流程

### Step 1: 算九个月储备

- 用当前月收入或必要支出计算储备线。
- 没达到就不裸辞。

### Step 2: 设年度目标

- 写清今年赚多少就停。
- 目标必须是具体数字。

### Step 3: 降低物欲

- 把生活支出压到能撑过焦虑的水平。
- 避免用消费缓解自由职业不确定性。

### Step 4: 单点服务核心目标

- 一个阶段只服务一件事。
- 自由职业阶段先服务赚钱，不同时追求所有人生目标。

### Step 5: 到点复盘和停手

- 达到目标后复盘状态。
- 不自动把 100 万目标升级成 300 万。

## 判断点 / 决策树

```text
九个月储备线是否达到？
  ├─ 否 → 继续上班或先扩大已验证的副业收入
  └─ 是 → 进入年度目标和停手线复核

副业收入是否已经出现连续正反馈？
  ├─ 否 → 不裸辞，先做小规模验证
  └─ 是 → 可以评估裸辞，但保留回撤方案

年度目标是否已经达到？
  ├─ 是 → 复盘状态并允许停手，不自动加码
  └─ 否 → 继续执行到复盘节点，不用情绪替代数字
```

## 常见坑

- ❌ 只算存款，不算每月真实支出和突发支出。
- ❌ 有九个月储备就默认副业已经成立，忽略收入是否可重复。
- ❌ 把年度目标不断上调，导致阶段性完成永远不算完成。
- ❌ 裸辞后同时追求多个方向，现金流不稳时先保住一个核心收入点。

## 附录：实例

雪姨的自由职业准备不是“想走就走”，而是先按九个月储备线做现金流缓冲，再给当年设一个明确的收入目标。她把阶段性赚钱和长期生活目标拆开处理，达到节点后允许自己停手，而不是被更大的数字继续推着走。
