# [SOP] 分账户强制储蓄法

## 一句话（≤ 40 字）
把收入拆账户，先储蓄再消费。

## 什么时候用

- 收入提高后仍存不下钱。
- 外派、异地或低消费场景中有储蓄窗口。
- 想同时配置活期、定投、保险和长期资金。
- **红线**：不适用于高负债、现金流已断裂的状态。

## 输入

- 月收入和固定支出。
- 目标储蓄率。
- 活期、投资、保险三个账户。

## 输出

- 一张月度分账户表。
- 自动转账或定投规则。
- 一个“先补安全垫 / 再做定投 / 再加长期配置”的优先级判断。

## 主流程

### Step 1: 先划走储蓄

- 工资到账当天先转储蓄账户。
- 不等月底剩多少。
- 第一次执行时先用低比例试跑，例如 10%-20%，确认不影响基本生活后再提高。

### Step 2: 分出长期资金

- 将部分资金放入基金定投、储蓄险或长期账户。
- 这笔钱默认不用于日常消费。
- 如果你不了解投资品，先把长期资金放到低风险现金管理或学习账户，不要因为“长期”就买看不懂的产品。

### Step 3: 留足活期安全垫

- 保留 3-6 个月基本支出的活期。
- 安全垫没满时，不做高风险投资。
- 自由职业、转型期、家庭负担较重的人，把安全垫提高到 6-12 个月。

### Step 4: 配置必要保障

- 先看自己和家庭的基础保险缺口。
- 保障优先级高于炫耀型消费。
- 先保障重大风险，再考虑储蓄型或养老型安排；不要为了“强制储蓄”牺牲现金流。

### Step 5: 每月复盘比例

- 对比目标储蓄率和实际储蓄率。
- 调整消费，而不是取消储蓄。
- 复盘时只问三件事：安全垫够不够、定投有没有中断、保障有没有明显缺口。

## 判断点 / 决策树

1. **现金流已经紧张吗？**
   - 是：先降固定支出和处理债务，不进入定投/长期保险。
   - 否：进入下一步。
2. **活期安全垫够 3-6 个月吗？**
   - 否：所有储蓄优先补安全垫。
   - 是：进入下一步。
3. **家庭极端风险是否有基础保障？**
   - 否：先补基础保险缺口。
   - 是：再考虑定投、长期储蓄或转型自由资金。

## 检查清单

- [ ] 工资到账当天是否自动划走储蓄，而不是月底看剩余。
- [ ] 活期安全垫是否至少覆盖 3 个月基本支出。
- [ ] 投资/保险产品是否能解释清楚，不靠销售话术购买。
- [ ] 每月是否能持续执行，而不是靠某个月的情绪冲动。
- [ ] 是否为转型、旅行、生病、状态不好留出自由资金。

## 常见坑

- **把储蓄等同于抠门**：Jamie 的样本不是不花钱，而是把钱花在高山徒步、旅行、转型等真正重要的体验上。
- **安全垫没满就追高收益**：这会把储蓄系统变成新的风险源。
- **保险替代现金流管理**：保障只能兜底极端风险，不能替代收入、储蓄和技能积累。
- **比例一上来过猛**：强制储蓄要能活下去，先建立稳定性，再追求高储蓄率。

## 附录：实例

Jamie 在印度外派期间，工资一半人民币、一半卢比。因为人民币在当地没有使用场景，她天然获得了“先存下来”的环境：一部分放活期，一部分做基金定投，一部分做储蓄险和家庭保险。这个案例的关键不是“外派才可以存钱”，而是她把收入到账后的路径固定下来，让储蓄先于消费发生。
