# [SOP] 撮合搞钱四步

## 一句话（≤ 40 字）

发现需求、找到对接人、造出双方信任、约定回报。

## 什么时候用

- 你频繁在朋友圈/社群/饭局刷到"我在找 XX"、"有人认识 YY 吗"这类具体需求。
- 你不亲自做产品/服务，但认识（或能找到）两边可能匹配的人。
- 你能承担基础沟通、信任背书和必要的前置协调（如约见、翻译、行程）。
- 你希望以"人对人"而非"产品对市场"的方式赚钱。
- **红线**：不适用于你完全不了解双方资质、涉及重大法律/资金风险、或双方明显信息严重不对等的交易。

## 输入

- 一个明确的需求方（有具体品类、预算、时间窗口）。
- 一个已知供给方，或找到供给方的下一跳线索。
- 你对双方基本可信度的判断依据（认识多久、有没有过合作、有没有可查资料）。
- 你可以投入的前置成本（时间、机票协调、见面安排）。

## 输出

- 一次高质量对接：双方见完面愿意继续谈。
- 一个可复用的撮合记录（模板见下）。
- 一份关键节点的回报约定（抽成、介绍费或未来置换）。

## 主流程

### Step 1: 捕捉具体需求

- 把刷朋友圈、社群、饭局作为主动的信息搜集动作，不是消遣。
- 只登记具体到"谁、要什么、为什么现在要、多少预算"的需求，忽略泛泛的"想合作/想赚钱"。
- 遇到有价值的需求立刻问一句"这个事儿你自己解决到哪一步了？"，判断你有没有插入价值。
- 做完信号：能一句话写出"A 需要 X，因为 Y，预算/期限是 Z"。

### Step 2: 回忆并激活可连接资源

- 从自己去过的地方、认识的人、听过的话里搜"我离这个需求有几跳"。
- 找不到直接供给方时，找"能继续转介绍的人"（下一跳原则）。
- 联系时说清"我在帮 A 找 X，你手上有没有 / 认识谁有？"——不绕弯。
- 做完信号：至少找到 1 个可信、愿意接对方电话的下一跳联系人。

### Step 3: 让需求方交底

- 确认真实预算、时间窗口、必须的门槛、绝对不能接受的风险。
- 反过来诚实告诉需求方你手里线索的成熟度（"我认识的人 A 说他能拿到，但没试过大宗"）——不夸大。
- 建立"我不是骗子中介，我是想帮你解决"的信号。
- 做完信号：需求方愿意告诉你之前没告诉外人的细节。

### Step 4: 制造双方之间的初始信任

- 对双方分别做 5 分钟"背景包装"：讲清对方是谁、为什么值得见、你怎么认识对方、对方近期在忙什么。
- 必要时安排前置动作：定机票、订会议室、准备翻译、发英文材料。
- 见面时你在场做"信任转译器"，见完面第 24 小时内两边各发一条"跟进"消息。
- 做完信号：双方第一次见面前已经知道对方可信在哪里，见面时无需你再解释。

### Step 5: 约定抽成或回报方式

- 在关键价值发生**之前**（一般是签合同前、打款前）把回报讲清：抽成比例 / 一次性介绍费 / 未来置换。
- 只对自己真实创造的连接价值收费，不做"过路收费站"。
- 白纸黑字或至少微信留痕；不接受"事成再说"。
- 做完信号：交易完成后关系不因钱变含糊，双方仍愿意介绍下一单。

## 判断点 / 决策树

| 情况 | 下一步 |
|---|---|
| 需求描述模糊 | 回到 Step 1 继续追问，暂不撮合 |
| 供给方资质不清 | 暂停，不做任何背书，回到 Step 2 换线索 |
| 需求方不肯交底 | 说明信任没建立，回到 Step 3 |
| 双方都可信但不认识 | 进入 Step 4 做信任转译 |
| 对接价值明显很大（>10 万级） | 提前进入 Step 5 白纸黑字定回报 |
| 事后需求方赖账 | 记入黑名单，不再撮合，也不为其做背书 |

## 模板 / 清单 / 打分卡

**撮合记录表**（每单一行）：

| 需求方 | 具体需求 | 供给线索/下一跳 | 双方可信证据 | 我创造的价值（信息/信任/协调） | 前置成本 | 回报约定 | 状态 |
|---|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |  |

**撮合前 5 问自检**：

- [ ] 我能一句话写出需求方要什么、为什么现在要？
- [ ] 供给方资质我至少有 1 个第三方佐证？
- [ ] 我是否已在事情发生**前**说清了回报方式？
- [ ] 如果这单出问题，双方会不会来找我兜底？我兜得起吗？
- [ ] 这单是我可以复用能力的，还是一次性运气？

## 常见坑

- ❌ 不要只介绍微信就当撮合完成——真正难的、也是唯一值钱的是"造出双方信任"。
- ❌ 不要为大单夸大自己手里的资源，一旦信任破产，后续所有单子都没了。
- ❌ 不要在价值发生之后才谈钱，那时候你已经没有筹码。
- ❌ 不要撮合你搞不清楚合规风险的交易（灰产、擦边、跨境资金），撮合不等于甩锅。
- ❌ 不要把"人脉"当唯一资源却不打理——不定期给两边发有价值的信息，人脉会自然衰减。

## 附录：实例

赵大晴（016 集）撮合印尼稀有矿一案：

1. **Step 1 捕捉需求**：她在朋友圈刷到上海朋友说"家里企业需要某种产自印尼的稀有矿产，这东西非常难找"。
2. **Step 2 回忆资源**：她想起自己去过印尼、听人提过当地矿产的人。
3. **Step 3 让需求方交底**：她跟上海朋友确认了具体品类、需要的量、可以接受的价格区间。
4. **Step 4 造信任**：她联系印尼的朋友、安排对方来中国的机票、亲自到场撮合见面，做双方之间的"信任转译器"。
5. **Step 5 回报约定**：跑成一笔大生意（原文未披露分成细节，但明确是"抽成"模式）。

**关键复盘**：她不拥有矿、不懂矿业，能拿到这笔钱靠的是"发现需求 + 认识两边 + 造出信任"这三步，而不是任何专业知识。她自评"我关注人远远大于关注事情"。
