# [框架] 婚前买房五因子判据

## 一句话（≤ 40 字）

用五个因子判断眼前这套房该不该买、能不能买。

## 什么时候用

- 30 岁左右，还没有第一套房，家里加自己能凑到几百万首付。
- 已经有一套房，想再买第二套投资房，纠结核心 vs 边缘。
- 单身或婚前女性想建立独立资产底盘。
- 已有三四五套，考虑房产在总资产的合理占比。
- **红线**：不适用于择时（"下半年是不是好时机"）；不适用于高杠杆冲动买房。

## 评估对象

- **一次具体的买房决策**——落到"这套房 / 这个楼盘 / 这个户型"的颗粒度，而不是"这座城市"。
- 尤其适合一线/强二线城市核心区、可出租、易流通的小户型。

## 维度定义

### 维度 1：区位——核心区还是边缘区

**一句话操作定义**：不看行政市级，只看在这座城市的核心/边缘位置。

| ✅ 好信号 | ❌ 坏信号 |
|---|---|
| 属于本市"核心城区"（如北京的海淀西城朝阳、上海的内环） | 远郊，产业/人口支撑弱 |
| 教育、医疗、地铁密度高 | 学区不吃、医院远、通勤 90 分钟+ |
| 出租需求稳定，租金能覆盖 40%+ 月供 | 有房难租，或租金极低 |
| 二手成交周期 3 个月内 | 挂牌半年无人问 |

→ **怎么观察**：链家/贝壳看该楼盘近 6 个月成交套数与周期；核心 vs 边缘参考"清北录取率"这类硬指标（海淀西城 vs 密云 ≈ 密云不如长沙天心区）。

### 维度 2：年龄阶段——是否需要第一块中产砖

**一句话操作定义**：是否处在"这套房会捆绑婚育/教育/身份权利"的窗口。

| ✅ 好信号 | ❌ 坏信号 |
|---|---|
| 30 岁前后，未来 3-5 年生活仍在这座城市 | 短期内确定离开这座城市 |
| 婚育、孩子上学等需求可能出现 | 只把房当纯投机资产 |
| 无房家庭，第一套 | 已有多套且已过婚育窗口 |

→ **怎么观察**：问自己"未来 5 年我大概率还会在这座城市生活吗"、"我不买房会不会因为户口/学区而错过某项权利"。

### 维度 3：房产数量——第一套还是叠加投资

**一句话操作定义**：这套是家庭第几套房，决定它是"必需品"还是"叠加投资"。

| ✅ 好信号 | ❌ 坏信号 |
|---|---|
| 家庭第一套，自住兼底盘 | 已有 3-4 套，仍继续重仓房产 |
| 小户型、总价可控、易变现 | 大平层/大别墅、低流动性 |
| 与现有房产在城市/区位上有分散 | 全部集中在同一城市、同一板块 |

→ **怎么观察**：先列出家庭所有房产的城市、区位、总价、贷款余额，再看这套是"补短板"还是"叠仓位"。

### 维度 4：总资产占比——是否过度压仓

**一句话操作定义**：买完这套后房产在家庭总资产中的比例。

| ✅ 好信号 | ❌ 坏信号 |
|---|---|
| 房产占比 ≤ 50%，首付后仍有 6-12 个月安全垫 | 房产占比 > 70%，杠杆打满、现金流紧绷 |
| 有其他流动资产（股票、基金、现金）分散 | 家庭资产几乎全压在房子上 |
| 女性买家：稳健资产占比 20-30% | 女性买家：稳健资产 < 10% |

→ **怎么观察**：模拟"买完这套 → 未来 12 个月现金流是否覆盖房贷+生活"，并把安全资产占比拉到女性 20-30% / 男性 10-20%。

### 维度 5：工作稳定性——现金流能否抗波动

**一句话操作定义**：如果收入下降 30%，能否继续还贷 12 个月。

| ✅ 好信号 | ❌ 坏信号 |
|---|---|
| 自己或伴侣一方在体制内/头部企业稳定 | 双方都在高波动行业（自媒体/创业/中介） |
| 有家庭/父母可提供 6 个月兜底 | 完全无外部现金流兜底 |
| 有副业/第二收入线 | 单一收入且已裁员风险信号明显 |

→ **怎么观察**：做一次"收入下降 30% 情景推演"，看还贷+基本生活是否仍能覆盖 12 个月。

## 打分卡 / 分级表

| 因子 | 权重 | 得分 (1-5) | 证据 | 风险备注 |
|---|---:|---:|---|---|
| 区位 | 30% |  |  |  |
| 年龄阶段 | 20% |  |  |  |
| 房产数量 | 15% |  |  |  |
| 总资产占比 | 20% |  |  |  |
| 工作稳定性 | 15% |  |  |  |
| **加权综合** | 100% |  |  |  |

**分级结论**：

- **A 级（加权 ≥ 4.0，且区位与工作稳定性均 ≥ 4）**：尽量买，优先核心区小户型。
- **B 级（加权 3.0–3.9）**：可以买，但降低预算/面积、优先流动性。
- **C 级（加权 2.0–2.9）**：暂缓，先补短板（先攒现金流 / 换城市 / 等换工作稳定）。
- **D 级（加权 < 2.0，或工作稳定性 ≤ 2）**：别买，先扭转财务/职业状况。

## 打完分怎么用（决策后果）

- **A 级**：立刻进入选盘阶段，重点看核心区、稍小、可出租、流动性高的具体房源。
- **B 级**：先降 30% 预算或改地段，宁可小一点也不要边缘低流动性。可参考 [[02方法流程/_stubs/搞钱女孩/[SOP] 016-撮合搞钱四步|撮合搞钱四步]] 之类的收入扩张方法先增加缓冲。
- **C 级**：暂停买房，把精力放在"人力资本"上（见 [[03概念链接/_stubs/搞钱女孩/[概念] 017-人力资本|人力资本]]），先把工作稳定性和现金流拉到 4 分以上再回来重估。
- **D 级**：这次不要买；如果被家人/伴侣催促，用这张打分表当"劝退证据"。

## 常见坑

- ❌ 不要只按行政城市判断——"密云的北京"和"朝阳的北京"根本不是同一种资产。
- ❌ 不要把刚需房完全当投资品（会因为择时纠结拖过窗口）；也不要把投资房当情绪安全感（会牺牲收益率）。
- ❌ 不要为了面积牺牲流动性——第一套更看重"可出租、可转手"。
- ❌ 不要用杠杆打满买房——女性尤其要保 20-30% 安全资产。
- ❌ 不要指望这个框架回答"下半年是不是好时机"，框架给的是"该不该 / 挑哪套"，不是择时。

## 附录：实例

**A 级案例**（017 集香帅原型）：30 岁北京上班族、无房、家里加自己能凑到两三百万——

- 区位 4 分（选朝阳/海淀边界的小区）
- 年龄阶段 5 分（正处于婚育窗口）
- 房产数量 5 分（第一套自住兼底盘）
- 总资产占比 4 分（首付后现金流仍有 12 个月）
- 工作稳定性 3 分（互联网大厂但有裁员波动）

加权 ≈ 4.2 → **A 级：尽量买**。挑核心区、稍小、可出租、流动性高的房源。理由不是收益率，而是"你并没有左边一个好选择、右边一个更好选择"——不买房把 200 万拿去买股票，可能变 400 万也可能没了，且你还是没房；房产捆绑婚育/教育/身份等大量看不见的权利。

**C 级反例**：已经有 3 套郊区投资房、家庭房产占比 80%、女性买家稳健资产不到 10%——

- 区位 2 分（都在远郊）
- 年龄阶段 3 分
- 房产数量 1 分（已过度）
- 总资产占比 1 分
- 工作稳定性 3 分

加权 ≈ 2.0 → **C 级：暂缓**。先减仓、再重新配置国际/持续现金流资产，不叠第 4 套。
