# [SOP] 030-27岁负债百万，35岁提前退休行动框架

## 一句话

先接受现实，再区分能决定和不能决定的事；把财务自由、时间自由和工作/事业分开算，最后把目标反推成够得着的下一步。

## 什么时候用

- 你背着债务或现金流压力，想翻身但不知道先从哪一步下手。
- 你想提早退出高消耗工作，开始半退休或半自由职业状态。
- 你面前有一份赚钱机会，但你不确定它到底算工作、事业还是短期现金流。
- 你需要把“我想自由”落成一个可以执行的目标。
- **红线**：不适用于纯情绪宣泄或完全没有现实账本的空想。

## 输入

- 当前负债、月固定支出、月可变支出、当前收入。
- 可支配时间、精力、家庭责任。
- 现有工作和事业分别占多少时间。
- 你想要的生活方式和退休水位。
- 当前能做的赚钱动作，以及你真正的能力圈。

## 输出

- 一个够得着的目标。
- 一张工作 / 事业 / 自由时间配置表。
- 一个 3 个月到 6 个月的现金流安全垫目标。
- 一条是否下场的决策路径。

## 主流程

### Step 1: 先写现实账

- 列出债务、每月固定支出、可变支出、当前收入、家庭支出。
- 把“我觉得我需要很多钱”改写成具体数字。
- 先回答一句话：如果我保持当前状态，还能撑多久。

### Step 2: 区分能决定和不能决定

- 不能决定：过去爆仓、离婚、外部市场、已经发生的损失。
- 能决定：之后做什么、每天时间怎么配、收入从哪里来。
- 完成信号：每个麻烦都能被放进“不能改”和“能改”两个篮子里。

### Step 3: 把目标从“想自由”改写成“够得着”

- 财务自由不是无限大数字，而是能覆盖生活方式的安全线。
- 时间自由不是躺平，而是把时间配置权拿回来。
- 先定 3 个月 / 1 年 / 3 年三档目标。
- 完成信号：目标小到 30 天内就能开始做第一步。

### Step 4: 把钱和时间分开算

- 财务自由 = 资产或现金流覆盖支出。
- 时间自由 = 每周有多少时间真正属于自己。
- 如果钱多但时间全被吞掉，不叫自由。
- 完成信号：你能分别说清两条线。

### Step 5: 把工作和事业分开

- 工作：为了赚钱，不一定喜欢。
- 事业：出于内在动力，赚钱可有可无。
- 先问自己：现在这件事到底是现金流工具，还是事业主线。
- 完成信号：每件事都能被归类。

### Step 6: 设定时间与精力配置

- 把最贵的时间留给高杠杆事情。
- 把低价值但必须做的事情压到最短。
- 用“事业 5 小时 + 生活 / 学习 / 关系”去观察当前分配。
- 完成信号：你知道每周时间花在哪。

### Step 7: 面对新机会先问 3 个问题

- 这件事在我的能力圈里吗。
- 它是在帮我接近自由，还是在消耗自由。
- 我能不能在不伤主目标的前提下试错。
- 完成信号：不是“看着能赚”就上。

### Step 8: 决定要不要下场

- 认知清楚 + 能力圈内 + 有现金流缓冲 = 可以下场。
- 目标不清 + 能力圈外 + 会吞掉主目标 = 不下场。
- 介于中间 = 小额试错。
- 完成信号：能给出明确 yes / no / 先试。

## 判断树

```text
能说清我为什么想做吗？
  ├─ 能 → 继续看能力圈和现金流
  └─ 不能 → 先别下场，先把目标说清
```

```text
这件事在能力圈内吗？
  ├─ 是 → 看现金流和时间配置
  └─ 不是 → 先小额试错或放弃
```

```text
它会吞掉我的自由吗？
  ├─ 会 → 不下场 / 只试错
  └─ 不会 → 可以推进
```

## 常见坑

- 把“想自由”写成一个永远够不到的大数。
- 把工作和事业混成一条线。
- 只算钱，不算时间。
- 先焦虑后行动。
- 把过去的失败当成未来的判决。

## 附录: 原话与翻译

- “工作 vs 事业” -> 工资工具 vs 内在驱动。
- “财富自由 vs 时间自由” -> 钱是工具，自由是目标。
- “先接受现实” -> 不跟已经发生的事争辩。
- “够得着的目标” -> 让下一步真的能做出来。
