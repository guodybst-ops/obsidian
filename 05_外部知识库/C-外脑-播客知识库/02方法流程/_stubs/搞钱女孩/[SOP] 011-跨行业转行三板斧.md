# [SOP] 跨行业转行三板斧

## 一句话（≤ 40 字）
先访谈，再找内推，最后迭代简历。

## 什么时候用

- 想从一个行业跳到完全不同的行业。
- 现有履历和目标岗位看起来“不相关”。
- 已经知道目标行业大方向，但不知道怎么证明自己能进。
- **红线**：不适用于连目标行业都没圈定的阶段。

## 输入

- 目标行业或目标岗位清单。
- 10 个可访谈对象候选。
- 现有简历、项目经历、可迁移能力列表。

## 输出

- 一张行业岗位信息表。
- 一份可投递简历。
- 一批可请求内推或介绍的弱连接。

## 主流程

### Step 1: 访谈目标行业的人

- 找 5-10 个目标行业从业者，问“这个岗位每天在做什么”。
- 把自己做过的事列出来，请对方判断哪些经历可迁移。
- 做完信号：能写出目标岗位的 3 个真实日常任务。

### Step 2: 激活弱连接

- 从学长学姐、前同事、LinkedIn、小红书等渠道找可介绍的人。
- 请求具体帮助：内推、信息访谈、帮忙看简历，不泛泛说“求建议”。
- 做完信号：至少拿到 3 条有效反馈或 1 次内推机会。

### Step 3: 重写能力叙事

- 把旧行业经历翻译成目标行业能懂的语言。
- 每条经历都写“动作 + 结果 + 与目标岗位的关系”。
- 做完信号：陌生人能在 30 秒内看懂你为什么能转过去。

### Step 4: 迭代 20-40 版简历

- 每投一轮，根据反馈改一版。
- 把无回应、面试追问、被认可的点都记录下来。
- 做完信号：简历里不再出现只对原行业有意义的黑话。

### Step 5: 用面试继续校准

- 面试中继续收集“目标行业到底在乎什么”。
- 如果连续 3 次卡在同一问题，回到 Step 3 重写叙事。
- 做完信号：能稳定讲清转行理由与可迁移能力。

## 判断点 / 决策树

| 情况 | 下一步 |
|---|---|
| 不知道岗位日常 | 回到 Step 1 继续访谈 |
| 有岗位认知但没人推荐 | 回到 Step 2 扩大弱连接 |
| 有面试但讲不清自己 | 回到 Step 3 重写能力叙事 |
| 简历无回应 | 回到 Step 4 做版本迭代 |

## 模板 / 清单 / 打分卡

| 目标岗位 | 访谈对象 | 岗位日常任务 | 我的可迁移经历 | 简历改法 | 后续动作 |
|---|---|---|---|---|---|
|  |  |  |  |  |  |

## 常见坑

- 不要只投简历不访谈，跨行业最大缺口通常是语言体系不同。
- 不要把原行业头衔当优势，先翻译成目标岗位要的能力。
- 不要泛泛求建议，弱连接更愿意回应具体请求。
- 不要投 3 版没结果就判断自己不行，转行需要版本迭代。

## 附录：实例

林蜀黍从 IBM IT 管培生转到综艺创业公司。她先找不同行业的人聊岗位日常，再通过学长学姐和 LinkedIn 激活 network，最后把简历和 cover letter 改了 40 多版，才拿到文娱行业 offer。
