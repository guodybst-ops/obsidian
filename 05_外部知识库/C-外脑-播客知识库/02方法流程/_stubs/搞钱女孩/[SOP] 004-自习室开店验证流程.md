# [SOP] 自习室开店验证流程

## 一句话（≤ 40 字）
用需求和算账验证自习室能不能开。

## 什么时候用

- 想开自习室或自助空间。
- 已观察到稳定排队、学习、备考需求。
- 需要判断“喜欢”是不是“需求”。
- **红线**：不适用于只因自己喜欢书店/空间而开店。

## 输入

- 目标城市和商圈。
- 房租、人力、座位数、价格。
- 竞品与潜在用户观察。

## 输出

- 一张开店测算表。
- 一个是否开店的决策。
- 一个“不开 / 小店试跑 / 扩店复制”的下一步动作。

## 主流程

### Step 1: 观察真实痛点

- 找到稳定出现的备考、自习、安静空间需求。
- 不以个人喜好替代需求。
- 记录痛点出现的时间、频率、用户画像和替代方案。例如：学生是否每天来、为什么在家学不进去、愿意为氛围付多少钱。

### Step 2: 做城际和竞品调研

- 看同城和外地成熟店的价格、座位、营业时段。
- 记录人流和满座时段。
- 至少拆 3 类信息：选址逻辑、成本结构、会员价格。只看装修风格不算调研。

### Step 3: 建收入成本模型

- 算房租、人力、装修、座位数和满座率。
- 做保守、中性、乐观三档。
- 必须算最大亏损承受度：这笔钱全亏完，你是否还能生活和继续试错。

### Step 4: 小步开出第一家

- 先开可控规模，不一开始重资产。
- 先用老客、地推和线上渠道验证。
- 第一家店要验证“选址 + 定价 + 用户转化 + 运营方式”，不要一开店就卖加盟梦。

### Step 5: 根据数据提价或复制

- 如果满座和复购稳定，测试提价。
- 没跑通前不谈加盟和连锁。
- 复制前先确认 SOP 能离开创始人本人运转：客服、门禁、座位、清洁、售后、续费都要有规则。

## 判断点 / 决策树

1. **有没有明确需求？**
   - 只有“我喜欢书店/空间”：不开。
   - 有稳定备考、自习、安静空间需求：进入调研。
2. **最大亏损能承受吗？**
   - 不能承受：不开，或缩小规模。
   - 能承受：进入试跑。
3. **第一家店数据是否跑通？**
   - 满座、复购、续费、转介绍稳定：可测试提价或复制。
   - 只能靠创始人硬撑：先修运营，不复制。
4. **是否能少雇人或远程管理？**
   - 不能：重新核算人力和管理成本。
   - 能：进入半无人/无人模型设计。

## 常见坑

- **把喜欢误当需求**：书店、咖啡、空间审美都可能只是创始人情怀，不等于用户愿意持续付费。
- **不算最大亏损**：只算赚钱不算赔钱，就无法判断自己是否真的能开。
- **开店后等客上门**：自习室也需要引流、转化、续费和本地运营。
- **没跑通就复制**：第一家店数据不稳时，扩张只会放大亏损。
- **追求零风险**：实体创业没有零风险，只能把风险算清楚、控在能承受范围内。

## 附录：实例

楠姐先在书店里看到考研学生每天早上排队，再去郑州、西安逐家调研自习室，记录选址、户型、布局、设备、成本、客单价和投资回报率。回到本地后，她给自己 3 天判断最大亏损是否能接受，一个月内开出第一家店，再把书店老会员转化成自习室种子用户。这个案例的关键动作是：先看到真实需求，再算账，再小步开店。
