# [框架] 选项目 82 开

## 一句话（≤ 40 字）

八成看自己擅长什么，两成看外部环境。

## 什么时候用

- 想从上班迁移到自由职业或副业。
- 手里有多个项目机会，不知道哪个该先做。
- 担心自己只是在追风口，或者担心自己错过风口。
- 想验证一门"年入百十来万"的小生意值不值得下水。
- **红线**：不适用于完全没有基本技能沉淀的从零创业（这时候先补技能，不要选项目）；也不适用于必须靠"融资讲故事"才能启动的大规模创业（那需要另一套框架）。

## 评估对象

- **一个具体的副业 / 自由职业项目 / 小生意**——落到"这个品牌 / 这个方向 / 这个客户"的颗粒度。
- 规模目标定位在"年入百十来万"的小生意，而非"敲钟型"大创业。

## 维度定义

### 维度 1：擅长度——我做这件事是否顺手 (权重 40%)

**一句话操作定义**：这件事是否命中我过去反复被验证的长板。

| ✅ 好信号 | ❌ 坏信号 |
|---|---|
| 过去工作里反复被验证的能力 | 只是听说这个赛道赚钱 |
| 做起来消耗低、表达自然 | 需要长期伪装或说不认同的话 |
| 3-5 个朋友都夸我这方面强 | 只有我自己觉得强 |

→ **怎么观察**：问 3-5 个共事过的朋友"你觉得我最擅长什么"，重合的答案就是长板。

### 维度 2：不可替代价值——我在这个项目里的独有筹码 (权重 20%)

**一句话操作定义**：在这个项目里，我有什么部分是别人难以外包的。

| ✅ 好信号 | ❌ 坏信号 |
|---|---|
| 有沉淀多年的客户、人脉、表达、判断 | 谁都能做，只能拼低价 |
| 离开原公司/平台仍能带走 | 完全依赖原公司光环 |
| 有 portable 的能力 | 只有一项薄薄的技能 |

→ **怎么观察**：写出你在项目里"不能被外包"的那一环——如果写不出，说明可替代性太高。

### 维度 3：自身需求——我自己是不是真的会用 (权重 15%)

**一句话操作定义**：这个产品/服务，我自己现在有没有在花钱花时间。

| ✅ 好信号 | ❌ 坏信号 |
|---|---|
| 自己每天/每周都会用 / 会买 | 只是"觉得别人会买" |
| 能持续产生真实体验和反馈 | 只有商业想象，没有生活连接 |
| 我就是我最好的第一批用户 | 我自己都不用 |

→ **怎么观察**：翻你过去 90 天的消费记录，看这个品类你花了多少钱、多少时间。

### 维度 4：周围需求——身边人是否也有类似需求 (权重 15%)

**一句话操作定义**：从"我一个人有需求"扩展到"我这个圈层的人普遍有需求"。

| ✅ 好信号 | ❌ 坏信号 |
|---|---|
| 身边不同人群都出现同类需求 | 只有你一个人喜欢 |
| 需求不是一次性尝鲜 | 只是一阵热闹 |
| 你能想到 3 个不同职业的人都会买 | 只有你这一个圈层会买 |

→ **怎么观察**：问周围 10 个不同职业/年龄的人是否已经在为类似东西付费。

### 维度 5：外部趋势——是否明显和大趋势相悖 (权重 10%)

**一句话操作定义**：不追最热，但也不逆行。

| ✅ 好信号 | ❌ 坏信号 |
|---|---|
| 高频、刚需、长期消耗 | 明显逆产业趋势（如现在做汽油车） |
| 中等规模足以支撑年入百来万 | 只能靠宏大故事融资才能活 |
| 中国大市场至少养得起 | 只能靠海外市场且政治风险高 |

→ **怎么观察**：判断的重点是"这个方向是不是明显不该做"，而不是"是不是最热"——只要没和大趋势相悖就够了。

## 打分卡 / 分级表

| 维度 | 权重 | 得分 (1-5) | 证据 | 备注 |
|---|---:|---:|---|---|
| 擅长度 | 40% |  |  |  |
| 不可替代价值 | 20% |  |  |  |
| 自身需求 | 15% |  |  |  |
| 周围需求 | 15% |  |  |  |
| 外部趋势 | 10% |  |  |  |
| **加权综合** | 100% |  |  |  |

**分级结论**：

- **做（加权 ≥ 4.0 且擅长度 ≥ 4）**：立刻小规模下水，用"损失可承受"的一笔钱做出第一版产品/交付。
- **小试（加权 3.0–3.9）**：做一个最小验证——比如三五杯的做法是"先做一款礼盒，给周边人送一送，不合适当伴手礼送掉"。
- **暂缓（加权 2.0–2.9）**：先回去补短板；如果擅长度低但趋势高，属于典型"追风口陷阱"，尤其要克制。
- **不做（加权 < 2.0 或 擅长度 ≤ 2）**：把这个机会让出去，即便它看起来很赚钱——"人挣不了认知以外的钱"。

## 打完分怎么用（决策后果）

- **做**：进入下一步——用可承受损失的一笔钱去试，参考 [心法] 开始做比想更重要（stub 候选）。
- **小试**：定义"最坏情况"——比如三五杯的"最坏就是把货送掉当伴手礼"——只要最坏情况可承受，就下水。
- **暂缓**：不做的原因写下来，避免以后又冲动进入；同时列出"要做的话我先要补什么能力"，回到长板建设。
- **不做**：明确告诉自己"这是我认知以外的钱"，平静让出，去做自己的赛道。

## 常见坑

- ❌ 不要用"这个风口赚钱"替代"我在里面有什么价值"——归因偏差最容易发生在这里。
- ❌ 不要把自由职业当逃避上班——中心词仍然是职业（见 [[03概念链接/_stubs/搞钱女孩/[概念] 018-自由职业中心词是职业|自由职业中心词是职业]]）。
- ❌ 不要把"朋友都喜欢"当成大市场验证——先分清小生意和大创业。
- ❌ 不要跳过"自身需求"直接进入——如果你自己都不用，你不知道产品好坏。
- ❌ 不要长时间前期筹谋——超哥的原话是"开始做比想更重要"，因为合伙人关系和实际执行差距只有下水才能量化。

## 附录：实例

**018 集三五杯茶的 82 开推演**（超哥原型）：

- **擅长度 5 分**：做茶的本质是"表达和传播"——把已有产品用新方式传达给年轻人，正好是她的长板（表达）。
- **不可替代价值 4 分**：她自己 + 刘飞（三五环）+ 乐克（金云赫兹）三人的播客受众和内容能力，别人短期难复制。
- **自身需求 5 分**：她自己每天从咖啡转向喝茶，是第一批用户。
- **周围需求 4 分**：身边不同年龄段朋友也开始喝袋泡茶，不是一次性尝鲜。
- **外部趋势 3 分**：新消费遇冷，但茶是刚需 + 高频消耗品；中国符号产品在崛起；至少没有明显逆行。

加权 ≈ 4.4 → **做**。

实际操作也印证了"小规模下水"逻辑——2022 疫情逆势开张，第一批产品刚上线就赶上上海封城，最终"没亏、微微盈利"。她坦白："这里可能有归因偏差——因为我想做这个决定，所以我觉得它 make sense。但真正推动我的是第一重：我更擅长什么。"

**反例（追风口陷阱）**：她观察到"别人聊哪个赛道挣钱我就跃跃欲试"是她过去踩过的坑——比如说自己"不认同的话"型内容/带货，尽管有钱途，她的擅长度 = 2 → **不做**。
