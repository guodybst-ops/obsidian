# [SOP] 分手拖延两周法则

## 一句话（≤ 40 字）
从有分手念头到跟对方第一次分手谈话，控制在两周以内。

## 什么时候用（触发条件）

- 你已经在心里出现"是不是该分手了"的具体念头（不是气头上一闪念，而是隔了几天仍然浮现）
- 你和对方之间**已经没有倾诉欲**、想到聊天场景先感到疲惫
- 你反复用"再看看"、"等他改改"、"再撑一撑"给自己延期
- **红线**：不适用于处于自伤/自杀边缘或有暴力威胁的关系——这类场景要优先向专业机构求助

## 输入

- 一支笔和一份可以随时打开的备忘录（手机 memo 即可）
- 一个可以说话的朋友（不是对方，也不是共同朋友）
- 明确的日历截止日：出现念头的当天 + 14 天

## 输出

- 一段"最激烈时刻的情绪备忘录"（一份可以在犹豫时反复读的自我支持文本）
- 一次已发生的、面对面的分手谈话（而不是"我在心里已经分了"）
- 完成信号：你已经和对方**当面**说出"我们分手吧"这句话，无论对方接受与否

## 主流程

### Step 1：识别念头（Day 0）

- 出现"是不是该分手了"的具体念头时，**在备忘录里写下今天日期 + 一句话触发原因**
- 判断：这个念头是"一次吵架后的情绪反应"还是"最近两周反复浮现的判断"？
  - 前者 → 先等 3 天冷静观察
  - 后者 → 立刻走 Step 2

### Step 2：写情绪备忘录（Day 0-3）

- 在情绪**最激烈、最确定要分手**的那一刻，把你的感受完整写下来
- 内容要具体：为什么这一刻想分？他做/没做什么？你身体的反应是什么？
- 备忘录的作用：**分手期没人支持你，只能自己支持自己；人会遗忘"最想分手那一刻"，所以留一份陪自己走完流程的文本**
- 完成信号：文档 ≥ 300 字，写完能让你觉得"我不是无理取闹"

### Step 3：定谈话截止日（Day 3-5）

- 在日历上标记"Day 14"作为第一次分手谈话的最晚截止日
- 提前和一个可以互当垃圾桶的朋友预告："我会在下周三之前和 XXX 谈"——把 deadline 外部化

### Step 4：约谈话（Day 7-14）

- 约一个**当面**的场合（不是微信、不是电话）
- 说明清楚这次见面的性质："我想和你严肃聊一件事"，不要伪装成普通约会
- 谈话前最后一次读一遍你的情绪备忘录

### Step 5：真的谈（≤ Day 14）

- 谈话时把"我想分手"作为**开头**说出来，而不是铺垫半小时最后不敢开口
- 允许对方情绪反应，但**不承诺"再试一试"**——你已经做过 14 天的自我校验
- 如果对方要求"再给我一次机会"，看情绪备忘录里那些具体理由是否还成立

## 判断点

```
Day 0 出现念头
  是气头上一闪念 → 等 3 天再判断
  是反复浮现 → 立刻写情绪备忘录

Day 14 未谈话
  仍然想分 → 立刻约谈话（不允许再拖）
  已经不想分 → 回头看备忘录里的理由是否真的消解了；如果只是"习惯了、不想麻烦"，不算真的消解
```

## 模板 / 清单 / 打分卡（情绪备忘录模板）

```
日期：
最想分手的这一刻，我的感受是：
触发事件（具体到 5 分钟前 / 今天 / 这周发生了什么）：
身体反应（胸口紧 / 想哭 / 麻木）：
如果继续和他在一起 1 年后：
如果不和他在一起 1 年后：
不能告诉他的一个真心话：
```

## 附录：实例

当一个人连续两周反复出现“是不是该分手了”的念头，却一直用“再看看”拖延，可以在 Day 0 记录触发原因，随后完成情绪备忘录，并在 Day 14 前完成一次当面谈话。这个例子的完成标准不是对方是否同意，而是自己是否真正把判断说出口。

## 常见坑

- ❌ 拖过两周会自动拖到 3-6 个月（同"离职念头 / 做小红书念头"是同构的心理机制）
- ❌ 用"要不要跟他讲清楚"当作拖延借口——分手谈话本身就是"讲清楚"
- ❌ 只在微信上分——对方随时可以撤回情绪，你也随时可能被劝回
- ❌ 把情绪备忘录写成"分析他"——重点是记录**你自己**的感受，不是审判他

## 附录：源头

出自《搞钱女孩》028 集，Blake 在做视频选题时读到《如何防止相守终老》，最受启发的一点："**很多人在拖延分手这件事情上浪费了太多的时间**"。他把它与"离职念头拖 3 个月半年"是同构的心理机制识别为同一件事。
