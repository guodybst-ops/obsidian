# [框架] 027-三条腿收入结构

## 一句话（≤ 40 字）

评估个人年收入是否稳固：兜底 + 探索 + 沉淀，三条腿缺一都不稳。

## 什么时候用

- 你在思考"要不要辞职 / 要不要单靠副业 / 要不要 all in 一件事"。
- 你已经有一份工作，想加一条副业但拿不准从哪开始。
- 你自由职业半年到一年，收入起伏大想找结构性解法。
- 你被"某某年入百万只靠一件事"的爽文击穿，想校准。
- **红线**：**不适用于**每月固定支出低于 3000 元的极简生活者（三条腿对他们过重）。

## 评估对象

- 一个具体的人（自己或他人）当前 12 个月的收入结构。

## 维度定义

### 维度 1: 兜底腿（工资 / 主营现金流）

指**每月/每季度稳定、可预测、被外部合约保障**的收入。典型代表：工资、长期合同、固定客户维护。

| 好信号 | 坏信号 |
|---|---|
| 覆盖 100% 房贷+日常开支 | 只够覆盖 50% 以下开支 |
| 至少签到年度合约 / 有 3 个月以上通知期 | 随时可能被砍（例：项目制无保障） |
| 你随时能睡好觉，不会周日晚上失眠 | 你每月看余额都心跳加速 |

→ 怎么观察：过去 12 个月**最低月收入**能不能覆盖当月**必要支出**。

### 维度 2: 探索腿（副业 / 短期项目）

指**当下能变现、但收入不稳定、你在主动尝试**的收入。典型代表：小报童专栏、零散咨询、公众号广告、短期合作。

| 好信号 | 坏信号 |
|---|---|
| 每月能带 10-30% 额外收入 | 完全不产生现金流，只是"在做"没在收 |
| 有 2-3 个探索方向而不是 1 个 | 只押 1 个方向且已投入 6 个月未回本 |
| 每次探索能沉淀能力/内容资产 | 每次探索都从零开始、创意型无法复利 |

→ 怎么观察：过去 6 个月，**至少一个探索项**是否走到"有付费用户/客户"这一步。

### 维度 3: 沉淀腿（差异化技能 / 长期 IP）

指**现在还不赚钱、但你在积累的差异化技能或 IP**。典型代表：占星、写作、深度专业、影视 IP。

| 好信号 | 坏信号 |
|---|---|
| 别人有需求会主动想到你（"XX 懂这个"） | 别人不知道你在做这件事 |
| 你能持续输出（每月至少 4 条内容） | 断续输出、随心情 |
| 这个技能**难以被大厂/同行短期复制** | 技能极普通、无门槛 |

→ 怎么观察：**外部主动询问**次数（过去 6 个月，别人主动问你这方面的经验/合作/知识）。

## 打分卡 / 分级表

对着自己/他人的**当前 12 个月**打分：

| 维度 | 1-5 分 | 我的证据 | 下一步动作 |
|---|---:|---|---|
| 兜底腿 |  |  |  |
| 探索腿 |  |  |  |
| 沉淀腿 |  |  |  |

**总分 → 结构诊断**：

| 总分 | 结构判断 | 行动建议 |
|---:|---|---|
| ≥ 12 | 稳定三条腿 | 优化比例（例：兜底腿从 80% 逐步降到 60%） |
| 9-11 | 两条腿 | 补最弱那条，别急着砍任何一条 |
| 6-8 | 一条腿 | 现阶段不折腾，先加第二条 |
| ≤ 5 | 无结构 | 先建兜底腿，其他暂缓 |

## 打完分怎么用

- **兜底腿低分**：不建议辞职、不建议单干；先修补主营/工资，或降本让主营够用。
- **探索腿低分**：花 1 个季度选一个方向真跑一次（有付费用户），不要同时铺 3 条。
- **沉淀腿低分**：找一个你**已经喜欢做且难以外包**的技能开始定期输出，2 年为最小观察周期。
- **总分够，比例失衡**：不必执着于"某一刻的比例"，看**未来 3 年目标比例**逐步迁移即可。

## 常见坑

- ❌ 把"想做的事"当成沉淀腿——沉淀腿必须已经有**输出证据**，不是"我打算学 XX"。
- ❌ 把"多个副业"当成三条腿——三条腿是**性质不同**的三条（兜底/探索/沉淀），不是量的三条。
- ❌ 兜底腿是 0 就急着搞第三条——**顺序是从下往上**（先兜底、再探索、最后沉淀）。
- ❌ 把"稿费/广告"当成沉淀腿——它是探索腿，除非你已形成 IP。

## 附录：实例

**七天路过 · 杭漂 2.0 阶段（当前）**

- **兜底腿（80%）**：冥想公司市场岗位工资。
- **探索腿（20%）**：小报童专栏 + 零散咨询。
- **沉淀腿（暂 0%，正在积累）**：占星差异化技能 + 写作长期 IP。
- **诊断**：结构完整，只是探索腿占比偏低。她自己说"不用太在意某一刻的比例，要瞄准最终想达成的比例"。
- **验证**：她能从阿里离开一段时间的"我想开了社群"再回归打工，不慌，说明兜底腿修复够快。

**参考对照 · 她朋友 · 言情作家型**

- **兜底腿**：无（自由作家）。
- **探索腿**：写言情小说。
- **沉淀腿**：影视 IP 版权（与光线传媒合作，年入百万+，重庆买房）。
- **诊断**：探索 → 沉淀已跑通，兜底腿由 IP 现金流反哺，属于结构不同但成立的形态。

## 附录：为什么值得用

七天路过原话："**人只有一条腿是不稳的，三条腿才稳。**" 相比"all in 一件事" vs "多副业分散"两种极端，三条腿模型给的是**性质分层**——每条腿承担的功能不同，因此比例可以在人生不同阶段流动。
