# [框架] 024-抖音渠道结构跟风向

## 一句话
按"平台自己在推谁"逐年调整达播/店播/商品卡三者的销售占比。

## 什么时候用

- 你在抖音做品牌店已经跑了一年以上
- 到年度复盘/季度复盘时点，要重估销售结构
- 你听到"达播转化率在下降"或"抖音商城成交在拉高"这类信号
- **红线**：不适用于起号期账号（起号期没有历史数据可对比）

## 评估对象

- 一个抖音品牌店过去一年的销售构成
- 颗粒度：GMV 按渠道类型（达播 / 店播 / 商品卡+商城）拆分

## 维度定义

### 维度 1：达播占比

- 达人带货带来的 GMV / 总 GMV
- 观测信号：**转化率是否在下降**、**头部达人报价是否在涨**

| ✅ 加投信号 | ❌ 减投信号 |
|---|---|
| 头部达人整体转化率同比上涨 | 转化率同比明显下降 |
| 你的品能进头部达人自然选品 | 需要越涨越高的坑位费 |
| 品类需要高信任背书 | 用户已能通过商品卡自决 |

### 维度 2：店播占比

- 自家账号直播带来的 GMV / 总 GMV
- 观测信号：**店播 GMV 是否稳定上涨**、**主播能力是否可复制**

| ✅ 加投信号 | ❌ 减投信号 |
|---|---|
| 店播 GMV 同比稳定上涨 | 主播离职就断层 |
| 有可复用的直播脚本和流程 | 靠一个"神主播"撑单 |
| 平台还在给店播流量倾斜 | 平台明显把流量切给别的入口 |

### 维度 3：商品卡 / 抖音商城占比

- 商品卡、猜你喜欢、抖音商城入口成交 GMV / 总 GMV
- 观测信号：**平台官方是否在主推**、**成交是否在拉高**

| ✅ 加投信号 | ❌ 减投信号 |
|---|---|
| 平台官方多次推商城/商品卡入口 | 平台把资源切回内容侧 |
| 商品卡自然搜索成交上涨 | 搜索转化持续下滑 |
| 品类是复购型/搜索决策型 | 品类必须种草才成交 |

### 维度 4：平台风向信号（顶层维度）

- 单独一维用于校准：**"平台自己推谁，我们就往哪个跑。"**
- 观测信号：抖音年度商家大会主推口径、官方 case study 举例的渠道、后台流量分配变化

## 分级 / 打分表

**结构诊断卡**：

| 年度 | 达播 | 店播 | 商品卡 | 平台风向 | 结论 |
|---|---:|---:|---:|---|---|
| 上年 |  % |  % |  % |  |  |
| 本年目标 |  % |  % |  % |  | 加大/维持/减小 |

**分级建议**：

- **A：与风向对齐** → 维持结构，重点优化单个渠道内部效率
- **B：结构落后风向 1 步** → 本年度把权重挪 5–15%，慢调
- **C：结构落后风向 2 步以上** → 本年度大幅调结构，同时补人和内容资产

## 打完分怎么用

- 达播减、店播加、商品卡加 → 招店播主播/搭建直播矩阵 + 补商品卡关键词优化
- 达播加、店播减 → 品牌可能还在教育期，回到达人带货铺信任
- 全部下滑 → 不是结构问题，是品/供应链问题，回 [[02方法流程/_stubs/搞钱女孩/[SOP] 024-DTC品类切入尽调法|品类尽调]]

## 常见坑

- ❌ 硬扛平台风向：平台推商品卡你还在死磕达播 = 逆水行舟
- ❌ 一次调整过猛：一年内把某个渠道从 50% 归零，团队跟不上
- ❌ 只看自家数据：忽视"平台官方在推谁"这个顶层信号

## 附录：实例

Willa 的西苔 2023 年结构：达播 : 店播 = 51 : 49；她 2024 年判断"达播整体转化率和体量在下降，店播稳定上涨，抖音商城/商品卡成交在拉高，官方也在主推"→ 结构向店播 + 商品卡倾斜。她的一句话总结："他推哪个我们跑哪个，打不过咱们就加入呗。"
