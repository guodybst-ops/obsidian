# [框架] 029-效率生意 vs 主理人生意选边框架

## 一句话（≤ 40 字）

用能力圈四维对比，判断该做效率赛道还是主理人赛道。

## 什么时候用

- 你要开一家实体小店（咖啡/花店/民宿/独立餐厅），在"跟连锁卷低价"和"做小而美"之间犹豫。
- 你已经在跑，但外面价格战让你想跟进 9.9 元赛道，纠结要不要跟。
- 有投资方劝你"一年开几十家"，你不确定要不要接。
- **红线**：不适用于纯供应链型 B2B、不适用于信息差型电商——本框架只服务线下体验型小店。

## 评估对象

- 一个具体的实体小店品类 + 你自己（个人 or 团队）的能力组合。

## 维度定义

### 维度 1：供应链效率——同品类下你的采购/损耗成本差

| ✅ 好信号 | ❌ 坏信号 |
|---|---|
| 有大规模集采能力 / 直采源头 | 只能从中间商拿货 |
| 有中央厨房 / 仓配体系 | 每店独立进货 |
| 损耗率能压到 3% 以下 | 损耗率 10% 以上 |

→ 怎么观察：算你和瑞幸/星巴克在同一款咖啡豆上的到货价差；差距 < 20% 说明供应链拉不开。

### 维度 2：数字化能力——获客、订单、复购的系统化程度

| ✅ 好信号 | ❌ 坏信号 |
|---|---|
| 有自建 App / 小程序会员体系 | 只靠外卖平台和微信群 |
| 能算清 CAC / LTV / 复购率 | 数据靠感觉 |
| 有算法调度 / 动态定价 | 完全人工排班和定价 |

→ 怎么观察：你能不能拉出上月每一杯咖啡的来源渠道？不能 → 数字化不合格。

### 维度 3：开店/复制能力——3 个月开 10 家店的能力

| ✅ 好信号 | ❌ 坏信号 |
|---|---|
| 有拓店团队 + 装修标准 SOP | 每家店老板亲自装 |
| 有店长培养体系（培训 → 上岗 ≤ 30 天） | 店长离职即崩 |
| 单店回本周期 ≤ 12 个月 | 单店回本 ≥ 24 个月 |

→ 怎么观察：给你 500 万，你能不能 90 天内开出 10 家能自转的店？不能 → 复制能力不合格。

### 维度 4：内容与体验能力——用户"为什么来你这"的非价格理由

| ✅ 好信号 | ❌ 坏信号 |
|---|---|
| 有稳定内容输出（播客/公众号/展览/市集） | 只靠美团点评 |
| 有回头客能叫出名字 | 客人来一次就消失 |
| 到店体验（服务/氛围/出品）有明显记忆点 | 和连锁体验无差别 |

→ 怎么观察：一鹏原话——"没有内容，别人买你 9.9 和买连锁 9.9 只是一个概率问题"——你能给一个不选连锁而选你的理由吗？

### 维度 5：你的能力圈——你和团队真正擅长的东西

| ✅ 好信号 | ❌ 坏信号 |
|---|---|
| 主创对品类有真实日常使用 | 只是听说品类火 |
| 团队里有做过内容 / 服务的核心成员 | 团队清一色供应链背景做主理人店 |
| 你能一句话说出"我们不能做什么" | 你觉得"我们什么都能做" |

→ 怎么观察：一鹏反例——"美式复古风火，你日常生活中有这些东西吗？没有 → 必死无疑"。你日常就在这个品类里吗？

## 打分卡 / 分级表

**每维度打 1-5 分**：

| 维度 | 我的得分 | 大品牌得分 | 差距 |
|---|---:|---:|---:|
| 供应链效率 |  | 5 |  |
| 数字化能力 |  | 5 |  |
| 开店/复制能力 |  | 5 |  |
| 内容与体验能力 |  | 2 |  |
| 你的能力圈（自评） |  | — |  |

**分级判断**：

- **A. 效率型选手**：维度 1-3 加总 ≥ 12 分 → 可以卷价格战，进 10 元赛道也不慌。
- **B. 主理人型选手**：维度 4-5 加总 ≥ 8 分，1-3 加总 < 9 分 → 做慢、做美、做内容，不要进 10 元赛道。
- **C. 双弱**：全部 ≤ 3 分 → 现在不是你入场的时机，先补一项优势再来。
- **D. 分裂型**：几个维度都不错但没有一个突出 → 危险，容易被上下夹击。

## 打完分怎么用

- **A 级（效率型）**：进 10 元咖啡赛道，参考瑞幸/Manner 打法。链到 [[03概念链接/_stubs/搞钱女孩/[对比] 029-效率生意 vs 主理人生意|效率生意 vs 主理人生意]]。
- **B 级（主理人型）**：**做内容 + 做体验，不进 10 元赛道**。参考大小咖啡打法——播客/艺术空间/市集/巧克力四板块建品牌厚度。同时用 [[02方法流程/_stubs/搞钱女孩/[SOP] 029-咖啡馆开店前算账反推法|开店前算账反推法]]确认财务模型。
- **C 级（双弱）**：**暂缓开店**。先补一项优势——要么去连锁做 2 年学效率生意，要么先自媒体做内容起量。
- **D 级（分裂）**：**收缩到 B**。放弃复制野心，专注做一家有内容的小店。

## 常见坑

- ❌ 用一时的价格战情绪判断——9.9 元咖啡战是一波周期，别赌短期心态。
- ❌ 高估自己内容能力——"有个公众号"不等于有内容能力，看是不是"稳定输出 + 回头客"。
- ❌ 把"我很爱咖啡"当成能力圈证据——一鹏本人反例："我不知道什么叫热爱咖啡，我只是日常习惯"。
- ❌ 觉得"我可以两条腿走"——本框架是选边不是骑墙，双维度都平庸就是双弱。
- ❌ 忽略维度 5——供应链再好，你不生活在这个品类里，做不出体验。

## 附录：实例

**大小咖啡（B 级 · 主理人型）**：

- 维度 1 供应链：3 分（价格透明 + 无集采优势）
- 维度 2 数字化：2 分（无自建系统）
- 维度 3 开店：2 分（7 年 5 家店）
- 维度 4 内容与体验：5 分（周更播客 + 艺术空间 + 市集 + 巧克力矩阵）
- 维度 5 能力圈：5 分（一鹏自己就在精品吃喝里生活）

→ 综合 B 级——做慢做美做内容，2016 年到 2023 年活下来。

**瑞幸对照（A 级 · 效率型）**：维度 1-3 都是 5，维度 4-5 是 2-3。→ 做 9.9 元赛道理所当然。

**假想反例（D 级 · 分裂）**：一个"想开美式复古咖啡馆"的人，他不生活在美式复古里，也没有供应链，只是觉得火——五维全 2 分，一鹏原话"必死无疑"。
