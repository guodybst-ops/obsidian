# [SOP] 熟人合伙分账避坑流程

## 一句话（≤ 40 字）
合伙前先把钱权责写清。

## 什么时候用

- 准备和熟人合伙拍片、开店、做项目。
- 几个自然人想先干起来再补合同。
- 分账、投入、退出还没说清。
- **红线**：不适用于已经发生纠纷后的法律替代。

## 输入

- 合伙人名单。
- 投入清单。
- 收入、成本、分账规则。

## 输出

- 一份合伙前分账清单。
- 一份退出和止损约定。

## 主流程

### Step 1: 明确主体

- 判断是否成立公司、项目组或签自然人协议。
- 不要三个人凑一份模糊合同。

### Step 2: 写清投入

- 每个人投入多少钱、时间、设备、人脉。
- 投入不等于股权，必须单独约定。

### Step 3: 写清分账

- 收入先扣哪些成本，再按什么比例分。
- 谁有付款审批权。

### Step 4: 写清退出

- 合伙人中途退出怎么结算。
- 争议发生时找谁调停或走什么流程。

### Step 5: 设置止损线

- 亏到多少钱必须暂停。
- 超过止损线不得靠面子硬撑。

## 判断点 / 决策树

```text
主体、投入、分账、退出、止损线是否都写清？
  ├─ 是 → 进入小额试运行，约定复盘日期
  └─ 否 → 暂缓合作，先补齐缺项

是否已经发生纠纷？
  ├─ 是 → 停止追加投入，转入证据整理与专业咨询
  └─ 否 → 按约定执行并保留收支记录
```

## 常见坑

- ❌ 用“都是朋友”替代书面约定，关系越近越要把钱权责写清。
- ❌ 把时间、人脉、设备等投入口头估价，最后无法公平结算。
- ❌ 亏损后继续靠面子追加投入，超过止损线就应暂停。
- ❌ 只约定怎么分钱，不约定谁能退出、如何退出。

## 附录：实例

抱抱复盘熟人合伙项目时，问题不是单一的亏损，而是前期没有把投入、分账和退出写清，导致关系和项目一起承压。按本 SOP 重做时，应先把各方投入折成清单，再写清成本扣除顺序、分账比例和止损线，最后才决定是否继续合作。
