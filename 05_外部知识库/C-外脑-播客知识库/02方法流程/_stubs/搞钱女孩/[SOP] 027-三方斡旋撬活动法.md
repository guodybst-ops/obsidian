# [SOP] 027-三方斡旋撬活动法

## 一句话（≤ 40 字）

用 A 的模糊承诺撬 B，用 B 的承诺撬 C，直到三方各自到位。

## 什么时候用

- 你要办的活动/合作**任何一方独立不承诺**（"你先落地场地我再决定 / 你先请到人我才批预算"）。
- 你手里**没有钱、也没有硬渠道**，只有牵头意愿和信息。
- 至少有 3 个角色：**场地方 / 资源方 / 站台方**（或类比的三方结构）。
- **红线**：不适用于**只有两方**的谈判（那是普通商务），也不适用于**任何一方明确要求"其他两方先书面签字"**的场合。

## 输入

- 一个模糊但可行的活动主意（例：新书首发会）。
- 三方各自的最低可接受承诺（例：书店愿意先"暂留档期"、出版社愿意先"考虑参与"、畅销书作者愿意先"看看时间"）。
- 一个自己牵头的时间窗（1-2 周集中打电话）。

## 输出

- 三方各自"落地一半"的书面确认（口头亦可，但要留证据）。
- 一场跑通的活动 + 至少 1 个可传播的现场素材（观众数、媒体、加印）。

## 主流程

### Step 1: 拆结构，列三方

- 写下：**我要办 X。**
- 拆出必须到场的三方角色（示例：**书店/场地 A × 资源/主办 B × 站台/流量 C**）。
- 三方缺一不可 → 才有"斡旋"空间；不缺 → 不用这个方法。

### Step 2: 对 A 说"C 会来"（用最强背书的口吻，但不作硬承诺）

- 打给 A：**"我们这边会有 C 类型的畅销/头部方来站台，能不能先给我们留一个档期？"**
- 目标：拿到 **A 的档期口头保留**（不是硬合同）。
- 如果 A 追问"到底哪位 C" → 给一个模糊范围（"我们正在接触 3 家，1 周内能确认")。

### Step 3: 对 B 说"A 的场地已经在推进"

- 打给 B：**"798 那边的 A 我已经在跟他谈档期，你们出版社/公司要不要参与？"**
- 目标：拿到 **B 的原则性同意**（预算/人力初步同意）。

### Step 4: 对 C 说"活动会在 A 举办、且 B 参与、且有媒体"

- 打给 C：**"我们会在 798 A 这个地方做活动，B 出版社也已经在推进，届时会有媒体（列已经在联系的 2-3 家）到场。"**
- 目标：拿到 **C 的口头站台承诺**。

### Step 5: 三方回调 · 用真承诺换真承诺

- 拿 C 的口头承诺，回头**升级** A 的口头档期为**正式档期**。
- 拿 A 的正式档期，回头**升级** B 的"原则同意"为**预算/物料落地**。
- 拿 B 的物料预算，回头**给 C 邮件确认**媒体计划、宣发排期。

### Step 6: 交叉见证 + 时间点收口

- 让三方通过邮件/群/合同互相看到对方的确认（**关键——让承诺可视化**）。
- 定一个共同截止日（例："下周三前如果任一方退出，活动取消"）→ 把"斡旋态"固化为"合作态"。

### Step 7: 现场跑一次 + 沉淀素材

- 跑活动，抓住 3 个素材：**人数（例：300 人现场）+ 媒体（例：梨视频/新华网）+ 首印结果（例：卖完 → 加印）**。
- 这些素材本身是下一轮斡旋的资本。

## 判断点 / 决策树

```
Step 2 对 A 撬不动
  ├─ 原因是"没有 C" → 先跳 Step 4 找一个愿意先松口的 C，再回来
  └─ 原因是"档期真没有" → 换场地 A' 或延后

Step 3 对 B 撬不动
  ├─ 原因是"C 太弱" → 升级 C（找更头部的站台方）
  └─ 原因是"和 A 关系差" → 换场地 A'

Step 4 对 C 撬不动
  ├─ 原因是"不认识我" → 用 A 或 B 引荐
  └─ 原因是"看不上媒体" → 补 2 家媒体，回头再谈
```

## 模板 / 清单

**三方斡旋跟踪表**（可复制粘贴）：

| 角色 | 是谁 | 我给他讲的话术 | 他的承诺（口头/正式） | 需要另外两方给什么 | 当前状态 |
|---|---|---|---|---|---|
| A 场地 |  |  |  |  |  |
| B 主办 |  |  |  |  |  |
| C 站台 |  |  |  |  |  |

**电话话术骨架**：

- "**我们这边有 [其他两方的一方] 已经在推进**，你们要不要一起？"
- 不撒谎、不承诺、只描述**"正在推进"**的事实。

## 常见坑

- ❌ 一开始就对某方硬承诺"另外两方一定到"——一旦某方黄了，你的信用崩掉。
- ❌ 对三方各讲不同版本的核心内容（时间、地点、主题不一致）——三方一碰头就穿帮。
- ❌ 拖太久不收口——三方各自的口头承诺会随时间贬值。**从 Step 2 到 Step 6 不超过 2 周**。
- ❌ 只挑一方好谈的——三方缺一撬不起来。
- ❌ 忘了留证据（Step 6 交叉见证）——活动前一天有人退出你无凭据。

## 附录：实例

**七天路过 · 2018 年 10 月 · 《大大的城市小小的我》首发会**

- **A（场地）**：798 一家大书店。话术："我们会有畅销书作家来站台。"
- **B（主办）**：出版社。话术："我找到了 798 的场地。"
- **C（站台）**：某畅销书作者。话术："我们会在 798 做活动，而且有媒体来。"
- **收口**：三方各拿一半、都愿意加入。
- **结果**：现场 300 多人，梨视频、新华网记者到场，首印卖完加印，半年内卖出台湾版权。
- **原素材来源**：她自己参考"施瓦辛格竞选加州州长"的三方斡旋故事。
