# [SOP] 命运齿轮启动四步

## 一句话

从"缺钱/受够/看到风口"到主动做出第一个动作的启动流程。

## 什么时候用

- 你已经不满意当下生活或收入，但迟迟没做动作。
- 你有想赚钱的念头，但不知道"第一步在哪里"。
- 你已经看到一个外部风口，但还在观望要不要下场。
- **红线**：不适用于财务紧急兜底（需先做现金流保底，再谈齿轮），也不适用于纯情绪逃离（换城市、换恋爱不是这里的"动作"）。

## 输入

- 一个具体的"不满"（缺钱数额 / 具体讨厌的场景 / 看到的具体风口）。
- 手机 / 通讯录 / 你所在的一个社群（有一个即可）。
- 24 小时内可用的空闲时段。

## 输出

- 一个已发出去的具体动作（一封投稿邮件 / 一次群内提问 / 一次电话回应 / 一条朋友圈方案）。
- 至少一个来自外部的反馈信号（正/负都算）。

## 主流程

### Step 1: 把"不满"翻译成一个具体数字或场景

- 写下"我现在最不满的是 ___"，尽量具体。
- 写下"我需要 ___ 元 / 我要离开 ___ 状态"。
- 判断信号：如果只能写"我不开心"，回到具体细节继续写；写不出具体数字就没有触发扳机。

### Step 2: 列出手边所有可用的信道（穷举，不筛选）

- 打开微信通讯录、社群、订阅号邮箱、朋友圈——把可能相关的信道全部列出来。
- 参照物：七天路过一次性翻了 50+ 个公众号邮箱；黄小刀把生财有术微信群当成第一个发起地。
- 判断信号：清单不到 20 条，说明"没在找"，回 Step 1 补细节。

### Step 3: 做第一个"发出去"的动作

- 从清单里任选一个信道，发一条**具体、可回复**的信息（投稿、提问、方案、求助均可）。
- 动作模板：`我是 __，我看到 __，我可以做 __，价格/时间是 __，能不能一起？`
- 判断信号：动作已经离开你的手，进入别人视野——第一个齿轮咬合完成。

### Step 4: 接住反馈并立即回应

- 有正反馈（"扣 1"/"我付费"/"来给我们写稿"）→ 立即回话并把动作升级（组队/写大纲/敲选题）。
- 有负反馈或无反馈 → 回 Step 2 换下一条信道，不停留在"反馈不好"这件事上。
- 判断信号：当天出现第一次别人 → 你 → 别人的三次交互，齿轮开始转动。

## 判断点 / 决策树

```
是否有具体不满 → 无 → 回 Step 1
是否列出 20+ 信道 → 无 → 回 Step 2
是否已发出第一个动作 → 无 → 回 Step 3
是否有任何反馈 → 无 → 回 Step 4 换信道
```

## 模板 / 清单

**齿轮启动 24 小时清单**

- [ ] 写下 1 个具体不满
- [ ] 列出 20+ 可用信道
- [ ] 发出 1 条具体请求
- [ ] 记录第一条反馈

## 常见坑

- ❌ 把"想想再说"当动作——想不算动作，发出去的信息才算。
- ❌ 只发 1-2 个信道就觉得"没用"——七天路过 50+ 里只有 1 个回复，样本量决定结果。
- ❌ 等大佬主动找上门——大佬只会记得那些主动发消息的人。

## 附录：实例（七天路过 · 廊坊到北京）

- 具体不满：小城公司放假一个月没工资，一眼望到头。
- 信道清单：50+ 个微信公众号投稿邮箱。
- 第一个动作：一封一封投稿"我可不可以给你们写稿"。
- 反馈：只有 1 家回复（桃路音乐 / 桃路文化），200 元/篇 × 8 篇 = 1600 元/月。
- 一年后：因为写作被人民日报转载 → 出版书 → 网易内推 → 阿里 → 我想开了社群。第一个雪球咬合。

## 附录：为什么值得用

三位嘉宾在同一集里给出了同构的齿轮启动模型（七天路过缺钱 / 陈雪受够 / 黄小刀风口），触发器不同，动作范式一致：**具体不满 → 穷举信道 → 发出动作 → 接反馈**。这条 SOP 就是把三个故事的最大公约数抽出来。
