# [心法] 023-积极撞击世界，成败皆尾反馈

## 一句话

启动的两种结果都不亏：赚到钱或赚到经验。

## 什么时候想起它

- 你识别到一个可能的异常值/机会，但不确定能不能变现。
- 你在评估一个新项目的 ROI，越算越不敢启动。
- 你已经"想了半年做 XX"却一步没动过。
- **反向触发（想起它就要警觉）**：出现"如果失败了怎么办"这种反复内耗的念头。

## 具体怎么用

- 用"玩票性质"启动——不定 KPI、不定期限、拉 3-5 个人小范围开搞。
- 前 3 天专注在**产出一个具体可交付物**（一份手册 / 一个页面 / 一次直播）。
- 不管产出结果好坏，都做一次日流水复盘。
- 只在真的跑通后再谈公司化 / 全职化。

## 反例

看到风口后花两个月做市场分析、写商业计划书、找投资人聊——等准备好，窗口关了。

## 常见误读

- ❌ 理解成"什么都可以撞"——是**在异常值信号成立后**再撞，参照 [[02方法流程/_stubs/搞钱女孩/[心法] 023-反复被提及即异常值]]。
- ❌ 理解成"不用复盘"——尾反馈的关键是"赚到经验"，没有复盘就没有经验。
