# [框架] 项目评估：想做 × 能做 × 可做（+ 时间带宽）

## 一句话（≤ 40 字）
用四个维度判断一个项目现在适不适合你做，先接受 65 分。

## 什么时候用

- 手边有多个副业 / 转行 / 创业候选项目，需要取舍。
- 别人问你"XX 项目能不能做"你想给一个负责任的回答。
- 你正在纠结"我到底该做小红书 / 跨境 / 摆摊 / 快团团"。
- **红线**：不适用于纯兴趣项目（无变现意图），也不适用于本金极小、只是想"试试水感"的初次探索。

## 评估对象

- 一个**具体**候选项目 / 副业方向 / 转行选项，需具备：
  - 有明确品类和模式（例："在小红书做家居精准客群成交"）
  - 有可估算的投入（时间 or 现金）
  - 有可想象的收益路径

不适用："搞副业"这种泛泛项。

## 维度定义

### 维度 1：想做（Want）——你的热情所在

**一句话操作定义**：不需要每天亢奋，但至少不讨厌，愿意持续投入时间。

**观测信号**：

| ✅ 好信号（想做强） | ❌ 坏信号（想做弱） |
|---|---|
| 一个月不用逼自己也在琢磨它 | 只在焦虑或攀比时才想到 |
| 做的时候能进入状态、不看时间 | 做半小时就想开小红书 |
| 你能连续讲 30 分钟不重复 | 只能复述别人说过的话 |
| 见到同行做得好会想学而不是嫉妒 | 主要情绪是"我也要吃到这波" |

→ **怎么问出来**：如果这个项目一年赚不到 5 万，你还愿不愿意继续做？

### 维度 2：能做（Can）——你的优势区间

**一句话操作定义**：技能 + 能力 + 资源三者合一，你做起来比别人更轻松。

**观测信号**：

| ✅ 好信号（能做强） | ❌ 坏信号（能做弱） |
|---|---|
| 已有相邻经验/项目/身份可迁移 | 全新领域从零开始 |
| 起步动作你已经做过 | 起步动作要花几个月摸清 |
| 有现成的人脉/渠道/供应链 | 需要从陌生人开始搭 |
| 别人问你能给出具体回答 | 只能复述二手信息 |

→ **怎么问出来**：这件事让你和一个 985 应届生同时起步，你比他快 3 个月能拿到第一笔钱吗？

### 维度 3：可做（Feasible）——行业趋势与合规

**一句话操作定义**：行业顺风、政策不打压、模式合规——不逆风而行。

**观测信号**：

| ✅ 好信号（可做强） | ❌ 坏信号（可做弱） |
|---|---|
| 大盘处于上升期或结构性利好 | 处于夕阳期或被政策打压（如教培） |
| 商业模式清晰、有跑通过的样本 | 只有 KOL 口嗨、缺现金流样本 |
| 合规、无擦边、无灰产 | 涉及刷单/暴利承诺/信息不对称套利 |
| 至少能想清"钱从哪来" | 说不清利润来自哪条线 |

→ **怎么问出来**：找 3 个已经在这个赛道跑通的人，他们是靠什么线赚到钱的？

### 维度 4：时间/精力带宽（Bandwidth）——第四维隐藏刻度

**一句话操作定义**：你有正职/家庭时，还能为这个项目留出多少可持续投入的时间。

**观测信号**：

| ✅ 好信号（带宽足） | ❌ 坏信号（带宽紧） |
|---|---|
| 每周至少能稳定投 10 小时 | 每周只能挤 2-3 小时且不稳定 |
| 项目模式相对轻运营 | 项目本身重运营（快团团式选品+社群+售后） |
| 主业稳定、下班后能切换状态 | 主业加班多、精气神已被消耗 |
| 有合伙人/外包分担部分交付 | 全靠自己一个人扛 |

→ **怎么问出来**：连续 3 个月每周投 10 小时，你还愿意 / 还撑得住吗？

## 打分卡 / 分级表

| 维度 | 1-5 分 | 我的证据 | 备注 |
|---|---:|---|---|
| 想做 |  |  |  |
| 能做 |  |  |  |
| 可做 |  |  |  |
| 时间/精力带宽 |  |  |  |
| **总分** |  | | 满分 20 |

**分级规则（65 分预设，即 13/20 ≈ 65%）**：

- **≥16 分（≈ 80%）**：可以立刻投最小可行版本（MVP）。
- **13-15 分（≈ 65-75%）**：**这就是一个 65 分项目**，值得做，只是要把最弱的一维单独制定补齐计划。
- **9-12 分**：暂缓——先补最弱的一维，或者去做上一档目标；不能凑合上马。
- **≤8 分**：不要做，就算别人在赚也不要跟——**没有不能做的项目，不行的是人**。

## 打完分怎么用（先算账再决策）

打完维度分后必过 **65 分四把尺**：

1. **算账**：
   - 利润天花板：这行业头部赚多少？
   - 投入成本：线上项目算时间；线下项目算租金/员工/存货，能不能负担？
   - 回本周期：多少个月？期间你亏得起吗？
2. **拆生意模型**：利润来自"粉丝量→广告"，还是"精准客群→to B 成交"？
3. **看大盘趋势**：朝阳还是夕阳？政策鼓励还是打压？**不逆风而行**。
4. **卡合规红线**：违法违规的一票否决，无论利润多诱人——"你想赚他的佣金，人家惦记的是你的本金"。

四把尺全过 → 进入行动阶段；卡在任一尺 → 回打分卡对应维度重估。

## 常见坑

- ❌ 追求"满分项目"——预期不切实际，先接受 65 分。
- ❌ 只看"想做"→ 项目做不下去；只看"可做"→ 起步就落后；只看"能做"→ 撑不过热情期。
- ❌ 忽略"时间/精力带宽"——有正职的人做重运营副业几乎必然翻车。
- ❌ 用"粉丝为啥不涨"衡量所有内容项目——精准客群路线本来就不看粉丝量。
- ❌ 被"月入百万"数字迷惑，不看合规和风险——**利润数字前先看红线**。

## 附录：实例

**正例——搞钱女孩本身（雪怡自解）**：
- 想做：她本人喜欢听播客
- 能做：已有个人播客《主动交代》做了近两年+播客人脉+"很会问问题"
- 可做：播客对上班族投入相对可控 + 一期发布可持续滚动流量
- 时间带宽：与主播搭档，可分担
- → 三圈全交集、时间带宽通过，跑通。

**反例——雪怡跟风炒股亏钱**：
- 想做但很浅（听消息就买，没真感兴趣）
- 能做完全不满足（不懂行业、公司、买卖时机、收入预期）
- 时间带宽不足（买完就不管）
- → 亏钱是必然，不是运气差。

**第四维演绎——小辉放弃快团团**：
- 想做 ✓、能做 ✓（本就在做社群）、可做 ✓（赛道正热），**但正职占用+快团团重运营** → 果断放弃。理性认赔的"试错成本很低、回报很高"。
