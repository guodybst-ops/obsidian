# [SOP] 500 人深度私域法

## 一句话（≤ 40 字）

只做一个群，用服务密度和个人 IP 换复购。

## 什么时候用

- 供应链、价格都拼不过更大玩家（快团团、社群团购）。
- 私域人数不多，但客户关系真实，能亲力亲为跟每个人互动。
- 产品需要信任、售后、长期陪伴（母婴、女性消费、贴身品类、手作服务）。
- 想把生意做"到 80 岁一起跳广场舞"的关系型生意。
- **红线**：不适用于低客单、无售后、只靠一次性流量的生意；也不适用于本人不愿做 IP 露脸的场景。

## 输入

- 1 个可持续维护的微信群（预留 500 人上限）。
- 20 个来自真实关系的种子用户（熟人 / 同场景群友 / 转介绍）。
- 可稳定供应的商品或服务（母婴品、家居、女装、贴身品类等）。
- 每天固定 2-4 小时互动 + 售后时间。
- 一个可露脸的个人 IP 阵地（视频号 / 小红书 / 朋友圈）。

## 输出

- 一个人均复购 100+ 次、年销售可到 6 位数的高信任私域群。
- 一套用户生命周期 + 复购维护机制（生日 / 母亲节 / 季度手写卡）。
- 一份可复用的售后处理标准（陪吐槽 → 拖 30 分钟 → 达成方案 → 发红包收尾）。
- 一个能承接用户长期需求的品类地图（母婴 → 妈妈自用 → 女性服务）。

## 主流程

### Step 1: 找 20 个真实关系的种子用户

- [ ] 从孕妇瑜伽群、社区妈妈群、宝宝早教班等**真实场景**里找前 20 个愿意下单的人。
- [ ] 不买流量、不拉陌生人；先跟"能撑第一单场"的朋友讲清楚你在做什么。
- [ ] 记住每个人的偏好和小孩年龄——**这一步就是关系资产的起点**。
- **做完信号**：群里有人主动问、主动买、主动反馈；且他们能带来下一批朋友。

### Step 2: 立群的价值观（反 PUA 妈妈准则）

- [ ] 明确群里反对什么：不 PUA 妈妈、不道德绑架任何生育选择（母乳 / 顺产 / 断奶都不评价）。
- [ ] 强制备注规则：**禁止"X X 妈妈"**，改成"蛇口新垣结衣""龙华高圆圆"等让妈妈做自己的昵称。
- [ ] 私聊用"宝贝 / 亲爱的"，不主动问"你家宝宝叫什么"。
- **做完信号**：用户知道这个群不只是卖货，更代表一种"爱自己是终身课题"的相处方式。

### Step 3: 把服务做成壁垒（不扩群，做密度）

- [ ] 亲自回复每一条重要消息，不甩客服号。
- [ ] 记住 VIP 客户偏好、重要节日礼物、季度/年度手写卡片（配你和孩子的合照）。
- [ ] 母亲节 9 点前送花、客户小孩生日给"妈妈"发红包（"妈妈才是最辛苦的那个"）。
- [ ] 给 TOP 3 消费客户送 600 多元级礼物（如娇兰口红礼盒）。
- [ ] **不追求开 10 个群，先把 1 个群的服务密度做满**。
- **做完信号**：用户遇到相关需求时先想到你，而不是先比价。

### Step 4: 半年后切个人 IP，让家人变副 IP

- [ ] 观察到"客户开始变成同行 / 价格战开打 / 佣金压低"就是切 IP 信号。
- [ ] 拍短视频、开直播、群内高频分享日常和价值观，让客户"从见笔记到见人"。
- [ ] 让可爱的家人（孩子 / 宠物）成为**副 IP**，一起占据主 IP 地位。
- [ ] 有条件的开线下沙龙 / 工作室 / 女性活动——**只要见过面的客户就不会走**。
- **做完信号**：客户愿意开车 1 小时来见你，"你"本身成了流量入口。

### Step 5: 用 LTV 视角处理售后

- [ ] **第 1 步**：先陪客户吐槽厂家（"这厂家怎么这样，太离谱了吧"），让客户被认可。
- [ ] **第 2 步**：拖 30 分钟去联系厂家，让客户情绪缓下来进入理性协商窗口。
- [ ] **第 3 步**：给两个方案（只退问题件 / 整套退回），单笔可自贴钱。
- [ ] **第 4 步**：加一层意外惊喜（甜品、小礼物）+ 发 6.6 或 5.2 小红包 + 从朋友圈找共同话题聊回去。
- [ ] 心里算的是**这个客户未来 1-2 年的账**，不是这一单。
- **做完信号**：纠纷结束后，用户仍愿意继续购买、且主动转介绍。

### Step 6: 随生命周期迁移品类和场景

- [ ] 客户小孩 3 岁后，母婴品需求结构性减弱——不要硬撑活跃度。
- [ ] **切品类**：从母婴切到贴身衣物、女装、包包、护肤等妈妈自己消费的品类。
- [ ] **切场景**：接受妈妈们回归工作后只有睡前才翻群，别再"每天早晚打鸡血"。
- [ ] **切变现**：从卖货切到 IP + 线下沙龙 + 直播带货 + 知识付费的多结构收入。
- **做完信号**：老用户需求变了，但关系没有断——"要一起做到 80 岁"。

## 判断点 / 决策树

| 情况 | 下一步 |
|---|---|
| 群人数少但复购高 | 继续做深，不急扩群 |
| 客户开始变成同行 / 佣金被压 | 立刻进 Step 4 切 IP |
| 比价严重 | 加强 IP、仪式感和售后差异 |
| 母婴需求下降 | 进 Step 6 切品类切场景 |
| 售后纠纷多 | 用 Step 5 的 4 步流程建立赔付标准 |
| 情绪劳动过载 | 淘汰不尊重劳动的客户，不是所有人都要留 |

## 模板 / 清单

**核心客户档案表**：

| 用户备注 | 关系来源 | 常买品类 | 客单价 | 重要日期 | 售后记录 | LTV 判定 | 下一次可推荐 |
|---|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |  |

**售后 4 步话术模板**：

1. **陪吐槽**："这厂家怎么这样，你收到这个心情肯定不好"
2. **拖 30 分钟**："我这就去帮你联系厂家，你稍等我一下"
3. **给两方案**："厂家说可以退问题件 / 我个人愿意帮你把整套退了，你觉得哪种更方便"
4. **发红包收尾**：6.6 或 5.2 红包 + 从她朋友圈找一个共同话题聊回去

**群规反 PUA 清单**：

- ❌ 禁止"X X 妈妈"备注
- ❌ 禁止评价母乳 / 顺产 / 断奶等生育选择
- ❌ 禁止以"你都是当妈的人了"劝退妈妈们打扮 / 学习 / 花钱
- ✅ 鼓励用"新垣结衣""高圆圆""易烊千玺的姐姐"等自我昵称
- ✅ 鼓励讨论妈妈自己的爱好和消费

## 常见坑

- ❌ **不要用低价做唯一壁垒**——低价一定会被更大供应链打掉。
- ❌ **不要盲目扩群到 10 个 20 个**——服务半径不够会稀释信任。
- ❌ **不要把单笔售后看得太重**——要算用户长期价值。
- ❌ **不要默认妈妈只关心孩子**——妈妈自己的消费是后半程增长点。
- ❌ **不要害怕收钱**——朋友要求退佣金给她是需要淘汰的关系，不是你该妥协的。
- ❌ **不要在焦虑时冲动交五位数割韭菜学费**——凭风口赚来的钱会拼实力亏掉。

## 附录：实例

### 149 元床套售后案例（LTV 视角样板）

客户洗完四件套后发现床套破洞，一般规则不给退（无法证明是原厂问题）。泳怡的处理链：

1. **共情**："大家收货都是随手一看就洗，谁会检查每个角落"（先站客户一边）；
2. **两方案**——只退床套 149 元 or 整套买下退给客户（自贴钱）；
3. 客户选后者，泳怡自贴 141 元（厂家只退 8 元）；
4. **再加一层**：客户是前公司甲方同事，她给同办公室 3 人每人送一份甜品作为额外致歉。

单笔亏 179 元，但客户在她这买 1-2 年，账绝对是赚的。

### 500 人一个群做到年销售 120 万+（服务密度壁垒样板）

泳怡只维护 1 个 500 人微信群，做到**人均复购 100+ 次、年销售 120 万+、月入至少 2 万+**。核心不是卖货技巧，是：

- **拼供应链拼不过 → 拼服务像海底捞**
- **仪式感高频叠加**：生日红包 / 母亲节送花（比老公还快）/ 季度手写卡（配儿子合照）/ TOP 客户娇兰口红礼盒
- **售后自贴钱换 LTV**
- **儿子作为副 IP**，成为群里的情感锚点
- **线下工作室 + 女性沙龙**，让"见过面的客户不会走"

### 用户生命周期迁移（切品类样板）

客户小孩长大到 3 岁后：
- **品类切换**：母婴品痛点减弱 → 切到贴身衣物、女装、包包等妈妈自己消费的品类。
- **场景切换**：妈妈们回归工作后，只有睡前才翻群，白天成交下降。
- **变现切换**：从纯卖货 → IP + 线下沙龙 + 未来直播带货 + 商业导师课运营助教。

**关键决定**：放弃"活跃度这个执念"，接受用户 LTV 到期后切场景切品类保住关系。
