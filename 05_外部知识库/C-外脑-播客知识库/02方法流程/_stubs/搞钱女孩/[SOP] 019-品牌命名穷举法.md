# [SOP] 品牌命名穷举法

## 一句话（≤ 40 字）
先定硬条件，再穷举筛出可注册可传播的名字。

## 什么时候用

- 要给消费品品牌、产品线或项目起名。
- 名字需要能被注册、能长成包装和视觉 IP。
- 不想只靠灵感和洗澡式拍脑袋。
- **红线**：不适用于只做内部代号、无需外部传播的项目。

## 输入

- 品类属性和使用场景（充盈类饮品 / 硬件 / 服务 / ...）。
- 注册可行性要求（是否已被抢注、商标类目、方言谐音检查）。
- 硬条件：字数、语感、视觉符号约束。
- 团队偏好清单（喜欢什么、坚决不要什么）。

## 输出

- 一份候选名称长名单（≥ 20 个）。
- 一份筛选理由表。
- 一个可注册、可传播、可视觉化的最终名字。

## 主流程

### Step 1: 写硬条件（不可妥协的筛子）

- 定字数（例如"3 个字不太靠谱、要 4 个字"）。
- 定品类关联要求（例如"必须能带出一种动物"）。
- 定产品属性联想要求（例如"充盈类产品要跟水相关"）。
- 做完信号：团队看到一个候选名，能秒判"过/不过硬条件"。

### Step 2: 列联想池（发散不评价）

- 围绕硬条件的核心元素做穷举——所有可以联想到的动物 / 颜色 / 动作 / 场景。
- 阶段目标是量，不是质。
- 做完信号：形成至少 50 个候选词根。

### Step 3: 做组合穷举

- 按字数和语感组合词根。
- 同步检查是否容易读、容易记、能做视觉符号。
- 做完信号：形成 20 个以上可讨论候选名。

### Step 4: 查注册与风险

- 商标检索（不同类目分别查）。
- 检索同名/近似品牌、负面联想、方言谐音、跨语言含义。
- 做完信号：候选名字不因注册或负面联想被卡死。

### Step 5: 叠加团队偏好做终选

- 在通过硬条件的候选里，允许审美和个人喜好进入。
- 偏好只做最后排序，不能覆盖硬条件。
- 做完信号：最终名字既过方法论、又保留团队真心喜欢的部分。

## 判断点 / 决策树

| 情况 | 下一步 |
|---|---|
| 好听但不可注册 | 删除 |
| 可注册但无品类联想 | 降级候选 |
| 有品类联想但不好记不好视觉化 | 回到 Step 3 重组词根 |
| 硬条件全过但团队没有一个真心喜欢 | 回到 Step 2 扩充联想池 |
| 硬条件通过且团队喜欢 | 进入终选 |

## 常见坑

- ❌ 不要只靠洗澡灵感——消费品名字必须能注册、能传播。
- ❌ 不要让个人审美先于硬条件——先过筛子再排序。
- ❌ 不要忽略视觉化——品牌名后续要长成包装和 IP。
- ❌ 不要跳过谐音/方言/跨语言检查——大众品是拿去给全国的。

## 附录：实例

"水獭吨吨"命名过程：
- 硬条件：4 个字（3 个字注册不下来）+ 快消品最好带动物 + 产品是充盈类要跟水相关。
- 联想池：把所有"跟水有联想的动物"全部列出来。
- 团队偏好：大家从表情包认识水獭、水獭有自己的节日、有人在做水獭保护。
- 最终：水獭 + "吨吨"（饮用感）= 水獭吨吨。莫莫子强调："它是相对科学的方法，只是把个人倾向、审美、爱好包含进去了。"
