# [SOP] 普通人搞钱开场四步

## 一句话

用够想 → 抱大腿 → 抄作业 → 建兵器库四步进入搞钱状态。

## 什么时候用

- 你想开始搞钱，但完全不知道从哪一步下手。
- 你已经加入了付费社群，但一直没有从"围观"变成"下场"。
- 你看到别人已经跑出来，怀疑自己是不是错过了。
- **红线**：不适用于负债兜底优先场景（先解决现金流，再谈开场）。

## 输入

- 一份"我最近很想要什么"的清单（可以是钱、可以是物、可以是身份）。
- 一份通讯录（微信好友里"目前混得比你好的人"名单）。
- 一个已经跑通的模板/案例（可以是社群里的项目，也可以是同行的做法）。

## 输出

- 一个具体的搞钱起点（一个项目 / 一个副业 / 一次合作）。
- 一次已经"抱上"的关系（作为志愿者/助理/学徒/合伙）。
- 一份专属于你的赚钱兵器库（能列出你手里的 3-5 张牌）。

## 主流程

### Step 1: 够想（把渴望具体到数字）

- 写下"我现在最想要的一件东西是 ___，价格是 ___ 元"。
- 亦仁式判据："以此为信念——白天想、晚上想"（不到这个程度就不叫够想）。
- 判断信号：一周内你至少 5 次冒出"这个东西/这个数字"的念头。

### Step 2: 抱大腿（找通讯录里最会赚钱的人）

- 打开通讯录，圈出"目前混得比你好、你能主动开口"的 3-5 人。
- 主动喊话："我看到你在做 __，我能不能做志愿者/帮忙/组员？"
- 判断信号：至少 1 人给你回复具体动作（不是"再看看"）。

### Step 3: 抄作业（找到跑通的模板并微改）

- 找到一个已经在社群里跑通的项目（例：生财有术 21 天航海）。
- 缩小规模微改成你能启动的版本（例：改成 7 天迷你航海）。
- 判断信号：能一句话讲清"我抄的是 __，我改的只是 __"。

### Step 4: 建兵器库（列你手里的 3-5 张牌）

- 列出你的：**擅长（1-2 项）+ 资源（1-2 项）+ 时间/精力可用度**。
- 用七天路过占星版本作为参照：工资钱 / 事业钱 / 投资钱 / 技能钱 / 偏财 / 房产 / 团体钱——不必信占星，但要意识到"钱路不只有工资一条"。
- 判断信号：能用一张 A4 纸画完你的兵器库，且每张牌都有具体证据。

## 判断点 / 决策树

```
Step 1 卡住 → 说明还不够想 → 先增加具体渴望的清晰度
Step 2 卡住 → 说明通讯录不够高质量 → 先加社群（参见 Step 3）
Step 3 卡住 → 说明社群选错了 → 换到"有跑通案例可抄"的社群
Step 4 卡住 → 说明还不了解自己 → 先做兵器库盘点，再回 Step 1
```

## 模板 / 清单

**开场四步动作卡**

| 步骤 | 我的填空 |
|---|---|
| 够想 | 我最想 __，价格 __，本周想过 __ 次 |
| 抱大腿 | 通讯录里的三个人：__ / __ / __，我已发消息给 __ |
| 抄作业 | 我抄的模板：__，我微改的地方：__ |
| 兵器库 | 擅长：__，资源：__，时间：__ |

## 常见坑

- ❌ 只做 Step 4 不做 Step 1——盘点自己无穷无尽，没有渴望不会启动。
- ❌ 抱大腿变成"聊天"——志愿者动作要具体（做数据/做客服/做剪辑），不是问"你能帮我看看吗"。
- ❌ 抄作业变成"发明轮子"——如果你在改核心结构，说明没在抄，是自己重新做。

## 附录：实例（黄小刀 · 生财 44268 号）

- 够想：看到风向标里所有人在讨论 ChatGPT，加上比尔盖茨判断"不亚于 PC 互联网时代的革命"。
- 抱大腿：把大纲私发给亦仁，一分钟内拿到"这个项目我投"。
- 抄作业：把生财有术的 21 天航海模板改成 7 天迷你航海。
- 兵器库：她本人 nobody（承认），但擅长打游戏 + 敢发朋友圈 + 死肥宅光脚不怕穿鞋——这些也是牌。
