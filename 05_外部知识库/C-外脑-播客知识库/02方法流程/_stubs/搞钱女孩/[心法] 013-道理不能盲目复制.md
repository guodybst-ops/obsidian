# [心法] 道理不能盲目复制

## 一句话（≤ 30 字）
复制方法前，先复制它的前提。

## 什么时候想起它

- 听到别人说"我一开始就定位高端"时。
- 看完一本书 / 一个金句，准备直接照着做投资或创业决策时。
- 看到一个成功案例，想把步骤原样搬到自己身上时。
- 面对宏观建议（如"长期看好指数基金"），准备做个人短线操作时。
- **反向触发**：当你只记住一句金句，却说不清它适用条件时。

## 具体怎么用

- 先问一句：这条建议成立时，对方手里已有多少资源、作品、现金、信任、IP？
- 再问一句：我的条件和他的条件差在哪里？差的那部分能否补齐或降级？
- 最后决定：照做、降级做、延后做，还是不做。

## 反例

看到花艺博主一开始就定位中高端，就在自己没有存款、没有作品、没有客户信任时直接报高价——**忽略了对方辞职前已有几十万存款 + IP + 作品积累**，结果没人买单。

## 常见误读

- ❌ 不要把"不能盲目复制"理解成"不要学习别人"。要学的是**前提、路径和约束**，不只是结论。
- ❌ 不要把宏观理论直接当个人短线操作建议——书上讲宏观，你用它做微观决策，是**语境错位**。
- ❌ 不要把"道理救不了我"当作放弃学习的借口，道理仍然是路径地图，只是要判断使用条件。

## 附录：原文素材

### 花艺博主定位之争（雪姨反驳）

抱抱室友是花艺定制博主，一开始就把定位打到中高端做 B 端，理由是"一开始定便宜就永远升级不了"。

雪姨反驳：这个道理**在使用者已经有前提条件时**才成立——那位博主辞职前**有几十万存款 + 已经有 IP + 有作品积累**。如果新人 freelancer 没有这些底子就直接定高价，**没有人会为你付款**。手艺人的正确路径是"**小案子建立信任 → 层层加码 → 走高**"，做生意的核心是信任和人品。

### 基金亏损的反思框架

粉丝问："我看了某本长期看好指数基金的书买了基金，收益还不如无脑买股票。" 三位主播的四层反思：

1. **信息片面**：书 / 建议 / 金句都是"某个特定环境下"的产物，没有完整前因后果。
2. **理解力差异**：同一本书不同人看到不同东西。
3. **不能自欺**：看了就能搞到钱——"大兄弟哦"。
4. **宏观 vs 微观错位**：书上是宏观理论，你却用它做个人微观投资决策。
