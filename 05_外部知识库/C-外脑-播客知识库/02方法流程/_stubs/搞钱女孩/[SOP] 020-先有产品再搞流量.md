# [SOP] 先有产品再搞流量

## 一句话（≤ 40 字）
先验证能卖什么，再让流量服务产品。

## 什么时候用

- 想做小红书 / 知识付费 / 咨询 / 副业 IP。
- 一上来就焦虑"账号不涨粉"。
- 有技能但不知道怎么"产品化"。
- **红线**：不适用于纯内容爱好账号，也不适用于"只想涨粉不想变现"的场景。

## 输入

- 你能解决的问题列表（写"帮谁解决什么"，不写"我会什么"）。
- 一个可低价试卖的最小产品（一次咨询/一节课/一个模板/一次陪跑）。
- 目标用户和最小触达渠道（朋友圈/社群/小红书私信）。

## 输出

- 一个真实有人付费的 MVP 产品。
- 一组用户反馈和可展示的成交案例。
- 后续流量内容的精准方向（内容为已验证产品服务）。

## 主流程

### Step 1: 写出可卖问题

- 不写"我会什么"，写"我能帮谁解决什么"。
- 从工作/学习/生活里找普通人不懂但你熟悉的内容（识别知识诅咒可利用点）。
- 判据："我懂的是不是超过世界普通人 60%？"——是就可卖。
- 做完信号：能写出 3 条明确的"帮谁解决什么"。

### Step 2: 做最小产品

- 把问题打包成一次咨询 / 一节小课 / 一个模板 / 一次陪跑。
- 价格先低（例如 99 元/小时），让用户容易试。
- 做完信号：产品能在 1 页内讲清楚。

### Step 3: 先卖给真实用户

- 从朋友圈、老同事、社群、小红书私信里找第一批用户。
- 不先追粉丝量，先追真实付费。
- 做完信号：有人为它**付款**（不是只说"有用"）。

### Step 4: 用案例涨价

- 每完成一个付费案例，记录问题、过程、结果、反馈。
- 有 3-5 个案例后再涨价或升级产品（99 元 → 500 元）。
- 做完信号：从低价试卖走向稳定报价。

### Step 5: 再做内容和流量

- 把用户真实问题改写成内容选题。
- 让流量服务已验证产品，而不是先烧流量再空转找产品。
- 做完信号：内容吸引的用户正好需要你的产品。

## 判断点 / 决策树

| 情况 | 下一步 |
|---|---|
| 没人愿意付费 | 回到 Step 1，改产品或改目标用户 |
| 有人付费但交付吃力 | 缩小承诺，优化交付流程 |
| 有案例但没流量 | 进 Step 5，开始把案例内容化 |
| 有流量但没成交 | 回到 Step 1，重写"帮谁解决什么" |
| 想去考证 | **先跑 Step 3-4，等付费验证再考** |

## 常见坑

- ❌ 还没产品就焦虑涨粉——流量会放大空心。
- ❌ 先考证再验证需求——可能白花时间。
- ❌ 认为自己懂的没人买——大概率是知识诅咒。
- ❌ 一开始承诺大结果——先做小交付，用交付质量攒案例。

## 附录：实例

- 龙黑黑的朋友做职业规划咨询：**99 元/小时**接单起步 → 攒够案例 → 涨到 **500 元/小时** → 反过来去考职业规划师证。顺序如果反了，"就等于前面白白把时间花进去了"。
- 龙黑黑自己：一开始"刻意无视身边的小红书需求"想专注跨境，但客户不断主动找上门；转念——"嘴边的饭我都不吃，我是不是傻？"——把重心切到小红书 IP + 训练营，8 月推出针对大厂人的知识付费训练营。
