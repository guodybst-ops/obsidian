# [SOP] 023-抄作业方法论

## 一句话

在没有原创能力时，找到细分领域交付最完善的标杆，直接复用其骨架并压缩时长。

## 什么时候用

- 你要在新领域快速做出一个可交付产品（训练营/社群/内容/店铺 SOP）。
- 你自己没有相关领域的从业经验，找不到"应该讲什么"的骨架。
- 该领域已存在被验证过、交付完整的头部产品可参考。
- **红线**：不适用于强合规、强专业门槛领域（医疗/法律/金融合规）；不适用于目标是长期壁垒的核心产品线。

## 输入

- 一个已明确的目标产品形态（例：7 天训练营 / 21 天航海 / 一个店铺）。
- 一份已被市场验证的头部作业（黄小刀例：生财 21 天航海）。
- 一套辅助工具（例：ChatGPT，用于抹平底层逻辑和模仿标杆两条学习曲线）。

## 输出

- 一份可直接开跑的骨架（航线图、日节奏、交付方式）。
- 一次能真正跑通并交付的实操。

## 主流程

### Step 1: 挑标杆——挑"交付程度最好"的作业

- 判据：**交付最详尽**（每日动作、每周里程碑、每次直播的主题都有）；不是"最火"，而是"细节最完整"。
- 判断信号：能拿到航线图 / 基础目标 / 进阶目标 / 每周节奏表。
- 反面：只有一句口号或一个爆款标题的标杆，跳过。

### Step 2: 拆骨架——把标杆的模板抽出来

- 抽三样东西：
  1. **航线图**（第 N 天做什么）。
  2. **日节奏**（每天的固定动作组合）。
  3. **交付方式**（直播/群/手册/作业）。
- 判断信号：能对着表格说清"如果我明天开营，Day 1 到 Day N 每天做什么"。

### Step 3: 压时长——把 21 天压到 7 天

- 保留骨架，减掉冗余节点：合并重复直播、压缩答疑窗口、去掉可选加餐。
- 判断信号：核心里程碑没丢，只是节奏更密。

### Step 4: 用 AI 抹平底层——补上"你原本不懂的部分"

- **两种学习**都用 AI 加速：
  1. 底层逻辑（开头讲什么、中间讲什么、如何提炼价值观、如何让听众共鸣）。
  2. 模仿标杆（把标杆内容丢给 ChatGPT 拆结构）。
- 判断信号：你能对着 ChatGPT 输出的骨架去做迁移，而不是从零试错。

### Step 5: 跑一遍 → 复盘 → 再跑

- 用抄来的骨架直接开一期（参照 [[02方法流程/_stubs/搞钱女孩/[SOP] 023-7×24小时训练营从0到百万]]）。
- 结束后一日一日拆日流水，发到最高价值圈子（也是获客钩子）。
- 判断信号：第二期能对上一期做优化，不再照抄。

## 判断点 / 决策树

```
标杆完整 → 直接抄骨架
标杆只有部分完整 → 抄可复用部分 + AI 补齐缺口
找不到标杆 → 该领域可能不适合"抄作业"路径，回到 03/04 层判断是否入场
标杆离你太远（受众/客单差三倍以上）→ 只抄结构，不抄客单价与话术
```

## 常见坑

- ❌ 以为"抄作业"是抄内容——抄的是骨架和节奏，不是文案。
- ❌ 挑最火的标杆而不是交付最完整的——火不代表可复制。
- ❌ 抄完不做日流水复盘——第二期就没有护城河。
- ❌ 抄完就想改成"自己的"——冷启动阶段先跑通，再谈原创。

## 附录：实例

黄小刀 023 集原话：**"做训练营，我最早的时候我的目标非常简单，就是抄作业。谁的作业最成功？生财的航海最成功，21 天的航海，起码是做知识付费领域里训练营里最详尽、交付程度最好的。那我自己不会写作业，因为我自己之前的确没有做过任何的训练营，那就跟着大佬抄作业就好了。他是 21 天，我把它拆到 7 天。"**
