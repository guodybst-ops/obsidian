# [SOP] 小红书先定变现方式

## 一句话（≤ 40 字）

先选变现闭环，再倒推内容赛道。

## 什么时候用

- 准备做小红书账号，但不知道发什么内容。
- 账号有内容冲动、有粉丝但赚不到钱。
- 想判断自己适合商家博主还是纯博主。
- 已经在做小红书副业，但主业还没跑通到能切换的程度。
- **红线**：不适用于只想记录生活、不追求变现的账号。

## 输入

- 你是否已有产品、服务、技能、供应链或门店（"我卖什么"的清单）。
- 可持续输出的兴趣点、经验、专业能力列表。
- 目标用户画像（他们平时买什么、在哪里被种草、客单价范围）。
- 可投入的每周更新时间与试错预算。

## 输出

- 一个明确的小红书变现类型（商家博主 or 纯博主）。
- 一张可复用的内容选题表（20 条起）。
- 一个跑通的最小成交验证动作（一条询单笔记 or 一次真实付款）。
- 一份账号包装清单（昵称/简介/首图/合集/置顶笔记）。

## 主流程

### Step 1: 盘可卖物

- [ ] 列出你能交付的产品、服务、课程、咨询、门店、手作、供应链、代理资格。
- [ ] 判断"这些东西的目标用户是否天然在小红书"。
- [ ] 有具体可卖物 → 商家博主路径；确实没有可卖物 → 转 Step 2 走纯博主路径。
- **做完信号**：能写出"我卖什么 / 给谁 / 解决什么问题 / 客单价大概多少"。

### Step 2: 定变现路径

- [ ] 商家博主路径：内容 → 询单 / 私信 / 店铺 / 线下成交，粉丝要求低，几十几百粉也能出单。
- [ ] 纯博主路径：内容 → 粉丝量 / 互动率 / 品牌广告报价，粉丝量通常需要堆到 7-8 万起才好接单。
- [ ] 选定其一，作为下一阶段的锚点，不要边做边换。
- **做完信号**：能一句话说清"我的第一笔钱从哪里来"。

### Step 3: 倒推内容赛道

- [ ] 从"用户为什么买"倒推内容，而不是从"我想发什么"开始。
- [ ] 用"兴趣点 × 可长期输出 × 可成交"三项交叉筛出赛道。
- [ ] 特别关注"用户喜欢 + 能和文化沾边 + 视觉好看"的窄品类（如文玩手串、国风饰品、寺庙文创、手工蛋糕）。
- **做完信号**：能列出 20 个既能种草又能成交的选题。

### Step 4: 跑最小成交验证

- [ ] 商家博主：发 3-5 篇能引导咨询的笔记，观察是否有真实询单和付款。
- [ ] 纯博主：先测试垂直内容的互动率与完播率，不追泛流量。
- [ ] 每一条笔记复盘：点赞收藏比、私信数、成交数、被平台限流风险（如"私信我""电话号码"这类词要避免）。
- **做完信号**：出现真实订单、真实私信，或至少一条可复用的爆文结构。

### Step 5: 迭代账号包装 + 用户提问反哺内容

- [ ] 优化昵称、简介、首图、标题、合集和置顶笔记，让用户 3 秒看懂"你能提供什么"。
- [ ] 把用户常问的问题改写成下一轮内容，用真实成交案例做背书。
- [ ] 每周固定复盘一次数据 + 用户反馈，判断是否需要回到 Step 2 调整变现路径。
- **做完信号**：粉丝主页留言从"你在哪里"变成"多少钱 / 怎么买"。

### Step 6: 主业副业切换判断

- [ ] 副业连续 3 个月有稳定成交或询单 → 进入切换准备。
- [ ] 切换前算清现金储备（至少 6 个月生活费）、家庭支持度、可接受的最大回撤。
- [ ] **不要裸辞**——先让副业跑出正反馈，再动主业。
- **做完信号**：能写出一份"什么条件成立我就切主业"的清单。

## 判断点 / 决策树

| 情况 | 下一步 |
|---|---|
| 有产品/服务但粉丝很少 | 走商家博主路径，用几十几百粉试成交 |
| 没产品但内容力强 | 走纯博主路径，先做垂直粉丝和互动率 |
| 有兴趣但找不到成交路径 | 回 Step 1 找可卖物 / 可接单能力 |
| 内容有流量但没钱 | 回 Step 2 重设变现闭环 |
| 副业无真实付款 | 回 Step 4 换选题或改主页包装 |
| 副业连续 3 月有稳定收入 | 进入 Step 6 切换判断 |

**账号包装 5 件套**：昵称 → 简介 → 首图 → 合集 → 置顶笔记，五个位置必须一眼说清"你能提供什么"。

## 常见坑

- ❌ **不要先追爆款再想怎么赚钱**——爆款和变现可能完全脱节。
- ❌ **不要把粉丝数当唯一指标**——商家博主几十粉也可能成交。
- ❌ **不要没有产品却硬做商家博主**——会变成空转种草，卖不动。
- ❌ **不要一上来就发"私信我"、留电话号码**——会秒被官方限流。
- ❌ **不要裸辞创业**——先跑出最小正反馈再动主业；单打独斗、没资源的裸跳后期一定难。

## 附录：实例

### 谢无敌自己的家居账号（商家博主路径）

- 2021 年 3 月开号，家居设计师 IP，服务家里在红星美凯龙的三家实体店。
- 第一个月引流一个客户到线下变现 10 万；第二个月引流设计服务 + 产品采购，变现 200 多万。
- 3 个月正反馈跑通后，6 月辞职，7 月创办闪电猫传媒。

### 隐藏赛道：文玩手串 / 国风饰品 / 寺庙文创（商家博主路径）

社群里做这类的博主，几十几百粉也能开单，一个月可以做到 20 万营收。核心逻辑：**用户喜欢 + 能和文化沾边 + 视觉好看**，客单价中等（几十到几百），复购率不算高但目标用户足够精准。

### 星球会员案例（多路径）

- **教育培训小编**：几千月薪 → 帮公司做小红书证书培训账号 → 2 年后年薪 50 万 + 新项目 5:5 分成（**商家博主 + 转合伙人**）。
- **蛋糕店高芬**：前台四五千工资 → 做手工蛋糕小红书 1.5 年 → 虹口开自己的店（**商家博主 + 高客单价窄品类**）。
- **大三学生"射婷学姐"**：成长博主，一单商单几百到 2000 元 + 代运营副业（**纯博主 + 商单**）。
- **宠物博主"阿条和铁锤"**：辞职后做到 5 万粉，双 11、618 单月收入顶过去一整年打工年薪（**纯博主 + 平台大促**）。

**共同特征**：愿意改变自己 / 执行力强 / 愿意和一群人一起努力。
