# HF0式增长冲刺法

## 一句话

在12周内暂停常规工作，将团队置于一个重新设计的时间、空间和规则容器中，只聚焦一个核心目标（通常是收入增长），通过每周结果汇报、peer pressure和极简目标建立信念感，实现平时难以达到的增长速度。

## 怎么用

### Step 1：设定唯一核心目标

目标必须极度简单，最好就是一个数字。例如：
- 月收入从8万→50万美元
- 周环比增长从2%→20%
- DAU从1000→10000

关键原则：不能中途换目标。HF0创始人坚持ACE Studio必须盯收入，换目标只是害怕和妥协。

### Step 2：设计容器（时间+空间+规则）

**时间**：12周封闭周期。暂停常规工作——不参加外部会议、减少客户拜访、推迟非紧急功能开发。

**空间**：一个与日常隔离的物理环境。可以是硅谷的house（HF0原版），也可以是在惠州租的海景house（ACE Studio复刻）。核心是打开门就感到"这里不一样"。

**规则**：
- 每周一demo dinner：2分钟向所有人讲本周结果（不是讲"做了什么"而是"结果数据"）
- 每周二check-in：半小时讨论目标、指标和阻塞
- Data by dinner文化：早上有想法，晚上看数据

### Step 3：穷举方案按概率测试

当增长停滞时：
1. 穷举所有可能的增长方案（至少20个）
2. 按成功概率从高到低排序
3. 从最高概率方案开始逐一测试
4. 先试最快的：涨价是最容易测试的方案（改价格→看日收入变化）

### Step 4：多线叠加形成爆发

单条增长线不够——需要多条线同时见效：
- 定价实验（不同价格点、取消试用、改变付费模型）
- 规模化influencer营销（从月几十个→日100个，建立SOP）
- 广告放大（把表现好的influencer视频投入付费广告）
- 老用户召回（每次产品升级后给流失付费用户发邮件）
- 产品升级（持续提升核心能力）

### Step 5：周期性复刻

HF0式的强度不可持续——可以在研发周期和增长周期之间交替：
- 某段时间只关心增长（HF0模式）
- 某段时间只关心研发突破（封闭研发）
- 关键不是持续高压，而是在特定周期内让团队进入"规则不同、目标单一、每周拿结果"的状态

## 完整示例

以ACE Studio在HF0的经历推演：

```
前五周（低谷期）：
- 目标：月收入8万→50万
- 实际：每周只增长1-2%
- 隔壁团队每周增长30-40%，peer pressure巨大
- 一度想换目标，被HF0创始人否决

第六周（转折点）：
- 穷举增长方案，第一个试"涨价"
- 涨价50%：日收入增长约40%
- 涨价100%：日收入增长约60%
- 选择涨价50%方案（增长最大化的点）

第七-十二周（爆发期）：
- 继续测试定价：取消试用、取消月卡改季度卡
- 建立influencer机器：从月几十个→日100个联系
- 表现好的视频投付费广告放大
- 产品升级后召回流失付费用户
- 结果：月收入从8万→约80万（10倍增长）
```

## 适用场景与边界

**适用场景**：
- 已经找到PMF、需要加速增长的AI应用/SaaS团队
- 团队规模10-50人，可以灵活调整工作模式
- 需要打破"合理但缓慢"的增长节奏

**局限性**：
- 不适合0-1阶段还在找PMF的团队（目标还不清晰）
- 极强的peer pressure可能导致团队burnout
- 高度依赖创始人/核心团队的信念感和执行力
