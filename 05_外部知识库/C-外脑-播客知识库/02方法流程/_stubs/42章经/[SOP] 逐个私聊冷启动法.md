# 逐个私聊冷启动法

## 一句话

在社区/平台上一对一私聊潜在用户的冷启动方法。不是投广告或做内容，而是找到早期种子用户聚集的地方，逐个手工联系，直到积累出第一批核心社区。适用于 To C 社区/平台类产品的冷启动。

## 怎么用

### Step 1：定位早期种子用户在哪里

找到目标用户聚集的已有社区和平台。不一定是大平台，而是**你的品类里的早期采纳者**在讨论什么、在哪里讨论。

Jay 的做法：Discord、Reddit、X。具体判断标准：只要有在任何 server 发过 Prompt 的人，就是潜在用户。

### Step 2：逐个私聊

不是发公告、不是建群拉人，而是**一个一个私聊**。内容要点：
- 简短的自我介绍
- 说明你在做什么（"有这么一个社区"）
- 邀请对方来看看
- 语气真诚，不是营销话术

Jay 累计私聊数千人，最早 500-600 人是这样拉来的。

### Step 3：接受负面反馈

有人会骂你做的是屎。这是正常的。留下来的才是真正有需求的种子用户。不要因为负面反馈放弃，而是坚持联系足够多的人，直到门槛用户量达到。

### Step 4：种子用户拉种子用户

第一批核心用户产生后，他们会在所在社区自发传播，产生第二波自来水增长。

### 关键原则：不规模化的事，做到极致

Jay 引用 PG 的 Do Things That Don't Scale：在早期不追求规模化手段，手工做那些「不能规模化」的事，直到 PMF 信号出现。

## 完整示例

以 FlowGPT 冷启动推演：

| 阶段 | 操作 | 结果 |
|---|---|---|
| 定位种子用户 | Discord 上搜索所有发过 Prompt 的 server 和用户 | 识别出数千个潜在用户 |
| 逐个私聊 | "你好，我在做一个 Prompt 社区，可以来看看" | 有人骂，有人来 |
| 累计 | 持续私聊直到累计 500-600 人 | 形成第一批核心社区 |
| 自传播 | 种子用户开始在 Discord/Reddit/X 上自发传播 | 第二周出现强自传播性 |
| 验证 PMF | 用户量暴涨 → 决定辍学 all in | 确认社区模式成立 |

## 适用场景与边界

### 什么时候用
- To C 社区/平台类产品冷启动
- 目标用户分散在已有社区中
- 品类早期，没有现成的获客渠道
- 产品形态已经可展示（即使很简陋）

### 什么时候不用
- 需要大规模付费投放的品类（如电商）
- 目标用户没有明确的聚集社区
- B2B 企业级产品销售（需要更结构化的销售流程）
- 用户量需要瞬间突破的商业模式（如 O2O）

### 已知局限
- 极其耗时，不适合追求快速上量的场景
- 依赖创始人/核心团队的个人时间和精力
- 心理门槛高——需要接受大量冷遇和拒绝
- 只适用于早期阶段，规模化后需要切换获客方式
