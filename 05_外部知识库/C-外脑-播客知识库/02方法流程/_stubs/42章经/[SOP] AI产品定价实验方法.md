# AI产品定价实验方法

## 一句话

通过系统化的定价实验（而非凭感觉定价），把价格、付费模型和增长系统作为商业模式的一部分来测试，而不只是产品开发的附属品。

## 怎么用

### Step 1：穷举增长方案，按概率排序

列出所有可能带来增长的方案（类似Quora当年列出20个增长方案），按成功概率从高到低排序：
1. 涨价（最容易测试，见效最快）
2. 改变付费模型（如取消试用、取消月卡、改为按结果付费）
3. 优化定价结构（不同的价格层级）
4. 增长渠道优化
5. 产品升级

### Step 2：逐一测试

从概率最高的方案开始：
- 设定三组不同价格，同时测试
- 观察日收入变化（不只是转化率）
- 涨价后如果收入同比例增长，说明原来定价偏低
- 不断测试直到找到收入最大化的定价点

### Step 3：与其他增长手段叠加

- 定价优化 + influencer增长 + 广告放大 + 老用户召回 + 产品升级
- 多条线同时见效，形成增长爆发
- 每次产品升级后发送邮件召回流失付费用户

## 完整示例

以ACE Studio的定价实验推演：

```
初始状态：月收入约8万美元
定价实验方案：
- 方案A：原价（对照组）
- 方案B：涨价50%
- 方案C：涨价100%

第一天结果：
- 方案B：日收入增长约40%（涨价50%只损失少量用户）
- 方案C：日收入增长约60%（涨价100%损失更多用户但仍净增长）

结论：原有定价偏低，选择方案B（增长最大化的点）

后续实验：
1. 取消试用期 → 减少白嫖用户，ARPU提升
2. 取消月卡改为季度卡 → LTV提升
3. 多层级定价 → 满足不同需求用户

结果：月收入从8万→约80万（含其他增长的叠加效应）
```

## 适用场景与边界

**适用场景**：
- AI应用/SaaS产品的商业化早期阶段
- 已有一定用户基础和PMF验证的产品
- 需要快速提升收入的增长阶段

**局限性**：
- 需要足够用户量才能做A/B测试 [AI推理]
- 涨价可能导致团队自满、不再优化产品价值
- 仅适用于已找到基本PMF的产品，不适合0用户阶段
