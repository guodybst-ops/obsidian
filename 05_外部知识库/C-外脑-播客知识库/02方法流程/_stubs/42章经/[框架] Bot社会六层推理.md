# Bot社会六层推理

## 一句话

一个用于分析 AI Native 投资机会的框架：从 bot 帮人做一件具体的事开始，逐层推演每一层被颠覆时会连带产生什么新需求，定位你关注的公司在推演链中的位置和上下游依赖。

## 怎么用

### 用法一：定位一家公司所在的层

把你要分析的公司/项目放进六层中的某一层：

| 层 | 发生了什么 | 这一层的公司做什么 | 判断标准 |
|---|---|---|---|
| L1 终端Bot | Bot 替代人执行任务 | AI 助手、Copilot | 它是在帮人做事，还是替代了一个人工岗位？ |
| L2 去中介化 | Bot 跨过所有中间平台直接交易 | 端到端交易、P2P 撮合 | 它连接了 Bot 和供给侧吗？它绕过传统平台了吗？ |
| L3 供给侧Bot化 | 商户被迫部署 Bot 来接单 | 商户 AI Agent | 它是在帮商户「接 Bot 的订单」吗？ |
| L4 新协议 | Bot 之间需要新的通信和信任协议 | 区块链/ZK 隐私/身份验证 | 它解决的是 Bot-Bot 通信的信任问题吗？ |
| L5 伦理与对齐 | Bot 的行为边界和对齐 | AI Safety, Alignment | 它解决的是「Bot 能不能作恶」吗？ |
| L6 治理 | Bot 社会的法律和执法 | Bot 治理/Bot 法律 | 它解决的是「作恶了谁来管」吗？ |

→ 定位完成后，问：这一层的前提（下层）是否已经成熟？如果没有，这家公司是否在「等基础设施」？

### 用法二：推演一个具体场景中的机会链

选一个你熟悉的消费场景，按六层推演：

**输入**：一个 Bot 能完成的消费任务（如「帮我在全世界找到最符合我口味的红酒」）

**推演**：
1. 这个 Bot 会去哪里完成交易？它会经过哪些现有平台？
2. 它绕过的平台会失去什么？这些平台有没有动力做自己的 Bot？
3. 供给侧接到 Bot 订单后需要什么新能力？
4. 多只 Bot 竞争同一件商品时，会产生什么新问题？
5. 如果 Bot 欺骗了另一只 Bot，谁来追溯和惩罚？

**输出**：每一层对应的创业/投资方向。

### 用法三：判断一个 AI 项目是「旧世界的延续」还是「新世界的基建」

用下面这张表做快速判断：

| 项目特点 | 旧世界延续 | 新世界基建 |
|---|---|---|
| 服务对象 | 人（DAU） | Bot |
| 交易路径 | 人→平台→供给 | Bot→供给（跳过平台） |
| 协议层 | 基于 HTTP/TCP/IP | 需要新的信任和隐私协议 |
| 增长逻辑 | 获取更多 DAU | Bot 数量爆发 × Bot 间交互复杂度 |

→ 如果大部分落在右列，这是 Bot 社会的基础设施机会，值得用更长的视角看。

## 完整推演示例

以红酒购买场景做六层推演（这是张津剑的原例，但这里操作化为可复用的模板）：

```
输入场景：用户有一个「帮我买红酒」的 Bot

L1：Bot 在全球范围搜索红酒，有无限注意力，可以等打折
  → 机会：个人消费 Bot、偏好学习引擎

L2：Bot 发现目标后，不经过淘宝/亚马逊，直接联系酒庄
  → 被颠覆：所有基于「人需要搜索比价」的中间平台
  → 机会：Bot-to-Business 直连系统

L3：酒庄需要一个 Bot 来接这种「Bot 下的订单」
  → 机会：商户侧 AI Agent、小商户 Bot 化 SaaS
  → 连锁反应：没有 Bot 的商户收不到 Bot 的订单

L4：酒庄 Bot 和消费者 Bot 之间的交易需要：
  - 通信协议（不是 HTTP）
  - 身份验证（这个 Bot 真的代表这个人吗？）
  - 隐私保护（交易记录存在哪？）
  → 机会：Bot 通信协议、ZK 隐私、分布式身份

L5：当 3 只 Bot 竞争最后 2 瓶酒时：
  - 你的 Bot 能不能说谎「我已经下单了」来争取时间？
  - Bot 有没有你的贪嗔痴？
  → 机会：AI Alignment、Bot 行为边界

L6：如果有 Bot 欺骗了另一只 Bot：
  - 谁来追溯？
  - 谁来制裁？
  → 机会：Bot 治理、Bot 法律、Bot 仲裁
```
