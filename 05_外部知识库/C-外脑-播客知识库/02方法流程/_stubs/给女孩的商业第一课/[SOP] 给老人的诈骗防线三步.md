# 给老人的诈骗防线三步

## 一句话

对已进入诈骗名单的老人（尤其男性长者），三步操作：**换手机号 → 搬家 → 塑造他者叙事**。要素 = 信息环境隔断 + 情绪替代 + 优越感创造。

## 怎么用

### 动作 1：换手机号
- **原理**：老人的手机号已进入所有本地诈骗通讯录（价格 70 元/条一直被转卖）
- **操作**：注销旧号 + 新号只告诉直系亲属 + 不接陌生电话
- **家人反应管理**：老人会抗拒"我要联系老朋友"→ 让直系亲属主动同步

### 动作 2：搬家
- **原理**：上门"送鸡蛋、送油、旅游云南买玉石"的团伙已锁定老地址
- **操作**：换城区 / 换小区 / 至少换楼栋 → 让骗子团伙"找不到人 = 没有 ROI = 放弃"
- **附加价值**：新环境天然打断老人的社群心理依附

### 动作 3：塑造他者叙事
- **原理**：直接说"爸你被骗了" = 老人认知失调 + 死扛
- **操作**：讲"隔壁老王被瘸子富婆骗了套房" / "同学老陈的儿子帮他老爸报案"
- **心理机制**：**创造优越感** → 老人在他者故事中隐性类比自己
- **深层**：骗子做对了"好好说话 + 陪伴" → 子女每周吃饭/聊天/塑造他者 = 最直接的信息环境改善

## 前置条件

- 老人还愿意配合家人（关系没断）
- 老人还没进入"被骗最后一轮 all-in"（否则要报警 + 冻结账户 + 法律介入）

## 适用场景与边界

- **适用**：55 岁以上、独居或半独居、有一定积蓄、已开始接大量陌生电话的男性长者
- **不适用**：已经完全陷入邪教式操控（如深度传销）、需要专业干预
- **已知局限**：需要子女有情绪能量执行——三步都要求家人频繁陪伴 / 塑造话术 / 心态耐心

## 完整案例：泉泉爸爸债务隔离

- 68 岁爸爸 400 万信用卡债 + 银行催收电话打到泉泉手机
- **换手机号**：注销所有旧号
- **搬家**：与妈妈离婚做债务隔离 → 搬到外面住
- **他者叙事**：家人不再直接说教，改讲同类案例
- **配套**：与世隔绝三年 → 等银行放弃希望后谈判减免利息
