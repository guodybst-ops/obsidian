# Top Sales 反向学习法（骗子视角）

## 一句话

**把每次被骗当学费，反向研究"骗子做对了什么"**。若能把骗子在"建立信任 / 制造稀缺 / 情绪操纵"三维度做对的操作学到手 + 用在合法产品上 = Top Sales。

## 怎么用

### 步骤 1：把被骗还原为骗局技术清单

对每次被骗（或听到别人被骗）做拆解：

- **建立信任维度**：骗子做了什么让你相信？
  - 例：瘸子富婆天眼查显示"某银行家夫人" + 奔驰大 G + 只送鸡蛋不送凡克雅宝
- **制造稀缺维度**：骗子如何制造"过时不候"？
  - 例：雪球 DMA 5000 万容量上限（"更大规模的资金进不来抢生意"）
- **情绪操纵维度**：骗子在什么情绪弱点上下手？
  - 例：55 岁男性长者 = "不允许自己失败" + "希望自己聪明过朋友"

### 步骤 2：抽取通用技术模块

从多个案例中抽公共模式：
- **数字锚定**：真实估值 200 万的画 → 报 500 万 + 切成 500 万份 × 1 元/份
- **社会证明**：先请一批小规模真实赚钱案例做背书
- **反脆弱伪装**：把"高杠杆"包装成"200 只股池分散 + 大盘期权对冲"

### 步骤 3：只把合法可用的部分用在自己产品上

- **可用**：建立信任的所有细节（个人形象、社交证据、真诚沟通）
- **可用**：情绪触点的洞察（客户真正在意什么）
- **禁用**：制造虚假稀缺 / 隐瞒风险 / 违反监管 / 一对一 close 时的情绪勒索

## 前置心态

**对骗子有怜悯之心**：看到销售的难处 → 你就知道**他说的话不是内心的话，是结构逼的**。这份怜悯是本方法的伦理底线——你学的是技术，不学人格。

## 完整案例：斯斯延伸

斯斯把本方法总结为播客标题："**像骗子一样研究自己**"——
- 研究骗子对高净值女性的话术 → 优化自己对高净值女性的付费转化
- 研究骗子的"陪伴 + 好好说话" → 应用到复购老客户维护

## 适用场景与边界

- **适用**：销售 / 服务 / 内容付费 / 私域运营 / 品牌营销
- **不适用**：需要建立长期信任的关系型业务（如律师 / 医生）——短期骗术会摧毁长期口碑
- **心理陷阱**：容易把"骗子做对了什么"和"我应该像骗子"混淆——必须持续用步骤 3 的伦理筛过滤
