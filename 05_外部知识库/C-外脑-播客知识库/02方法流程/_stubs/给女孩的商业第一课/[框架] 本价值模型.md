# 本价值模型（成本-价格-价值）

## 一句话

判断一件事该不该干看三样：成本、价格、问题价值。铁律——成本必须小于价值。价格在两者之间浮动，消费者剩余（价值-价格）越大产品越有竞争力。

## 三要素定义

- **成本**：完成这件事需要投入的钱、时间、机会成本
- **价格**：客户实际支付的数字
- **问题价值**：这件事解决了客户多贵的问题（用客户时间成本、机会成本量化）

## 铁律

```
成本 < 价格 < 价值
消费者剩余 = 价值 - 价格
利润 = 价格 - 成本
```

- 如果价值 < 成本 → 这件事不该干
- 如果消费者剩余小 → 竞争力弱
- 如果利润被压 = 内卷（成本没变，价格降低）
- 如果成本降低 = 创新（更便宜方式解决同问题）

## 怎么用

### Step 1：列出三个数字

- 成本：X 元（含时间和机会成本）
- 价格：Y 元
- 价值：Z 元（客户如果不用你，需要多少钱解决同一问题？）

### Step 2：检验是否成本 < 价值

- 是 → 可以做
- 否 → 停下来重新设计成本或价值

### Step 3：区分内卷和创新

- 利润下降是因为成本没变、价格被压 → 内卷
- 利润下降是因为找到更便宜的办法解决同问题 → 创新

### Step 4：量化问题价值

- 客户如果不用你，需要多少钱？
- 需要多少时间？
- 会错过什么机会？

## 完整示例

### 案例1：同一件西装

- 通勤穿：价值 300 元
- 面试穿：价值 3000 元（因为可能拿到高薪 offer）
- 结婚穿：价值 30000 元（因为解决终身大事的仪式感）

同一件西装，问题价值不同，价格上限不同。

### 案例2：CES 机器狗 vs 人形机器人

- 机器狗：四条腿稳定，能驮东西检查煤气管道（贵的问题） → 成本 < 价值 → 可以卖
- 人形机器人：两条腿平衡难，只能表演武术 → 成本 > 家庭清洁的价值 → 目前难卖

## 适用场景与边界

- **适用**：定价决策、创业方向判断、B2B 咨询
- **不适用**：情绪价值主导的品类（成本-价值关系不成线性）
- **已知局限**：事前判断"问题价值"往往靠估计，不同人估法不同
