# 论迹不论心复盘法

## 一句话

每周每月只复盘"我做了什么、种下什么"，不复盘"我心情怎样、动机对不对"。

## 什么时候用

- ✅ 你在做【种子法则四步法】，需要**每周核对**种下了什么
- ✅ 你的复盘习惯偏向**"我是不是不够努力 / 我心态是不是不好"**——总卡在情绪层
- ✅ 你**持续 > 3 年在一件事上没有正反馈**（收入 / 用户 / 关系任一维度持续持平或下滑）
- ✅ 你能每周固定 20 分钟、每月固定 60 分钟复盘
- **红线**：**不适用于**初创前 2 年（数据太少，会误判方向）；**不替代**必要的情绪疏导（找朋友聊、找咨询师）；**不适合**追求"过程即意义"、不愿看结果的人

## 输入

- **每周 20 分钟**（固定周日晚上或周一早上）
- **每月 60 分钟**（固定每月最后一天）
- **1 张周复盘表** + **1 张月复盘表**（用下方模板）
- **上一周的每日签到**（四时冥想 / 种子卡 / 角落人练习等打勾记录）

## 输出

- **1 张周复盘表**（每周产出，贴桌前）
- **1 张月复盘表**（每月产出，存档）
- **≥ 3 年无正反馈事项清单**（如触发）+ 1 条反直觉调整
- **完成信号**：连续 4 周产出 4 张周表 + 1 张月表，且能一句话说清"这个月我主要种了什么、砍了什么"

## 主流程

### Step 1：列上周动作，不评价（周日 5 分钟）

- [ ] 打开周复盘表，回顾**上周实际做过的具体动作**（有日期、有对象、有产物）
- [ ] **只写"迹"，不写"心"**——写"周三给 A 发了资料"，**不写**"周三本来很累但坚持做了"
- [ ] 遗漏就遗漏，不补录心情理由
- **判断信号**：整段全是**动词 + 对象**，没有"因为 / 但是 / 其实我"

### Step 2：标记种子颜色（周日 5 分钟）

- [ ] 逐条给动作贴标签——**只贴 3 种颜色**：
  - 🟢 好种子（分享 / 撮合 / 关照角落人 / 承诺陪伴 / 帮记起好事）
  - 🔴 坏种子（挑拨 / 内心批判 / 抱怨 / 应付敷衍 / 心情好才做）
  - ⚪ 中性动作（跟种子无关的日常）
- [ ] 数一数本周：🟢 __ 条、🔴 __ 条、⚪ __ 条
- **判断信号**：能说出"本周好种子最多的是 XX 类、坏种子最多的是 YY 类"

### Step 3：定 1 条反向动作（周日 5 分钟）

- [ ] 找出本周 🔴 最多的那一类，写出**下周要做的 1 条反向动作**：
  - 挑拨 → 说 1 句撮合的真话
  - 内心批判同事 → 每天为 1 位同事的 1 件好事默默肯定
  - 心情好才陪对方 → 定 1 个准时锚点（"每周三 20 点电话 30 分钟"）
- [ ] **不问"我下周动机是不是纯"**——只承诺具体动作
- **判断信号**：下周动作**能被别人核查**（有具体时间、对象、可打勾）

### Step 4：每月检查"3 年无正反馈"事项（月末 30 分钟）

- [ ] 列出**你持续做了 > 3 年**但**任一维度（收入 / 用户 / 心情 / 家庭）持续持平或负向**的事
- [ ] 对每一项，回答 3 层判断（**只填一层，不做辩护**）：
  1. 错在**方向**（做的方向本身不对）？
  2. 错在**品类**（方向对但选错了对象/领域）？
  3. 错在**势**（外部时机不对，不是自己努力问题）？
- [ ] 找出一条**反自己直觉**的调整（一直想加 → 试着砍 90%；一直想当好人 → 承认好人身份反而伤到亲人）
- **判断信号**：调整能一句话讲清、下个月就能开始做；**不出现**"如果我更努力会不会好"这类问句

### Step 5：月末咖啡冥想 + 帮身边人记起好事（月末 15 分钟）

- [ ] 月末最后一晚做一次**加长版睡前咖啡冥想**（15 分钟）
- [ ] 回想本月**给自己的 3 颗好种子**——为它们默默庆祝一下
- [ ] 挑 **1 位身边人**（伴侣 / 父母 / 同事），**帮他 / 她记起过去的一件好事**——发信息或电话说给对方听
- [ ] 在月表底部写一句话："**本月我最珍贵的种子是 ____**"
- **判断信号**：对方回复了"哇你还记得" / 你自己睡意上来时嘴角是松的

## 判断点 / 决策树

```
写周表时不断写"因为 / 但是" ──→ 停下，只保留动词+对象
                              ↓
🔴 坏种子占比 > 50% ──────────→ 下周只做 1 条反向动作，别贪多
                              ↓
连续 4 周 🟢 都 < 3 条 ───────→ 检查是不是"心情好才做"；四时冥想复位
                              ↓
月末发现"3 年无正反馈" ───────→ 走 Step 4 三层判断，别再问"是不是我不够努力"
                              ↓
心态滑向"我这个人不行" ───────→ 停手，别复盘了；那是情绪不是种子
                              ↓
月末发现主线开花 ─────────────→ 继续种，别换赛道；同类第二颗可以起
```

## 常见坑

- ❌ **复盘变成情绪日记** → 写心情、写委屈、写"其实我很努力"——都不算本方法；周表只留动词+对象
- ❌ **一次月复盘就想彻底改命** → 反直觉调整每月只做 1 条，坚持 3 个月再看
- ❌ **只回顾今天做错的事** → 是给坏种子浇水；每周至少写出 1 件好种子并庆祝
- ❌ **把"3 年无正反馈"套用在 1-2 年的事** → 短周期看不出方向对错，会误判
- ❌ **滑向"我这个人不行"** → 应保持在"我这个方向 / 品类 / 势不行"层面；上升到人格层就停手

## 附录 A：来源背景

- **醉鹅娘 064**：曾明教授对负债 5600 万的醉鹅娘说："你唯一证明过成功的是做自媒体，做战略决定要黏糊不了。"醉鹅娘承认："**过去我一直很努力，从结果角度没有正反馈，那么努力这件事一定是错的**。"她把"做几条线"改成"只做自酿酒"——这是**看结果不看动机**的原型。
- **陈唐 098**：睡前咖啡冥想 = 回想并庆祝今天做的好事，喜悦是好种子的水分；帮身边人记起做过的好事 = 加速他们的好种子打开（陈唐母亲餐厅给僧人做饭的故事）。
- **陈唐 099**：**坐上修**（座上冥想）只是 30 分钟；**坐下修**的 23.5 小时里如何管理念头、语言、行为，才是真正种种子的时候——所以复盘要看那 23.5 小时里的**迹**。

## 附录 B：与"传统 KPI 复盘"的区别

| 维度 | 传统 KPI 复盘 | 论迹不论心复盘（种子系） |
|---|---|---|
| 关注对象 | 数字达成率、目标偏差 | 每周种下的种子颜色 |
| 反思焦点 | "我哪里没做好 / 心态是不是不够坚定" | "我做了什么迹 / 种了什么种子" |
| 期望周期 | 本月 / 本季度看结果 | 一周种、一周开花，长线 3-6 个月 |
| 情绪出口 | 容易陷入自责 / 焦虑 | 每周至少 1 次庆祝，月末冥想收敛 |
| 主动权归位 | 依赖外部反馈 | 复盘"我种了什么"，回到主体 |

## 附录 C：完整案例（醉鹅娘 12 年复盘）

- 12 年连续创业 + 3 亿营业额 + 200 人团队
- **结果**：负债 5600 万、抵押妈妈的房子、公司走向巨婴
- 曾明教诲："**你唯一证明过成功的是做自媒体。做战略决定要黏糊不了。**"
- 醉鹅娘承认："**过去我一直很努力，从结果角度没有正反馈，那么努力这件事一定是错的**。"
- **反直觉调整**：从"我要做几条线"改成"**只做自酿酒**"
