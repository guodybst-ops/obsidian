# 携修出海三合一

## 一句话

"携修" = **中国特别擅长的事 + 老外特别不擅长的事 + 强英语 / 当地语言能力**，三者相加。这是林国宇 094 集给中国留学生 + 打工人 + 厂二代出海的最粗最有效公式——**不要出海去学商科，出海去带一支中国队伍去落地**。

## 为什么这么做

- 中国现在占全世界工业产值 40% 以上，产业工人每年新增供给占全球 70% 以上，**国内已经消化不完**——工业出海是国家级方向
- 中国留学生绝大多数走了"泛泛学商科 / marketing"路线，回国找不到工作，出海也扎不下根
- 真正稀缺的是**懂中国工业 + 懂英语 + 懂当地规则**的三合一人才——这种人是国外新能源电池厂 / 中餐连锁 / 药企出海 / 一带一路投资的关键节点
- 一个厂二代出海立足了，家族企业才能出海立足——**"没有谁比自己的孩子更值得信任地放在海外"**

## 三合一公式

| 变量 | 含义 | 举例 |
|---|---|---|
| **中国擅长** | 你在中国是稀缺技能 | 8 级钳工、数控机床、精密制造、中式餐饮、供应链管理、直播电商、连锁品牌运营 |
| **老外不擅长** | 目标国的短板 | 欧美产业工人稀缺、当地不会做中餐连锁、欧美对亚洲供应链不熟悉 |
| **语言能力** | 英语 / 当地语言 | 至少雅思 7 分或当地小语种流利 |

**乘积效应**：三者相乘产出——"雅思 7 分 + 8 级钳工 + 打遍天下无敌手"。

## 操作步骤

### Step 1：识别中国稀缺技能池
盘点自己或家族在中国有什么"老外没有"的能力：
- 制造业：数控 / 焊工 / 机加 / 精密制造 / 电池 / 光伏
- 内容 / 电商：短视频 / 直播 / 私域 / IP 运营
- 消费品：中餐连锁 / 中式养生 / 中医
- 供应链：报关 / 集装箱运营 / 跨境物流

### Step 2：对准出海目的地
不要默认美国。参考"十四五 / 十五规划"和一带一路：
- **蓝海**：非洲（尼日利亚、肯尼亚、埃及）、拉美（阿根廷、巴西）、金砖国家
- **中海**：越南、印尼、马来西亚（供应链腹地）
- **红海**：美国、欧洲（法律成本高，落地难，但产值大）

### Step 3：语言能力强化到"可工作"
- **不是"能考试"级别**，是"能开会、能签合同、能骂人"级别
- 至少 6 个月的强化学习
- 目的国是非英语国家（越南 / 印尼 / 拉美），学**当地小语种**优先级高于再刷英语

### Step 4：走"厂 + 带留学"复合路径
094 集林国宇的核心公式：
- **不要泛泛学 supply chain / marketing**
- 学"家族产业上下游 + 当地规则"——学的是**怎么在那边落一个厂**：过多少城审批、搞定几个议会、给多少环保组织交钱
- 参考福耀玻璃美国厂纪录片：机床运过去 / 建厂只是万里长征第一步

### Step 5：搭队伍出海（不是自己出海）
- **打包一支中国工人 / 工程师小分队一起过去**
- 出海后微信群继续用——沟通语言仍是中文
- 不用当地人做核心岗，用当地人做**审批 / 关系 / 合规**接口

### Step 6：小国 + 央企国企资源嫁接
如果去小国留学（尼日利亚 / 肯尼亚 / 埃及）：
- 主动接触当地大使馆 / 华人华侨 / 央企办事处
- 一号 / 二号首长来访时，主动做产品化自我介绍
- 目标：成为**当地包打听**——不是打工，是解决问题

## 判断指标

- **短期（1 年）**：语言流利到能开会 + 已识别 3 个中国稀缺技能池
- **中期（3 年）**：在目的国建立一个可落地的项目 / 工厂 / 门店
- **长期（10 年）**：能把中国工人小分队打包过去，成为当地某赛道第一把交椅

## 边界

- **不适用**：完全不做实业、纯学术 / 纯艺术方向的孩子
- **警惕**：光有语言没有中国稀缺技能——变成中介，最容易被替代
- **警惕**：光有技术没有语言——变成打工人，进不了核心决策
- **不要浪漫化**：非洲有狮子、印度有种姓、越南要 51% 本地股份——落地都是苦活

## 反直觉点

- ❌ 出海是躲避国内内卷 —— 错。**是国家级战略溢出，跟着国家投资方向走**
- ❌ 学商科出海 —— 错。**技术类 + 当地规则**才是稀缺
- ❌ 学好当地文化最重要 —— 错。**先把中国稀缺技能带过去**，再理解当地
- ❌ 一个人闯天下 —— 错。**打包中国团队一起过去**
