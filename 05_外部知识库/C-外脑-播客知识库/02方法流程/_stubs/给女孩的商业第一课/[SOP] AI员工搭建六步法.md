# AI 员工搭建六步法

## 一句话

把可稳定执行、能自我迭代的 AI 工作流当成组织里的"硅基员工"。搭建路径：现场观察→拆最小单元→做样本对→训练 skill→龙虾调度→上线迭代。核心动作是让业务大拿而不是技术专家来训练。

## 六步流程

### Step 1：回到事故现场

- 别听同事口头描述"AI 做不了"
- 打开电脑，看真实鼠标怎么点、文件在哪、聊天记录长什么样
- 记录每一步操作和判断（这一步花了多少秒？为什么这么做？）

### Step 2：拆最小可执行单元（skill）

- 每个 skill 是一个"最小稳定执行单元"
- 比如"炒股龙虾"拆成：行情查询/分析师观点/持仓/止盈止损/复盘 5 个 skill
- Skill 之间可组合，独立可测试

### Step 3：做样本对（好 vs 差）

- 找出你手头 10 个好稿 + 10 个差稿
- 让 AI 对比总结差异 → 抽取"隐性标准"
- 例如"有人味文案"、"梗密度"、"广告感"等黑话，都可以通过样本对训练成规则

### Step 4：训练 skill（业务大拿定义标准）

- 让懂业务的人定义好样本和标准
- 不要把训练完全交给技术人员
- 每个 skill 上线前先由业务人验证 10 次

### Step 5：龙虾调度（项目经理级智能体）

- 龙虾 = 有记忆、个性、目标和调度能力的项目经理
- 给龙虾目标 → 它自动调用所需 skill → 输出结果
- 龙虾内部会自我复盘并调整调用顺序

### Step 6：上线迭代（token 量+反馈闭环）

- 衡量指标不是真人 headcount，而是 AI 工作流数量、token 消耗、复用次数
- 每周复盘：哪些 skill 被高频调用、哪些效果差
- 差的 skill 补样本、改标准

## 完整示例：销售团队 AI 化

1. **现场**：销售同学原来用 AI 给话术建议 → 火火让打开电脑看真实聊天记录
2. **拆单元**：拆成"分析长周期聊天记录"+"评分"+"规划下一步"3 个 skill
3. **样本对**：找 20 组已成交 vs 未成交的聊天记录做对比
4. **训练**：销售同学自己定义"什么样的对话质量高"
5. **龙虾**：用 Claude Code 把 3 个 skill 打包成一个销售龙虾
6. **上线**：销售同学用它评估自己的对话，一个人变多角色

## 适用场景与边界

- **适用**：重复性强、有明确好坏标准的岗位工作（客服、销售、HR 打招呼、投放、内容审核）
- **不适用**：需要极高上下文和情感判断的战略决策
- **已知局限**：需要业务大拿投入 20-40 小时训练；小公司缺少足够样本
