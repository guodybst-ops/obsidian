# 河床模型

## 一句话

**把生意画成河：两侧堤坝拉势能、中间河床接流水，识别谁是水谁是河床，再决定预算投哪。**

## 什么时候用

- ✅ **年度营销规划**：需要给下一年的营销资源分配定盘
- ✅ **获客卡顿**：短视频/投放/日常直播 ROI 越来越差，越砸越难做
- ✅ **诊断"是否在做水而不是做河床"**：怀疑所有资源都投在会变的东西上
- ✅ **有老板 IP 但没变成生意**：老板讲了很多但转化跟不上，需要把 IP 和成交界面串起来
- **红线**：**不适用于年营收 1000 万以内**（老板没时间做右堤坝，先只做左堤）；**不适用于 5 亿以上**（大厂已有 CMO 体系）；**不适用于老板不愿上台的公司**

## 输入

- **年营收数字** + 未来 12 个月预测
- **老板本人是否愿意上场**（不愿意 → 直接判定不适用）
- **当前营销资源清单**（所有正在做的动作：短视频、投放、直播、内容、私域、发布会、老板 IP 等）
- **是否有 300 万+ 年度营销预算**（用于两侧堤坝的施工）
- 前置：**能一句话说清楚自己的产品在解决什么客户的什么问题**

## 输出

- 一张**河床画像卡**（三格填满）
- 一份**施工比例判定**（左堤 / 河床 / 右堤 三个 0-5 分）
- 一份**未来 3 个月资源投向决定**（1-3 个具体动作 + 各自预算）
- **完成信号**：能对老板一句话说清"我们今年营销的枪口偏向 X 侧堤坝，因为 Y"

## 主流程

### Step 1：画河床图，把当前所有资源填进三格
- 拿一张空白纸，画三格结构：**左堤 / 中间河床 / 右堤**
- 左堤 = 老板 IP / 员工 MCN / 干货内容（种草）
- 河床 = 短视频 / 信息流投放 / 日常直播 / 客服 / 私域（收货）
- 右堤 = 大厂直播 / 周年庆 / 年度发布会 / 跨年演讲（打爆）
- 把公司当前正在做的**每一项**营销动作，写进对应格子
- **判断信号**：三个格子都有至少 1 项 → 进 Step 2；有格子空着 → 记下"这一侧势能为 0"

### Step 2：给每一项打"水 / 河床"标签
- 逐条问：**"这件事停 3 个月会不会归零？"**
  - 会归零 → 是**水**（当期流量、当期投放、当期直播）
  - 不会归零 → 是**河床**（品牌资产、内容库、老板认知、客户信任）
- 统计比例：河床项 / 总项 = 河床占比
- **判断信号**：河床占比 < 30% → 严重偏向做水，Step 4 必须往河床倾斜；≥ 50% → 势能已沉淀，Step 4 可以做水放大

### Step 3：按体量查决策表，定三格施工比例
- 打开下方"施工比例决策表"，找到当前营收段
- 记下推荐的**左堤 / 河床 / 右堤**得分（0-5）
- 与自己河床图现状对比，**差距最大的那一格就是本季度要补的**
- **判断信号**：能说出"我今年最缺 X 侧，现在只有 Y 分，应该到 Z 分"

### Step 4：决定资源投向，把预算切成 3 块
- 用下方"预算分配卡"模板，把年度营销预算切成左堤 / 河床 / 右堤
- **原则一**：**中间河床只负责收货，不要压种草任务**（把种草压给日常直播 = 最常见错误）
- **原则二**：**两侧堤坝一定要老板站台**——大厂直播尤其是一年只憋一次的一把手工程
- **原则三**：**非标程度越高、单价越高，堤坝越要厚**
- 落地为 1-3 个具体动作 + 各自预算 + 时间点

### Step 5：3 个月复盘，看势能有没有拉起
- 3 个月后问三个信号：
  - **左堤**：老板 IP 内容的**收藏比**是否上升？（不看播放量）
  - **河床**：日常直播 / 投放的**成交客户复购率**是否上升？
  - **右堤**：如果做过一次大厂直播，**是否带来新的头部客户询盘**？
- 有变化 → 保留当前施工比例
- 无变化 → 回 Step 2 重新检查"水/河床"标签是否打错

### Step 6：季度调整，跨档就重画
- 如果营收段跨档了（如 3000 万 → 1 亿）→ 回 Step 3 重查表
- 势能拉起但没跨档 → 考虑**采买更高势能 IP 到右堤坝当客座**

## 判断点：施工比例决策表

| 年营收段 | 左堤（老板 IP） | 中间河床（日常营销） | 右堤（大厂直播） | 主打动作 |
|---|---|---|---|---|
| **1000 万以内** | 3-4 分（老板亲做） | 2 分（少而精） | 0 分（不适用） | 只做左堤，一条命打出去 |
| **3000 万-1 亿** | 4-5 分（老板 IP + 员工 MCN） | 3 分 | 1-2 分（小型发布会） | 完整河床，左堤为主 |
| **1 亿-3 亿** | 4 分 | 4 分（重塑内容叙事） | 3-4 分（周年庆 / 年度演讲） | 三块都抓 |
| **5 亿以上** | 3 分 | 5 分（预算杠杆） | 5 分（外挂 CMO 切入） | 从右堤切入 + 河床调度权 |

```
老板不愿上台            → 不适用，考虑"员工 MCN 分布式内容"
年营收 < 1000 万        → 只做左堤，不要碰右堤
年营收 > 5 亿 且有 CMO  → 跳到"挑客户四层"
非标 + 高单价           → 两边厚 + 中间饱（全上）
标品 + 低单价           → 中间做重，两边可以省
河床占比 < 30%          → 危险，重心必须往河床倾斜
```

## 常见坑

- ❌ **把种草任务压给日常直播** → 日常直播只该收货，逼它种草就两头都做不好
- ❌ **老板不上台强做右堤** → 大厂直播的核心资产就是老板本人，替身不成立
- ❌ **1000 万以内公司硬做完整河床** → 预算撑不起两侧堤坝，一条命打三线一定崩
- ❌ **打标签时把"投放"打成河床** → 投放停 3 个月一定归零，是水；只有内容库 / 客户信任才是河床
- ❌ **一次大厂直播想反复复用** → 老板一年只憋一次，重复价值有限

## 附录 A：实例（润宇服务的一家 5 亿+客户）

1. 从**大厂直播**（周年庆）进入（右堤坝切入）
2. 借周年庆植入年度营销叙事重塑——**"四面 CT 扫描"**：产品面 / 展示面 / 业务面 / 成交面
3. 帮客户搭建**老板 IP + 员工 MCN**（左堤坝）
4. 中间河床（日常投放 / 短视频 / 日常直播）由对方团队执行
5. 采买 2-3 位垂类**高势能 IP 到右堤坝做客座**（花 5 万请古典 / 经济学家 / 社会学家来做 30 分钟分享，比投他一条 30 万商单效果都好）

**结果**：三格施工比例达成 4-5-5，一年内客户询盘结构从"投放为主"转为"内容资产为主"。

## 附录 B：原话与洞察（不进主流程）

> "未来的线上新媒体营销三板斧是一个合床模型：两边堤坝是老板 IP + 大厂直播，中间河床是日常营销界面。"

> "这就是刘润说的枪口向左向右差 5 公分，中间成本差一个亿。"

> "老板 IP 的根本是撬动后面资产的发动机和杠杆的支点，但它不是终点。"

> "势能一定是两边高、中间低——用户像黄河的水，被沉淀在中间。"

**为什么"生意像河"这个隐喻站得住**：河的水年年变，但河床几十年不变；生意的流量年年变（红利转移、平台迁徙），但客户信任、老板认知、内容资产不变。**把资源投向河（水）是"赚今天的钱"，把资源投向河床是"沉淀明天的势能"**。河床模型的本质就是让操盘手在每一次预算分配前，都被迫回答一次"我这一笔在做水还是在做河床"。
