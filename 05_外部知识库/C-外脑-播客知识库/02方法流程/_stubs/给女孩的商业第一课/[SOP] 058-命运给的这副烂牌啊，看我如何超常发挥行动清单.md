# [SOP] 058-命运给的这副烂牌啊，看我如何超常发挥行动清单

## 一句话（≤ 40 字）
把「命运给的这副烂牌啊，看我如何超常发挥」转成可执行检查清单。

## 什么时候用
- 你正在处理与「命运给的这副烂牌啊，看我如何超常发挥」相似的问题。
- 你需要把播客里的建议转成可以打勾的动作。
- **红线**：如果当前问题需要专业医疗、法律或财务意见，先找专业人士复核。

## 输入
- 当前问题的一句话描述。
- 你已经掌握的事实、约束和可用资源。
- 来源单集：[[89单集笔记/给女孩的商业第一课/058 - 命运给的这副烂牌啊，看我如何超常发挥？|058]]

## 输出
- 一张本周行动清单。
- 至少一个可以验证的完成信号。

## 主流程

### Step 1: 记录自己过去一周的时间花在哪，区分主动时间和被动
- 执行：记录自己过去一周的时间花在哪，区分主动时间和被动时间，找出可以优化的部分。
- 完成信号：能写下本步的结果或下一步判断。

### Step 2: 列出自己微信里最想链接的3位优秀人士，主动发一条
- 执行：列出自己微信里最想链接的3位优秀人士，主动发一条有具体价值的消息（而非泛泛的“想认识你”）。
- 完成信号：能写下本步的结果或下一步判断。

### Step 3: 练习“体面拒绝”：下次遇到不想见的邀约，用“最近
- 执行：练习“体面拒绝”：下次遇到不想见的邀约，用“最近排满了，如果有具体事可以微信上说，看我能不能帮上忙”来回应。
- 完成信号：能写下本步的结果或下一步判断。

### Step 4: 复盘一次“差一点”的经历，诚实地还原心路历程，找
- 执行：复盘一次“差一点”的经历，诚实地还原心路历程，找出那一点差距的必然原因。
- 完成信号：能写下本步的结果或下一步判断。

### Step 5: 如果正处于低谷期，列出3件以前没做过但低成本可尝
- 执行：如果正处于低谷期，列出3件以前没做过但低成本可尝试的事（如开一个社交媒体账号、写一篇长文、参加一个线下活动）。
- 完成信号：能写下本步的结果或下一步判断。

### Step 6: 阅读或观看关于长征的史料（如《红军长征记》），思
- 执行：阅读或观看关于长征的史料（如《红军长征记》），思考其中应对绝境的方法如何应用到自己的处境。
- 完成信号：能写下本步的结果或下一步判断。

### Step 7: 每周主动给一位比自己优秀的人提供一次有价值的反馈
- 执行：每周主动给一位比自己优秀的人提供一次有价值的反馈或建议（可以是反对意见），练习“精神茅台”式沟通。
- 完成信号：能写下本步的结果或下一步判断。

## 判断点 / 决策树

```
如果动作能在 48 小时内完成 → 直接执行
如果动作依赖他人反馈 → 先发出一次最小请求
如果动作涉及高风险决策 → 回到来源单集和专业意见复核
```

## 常见坑
- 不要只收藏不执行，至少选一条 48 小时内能做的动作。
- 不要把单集建议当成普遍真理，先看自己的场景是否匹配。
- 不要删掉来源链，后续需要回到原文核对。

## 附录：实例

以「命运给的这副烂牌啊，看我如何超常发挥」为例，先选 1 条最小动作执行，再用 1 周观察是否带来真实反馈；如果没有反馈，回到清单换下一条，而不是继续空想。
