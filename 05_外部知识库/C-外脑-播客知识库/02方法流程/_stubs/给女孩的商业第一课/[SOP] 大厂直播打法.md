# 大厂直播打法

## 一句话

**用老板一年一次的年度直播，切进企业决策中心，换全年营销授权。**

## 什么时候用

- ✅ **想切入 3000 万-3 亿客户但没有入口**：老板不接一般 To B 陌拜
- ✅ **服务方想从"卖 30 条短视频"跳到"当外挂 CMO"**：需要一次战略切入点
- ✅ **客户老板明年有周年庆 / 发布会 / 年度演讲**：抢在筹备启动前进入
- ✅ **想借一次内容重新整合客户全公司资源**（产品 / 展示 / 业务 / 成交）
- **红线**：**不适用于老板不愿露脸的公司**（大厂直播的资产是老板本人，替身不成立）；**不适用于年营收 1000 万以下**（预算撑不起）；**不适用于 5 亿以上已有完整 CMO 体系**；**不适用于一年做超过 5 家客户的服务方**（超载会全部烂尾）

## 输入

- **客户明年的年度锚点**（周年庆 / 发布会 / 客户答谢会 / 年度演讲 / 或和老板一起造一个）
- **老板本人 3 次深度对话时间**（每次 2-4 小时，含项目立项 / 叙事共创 / 现场彩排）
- **60-90 天筹备周期**（不足 60 天不接）
- **客户内部授权**：产品 / 市场 / 销售 / 客服 至少能各出 1 位对接人
- 前置：**你已经通过 [[挑客户四层]] 判定客户是第②③层，且老板愿意进决策中心**

## 输出

- 一场**90-120 分钟的年度直播**（核心内容 30-40 分钟）
- 一份**四面 CT 扫描报告**（产品 / 展示 / 业务 / 成交 四面的现状 + 短板）
- 一份**年度营销叙事框架**（含五步桥完整脚本）
- 一份**直播后 30 条短视频剪辑素材包** + 河床模型三格施工计划
- **完成信号**：直播后老板**主动**发起"接下来全年怎么打"的对话（不是你去 push）

## 主流程

### Step 1：找到年度锚点，锁定日期
- **动作**：和老板对齐"明年公司**只做一次**对外发声的事件"是哪一件
- 优先级：**周年庆 > 新品发布会 > 年度演讲 > 客户答谢会**
- 若无固定锚点，和老板一起造一个（例：品牌 X 周年 / 产品 X 代升级）
- **日期约束**：至少留出 **60-90 天筹备期**；筹备期不足 → 谈明年
- **判断信号**：日期定死 + 老板亲口承诺"这天我全天在"→ 进 Step 2

### Step 2：做四面 CT 扫描，找出短板
- **动作**：进场后 2 周内，按四面各出 1 份扫描表（模板 A）——
  - **产品面**：产品线全景 / SKU 结构 / 差异化点
  - **展示面**：官网 / 短视频 / PPT / 门店 / 包装的一致性
  - **业务面**：客户结构 / 渠道结构 / 销售链路
  - **成交面**：客单价 / 转化率 / 复购率
- 每面找出 **3 个最短的短板** → 汇总成"12 个待补齐点"
- **判断信号**：4 张扫描表 + 12 个短板清单交付给老板，老板认可 → 进 Step 3

### Step 3：定差异化方向（枪口向左还是向右）
- **动作**：拿着 12 个短板问老板 3 个问题：
  - 我们今年的枪口**打高端引领**还是**打性价比破圈**？
  - 主打**打向往**还是**打恐惧**？（红线：不做恐惧，见 [[商业叙事构架]]）
  - 单点撬动**哪一个 KPI**（客单价 / 复购 / 新客获取）？
- 定完差异化，才进 Step 4 选选题 / 素材 / 嘉宾
- **判断信号**：能一句话说清"我们这场直播的枪口偏向 ___，撬动 ___ 一个 KPI"→ 进 Step 4

### Step 4：套商业叙事构架，写直播脚本
- **动作**：直接调用 [[商业叙事构架]] 的五步桥模板：
  ```
  起点：产品 → 桥 1 需求触发 → 桥 2 需求原因 →
  桥 3 解决方案 → 桥 4 能力证明 → 桥 5 产品是啥 → 终点：向往
  ```
- 老板主讲部分不超过 **30-40 分钟**，占总时长 1/3
- 每座桥必须**视觉化**（撕板 / 站位 / 具体主角 / 真实道具），不能只讲道理
- **判断信号**：脚本过 [商业叙事构架] 的 **5 项测试清单**全部打勾 → 进 Step 5

### Step 5：排嘉宾组合 + 现场彩排
- **动作**：按下表组三类嘉宾——
  - **老板本人**（主讲，30-40 分钟）：必须亲上，不设替身
  - **客座高势能 IP 1-2 位**（20 分钟客座）：垂类专家 / 经济学家 / 社会学家，花 3-5 万请人比投 30 万商单效果好
  - **案例客户见证 1-2 位**（10 分钟）：真实客户带故事上台
- 直播前 7 天**彩排**：全流程走 1 遍，卡时长、试道具、调机位
- **时长控制**：总时长 90-120 分钟，核心 30-40 分钟
- **判断信号**：彩排后老板能**不看稿讲完自己的 30 分钟**→ 进 Step 6

### Step 6：直播现场执行 + 内容资产化
- **动作**：直播当天，执行 5 件事——
  - **机位 3 个**：老板主讲位 + 全景位 + 特写位
  - **视觉道具**：所有抽象逻辑必须现场用道具 / 撕板 / 站位表达
  - **实时留客钩子**：15 分钟一个（不是打折促销，是内容深度触发）
  - **不追单不催单**（客户被促销吓跑）
  - **录制原始素材**（4K + 独立音轨）
- 直播后 2 周内产出：
  - 30 条短视频剪辑（用于河床中间层的收货界面）
  - 1 份年度商业叙事框架（老板 IP 内容主线）
  - 1 份"接下来全年怎么打"方案（作为进入外挂 CMO 服务的入场券）
- **判断信号**：老板**主动**约你聊全年 → 从大厂直播打法升级到 [[挑客户四层]] 第③层

## 判断点：进 / 不进决策表

| 情形 | 该怎么办 |
|---|---|
| 老板愿意亲上 + 有 60-90 天筹备期 + 客户在 3000 万-3 亿档 | ✅ 接单 |
| 老板不愿亲上 | ❌ 退单，或降级到员工 MCN 分布式内容 |
| 筹备期 < 60 天 | ❌ 谈明年，不接短周期"救火" |
| 客户只想要"直播执行"、不给全年授权 | ❌ 降级到 [[挑客户四层]] 第①层项目制 |
| 客户 5 亿+ 已有 CMO | ❌ 不适用，走 [[挑客户四层]] 第④层合伙人路径 |
| 客户只想打恐惧 / 焦虑营销 | ❌ 主动退出（红线，不接） |

```
筹备期 < 60 天              → 谈明年
老板不愿亲上                → 退单或员工 MCN
客户只想执行不想授权         → 降级项目制
无年度锚点 + 老板不愿造      → 退单
```

## 常见坑

- ❌ **老板不亲上，找副总替身** → 大厂直播的核心资产就是老板本人，替身直播观众一眼看出，直接崩
- ❌ **筹备期 < 60 天硬接** → 四面 CT 扫描做不完 + 叙事没打磨 + 老板没彩排，现场必翻车
- ❌ **直播里塞打折促销** → 客户被促销吓跑（"你们不是干品牌吗？"）；留客钩子只能是**内容深度触发**
- ❌ **只做直播不做后续 30 条短视频** → 大厂直播是**引子**不是产品，不做后续河床承接就白干
- ❌ **打恐惧营销抄近道** → 制造焦虑短期出单但长期反噬 + 违反红线（见 [[商业叙事构架]]）
- ❌ **接了这单又同时接同行业竞品的相同项目** → 排他性丧失，两边都不信你
- ❌ **一年做超过 5 家** → 大厂直播是密集深度工程，超载全部烂尾

## 附录 A：实例（润宇服务的一家 5 亿+客户）

**切入路径**（完整跑通 SOP）：

1. **Step 1（锚点）**：客户 5 周年 → 定死"周年庆"作为年度锚点
2. **Step 2（四面 CT 扫描）**：发现"展示面不一致 + 成交面客单价偏低"是最大短板
3. **Step 3（差异化）**：定"打高端引领"，撬动客单价 KPI
4. **Step 4（叙事）**：起点=产品，终点=向往，走五步桥
5. **Step 5（嘉宾）**：老板 + 采买 2-3 位垂类**高势能 IP 客座**（花 5 万请古典 / 经济学家 / 社会学家做 30 分钟分享，比投他一条 30 万商单效果都好）
6. **Step 6（承接）**：直播后老板 IP + 员工 MCN + 中间河床（日常投放 / 短视频 / 日常直播）三格施工，跑通完整 [[河床模型]]

**结果**：直播后老板主动增加对话频率，服务方从"一次性直播执行商"升级为**外挂 CMO**（见 [[挑客户四层]] 第③层）；一年后客户询盘结构从"投放为主"转为"内容资产为主"。

## 附录 B：原话与洞察（不进主流程）

> **"大厂直播是一次性入场券，但换来的是全年营销叙事重塑的授权。"**

> **"外部以为我们在做流量转化，其实我们在做进入企业决策中心的战略入口。"**

> **"老板一年就憋这么一次，一定用力过猛 100%。你想失败都难。"**

**为什么是最佳入口的三个理由**：
1. **老板一年只憋这一次**（年会 / 周年庆 / 发布会）——那半小时是老板最用心、最愿意倒出全公司战略的时刻，你能拿到别的场景一年都拿不到的深度对话
2. **一把手工程 = 结果保证**——老板亲自来了，团队全 all-in，失败都难
3. **部门壁垒自动瓦解**——企业服务最难的圈层壁垒（市场 / 销售 / 产品互不服）因一把手在场自动打通

**杠杆最大化**：借由大厂直播这个入口，你可以顺势植入全年的营销叙事重塑（四面 CT 扫描），从"直播操盘手"升级为"外挂 CMO"。**"我们主动退出过一个'贼有名、贼多钱'的代运营邀约——因为进不了决策中心，时间成本回收不了。我不干不是因为高傲，是因为我认为我的未来更贵。"**

**为什么"大厂直播 ≠ 老板 IP"更快**：老板 IP 需要 60-90 条视频慢慢养，但大厂直播一次憋出老板一年的浓缩内容，杠杆效率高得多。二者是配套关系——大厂直播是**右堤坝**，老板 IP 是**左堤坝**，中间河床承接（见 [[河床模型]]）。
