# [SOP] 080-小环境决定大财运！家庭财富一次给你讲清楚行动清单

## 一句话（≤ 40 字）
把「小环境决定大财运！家庭财富一次给你讲」转成可执行检查清单。

## 什么时候用
- 你正在处理与「小环境决定大财运！家庭财富一次给你讲清楚」相似的问题。
- 你需要把播客里的建议转成可以打勾的动作。
- **红线**：如果当前问题需要专业医疗、法律或财务意见，先找专业人士复核。

## 输入
- 当前问题的一句话描述。
- 你已经掌握的事实、约束和可用资源。
- 来源单集：[[89单集笔记/给女孩的商业第一课/080 - 小环境决定大财运！家庭财富一次给你讲清楚|080]]

## 输出
- 一张本周行动清单。
- 至少一个可以验证的完成信号。

## 主流程

### Step 1: 和伴侣一起制定未来10年的家庭蓝图，倒推需要多少
- 执行：和伴侣一起制定未来10年的家庭蓝图，倒推需要多少钱，建立共同账户，每月存入收入的20%-30%
- 完成信号：能写下本步的结果或下一步判断。

### Step 2: 每季度开一次家庭财务复盘会，夫妻俩一起做PPT
- 执行：每季度开一次家庭财务复盘会，夫妻俩一起做PPT，回顾资产配置，共同决定调整方向
- 完成信号：能写下本步的结果或下一步判断。

### Step 3: 如果流动资产在1000万以下，认真评估租房vs买
- 执行：如果流动资产在1000万以下，认真评估租房vs买房的性价比，不要被“房本位”绑架
- 完成信号：能写下本步的结果或下一步判断。

### Step 4: 黄金配置不超过总资产的25%，自制力强买黄金ET
- 执行：黄金配置不超过总资产的25%，自制力强买黄金ETF，自制力弱买金条
- 完成信号：能写下本步的结果或下一步判断。

### Step 5: 投资前先问自己：我是什么样的人？我能承受多大波动
- 执行：投资前先问自己：我是什么样的人？我能承受多大波动？我有没有时间看盘？然后选择适合自己的游戏
- 完成信号：能写下本步的结果或下一步判断。

### Step 6: 把家务和育儿外包一部分，让夫妻俩从“白天打仗、晚
- 执行：把家务和育儿外包一部分，让夫妻俩从“白天打仗、晚上打仗”的循环中解脱出来，一起瘫在沙发上享受生活
- 完成信号：能写下本步的结果或下一步判断。

### Step 7: 找到已经结婚7-10年的夫妻，请他们拿出家庭账单
- 执行：找到已经结婚7-10年的夫妻，请他们拿出家庭账单，一项项对，了解未来可能出现的重大负债
- 完成信号：能写下本步的结果或下一步判断。

## 判断点 / 决策树

```
如果动作能在 48 小时内完成 → 直接执行
如果动作依赖他人反馈 → 先发出一次最小请求
如果动作涉及高风险决策 → 回到来源单集和专业意见复核
```

- 不要删掉来源链，后续需要回到原文核对。
