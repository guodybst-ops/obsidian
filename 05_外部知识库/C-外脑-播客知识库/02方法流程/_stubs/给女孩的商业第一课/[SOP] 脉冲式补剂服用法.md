# 脉冲式补剂服用法

## 一句话
补剂不是天天吃越吃越好，而是按"密集 → 停 → 再密集"的脉冲节奏，让身体产生反馈、避免耐受，用 28 天试错窗口检验真伪功效。

## 为什么这么做
- 天天吃 + 常年吃 = 身体钝化，感受消失，反而说明补剂没起作用或已经耐受。
- 大部分补剂真正起效需要一个足量周期（约三个月），但过了这个周期继续堆量并不会线性增益，反而进入平台期。
- 用户对"吃了没感觉"的最短判定窗口是 28 天，超过 28 天没有主观改善就应该停用而不是死磕。
- 脉冲节奏 = 让身体在"用—休"之间形成信号差，也倒逼消费者定期复盘，而不是被订阅制/自动续订套牢。

## 操作步骤
1. **选品**：只认成分 + 剂量，不看"抗衰、提亮、补气血"这类功效关键词。
2. **密集期**：连续吃三个月，剂量按官方推荐上限（不叠加多品同成分）。
3. **28 天体检**：第 28 天做一次自我复盘（睡眠、精力、皮肤状态），无明显改善即申请退款/停用。
4. **停用期**：满三个月后停一个月，观察身体是否回落、是否有"戒断感"。
5. **再决策**：如停用后明显退步，再进入下一轮密集期；如无差别，说明该品对你无效，永久剔除。
6. **单品原则**：同一时间不叠加三个以上补剂，避免变量混淆。

## 判断指标
- 每一轮结束后能明确说出"我为什么继续吃/为什么停"，而不是习惯性下单。
- 补剂支出年内下降但主观状态上升，说明筛选生效。
- 家里同时开封的补剂 ≤ 3 种。

## 常见误区
- 把补剂当"每日必吃"，吃成安慰剂。
- 一次上五六种，出问题分不清是哪个的锅。
- 迷信"进口/网红/明星同款"关键词，不看实际成分含量。
- 只吃不测，没有复盘节点。

## 边界
- 不适用于医生开具的处方药、慢病长期用药，那类必须遵医嘱连续服用。
- 孕产妇、慢病人群应先咨询医生，不能套用脉冲节奏。
- 本方法适合"锦上添花型"营养补充剂（麦角硫因、辅酶 Q10、维生素等）。
