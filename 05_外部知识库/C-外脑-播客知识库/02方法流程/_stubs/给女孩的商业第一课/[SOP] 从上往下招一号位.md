# 从上往下招一号位

## 一句话

**新业务线先招一号位（VP / 总监），让他自己搭团队；禁止基层先行、倒序招人。**

## 什么时候用

- ✅ **新业务线立项**：要开一条新战线（新品类 / 新地区 / 新技术栈），且这条线需要独立能力和独立目标
- ✅ **老业务线转型**：技术栈 / 商业模式整体换血（如导流网站转电商、Java 转 PHP）
- ✅ **一号位空缺**：原一号位离职、被收购变副手、能力跟不上速度
- ✅ **公司规模**：**30 人以上、100 人以下**是最典型区间（美丽说 80 人转型是标杆案例）
- **红线**：**不适用于 3-5 人超小公司**（老板本人即一号位）；**不适用于纯执行型部门**（客服中心、后勤）；**不适用于成熟公司临时项目**（派内部资深员工挂帅即可）

## 输入

- **业务目标一句话**：这条线未来 12-18 个月要拿到什么（营收 / 增长 / 转型完成度）
- **一号位画像**：过往战绩、心力、精力要求（详见下方"模板 A"）
- **允许的空缺期**：3-6 个月，期间由**老板亲自兼任**这条业务
- **允许的授权范围**：一号位到岗后拥有对本条线的**招聘权 / 开除权 / 薪资权**
- **原有存量员工名单**：这条业务线上现有的人（可能要被转岗或让走）

## 输出

- 一份**一号位画像卡**（模板 A）
- 一份**面试话术**（模板 B），全程只面试一号位候选人，不面基层
- **完成信号**：一号位入职后 **3 个月内**能定出自己的团队编制并开始面自己人（老板 / HR 只参与临门一脚）

## 主流程

### Step 1：先定"要做什么事"，再定一号位画像

- 打开模板 A，**先写业务目标**（"12 个月内电商 GMV 到 X 亿"），再倒推所需过往战绩
- 一号位画像三要素：**同类型公司同规模同岗位**做过 + **心力 all-in** + **精力能承受高强度**
- **绝对不要先定 headcount 数**——headcount 由一号位到岗后自己定
- **判断信号**：画像具体到"从哪家哪类公司挖"（如敏哥挖美丽说研发 VP = 从**百度端窝端**）

### Step 2：全力挖一号位，空缺期由老板兼任

- 允许时间等 **3-6 个月**
- 允许空缺期由**老板本人亲自兼任**这条业务
- **绝对不要**为了填空缺让 HR 先招基层"我先用着"——违反本 SOP 第一红线
- **判断信号**：候选人过往公司规模、岗位、业务阶段能对得上你的画像，而不是"名校 / 大厂 logo"

### Step 3：面试一号位（用模板 B 话术，不聊专业）

- **不跟高端候选人聊专业**——你聊得越多越像小丑
- 用模板 B 里的话术：**聊过往经历 + 内斗 + 判断品行**
- 面试时脑海里始终浮现**老板的样子**——你按老板的人设去问
- **核心判据**：他能不能说服你身上有能达成这件事的**一个亮点**（一个就够）

### Step 4：一号位到岗，让他自己组团队

- **允许他带子母人**（前公司的老下属带过来 3-4 个）—— 敏哥直言美丽说供应链老大就是他从京东挖过来的，带 3-4 人一起
- HR 只负责**办入转调离**，不干预一号位的选人
- 老板对一号位的**授权 = 组团队权 + 招聘权 + 开除权 + 薪资权**
- **判断信号**：新招进来的团队**基本都是一号位面的**，老板/HR 只做临门一脚

### Step 5：处理老一批基层（转岗 / 走人）

- **能转岗**的转岗（美丽说买手团队转岗做海外淘 Haigo）
- **不愿意转的走人**——好聚好散或按劳动法补偿
- **不要因为"情"留人**——留下的都是一号位难受、公司也难受、最终还是要给离职补偿金
- **判断信号**：这条业务线跟一号位强绑定（一号位走 = 业务大概率跟着变）

## 判断点：什么时候招一号位 vs 什么时候招骨干

```
新业务线立项 / 老业务线转型 ────────→ 招一号位（Step 1-5）
                                    ↑
一号位已在位 3 个月以上 + 已定编制 ──→ 招骨干（一号位自己面）
                                    ↑
一号位刚到岗（< 3 个月）────────→ 不招骨干，等一号位定编
                                    ↑
纯执行型部门（客服/后勤）──────→ 不需要一号位，招组长即可
                                    ↑
老板兼任期间（一号位空缺）────→ 只维持存量，不新增招聘
```

**快速自检 3 问**：
1. 这条线**能不能独立算账**？能 → 需要一号位；不能 → 归到隔壁一号位下面招骨干
2. 现有一号位**能不能给这条线定编制**？能 → 招骨干；不能 → 先补一号位
3. 我准备招的这个人**能不能自己带团队**？能 → 是一号位；不能 → 就是骨干

## 模板 B：面试一号位话术

对候选人**只聊两类话题**（原文可直接抄）：

> **① 过往经历里的关键决策**
> "你上一段业务从 X 到 Y，你做过最难的一个决策是什么？当时怎么权衡的？"
>
> **② 组织中的内斗与判断**
> "你上一家公司里，你跟你的老板/合伙人有过分歧的时候，你怎么处理的？"
>
> **③ 意向确认（跟高端人只需要这一步）**
> "如果我们一起干这条业务线，未来 12 个月你会怎么切入？先干什么？"

- ✅ 通过：他能说出**具体细节 / 具体判断 / 具体动作**
- ❌ 淘汰：他讲的都是"我们公司下午有下午茶"式的形式记忆
- ❌ 淘汰：**只挂 logo 的"大厂系"**（阿里系 / 字节系 HR 那类，华而不实）

## 常见坑

- ❌ **先招基层"我先用着"** → 一号位来了会说"给我配的这是什么垃圾"，你为了关系咬牙留下→最终还是要付离职补偿金→**公司两头亏**
- ❌ **迷信"阿里系 / 字节系"** → 那是马云 / 张一鸣牛逼，不是他 HR 牛逼；出来的人到你这里水土不服
- ❌ **不允许一号位带老下属** → 组团队速度慢 3-6 个月，且一号位缺乏"信得过"的核心圈
- ❌ **老板不放权** → 一号位到岗还是老板拍板招人开人，一号位变傀儡，3 个月内一定走
- ❌ **拿"学习能力强"当理由招错阶段的人** → 门当户对是硬约束，学习能力弥补不了阶段差
- ❌ **业务不行时先动 HR** → **HR 是最不重要的角色**——"公司好的时候销售说了算，公司不行的时候 HR 才说了算"；转型该动的是**研发 / 供应链 / 业务的一号位**

## 附录：实例（美丽说 80 → 300 → 1500 人的完整跑通）

**业务背景**：2013 年阿里断链，美丽说被迫从"导流网站"转型电商——**导流用 Java，电商用 PHP，技术栈整体换血**。腾讯投了钱，阿里更不管了。

**Step 1 画像**：
- 业务线：电商研发
- 目标：12 个月内把电商站点从 0 搭起来
- 战绩要求：**在大型电商公司做过 PHP 技术栈的研发 VP**
- 定位挖角源：**百度端窝端**（百度电商团队）

**Step 2 挖人**：CEO 徐易容第一个换的**不是 HR，是研发 VP**——从百度端窝端挖了一个研发大佬过来。老板亲自出面，空缺期 CEO 兼任电商方向决策。

**Step 3 面试**：CEO 亲自面，聊的是"你在百度端窝端做过什么、怎么带团队、怎么看电商的技术未来"——不聊 PHP 语法细节。

**Step 4 组团队**：研发 VP 到岗后**两个月内**从百度端窝端老同事那里"端"了整个团队过来。**下面所有人自然流动**——原有 Java 团队离职的办离职，能转 PHP 的转岗。

**Step 5 处理存量**：
- **80 → 300 人**：新业务线 BU（美丽说 Haigo 海外淘）扩张，**原买手团队转岗做海外淘**；**不愿意转的走人**
- **300 → 500 → 1500 人**：能力跟不上速度的员工好聚好散或补偿走人；同时通过**重组收购 3-5 家公司**（如吴世春的石神摇遥）加人，被收 CEO 要么套现离场、要么留下当 BU leader

**跑通结果**：从 80 人做到 1500 人，融了 7 轮。**HR 全程只办入转调离**，不参与选人。敏哥自己就是那个 HRBP 负责人（买手团队 + Haigo BU 的 HR 头）。
