# 做减法的量级判据

## 一句话

**优化 10% ≠ 减法。真正的减法是只留 10%、砍掉 90%**——不砍到痛，就是没做过减法。

## 怎么用

### 判据 1：量级判据
- 砍 10% → 优化，不是减法
- 砍 90% → 强制重排优先级 = 真减法
- 如果砍完发现只剩 1 条业务线还在赚钱，其他都在烧钱 → 减对了

### 判据 2：重开创业假设
> "如果我今天重新开始创业，会怎么做？"

用这个假设倒推：
- 现在的团队里，哪几个人是"重开会立刻重新雇"的？留
- 现在的业务线里，哪一条是"重开会立刻做"的？留
- 现在的 SKU 里，哪些是"重开会立刻上"的？留
- 剩下的全部砍

### 判据 3：A/B 犹豫 = 未看清
如果做减法时在"砍 A 还是砍 B"之间犹豫 → 说明你**没有彻底看清**这两件事哪个更重要。花时间看清，别急着执行。

## 完整案例：醉鹅娘 200 → 20 人

- 生完孩子躺月子期间做减法：**200 人裁到 20 人**
- 砍掉：多 SKU 的选品业务、代运营业务、多渠道分发
- 只留：**广寒记**（自酿酒品牌，一条业务线）
- 触发点："如果我今天重新开始创业，肯定只做这一件事"

## 适用场景与边界

- **适用**：多年积累但持续亏钱的多业务线公司；从内容/流量转品牌的创业者
- **不适用**：早期尚在探索 PMF 的公司（此时应做扩张不是减法）
- **心理陷阱**：砍完的人会经历一段"我是不是错过了 X 机会"的痛苦期，需要预先接受
- **已知局限**：砍到 10% 的判据不适用于业务组合本身就该保持广度的公司（如平台型公司）
