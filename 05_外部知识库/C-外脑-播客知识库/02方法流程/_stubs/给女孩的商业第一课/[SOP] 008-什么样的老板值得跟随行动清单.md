# [SOP] 008-什么样的老板值得跟随行动清单

## 一句话（≤ 40 字）
把「什么样的老板值得跟随」转成可执行检查清单。

## 什么时候用
- 你正在处理与「什么样的老板值得跟随」相似的问题。
- 你需要把播客里的建议转成可以打勾的动作。
- **红线**：如果当前问题需要专业医疗、法律或财务意见，先找专业人士复核。

## 输入
- 当前问题的一句话描述。
- 你已经掌握的事实、约束和可用资源。
- 来源单集：[[89单集笔记/给女孩的商业第一课/008 - 什么样的老板值得跟随？|008]]

## 输出
- 一张本周行动清单。
- 至少一个可以验证的完成信号。

## 主流程

### Step 1: 写下自己当前工作目标岗位里，哪些事情让我有正向能
- 执行：写下自己当前工作/目标岗位里，哪些事情让我有正向能量，哪些事情像“精神损失费”。
- 完成信号：能写下本步的结果或下一步判断。

### Step 2: 拆一个自己感兴趣行业的上下游：上游是谁，中游是谁
- 执行：拆一个自己感兴趣行业的上下游：上游是谁，中游是谁，下游是谁，终端用户是谁。
- 完成信号：能写下本步的结果或下一步判断。

### Step 3: 找 3 个行业内从业者聊天，用同一组问题交叉验证
- 执行：找 3 个行业内从业者聊天，用同一组问题交叉验证行业判断。
- 完成信号：能写下本步的结果或下一步判断。

### Step 4: 面试创业公司时，观察创始人讲产品和用户时是否真的
- 执行：面试创业公司时，观察创始人讲产品和用户时是否真的兴奋，而不是只讲融资、规模和故事。
- 完成信号：能写下本步的结果或下一步判断。

### Step 5: 评估一个老板时，记录他是否愿意给具体反馈、是否愿
- 执行：评估一个老板时，记录他是否愿意给具体反馈、是否愿意花时间训练人。
- 完成信号：能写下本步的结果或下一步判断。

## 判断点 / 决策树

```
如果动作能在 48 小时内完成 → 直接执行
如果动作依赖他人反馈 → 先发出一次最小请求
如果动作涉及高风险决策 → 回到来源单集和专业意见复核
```

## 常见坑
- 不要只收藏不执行，至少选一条 48 小时内能做的动作。
- 不要把单集建议当成普遍真理，先看自己的场景是否匹配。
- 不要删掉来源链，后续需要回到原文核对。
