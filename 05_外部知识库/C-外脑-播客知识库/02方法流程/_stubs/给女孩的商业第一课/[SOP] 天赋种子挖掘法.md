# 天赋种子挖掘法

## 一句话

**找一位曾有天赋、现陷低谷的迷茫者，用"向他请教"的方式陪伴三个月。**

## 什么时候用

- ✅ 你**不知道自己天赋是什么**、找不到方向
- ✅ 你已经**用错力**：苦练"你以为的天赋"、闭关列清单、找一堆人聊天却更迷茫
- ✅ 你能接受**长周期非零和方法**（3-4 个月才见结果，回馈不一定从对方回来）
- ✅ 你手边**能想到至少 1 位**曾经在事业上有高光时刻但现在陷入低谷的中年朋友
- **红线**：**不适用于**眼下要交作业的短期焦虑；**不替代**必要的自我探索；**不适合**手边真的没有可以请教的迷茫者的人（可退化为【找角落人练习】）

## 输入

- **20 分钟安静时间 × 1 次**（做启动内省）
- **3 个月执行周期**（每 1-2 周一次通话，共 6-8 次）
- **1 位候选迷茫者**（曾有高光、现在陷落、身边人已不再联系他的那种）
- **1 个可打电话到本人的联系方式**
- **1 张空白 A4 纸 + 便签**

## 输出

- **1 份天赋碎片清单**（你人生里所有做过就上头的小事）
- **1 份请教通话话术卡**（每次通话开头可直接用）
- **1 份 3 个月签到表**（记录每次通话日期 + 对方状态变化）
- **完成信号**：3 个月内你在某个安静时刻（发呆 / 散步 / 坐车）出现"过去所有零碎经历突然连成一个方向"的顿悟

## 主流程

### Step 1：启动内省——20 分钟静坐 + 3 个问题（只做 1 次）

- [ ] 找一处 20 分钟不被打扰的地方，一张空白 A4 纸
- [ ] 依次在纸上回答 3 个问题（不评判、不筛选、想到什么写什么）：
  1. **从小到大，我做什么事情做完会自己上头？**（不问值不值钱、有没有前途）
  2. **有哪些"看似不相关"的经历，我至今记得当时的感受？**（哪怕 5 分钟的画面也算）
  3. **谁是我认识的"曾经很厉害、现在很沉默"的中年人？**（列 3 个候选）
- [ ] 写完之后**不做归纳、不做剖析**——把纸折起来放抽屉
- **判断信号**：**不要**当场从这张纸得出"我的天赋是 X"的结论——写完更迷茫是正常的

### Step 2：选 1 位候选迷茫者（1 周内定人）

- [ ] 从 Step 1 的第 3 题里选**最符合以下画像**的一位：
  - 家乡认识 / 老同学介绍 / 家庭朋友，**可以直接打电话到本人**
  - 曾经在事业上有过**高光时刻**（有具体高光事件，不是笼统"以前挺不错"）
  - 现在**身边人已不再联系他**（关键判据）
- [ ] **不要**选：网红 / 大 V / 完全不认识的人 / 直接竞争对手
- **判断信号**：你说得出这个人过去**一个具体的高光故事**（哪一年、做了什么、为什么厉害）

### Step 3：每 1-2 周一次电话，用"请教话术"（持续 3 个月）

- [ ] **每次通话前** 30 秒写下你**当下真的困惑**的一件事
- [ ] **通话开头**直接用下方话术，**不要闲聊"你最近怎么样"**
- [ ] **通话主题**始终是"我遇到问题，你当年是怎么做的"——目标是**让他想起他的激情、他的使命**
- [ ] **不要**在通话中指出他的问题（"你家人因为你很痛苦"），他已经十几年没工作，不需要再听
- [ ] 每次通话结束在签到表上写：**日期 / 通话时长 / 对方今天状态**
- **判断信号**：3 个月共 6-8 次通话，对方的语速 / 谈起过去时的语气 / 主动分享的意愿逐渐变化

### Step 4：等待种子在"卸载场景"开花（不控频、不主动复盘）

- [ ] **不要**每周问自己"我天赋是啥"——种子开花不是抠出来的
- [ ] 3 个月里正常生活，**让自己有一些进入空虚落寞的时刻**：
  - 一段全情投入的工作刚结束
  - 长途出租车 / 高铁 / 飞机上发呆
  - 独自散步、看窗外
- [ ] 那颗种子会**在你完全不设防的一刻打开**（陈唐是坐北京出租车看人行天桥掠过窗外时，5 分钟豁然开朗）
- [ ] **一旦顿悟出现**：立刻把浮现的画面 / 关联 / 方向抄到 Step 1 那张 A4 纸上
- **判断信号**：过去所有零碎经历"像北斗七星一样连成一个方向"——从此不再迷茫

## 判断点 / 决策树

```
Step 1 写完还是迷茫 ─────→ 正常！种子没到，别硬抠答案
                        ↓
Step 2 找不到符合画像的人 → 退化用【找角落人练习】（日常版）
                        ↓
Step 3 对方一开始很淡漠 ──→ 别放弃，前 2 次通话很正常
                        ↓
2 个月对方状态无变化 ────→ 检查是不是"指出他问题"而不是"请教"
                        ↓
3 个月你还在苦练"你以为的天赋" → 大概率没做到"以请教方式"
                        ↓
出现顿悟场景 ───────────→ 立刻记录，感受就是种子开花本身
```

## 模板 A：请教通话话术卡（可复制粘贴）

**通话开头（直接说，别铺垫）**：

> "XX 叔叔 / 阿姨，好久没打给您。我最近遇到一个问题，我知道您当年在 ______ 领域做过 ______，我想请教您——**您当年是怎么处理 ______ 的？有没有可以给我的建议？**"

**通话中三个禁区**：
- ❌ 不要说"您现在怎么样？"（开场就把他推到"低谷"位置）
- ❌ 不要说"您家里 / 身体最近怎么样？"（不要点破他的痛处）
- ❌ 不要说"我觉得您以前很厉害"（不要评价他）

**通话结尾**：

> "太感谢您了，我下次遇到类似问题还想找您。**大概两周后我再打给您**，可以吗？"

**关键**：每次通话结束前，**约好下次通话的时间锚点**——让他有"被期待"的感觉。

## 常见坑

- ❌ **想清楚了才行动** → 迷茫的人想不清楚，只能靠动作种；等你想清楚就晚了
- ❌ **一次通话就想要顿悟** → 是 6-8 次通话累积后在"卸载场景"里开花，不是打完立刻见效
- ❌ **通话变成"我来救你"** → 对方是完整的人，你是去请教他不是救他；一有救人心态种子会变味
- ❌ **主动写日记复盘"我天赋是啥"** → 复盘越勤越种不出来；反而是"卸载"的空虚时刻才开花
- ❌ **期待"从这个人身上回来"** → 回馈可能从第三方回来、有时间差；陈唐这颗种子不是从钢材朋友身上回来的

## 附录 A：实例（陈唐陪 50 岁钢材朋友 3-4 个月）

**陈唐的原始困境**：大学毕业时，同学都进银行、读研、出国，陈唐"卡在原地"，不知道自己要什么。听到笔的故事时最大的困惑是：**"一个迷茫的人怎么去帮另一个迷茫的人？"**

**候选对象**：家乡认识的一位 **50 多岁**钢材生意朋友——
- 90 年代提大哥大坐绿皮火车跑全国钢材市场
- 公司里**第一个有大哥大的副总**
- 后来**因为喝酒身体垮掉早退**，失去了事业激情
- 家人不快乐，**家人和老同事都不再打电话给他**
- 已经十几年没工作了，以前找他的人排队，现在没有人再找他，单位也不再尊重他

**陈唐动作**：
- 以"**向他请教**"的方式帮他找回激情
- 每次电话开头："**我遇到这个问题，你当年是怎么做的？有没有给我的建议？**"
- **每一两周一次电话，做了三四个月**

**种子开花场景（不是被抠出来的）**：
- 某天格西老师北京课程结束、陈唐送他回美国后，"很落寞"
- 坐在**北京出租车后座**发呆，看着窗外一条条**人行天桥掠过**
- **就在那一刻，那颗种子打开了**——小时候带一群孩子玩游戏冲在第一个、大学跳街舞、尝试做主持人、亚运会播音员、竞选班长、商业案例比赛、学英文……那些碎片化的东西全部浮现
- **那些画面一张张出现，最后竟然连起来了**——就像看星空，不仔细看是没关联的一颗颗独立的点，懂得看你能看到北斗七星、猎户座
- 大概 **5 分钟的体验，豁然开朗**。**从那次之后基本上没有迷茫过**

**关键洞察**：**没有种子的话，零散的经历还是零散经历**——你只能看到棍子的每个碎片，看不到那是笔；是种子把这些碎片组合成了一个方向。

## 附录 B：反例（陈唐的宿舍闭关）

在陪 50 岁钢材朋友之前的**一两年**，陈唐也做了很多尝试：
- 找师兄师姐聊、找过来人问方向
- 模仿《奇特的一生》，**把自己关在宿舍两天**穷尽写下所有能做的事，写在 A4 纸上——**那是他人生第一次闭关**

**结果**：写完之后**地上都是纸，但他更迷茫了**。

**原因**：**列清单 / 自我剖析 / 找人聊天都不是种子**——你只能看到棍子的每个碎片，看不到那是笔。能把碎片组合成方向的**不是理性归纳，是种子**。

## 附录 C：为什么"苦练技能"不是路径

古老经典把每个人内心深处的天赋叫**银矿**，也叫**如来藏**——像一个宝藏盒，外面裹着一层纱布。**差别不在有没有矿，而在有没有掀开那层纱布**。掀开的动作**不是苦练矿本身**，是种对应的种子。

**陈唐 098 补注**：能站在舞台上的人不一定是最有才能的——**你能站在那个舞台上，是种子创造的机会，不是才能本身**。
