# [SOP] 木马程序识别改写法

## 一句话（≤ 40 字）
把自动反应找出来，再改写成可执行的新选择。

## 什么时候用（触发条件，3-5 条 bullet）

- 你总在同类场景里反复恐惧、退缩或自我否定。
- 你明知不合理，却还是会按老反应行动。
- 你想分清“事实危险”和“想象危险”。
- **红线**：不替代严重创伤或心理危机的专业支持。

## 输入（做之前要准备的东西）

- 一个最近反复出现的卡点场景。
- 一张纸或一个文档。
- 15 到 30 分钟不被打扰的时间。

## 输出（做完得到什么）

- 一条被识别出来的旧木马。
- 一句新的替代信念。
- 一个本周内可执行的微动作。

## 主流程（核心，占篇幅 ≥ 60%）

### Step 1：写出自动反应

- 只写事实：发生了什么，你第一反应是什么。
- 不解释自己，不评价自己。
- 做完信号：你能把“场景”与“解释”分开。

### Step 2：追问木马来源

- 问自己：这个反应最早像谁的声音？
- 可能来自父母、学校、影视、宗教、关系创伤或过去失败。
- 做完信号：你知道这不是天生如此，而是有来源。

### Step 3：区分事实与想象

- 列两栏：真实证据 / 我脑补的危险。
- 如果它没真实发生过，就先归入“想象危险”。
- 做完信号：你知道自己是在应对现实，还是在应对旧程序。

### Step 4：写替代信念

- 用一句具体的话替代旧木马。
- 例如把“我不配”改成“我现在还不会，但可以学会”。
- 做完信号：新句子不是鸡汤，而是你愿意暂时采纳的行动口令。

### Step 5：做一个反向微动作

- 选一个低风险动作，证明你不必再按旧程序活。
- 必须小到 7 天内做得完。
- 做完信号：你不是只想通，而是真改了一个行为。

## 判断点 / 决策树

| 状态 | 下一步 |
|---|---|
| 写不出来源 | 先从最近一次最强烈反应开始 |
| 全是情绪没有事实 | 回到 Step 1 重写场景 |
| 新信念太空泛 | 缩小成一句更具体的话 |

## 模板 / 清单 / 打分卡

| 场景 | 自动反应 | 旧木马来源 | 事实危险 | 想象危险 | 新信念 | 微动作 |
|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |

## 常见坑（3-5 条硬红线）

- ❌ 不要把“识别木马”写成控诉大会。
- ❌ 不要一上来追求彻底痊愈。
- ❌ 不要只写新信念，不配一个小动作。

## 附录：实例

102 集里，李欣频把恐惧、匮乏、自我设限等反应称为“木马程序”，强调先识别自动驾驶，再通过转念与行动重写程序。
