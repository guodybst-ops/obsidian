# [SOP] 015-和97年亿万富翁聊聊：大学里不教的创富思维行动清单

## 一句话（≤ 40 字）
把「和97年亿万富翁聊聊：大学里不教的创」转成可执行检查清单。

## 什么时候用
- 你正在处理与「和97年亿万富翁聊聊：大学里不教的创富思维」相似的问题。
- 你需要把播客里的建议转成可以打勾的动作。
- **红线**：如果当前问题需要专业医疗、法律或财务意见，先找专业人士复核。

## 输入
- 当前问题的一句话描述。
- 你已经掌握的事实、约束和可用资源。
- 来源单集：[[89单集笔记/给女孩的商业第一课/015 - 和97年亿万富翁聊聊：大学里不教的创富思维|015]]

## 输出
- 一张本周行动清单。
- 至少一个可以验证的完成信号。

## 主流程

### Step 1: 写下你手里已有的 5 类资源：身份背书、可触达的
- 执行：写下你手里已有的 5 类资源：身份背书、可触达的人群、能低成本调动的人、特殊信息源、别人愿意信任你的理由。
- 完成信号：能写下本步的结果或下一步判断。

### Step 2: 评估一个机会前，至少回答 8 个问题：谁付钱、为
- 执行：评估一个机会前，至少回答 8 个问题：谁付钱、为什么现在付、市场有多大、现金流如何、竞争对手是谁、你有什么差异、最坏亏多少、什么时候撤。
- 完成信号：能写下本步的结果或下一步判断。

### Step 3: 下次做 To B 或职场交付前，先写出对方 KP
- 执行：下次做 To B 或职场交付前，先写出对方 KPI、对方领导 KPI、对方再上一级 KPI，再设计交付方案。
- 完成信号：能写下本步的结果或下一步判断。

### Step 4: 如果想认识一个更强的人，先找一件你能高质量完成的
- 执行：如果想认识一个更强的人，先找一件你能高质量完成的小事，不要一上来请求对方给资源。
- 完成信号：能写下本步的结果或下一步判断。

### Step 5: 每周约一次和自己背景不同的人吃饭或聊天，并记录对
- 执行：每周约一次和自己背景不同的人吃饭或聊天，并记录对方行业里一个你原本不知道的真实规则。
- 完成信号：能写下本步的结果或下一步判断。

### Step 6: 发朋友圈或私域内容时，明确这一条要测试什么：信任
- 执行：发朋友圈或私域内容时，明确这一条要测试什么：信任、价格、场景、需求强度，还是目标人群画像。
- 完成信号：能写下本步的结果或下一步判断。

### Step 7: 每次成交后追问一个不冒犯的问题：这次是给谁买、为
- 执行：每次成交后追问一个不冒犯的问题：这次是给谁买、为什么买、还会在什么场景用，用来反推产品包装和文案。
- 完成信号：能写下本步的结果或下一步判断。

## 判断点 / 决策树

```
如果动作能在 48 小时内完成 → 直接执行
如果动作依赖他人反馈 → 先发出一次最小请求
如果动作涉及高风险决策 → 回到来源单集和专业意见复核
```

## 常见坑

- 不要把单集建议当成普遍真理，先看自己的场景是否匹配。
- 不要删掉来源链，后续需要回到原文核对。
