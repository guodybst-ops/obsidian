# [SOP] 099-重建注意力行动清单

## 一句话（≤ 40 字）
先切断睡前输入，再慢慢养回专注。

## 什么时候用（触发条件，3-5 条 bullet）
- 你被手机和即时反馈拖着走。
- 你想恢复专注，但总靠意志力失败。
- 你想做一个低门槛版的圆圈日练习。
- **红线**：开车、值班等必须在线的场景，不强行断联。

## 输入（做之前要准备的东西）
- 一个固定睡前时点。
- 一个可以放置手机的地方或锁袋。
- 一本纸质书或一个静坐位置。

## 输出（做完得到什么）
- 一份 7 天注意力恢复实验表。
- 可衡量的完成信号：连续 3 晚不在床上刷手机。

## 主流程（核心，占篇幅 ≥ 60%）

### Step 1: 固定睡前断联时点
- 选一个每天都能执行的时点，把手机和电脑移出手边。
- 如果做不到一小时，就先从 20 分钟开始。
- 完成信号：你知道自己每天什么时候停止输入。

### Step 2: 填一个低刺激动作
- 在断联后只保留静坐、散步或纸书阅读中的 1 个。
- 如果动作需要切换设备，说明刺激还太强。
- 完成信号：这段时间里没有重新拿起手机。

### Step 3: 记录分心触发物
- 每天记 1 次最容易分心的触发物。
- 如果触发物重复出现，就优先处理它。
- 完成信号：你知道自己不是“自控差”，而是被什么拖走。

### Step 4: 每周做一次加长版安静时段
- 每周安排 30-60 分钟更完整的安静时段。
- 如果整块时间太难，就拆成两段。
- 完成信号：本周至少完成 1 次加长练习。

## 判断点 / 决策树（如有分支）

```text
如果晚上总反复拿手机 → 缩短到 20 分钟先做成
如果 20 分钟稳定了 → 再延长到 1 小时
如果白天也被拖走严重 → 额外加一段白天静时段
```

## 模板 / 清单 / 打分卡（可复制粘贴）

| 项目 | 记录 |
|---|---|
| 今天断联时间 |  |
| 我做了什么低刺激动作 |  |
| 最主要触发物 |  |
| 今天是否破功 |  |
| 明天调整什么 |  |

## 常见坑（3-5 条硬红线）
- ❌ 不要把“刷有用内容”当放松。
- ❌ 不要期待当天就彻底安静。
- ❌ 不要一上来做太狠导致第二天放弃。
