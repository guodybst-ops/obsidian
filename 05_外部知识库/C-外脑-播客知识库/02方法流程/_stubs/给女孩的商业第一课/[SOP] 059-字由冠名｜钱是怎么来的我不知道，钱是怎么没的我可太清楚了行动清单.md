# [SOP] 059-字由冠名｜钱是怎么来的我不知道，钱是怎么没的我可太清楚了行动清单

## 一句话（≤ 40 字）
把「字由冠名｜钱是怎么来的我不知道，钱是」转成可执行检查清单。

## 什么时候用
- 你正在处理与「字由冠名｜钱是怎么来的我不知道，钱是怎么没的」相似的问题。
- 你需要把播客里的建议转成可以打勾的动作。
- **红线**：如果当前问题需要专业医疗、法律或财务意见，先找专业人士复核。

## 输入
- 当前问题的一句话描述。
- 你已经掌握的事实、约束和可用资源。
- 来源单集：[[89单集笔记/给女孩的商业第一课/059 - 字由冠名｜钱是怎么来的我不知道，钱是怎么没的我可太清楚了！|059]]

## 输出
- 一张本周行动清单。
- 至少一个可以验证的完成信号。

### Step 1: 像骗子研究你一样研究自己：列出自己最容易冲动消费
- 执行：像骗子研究你一样研究自己：列出自己最容易冲动消费/投资的场景（如股市暴跌时抄底、销售热情推荐时办卡），提前设计应对流程。
- 完成信号：能写下本步的结果或下一步判断。

### Step 2: 每次做重要投资决策前，等一天再决定，并给一个信任
- 执行：每次做重要投资决策前，等一天再决定，并给一个信任的朋友打电话征求意见。
- 完成信号：能写下本步的结果或下一步判断。

### Step 3: 买房产大额商品时，至少问三个不同销售该产品的缺点
- 执行：买房产/大额商品时，至少问三个不同销售该产品的缺点，每家说三个。
- 完成信号：能写下本步的结果或下一步判断。

### Step 4: 把父母手机号换掉，或搬家，切断骗子联系渠道。每周
- 执行：把父母手机号换掉，或搬家，切断骗子联系渠道。每周/两周和父母吃饭，分享“隔壁有个笨蛋被骗了”的故事，而不是直接教育。
- 完成信号：能写下本步的结果或下一步判断。

### Step 5: 放弃“自己会投资”的妄念，承认95%的人不适合炒
- 执行：放弃“自己会投资”的妄念，承认95%的人不适合炒股。如果非要投资，只买简单的东西（如标普500、伯克希尔），不碰复杂衍生品。
- 完成信号：能写下本步的结果或下一步判断。

- 执行：不要把钱交给那些一生都想翻盘、风险偏好极高的人（如大学同学那种），可以和他们交往吸取生命力，但别投钱。
- 完成信号：能写下本步的结果或下一步判断。

### Step 7: 建立“冲动决策警报”：当密码输错两次、半夜起来操
- 执行：建立“冲动决策警报”：当密码输错两次、半夜起来操作、特别着急时，立刻停手。
- 完成信号：能写下本步的结果或下一步判断。

## 判断点 / 决策树

```
如果动作能在 48 小时内完成 → 直接执行
如果动作依赖他人反馈 → 先发出一次最小请求
如果动作涉及高风险决策 → 回到来源单集和专业意见复核
```

## 常见坑
- 不要只收藏不执行，至少选一条 48 小时内能做的动作。
- 不要把单集建议当成普遍真理，先看自己的场景是否匹配。
- 不要删掉来源链，后续需要回到原文核对。
