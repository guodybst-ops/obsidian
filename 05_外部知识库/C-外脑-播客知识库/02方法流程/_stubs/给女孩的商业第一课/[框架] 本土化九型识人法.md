# 本土化九型识人法

## 一句话

把九型人格当成商业和关系中的共识语言——不是给人贴死标签，而是快速判断对方注意力、恐惧、欲望、决策偏好，从而选择合适的沟通方式。

## 四类识人重点

### 一号 · 秩序审判官

- **核心特征**：重规则、重正确、重 SOP，反感灰色投机和强情感拉扯
- **商业表现**：适合法务/财税/监督/公益律师；老板高度信任的中高层
- **相处方式**：不要吹嘘/送礼/硬 social；用长期、细颗粒、可复盘的工作结果建信任
- **雷点**：直播运营看你如何把在线人数从 82 拉到 100，并在飞书里复盘细节

### 六号 · 焦虑侦察官

- **核心特征**：默认风险存在，先怀疑再验证，验证通过后非常忠诚
- **商业表现**：很多年收入百万级中小企业主，做事稳、花钱谨慎、重熟人背书
- **相处方式**：主动暴露漏洞；提前讲合作中会出现的问题；用小范围验证降低不确定感
- **雷点**：不要说"团队无所不能"，要主动说"我不擅长高级电影感"

### 八号 · 阿尔法船长

- **核心特征**：强控制、强责任、强结果导向，喜欢直接和硬扛
- **商业表现**：适合冲锋/破局/带强结果团队
- **相处方式**：做错就承认并说明怎么改；不要包装/防御/观察情绪
- **雷点**：董明珠看 PPT 时不要现场揣摩气氛或找借口

### 九号 · 调停者和棋盘手

- **核心特征**：不急于表态，喜欢维持系统平衡，能容纳不同人性并重新摆位
- **商业表现**：大国企/大体制/大存量盘子，让多个强势角色为同一盘棋服务
- **相处方式**：展示你能容人、能把人放到合适位置
- **雷点**：不要动不动以"干掉谁"证明自己有魄力

## 自我识别法

### 第一步：分三区

- 心区（2、3、4）：情感驱动、追求形象
- 脑区（5、6、7）：思考驱动、追求安全或探索
- 腹区（8、9、1）：本能驱动、追求控制或和平

### 第二步：外界评价交叉验证

- 收集家人/同事/朋友对你的评价关键词
- 找出重复频率最高的三个

### 第三步：给你一个亿后你想做什么

- 想影响/支配/参与动态关系 → 偏 3、7、8
- 想隐居/创作/不为售卖表达 → 偏 4、5、9
- 先追问钱从哪来 → 偏 1、2、6

## 完整示例：向六号老板销售 IP 服务

1. 判断对方是六号（做事稳、花钱谨慎、重熟人背书）
2. 不要说"我们团队无所不能"
3. 主动说明："我们擅长访谈切片，不擅长高级电影感"
4. 提前讲合作前期的摩擦（提要求会返修 2-3 轮）
5. 用一个 5 万块的小项目做小范围验证
6. 六号验证通过后成为长期客户，忠诚度极高

## 适用场景与边界

- **适用**：To B 高客单销售、上下级关系管理、贵人关系推进
- **不适用**：短期一次性交易、快速消费品营销
- **已知局限**：识人本质是概率工具，重大时刻才能真正验证型号；不要用来给人贴死标签
