# [SOP] 077-如果你也想做访谈，这期价值百万行动清单

## 一句话（≤ 40 字）
把「如果你也想做访谈，这期价值百万」转成可执行检查清单。

## 什么时候用
- 你正在处理与「如果你也想做访谈，这期价值百万」相似的问题。
- 你需要把播客里的建议转成可以打勾的动作。
- **红线**：如果当前问题需要专业医疗、法律或财务意见，先找专业人士复核。

## 输入
- 当前问题的一句话描述。
- 你已经掌握的事实、约束和可用资源。
- 来源单集：[[89单集笔记/给女孩的商业第一课/077 - 如果你也想做访谈，这期价值百万|077]]

## 输出
- 一张本周行动清单。
- 至少一个可以验证的完成信号。

## 主流程

### Step 1: 确定访谈品类：优先选择有流量的女性成长、职业故事
- 执行：确定访谈品类：优先选择有流量的女性成长、职业故事等，而非直接做商业访谈。
- 完成信号：能写下本步的结果或下一步判断。

### Step 2: 建立嘉宾储备库：至少储备10位“松鼠属性”的专家
- 执行：建立嘉宾储备库：至少储备10位“松鼠属性”的专家或名人，确保前10期有高质量嘉宾。
- 完成信号：能写下本步的结果或下一步判断。

### Step 3: 写邀请函：清晰说明节目定位、拍摄方式、时长、能给
- 执行：写邀请函：清晰说明节目定位、拍摄方式、时长、能给嘉宾什么，尽量写长写详细。
- 完成信号：能写下本步的结果或下一步判断。

### Step 4: 做钱彩：搜百度30页之后、换5个平台搜关键词、看
- 执行：做钱彩：搜百度30页之后、换5个平台搜关键词、看评论区前三位讨论什么，形成至少5万字资料。
- 完成信号：能写下本步的结果或下一步判断。

### Step 5: 设计商业气口：在第一期节目就留好植入位置，如人名
- 执行：设计商业气口：在第一期节目就留好植入位置，如人名条、开场广告、结尾logo等。
- 完成信号：能写下本步的结果或下一步判断。

### Step 6: 现场纪律：全场静音、麦不开不聊重要问题、进入第一
- 执行：现场纪律：全场静音、麦不开不聊重要问题、进入第一个问题后忘掉大纲、坐得住。
- 完成信号：能写下本步的结果或下一步判断。

### Step 7: 当场复盘：聊完关机后立刻拿白板，让所有工作人员写
- 执行：当场复盘：聊完关机后立刻拿白板，让所有工作人员写印象深刻的点，统一后期方向。
- 完成信号：能写下本步的结果或下一步判断。

## 判断点 / 决策树

```
如果动作能在 48 小时内完成 → 直接执行
如果动作依赖他人反馈 → 先发出一次最小请求
如果动作涉及高风险决策 → 回到来源单集和专业意见复核
```

- 不要删掉来源链，后续需要回到原文核对。
