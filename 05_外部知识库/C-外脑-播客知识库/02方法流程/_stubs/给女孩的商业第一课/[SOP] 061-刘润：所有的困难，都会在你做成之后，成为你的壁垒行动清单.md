# [SOP] 061-刘润：所有的困难，都会在你做成之后，成为你的壁垒行动清单

- 你正在处理与「刘润：所有的困难，都会在你做成之后，成为你的」相似的问题。
- 你需要把播客里的建议转成可以打勾的动作。
- **红线**：如果当前问题需要专业医疗、法律或财务意见，先找专业人士复核。
