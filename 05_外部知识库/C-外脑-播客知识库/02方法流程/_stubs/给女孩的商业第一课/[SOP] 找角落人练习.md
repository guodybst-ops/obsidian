# 找角落人练习

## 一句话

进入任何新人群，找最边缘的那个人走过去打招呼，睡前庆祝这颗种子。

## 什么时候用

- ✅ 你**社恐 / 社交焦虑**，进入陌生场合胸口发紧、想逃跑
- ✅ 你渴望**"被人关爱"**但不擅长主动搭讪
- ✅ 你手边**找不到「想和你要同样东西的人」**，做不动【天赋种子挖掘法】——用本练习做日常退化版
- ✅ 你愿意**每周至少练 3 次**、坚持 3 周以上
- **红线**：**不适用于**目标性引流 / 变现 / KPI 场景（种子会变味）；**不替代**必要的深度社交

## 输入

- **场合 1 个**（社群聚会 / 培训 / 展会 / 新公司午餐 / 线上新群）
- **进入前 3 分钟**用来环视
- **1 次微互动 2-5 分钟**
- **睡前 3 分钟**做庆祝签到

## 输出

- **1 次"关照角落人"的微互动**（哪怕一句话也算）
- **1 条当日签到**（写在冥想卡上）
- **完成信号**：连续 3 周、每周 ≥ 3 次签到打勾

## 主流程

### Step 1：进入场合前 3 分钟环视识别（每次进场都做）

- [ ] 到达场合后**不急着找人打招呼**，找个位置站定或坐下
- [ ] 环视一圈，用**识别信号**找出"最像角落人"的 1-2 位：
  - 低头看手机但**手指不刷屏**（假装忙）
  - 独自**站在墙边 / 坐在最外圈**
  - **没人跟 ta 说话**、身边至少 1 米空档
  - 表情紧张、肢体拘谨
- [ ] 心里定一位目标（先易后难：**离你最近的那位**）
- **判断信号**：你能一句话说出"我今天要走过去的是穿 XX 衣服站在 XX 位置的那个人"

### Step 2：走过去开一个低压问题（60 秒内）

- [ ] 走过去，**站在斜前方 1 米**（不正对、不逼近）
- [ ] 开一个**低压问题**（照着话术卡念）——**不问工作、不问身份、不问收入**
- [ ] 如果对方只回一个字：**别追问**，笑一下、等 3 秒
- **判断信号**：你说出了第一句话，无论对方怎么回

### Step 3：陪站 2-5 分钟就撤（不必成朋友）

- [ ] 说完话**停留 2-5 分钟**，聊什么都行——甜点 / 天气 / 场地 / 主办方
- [ ] **不加微信、不留电话**（除非对方主动提）
- [ ] 想告辞时说："**很高兴认识你，我去那边看看**"——不解释、不铺垫
- **判断信号**：撤走时你没有"我是不是没聊够 / 尬走了"的懊悔感

### Step 4：睡前 3 分钟庆祝这颗种子（当晚做）

- [ ] 睡前坐床边或躺床上，回想今天走过去说的那句话
- [ ] **默念一句庆祝**："今天我关照了 XX 的那位角落人，我为这颗种子开心。"
- [ ] 在冥想卡 / 便签上**打勾一次**
- **判断信号**：连续 7 天签到，卡上打勾 ≥ 5 次；**没庆祝的一次不算完成**

## 判断点 / 决策树

```
场合里找不到角落人 ────→ 你还没静下来，退回 Step 1 再环视一圈
                     ↓
走过去开口卡壳 ──────→ 直接用话术卡下方 3 句应急话术之一
                     ↓
对方冷淡不搭理 ──────→ 正常，停 2 分钟自然撤，本次仍算完成
                     ↓
自己变成"救助者" ────→ 停手；对方是完整的人，回 Step 1 重找
                     ↓
连续 3 周签到达标 ────→ 观察进入新场合时的胸口紧张度是否变松
```

## 模板 B：变体清单（可直接抠走用）

| 场景 | 找谁 | 说什么 |
|---|---|---|
| 线下聚会 | 靠墙 / 一个人的 | "你也是一个人来的吗？" |
| 新公司午餐 | 独自吃饭的新同事 | "我坐你旁边可以吗？" |
| 线上新社群 | 最少发言的成员 | 对 ta 一句发言给一个真诚回应 |
| 培训 / 展会 | 展位前无人搭理的工作人员 | "你们这个产品是做什么的？" |
| 老家聚会 | 那位十几年没工作的中年长辈 | "叔叔，我最近有个问题想请教您……" |

## 常见坑

- ❌ **变成 CTA 型社交** → 为引流 / 变现找角落人，种子会变味；不加微信、不推名片
- ❌ **抱着"我来救你"心态** → 对方是完整的人，你只是打个招呼；一有拯救者情结种子就废
- ❌ **强迫自己变 E 人 / 陪聊 30 分钟** → 2-5 分钟就撤是本方法的关键
- ❌ **不庆祝就算完成** → 睡前 3 分钟庆祝是种子的水分，不庆祝不长
- ❌ **只做 1-2 次就要看效果** → 至少 21 天再自评，短周期看不出变化

## 附录 A：来源背景

- **陈唐 099 现场原话**：面对一位 I 型创业者的社恐提问时，陈唐说自己**"到今天都没有解决社交恐惧"**，但学到一招终身受益——不找 superstar，找角落人。
- 陈唐十几年前从格西老师学到此招，做了很多年之后感到：即使一个人做圆圈日，也会觉得**"小鸟、蜜蜂、自然在保护你"**。
- **底层逻辑**：己所欲，先施于人——你想被看见，就先去看见没被看见的人；你想被关爱，就先给出关爱这颗种子。

## 附录 B：为什么"逼自己变 E 人"没用

- 陈唐案例：马斯克是低社交成功范例、黄仁勋是高社交成功范例——**两条路都通**，社交能力不是成功的因。
- 陈唐公司销冠是极内向的人，从不主动跟客户打交道，但**懂得分享和给予**，客户自动上门。
- 结论：**不需要成为社交型选手，需要种"被看见"的种子**。
