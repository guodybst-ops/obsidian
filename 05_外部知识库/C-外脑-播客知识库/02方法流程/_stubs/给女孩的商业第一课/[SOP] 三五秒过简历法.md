# 三五秒过简历法

## 一句话

**按"关键词 → 主导度 → 结果数字"三处 3-5 秒过一份简历，任一处缺就淘汰。**

## 什么时候用

- ✅ 手里堆着 **50 份以上简历**，需要今天筛完
- ✅ 岗位有**明确的关键词**（技术栈 / 类目名 / 战绩指标 / 大厂名）
- ✅ 正在做**初筛**（第一轮，还没约面试）
- ✅ 想训练团队 HR 从"细看每份"升级到"批量过 500 份/小时"
- **红线**：**不适用于 VP+ 高端稀缺岗**（要深度尽调，走一号位招聘 SOP）；**不适用于跨行业候选人**（关键词对不上不代表不合适，需人工判断）；**不适用于内推关系户**（走关系单独通道）

## 输入

- 一份**岗位 JD**（要能提炼出关键词的那种，不是"能力可迁移"式含糊描述）
- 一叠简历（纸面 / PDF / BOSS 后台列表）
- **计时器**（真的计时——每份 3-5 秒硬约束，防止你陷进去细看）
- 一张**关键词卡**（Step 1 产出）

## 输出

- 一份**通过简历清单**（进入下一轮面试排期）
- 一份**淘汰理由标签**（用统一 4 个标签，见下方"淘汰标签表"）
- **完成信号**：一小时过完 500-800 份简历，剩下的**每一份**你都能一句话说出"为什么留下"

## 主流程

### Step 1：先写关键词卡（10 分钟，一次性）

- 对着 JD 提炼 **3-5 个必须命中**的关键词
- 每个关键词都要具体到**词**，不能是概念
- 用下方"关键词卡模板"填空
- **判断信号**：关键词能**在简历上直接搜**（Ctrl+F）；不能就是抽象度太高，重写

**关键词示例**：
- 主编岗 → `10万+`、`公众号`、`垂直类目名`（如"美妆"、"母婴"）
- 供应链岗 → `京东`、`仓储`、`服装 SKU`
- 技术岗 → `PHP`、`大厂后端`、`高并发`
- HR 岗 → `Fesco / 京东 / 美丽说`、`500 人以下`、`独立负责过 XX 模块`

### Step 2：3 秒扫关键词（第一处：全文搜）

- 打开简历（PDF 直接 Ctrl+F，纸面直接扫一遍）
- 关键词命中数 = 0 → **直接淘汰**，贴标签"关键词未命中"
- 关键词命中数 ≥ 1 → 进 Step 3
- **判断信号**：3 秒内做完决定，做不完就是没坚持规则

### Step 3：5 秒看主导度（第二处：项目描述）

对命中关键词的那一段工作经历，只看两点：
- **"主导"还是"参与"**？
  - 主导 / 独立 / 主笔 / 负责 → ✅
  - 参与 / 协助 / 支持 / 辅助 → ❌（贴标签"只是参与"）
- **服务的公司规模、行业、周期**匹不匹配你？
  - 匹配（同行同规模）→ ✅
  - 不匹配（比如 500 人以上大厂 → 你 30 人小公司）→ 结合 Step 4 决定

### Step 4：5 秒验数据（第三处：结果行）

- 看这段经历有没有**明确数字**（PV / GMV / 10 万+ 篇数 / 团队规模 / 营收）
- 有数字 + 主导 + 关键词命中 → **保留进面试排期**
- 只有关键词命中但没数字或只是参与 → **淘汰**，贴标签"无结果数据"
- 数字明显吹嘘（如"参与百亿项目"但个人角色不明）→ **淘汰**，贴标签"数据可疑"

### Step 5：贴淘汰标签（每份 1 秒）

用下方"淘汰标签表"给每份淘汰简历贴 1 个标签，方便：
- 复盘 JD 是否合理（如果 90% 都是"关键词未命中"→ JD 的关键词定得太严）
- 复盘投递渠道（如果 90% 是"数据可疑"→ 换渠道）

## 判断点：3 处扫描决策树

```
一份简历上手（Ctrl+F 或纸面扫）
    ↓
Step 2：3 秒搜关键词
    ├─ 命中 0 个 → 淘汰（"关键词未命中"）
    └─ 命中 ≥ 1 个 → 继续

    ↓
Step 3：5 秒看主导度
    ├─ "参与 / 协助 / 支持"字眼 → 淘汰（"只是参与"）
    └─ "主导 / 独立 / 主笔"字眼 → 继续

    ↓
Step 4：5 秒验数字
    ├─ 无数字 → 淘汰（"无结果数据"）
    ├─ 数字可疑（个人角色 vs 总盘量不匹配）→ 淘汰（"数据可疑"）
    └─ 数字明确 + 主导 → ✅ 通过初筛
```

**边界规则**：
- 高端稀缺岗（月薪 5 万+）→ **不走本 SOP**，走深度尽调
- 应届生岗 → **放宽 Step 3、Step 4**，重点看 Step 2 关键词（学校 / 实习 / 竞赛名）
- 跨行业但你老板坚持想面 → 允许"关键词未命中"但**同频**（走[[02方法流程/_stubs/初创公司门当户对招聘法]]验同频）

## 模板 A：关键词卡（每个岗位填一张）

```
━━━━━━━ 关键词卡 ━━━━━━━
岗位：__________________
汇报对象：______________
薪资 range：____________

必须命中关键词（3-5 个，具体到词）：
1. ______________________
2. ______________________
3. ______________________
4. ______________________
5. ______________________

主导度关键词（这些才算数）：
□ 主导 / 独立 / 主笔 / 负责 / 操盘

参与度关键词（这些不算数）：
□ 参与 / 协助 / 支持 / 辅助 / 配合

必须出现的数字类型（选 1-2）：
□ 用户量 / PV / DAU
□ 营收 / GMV / 客单价
□ 内容量（10 万+ 篇数）
□ 团队规模 / 管理人数
□ 项目周期 / 上线时间

红线（出现这些标签直接过）：
□ 大厂 5-6 年从没跳过
□ 上一份 500 人以上大公司
□ 跨行业跳槽 + 无过渡缓冲
━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 模板 B：淘汰标签表（4 个标签够用）

| 标签 | 含义 | 后续动作 |
|---|---|---|
| **关键词未命中** | Step 2 挂 | 不通知；若累计 > 90% → 检查 JD |
| **只是参与** | Step 3 挂 | 不通知；标记该简历库质量 |
| **无结果数据** | Step 4 无数字 | 不通知；下次投递渠道调整 |
| **数据可疑** | Step 4 数字明显吹嘘 | 不通知；打标记警惕该猎头/渠道 |

## 模板 C：一小时过 500 份简历的动作节奏

```
分钟 0-5：写关键词卡（不允许跳过）
分钟 5-10：打开 BOSS 后台 / 简历文件夹
分钟 10-60：批量过筛
    - 每份 5 秒硬约束（真的计时，超时就下一份）
    - Ctrl+F 搜关键词
    - 命中的看主导度和数字
    - 三关全过 → 拖到"通过"文件夹
    - 任一关挂 → 贴标签，下一份

一小时后：
    - 通过文件夹应有 20-50 份
    - 淘汰标签统计一遍，判断 JD / 渠道是否要调
```

## 常见坑

- ❌ **看简历"从头看到尾"** = 效率灾难 → 一小时看不完 30 份，一天推不出 1 个候选人
- ❌ **JD 关键词写成"能力可迁移""复合型人才"** = 无法搜索 → 关键词卡废掉，回 Step 1 重写
- ❌ **看到牛简历就细读** = 破坏节奏 → 5 秒硬约束不能破，牛简历通过后自然会进面试
- ❌ **不贴淘汰标签** = 无法复盘 → 下次同样的 JD 同样的渠道，还是烂简历一堆
- ❌ **求职者堆关键词** = "关键词汤" → 反而不专业（这条给求职者：见附录 A）
- ❌ **对高端岗也用 3-5 秒** = 错杀好人 → VP+ 稀缺岗必须深度尽调

## 附录 A：反向使用——求职者优化简历（可送给候选人）

**给求职者的 3 条硬规则**：

1. **姓名下 200 字内出现关键词**——不要放"个人简介"式废话
   - ❌ "10 年互联网从业经验，热爱产品，追求极致体验"
   - ✅ "10 年电商 PM，主导 3 个 GMV 破 10 亿项目，前京东商城供应链负责人"

2. **用数字代替形容词**
   - ❌ "参与了大量爆款文章的策划"
   - ✅ "独立主笔 32 篇 10 万+，其中 8 篇跨号阅读破百万"

3. **每段工作都有 3 秒可扫的结果行**
   - 用**加粗 / 首行 / 数字**让扫描者 3 秒就能看到你的核心贡献

**验证方式**：把你的简历给一个陌生人看 5 秒，让他复述你做过什么——**能复述具体动作和数字 = 简历合格**。

## 附录 B：为什么猎头看简历只用 3-5 秒

- **市场压力**：猎头一天要过成百上千份简历，一份一份细看根本推不出人
- **BOSS 后台版本不同**：猎头版能看到候选人的真实活跃度、跳槽频次，权限比 HR 高
- **关键词是市场共识**：JD 上的关键词就是市场公认的入门门槛，没命中说明不达标
- **数字是可验证的**：形容词是主观的，数字是客观的——数字对得上，能力大概率对得上

## 附录 C：反直觉——泉泉找主编只看一个关键词

- **需求**：泉泉给主编 JD 写了一堆要求
- **敏哥筛法**：只留一类人 → **有没有 10 万+**
- **原理**：主编岗的核心战绩就是"能不能写出爆款"，一个数字就能验证
- **结果**：一小时过 500 份，剩下 10 份都是有 10 万+ 战绩的，直接进面试
- **启示**：JD 写得再花哨，也要能抽出**1 个决定性数字关键词**

## 附录 D：金句原话

> "3 到 5 秒过一份简历——简历不像聊天，不能先寒暄，第一眼就要把最好的一面拍出来。"
>
> "猎头看的 BOSS 后台版本不一样——权限比你多，能看到候选人的真实活跃度。"
>
> "先看关键词，没关键词直接过；有关键词再延伸看服务内容。"
