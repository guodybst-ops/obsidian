# [SOP] 065-本集行动清单

## 一句话
把本集原始资料里最明确的做法信号落成一张执行清单。

## 什么时候用
- 你已经读过这一集的原始资料，准备把其中的做法转成自己的动作。
- 你想把嘉宾或叙事里的有效做法，改写成当前项目能执行的步骤。
- 你需要保留原始信号、落地动作、验证方式之间的对应关系。
- 红线：不适用于还没读原始资料、只想凭一句口号直接行动的场景。

## 输入
- 本集原始资料。
- 你当前要处理的一个具体问题、场景或决策。
- 一张可以记录动作、判断和验证结果的清单。

## 输出
- 4 条以内可执行动作。
- 每条动作对应的原始资料信号和验证方式。
- 完成信号：你已经把至少 1 条原始做法变成当前任务里的具体动作。

## 判断点 / 决策树
- 如果原始资料给的是原则句：先把原则改写成动作，再执行。
- 如果原始资料给的是顺序句：按先后顺序拆成子任务。
- 如果原始资料给的是判断句：先补齐数据，再决定是否采用。
- 如果几条做法互相打架：先保留最贴近当前问题的那一条。

## 常见坑
- 不要脱离原文上下文，只摘一句口号就开干。
- 不要把叙述句直接当流程，先翻成动作或判断条件。
- 不要同时追太多条线，优先执行最贴近当前问题的一条。
- 不要执行后不复盘，至少补一条验证结果。
