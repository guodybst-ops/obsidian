# [SOP] 049-IP合伙签约前法律体检清单

## 一句话（≤ 40 字）
签约前查清权责利、资产归属和退出。

## 什么时候用（触发条件，3-5 条 bullet）
- 准备和朋友、合伙人、MCN、机构或公司共同做 IP。
- 要签账号运营、内容合作、授权、股权、分成或劳动相关协议。
- 账号、商标、昵称、声音、肖像、作品或课程会产生商业价值。
- 对方用情义、资源、机会吸引你，但权责利还没写清。
- **红线**：本清单不能替代律师审合同，复杂合约必须找专业律师定制。

## 输入（做之前要准备的东西）
- 拟签合同、授权书、补充协议、聊天承诺和报价单。
- 自己现有劳动合同、竞业限制、保密协议和公司制度。
- 账号、商标、域名、社群、素材、课程、播客、视频、图片等资产清单。
- 各方出钱、出力、资源、渠道和预期收益安排。

## 输出（做完得到什么）
- 一份签约前风险检查表。
- 需要补充进合同的条款清单。
- “可签 / 暂缓 / 必须找律师”的初步结论。
- 完成信号：你能回答“我要什么、对方给什么、我要付出什么、分手怎么办”。

## 主流程（核心，占篇幅 ≥ 60%）

### Step 1: 说清合作交换
- 写下“我要什么、对方给什么、我要付出什么”。
- 如果任何一项只能用“资源很多、机会很好、以后再说”回答，先暂停签约。
- 做完信号：合作不是靠感觉，而是能写成交换表。

### Step 2: 检查劳动合同与竞业限制
- 查看自己是否受竞业、保密、副业限制或职务作品约束。
- 若仍在职，确认当前合作是否和雇主业务、客户、账号或工作时间冲突。
- 做完信号：知道这件事会不会违反已有义务。

### Step 3: 确认 IP、ID、IT 归属
- 列出 IP 内容、账号 ID、商标昵称、域名、小程序、数据后台、素材源文件、剪辑工程。
- 写清谁拥有、谁管理、谁可使用、谁能改密码、拆伙后谁带走。
- 做完信号：核心资产不会因为“谁注册的”而产生重大争议。

### Step 4: 核对授权范围和期限
- 检查授权内容、地域、平台、期限、是否独家、是否可转授权、是否可二创。
- 对“永久、全球、不可撤销、免费、可转授权”等词提高警惕。
- 做完信号：你知道自己到底让渡了哪些权利。

### Step 5: 算清出钱出力和经济账
- 把现金投入、时间投入、资源投入、隐性费用和外部居间费用列出来。
- 明确收入分配、成本承担、报销规则、亏损承担和财务审批。
- 做完信号：赚钱和亏钱时，谁说了算、谁承担，合同都有答案。

### Step 6: 写清退出和争议处理
- 约定退出条件、冷静期、股权或分成处理、账号交接、未完成项目处理。
- 写清争议解决方式、管辖地、证据留存和违约责任。
- 做完信号：合作破裂时，不需要靠吵架决定资产归属。

### Step 7: 标记律师介入项
- 对高金额、长周期、独家授权、人格权、商标、股权、竞业相关条款打上“律师必看”。
- 在签字前集中问律师，不用碎片化猜测。
- 做完信号：明确哪些风险自己能判断，哪些必须交给专业人士。

## 判断点 / 决策树（如有分支）

```text
如果合同里没有退出机制 → 暂缓签约，先补退出条款
如果涉及独家/永久/可转授权 → 找律师审
如果账号或商标不是自己持有 → 先确认归属和使用边界
如果自己仍在职且有竞业/保密 → 先核劳动合同
如果对方拒绝写清分成和资产 → 不要用情义替代合同
如果金额小但人格权/IP长期让渡 → 仍按高风险处理
```

## 模板 / 清单 / 打分卡（可复制粘贴）

| 检查项 | 关键问题 | 当前答案 | 风险等级 | 待补条款 |
|---|---|---|---|---|
| 合作交换 | 我要什么/对方给什么/我付出什么？ |  | 高/中/低 |  |
| 劳动与竞业 | 是否违反在职合同或保密义务？ |  | 高/中/低 |  |
| IP 归属 | 内容、商标、昵称、课程归谁？ |  | 高/中/低 |  |
| ID 归属 | 账号、域名、社群、后台谁控制？ |  | 高/中/低 |  |
| IT 归属 | 素材、数据、源文件、系统谁拥有？ |  | 高/中/低 |  |
| 授权范围 | 平台、期限、独家、转授权是否清楚？ |  | 高/中/低 |  |
| 经济账 | 出钱出力、成本、分成、亏损怎么算？ |  | 高/中/低 |  |
| 退出机制 | 退出、拆伙、争议怎么处理？ |  | 高/中/低 |  |

## 常见坑（3-5 条硬红线）
- ❌ 不要因为对方是熟人或大佬，就跳过合同。
- ❌ 不要只谈开始怎么赚钱，不谈分手怎么收场。
- ❌ 不要随手签授权书，授权书可能比主合同更致命。
- ❌ 不要忽略账号、后台、素材源文件这类“看不见的资产”。
- ❌ 不要用本清单替代律师，尤其是股权、竞业、人格权和长期授权。

## 附录：实例（1 个跑通的例子，与主流程分开）

两个人准备共创一个播客 IP。签约前检查发现：账号由 A 手机注册，剪辑工程在 B 电脑里，节目名还没注册商标，商业合作由第三方朋友介绍但没有居间费用约定。按清单处理后，双方补充条款：账号和商标归项目公司，双方都有后台查看权但改密需双签；剪辑源文件每月归档到共用云盘；商业合作收入先扣除明确成本，再按比例分成；任何一方退出时，节目名和历史内容不得单方带走，新增个人节目需另起名称。最后再交律师审定。
