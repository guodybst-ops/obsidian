# [SOP] 039-贵人链接进度汇报法

## 一句话
先做出小结果，再用进度汇报维持贵人链接。

## 什么时候用
- 想链接前辈、导师、社群大佬、潜在合作方时。
- 已经获得建议、资源或机会，需要持续跟进时。
- 自己背景普通，但愿意主动做事、补位和反馈时。
- **红线**：不适用于只想索取资源、不准备行动的人。

## 输入
- 自己目前能做的基本盘：技能、时间、案例、账号、作品。
- 对方正在做的项目、社群、内容或公开需求。
- 一条可上手的小任务。
- 进度汇报模板。

## 输出
- 一次低打扰的自荐或跟进消息。
- 一份阶段性进度汇报。
- 一个可持续的小结果循环。

## 主流程

### Step 1: 做出基本盘
- 先完成能证明主动性的作品、账号、案例、任务或学习记录。
- 不要空口说“我很想学”，要拿出“我已经做了什么”。
- 做完信号：对方不认识你，也能从材料看出你有行动力。

### Step 2: 找到对方身边可上手的杂活
- 观察对方公开内容、社群、活动、项目里缺什么。
- 优先找低风险、重复性、耗时但不关键的任务。
- 做完信号：你能说清“我可以具体帮你做哪一件小事”。

### Step 3: 主动自荐
- 用短消息说明你是谁、做过什么、能帮什么、预计怎么交付。
- 不要求对方立刻给大机会，只请求一个小试用。
- 做完信号：对方可以用“好 / 不用 / 你先试试”快速回复。

### Step 4: 实践对方建议
- 如果对方给建议，先照做一轮，不急着追问更多。
- 遇到问题自己先查、先试、先记录。
- 做完信号：你能带着结果回来，而不是带着同一个问题回来。

### Step 5: 定期反馈进度
- 按周、双周或关键节点汇报：做了什么、得到什么、遇到什么、下一步做什么。
- 汇报要短、具体、有结果，不写长篇情绪。
- 做完信号：对方能快速看到自己的建议产生了价值。

### Step 6: 持续输出小结果
- 把每次建议转成作品、数据、案例、客户反馈或可复用文档。
- 小结果稳定后，再请求更大机会或更深建议。
- 做完信号：链接关系从“求帮忙”变成“共同看见进展”。

### Step 7: 给对方提供价值
- 反向提供信息、整理、反馈、传播、连接或执行支持。
- 价值不一定大，但要真实、及时、减轻对方负担。
- 做完信号：对方感到你不是只拿资源，而是能共创。

## 判断点 / 决策树

```text
如果还没有作品或行动 → 退回 Step 1
如果不知道能帮什么 → 退回 Step 2 观察对方需求
如果对方给建议后没有执行 → 不要继续追问，先做 Step 4
如果汇报超过 300 字还没说结果 → 重写为“动作-结果-下一步”
如果连续 2-3 次没有回应 → 降低频率，继续自己做结果
```

## 模板 / 清单 / 打分卡

**自荐模板**

> 你好，我是【姓名/身份】。我最近已经做了【具体基本盘】。看到你在做【项目/活动/内容】，我可以先帮你做【一个小任务】，预计【时间】交付【产物】。如果你觉得合适，我可以先试一版。

**进度汇报模板**

| 模块 | 内容 |
|---|---|
| 上次建议 | |
| 我做了什么 | |
| 具体结果 | 数据 / 作品 / 反馈 |
| 我学到什么 | |
| 下一步 | |
| 需要你判断的问题 | 只问 1 个 |

## 常见坑
- ❌ 不要一上来就求大资源。
- ❌ 不要只说自己很努力，要展示小结果。
- ❌ 不要把进度汇报写成情绪倾诉。
- ❌ 不要收到建议后不执行，又继续要建议。
- ❌ 不要只拿不还，链接要能给对方减负。

## 附录：实例

一个普通学生想链接社群前辈。她先整理了 10 篇社群精华笔记，做成公开文档；观察到前辈活动缺少志愿者，就自荐负责签到和会后资料整理。活动后，她按周汇报：整理了多少资料、帮助多少人找到信息、下一步想把资料做成 FAQ。几轮后，对方开始把更多运营小任务交给她，她也持续积累作品和机会。
