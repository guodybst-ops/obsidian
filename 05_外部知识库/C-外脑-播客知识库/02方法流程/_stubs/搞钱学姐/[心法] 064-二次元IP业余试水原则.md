# [心法] 二次元IP业余试水原则

## 一句话（≤ 30 字）
做小 IP，先业余试水，不要 All in。

## 什么时候想起它（触发场景，3-5 条）

- 你看到二次元、谷子、潮玩或小 IP 很赚钱，想立刻入局。
- 你有角色、画风或故事灵感，但还没有稳定粉丝。
- 你想做周边、授权或二创，但不确定能不能变现。
- 你发现自己只是被风口刺激，并没有长期创作习惯。
- **反向触发**：当你想辞职全职做 IP 时。

## 具体怎么用（1-3 条动作，≤ 100 字）

- 保留主业，用业余时间围绕一个共鸣点持续发角色和故事。
- 先验证是否有稳定互动、铁粉和小批量周边需求。
- 有授权、生产、签约机会时，先核对版权、成本和平台规则。

## 反例（1 个即可，让你能立刻识别陷阱）

只看到淘宝二次元增长和小艺术家被签约，就辞职做 IP；更新一个月后断更，既没粉丝，也没版权和生产能力。

## 常见误读（1-3 条，可选）

- 不要把“画着玩”理解成随便糊弄；它仍然需要持续更新。
- 不要把二次元等同于稳赚；行业有不确定性和平台风险。
- 不要忽视 AI 生成内容的标注、原创和平台识别问题。
