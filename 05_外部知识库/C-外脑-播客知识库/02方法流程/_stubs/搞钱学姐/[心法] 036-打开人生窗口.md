# [心法] 打开人生窗口

## 一句话
觉得人生变窄时，先换视角、去探索，再决定下一步。

## 什么时候想起它
- 你只在原有环境里比较，越来越觉得人生没有选择。
- 你把一个大愿望拆成过高门槛，迟迟没有出发。
- 你对陌生生活方式有好奇，却只停留在想象。
- **反向触发（想起它就要警觉）**：开始只用焦虑、流量或短期收益替自己做决定。

## 具体怎么用
- 主动进入一个陌生但安全的场域，先观察真实的人和生活方式。
- 把“以后再说”的愿望缩成一次能完成的出发、体验或对话。

## 反例
只刷别人旅行或创业的结果，再用自己的条件不足证明“我做不到”，人生窗口会越来越窄。
