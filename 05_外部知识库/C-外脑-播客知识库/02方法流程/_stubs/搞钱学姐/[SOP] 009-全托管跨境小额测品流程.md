# [SOP] 全托管跨境小额测品流程

## 一句话（≤ 40 字）
用小批量测品进入全托管跨境平台。

## 什么时候用（触发条件，3-5 条 bullet）

- 你有供应链、库存、工厂资源或低客单产品。
- 你想低门槛测试跨境平台。
- 你不确定哪个产品适合海外市场。
- 你需要先跑通测品和补货，不想一开始重投入。
- **红线**：不适用于不了解平台罚款、侵权、发货规则就盲目上架的情况。

## 输入（做之前要准备的东西）

- 5-10 个候选产品。
- 供货价、库存、补货周期、可接受毛利。
- 平台规则：全托管 / 半托管、罚款、仓储、退货、品控。
- 云仓或发货方案。

## 输出（做完得到什么）

- 一组通过平台审核的测品。
- 一张补货节奏表。
- 一张平台风险清单。
- 一个是否继续放量或转半托管的判断。

## 主流程（核心，占篇幅 ≥ 60%）

### Step 1: 选择平台模式并拆责任边界

- 优先从全托管或半托管里选一个模式。
- 写清自己负责什么、平台负责什么。
- 列出平台负责的销售、流量、履约、客服部分。
- 列出你负责的选品、供货、补货、价格、质量部分。
- 做完信号：你知道自己需要做选品、定价、供货还是运营，不会把平台能力误当成自己的能力。

### Step 2: 小批量测品

- 不一开始定制大货。
- 先用 5-10 个市场通货或轻量库存测试。
- 做完信号：每个产品都有上架数量、成本和观察指标。

### Step 3: 按数据补货

- 看销售速度、退货、差评、加购和平台反馈。
- 只给跑出信号的产品补货。
- 做完信号：补货不是凭感觉，而是跟着销售数据走。

### Step 4: 接入云仓或稳定发货

- 如果节假日、人手或跨境时效压力大，提前准备云仓。
- 发货不稳会放大罚款和差评风险。
- 做完信号：你知道每个产品的最晚补货和最晚发货时间。

### Step 5: 管理 SKU 复杂度

- 花色、尺码、款式越多，库存和出错越高。
- 先做少量 SKU，等数据稳定再扩展。
- 做完信号：SKU 数量和管理能力匹配。

### Step 6: 识别平台风险

- 逐条检查罚款、仓储、侵权、品控、差评、退货规则。
- 高风险品类先不碰。
- 做完信号：每个风险都有预案或放弃理由。

### Step 7: 决定下一阶段

- 全托管跑通：继续小规模扩品。
- 某类产品稳定：考虑半托管或品牌化。
- 风险大于收益：停止补货，清库存。
- 做完信号：下一步不是惯性加码，而是基于数据选择。

## 判断点 / 决策树（如有分支）

```text
不懂平台罚款规则 -> 暂不上架
产品只能大批量定制 -> 暂缓，先找可小测产品
销售有信号但发货跟不上 -> 先补履约能力
退货/差评高 -> 停止补货，查质量和描述
稳定跑通 -> 再考虑半托管或品牌化
```

## 常见坑（3-5 条硬红线）

- 不要一开始大批量定制。
- 不要只看平台流量，不看罚款和履约规则。
- 不要 SKU 一次铺太多。
- 不要把短期爆单当成长期产品力。

## 附录：实例（1 个跑通的例子，与主流程分开）

有一批低客单产品时，先选 5-10 个上全托管平台，给出合理供货价，由平台测试海外受众。只给销售和评价都稳定的产品补货；如果发货压力变大，先接云仓，而不是继续盲目扩 SKU。
