# [SOP] 031-大白话合同风险兜底法

## 一句话
把合作风险翻译成合同条款，先兜底再签字。

## 什么时候用
- 准备签商稿、服务、合伙、雇佣、外包等合作合同时。
- 对合同条款看不懂，但已经知道自己最担心什么时。
- 合作中出现新变量，需要补充规则或补充协议时。
- **红线**：金额高、责任重、周期长的合同，不只靠自查，必须找律师。

## 输入
- 合作目标、报价、交付物、付款方式、周期、参与方名单。
- 自己最担心的 3-5 个风险。
- 对方提供的合同初稿，或 AI 生成的基础合同框架。
- 可咨询的律师、法务或熟悉合同的人。

## 输出
- 一份“白话诉求 → 合同条款”的兜底清单。
- 一份检查过双方义务是否对等的合同版本。
- 需要律师确认的问题列表。

## 主流程

### Step 1: 列出合作诉求和风险
- 写清楚这次合作你必须拿到什么：钱、署名、数据、案例权、交付边界、退出条件。
- 写清楚你最怕发生什么：拖款、无限返工、临时加需求、对方违约、知识产权不清。
- 做完信号：你能用白话说出“这份合同至少要保护我哪几件事”。

### Step 2: 生成基础合同框架
- 用现有模板或 AI 生成基础框架，先覆盖主体、费用、交付、验收、违约、保密、知识产权、争议解决。
- 遇到行业特殊合作，就补上专门模块，例如账号授权、素材使用、员工离职、客户归属。
- 做完信号：合同不再只有口头约定，而是有完整章节。

### Step 3: 把不懂的法律诉求写成白话条款
- 把“我怕对方一直让我改”写成“修改次数、修改范围、超出费用”。
- 把“我怕做完拿不到钱”写成“预付款、节点款、逾期付款责任”。
- 把“我怕对方临时反悔”写成“取消合作、终止合作、已发生费用结算”。
- 做完信号：每个风险都能在合同里找到对应条款。

### Step 4: 检查双方约束是否对等
- 对照双方义务：你违约有什么责任，对方违约是否也有责任。
- 对照权利边界：对方能要求你什么，你能要求对方什么。
- 遇到“只罚你、不罚对方”的条款，标红要求修改。
- 做完信号：合同不是单方面保护对方。

### Step 5: 标出必须请律师看的问题
- 标出金额大、违约责任重、知识产权复杂、长期排他、股权合伙、劳动关系等高风险条款。
- 把问题整理成“我担心什么 + 当前条款怎么写 + 想请你判断什么”。
- 做完信号：律师能快速定位要看的重点，而不是从头猜你的需求。

### Step 6: 合作中新变量及时补条款
- 一旦出现新交付、新人员、新费用、新素材、新渠道，先补书面约定再继续推进。
- 小变更可用邮件、聊天记录确认；大变更用补充协议。
- 做完信号：合作变化有书面痕迹，不靠记忆和情分。

## 判断点 / 决策树

```text
如果金额高、周期长、责任重 → 先付费咨询律师，再签字
如果只是小额低风险合作 → 跑完白话兜底清单，再签字
如果合同只约束你、不约束对方 → 退回 Step 4 修改
如果合作内容发生变化 → 退回 Step 6 补充条款
如果说不清自己怕什么 → 退回 Step 1 先列风险
```

## 模板 / 清单 / 打分卡

| 白话担心 | 对应条款 | 当前是否写清 | 需要修改 |
|---|---|---|---|
| 对方拖款 | 付款节点、逾期责任 | 是 / 否 | |
| 对方无限返工 | 修改次数、超出费用 | 是 / 否 | |
| 对方临时加需求 | 需求变更流程 | 是 / 否 | |
| 成果被乱用 | 知识产权、使用范围 | 是 / 否 | |
| 合作突然终止 | 终止条件、费用结算 | 是 / 否 | |
| 双方责任不对等 | 违约责任 | 是 / 否 | |

## 常见坑
- ❌ 不要因为对方熟就不签书面约定。
- ❌ 不要把“我以为”当成合同条款。
- ❌ 不要只检查价格，忽略验收、违约和知识产权。
- ❌ 不要用 AI 生成合同后直接签，AI 只能帮你起草框架。
- ❌ 不要等纠纷发生后才补条款，变量出现时就补。

## 附录：实例

一位内容服务者接企业商稿，报价 20000 元。她先列出三类风险：客户拖款、客户要求无限修改、客户把稿件二次授权给其他账号。合同里对应补上：50% 预付款，交付初稿后 3 个工作日内反馈；免费修改 2 轮，超出按每轮 1000 元计费；稿件仅限品牌自有账号发布，二次授权需另行书面确认。金额和知识产权都较敏感，她把这三条发给律师复核后再签。
