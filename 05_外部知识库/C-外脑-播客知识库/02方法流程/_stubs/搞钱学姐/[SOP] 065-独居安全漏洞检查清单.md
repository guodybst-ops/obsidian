# [SOP] 独居安全漏洞检查清单

## 一句话（≤ 40 字）
按门锁、监控、定位和取证排查独居漏洞。

## 什么时候用（触发条件，3-5 条 bullet）

- 你刚租房、买房、装修完或换城市独居。
- 房子曾经有中介、房东、装修工、保洁或前租客进出。
- 你在社交平台发过居住环境、窗外景色或小区信息。
- 你遇到陌生外卖、门口异常、物品丢失或钥匙异常。
- **红线**：不适用于正在发生危险的现场；现场危险先报警和离开。

## 输入（做之前要准备的东西）

- 房屋钥匙、门锁、门口地毯、备用钥匙位置。
- 过往进出人员名单：房东、中介、装修工、保洁、维修人员。
- 公开发布过的照片、视频和定位信息。
- 门口、室内、小区公共区域的监控条件。
- 可联系的物业、邻居、朋友和派出所电话。

## 输出（做完得到什么）

- 一张“独居安全漏洞表”。
- 一组门锁、监控、照片和取证的修复动作。
- 完成信号：你知道谁能进入、哪里有记录、异常时怎么取证。

## 主流程（核心，占篇幅 ≥ 60%）

### Step 1: 列出所有可能进出的人

- 写下过去 30 天接触过房屋钥匙、密码或门禁的人。
- 如果有装修、维修、保洁或中介带看，把姓名、电话、时间段补上。
- 做完信号：你能说清“谁曾经有机会进入这套房”。

### Step 2: 更换门锁并验证旧钥匙

- 换锁时拍视频，记录旧锁、新锁、钥匙数量和安装过程。
- 换完后拿旧钥匙实际试一次，确认旧钥匙打不开新锁。
- 如果旧钥匙能开，立刻联系锁匠复检，并暂停让外人进入。
- 做完信号：旧钥匙、备用钥匙和未知钥匙都已被验证失效。

### Step 3: 清除隐蔽备用钥匙

- 检查地毯下、门框上、鞋柜、消防栓、窗台、弱电井等位置。
- 找到任何旧钥匙都拍照、收走，并记录发现位置。
- 做完信号：门口周边没有任何可被外人取用的钥匙。

### Step 4: 补齐门口和室内监控

- 安装带监控的门铃，确保有人出现在门口会记录和提醒。
- 如有装修或长期无人居住，给室内关键入口加临时监控。
- 检查断电、断网、存储满时是否还能保留关键记录。
- 做完信号：门口异常、室内进出、小区公共监控能互相印证。

### Step 5: 清理公开定位线索

- 回看社交平台上窗外景色、小区楼栋、门牌、外卖单、物业标识。
- 删除或打码可能被“三张图定位”的内容。
- 发布居住相关内容时延迟发布，不暴露实时位置。
- 做完信号：陌生人不能通过照片轻易定位到楼栋和门牌。

### Step 6: 建立异常取证流程

- 遇到物品丢失、陌生外卖、门口异常，先保存电话、截图、监控和时间线。
- 有财物损失或疑似入室，先报警，再联系物业调监控。
- 用 16 倍速等方式缩小监控排查范围时，先锁定最小时间窗。
- 做完信号：异常事件能形成“时间、人物、证据、损失”的闭环。

## 判断点 / 决策树（如有分支）

```text
正在有人敲门或试图进入 -> 先离开危险区域并报警
发现旧钥匙能开新锁 -> 暂停入住，立刻复检换锁
发现物品丢失但无证据 -> 先锁定时间窗，再调监控
收到陌生外卖或电话 -> 不开门，核对平台订单和商家
照片疑似暴露住址 -> 删除/打码，并检查是否已被传播
```

## 常见坑（3-5 条硬红线）

- 不要以为换锁就一定安全，旧钥匙必须实际验证。
- 不要把钥匙放在地毯、门框或鞋柜等门口位置。
- 不要在社交平台暴露窗景、门牌、小区和外卖单。
- 不要等物业或警察替你筛海量监控，先自己缩小时间窗。
- 不要用“门口放男鞋”替代真正的门锁和监控。

## 附录：实例（1 个跑通的例子，与主流程分开）

一次装修纠纷里，房主发现旧空调丢失。她先报警，再去物业调监控；因为前一天拍过全屋视频，能把丢失时间锁定在 24 小时内，最后从监控看到对方进入并拿走空调。后续又发现旧钥匙竟能打开新锁，这说明“换锁后验证旧钥匙失效”必须成为独居安全检查项。
