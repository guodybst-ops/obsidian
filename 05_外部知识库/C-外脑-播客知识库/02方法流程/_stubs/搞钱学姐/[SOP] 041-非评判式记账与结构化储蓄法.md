# [SOP] 041-非评判式记账与结构化储蓄法

## 一句话（≤ 40 字）
先无评判记录钱流，再分篮子储蓄。

## 什么时候用（触发条件，3-5 条 bullet）
- 每月收入不低，但月底总觉得钱不见了。
- 信用卡、花呗、分期、冲动消费让现金流失控。
- 想开始储蓄，却一记账就自责、羞耻或放弃。
- 已经有存款目标，需要把钱分成安全感、长期目标和自由支配几类。
- **红线**：不适用于已经出现债务违约、催收或法律风险的紧急场景，先处理债务危机。

## 输入（做之前要准备的东西）
- 最近 1-3 个月的账单、支付记录、信用卡账单和现金支出回忆。
- 一个记账工具：App、表格或纸本均可。
- 当前月收入、固定支出、债务还款、已有存款。
- 一个不被打扰的 30-60 分钟复盘时间。

## 输出（做完得到什么）
- 一张月度钱流向表。
- 3-5 个主要漏钱点。
- 一套三层或多篮子储蓄账户安排。
- 至少 1 个可执行的下月调整动作。
- 完成信号：你能说清楚钱去哪了、下月先存哪笔钱、哪些支出要暂停。

## 主流程（核心，占篇幅 ≥ 60%）

### Step 1: 记录所有支出
- 把最近 1-3 个月每一笔支出先记下来，不评价、不解释、不美化。
- 遇到想不起用途的支出，就标记为“待确认”，不要因为不完整而停止。
- 做完信号：账单里 80% 以上的支出已经进入同一张表。

### Step 2: 标注支出类型
- 给每笔支出贴上类型：刚需、成长、健康、关系、快乐、冲动、债务、未知。
- 遇到一笔钱同时属于两类，先按“主要目的”归类。
- 做完信号：你能看到哪些类别占比最高。

### Step 3: 识别小额漏点
- 汇总 50 元以下、100 元以下或高频订阅类支出。
- 找出“单笔不痛、累计很痛”的项目，例如零食、外卖、会员、闲置小物。
- 做完信号：列出 3 个最想先止漏的支出入口。

### Step 4: 设置三层储蓄篮子
- 先建立“生存安全篮子”：覆盖 3-12 个月必要生活费，目标可逐步拉到一年 gap 资金。
- 再建立“长期目标篮子”：学习、买房、养老、保险、长期投资等。
- 最后建立“自由支配篮子”：旅行、礼物、爱好、奖励自己。
- 做完信号：每笔收入到账后，知道先进入哪个篮子。

### Step 5: 固定转入比例
- 给每个篮子设置收入占比，先从可坚持的小比例开始。
- 如果当月收入不稳定，改用固定金额或“收入到账即转出”的方式。
- 做完信号：下次发工资或收款时，不需要重新思考就能转账。

### Step 6: 月末复盘调整
- 每月底看一次：哪类超支、哪类低估、哪类储蓄成功。
- 只调整一个变量，例如减少一个订阅、提高 5% 储蓄、延长冷静期。
- 做完信号：下月有一条明确调整规则，而不是泛泛说“少花点”。

## 判断点 / 决策树（如有分支）

```text
如果每月结余为负数 → 先止漏和处理债务，不急着做长期投资
如果每月结余为正但留不住 → 先设置到账即转出的储蓄篮子
如果已有 3 个月生活费 → 继续补到 6-12 个月，并建立长期目标篮子
如果一记账就自责 → 回到 Step 1，只记录事实，暂停评价 7 天
```

## 模板 / 清单 / 打分卡（可复制粘贴）

| 日期 | 金额 | 支出项目 | 类型 | 是否必要 | 是否可延迟 | 下月动作 |
|---|---:|---|---|---|---|---|
|  |  |  | 刚需/成长/健康/关系/快乐/冲动/债务/未知 | 是/否 | 是/否 | 保留/减少/暂停/替代 |

| 储蓄篮子 | 目标金额 | 当前金额 | 每月转入 | 用途边界 |
|---|---:|---:|---:|---|
| 生存安全篮子 |  |  |  | 只用于生活费、医疗、失业缓冲 |
| 长期目标篮子 |  |  |  | 学习、房产、养老、长期资产 |
| 自由支配篮子 |  |  |  | 爱好、旅行、礼物、奖励 |

## 常见坑（3-5 条硬红线）
- ❌ 不要边记账边骂自己，羞耻感会让流程中断。
- ❌ 不要一上来追求 100% 精确，先建立持续记录。
- ❌ 不要把所有钱放在一个账户里，容易把安全钱花成快乐钱。
- ❌ 不要只盯大额消费，小额高频漏点也会吞掉结余。
- ❌ 不要为了省钱牺牲必要健康支出。

## 附录：实例（1 个跑通的例子，与主流程分开）

一个月入 12000 元的人复盘后发现：房租和通勤 4500 元，外卖奶茶 1800 元，购物 2200 元，订阅会员 300 元，实际结余只有 500 元。她先不评价自己，只把外卖奶茶和购物标成“高频漏点”，下月设置工资到账后先转 2000 元到生存安全篮子、500 元到长期目标篮子、500 元到自由支配篮子；同时把外卖预算降到 1000 元，购物先放入 48 小时清单。月底复盘时，只看是否完成转账和是否少掉一个漏点。
