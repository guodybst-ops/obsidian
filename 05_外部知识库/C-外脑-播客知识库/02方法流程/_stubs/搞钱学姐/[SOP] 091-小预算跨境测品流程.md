# [SOP] 小预算跨境测品流程

## 一句话（≤ 40 字）
用小批量真实订单验证跨境选品。

## 什么时候用（触发条件，3-5 条 bullet）

- 手里只有 5000 到 1 万预算，想尝试跨境或热点周边。
- 还不确定卖什么、在哪卖、卖给谁。
- 想从 1688、义乌市场或供应商小批量找货。
- **红线**：不用于侵权、假货、无法报关或平台禁售产品。

## 输入（做之前要准备的东西）

- 目标平台候选：例如新兴跨境平台、夜市、本地社群或小店。
- 热点/品类线索：赛事、演唱会、宠物、童装、包挂、轻定制等。
- 预算上限：首批货、物流、样品、平台费用和售后预留。
- 供应商名单：至少 3 个可小批量或一件起批的供给。

## 输出（做完得到什么）

- 一组真实订单或明确无需求结论。
- 一张产品利润和履约复盘表。
- 一批可继续加量、轻定制或放弃的 SKU。

## 主流程（核心，占篇幅 ≥ 60%）

### Step 1: 先定“卖给谁”和“在哪卖”

- 写出目标买家：球迷、宠物主人、亲子人群、演唱会粉丝、跨境平台买家等。
- 选择一个主要渠道：夜市、社群、小红书、虾皮、TikTok Shop、新兴跨境平台等。
- 完成信号：能说清“谁会在什么场景下买”。

### Step 2: 用数据找品而不是凭感觉押品

- 在下游平台查销量、搜索、图搜、词搜、竞品价格和同款数量。
- 标记红海/蓝海：同款商家太多则优先找差异化或放弃。
- 完成信号：知道这个品是“没人卖”“有人卖且还动销”还是“已经拥挤”。

### Step 3: 回到 1688 或义乌市场找确定供给

- 找 3 个以上供应商，确认起批量、单价、见重尺、发货时效、退货率和售后。
- 优先选择支持小批量、一件起批、轻定制、履约数据透明的商家。
- 完成信号：能算清单件总成本和最小试错成本。

### Step 4: 先小批量上架或铺货

- 首批只拿一箱、一袋或最低起订量，不压超出预算的库存。
- 泛铺型买家可以先铺多个 listing，看哪个出现真实订单。
- 完成信号：拿到真实付款、询单或明确无人购买。

### Step 5: 根据动销做轻改款

- 对有订单的 SKU 做图片、标题、组合、颜色、轻定制或包装优化。
- 对无动销 SKU 限时下架或停止补货。
- 完成信号：从泛铺转向 1 到 3 个更明确的精品方向。

### Step 6: 放量前过合规和履约清单

- 检查商标、IP、肖像、平台禁售、报关报税、物流体积重量和退税。
- 物流和属性数据不准时，不放量。
- 完成信号：知道最可能导致罚款、封店或亏损的点在哪里。

### Step 7: 复盘并决定加量或换品

- 复盘订单数、毛利、退款、物流、客服、平台处罚风险和补货周期。
- 达到利润和履约目标再加量；否则记录原因并换品。
- 完成信号：下一轮测试不重复同一个坑。

## 判断点 / 决策树

```text
如果有真实订单 + 供给稳定 + 合规安全 → 小幅加量
如果有热度但无付款 → 改标题/渠道/价格后再测一次
如果有订单但履约不稳 → 限量卖，不放量
如果存在授权或平台高风险 → 换表达或放弃
如果同款商家过多且毛利薄 → 做轻定制或换细分人群
```

## 常见坑（3-5 条硬红线）

- 不要先问“怎么卖”，先问“卖给谁”。
- 不要一上来重仓库存。
- 不要忽略授权、肖像、商标和平台规则。
- 不要只看商品热度，不看物流和履约。
- 不要用 AI 结果替代人工合规确认。

## 附录：实例

一个预算 8000 元的新手想做世界杯宠物球衣。先确认目标买家是养宠球迷，渠道选小红书和跨境新兴平台；再查同款销量和搜索热度；然后在 1688 找支持小批量的供应商，确认见重尺和发货时效。首批只拿最低起订量上架测试，有订单后再做队伍颜色、宠物尺寸和轻定制优化。若发现使用队徽存在授权风险，则改成非侵权的配色、口号或泛足球元素。
