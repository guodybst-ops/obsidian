# [框架] 078-创业项目胜率优先筛选模型

## 一句话（≤ 40 字）
先看胜率和优势，再看项目规模。

## 什么时候用（触发条件，3-5 条 bullet）
- 准备选择创业、副业、项目或新业务方向。
- 很想证明自己，倾向选很难、很体面、很大的事。
- 面前有多个机会，不知道哪个更值得投入。
- 想判断“这是不是我的游戏”。
- **红线**：不适用于只追求理想表达、不以赚钱为主要判断标准的项目。

## 评估对象（这个框架用来打分的是什么）
- 评估对象：一个具体创业项目、副业机会或赚钱游戏。
- 颗粒度：至少具体到客群、产品、渠道和变现方式。
- 目标：筛出“更容易赚钱、自己有优势、收益可接受”的项目。

## 维度定义（框架的骨）

### 维度 1：游戏胜负率——同场玩家有多少人能赚钱

**观测信号**：

| ✅ 好信号（这方面强） | ❌ 坏信号（这方面弱） |
|---|---|
| 10 个入场玩家里，多数能赚到钱 | 10 个玩家只有 1 个能赚钱 |
| 普通执行者也能拿到小结果 | 只有头部、天才或极少数能赢 |
| 项目赚钱路径清楚 | 只靠运气、风口或单点爆发 |

→ **怎么问出来 / 怎么观察出来**：问“同一批入场的人，赚钱比例大概是多少？”

### 维度 2：个人优势排名——你能成为第几名

**观测信号**：

| ✅ 好信号（这方面强） | ❌ 坏信号（这方面弱） |
|---|---|
| 你有渠道、资源、执行、经验或成本优势 | 完全没有优势，只靠热情 |
| 能估计自己在玩家里的位置 | 不知道对手是谁 |
| 优势能持续一段时间 | 优势很快被复制 |

→ **怎么问出来 / 怎么观察出来**：问“我凭什么成为这个游戏里能赚钱的人？”

### 维度 3：收益规模——第 N 名赚的钱是否值得你做

**观测信号**：

| ✅ 好信号（这方面强） | ❌ 坏信号（这方面弱） |
|---|---|
| 第 3、第 5、第 10 名的收益也能接受 | 只有第一名有意义 |
| 收益覆盖时间、机会成本和心理成本 | 做成了也不够支付投入 |
| 现金流回收路径清楚 | 规模很大但离你很远 |

→ **怎么问出来 / 怎么观察出来**：问“如果我只能做到中上水平，这个收益我还要不要？”

### 维度 4：难度与接地气——是否为了证明自己而选难题

**观测信号**：

| ✅ 好信号（这方面强） | ❌ 坏信号（这方面弱） |
|---|---|
| 项目简单、接地气、能赚钱 | 为了体面选复杂难题 |
| 尊重市场规律和传统打法 | 看不起地推、销售、广告、基础运营 |
| 愿意做“能赚钱的事” | 用创业证明自己很特别 |

→ **怎么问出来 / 怎么观察出来**：问“我是在赚钱，还是在用创业证明自己？”

### 维度 5：安全感与退出——失败后是否还能换局

**观测信号**：

| ✅ 好信号（这方面强） | ❌ 坏信号（这方面弱） |
|---|---|
| 有生活底线、现金流和退出路径 | 一失败就击穿生活 |
| 项目资产可迁移 | 失败后经验、客户、内容都清零 |
| 能接受不是自己的游戏就不玩 | 明知不适合还硬撑 |

→ **怎么问出来 / 怎么观察出来**：问“如果这不是我的棋，我能不能及时离场？”

## 打分卡 / 分级表（可复制粘贴）

| 维度 | 0 分：危险 | 1 分：偏弱 | 2 分：可试 | 3 分：强适配 | 当前分 | 证据 |
|---|---|---|---|---|---:|---|
| 游戏胜负率 | 几乎没人赚钱 | 少数赚钱 | 部分赚钱 | 多数可赚钱 |  |  |
| 个人优势排名 | 无优势 | 优势弱 | 有明确优势 | 能进前列 |  |  |
| 收益规模 | 中位收益不够 | 勉强覆盖 | 可接受 | 很值得 |  |  |
| 难度与接地气 | 为体面选难题 | 过度复杂 | 基本接地气 | 简单能赚钱 |  |  |
| 安全感与退出 | 失败击穿 | 退出困难 | 可止损 | 可换局 |  |  |

分级：
- **A 级（12-15 分）**：优先投入，先小规模跑通再放大。
- **B 级（8-11 分）**：可以试，但要设止损线和验证周期。
- **C 级（0-7 分）**：暂缓，不要用创业证明自己。

## 打完分怎么用（决策后果）

- 胜负率低：除非你有绝对优势，否则不入场。
- 个人优势低：先补优势或换更适合自己的游戏。
- 收益规模低：即使能做，也不要当主线。
- 难度维度低：检查自己是不是放不下面子。
- 退出维度低：先算生活底线和止损线。

## 常见坑（3-5 条）
- ❌ 不要先看行业规模，再忘了问自己能不能赢。
- ❌ 不要选一个只有万里挑一才能成功的游戏。
- ❌ 不要把创业当成证明自己聪明、体面或厉害的考场。
- ❌ 不要看不起简单、接地气、能赚钱的生意。
- ❌ 不要在不是自己的游戏里硬扛。

## 附录：实例（1 个跑通的例子）

一个人面前有两个项目：A 是高端内容平台，规模大但只有头部能赚钱；B 是本地优惠服务，规模不大但 10 个玩家里 6-8 个能赚到钱，且她有渠道和执行优势。按框架打分，A 胜负率 0、个人优势 1、收益规模 3、难度 0、退出 1，总分 5；B 胜负率 3、个人优势 2、收益规模 2、难度 3、退出 2，总分 12。结论：先做 B，用高胜率项目建立现金流，再考虑 A。
