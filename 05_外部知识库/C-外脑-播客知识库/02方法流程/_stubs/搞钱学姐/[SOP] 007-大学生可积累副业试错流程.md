# [SOP] 大学生可积累副业试错流程

## 一句话（≤ 40 字）
用一个月试错找到可积累的副业方向。

## 什么时候用（触发条件，3-5 条 bullet）

- 你是大学生，想搞钱但不知道选哪条路。
- 你在家教、内容、摄影、实习、技能服务之间摇摆。
- 你担心副业只能赚短期钱，不能积累能力。
- 你想用一个月做出作品集或真实反馈。
- **红线**：不适用于违法违规、代写作弊、伤害长期信用的赚钱方式。

## 输入（做之前要准备的东西）

- 3-5 个候选副业方向。
- 每周可投入时间。
- 已有技能、兴趣、设备、平台账号。
- 一个可展示输出的位置：作品集、账号、样片、服务清单。

## 输出（做完得到什么）

- 一个可继续投入的副业方向。
- 一份作品集 / 账号 / 样片 / 服务清单。
- 一张“短期钱 vs 长期积累”评估表。

## 主流程（核心，占篇幅 ≥ 60%）

### Step 1: 列出低成本候选方向

- 写出 3-5 个你能立刻尝试的方向。
- 每个方向都要能在一周内产出一个小作品或一次服务。
- 做完信号：每个方向都有一个本周动作。

### Step 2: 排除低积累方向

- 删掉明显损害信用、没有作品沉淀、只靠重复劳动换钱的方向。
- 如果方向只能赚一次钱，标记为“短期钱”，不要当主线。
- 做完信号：剩下的方向至少能沉淀技能、作品或人脉。

### Step 3: 设定一个月测试期

- 给每个候选方向设一个测试动作和观察指标。
- 指标可以是作品反馈、咨询数、成交数、简历加分、账号数据。
- 做完信号：你知道 30 天后看什么。

### Step 4: 同时看数据和体感

- 每周记录数据，也记录自己是否愿意继续做。
- 不只追热点，也不只凭兴趣。
- 做完信号：你能说清哪个方向既有反馈，也不持续消耗你。

### Step 5: 选择一个可积累方向

- 从测试结果里选一个方向继续投入。
- 把输出整理成作品集、账号、样片或服务说明。
- 做完信号：别人能通过你的公开材料判断你能做什么。

### Step 6: 主动投给真实需求方

- 把作品发给可能需要的人、社群、老师、公司或客户。
- 不等别人发现你，主动举手。
- 做完信号：至少获得一次真实回应或拒绝。

### Step 7: 复盘长短期收益

- 记录这件事赚到的钱、学到的技能、认识的人、留下的作品。
- 只赚短期钱但没有积累的，降级为临时收入。
- 做完信号：你能决定继续、换方向或只偶尔做。

## 判断点 / 决策树（如有分支）

```text
没有任何候选方向 -> 从已有技能和身边需求各列 3 个
方向只能短期换钱 -> 不当主线，只作为现金补充
数据好但极度消耗 -> 降低投入或换方向
体感好但无人需要 -> 调整展示方式或换目标人群
有作品有反馈 -> 继续投入 30 天
```

## 模板 / 清单 / 打分卡（可复制粘贴）

| 方向 | 本周动作 | 30 天指标 | 短期收入 | 长期积累 | 体感 | 结论 |
|---|---|---|---:|---|---|---|
|  |  |  |  | 技能 / 作品 / 人脉 / 信用 | 1-5 | 继续 / 暂停 / 临时做 |

## 常见坑（3-5 条硬红线）

- 不要为了短期钱牺牲信用。
- 不要只看别人说什么赚钱，要看自己能不能做出作品。
- 不要测试一天没反馈就放弃。
- 不要把作品藏起来，机会需要被看见。

## 附录：实例（1 个跑通的例子，与主流程分开）

如果你想试摄影副业，不要只说“我会拍照”。先约 3 次校园拍摄，整理 9 张样片，发布到小红书和简历作品集，再主动投给社团、活动组织者或实习岗位。30 天后看有没有咨询、转介绍或简历加分。
