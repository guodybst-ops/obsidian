# [SOP] 054-年度保单年检流程

## 一句话（≤ 40 字）
每年检查保障是否重复、缺口或过期。

## 什么时候用（触发条件，3-5 条 bullet）
- 每年固定做一次家庭财务复盘时。
- 结婚、离婚、生子、父母变老、换工作、自由职业或收入变化后。
- 体检报告出现新异常，担心以后买不了保险时。
- 家里已有多张保单，但没人说得清各自赔什么。
- **红线**：本流程只做保单梳理，具体产品选择和健康告知需咨询专业人士。

## 输入（做之前要准备的东西）
- 所有保单合同、电子保单、缴费记录和保险公司 APP 截图。
- 家庭成员信息：年龄、职业、婚姻、子女、父母、健康状况。
- 最近一次体检报告、既往病史、收入和家庭责任变化。
- 现有受益人、投保人、被保险人、保费、保额和续保信息。

## 输出（做完得到什么）
- 一张家庭保单总表。
- 重复保障、缺口保障、受益人错误、年龄节点风险清单。
- “保留 / 调整 / 咨询专业人士 / 暂不处理”的行动结论。
- 完成信号：每张保单为什么买、赔什么、谁受益、何时缴费都能说清。

## 主流程（核心，占篇幅 ≥ 60%）

### Step 1: 汇总所有保单
- 按家庭成员列出健康险、医疗险、重疾险、意外险、寿险、储蓄类保险、养老金或教育金。
- 记录保费、保额、保障期限、缴费期限、续保规则和受益人。
- 做完信号：没有“我好像买过一份但找不到”的保单。

### Step 2: 标记关键年龄节点
- 给父母、自己、伴侣、孩子分别标出未来 1-3 年的年龄节点。
- 重点关注父母 55 岁前后、58 岁前后，成年人 26-28 岁体检变化、38-40 岁重疾成本变化，孩子出生 28 天后和 12 岁前等节点。
- 做完信号：知道哪些保障如果现在不看，未来可能变贵或变难。

### Step 3: 检查重复和缺口
- 对比每张保单实际赔付范围，找出重复保障和未覆盖风险。
- 重点检查百万医疗险、防癌险、意外险、意外医疗、重疾险、寿险是否功能重叠或缺失。
- 做完信号：每一项风险至少知道“已覆盖 / 重复 / 缺口 / 不需要”。

### Step 4: 核对人生节点变更
- 结婚后检查配偶是否需要成为受益人；生子后检查是否要调整给孩子的安排。
- 离婚、再婚、父母养老责任变化后，重新确认受益人和投保安排。
- 做完信号：理赔时钱会流向你真正想照顾的人。

### Step 5: 检查现金流和缴费压力
- 汇总年度保费占收入比例，确认未来几年是否能持续缴纳。
- 对缴费压力过高、保障重复或目标不清的保单打上复查标记。
- 做完信号：保费不会挤压家庭必要生活和应急现金。

### Step 6: 形成年度调整清单
- 把问题分成“立刻改受益人、补资料咨询、等待下次复盘、暂不调整”。
- 涉及退保、加保、健康告知、未成年人受益安排时，先咨询专业人士。
- 做完信号：有明确下一步，而不是只知道“保险很复杂”。

## 判断点 / 决策树（如有分支）

```text
如果保单找不全 → 先补齐保单，不做调整
如果同一风险重复覆盖 → 判断是否真重复，再咨询是否保留
如果健康报告已有异常 → 不要自己猜，先做专业核保咨询
如果婚姻/子女状态变化 → 先查受益人
如果年度保费压力过大 → 优先保基础风险，不盲目加新单
如果父母或孩子临近年龄节点 → 提前 3-6 个月复查方案
```

## 常见坑（3-5 条硬红线）
- 不要买完保险就多年不看，人生节点变化会让原安排失效。
- 不要只看产品名字，要看实际赔付范围。
- 不要让前任、默认法定继承或错误受益人留在保单里。
- 不要在体检异常后隐瞒健康状况自行投保。
- 不要为了“看起来很全”重复购买，保费压力也是风险。

## 附录：实例（1 个跑通的例子，与主流程分开）

一个三口之家年检时发现：丈夫婚前寿险受益人仍是父母，妻子有百万医疗险又买了功能重叠的防癌险，孩子出生后没有单独整理医疗保障，父母一方接近 55 岁还没有梳理医疗险续保问题。按流程处理后，先补齐保单总表，再把受益人调整提交给保险公司；重复项不立刻退，先咨询专业人士；父母保障单独约时间核保；孩子保障放入下月家庭财务会议处理。
