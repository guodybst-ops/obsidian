# [SOP] 合作争议事实材料留存与公开说明流程

## 一句话
在合作争议中先固化事实材料，再决定是否进行有限公开说明。

## 什么时候用
- 合作、版权、账户或资产归属出现公开争议。
- 你需要把口头争执改成可核对的事实材料。
- 争议已进入或可能进入正式处理程序。
- **红线**：本流程不构成法律意见；涉及权利义务和公开表述时，应咨询执业律师。

## 输入
- 合同、授权、聊天、邮件、平台记录和创作过程材料。
- 可核对的时间、人物、文件和版本信息。
- 已公开的对方说法与待回应的具体事项。

## 输出
- 一份按时间排序的事实时间线。
- 一份“可公开 / 仅供专业人士 / 不回应”的材料清单。

## 主流程

### Step 1: 固化原始材料
- 导出并保存原始文件、聊天记录、授权文件、平台通知和版本信息。
- 记录取得时间和来源，不修改原件。
- 做完信号：每项材料都能追溯到原始载体。

### Step 2: 建立事实时间线
- 只写时间、参与人、发生事项和对应证据编号。
- 将推测、情绪和法律结论单独标注，不混入事实栏。
- 做完信号：第三方能按时间核对每一项材料。

### Step 3: 区分回应范围
- 将问题分为必须澄清的事实、应交由程序处理的争议和不宜公开的信息。
- 对未核实内容不作扩张性回应。
- 做完信号：每个公开句子都对应一份可核对材料。

### Step 4: 走正式程序并更新记录
- 将材料交给适格的专业人士或程序渠道。
- 公开表达只说明已核实事实和程序状态，不替代裁决。
- 做完信号：后续新增材料能继续挂入同一时间线。

## 判断点 / 决策树

```text
没有原始材料 -> 不公开定性，先回到 Step 1
事实和判断混在一起 -> 回到 Step 2 拆分
涉及权利义务解释 -> 咨询执业律师
争议进入程序 -> 以程序材料为准，避免舆论替代裁决
```

## 模板 / 清单 / 打分卡

| 时间 | 事项 | 参与人 | 原始材料 | 可公开范围 |
|---|---|---|---|---|
|  |  |  | 文件 / 链接 / 截图编号 | 可公开 / 专业处理 / 不公开 |

## 常见坑

- ❌ 不要修改、剪裁或覆盖原始材料。
- ❌ 不要把个人判断写成已被裁决的事实。
- ❌ 不要用公开回应替代正式法律程序。
