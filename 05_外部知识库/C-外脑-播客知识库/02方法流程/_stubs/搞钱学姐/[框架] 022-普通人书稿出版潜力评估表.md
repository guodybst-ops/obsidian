# [框架] 普通人书稿出版潜力评估表

## 一句话（≤ 40 字）
用 4 个维度判断普通人书稿是否值得出版。

## 什么时候用（触发条件）
- 已经有一批文章、故事、日记、访谈稿，想判断能否成书时。
- 准备给编辑、出版人、经纪人递选题时。
- 想把个人经历从“能写”推进到“能出版”时。
- **红线**：不适用于只想练笔、暂不面向读者的私人写作。

## 评估对象
- 一本非虚构书稿、个人故事选题、公众号合集或人物经验型写作项目。
- 颗粒度到“一个书名 + 一类读者 + 一组核心篇章”。

## 维度定义

### 维度 1：聊天感——读者是否愿意一路听下去

**观测信号**：

| ✅ 好信号 | ❌ 坏信号 |
|---|---|
| 语言像真人在说话，有节奏、有停顿 | 全是概念、口号和正确废话 |
| 开头 3 分钟能进入具体场景 | 开头大段背景、时代意义 |
| 有哭、笑、尴尬、犹豫等真实质感 | 读起来像汇报材料或自我表彰 |

→ **怎么问出来 / 怎么观察出来**：把开头 1000 字读给一个目标读者听，看对方是否追问“后来呢”。

### 维度 2：文字里是否看得见人——故事是否有具体生命

**观测信号**：

| ✅ 好信号 | ❌ 坏信号 |
|---|---|
| 有具体人物、场景、选择和代价 | 只有观点，没有人经历了什么 |
| 写得出一个人为什么这样活 | 人物像案例标签或工具人 |
| 细节能让读者看到自己或身边人 | 细节空泛，读完记不住任何画面 |

→ **怎么问出来 / 怎么观察出来**：抽一章问“这一章里最像人的一句话 / 一个动作是什么”，答不出就要补场景。

### 维度 3：独特定位——是否满足“所有人都能谈，只有我能写”

**观测信号**：

| ✅ 好信号 | ❌ 坏信号 |
|---|---|
| 主题公共，但视角来自不可替代的经历 | 选题只是追热点，谁都能写 |
| 能一句话说清“我比同题作者特殊在哪里” | 只能说“这个话题很火” |
| 标题、目录、样章都围绕独特身份展开 | 身份、故事、读者需求互相脱节 |

→ **怎么问出来 / 怎么观察出来**：套一句话：“所有人都能谈____，只有我能写____。”填不出来就定位未成型。

### 维度 4：普通读者代入感——读者是否相信“我也可以”

**观测信号**：

| ✅ 好信号 | ❌ 坏信号 |
|---|---|
| 读者能从故事里看到自己的困境和可能性 | 主角太遥远，只剩仰望 |
| 有失败、烂稿、试错和小进步 | 只有成功结果，没有过程 |
| 不是炫耀，而是给人一点行动信心 | 读完只觉得“跟我没关系” |

→ **怎么问出来 / 怎么观察出来**：请目标读者读完样章后写下“我也想试的一件事”，写不出说明代入感不足。

## 打分卡 / 分级表（可复制粘贴）

| 书稿 / 选题 | 聊天感 | 人物可见度 | 独特定位 | 读者代入感 | 综合结论 |
|---|---|---|---|---|---|
|  | 0-5 | 0-5 | 0-5 | 0-5 |  |

- **A 级：17-20 分**：可推进书稿方案，补目录、样章和目标读者画像。
- **B 级：12-16 分**：有出版潜力，先重写低分维度再递选题。
- **C 级：0-11 分**：更适合继续连载、练稿或做内容账号，不急着出版。

## 打完分怎么用

- 聊天感低：先改开头和叙述语气，不急着扩目录。
- 人物可见度低：补访谈、场景、冲突和细节。
- 独特定位低：重做书名和核心命题。
- 读者代入感低：加入普通读者可复用的过程、失败和选择。

## 常见坑

- ❌ 不要把热点话题误当成出版定位。
- ❌ 不要一上来追求“写得高级”，先保证有人愿意读下去。
- ❌ 不要只有道理，没有人。
- ❌ 不要用“我很特别”替代读者可感知的独特证据。

## 附录：实例

一个作者想写“女性成长”。打分后发现主题很大，但无法回答“只有我能写什么”。她把命题改成“从小镇柜员到城市项目经理的十年账本”，补进工作场景、家庭压力、第一次涨薪、第一次离职等章节。独特定位从 1 分升到 4 分，书稿方向从泛成长变成可识别的基层女性经验。
