# [框架] 老板IP业务适配判断表

## 一句话（≤ 40 字）
用 6 个维度判断老板要不要做 IP。

## 什么时候用（触发条件）
- 老板、创始人、顾问或专业服务者想做个人 IP 时。
- 公司想把内容、销售、转化和交付连起来时。
- 流量增长后，产品和商业模式开始涌现但不稳定时。
- **红线**：不适用于还没有业务、没有交付、只想当网红的人。

## 评估对象
- 一个老板 / 创始人 / 高管 / 顾问的 IP 化机会。
- 颗粒度到“这个人 + 这个业务 + 这类客户 + 这个渠道”。

## 维度定义

### 维度 1：主业基础——是否已有业务流和真实交付

**观测信号**：

| ✅ 好信号 | ❌ 坏信号 |
|---|---|
| 已有稳定产品、服务、客户或案例 | 还没有 0 到 1，就急着谈 IP |
| 内容能从真实业务里长出来 | 只能讲人设，讲不出业务细节 |
| 展示给别人看也学不了核心能力 | 一看就能抄，且抄了也差不多 |

→ **怎么问出来 / 怎么观察出来**：问“如果没有流量，这个业务本身是否还能成交？”

### 维度 2：商业定位——卖什么、卖给谁是否清楚

**观测信号**：

| ✅ 好信号 | ❌ 坏信号 |
|---|---|
| 能一句话说清卖什么、卖给谁 | 想服务所有人 |
| 目标客户有明确预算和购买场景 | 只有粉丝画像，没有客户画像 |
| 产品价格、成交路径、复购逻辑清楚 | 内容火了但不知道卖什么 |

→ **怎么问出来 / 怎么观察出来**：填空：“我卖____给____，帮他们解决____。”

### 维度 3：目标客户内容偏好——客户愿不愿意看这种内容

**观测信号**：

| ✅ 好信号 | ❌ 坏信号 |
|---|---|
| 内容主题来自客户真实关心的问题 | 只追平台热点 |
| 客户看完会产生信任或咨询 | 只有同行点赞或泛粉围观 |
| 平台选择匹配客户的信息习惯 | 在客户不看的平台持续用力 |

→ **怎么问出来 / 怎么观察出来**：拿 10 条内容问目标客户“哪条会让你想进一步聊业务？”

### 维度 4：人设差异——同样内容由你说有什么不同

**观测信号**：

| ✅ 好信号 | ❌ 坏信号 |
|---|---|
| 经历、立场、表达风格有辨识度 | 换个人说也一样 |
| 人设来自真实业务和真实性格 | 硬凹造型迎合流量 |
| 差异能增强信任，不只是博眼球 | 有记忆点但和成交无关 |

→ **怎么问出来 / 怎么观察出来**：问“同样观点，我说和别人说的差异是什么？这个差异会帮助成交吗？”

### 维度 5：流量转化交付——接得住多少信任

**观测信号**：

| ✅ 好信号 | ❌ 坏信号 |
|---|---|
| 有咨询、筛选、成交、交付和售后流程 | 流量来了只能临时接待 |
| 产品和交付能力能承接曝光 | 爆款之后交付崩掉 |
| 能衡量线索质量和成交率 | 只看播放量和涨粉 |

→ **怎么问出来 / 怎么观察出来**：模拟 100 个咨询进来，看是否知道谁跟进、卖什么、怎么交付。

### 维度 6：销售团队协同——IP 能否融入业务组织

**观测信号**：

| ✅ 好信号 | ❌ 坏信号 |
|---|---|
| 内容能成为销售材料和客户教育工具 | 内容部门和销售部门互不相干 |
| 销售知道如何承接 IP 带来的线索 | 老板一个人热闹，团队接不住 |
| 反馈能反哺选题、产品和话术 | 内容只服务曝光，不服务生意 |

→ **怎么问出来 / 怎么观察出来**：让销售用 3 条内容去跟进客户，看是否能提升沟通效率。

## 打分卡 / 分级表（可复制粘贴）

| 对象 | 主业基础 | 商业定位 | 内容偏好 | 人设差异 | 转化交付 | 销售协同 | 综合结论 |
|---|---|---|---|---|---|---|---|
|  | 0-5 | 0-5 | 0-5 | 0-5 | 0-5 | 0-5 |  |

- **适合做老板 IP：24-30 分**：可系统投入内容与转化。
- **先做业务内容：16-23 分**：先围绕客户问题稳定输出，不追爆款。
- **暂不适合：0-15 分**：先补业务、产品、交付或销售基础。

## 打完分怎么用

- 主业基础低：先做业务，不要急着包装 IP。
- 商业定位低：先确定卖什么卖给谁。
- 转化交付低：先补咨询、成交和交付 SOP。
- 销售协同低：让内容进入销售流程，而不是单独做账号。

## 常见坑

- ❌ 不要把自媒体涨粉等同于能赚钱的 IP。
- ❌ 不要客户还没完成 0 到 1 就开始谈 IP。
- ❌ 不要只做人设，不接业务。
- ❌ 不要追爆款，忘了生意本身。

## 附录：实例

一个 B 端顾问想做 IP。评估发现：她有真实客户案例，能说清卖给谁，但内容只讲行业观点，无法带来咨询；团队也没有线索承接流程。结论是“先做业务内容”。下一步不是拍情绪爆款，而是围绕客户高频问题做 20 条案例拆解，并同步建立咨询表、报价页和销售跟进话术。
