# [SOP] 小白访谈信息差挖掘法

## 一句话（≤ 40 字）
用小白问题访谈陌生行业，挖出可变现信息差。

## 什么时候用（触发条件，3-5 条 bullet）

- 你想做访谈 IP，但面对的是自己不懂的行业。
- 你想通过采访离职者、创业者、店主或从业者挖信息差。
- 你需要把一个行业讲给普通小白听懂。
- 你想从看热闹升级到理解赚钱链路。
- **红线**：不适用于只想套隐私、猎奇曝光或未经同意发布敏感内容。

## 输入（做之前要准备的东西）

- 一个访谈主题：行业、职业、离职路径、创业项目或副业模式。
- 嘉宾公开资料：账号、作品、店铺、过往采访、评论区问题。
- 小白读者画像：他们听不懂什么、想知道什么、怕什么。
- 录制同意、发布边界、删改规则和备选嘉宾。

## 输出（做完得到什么）

- 一份小白访谈提纲。
- 一张信息差清单：成本、收入、渠道、风险、坑、关键人脉。
- 一条可发布内容或选题信号。
- 完成信号：读者看完知道“如果我真投 10 万，要先问哪些问题”。

## 主流程（核心，占篇幅 ≥ 60%）

### Step 1: 把访谈目标写成投资问题

- 不写“聊聊你的故事”，改成“如果我明天真金白银投 10 万做这件事，我要问清什么”。
- 列出成本、收入、渠道、风险、资质、周期、退出方式。
- 做完信号：提纲能服务决策，而不是只听热闹。

### Step 2: 做轻量预研

- 用公开资料、平台搜索和 AI 辅助理解行业基础词。
- 查嘉宾账号、评论区、历史内容和可验证数据。
- 不懂的地方标记出来，准备在访谈里问。
- 做完信号：你知道哪些是常识问题，哪些是需要嘉宾解释的问题。

### Step 3: 设计小白话术

- 用“我问一个比较浅的问题”降低冒犯感。
- 用“我的粉丝也是小白，想帮他们问一下”把问题转成用户视角。
- 不装懂，直接请嘉宾把复杂概念讲成人话。
- 做完信号：问题浅，但不空；嘉宾愿意解释，观众能听懂。

### Step 4: 前采筛掉不合适嘉宾

- 录制前先简短沟通主题、边界和可公开内容。
- 判断嘉宾是否有真实经历、表达能力和基本诚意。
- 前采不对劲就暂停，不强行录。
- 做完信号：录制前已经降低放鸽子、删稿和无内容风险。

### Step 5: 现场追问赚钱链路

- 追问“第一单怎么来、客户从哪来、成本是什么、利润剩多少”。
- 追问“最容易踩的坑、谁在中间赚钱、哪一步最难复制”。
- 对数字、流程和结论要求举例。
- 做完信号：不是只听人生故事，而是拿到行业运行方式。

### Step 6: 整理信息差并保护边界

- 把访谈内容拆成“普通人不知道但有用的信息”。
- 删除不能公开的隐私、商业机密和敏感细节。
- 发布前按约定给嘉宾确认必要边界。
- 做完信号：内容既有信息密度，也不伤害嘉宾和读者。

### Step 7: 用选题信号吸引下一轮资源

- 在内容里留下明确场景，让品牌、嘉宾或读者知道你能承接什么。
- 记录评论区问题，作为下一次访谈提纲。
- 如果某类问题反复出现，升级成系列选题。
- 做完信号：一次访谈带来下一次嘉宾、商单或读者问题。

## 判断点 / 决策树（如有分支）

```text
行业完全不懂 -> 先轻量预研，再用小白话术问
嘉宾前采无诚意 -> 换嘉宾
回答太抽象 -> 追问第一单、成本、渠道、利润、坑
涉及隐私或商业机密 -> 不发布或打码处理
内容没有信息差 -> 回到 Step 1，重写决策问题
```

## 模板 / 清单 / 打分卡（可复制粘贴）

### 小白访谈提纲模板

| 模块 | 问题 |
|---|---|
| 入行入口 | 你第一步是怎么进入这个行业的？ |
| 第一单 | 第一笔钱从哪里来？客户为什么信你？ |
| 成本结构 | 如果我真投 10 万，钱会花在哪里？ |
| 收入结构 | 谁付钱？按什么计费？多久回款？ |
| 中间商 | 这个链条里谁在赚差价？ |
| 信息差 | 普通人最不知道的一点是什么？ |
| 风险坑 | 小白最容易在哪一步亏钱？ |
| 可复制性 | 哪些人适合做，哪些人别做？ |
| 下一步 | 如果只试 7 天，第一步做什么？ |

## 常见坑（3-5 条硬红线）

- 不要装懂，装懂会问不出信息差。
- 不要只问情绪故事，不问成本、渠道和风险。
- 不要为了爆款忽略嘉宾删稿、隐私和发布边界。
- 不要把单个嘉宾案例包装成所有人可复制。
- 不要只为爱发电，阶段目标和变现路径要提前设好。

## 附录：实例（1 个跑通的例子，与主流程分开）

面对一个完全不懂的行业，访谈者可以直接说：“我问一个比较浅的问题，我的粉丝也都是小白。假设我明天要真金白银花 10 万做这个项目，我要先问清哪些问题？”这个问法既保留小白视角，又能把嘉宾带到成本、收入、风险和信息差上。
