# [框架] 租房买房决策评估表

## 一句话（≤ 40 字）
用 5 个维度判断现在该买房还是租房。

## 什么时候用（触发条件）
- 正在纠结背房贷还是继续租房时。
- 准备买首套房、置换、卖房止损或长期持有时。
- 房价下跌、收入变化、城市变动导致原计划失效时。
- **红线**：不替代个性化财务、税务、法律建议；高杠杆买房前需独立测算。

## 评估对象
- 一个具体城市、板块、房源与个人家庭财务状况的组合。
- 颗粒度到“这套房 + 这个价格 + 我的收入和现金流”。

## 维度定义

### 维度 1：刚需抗跌——所谓刚需能否扛住最差情况

**观测信号**：

| ✅ 好信号 | ❌ 坏信号 |
|---|---|
| 学区、通勤、家庭照护等需求真实且长期 | 只是被“必须有个根”推动 |
| 最差情况下仍能接受价格下跌和流动性下降 | 只想正常上涨，不敢想下跌 |
| 租房无法满足核心生活需求 | 租房体验其实可替代 |

→ **怎么问出来 / 怎么观察出来**：问“如果 5 年不涨、跌 30%、卖不掉，我还愿意住吗？”

### 维度 2：估值水平——租售比和房价收入比是否合理

**观测信号**：

| ✅ 好信号 | ❌ 坏信号 |
|---|---|
| 租金回报能接近或覆盖利率 / 机会成本 | 租金远低于月供和资金机会成本 |
| 房价收入比在家庭可承受范围内 | 需要透支多年收入和家庭支援 |
| 价格能用租金、收入、现金流解释 | 只能靠“以后会涨”解释 |

→ **怎么问出来 / 怎么观察出来**：计算年租金 / 总房价、总房价 / 家庭年可支配收入、月供 / 稳定月收入。

### 维度 3：长周期趋势——人口、城市化、杠杆是否支持继续上涨

**观测信号**：

| ✅ 好信号 | ❌ 坏信号 |
|---|---|
| 城市人口、产业、收入仍有支撑 | 人口流出、产业弱化、库存高 |
| 杠杆空间和购买力还有余量 | 居民杠杆已高，新增购买力不足 |
| 长期需求能支撑租金和交易 | 只靠短期政策或情绪反弹 |

→ **怎么问出来 / 怎么观察出来**：看人口流入、产业岗位、成交量、库存、居民收入与杠杆，而不是只看近期涨跌。

### 维度 4：现金流与杠杆——房子会不会拖垮生活

**观测信号**：

| ✅ 好信号 | ❌ 坏信号 |
|---|---|
| 月供、税费、维修、空置都能覆盖 | 只算首付和月供，不算持有成本 |
| 有 12 个月以上安全垫 | 收入一波动就断供或焦虑 |
| 租金现金流能部分覆盖持有成本 | 租金不足，长期纯消耗现金流 |

→ **怎么问出来 / 怎么观察出来**：做“正常 / 悲观 / 极端”三档现金流表。

### 维度 5：资产配置——房产占比是否过高

**观测信号**：

| ✅ 好信号 | ❌ 坏信号 |
|---|---|
| 买房后仍有现金、保险、流动资产 | 全部资产都压在一套房上 |
| 能接受房产低流动性 | 随时可能需要现金却买入重资产 |
| 购买力稀释和机会成本已纳入计算 | 只看名义价格能否回到高点 |

→ **怎么问出来 / 怎么观察出来**：计算买房后房产净值占家庭总资产比例，以及现金能撑多久。

## 打分卡 / 分级表（可复制粘贴）

| 房源 / 方案 | 刚需抗跌 | 估值水平 | 长周期趋势 | 现金流杠杆 | 资产配置 | 综合结论 |
|---|---|---|---|---|---|---|
| 买入 | 0-5 | 0-5 | 0-5 | 0-5 | 0-5 |  |
| 继续租 | 0-5 | 0-5 | 0-5 | 0-5 | 0-5 |  |

- **买入优先**：刚需抗跌 ≥ 4，现金流 ≥ 4，估值不低于 3。
- **继续租优先**：估值低、现金流低、资产配置过度集中。
- **观望 / 换标的**：刚需真实但估值或现金流不通过。

## 打完分怎么用

- 现金流低于 3 分：不要买，先降预算或提高安全垫。
- 估值低于 3 分：等待价格、租金或收入改善，不要用信仰补差额。
- 刚需高但资产配置低：考虑更小、更便宜或更灵活的标的。

## 常见坑

- ❌ 不要把“保值”当成确定收益。
- ❌ 不要只看房价名义回到高点，忽略购买力稀释。
- ❌ 不要用过去 30 年经验直接外推未来。
- ❌ 不要把租房焦虑当成买房能力。

## 附录：实例

一个人在高位买房后亏损 40%，纠结是否卖出。评估发现：租金回报无法覆盖机会成本，家庭资产高度集中在房产，现金流压力高，但房子仍满足通勤和居住需求。结论不是立刻斩仓或死扛，而是分别测算“卖出后现金如何配置”和“继续持有 5 年现金流是否可承受”，再决定。
