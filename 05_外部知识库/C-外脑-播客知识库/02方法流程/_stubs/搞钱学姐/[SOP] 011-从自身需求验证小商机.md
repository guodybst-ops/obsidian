# [SOP] 从自身需求验证小商机

## 一句话（≤ 40 字）
从自己的刚需出发，小批量验证身边商机。

## 什么时候用（触发条件，3-5 条 bullet）

- 你自己刚遇到一个高频、具体、愿意花钱解决的问题。
- 你身边有人反复问同类资源、商品、渠道或经验。
- 你想用低成本方式试一次卖货、组织资源或做服务。
- 你还没有成熟产品，只想先验证是否有人买单。
- **红线**：不适用于需要重资产投入、强资质许可或你完全不了解的生意。

## 输入（做之前要准备的东西）

- 一个你亲身体验过的需求。
- 3-10 个可能有同类需求的人。
- 一个可小批量交付的资源：商品、团购、服务、资料或组织能力。
- 一段低成本触达话术。
- 你能承受的试错预算和时间上限。

## 输出（做完得到什么）

- 一张小商机验证表。
- 一次小批量成交或明确拒绝反馈。
- 一个是否继续复制、换人群或停止的判断。
- 完成信号：你能说清谁买、为什么买、哪里卡住、下次怎么改。

## 主流程（核心，占篇幅 ≥ 60%）

### Step 1: 记录自己的刚需

- 写下最近让你主动找解决方案的需求。
- 标注它出现的场景、频率、痛感和你愿意付出的价格。
- 做完信号：你能用一句话说清“我为什么需要它”。

### Step 2: 找到同类人群

- 列出和你处境相似的人：同学、同事、同城用户、社群成员、前同事。
- 观察他们是否也在问同类问题，或是否已经为类似方案付费。
- 做完信号：你至少找到 3 个可触达的候选用户。

### Step 3: 组织最小资源

- 选择最轻的交付方式：代买、拼单、团购、资料整理、小群服务。
- 控制首批规模，优先保证可交付和可退款。
- 做完信号：你能在不追加大成本的情况下完成第一批交付。

### Step 4: 发起低成本触达

- 用具体场景开头，不用宏大宣传。
- 说明你自己为什么需要、准备提供什么、价格或参与方式是什么。
- 做完信号：你收到明确的报名、询问、拒绝或沉默数据。

### Step 5: 根据受挫点调整

- 如果没人回应，先换表达方式，再换触达人群。
- 如果有人问但不买，追问价格、信任、交付、时机哪个卡住。
- 如果有人买但交付吃力，缩小承诺或降低批量。
- 做完信号：你知道问题出在人群、话术、价格还是交付。

### Step 6: 复盘是否能复制

- 统计成交人数、收入、成本、耗时、售后压力和转介绍可能。
- 判断它是一次性帮忙，还是能形成可重复的小项目。
- 做完信号：你得到继续、调整或停止的结论。

## 判断点 / 决策树（如有分支）

```text
自己没有真实需求 -> 暂停，回到 Step 1
同类人群找不到 -> 换需求或换场景
有人问但没人买 -> 回到 Step 4 改话术/价格/信任证明
有人买但交付失控 -> 缩小批量或改成交付形式
小批量成交且售后可控 -> 进入下一轮复制
```

## 常见坑（3-5 条硬红线）

- 不要把“我喜欢”直接当成“别人会买”。
- 不要第一轮就囤货、租场地或做复杂包装。
- 不要只听夸奖，要看对方是否付费或投入时间。
- 不要把一次成交误判为可规模化生意。

## 附录：实例（1 个跑通的例子，与主流程分开）

一个学生发现自己想买有设计感的明信片，也发现宿舍同学有送礼和装饰需求。她先小批量拿货，逐间宿舍沟通，记录哪些款式被问得最多、什么价格能成交、哪些说法会被拒绝。第一轮卖完后，再决定是继续补货、换款式，还是停止这个小生意。
