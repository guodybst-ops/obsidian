# [框架] 快钱项目长短线判断表

## 一句话（≤ 40 字）
用 6 个维度判断快钱项目能不能长期做。

## 什么时候用（触发条件）
- 看到 CPS、套利、热点、短剧分发、返利、带货等机会时。
- 某个副业项目短期很赚钱，但不确定能否加码时。
- 团队被快钱项目带动，开始想扩大投入时。
- **红线**：不用于判断违法、灰产或明显侵权项目；这类项目直接排除。

## 评估对象
- 一个快钱型项目、套利机会、平台红利或副业模式。
- 颗粒度到“一个平台 + 一个产品 / 流量渠道 + 一种变现方式”。

## 维度定义

### 维度 1：是否拥有用户——钱是用户给的，还是上游漏下来的

**观测信号**：

| ✅ 好信号 | ❌ 坏信号 |
|---|---|
| 有自己的用户池、社群、账号或复购关系 | 只是在别人的流量池里捡佣金 |
| 能直接触达用户并理解需求 | 用户是谁、为什么买都不知道 |
| 项目结束后用户还能留下 | 平台停了，所有关系归零 |

→ **怎么问出来 / 怎么观察出来**：问“如果上游明天停佣，我还能联系谁、卖什么、服务谁？”

### 维度 2：上游政策影响——生死是否掌握在别人规则里

**观测信号**：

| ✅ 好信号 | ❌ 坏信号 |
|---|---|
| 平台规则变化只影响利润，不影响生存 | 平台一改规则，项目立刻归零 |
| 有多渠道、多平台或自有承接 | 单一平台、单一政策、单一接口 |
| 合规边界清楚 | 靠打擦边球维持收入 |

→ **怎么问出来 / 怎么观察出来**：列出项目最依赖的 3 个外部规则，看哪一个变化会导致项目停摆。

### 维度 3：信息差寿命——别人多久能学会

**观测信号**：

| ✅ 好信号 | ❌ 坏信号 |
|---|---|
| 信息差背后有执行、供应链、用户理解壁垒 | 只是早知道一个链接或玩法 |
| 越做越懂行业 | 越多人进场，利润立刻塌 |
| 可以从信息差升级为能力差 | 只能靠“别让别人知道”赚钱 |

→ **怎么问出来 / 怎么观察出来**：问“这个玩法被公开后，我还有什么优势？”

### 维度 4：投入产出周期——赚的是现金流还是幻觉

**观测信号**：

| ✅ 好信号 | ❌ 坏信号 |
|---|---|
| 投入小、回款快、亏损可控 | 回款慢、垫资大、账期长 |
| 能快速试错并停损 | 为了补亏不断加码 |
| 利润计算包含人力、风险和机会成本 | 只看流水，不算成本 |

→ **怎么问出来 / 怎么观察出来**：把“投入、回款周期、毛利、坏账、人工、封号风险”写进同一张表。

### 维度 5：团队是否会被快钱带浮躁——组织状态是否被破坏

**观测信号**：

| ✅ 好信号 | ❌ 坏信号 |
|---|---|
| 团队把快钱当阶段性机会 | 团队开始拒绝慢活和基础建设 |
| 有明确止盈、止损和复盘机制 | 赚钱时膨胀，亏钱时互相甩锅 |
| 快钱不挤压主业能力建设 | 所有人只追下一个风口 |

→ **怎么问出来 / 怎么观察出来**：观察项目赚钱后，团队是否还愿意做用户体验、产品、交付和复盘。

### 维度 6：能否沉淀长期能力——项目结束后留下什么

**观测信号**：

| ✅ 好信号 | ❌ 坏信号 |
|---|---|
| 留下用户、数据、供应链、内容或销售能力 | 钱赚完，什么都没留下 |
| 能转化为下一项目的经验 | 每次都从零开始追热点 |
| 形成行业判断或可复用流程 | 只有运气故事，不能复制 |

→ **怎么问出来 / 怎么观察出来**：问“这个项目停掉后，下一件事会不会更容易？”

## 打分卡 / 分级表（可复制粘贴）

| 项目 | 用户资产 | 上游依赖 | 信息差寿命 | 投入产出 | 团队心态 | 长期能力 | 综合结论 |
|---|---|---|---|---|---|---|---|
|  | 0-5 | 0-5 | 0-5 | 0-5 | 0-5 | 0-5 |  |

- **短线机会：现金流高，但长期能力 ≤ 2 项**：小仓位快进快出，设置止盈止损。
- **可转长线：现金流可控，且能沉淀用户 / 能力 / 供应链**：逐步制度化。
- **危险项目：高上游依赖 + 高垫资 + 无合规边界**：不做或立即退出。

## 打完分怎么用

- 上游依赖低分：必须先做备选渠道，否则不加码。
- 用户资产低分：只能按短线项目管理，不要写长期故事。
- 长期能力高分：把快钱的一部分投入到流程、团队和用户资产。

## 常见坑

- ❌ 不要把时代红利误判成个人能力。
- ❌ 不要只看投入小、产出高，忽略能否持续。
- ❌ 不要在快钱项目里加不可逆杠杆。
- ❌ 不要因为短期赚钱就放弃用户体验。

## 附录：实例

一个短剧 CPS 项目短期回款快，但用户不在自己手里，上游佣金政策一变就会影响收入，信息差公开后竞争加剧。打分后判定为“短线机会”。操作策略是小团队执行、快速回款、保留利润，不把它包装成长期主业；同时把经验沉淀为投放、分发和用户洞察能力。
