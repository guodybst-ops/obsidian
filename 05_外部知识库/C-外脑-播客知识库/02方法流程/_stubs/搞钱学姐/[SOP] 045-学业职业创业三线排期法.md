# [SOP] 学业职业创业三线排期法

## 一句话
用主线、维持线和试验线安排学业、职业与创业的优先级。

## 什么时候用
- 你同时承担学业、职业和创业/副业角色。
- 三件事都重要，结果每件都被碎片时间拖垮。
- 你需要在一个阶段内明确主次。
- **红线**：不要用过度排期掩盖休息、健康或现实承受力不足。

## 输入
- 本阶段所有角色和硬截止日期。
- 每周可支配时间与不可牺牲的休息边界。
- 一个最重要的阶段目标。

## 输出
- 一张主线、维持线、试验线三栏周计划。
- 一条明确的暂缓清单。

## 主流程

### Step 1: 标出本阶段唯一主线
- 在学业、职业和创业中只选一条本阶段必须赢的主线。
- 主线必须对应真实截止日期、现金流或长期关键节点。
- 做完信号：知道本周最先被保护的时间块。

### Step 2: 给其余角色设维持线
- 每个非主线角色只保留最低必要动作。
- 不新增与主线无关的大项目。
- 做完信号：每条维持线都有清晰的“做到这里就够了”。

### Step 3: 留一条低成本试验线
- 只给探索性项目一个可停止、可复盘的小动作。
- 试验不占用主线的关键时间。
- 做完信号：试验失败也不影响主线交付。

### Step 4: 每周复盘并换线
- 复盘时间浪费、重复沟通和等待，把它们从下周计划删掉。
- 仅在阶段条件变化后切换主线。
- 做完信号：下周计划比本周更少、更清楚。

## 判断点 / 决策树

```text
三条线都写成主线 -> 退回 Step 1 重新排序
维持线开始侵占主线 -> 缩小或暂缓
试验线需要重投入 -> 先完成主线，再评估
健康或家庭边界受损 -> 降低总负荷
```

## 常见坑

- ❌ 不要把“忙”误当成三线并进。
- ❌ 不要在每条线都追求满分。
- ❌ 不要忽略沟通、等待和拖延造成的时间浪费。
