# [SOP] 034-阶段生日复盘三组问题法

## 一句话
用三组问题复盘阶段人生，沉淀下一阶段行动。

## 什么时候用
- 生日、跨年、项目结束、换工作、搬家等阶段节点。
- 感到迷茫、内耗、害怕被看见，需要重新确认自己时。
- 想把过去一段时间的经历整理成下一阶段习惯时。
- **红线**：不适用于情绪很崩溃、无法独自复盘的时刻，先找支持系统。

## 输入
- 过去 6-12 个月的日记、朋友圈、项目记录、收入记录、聊天记录。
- 一段不被打扰的时间，建议 60-90 分钟。
- 纸笔或文档。
- 可以托举你的朋友、同事、导师名单。

## 输出
- 三件最重要的事。
- 三件最需要改的事。
- 三个继续沿用的好特质。
- 一份下一阶段固定行动清单。

## 主流程

### Step 1: 回看不敢记录 / 不敢说的时刻
- 翻过去的记录，标出那些当时不敢发、不敢讲、不敢承认的经历。
- 写下当时你害怕什么：被误解、被否定、显得失败、显得不够好。
- 做完信号：你找到 3 个最想躲开的片段。

### Step 2: 列出最重要的三件事
- 从结果、关系、能力、选择里各挑候选，再压缩成 3 件。
- 每件事写清“它为什么重要”和“它带来什么复利”。
- 做完信号：这 3 件事能代表这一阶段的主线。

### Step 3: 列出最需要改的三件事
- 只写会反复制造代价的模式，不写笼统缺点。
- 每件事配一个具体替代动作，例如“提前完成”“正式沟通”“固定时间做固定的事”。
- 做完信号：每个问题都有下一次可执行动作。

### Step 4: 列出继续沿用的好特质
- 找出曾经救过你的特质：稳定输出、遇到问题解决问题、重视重大决策等。
- 写下这些特质下一阶段怎么继续发挥。
- 做完信号：你不是只看到问题，也看到可复用优势。

### Step 5: 识别托举关系
- 列出过去一年真正托住你、提醒你、帮你看见自己的人。
- 区分“情绪支持”“资源支持”“决策支持”“协作支持”。
- 做完信号：你知道下一阶段哪些关系需要珍惜和维护。

### Step 6: 固化下一阶段习惯
- 把复盘结论写成固定行动：固定时间、固定场景、固定产物。
- 每个行动只保留一个启动动作，不写宏大愿望。
- 做完信号：明天就知道第一件要做什么。

## 判断点 / 决策树

```text
如果只写出情绪，没有行动 → 退回 Step 3 写替代动作
如果只写出问题，看不到优势 → 退回 Step 4 找好特质
如果所有结论都指向“证明自己” → 退回 Step 1 看真实恐惧
如果下一阶段动作超过 5 个 → 砍到 1-3 个固定行动
```

## 模板 / 清单 / 打分卡

| 问题组 | 我的答案 | 下一阶段动作 |
|---|---|---|
| 最重要的三件事 | 1. 2. 3. | 继续投入什么 |
| 最需要改的三件事 | 1. 2. 3. | 用什么动作替代 |
| 继续沿用的好特质 | 1. 2. 3. | 放进哪个固定场景 |
| 托举我的关系 | 人名 / 关系 / 托举方式 | 如何回应和维护 |

## 常见坑
- ❌ 不要把生日复盘写成自我审判。
- ❌ 不要只列成绩，不看恐惧和关系。
- ❌ 不要把“我要变好”写成行动，要写具体习惯。
- ❌ 不要把 AI 或他人的建议当成自己的确认决策。

## 附录：实例

一个内容创作者在生日复盘时发现，自己最不敢说的是“害怕节目太小不值得被关注”。她列出最重要三件事：稳定输出、重新定位节目、建立听众连接；最需要改三件事：提前完成、正式沟通、固定时间做固定的事；继续沿用的特质：遇到问题解决问题、愿意复盘、重视重大选择。最后固化为每周一上午选题会、每周三集中录制、每月底做一次公开复盘。
