# [框架] 074-行业入局时机判断模型

## 一句话（≤ 40 字）
用五个维度判断一个行业现在能不能入。

## 什么时候用（触发条件，3-5 条 bullet）
- 准备转行、跳槽、副业、投资或进入一个新赛道。
- 看到行业很热，但不知道自己是不是晚了。
- 发现行业像“夕阳”，但怀疑里面仍有机会。
- 想判断一门生意还能不能干。
- **红线**：不适用于只看风口情绪、没有任何行业资料的拍脑袋决策。

## 评估对象（这个框架用来打分的是什么）
- 评估对象：一个具体行业、赛道、项目机会或职业进入点。
- 颗粒度：不要评估“AI”“消费”这种大词，至少细到一个细分业务。
- 目标：判断现在是抢先进入、谨慎跟进、稳定进入，还是暂缓退出。

## 维度定义（框架的骨）

### 维度 1：行业周期阶段——处在导入、成长、成熟还是衰退

**观测信号**：

| ✅ 好信号（这方面强） | ❌ 坏信号（这方面弱） |
|---|---|
| 成长期需求快、商业模式已验证 | 导入期模式没验证，只靠故事融资 |
| 成熟期仍有稳定现金流 | 成熟期增长慢，却要求高增长回报 |
| 衰退期仍有局部刚需或回光机会 | 衰退期需求快速消失，替代方案更强 |

→ **怎么问出来 / 怎么观察出来**：问“这个行业的钱现在来自新增需求、替换需求，还是存量消耗？”

### 维度 2：风险偏好匹配——行业风险是否适合你

**观测信号**：

| ✅ 好信号（这方面强） | ❌ 坏信号（这方面弱） |
|---|---|
| 高风险机会匹配你的现金流和履历承受力 | 追风口导致履历变花、现金流断裂 |
| 你清楚最坏结果并能承受 | 只看到高薪、高回报，没算失败成本 |
| 家庭、年龄、存款支持试错 | 明明追求稳定，却进入强波动行业 |

→ **怎么问出来 / 怎么观察出来**：问“如果这个机会 6 个月后失败，我损失什么，能不能承受？”

### 维度 3：商业模式验证——赚钱方式是否已经跑通

**观测信号**：

| ✅ 好信号（这方面强） | ❌ 坏信号（这方面弱） |
|---|---|
| 已有人用同类模式稳定收费 | 只有融资、补贴或流量，没有付费闭环 |
| 客户愿意持续付钱 | 用户热闹但不付费 |
| 成本结构和毛利能算清 | 只讲规模，不讲利润 |

→ **怎么问出来 / 怎么观察出来**：问“谁付钱、为什么付、能付多久？”

### 维度 4：个人成长匹配——行业速度是否适合你的能力曲线

**观测信号**：

| ✅ 好信号（这方面强） | ❌ 坏信号（这方面弱） |
|---|---|
| 行业成长给你练能力、拿结果的空间 | 行业速度快到你跟不上，很快被淘汰 |
| 你的旧经验可以迁移进来 | 完全从零开始且没有学习资源 |
| 进入后能形成第二增长曲线 | 只是逃离原行业，没有新优势 |

→ **怎么问出来 / 怎么观察出来**：问“我进去后 3 个月能产出什么可验证能力？”

### 维度 5：退出信号——什么时候该暂缓或跑路

**观测信号**：

| ✅ 好信号（这方面强） | ❌ 坏信号（这方面弱） |
|---|---|
| 有明确止损线和观察指标 | 亏了还用沉没成本硬扛 |
| 关键数据恶化时能及时调整 | 只靠情绪坚持 |
| 退出后资源可复用 | 退出就清零，资产不可迁移 |

→ **怎么问出来 / 怎么观察出来**：问“什么指标连续恶化时，我必须停止投入？”

## 打分卡 / 分级表（可复制粘贴）

| 维度 | 0 分：不清楚 | 1 分：风险高 | 2 分：可跟进 | 3 分：适合进入 | 当前分 | 证据 |
|---|---|---|---|---|---:|---|
| 行业周期阶段 | 不知道阶段 | 模式未验证/明显衰退 | 成长或成熟但有疑点 | 阶段清晰且机会匹配 |  |  |
| 风险偏好匹配 | 没算损失 | 最坏结果承受不了 | 能小规模试 | 风险收益匹配 |  |  |
| 商业模式验证 | 不知谁付钱 | 付费弱 | 有部分付费 | 付费闭环稳定 |  |  |
| 个人成长匹配 | 没有迁移能力 | 跟不上行业 | 有学习路径 | 能形成优势 |  |  |
| 退出信号 | 没止损线 | 退出会清零 | 可部分转向 | 退出机制清楚 |  |  |

分级：
- **A 级（12-15 分）**：可以进入，先做小规模验证再加码。
- **B 级（8-11 分）**：谨慎跟进，补齐信息或先从副业/试点切入。
- **C 级（0-7 分）**：暂缓进入，优先补行业研究、现金流或能力差距。

## 打完分怎么用（决策后果）

- 周期阶段低分：先做行业资料补全，不急着进。
- 风险匹配低分：不要全职跳入，先用副业或项目制测试。
- 商业模式低分：只做学习或观察，不投入大额资金。
- 个人成长低分：先补关键能力，再找低风险入口。
- 退出信号低分：先写止损线，再开始投入。

## 常见坑（3-5 条）
- ❌ 不要只因为行业热就进，热度不是商业模式。
- ❌ 不要用别人的风险偏好替代自己的风险承受力。
- ❌ 不要把夕阳行业一刀切，先看局部需求和替代节奏。
- ❌ 不要只算上行空间，不写最坏结果。
- ❌ 不要在亏损后才临时想退出机制。

## 附录：实例（1 个跑通的例子）

一个职场人想进入新 AI 应用赛道。打分发现：行业处于成长期 3 分，商业模式已有付费但还不稳定 2 分，自己的产品经验能迁移 2 分，风险承受力一般 1 分，退出信号未设 0 分，总分 8 分。结论不是立刻裸辞，而是先用 8 周做一个垂直场景小项目，设定“无付费、无用户留存、现金流压力超过阈值”三条止损线。
