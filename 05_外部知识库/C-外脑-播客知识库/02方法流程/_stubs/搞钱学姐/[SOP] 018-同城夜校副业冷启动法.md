# [SOP] 同城夜校副业冷启动法

## 一句话（≤ 40 字）
用同城兴趣课从小红书冷启动夜校副业。

## 什么时候用（触发条件，3-5 条 bullet）

- 你所在城市有上班族下班学习、社交、兴趣体验需求。
- 你能组织老师、场地或课程资源。
- 你想用小红书和私域低成本验证副业。
- 你希望先开小班跑通，再扩展活动和合作。
- **红线**：不适用于没有本地交付能力、只想线上空卖课程的情况。

## 输入（做之前要准备的东西）

- 一个同城刚需兴趣课主题。
- 可交付的老师、场地、时间和课程大纲。
- 小红书账号或本地内容发布渠道。
- 报名私域入口和收款方式。
- 第一班的最低成班人数和成本表。

## 输出（做完得到什么）

- 一场小班夜校课程。
- 一套小红书引流到私域报名流程。
- 一张成班、交付、复购和扩城复盘表。
- 完成信号：第一班有人付费到场，并留下反馈或复购线索。

## 主流程（核心，占篇幅 ≥ 60%）

### Step 1: 选择同城刚需兴趣课

- 选择下班后可参加、门槛低、体验感强的主题。
- 优先考虑琴棋书画、表达、运动、手作、生活技能等本地体验课。
- 做完信号：你能写出目标人群、上课时间、价格和成果。

### Step 2: 搭建最小交付

- 确认老师、场地、课时、材料、人数上限和退款规则。
- 首班控制规模，保证交付体验。
- 做完信号：课程不依赖大团队，也能独立开班。

### Step 3: 发布小红书同城内容

- 用同城关键词、课程成果、现场感和报名信息写笔记。
- 内容重点不是宏大愿景，而是“下班后能学什么、见到谁、得到什么”。
- 做完信号：笔记能引导用户评论、私信或进群。

### Step 4: 私域转化报名

- 把咨询用户导入群或私聊，回答时间、地点、价格、适合人群。
- 用明确名额和截止时间推动报名。
- 做完信号：达到最低成班人数并完成收款。

### Step 5: 小班精品交付

- 控制签到、破冰、课程节奏、拍照反馈和课后复盘。
- 现场收集用户对课程、老师、时间、价格的反馈。
- 做完信号：用户愿意发反馈、转介绍或报名下一场。

### Step 6: 扩展同城合作

- 和本地商家、场地、老师、社群做合作。
- 把跑通的课程复制成系列课、主题活动或联名活动。
- 做完信号：获客不只依赖单条笔记，开始有合作渠道。

### Step 7: 复制到更多城市

- 把课程大纲、老师标准、场地标准、报名话术和复盘表标准化。
- 先复制到资源条件相似的城市。
- 做完信号：第二个城市能按同一套表开出第一班。

## 判断点 / 决策树（如有分支）

```text
没人咨询 -> 回到 Step 3 改同城关键词和课程卖点
咨询多但不报名 -> 检查价格、时间、地点、信任证明
报名不足最低成班 -> 延期或换主题，不硬开亏损班
到课体验差 -> 暂停扩张，先修交付
复购和转介绍出现 -> 标准化后再扩展
```

## 常见坑（3-5 条硬红线）

- 不要先租长期场地，再找用户。
- 不要只做热闹活动，不算单场盈亏。
- 不要忽视老师稳定性和现场体验。
- 不要还没跑通一城就急着扩城。

## 附录：实例（1 个跑通的例子，与主流程分开）

在广州先选择下班后钢琴体验课，确认老师和场地后，在小红书发布同城笔记，引导用户进群报名。第一班人数不大，但完成真实收款和到场交付。课后收集反馈，再继续开同类课程，并逐步增加合作场地、老师和城市。
