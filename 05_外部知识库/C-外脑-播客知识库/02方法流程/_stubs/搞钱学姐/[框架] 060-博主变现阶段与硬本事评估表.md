# [框架] 060-博主变现阶段与硬本事评估表

## 一句话（≤ 40 字）
评估博主靠流量、产品还是硬本事赚钱。

## 什么时候用（触发条件，3-5 条 bullet）
- 你是博主、播客主、短视频创作者或个人 IP，想判断下一步变现路径。
- 当前靠广告、带货、卖课、社群或商单赚钱，但不确定是否可持续。
- 发现平台流量下降、广告变少、带货变卷。
- 想从“会做内容”转向“内容只是工具”。
- **红线**：不适用于只追短期爆款、没有交付意愿或明确伤害用户的项目。

## 评估对象（这个框架用来打分的是什么）
- 评估对象：一个博主或内容 IP 的商业化成熟度。
- 颗粒度：以一个账号或一个 IP 为单位评估。
- 目标：判断当前处于 1.0-4.0 哪个阶段，以及下一步应补流量、信任、产品、交付还是硬本事。

## 维度定义（框架的骨）

### 维度 1：平台流量依赖——离开平台还能不能活

**观测信号**：

| 好信号（这方面强） | 坏信号（这方面弱） |
|---|---|
| 有私域、复购、转介绍或站外收入 | 平台不给流量就没有收入 |
| 内容只是获客工具之一 | 把播放量当唯一资产 |
| 不同平台可以迁移同一专业能力 | 平台规则一变就崩 |

→ **怎么问出来 / 怎么观察出来**：问“如果明天这个平台限流，我还能靠什么收入活下去？”

### 维度 2：人设与信任——用户信你这个人吗

**观测信号**：

| 好信号（这方面强） | 坏信号（这方面弱） |
|---|---|
| 用户愿意了解你的生活、判断和价值观 | 只靠整活、颜值或猎奇停留 |
| 商业化不明显损害信任 | 一带货就被怀疑收割 |
| 能稳定表达真实经验 | 没话硬说，只为 KPI 更新 |

→ **怎么问出来 / 怎么观察出来**：问“用户是信内容刺激，还是信我的判断？”

### 维度 3：产品服务变现——能不能卖出清晰价值

**观测信号**：

| 好信号（这方面强） | 坏信号（这方面弱） |
|---|---|
| 能卖产品、服务、课程、社群或咨询，并说明价值 | 只能接广告或等打赏 |
| 收费和交付边界清楚 | 收钱后效果不可控且无法解释 |
| 适合自己的兴趣和能力 | 看别人赚钱才硬转型 |

→ **怎么问出来 / 怎么观察出来**：问“我卖的到底是产品、服务、知识，还是粉丝信任？”

### 维度 4：交付与供应链——商业化能不能稳定兑现

**观测信号**：

| 好信号（这方面强） | 坏信号（这方面弱） |
|---|---|
| 有供应链、客服、售后、内容交付或团队承接 | 全靠本人临场发挥 |
| 能控制质量和用户预期 | 卖完以后效果、口碑都失控 |
| 不需要用过度承诺换成交 | 靠强刺激、强话术、强焦虑转化 |

→ **怎么问出来 / 怎么观察出来**：问“成交以后，我能不能稳定交付到用户满意？”

### 维度 5：硬本事沉淀——是否拥有平台无关的能力

**观测信号**：

| 好信号（这方面强） | 坏信号（这方面弱） |
|---|---|
| 有现实生活中不可轻易替代的专业能力 | 只会做流量，不会解决具体问题 |
| 粉丝少也能靠专业成交 | 必须大流量才有商业价值 |
| 能持续学习、考证、实践、交付 | 只研究选题、剪辑和热点 |

→ **怎么问出来 / 怎么观察出来**：问“我不做视频，也能靠什么本事生活？”

## 打分卡 / 分级表（可复制粘贴）

阶段分级：

| 阶段 | 主要特征 | 典型收入 | 最大风险 | 下一步 |
|---|---|---|---|---|
| 1.0 流量整活 | 敢出来、会吸睛、靠平台分发 | 少量打赏/曝光 | 不可持续、难商业化 | 建立人设和稳定主题 |
| 2.0 人设内容 | 用户愿意看生活、观点和关系 | 广告、商单、直播 | 广告周期和平台流量波动 | 建立可售卖产品或服务 |
| 3.0 产品/IP | 能卖货、课、社群、服务 | 带货、课程、咨询、社群 | 交付压力和信任消耗 | 补供应链和交付系统 |
| 4.0 硬本事 | 平台只是工具，能力可迁移 | 专业服务、投资、企业、长期资产 | 成长慢、门槛高 | 深挖专业护城河 |

维度打分：

| 维度 | 0 分：危险 | 1 分：薄弱 | 2 分：可用 | 3 分：成熟 | 当前分 | 证据 |
|---|---|---|---|---|---:|---|
| 平台流量依赖 | 完全靠平台 | 有少量私域 | 有多渠道 | 平台无关收入稳定 |  |  |
| 人设与信任 | 只靠刺激 | 有人设但不稳 | 信任基本可变现 | 信任长期复利 |  |  |
| 产品服务变现 | 无产品 | 有尝试 | 有稳定产品 | 产品矩阵清晰 |  |  |
| 交付与供应链 | 无交付 | 交付靠本人硬扛 | 交付基本稳定 | 系统化可复制 |  |  |
| 硬本事沉淀 | 只有流量技巧 | 有兴趣方向 | 有专业能力 | 平台外也能赚钱 |  |  |

## 打完分怎么用（决策后果）

- 总分 0-5：先稳定内容定位，不急着卖课或带货。
- 总分 6-9：补人设信任和私域，谨慎接商业化。
- 总分 10-12：开始打磨产品、服务和交付闭环。
- 总分 13-15：减少平台焦虑，把内容当工具，继续加深硬本事。
- 平台流量依赖低于 2 分：立刻做私域和站外收入备份。
- 交付与供应链低于 2 分：不要扩大销售，先补交付。

## 常见坑（3-5 条）

- 不要把播放量误认为商业模式。
- 不要看别人带货赚钱，就卖自己不理解、不喜欢的产品。
- 不要用粉丝信任卖无法交付的课或服务。
- 不要把“做视频能力”当成唯一护城河。
- 不要让公司收入完全绑在本人每天更新上。

## 附录：实例（1 个跑通的例子）

一个 400 万粉内容 IP 曾经历广告、带货、卖课和社群等阶段。广告受经济周期和品牌预算影响，带货需要产品兴趣、供应链和投放能力，卖课需要对交付效果承担责任。复盘后，他把“做博主”从职业改成工具，转向研究投资等平台外能力。按本框架看，核心升级不是继续追更高播放，而是降低平台依赖、保留真实表达、补足能离开平台仍然成立的硬本事。
