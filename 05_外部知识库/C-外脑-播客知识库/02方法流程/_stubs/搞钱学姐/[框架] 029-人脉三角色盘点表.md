# [框架] 人脉三角色盘点表

## 一句话（≤ 40 字）
用 6 个维度盘点人脉角色和求助边界。

## 什么时候用（触发条件）
- 想整理微信、社群、合作网络和潜在资源时。
- 准备求助、引荐、组局、合作或做社群活动时。
- 感到社交低效，不知道谁能帮自己、自己能帮谁时。
- **红线**：不适用于把人当工具的功利社交；必须尊重对方边界。

## 评估对象
- 个人微信、社群、饭局、合作网络中的一个联系人或一组联系人。
- 颗粒度到“这个人当前最像哪类角色，我能如何维护关系”。

## 维度定义

### 维度 1：贵人——关键节点能拉你一把的人

**观测信号**：

| ✅ 好信号 | ❌ 坏信号 |
|---|---|
| 在关键节点给过机会、推荐或判断 | 只是名气大，但和你没有连接 |
| 理解你的方向，愿意在合适时帮忙 | 每次互动都很消耗或不对等 |
| 一次帮助会显著改变你的路径 | 帮忙内容只是泛泛鼓励 |

→ **怎么问出来 / 怎么观察出来**：问“这个人是否能在关键节点帮我打开一扇门？”

### 维度 2：智囊团——能帮你提高判断质量的人

**观测信号**：

| ✅ 好信号 | ❌ 坏信号 |
|---|---|
| 能指出盲区、补充信息、校准决策 | 只会情绪支持，没有新信息 |
| 对某一领域有经验或深度观察 | 观点很多但无法落到行动 |
| 你愿意在重要决策前请教 | 交流后更焦虑、更混乱 |

→ **怎么问出来 / 怎么观察出来**：回想最近 3 次请教，谁让你的判断变清楚。

### 维度 3：超级链接者——能把人和资源连接起来的人

**观测信号**：

| ✅ 好信号 | ❌ 坏信号 |
|---|---|
| 认识跨圈层的人，且愿意做有效引荐 | 只是通讯录大，但不做连接 |
| 能判断双方是否匹配 | 乱拉群、乱推人，增加噪音 |
| 引荐后双方都觉得有价值 | 只追求热闹，不负责匹配质量 |

→ **怎么问出来 / 怎么观察出来**：看这个人过去的引荐是否形成合作、信息增量或长期关系。

### 维度 4：自己能帮助谁——你在别人网络里的角色

**观测信号**：

| ✅ 好信号 | ❌ 坏信号 |
|---|---|
| 能说清自己能提供的信息、资源或经验 | 只想索取，不知道能贡献什么 |
| 别人会因某类问题想到你 | 你在别人眼中没有标签 |
| 帮助别人后也能积累声誉 | 过度帮忙导致自己被消耗 |

→ **怎么问出来 / 怎么观察出来**：写下“别人遇到什么问题时会想起我”。

### 维度 5：求助边界——什么忙可以开口，什么忙不该开口

**观测信号**：

| ✅ 好信号 | ❌ 坏信号 |
|---|---|
| 求助具体、轻量、可拒绝 | 上来就要高成本承诺 |
| 能说明背景、请求、截止时间和回报 | 只说“帮我看看” |
| 尊重对方不回复或拒绝 | 用关系绑架对方 |

→ **怎么问出来 / 怎么观察出来**：把求助写成 5 行以内，看对方是否能快速判断要不要帮。

### 维度 6：是否需要明码标价——保护时间和注意力

**观测信号**：

| ✅ 好信号 | ❌ 坏信号 |
|---|---|
| 高频咨询、深度建议有明确收费或交换机制 | 大量免费咨询挤占核心工作 |
| 朋友帮忙和专业服务边界清楚 | 关系越熟越不好意思谈钱 |
| 定价让双方都舒服 | 不定价导致怨气和消耗 |

→ **怎么问出来 / 怎么观察出来**：统计过去一月免费帮忙耗时，超过可承受范围就需要设边界。

## 打分卡 / 分级表（可复制粘贴）

| 联系人 | 贵人 | 智囊团 | 超级链接者 | 我能帮 TA 什么 | 求助边界清晰度 | 是否需定价 | 维护动作 |
|---|---|---|---|---|---|---|---|
|  | 0-5 | 0-5 | 0-5 |  | 0-5 | 是 / 否 |  |

- **核心关系**：至少一个角色 ≥ 4，且边界清晰。
- **潜在关系**：角色暂不明确，但互相有信息或资源增量。
- **消耗关系**：长期索取、边界不清、没有互相成长。

## 打完分怎么用

- 贵人高分：少打扰，关键节点带着具体问题求助。
- 智囊团高分：建立定期交流或付费咨询机制。
- 超级链接者高分：先说明匹配理由，再请求引荐。
- 自己能帮助谁低分：先建设个人标签和基本盘。

## 常见坑

- ❌ 不要只想找贵人，不建设自己能给出的价值。
- ❌ 不要把饭局数量当成人脉质量。
- ❌ 不要让免费咨询吞掉自己的注意力。
- ❌ 不要未经允许就把别人拉进群或强行引荐。

## 附录：实例

一个人想进入 AI 副业圈，先盘点微信联系人。A 是贵人，能在关键节点推荐项目；B 是智囊团，能判断项目真假；C 是超级链接者，认识很多社群主。她先向 B 付费咨询筛选方向，再请 C 引荐一个社群，最后在有明确作品后再向 A 请求推荐，避免一开始就消耗关键关系。
