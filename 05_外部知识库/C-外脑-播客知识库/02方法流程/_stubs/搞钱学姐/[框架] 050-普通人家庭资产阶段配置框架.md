# [框架] 050-普通人家庭资产阶段配置框架

## 一句话（≤ 40 字）
按阶段评估家庭资产是否先保本再增长。

## 什么时候用（触发条件，3-5 条 bullet）
- 家庭开始有结余，想做资产配置但不知道先后顺序。
- 面临买房、租房、保险、养老、基金或存款选择。
- 资产大多压在房产里，现金流变紧。
- 想降低高波动投资冲动，先建立保本意识。
- **红线**：不适用于短线投机、荐股、择时或高杠杆投资决策。

## 评估对象（这个框架用来打分的是什么）
- 评估对象：普通家庭当前资产配置状态。
- 颗粒度：以一个家庭为单位，评估现金流、风险保障、低波动资产、养老准备和房产压力。
- 目标：判断当前优先任务是补屏障、攒长期钱、优化房产占比，还是谨慎增加波动资产。

## 维度定义（框架的骨）

### 维度 1：年龄与赚钱阶段——是否把高收入窗口期转成长期资产

**观测信号**：

| ✅ 好信号（这方面强） | ❌ 坏信号（这方面弱） |
|---|---|
| 30-40 岁前后开始为长期目标存钱 | 收入高但全部花掉 |
| 知道未来赚钱能力可能变化 | 默认自己会一直高收入 |
| 按阶段调整风险承受能力 | 年龄增长但配置仍像短线赌局 |

→ **怎么问出来 / 怎么观察出来**：问“如果 40 岁后收入下降，我现在的资产能不能接住？”

### 维度 2：风险屏障——是否先覆盖健康、意外和现金流风险

**观测信号**：

| ✅ 好信号（这方面强） | ❌ 坏信号（这方面弱） |
|---|---|
| 有基础医疗、重疾、意外等保障意识 | 没有任何风险缓冲，出事只能卖资产 |
| 有 6-12 个月必要支出现金 | 所有钱都在不可快速取出的资产里 |
| 保障和家庭责任匹配 | 只买理财，不买风险屏障 |

→ **怎么问出来 / 怎么观察出来**：问“一场病、一次失业、一次意外，会不会直接击穿家庭现金流？”

### 维度 3：低波动资产——是否有稳定、可理解的底仓

**观测信号**：

| ✅ 好信号（这方面强） | ❌ 坏信号（这方面弱） |
|---|---|
| 配置存款、货币类、债券类或其他低波动资产 | 资金集中在高波动品种 |
| 明白收益和风险匹配 | 只看高收益，不看回撤 |
| 不推荐自己不理解的产品 | 跟风购买复杂产品 |

→ **怎么问出来 / 怎么观察出来**：问“这笔钱最大可能亏多少？我是否真的理解？”

### 维度 4：养老储备——是否为未来自己提前存钱

**观测信号**：

| ✅ 好信号（这方面强） | ❌ 坏信号（这方面弱） |
|---|---|
| 越早开始为养老或长期生活费储备 | 认为养老太远，完全不准备 |
| 把长期钱和短期消费钱分开 | 经常挪用长期储备 |
| 关注稳定复利而非暴富 | 期待靠一次投资解决养老 |

→ **怎么问出来 / 怎么观察出来**：问“这笔钱是给现在的我花，还是给未来的我托底？”

### 维度 5：房产占比与现金流——房子是否挤压家庭自由度

**观测信号**：

| ✅ 好信号（这方面强） | ❌ 坏信号（这方面弱） |
|---|---|
| 月供、物业、装修和机会成本都算入决策 | 只算房价涨不涨 |
| 房产占比不过度挤压现金流 | 大部分资产锁在房子里 |
| 租买决策服务生活和现金流 | 为面子或焦虑强行上车 |

→ **怎么问出来 / 怎么观察出来**：问“如果房子短期不涨，我还能舒服生活吗？”

## 打分卡 / 分级表（可复制粘贴）

| 维度 | 0 分：危险 | 1 分：薄弱 | 2 分：基本可用 | 3 分：稳健 | 当前分 | 证据 |
|---|---|---|---|---|---:|---|
| 年龄与赚钱阶段 | 没有阶段意识 | 知道但未行动 | 有部分长期储蓄 | 按阶段配置 |  |  |
| 风险屏障 | 无保险无现金 | 有单点保障 | 基本覆盖 | 家庭责任匹配 |  |  |
| 低波动资产 | 全高波动 | 底仓不足 | 有稳定底仓 | 底仓清晰可持续 |  |  |
| 养老储备 | 完全没准备 | 偶尔存 | 持续存 | 长期账户稳定 |  |  |
| 房产与现金流 | 房产挤压严重 | 压力偏高 | 可承受 | 留有自由度 |  |  |

分级：
- **A 级（12-15 分）**：底盘稳，可在小比例内研究更高波动资产。
- **B 级（8-11 分）**：先补短板，不急着追高收益。
- **C 级（0-7 分）**：优先保本、保现金流、保风险屏障，暂停高波动加仓。

## 打完分怎么用（决策后果）

- 风险屏障低于 2 分：先补现金储备和基础保障。
- 低波动资产低于 2 分：先建立稳定底仓，再谈收益增强。
- 养老储备低于 2 分：设立长期账户，避免和日常消费混用。
- 房产与现金流低于 2 分：重新计算月供、租买差额、装修和机会成本。
- 总分低于 8 分：不要把“抗通胀”当成冒险理由，先守住本金。

## 常见坑（3-5 条）

- ❌ 不要一上来追求高收益，普通人保本本身就很难。
- ❌ 不要把房产升值当作唯一答案，现金流压力也是真成本。
- ❌ 不要忽略保险和应急现金，风险屏障不是可有可无。
- ❌ 不要把养老储备当短期备用金反复挪用。
- ❌ 不要购买自己讲不清风险的复杂产品。

## 附录：实例（1 个跑通的例子）

一个 35 岁家庭年收入 50 万，有 20 万现金、300 万房产、180 万房贷、少量基金和无明确养老账户。打分：年龄阶段 2 分，风险屏障 1 分，低波动资产 1 分，养老储备 0 分，房产与现金流 1 分，总分 5 分。结论不是增加高波动投资，而是先补 6-12 个月现金储备，梳理医疗/意外/重疾保障，设立长期养老账户，并重新计算房贷对现金流的压力。等底盘分数到 10 分以上，再考虑小比例长期指数或其他波动资产。
