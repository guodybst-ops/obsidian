# [SOP] 085-家庭经济内循环财商养育法

## 一句话
在家先练钱的来源、价格和边界。

## 什么时候用
- 孩子开始问“钱从哪里来”“为什么别人家更有钱”时。
- 孩子对价格没有概念，容易乱花、乱要或过度懂事时。
- 家长想培养孩子赚钱意识，但又不想让孩子被匮乏感驱动时。
- 孩子想用劳动、技能或小项目换取零花钱时。
- **红线**：不适用于让未成年人承担家庭经济压力或替成人赚钱。

## 输入
- 孩子的年龄、理解能力和安全边界。
- 家庭可公开的收入来源、支出结构和职业说明。
- 一份额外劳动或项目清单。
- 固定奖励预算，避免临时加码造成通货膨胀。
- 法律、安全、隐私和平台规则边界。

## 输出
- 一张家庭经济内循环规则表。
- 一张额外劳动标价表。
- 一张“想买东西”的冷静决策单。
- 完成信号：孩子知道钱来自工作、劳动、技能或交换，也知道哪些钱不能赚。

## 主流程

### Step 1: 先把钱说清楚
- 用孩子听得懂的话解释家庭成员分别怎么赚钱、怎么花钱。
- 如实说明家里大致是什么状态，不羞辱贫穷，也不神化富裕。
- 做完信号：孩子知道钱不是凭空出现，也不是只能靠结婚或别人给。

### Step 2: 建立家庭经济内循环
- 先在家里设置可控的小型经济系统，再接触外部市场。
- 只给“额外劳动、项目任务、技能输出”标价，基础生活照顾不商品化。
- 奖励金额固定，不能因为孩子讨价还价或家长心软随意涨价。

### Step 3: 给劳动明码标价
- 每个任务写清楚价格、验收标准和结算周期。
- 任务可以是额外家务、整理项目、学习挑战、创作项目或小服务。
- 做完信号：孩子知道一项劳动要投入多少时间，能换来多少钱。

### Step 4: 拆分钱的去向
- 每次收入分成 3 份：可花、可存、可投入长期目标。
- 想买贵东西时，先放入愿望清单，冷静 24 小时以上。
- 可用共同出资：家长承担一部分，孩子用自己的钱承担一部分。

### Step 5: 讲清法律和安全边界
- 每个赚钱点都要问：安全吗？合法吗？会不会侵犯隐私？会不会伤害别人？
- 遇到灰色方法，先停止，再讨论为什么它看起来赚钱但代价更高。
- 做完信号：孩子能区分“真实挣钱”“绕规则占便宜”和“违法风险”。

### Step 6: 再连接真实市场
- 带孩子观察不同职业、不同工作方式和不同收入来源。
- 如果孩子想做小买卖，只做低金额、短周期、家长监督的练习。
- 练习后复盘：赚了什么、亏了什么、有没有情绪上头、有没有创造价值。

## 判断点 / 决策树

```text
孩子想赚钱 → 先查安全/法律/隐私边界
安全且合法 → 放入家庭内循环任务
不安全或违法 → 立即停止，改成案例讨论
孩子想买贵东西 → 放愿望清单，冷静后再决定
孩子过度懂事不敢花钱 → 增加“值得拥有”的体验，不只讲省钱
奖励金额越谈越高 → 冻结规则，防止家庭内通货膨胀
```

## 常见坑
- ❌ 不要让孩子背负“我要赚钱养家”的压力。
- ❌ 不要把所有家务都变成交易；家庭责任和额外劳动要分开。
- ❌ 不要用大额奖励长期绑定学习成绩，容易诱发做低预期或偷分。
- ❌ 不要只教省钱；也要让孩子体验“我值得拥有”。
- ❌ 不要让孩子独自接触外部交易、打赏、网购或高风险平台。

## 附录：实例

一次家庭内循环练习可以这样设计：孩子想通过英语考试获得奖励，家长先设定一次性目标和固定金额，完成后复盘“为什么这次能做到”。如果发现孩子之前有意压低表现，就不要继续用大额分数奖励，而是改为稳定的小任务价格表。另一个练习是孩子想买玩具，先放入愿望清单，24 小时后再判断是否还想要；若仍想要，家长出固定比例，孩子用自己的可花账户承担剩余部分。
