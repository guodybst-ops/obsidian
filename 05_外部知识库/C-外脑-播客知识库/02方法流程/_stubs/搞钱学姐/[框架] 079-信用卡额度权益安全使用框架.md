# [框架] 079-信用卡额度权益安全使用框架

## 一句话（≤ 40 字）
评估信用额度和权益能不能安全使用。

## 什么时候用（触发条件，3-5 条 bullet）
- 想办信用卡、提额、用免息期、薅权益或做垫付报销。
- 想判断额度是安全垫，还是超前消费陷阱。
- 面临大件消费、出差垫付、团建买单、旅行权益选择。
- 想区分额度党、权益党和危险负债。
- **红线**：不适用于借钱炒股、借钱买奢侈品、借贷投资或逃避还款。

## 评估对象（这个框架用来打分的是什么）
- 评估对象：一次信用卡使用计划、一张卡、一个额度策略或一个权益玩法。
- 颗粒度：以具体消费/垫付/权益场景为单位。
- 目标：判断“可用、谨慎用、不要用”，并设置还款和风险边界。

## 维度定义（框架的骨）

### 维度 1：三个钱包——现金流、信用额度、个人品牌是否匹配

**观测信号**：

| ✅ 好信号（这方面强） | ❌ 坏信号（这方面弱） |
|---|---|
| 有稳定现金流覆盖还款 | 没现金流，只靠额度过日子 |
| 信用额度是备用能力，不是消费冲动 | 把额度当收入 |
| 个人信用和工作口碑能支撑额度 | 频繁逾期、拆东墙补西墙 |

→ **怎么问出来 / 怎么观察出来**：问“我有多少钱、别人愿意借我多少、别人认为我值多少，三者是否一致？”

### 维度 2：负债承受力——债务是否在现金流安全线内

**观测信号**：

| ✅ 好信号（这方面强） | ❌ 坏信号（这方面弱） |
|---|---|
| 月债务低于确定性现金流的 30%-40% | 超过 50%，现金流一波动就危险 |
| 有明确还款来源 | 只相信未来会有钱 |
| 不做非必要负债 | 借钱买奢侈品、炒股或撑面子 |

→ **怎么问出来 / 怎么观察出来**：问“还款日那天，钱从哪里来？”

### 维度 3：免息周期回流——账期内资金是否确定回来

**观测信号**：

| ✅ 好信号（这方面强） | ❌ 坏信号（这方面弱） |
|---|---|
| 报销、AA、代付资金确定回流 | 对方是否还钱不确定 |
| 账单日、还款日清楚 | 不知道哪天还款 |
| 只利用免息，不碰逾期和高息分期 | 被“一天几块钱”误导 |

→ **怎么问出来 / 怎么观察出来**：问“这笔钱会在还款日前回来吗？”

### 维度 4：权益匹配——权益是否真的抵消成本

**观测信号**：

| ✅ 好信号（这方面强） | ❌ 坏信号（这方面弱） |
|---|---|
| 权益和真实生活方式匹配 | 为了权益制造消费 |
| 年费、门槛、使用次数算得清 | 只看贵宾厅、酒店升级等诱惑 |
| 权益节省的时间或钱可量化 | 实际用不上，还背年费 |

→ **怎么问出来 / 怎么观察出来**：问“我本来就会发生这个消费吗？”

### 维度 5：周期环境——通胀/通缩下策略是否不同

**观测信号**：

| ✅ 好信号（这方面强） | ❌ 坏信号（这方面弱） |
|---|---|
| 通胀周期理解债务成本和资产收益 | 任何周期都盲目加杠杆 |
| 通缩周期更重视现金 | 收入不稳还扩大负债 |
| 会调整额度使用比例 | 固定打法不看环境 |

→ **怎么问出来 / 怎么观察出来**：问“当下我更需要现金，还是更适合低成本债务？”

### 维度 6：能力圈价值观——是否在自己能控制的范围内

**观测信号**：

| ✅ 好信号（这方面强） | ❌ 坏信号（这方面弱） |
|---|---|
| 只做自己理解的规则和场景 | 看别人薅羊毛就复制 |
| 价值观先于技法 | 为了小利冒信用风险 |
| 可以选择不用额度 | 被额度推着消费 |

→ **怎么问出来 / 怎么观察出来**：问“我是在使用工具，还是被工具驱动？”

## 打分卡 / 分级表（可复制粘贴）

| 维度 | 0 分：危险 | 1 分：不稳 | 2 分：可控 | 3 分：健康 | 当前分 | 证据 |
|---|---|---|---|---|---:|---|
| 三个钱包 | 严重不匹配 | 现金弱 | 基本匹配 | 三者稳定 |  |  |
| 负债承受力 | 超 50% | 接近警戒 | 30%-40% 内 | 低负债且有余量 |  |  |
| 免息周期回流 | 回款不确定 | 账期模糊 | 基本清楚 | 回款稳定早于还款 |  |  |
| 权益匹配 | 为权益消费 | 用得少 | 可抵成本 | 高频刚需 |  |  |
| 周期环境 | 完全不看 | 判断模糊 | 有意识 | 策略匹配环境 |  |  |
| 能力圈价值观 | 被诱惑驱动 | 规则不清 | 只做熟悉场景 | 可用可不用 |  |  |

分级：
- **A 级（15-18 分）**：可使用，设置自动还款和记录表。
- **B 级（10-14 分）**：谨慎使用，只用免息和确定回流场景。
- **C 级（0-9 分）**：不要加杠杆，先修现金流和还款能力。

## 打完分怎么用（决策后果）

- 负债承受力低于 2 分：暂停新增消费和分期。
- 免息回流低于 2 分：不要替人垫付或做时间差。
- 权益匹配低于 2 分：不要为了权益办高年费卡。
- 能力圈低于 2 分：只保留基础卡，不碰复杂玩法。
- 总分低于 10 分：把信用卡当风险源，不当安全垫。

## 常见坑（3-5 条）
- ❌ 不要把额度当现金，额度只是可选择的信用能力。
- ❌ 不要为了积分、权益、贵宾厅制造不必要消费。
- ❌ 不要借钱炒股、买奢侈品或撑面子。
- ❌ 不要忽略真实年化利率和逾期代价。
- ❌ 不要在通缩、收入不稳时盲目扩大负债。

## 附录：实例（1 个跑通的例子）

一个职场人要为公司活动垫付 8000 元酒店费用，公司报销周期约 20 天，信用卡还款日在 40 天后。他有 3 个月应急金，月债务低于现金流 30%，这张卡还有常用出行权益。打分 15 分，可以使用；但必须保存发票、报销单和还款日提醒。若公司报销不确定或自己现金流紧张，则改为让公司预付款，不做垫付。
