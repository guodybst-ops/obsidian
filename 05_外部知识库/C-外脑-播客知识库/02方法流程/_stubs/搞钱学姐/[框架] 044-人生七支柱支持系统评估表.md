# [框架] 044-人生七支柱支持系统评估表

## 一句话（≤ 40 字）
用五类支柱评估人生支持系统缺口。

## 什么时候用（触发条件，3-5 条 bullet）
- 正在经历低谷、转型、失业、创业压力或关系震荡。
- 感觉自己只靠一个支点活着，一旦出事就全盘崩塌。
- 想给事业、婚姻、亲情、运动、学习、朋友、宠物做一次系统盘点。
- 需要设计 7 天小实验，补强最薄弱的支持来源。
- **红线**：不适用于严重抑郁、创伤或危机干预场景，应优先寻求专业帮助。

## 评估对象（这个框架用来打分的是什么）
- 评估对象：一个人的现实支持系统。
- 颗粒度：以最近 30 天的真实行为和可调用资源为准，不按想象中的关系打分。
- 七支柱映射：事业、学习归入“事业与成长”；婚姻、亲情归入“亲密与家庭”；运动单列；朋友单列；宠物作为日常陪伴和照料支柱单列。

## 维度定义（框架的骨）

### 维度 1：事业与成长——能否通过工作和学习获得价值感

**观测信号**：

| ✅ 好信号（这方面强） | ❌ 坏信号（这方面弱） |
|---|---|
| 有清晰的工作责任或项目目标 | 工作只剩消耗，看不到产出 |
| 每月至少有一次能力升级动作 | 长期停止学习，害怕被替代 |
| 能通过帮助别人建立价值感 | 只用外部评价判断自己有没有用 |

→ **怎么问出来 / 怎么观察出来**：问“最近 30 天，我在哪件事上变得更有用？”

### 维度 2：亲密与家庭——低谷时是否有人愿意共同承担

**观测信号**：

| ✅ 好信号（这方面强） | ❌ 坏信号（这方面弱） |
|---|---|
| 伴侣或家人知道你的真实压力 | 所有困难都只能自己扛 |
| 关系里能谈钱、病、失败和计划 | 只维持表面和气，不敢谈关键议题 |
| 至暗时刻有人留下来处理问题 | 一遇到困难就互相指责或消失 |

→ **怎么问出来 / 怎么观察出来**：问“如果明天收入中断，我能和谁讨论真实方案？”

### 维度 3：身体与运动——身体是否能作为稳定底盘

**观测信号**：

| ✅ 好信号（这方面强） | ❌ 坏信号（这方面弱） |
|---|---|
| 每周有固定运动或恢复节奏 | 只靠意志力硬撑，身体长期报警 |
| 睡眠、体检、饮食有基本维护 | 压力一来就牺牲身体 |
| 运动能帮助情绪回稳 | 情绪低谷时完全没有身体出口 |

→ **怎么问出来 / 怎么观察出来**：看最近 7 天是否有一次让身体恢复的行动。

### 维度 4：朋友与陪伴——是否有非功利的外部连接

**观测信号**：

| ✅ 好信号（这方面强） | ❌ 坏信号（这方面弱） |
|---|---|
| 有 1-3 个可以说真话的人 | 朋友圈很多，但无人可求助 |
| 能在朋友关系中互相支持 | 只有资源交换，没有情感连接 |
| 低谷时有人提醒你不是孤岛 | 遇事自动断联、封闭自己 |

→ **怎么问出来 / 怎么观察出来**：问“我最近一次主动联系朋友是在什么时候？”

### 维度 5：宠物与日常照料——是否有稳定的日常陪伴和责任感

**观测信号**：

| ✅ 好信号（这方面强） | ❌ 坏信号（这方面弱） |
|---|---|
| 宠物、植物或固定照料对象让生活有节律 | 日常完全失序，没有照料动作 |
| 照料行为带来稳定感而非额外崩溃 | 只在情绪空洞时冲动养宠 |
| 能通过小责任把自己拉回现实 | 生活中没有任何可持续的小锚点 |

→ **怎么问出来 / 怎么观察出来**：问“我每天有没有一件稳定照料动作？”

## 打分卡 / 分级表（可复制粘贴）

| 维度 | 0 分：缺失 | 1 分：脆弱 | 2 分：可用 | 3 分：稳定 | 当前分 | 证据 |
|---|---|---|---|---|---:|---|
| 事业与成长 | 无目标 | 有目标但停滞 | 有产出 | 持续升级且能助人 |  |  |
| 亲密与家庭 | 无可求助者 | 能聊但不能扛事 | 可讨论方案 | 能共担风险 |  |  |
| 身体与运动 | 长期透支 | 偶尔维护 | 有基本节奏 | 能稳定托底 |  |  |
| 朋友与陪伴 | 孤立 | 弱连接 | 有可说话的人 | 有互助网络 |  |  |
| 宠物与日常照料 | 失序 | 偶尔照料 | 有小锚点 | 日常稳定 |  |  |

分级：
- **稳态区（12-15 分）**：支持系统较稳，选择一个维度继续加深。
- **修补区（8-11 分）**：存在明显薄弱支柱，做 7 天小实验。
- **预警区（0-7 分）**：不要只靠意志力硬扛，先找现实支持人和专业资源。

## 打完分怎么用（决策后果）

- 找出最低分的 1 个维度，设计一个 7 天小实验。
- 如果最低分是“亲密与家庭”或“朋友与陪伴”，列出 3 个可联系支持人。
- 如果最低分是“身体与运动”，先安排低门槛恢复动作，例如散步、体检、早睡。
- 如果多个维度低于 1 分，先降低事业目标强度，优先补安全网。
- 如果打不出分，说明证据不足，先记录 7 天真实生活。

## 常见坑（3-5 条）

- ❌ 不要把事业成功当成唯一支柱，单支柱会放大风险。
- ❌ 不要用“我应该有很多朋友”打分，要看真实可调用关系。
- ❌ 不要把宠物当情绪止痛药，照料责任也要计入。
- ❌ 不要打完分就自责，分数只用于选择下一步。
- ❌ 不要把框架当诊断工具，它只是生活支持系统盘点。

## 附录：实例（1 个跑通的例子）

某创业者最近公司现金流紧张，给自己打分：事业与成长 2 分，亲密与家庭 1 分，身体与运动 0 分，朋友与陪伴 1 分，宠物与日常照料 2 分，总分 6 分，处于预警区。她的 7 天小实验不是继续加班，而是：每天走路 20 分钟；约一位朋友说清楚近况；和家人同步现金流压力；把本周工作目标缩小到一个关键交付。7 天后重新打分，看身体与朋友两个维度是否从 0/1 提升到 1/2。
