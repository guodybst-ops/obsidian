# [SOP] 时间流水账复盘法

## 一句话（≤ 40 字）
用 24 小时流水账校准目标和时间投入。

## 什么时候用（触发条件，3-5 条 bullet）

- 你总觉得时间不够用，但说不清时间去了哪里。
- 你有目标，却发现每天行动和目标脱节。
- 你想调整工作、赚钱、关系、健康和自我探索的投入比例。
- 你刚经历负债、转型、退休规划或人生阶段切换。
- **红线**：不适用于只想排满日程、不愿面对真实消耗的情况。

## 输入（做之前要准备的东西）

- 最近 1-7 天真实时间记录。
- 当前阶段的 1-3 个目标。
- 生命板块分类：赚钱、健康、关系、学习、休息、探索、杂务。
- 30-60 分钟安静复盘时间。

## 输出（做完得到什么）

- 一张 24 小时时间流水账。
- 一份生命板块投入占比。
- 一个下阶段时间调整方案。
- 完成信号：你能指出要增加、减少、停止的具体时间块。

## 主流程（核心，占篇幅 ≥ 60%）

### Step 1: 记录 24 小时流水

- 从起床到睡觉，每 30-60 分钟记录一次实际做了什么。
- 不美化、不补叙，只写真实行为。
- 做完信号：一天时间没有大片空白。

### Step 2: 标注生命板块

- 给每个时间块贴上分类：赚钱、健康、关系、学习、休息、探索、杂务。
- 同一时间块只选一个主用途。
- 做完信号：你能看到一天的时间分布。

### Step 3: 用第三视角判断

- 把表格当成别人的一天来看。
- 问：这个人最重视什么？他嘴上说的目标和时间投票一致吗？
- 做完信号：你写出 3 条客观观察，而不是自责。

### Step 4: 对照阶段目标

- 把当前 1-3 个目标写在表格旁边。
- 标出直接服务目标的时间块、间接服务目标的时间块、消耗目标的时间块。
- 做完信号：你知道时间和目标哪里错位。

### Step 5: 调整下阶段投入

- 给每个目标安排下一周最小时间块。
- 删除或压缩一个低价值消耗。
- 保留必要休息，不把复盘变成自我压榨。
- 做完信号：你得到一份可执行的下周时间方案。

### Step 6: 周期复盘迭代

- 每周固定复盘一次，比较计划和实际。
- 只调整 1-2 个变量，避免一次改完整个生活。
- 做完信号：连续 2-4 周后，目标相关时间占比稳定上升。

## 判断点 / 决策树（如有分支）

```text
没有真实记录 -> 先记录一天，不做判断
目标不清楚 -> 先写阶段目标，再复盘时间
目标重要但时间为 0 -> 下周安排最小时间块
时间很多但没有结果 -> 检查动作质量和反馈机制
休息不足 -> 先补休息，不用意志力硬扛
```

## 常见坑（3-5 条硬红线）

- 不要把时间复盘写成自责大会。
- 不要只记录计划，要记录真实发生。
- 不要把休息全部判定为浪费。
- 不要一次调整太多板块。

## 附录：实例（1 个跑通的例子，与主流程分开）

一个人目标是探索自由职业，但时间流水显示下班后 3 小时都在刷短视频，周末也没有任何产品或技能练习。复盘后，她把每周三晚和周六上午固定给探索项目，压缩无意识刷手机时间，并在每周日复盘产出。四周后，她能看到自己是否真的愿意为这个目标投入时间。
