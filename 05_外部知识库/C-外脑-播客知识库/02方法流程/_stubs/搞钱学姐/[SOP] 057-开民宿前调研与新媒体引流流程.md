# [SOP] 057-开民宿前调研与新媒体引流流程

## 一句话（≤ 40 字）
先住、访、算，再用内容验证民宿生意。

## 什么时候用（触发条件，3-5 条 bullet）
- 想从城市工作转向民宿、咖啡厅、小院空间或旅居地实体生意。
- 对一个城市有向往，但还没做过行业调研。
- 发现传统平台获客很卷，想用小红书、视频号和私域做差异化。
- 准备投入大额装修、租金或首付款前。
- **红线**：没有最坏结果承受能力、合同意识和内容获客能力时，不要直接签长期院子。

## 输入（做之前要准备的东西）
- 目标城市与片区：租金、淡旺季、房源、交通、客群和竞品密度。
- 真实消费样本：住过的民宿、酒店、咖啡厅、空间和用户体验记录。
- 行业访谈对象：民宿主理人、中介、房东、装修师傅、游客、平台运营者。
- 自身优势：内容、新媒体、设计、服务、供应链、私域或线下运营能力。
- 资金边界：启动资金、备用金、最坏结果和转让可能性。

## 输出（做完得到什么）
- 一份开民宿前调研表。
- 一张选址与房东风险评估表。
- 一套“内容养成戏 + 私域转化”的引流方案。
- “不做 / 小规模试 / 签约开干”的决策。

## 主流程（核心，占篇幅 ≥ 60%）

### Step 1: 先做真实消费者
- 在目标城市至少住 2-3 类不同民宿或空间，记录入住动线、价格、服务、细节和不满。
- 不要只看小红书照片，要亲自体验收款、入住、退房、管家和周边配套。
- 做完信号：能说清用户为什么选民宿而不是酒店。

### Step 2: 观察主理人日常
- 跟一个真实主理人近距离观察日常：接单、打扫、采购、修缮、沟通、处理差评。
- 询问收入结构、淡旺季、平台占比、隐形成本和最烦的坑。
- 做完信号：知道这不是“住在大理晒太阳”，而是空间运营。

### Step 3: 扩大访谈样本
- 通过主理人、中介、朋友继续访谈更多经营者。
- 主动收集劝退信息：市场饱和、价格战、房东反悔、装修超支、平台封控。
- 做完信号：不是只听鼓励，而是拿到了足够负面信号。

### Step 4: 找差异化获客路径
- 对比传统 OTA 和新媒体链路：平台订单、内容种草、私域成交、转介绍。
- 只有当你的优势能补上行业痛点时，才继续往下走。
- 做完信号：能写出“别人做不到，但我能做的获客方式”。

### Step 5: 计算最坏结果
- 列出租金、押金、装修、软装、人工、推广、空置、维修和时间成本。
- 写出最坏情况：转让、停业、亏损上限、账号资产和房东纠纷。
- 做完信号：最坏结果发生时，你仍能接受且有退出方案。

### Step 6: 筛选院子与房东
- 从地理位置、租金、空间潜力、改造难度、合同年限、房东人品、房东家庭情况、中介可靠度综合判断。
- 宅基地、长期租约、装修投入和房东反悔风险必须单独标红。
- 做完信号：签约不是因为喜欢院子，而是风险表通过。

### Step 7: 用养成内容引流到私域
- 把“我要做一件事”公开成连续内容：裸辞、签约、改造、装修、开业、踩坑、日常。
- 以一个平台为锚点，其他平台同步；把精准用户逐步沉淀到私域。
- 做完信号：开业前已有关注、询价、预订或转介绍。

## 判断点 / 决策树（如有分支）

```text
如果只喜欢城市氛围但不了解经营 → 回到 Step 1
如果访谈样本全在劝退且自己没有差异化能力 → 暂缓
如果资金只够开业没有备用金 → 不签长期合同
如果房东不靠谱或合同不清 → 不签
如果 OTA 订单很少但新媒体可转化 → 加强内容和私域
如果内容爆了但交付跟不上 → 先补运营，不盲目扩张
```

## 常见坑（3-5 条硬红线）
- 不要只凭向往开店，先用消费者身份住进去。
- 不要只问成功者，也要问做不下去的人。
- 不要把传统 OTA 当唯一渠道，除非你有价格、位置或评分优势。
- 不要低估装修超支和房东反悔风险。
- 不要内容火了就扩张，先验证入住率、复购和现金流。

## 附录：实例（1 个跑通的例子，与主流程分开）

某主理人在目标城市 gap 期间先住进民宿，观察主理人日常，又访谈更多民宿经营者。虽然大多数人反馈市场饱和、价格战严重，但他判断传统 OTA 链路不是自己的核心打法，而是用新媒体内容和个人 IP 拉动私域预订。签院子前，他把最坏情况设为转让小院，并评估账号、粉丝和改造成果仍可能保留部分价值。开业前用“从 0 到 1 改造小院”的连续内容积累精准用户，后续大部分订单来自小红书、视频号和私域。
