# [框架] 052-概率赔率人生决策评估表

## 一句话（≤ 40 字）
用概率、赔率和爆仓风险评估人生选择。

## 什么时候用（触发条件，3-5 条 bullet）
- 面临投资、创业、裸辞、买房、换城市、换职业等关键决策。
- 一个机会看起来很诱人，但不知道值不值得下注。
- 身边人都在冲，你担心错过窗口期。
- 想把“拍脑门”改成可复盘的判断。
- **红线**：不适用于违法、伤害身体或明显会击穿底线的选择。

## 评估对象（这个框架用来打分的是什么）
- 评估对象：一个具体选择、项目、资产、机会或人生行动。
- 颗粒度：一次只评估一个选择，不把多个机会混在一张表里。
- 目标：判断它是长期值得投入、可小额试错、只适合维持，还是必须避开。

## 维度定义（框架的骨）

### 维度 1：成功概率——这件事大概率能不能成

**观测信号**：

| 好信号（这方面强） | 坏信号（这方面弱） |
|---|---|
| 有历史数据、同类案例或自己过往胜率可参考 | 只靠“我感觉这次不一样” |
| 自己有相关能力、资源或经验 | 完全陌生，还拒绝补课 |
| 可以通过小测试提高判断准确度 | 一上来就要重仓或梭哈 |

→ **怎么问出来 / 怎么观察出来**：问“如果重复做 100 次，我大概能赢几次？”

### 维度 2：正向赔率——成功以后能带来多大回报

**观测信号**：

| 好信号（这方面强） | 坏信号（这方面弱） |
|---|---|
| 成功后能带来收入、能力、信用、资源或第二选择权 | 成功也只是省一点小钱或获得短暂爽感 |
| 回报可以复利积累 | 回报一次性消耗完 |
| 结果能打开下一阶段机会 | 做完仍困在原地 |

→ **怎么问出来 / 怎么观察出来**：问“它成功后，会让我未来更有选择吗？”

### 维度 3：负向爆仓——失败会不会击穿底线

**观测信号**：

| 好信号（这方面强） | 坏信号（这方面弱） |
|---|---|
| 最坏结果可承受，可止损 | 失败会破产、重伤、毁掉信用或关系 |
| 投入金额、时间、身体成本有上限 | 负面结果无法封顶 |
| 有备用金、保险、退路或退出条款 | 只想赢，没想过输 |

→ **怎么问出来 / 怎么观察出来**：问“最坏情况发生，我是否还能继续生活和重来？”

### 维度 4：时间框架——短期看和长期看是否一致

**观测信号**：

| 好信号（这方面强） | 坏信号（这方面弱） |
|---|---|
| 拉长到 5-10 年仍值得做 | 只在当下热潮里显得诱人 |
| 前期慢，但能积累复利 | 前期刺激，后期没有积累 |
| 不依赖一次运气 | 只能靠一次小概率暴击 |

→ **怎么问出来 / 怎么观察出来**：问“如果它 3 年内不爆，我还愿意继续吗？”

### 维度 5：信息质量与能力圈——判断依据是否站得住

**观测信号**：

| 好信号（这方面强） | 坏信号（这方面弱） |
|---|---|
| 信息来自研究、实践者、经典资料或可信专家 | 信息只来自短视频热点和情绪化内容 |
| 知道自己哪些地方不懂 | 把听来的结论当确定事实 |
| 有同频且优秀的人可请教 | 完全孤立决策，拒绝复盘 |

→ **怎么问出来 / 怎么观察出来**：问“我是在信息上游判断，还是被热点推着走？”

## 打分卡 / 分级表（可复制粘贴）

| 维度 | 0 分：危险 | 1 分：偏弱 | 2 分：可试 | 3 分：强 | 当前分 | 证据 |
|---|---|---|---|---|---:|---|
| 成功概率 | 完全没谱 | 低概率 | 有一定胜率 | 胜率高且可验证 |  |  |
| 正向赔率 | 成功回报很小 | 回报有限 | 回报较大 | 回报可复利放大 |  |  |
| 负向爆仓 | 失败会击穿底线 | 损失偏大 | 损失可控 | 最坏结果也能承受 |  |  |
| 时间框架 | 只适合短期热闹 | 长期不明 | 中长期可做 | 5-10 年仍值得 |  |  |
| 信息质量与能力圈 | 信息很差 | 信息不完整 | 信息基本够 | 信息上游且在能力圈 |  |  |

分级：
- **A 级（12-15 分）**：长期重点投入，设置节奏持续复利。
- **B 级（9-11 分）**：可做小规模试错，先补信息和能力短板。
- **C 级（6-8 分）**：只做低成本观察，不要重仓。
- **D 级（0-5 分）**：停止或避开，尤其负向爆仓低于 2 分时。

## 打完分怎么用（决策后果）

- 高概率 + 高赔率 + 爆仓可控：优先投入，拉长时间框架。
- 低概率 + 高赔率 + 爆仓可控：只用小钱、小时间测试。
- 高概率 + 低赔率：当作基本盘，不要幻想暴富。
- 低概率 + 低赔率：直接放弃。
- 任一机会负向爆仓为 0 分：不管看起来多诱人，都先避开。
- 信息质量低于 2 分：先补资料、问人、做小样本测试，再决策。

## 常见坑（3-5 条）

- 不要只看成功故事，不算失败概率。
- 不要把“可能暴富”当成期望值为正。
- 不要为了高赔率承受自己扛不住的爆仓风险。
- 不要用短期结果否定长期复利，也不要用长期主义掩盖短期赌博。
- 不要让低质量信息驱动高成本决策。

## 附录：实例（1 个跑通的例子）

评估“裸辞去做一个陌生创业项目”：成功概率 1 分，因为没有验证；正向赔率 3 分，因为成功后可能打开收入和自由度；负向爆仓 1 分，因为没有备用金会影响生活；时间框架 2 分，长期可能有积累；信息质量 1 分，只看了热点案例。总分 8 分，结论是不能裸辞重仓。改法：先保留主业，用 3 个月做小样本测试、建立现金缓冲、找行业内人士核实成本，再重新打分。
