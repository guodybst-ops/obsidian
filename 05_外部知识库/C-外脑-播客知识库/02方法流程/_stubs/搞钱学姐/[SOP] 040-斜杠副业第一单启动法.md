# [SOP] 040-斜杠副业第一单启动法

## 一句话
从别人认可过的能力出发，拿下副业第一单。

## 什么时候用
- 想开始副业，但总觉得自己还不够厉害时。
- 有技能、经验或兴趣，却不知道怎么卖出第一单时。
- 下班后想低风险测试咨询、课程、服务或陪跑产品时。
- **红线**：不适用于需要资质许可、高风险医疗法律金融等服务。

## 输入
- 别人夸过你、找你帮过忙、愿意请教你的能力清单。
- 3-5 个潜在客户或目标社群。
- 一个低价或公益小案例设计。
- 下班后可投入的固定时间。

## 输出
- 一个可售卖的最小服务包。
- 1-3 个真实案例或客户反馈。
- 第一单成交复盘。

## 主流程

### Step 1: 梳理别人认可过的能力
- 翻聊天记录、工作反馈、朋友求助、夸夸记录，找出别人反复认可你的地方。
- 把能力写成“我能帮谁解决什么问题”，不要只写技能名。
- 做完信号：你得到 3 个可测试的服务方向。

### Step 2: 设计低价 / 公益小案例
- 把服务缩到一个小结果，例如一次诊断、一份清单、一小时陪跑、一个模板。
- 给出低价、公益或限量体验，不一开始追求完美产品。
- 做完信号：潜在客户不用承担高风险也愿意试。

### Step 3: 直接接触潜在客户
- 从熟人、社群、朋友圈、过往同事里找最可能需要的人。
- 用具体问题开场，不用长篇自我介绍。
- 做完信号：你至少发出 10 个真实邀约或沟通。

### Step 4: 把下班时间优先给咨询和开发
- 固定一段下班时间，只做客户沟通、方案设计、交付和复盘。
- 少刷课，少搭系统，先接触真实客户。
- 做完信号：每周有固定副业推进时段。

### Step 5: 用真实反馈补技能
- 记录客户哪里听懂、哪里卡住、愿不愿付费、愿不愿推荐。
- 缺什么补什么，不为“还没准备好”无限学习。
- 做完信号：每次交付后都能改进服务包。

### Step 6: 复盘成交与内容
- 复盘谁买了、为什么买、哪里犹豫、结果如何。
- 把客户问题、反馈、案例转成内容选题，吸引下一批人。
- 做完信号：第一单不只是收入，而是变成案例和内容素材。

## 判断点 / 决策树

```text
如果不知道卖什么 → 退回 Step 1 找别人认可过的能力
如果没人愿意试 → 退回 Step 2 缩小服务包或降低首次门槛
如果只学习不接触客户 → 退回 Step 3 发出邀约
如果客户反馈不好 → 退回 Step 5 补技能和重写承诺
如果成交后没有后续线索 → 退回 Step 6 把案例内容化
```

## 模板 / 清单 / 打分卡

**能力转服务表**

| 别人认可过的能力 | 谁会需要 | 可交付小结果 | 首次价格 / 形式 | 目标客户 |
|---|---|---|---|---|
| | | | | |

**邀约模板**

> 我最近在测试一个【服务名】，主要帮【人群】解决【具体问题】。我可以先用【低价/公益】帮你做一次【小结果】，你只需要给我真实反馈。你愿意试试吗？

## 常见坑
- ❌ 不要等自己很厉害才开始，第一单就是训练场。
- ❌ 不要一开始做大课、大产品、大系统。
- ❌ 不要只问朋友“我适合做什么”，要看谁真的愿意付费或试用。
- ❌ 不要把下班时间都花在补课，客户反馈更关键。
- ❌ 不要成交后不复盘，第一单的价值不只是一笔钱。

## 附录：实例

一个职场人常被同事夸“很会整理面试故事”。她把能力转成 99 元的 1 小时简历故事诊断，先找 10 个准备跳槽的朋友试用。前 3 单里，她发现客户最卡的是“不知道怎么讲项目价值”，于是补了一个项目故事模板。完成第一单后，她把匿名案例写成内容，继续吸引下一批咨询。
