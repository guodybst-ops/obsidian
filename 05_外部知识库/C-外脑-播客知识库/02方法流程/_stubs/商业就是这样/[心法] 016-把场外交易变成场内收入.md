# [心法] 把场外交易变成场内收入

## 一句话（≤ 30 字）
强 IP 会收编自发交易并抽成。

## 什么时候想起它（触发场景，3-5 条）

- 某个赛事、演唱会、展会或 IP 周边出现大量二级转售。
- 平台开始推出“官方转售”“官方认证”“官方纪念品”。
- 原本粉丝自发交易的东西突然被官方包装成权益。
- **反向触发**：你以为自己在自由市场交易，但平台同时控制入口、规则和手续费。

## 具体怎么用（1-3 条动作，≤ 100 字）

- 先判断交易入口是否被官方控制，再算手续费和退出成本。
- 判断平台收编后，买家信任是否提升、卖家利润是否被抽走。
- 如果自己是经营者，寻找尚未被官方收编但需求真实的边缘场景。

## 反例

只看到二手票价格高，就以为可以套利，却忽略官方平台同时向买卖双方收手续费。
