# [框架] 大型赛事举办城市财务压力评估框架

## 一句话（≤ 40 字）
用五个维度判断城市办赛值不值得。

## 什么时候用（触发条件，3-5 条 bullet）

- 城市、园区、场馆或活动主办方要评估是否承办大型赛事。
- 一个项目声称能带来曝光、旅游和长期经济效益，但现金流路径不清楚。
- 需要拆清“谁承担成本、谁拿核心收入、谁背公共风险”。
- **红线**：不用于只看品牌曝光的小型活动；也不替代正式财政审计。

## 评估对象

- 城市级、区域级或场馆级大型活动承办项目。
- 颗粒度到“一个承办城市/城市委员会/场馆综合体”。

## 维度定义

### 维度 1：成本刚性——不办到位就无法交付

| 好信号 | 坏信号 |
|---|---|
| 场馆、安保、交通和运营预算可被清晰拆分 | 只有总预算，没有分项和责任主体 |
| 有上级补贴或专项拨款覆盖关键支出 | 成本主要靠城市临时兜底 |
| 可缩短运营天数或压缩非必要活动 | 主办方要求全周期无条件执行 |

→ **怎么观察**：先列场馆改造、安保、交通、球迷节、志愿者和行政成本。

### 维度 2：核心权益归属——最硬的钱流向谁

| 好信号 | 坏信号 |
|---|---|
| 城市能分享门票、赞助、场馆租金或本地消费分成 | 门票、转播、全球赞助和特许商品全部归上级 IP 方 |
| 城市可独立开发本地赞助 | 本地招商权限少、广告露出被严格限制 |
| 收入可入账到承办主体 | 收入大多是曝光、旅游带动等虚项 |

→ **怎么观察**：把所有收入按“现金入账/长期外溢/不可量化”三类分开。

### 维度 3：本地开源能力——城市能否把流量变现

| 好信号 | 坏信号 |
|---|---|
| 有本地赞助商、旅游局、商会和场馆资源 | 本地企业无法或不愿购买赞助包 |
| 球迷节、接待、城市消费能产生现金流 | 城市只能承担公共服务，不能变现 |
| 能把招待票、包厢和活动权益包装成商务价值 | 权益只能象征性露出，实际转化弱 |

→ **怎么观察**：检查本地赞助名额是否卖满、单价多少、权益是否可被品牌使用。

### 维度 4：公共财政兜底——风险最终落到谁身上

| 好信号 | 坏信号 |
|---|---|
| 有明确预算上限和风险分担机制 | 需要城市开“空白支票” |
| 政府补贴、税收增量和储备金来源清楚 | 缺口最终转嫁纳税人 |
| 项目公司与政府责任边界清楚 | 非营利委员会缺钱后由政府兜底但无上限 |

→ **怎么观察**：看是否存在担保协议、财政储备、住宿税增量和预算听证材料。

### 维度 5：体验外溢——谁为商业化买单

| 好信号 | 坏信号 |
|---|---|
| 现场消费提升但仍保持公共服务可达性 | 交通、停车、球迷节、活动都层层收费 |
| 价格上涨对应明确体验提升 | 只是把原本免费权益改成收费 |
| 球迷满意度和城市口碑同步上升 | 普通球迷被高票价和手续费挤出 |

→ **怎么观察**：记录现场消费价格、免费服务取消项和球迷负担变化。

## 打分卡 / 分级表（可复制粘贴）

| 项目 | 成本刚性 | 核心权益归属 | 本地开源能力 | 财政兜底风险 | 体验外溢 | 综合结论 |
|---|---|---|---|---|---|---|
| 城市 A | 高/中/低 | 城市/共享/IP方 | 强/中/弱 | 高/中/低 | 正/负 |  |

## 打完分怎么用

- 成本刚性高、核心权益归 IP 方、本地开源弱 → 谨慎承办或重新谈条件。
- 有上级补贴和本地赞助，但体验外溢负面 → 控制收费场景，避免口碑反噬。
- 本地开源强且财政风险可封顶 → 可以承办，但要单独建立城市收益追踪表。

## 常见坑

- 不要把“全球曝光”直接当现金收入。
- 不要只看游客消费，要看承办主体能不能分到这笔钱。
- 不要忽略安保和公共交通这类硬成本。
- 不要把主办方成功等同于城市成功。

## 附录：实例

2026 美加墨世界杯中，部分城市要承担接近 3 亿美元量级的场馆、安保和运营支出；门票、转播和全球赞助主要归国际足联。城市获得的新开源口子是 host city supporter 本地赞助，但权益主要集中在球迷节、招待票和贵宾接待。若本地赞助卖不满或政府补贴不足，城市财政压力就会明显上升。
