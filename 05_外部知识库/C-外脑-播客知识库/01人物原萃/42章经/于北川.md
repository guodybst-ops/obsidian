# 于北川

> 基于 42章经 053 集提炼。不是语录合集，是可调用的思维框架。

## 画像

- **身份**：Lessie AI 创始人，前抖音早期产品经理
- **背景**：2017 年校招加入抖音，经历了抖音从几千万到数亿 DAU 的增长过程（2018-2020 年关键阶段）。抖音产品团队早期只有十几人，约一半是校招生
- **标签**：抖音实战派 / 内容社区专家 / 字节文化出身 / AI people search

## 擅长 & 不擅长

- **擅长**：内容社区从冷启动到规模化的战略判断（调性、分发容器、天花板）；字节式组织文化的理解和评估；从大厂到创业的认知迁移
- **不擅长**：工具型和技术型产品的判断（他的经验集中在内容和社交产品）；B2B 产品的增长策略；数据不足——仅一集播客

## 核心心智模型

### 模型1：分发容器决定论

- **一句话**：分发容器的形态（单列全屏 vs 双列瀑布流 vs 列表 vs 搜索）天然决定分发效率、生态形态和内容类型。单列上滑的优势是消费效率极高（用户不需选择），有利于内容泛化和商业化；劣势是创作者反馈更不均，容易推大 V。双列的优势是流量更公平，中长尾更容易获得反馈。
- **来源**：[[42章经]] 053 — 核心对比，"不同分发容器天然擅长不同内容" [归纳]
- **怎么用**：
  1. 做内容产品时先问：你的目标内容类型是什么？短快消 → 单列；深度/图文/社区互动 → 双列
  2. 不在于短期 AB test 的差距——AB test 能测消费侧变化，但测不出生态和用户心智的长期差异
  3. 自检：你选择的容器是否与你想要的内容类型和创作者生态匹配？如果不匹配，调整容器还是调整目标？
  4. 用户心智是你和容器共同定义的——抖音用户打开就无脑消费，B 站用户打开就有"我要认真看"的心智
- **局限性**：分发容器是在产品形态层面的高阶决策框架——对大多数产品经理来说，产品的容器形态在创业初期就已经定了，后续只能微调。这个框架最有价值的应用场景是"设计一个新产品时选择容器"，而不是"优化一个已有产品"。此外，他的分析基于抖音和快手的成功案例，但容器的效果不是独立变量——它和内容供给、推荐算法、运营策略交织在一起。

### 模型2：冷启动的人群奠基原则

- **一句话**：内容社区的起点人群非常重要，因为它决定了后续能否泛化。抖音成功后没有从头条大量导用户进入，而是坚持更年轻化的独立品牌（黑色 UI、音乐、街舞、极限运动、技术流），避开快手下沉赛道。人群基底一旦歪了，后面怎么调都难。
- **来源**：[[42章经]] 053 — "内容社区的起点人群非常重要" [归纳]
- **怎么用**：
  1. 冷启动时先决定你的起点人群画像——不是"谁最可能用"，而是"这群人能否支持后续泛化"
  2. 运营品味在早期极关键：内容池不够大时，推荐系统不成熟，精选标签和人工运营决定了社区走向
  3. 不要从母产品大量导用户——火山从头条导量直接进入了快手的下沉赛道，抖音坚持独立品牌，形成了不同的调性
- **局限性**：他的框架来自一个成功案例（抖音 vs 火山）的后见之明。他无法证明"如果抖音也从头条导量，但选择不同的品牌和运营，会不会也成功"。人群选择在事后看似乎清晰，但事前没有可靠的判断标准。对于一个新社区来说，"选择哪个起点人群"和"这个人群能不能成功"是两个不同的问题——他更多解释了"为什么选对了"，而不是"怎么选对"。

### 模型3：天花板判断——简单 = 极大

- **一句话**：抖音能做到极大，最核心的原因是足够简单——用户打开后不需要任何选择，上滑即有即时娱乐。抖音最大的竞争对手不是其他短视频 App，而是游戏——争夺的是人们想放松、想杀时间的场景。一个产品能覆盖的本质需求越简单、越普遍，天花板就越高。
- **来源**：[[42章经]] 053 — "抖音最大的竞争对手本质上是游戏" [原话]
- **怎么用**：
  1. 问：你的产品对用户来说，是一个"需要做的决定"还是"不需要思考的本能"？前者有天花板，后者天花板更高
  2. 找真正的竞争对手：不是同类产品的头部，而是争夺同一场景的产品（抖音的对手不是快手，是游戏）
  3. 判断内容适配度：不是所有内容都适合你的分发容器。30 分钟深度视频不适合抖音（用户心智是短平快），攻略图文不适合单列 —— 搞清楚你的容器天然擅长什么，不要什么都想做
- **局限性**："简单"作为增长驱动力的前提是产品已经达到了内容供给的充裕程度——如果没有海量内容和精准推荐，"简单打开"可能意味着"打开即失望"。抖音的简单是建立在极复杂的推荐系统之上的——用户看到的是简单，后台是极端的复杂性。如果你的产品不能承担推荐系统的投入，"简单"可能意味着无趣。此外，"简单 = 极大"在内容消费领域成立，在其他领域（如生产力工具、社交产品）不一定适用。

## 决策启发式

1. **先定人群基底再做事**：内容社区冷启动的第一问题不是产品功能，是选择什么样的起点人群。人群基底决定泛化能力 — [[42章经]] 053
2. **容器决定生态**：单列适合消费效率和商业化，双列适合社区和中长尾。AB test 测得出短期，测不出生态 — [[42章经]] 053
3. **看真正的竞争对手**：不要只看同类产品，要看争夺同一场景的产品。抖音抢的是游戏的时间，不是快手的时间 — [[42章经]] 053
4. **不被"忙碌"骗过**：创业者很容易陷入写文档、修 bug 的成就感，而逃避产品定义、核心人才、资金安排等更难的事。要反自己的思维惰性 — [[42章经]] 053
5. **极致不是优化几个百分点**：字节教会他的是追问"能不能增长两倍、五倍"而不是"能不能优化 5%"。这种追问迫使团队寻找战略级变化 — [[42章经]] 053

## 内在张力 / 盲区

1. **大厂经验到创业的可迁移性**：他自己承认大厂训练的是"具体问题的分析和解决"，创业需要的是"战略选择、资源组织、招人、融资"。但他没有清楚说明他作为一个前抖音 PM 创业时，哪些经验是资产、哪些成了包袱。
2. **社交探索失败的未解之谜**：他提到抖音 2018-2020 年将社交作为重要战略但失败了，并把原因归结为"社交很难被拆成局部指标优化"。但这个反思比较浅——是不是还有其他原因（产品形态、用户心智、内容类型本质不匹配社交）他没有更深一层推演。
3. **信息源密度**：仅一集播客。他的 Lessie AI 创业方向（people search agent）刚起步，所有创业心得来自"创业第一年"的体感，不是来自"创业成功/失败后"的反思。
4. **利益立场**：作为 AI 创业者，他对 "AI 时代小公司机会" 的叙事有直接商业利益。他对字节文化的正面描述和对他自己公司方向的乐观判断，都应放在这个背景中理解。
