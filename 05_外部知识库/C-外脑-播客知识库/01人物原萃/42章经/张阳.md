# 张阳

## 画像

- **身份**：Answer.AI 联合创始人
- **背景**：经验涵盖出海产品、增长、商业化。上一段创业做社交方向。Answer.AI 一年内做到北美 AI Tutor 细分领域用户量与收入第一，2023 年破百万注册用户
- **标签**：AI 教育出海 / PMF 三段论 / 用户研究实战派 / 增长=商业化双轮驱动

## 擅长 & 不擅长

- **擅长**：AI 教育产品的 PMF 验证路径——用"三段论"精确判断产品状态；出海产品的用户研究实操（自己跑用户的笨功夫）；增长和商业化的协同设计（先赚钱再做规模的逻辑）
- **不擅长**：底层模型训练（他们是应用层）；非北美市场（坚定第一选择只看北美）；大规模品牌型增长（他的增长方法论集中在投放+自然增长的产品设计）

## 核心心智模型

### 模型1：PMF 三段论——第三段才是真的

- **一句话**：PMF 有三个层次，大多数人高估了自己。第一段：产品团队内部跑通（"我们觉得好"）→ 第二段：用户免费用得开心 → 第三段：用户愿意持续付费——第三段才是真正的 PMF，决定长期增长力和获客效率。
- **来源**：[[42章经]] 013 — "PMF 三段论：实验室跑通、免费用户留存好、付费用户愿意持续付钱——第三段才是真正的 PMF。" [原话]
- **怎么用**：
  1. 诚实自检——你现在在第几段？如果还在第一段，不要开始做增长
  2. 第二段到第三段的跨越是最难的：免费用着开心和愿意持续付钱之间有一道用户心理鸿沟
  3. 多邻国模型：核心付费用户在美国，免费用户在三四线国家——有钱人付费养免费教育飞轮
  4. 付费留存是 PMF 的最终确认信号——不再看注册量，看付费续费率
- **局限性**：三段论更适合效率/工具类产品——用户愿意付钱意味着解决了明确痛点。但对于社交/内容平台，付费不是核心信号——用户留存本身就是信号。此外，"第三段才是真的"可能在早期扼杀一些需要先有规模才能商业化的产品。

### 模型2：出海产品——通用性高于本地化

- **一句话**：最好的国际化产品底层是通用的——TikTok、Facebook、Instagram 全都用同一套产品逻辑。本地化主要在内容层、运营层、UI 细节。中国团队出海强项是 ToC 产品力+增长力+运营力（全球第一梯队降维打击），弱项是海外组织搭建。
- **来源**：[[42章经]] 013 — "好的国际化产品应该是通用的——TikTok、Facebook、Instagram 全都是同一套产品逻辑。" [原话]
- **怎么用**：
  1. 先确保核心产品逻辑是跨文化的——如果产品只在一种文化里通，想办法把它抽象到通用层
  2. 本地化投入只在"确实阻碍了使用"的地方——如印度用户不认识 icon 要加文字标签
  3. 用户研究自己做，不要找第三方——他曾在印度找的"高活用户"是中介临时注册的演员
  4. 5 人以内不必肉身出海（远程问卷+Discord 够用），5-10 万 DAU 当地至少需要一个长期配合的人
- **局限性**："全球同一套产品逻辑"的案例都来自巨型社交/内容平台——对于垂直工具类产品（如 AI Tutor），文化差异可能比想象中大。美国和印度的教育需求完全不同。他的方法论在 Answer.AI 上成功了，但时间太短（一年），可能是产品好而非方法论对。

### 模型3：AI 时代用户输入——人机交互史上最大的变化

- **一句话**：LLM 让用户第一次愿意写"小作文级 prompt"并持续追问——这是历史上人机交互输入量最大的一次变化。AI 产品设计的核心命题变成"如何更好激发用户输入 + 把输入用起来"。
- **来源**：[[42章经]] 013 — "AI 时代最大的变化是：用户输入意愿和输入量前所未有地放大。" [原话]
- **怎么用**：
  1. 重新设计产品的"输入体验"——不是填表单、不是点按钮，而是让用户用自然语言描述需求
  2. 下一代推荐系统可以基于长 prompt 做精准推荐——比行为数据准得多
  3. 用户参与创作门槛崩塌——"一句人话 = 一段可消费内容"
  4. 关键是让用户有"终于被理解了"的正反馈——Answer.AI 用户的核心体验是"终于敢提问+持续追问"
- **局限性**：长 prompt 输入适合 AI Tutor 这类天然需要用户表达的场景——但不是所有产品都能激发高质量输入。如果你的产品是"一键生成"，用户根本不需要写长 prompt——这个洞察的适用范围有限。此外，用户输入数据的隐私和存储是新的技术挑战。

## 决策启发式

1. **先赚钱再做规模**：上一代出海是"先做 DAU 再变现"；这一代必须顺序反过来。商业化能力是兜底——让你敢投放、敢冒险、敢试错 — [[42章经]] 013
2. **第一选择只看北美**：单一、大体量、付费习惯成熟。大胆做订阅、区分免费 vs 付费体验 — [[42章经]] 013
3. **增长会给你幻觉，克制是关键**：便宜买量带来的爆发感像追高——产品生态未必接得住。涨的时候要多想为什么涨、能不能接住 — [[42章经]] 013
4. **教育不是反人性的**：不要被"学习反人性"的叙事绑架。好的教育让你学完很开心——多邻国证明了。AI Tutor 打掉了不敢举手、不敢去办公室的心态门槛 — [[42章经]] 013
5. **做得垂、做得深就吃不掉**：Flashcard、个性化练习、跨步交互、Tutor 体验——这些不是 ChatGPT 通用版能提供的。大家一边担心模型万能、一边把模型用得很薄 — [[42章经]] 013

---

## 内在张力 / 盲区

1. **"通用产品逻辑"与"做得垂就吃不掉"的内在矛盾**：一方面说最好的产品是通用的、不需要大量本地化，另一方面说做得垂、做得深就吃不掉。这两条叙事同时为真时，意味着必须同时做到"底层通用+场景垂深"——这个要求极高，大多数创业团队做不到。
2. **印度调研踩坑的"幸存者事后总结"**：他在印度被中介骗了几千块找假用户——这是一个很好的故事，但"自己做用户研究"的结论可能 over-fit 了这次经历。第三方调研的问题不是"第三方不可靠"，而是"你自己不跟踪"。一个有经验的产品经理可以用第三方但不被坑——他可能从一次失败中得出了一个过于绝对的结论。
3. **一年北美 Top 1 的可持续性未知**：Answer.AI 的增长在 2023 年——AI 教育产品的热潮加上 TikTok 投放的红利。当大量竞品涌入、投放成本上升、模型基础能力继续进化时，Answer.AI 是否还能保持 Top 1 是未知数。仅一集访谈，盲区可能未被充分暴露。
