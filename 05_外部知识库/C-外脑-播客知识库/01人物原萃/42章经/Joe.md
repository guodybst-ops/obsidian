# Joe

## 画像

- **身份**：ACE Studio 创始人，时域科技 CEO
- **背景**：2019 年创立时域科技，想让 AI 帮普通人创作音乐。多种产品形态和技术路线探索后，2023 年聚焦专业消费者做 ACE Studio。英语四级没过，几个月把海外业务从零做到几十万美金月收入
- **标签**：AI音乐 / 出海 / 四级没过也出海 / 专业消费者 / 工作流 > 模型 / 歌声AI

## 擅长 & 不擅长

- **擅长**：AI 音乐工具的产品化——从「生成式 AI」到「可编辑工作流」的产品定位；出海获客——特别是从中国市场到 USA 付费用户的转变路径
- **不擅长**：基础 AI 模型研究（他明确说模型壁垒较低，核心在产品）；大众消费级产品（他的定位是专业消费者，非 casual user）

## 核心心智模型

### 模型1：AIGC 产出的是素材而非内容

- **一句话**：AIGC 生成的很多不是内容，而是素材——素材交到创作者手里二次加工，才真正产生价值。AI 音乐的核心差异化不在模型多好，而在后续的编辑工作流
- **来源**：[[42章经]] 021 [原话/归纳]
- **怎么用**：
  1. 分析一个 AIGC 产品：用户拿到生成结果后能做什么？如果只能「接受或重新生成」→ 这是素材产品，天花板是无限生成
  2. 如果能编辑、精修、混合、二次创作 → 这是内容产品，价值锚定在创作者而非模型
  3. Suno 对比：Suno 是 prompt → 85% 好的结果 → 无法精修。ACE Studio 是 85% 好的素材 → 可编辑工作流 → 接近 100% 作品
  4. 模型像城堡（越高越攻不破），产品像野蛮人——城堡墙越高越难，但音乐模型壁垒相对较浅，工作流更重要
- **局限性**：对于「专业消费者」（prosumer）这个定位而言，编辑工作流是有价值的。但对于纯 casual 用户——他们打开 Suno 就是想要一首好听的歌——编辑工作流是负担而不是价值。他的框架低估了「无编辑需求」市场的规模

### 模型2：出海作战手册——四级没过也能打

- **一句话**：出海不是泛泛海外，是攻克 USA 这个付费用户高地。英语不好不是障碍——关键是要站到用户所在的真实土壤上
- **来源**：[[42章经]] 021 [归纳]
- **怎么用**：
  1. 目标国家定 USA 而非泛泛海外——付费率差异巨大（国内 1-1.5%，海外 15%）
  2. 出海第一步：找到目标用户的流量阵地——对 ACE Studio 是 YouTube + Instagram（洛杉矶音乐圈把 IG 当微信）
  3. 参加行业展会——他参加 NAMM 音乐展是转折点，现场演示获得格莱美级音乐人背书
  4. 北极星指标改为付费率、ARPU、ARR，而非 Day 1 的 DAU
  5. 心态：起床那一下最难但起来后会爽
- **局限性**：他的出海经验高度绑定在 AI 音乐这个品类——洛杉矶音乐圈天然聚集在 IG 和 NAMM。不同品类的出海路径可能完全不同。而且他的产品形态允许他用英文 UI 加英文文档就能出海——不一定适用于高度本地化需求的产品

### 模型3：专业消费者定位——大众产品或小众高价值产品

- **一句话**：面向专业消费者（prosumer）而非 casual user。这些用户愿意为专业工具付费——海外付费率约 15%（远高于国内的 1-1.5%），且是订阅 + 循环扣款
- **来源**：[[42章经]] 021 [归纳]
- **怎么用**：
  1. 判断你的 AI 产品是服务 casual user（量大但付费意愿低）还是 prosumer（量小但付费意愿高）
  2. Casual user 做：靠量、广告、流量变现
  3. Prosumer 做：靠订阅、专业工作流、高 ARPU——国内起步也可以但 ROI 低，海外 prosumer 付费更成熟
- **局限性**：这个模型的隐前提是「prosumer 市场够大」——音乐制作领域确实存在，但在其他品类（如写作、视频）prosumer 的定义可能更模糊，市场规模可能不足

## 决策启发式

1. **AI 音乐的核心差异化不在模型在编辑工作流**：模型给你 85%，剩下的 15% 靠编 — [[42章经]] 021
2. **出海的目标国 = USA，不是泛泛海外**：国内付费率 1-1.5%，海外 15%——差距是十倍 — [[42章经]] 021
3. **站到用户所在的真实土壤上**：关键是找到他们的流量阵地（IG、YouTube、行业展会），不是坐在家里幻想 — [[42章经]] 021
4. **四级没过也可以赚美国人的钱**：英语不是障碍，障碍是你不去做 — [[42章经]] 021 and 037
5. **走出去之后立刻世界变不同了**：像起床——起来那一下最难，但起来后很爽 — [[42章经]] 021

## 内在张力 / 盲区

1. **出海的幸存者偏差**：他的出海故事很激励人——但他只讲了自己成功的部分。多少同品类 AI 音乐公司也出海了但没成功？他没有讨论这个背景概率
2. **专业消费者定位的天花板**：如果他定义的 prosumer 是「会用 DAW、需要编辑音乐的人」，这个群体的天花板有多高？ACE Studio 的月收入在几十万美金级别——作为一家公司这个数字完全说得过去，但作为「AI 音乐改变世界」的叙事，体量有限
3. **模型壁垒到底有多低？** 他认为音乐模型壁垒较低、工作流更重要。但如果 Suno/Udio 持续提升生成质量直至逼近「几乎不需要编辑」的程度——他的编辑工作流差异化就被消解了
