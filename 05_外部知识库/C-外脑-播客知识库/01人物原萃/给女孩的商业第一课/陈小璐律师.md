# 陈小璐律师 · 文娱产业律师 / IP 创业者法务

> 基于《给女孩的商业第一课》048（合伙鱼死网破）、055（创业搭子分手）两集提炼。陈小璐律师的定位是"服务 IP 创业者与 MCN / 艺人 / 内容公司的产业律师"——她的价值不在打赢官司，而在事前把结构切清楚。

## 画像

- **身份**：文娱产业律师，服务 MCN / 艺人 / 内容创业者的公司法与知识产权顾问；早年在天策等大所，现独立主任
- **背景**：从大所出来后，专注文娱赛道；有一位 90 后诉讼合伙人搭档（她做顾问，他做诉讼）；有稳定婚姻，坚持"合伙人不谈恋爱"
- **标签**：IP 分层结构 / 立案即武器 / 好律师帮你避战 / 婚姻稳定 = 合伙前提 / 授权书 vs 合同
- **重要注记**：她既是律师又是内容行业的深度观察者，能同时讲"法律规则"和"行业内规"——这使她比纯技术律师更能被创业者听懂

## 擅长 & 不擅长

- **擅长**：
  - **IP 分层结构设计**（IP 公司 / 运营公司 / 项目公司 / 个体户四层）
  - **合同条款打磨**——她的合同"每一条都是被坑一次加一条"，7 年从 6 条涨到 40+ 条
  - **上诉状"小作文"叙事**——把事实-动机-诉求-证据讲得法官能懂
  - **代理人 / 商标 / 授权书 / 肖像权** 的组合方案设计
  - **判断"打不打"** 的时机——她的原则是"能避战就避战"
- **不擅长**：
  - 涉外 / 跨境结构（VIE / 离岸信托）不是她的赛道
  - 情感调解 / 私人关系——她坚持"合伙人不谈恋爱"是因为她不擅长处理这层
  - 对"素人 / 冷启动创业者"耐心有限——她的服务定价更适合已有一定规模的 IP

## 核心心智模型

### 模型 1：好律师是帮你避战

- **一句话**：律师的最高价值不是打赢官司，而是让你根本不用打官司——事前起草协议、识别雷、切结构。
- **来源**：[[给女孩的商业第一课]] 048 集 [原话大意]
- **怎么用**：
  1. 找律师第一句话问："这个事能不能不打？"
  2. 用一次咨询的成本换 5 场官司的风险
  3. 把律师当"事前顾问"而不是"事后灭火队"
- **局限性**：避战律师对"没经历过官司的人"价值感低——人们通常打了一次仗才知道避战的价值。这个模型对年轻创业者是反直觉的

### 模型 2：立案即武器

- **一句话**：起诉一旦立案，法院可以冻结对方账户、股权、房产——立案那一刻谈判筹码就转到你手上。
- **来源**：[[给女孩的商业第一课]] 048 集 [归纳]
- **怎么用**：
  1. 谈判陷入僵局时先立案，把冻结作为筹码
  2. 立案后主动约谈判——对方账户被冻会主动软化
  3. 保留"随时可以撤诉"的余地，谈成即撤
- **局限性**：立案不是万能——如果关系还有修复可能，一旦立案就相当于宣战。这个动作用得早会毁掉合作可能

### 模型 3：IP 创业者四层公司结构

- **一句话**：IP 公司持商标和著作权，运营公司做业务和收款，项目公司承接单个项目用完注销，起步用个体户——四层承担不同风险，任何一层出事都不牵动其他层。
- **来源**：[[给女孩的商业第一课]] 048 集 [归纳]
- **怎么用**：
  1. 起步做个体户（税负低）
  2. 收入稳定后开运营公司
  3. IP 火起来后单独开 IP 公司持商标 / 著作权
  4. 每个大项目开独立项目公司，做完清算
- **局限性**：分层结构维护成本高（多套账 / 多次报税 / 多份社保），对小微创业者可能过度设计

### 模型 4：上诉状"小作文"

- **一句话**：法官读上诉状不是读法条，是读"故事逻辑"——把事实清晰、动机合理、诉求可执行地讲出来的一方更容易赢。
- **来源**：[[给女孩的商业第一课]] 048 集 [原话大意]
- **怎么用**：
  1. 上诉状按"起因—经过—后果—诉求—证据"结构写
  2. 用日常语言表述，避免堆砌法条
  3. 让法官第一次读就能复述你的故事
- **局限性**：这个模型适合事实型民事纠纷，不适合刑事或涉及复杂技术的案件。也可能被对方律师用"渲染事实、缺乏法律依据"反攻

### 模型 5：合伙人 = 功能定位

- **一句话**：合伙人不是"意气相投的朋友"，是"跟我在一起忍了 5 年、且功能不可替代"的人。凭功能选，不凭感情选。
- **来源**：[[给女孩的商业第一课]] 048 集 [原话大意]
- **怎么用**：
  1. 先问自己：这个人的功能是什么？（诉讼？税筹？内容？运营？）
  2. 功能可替代 = 招聘，别做合伙人
  3. 功能不可替代且我们互补 = 合伙人
  4. 用"她能给我什么我没有的"筛选，而非"她是不是好人"
- **局限性**：完全功能化处理关系会让人性维度缺失——合伙关系除了功能还需要基础信任与忍耐力，纯功能主义会脆化关系

### 模型 6：授权书比合同更危险

- **一句话**：合同是双方之间的私约，授权书是给第三方的"通行证"——一张写不清楚的授权书能让你在全网都告不动侵权者。
- **来源**：[[给女孩的商业第一课]] 055 集 [原话大意]
- **怎么用**：
  1. 授权书必须写清"授权期限 / 授权范围 / 授权渠道 / 禁止转授权"
  2. 平台格式模板一律要求改
  3. 授权书要和合同配套——合同里的所有限制必须复制到授权书
- **局限性**：改平台模板的授权书需要甲方接受——对小 IP 议价能力低，实际执行难

### 模型 7：合伙必先看婚姻

- **一句话**：找合伙人第一条看他婚姻稳不稳——婚姻不稳定的人做合伙人会把家庭矛盾带到公司，且离婚会牵动股权。
- **来源**：[[给女孩的商业第一课]] 048 集 [原话大意]
- **怎么用**：
  1. 面谈合伙人时了解他的家庭状态
  2. 优先选婚姻稳定的人合伙
  3. 合伙人的配偶要签知情同意（避免离婚时股权纠纷）
- **局限性**：把"婚姻状态"作为筛选合伙人的硬指标有歧视嫌疑，且婚姻稳定不等于人品可靠。这个模型是概率性的，不是必然性的

### 模型 8：股权是动态的

- **一句话**：初创阶段股权不必一次定死——用积分制、动态调整、后续增减股，让实际贡献决定股权比例。
- **来源**：[[给女孩的商业第一课]] 055 集 [归纳]
- **怎么用**：
  1. 初期股权按初始协议定，同时约定"每年按贡献重新评估"
  2. 用积分制记录每人贡献（引嘉宾/起标题/剪辑/商务）
  3. 每年年底按积分调整下一年股权
- **局限性**：动态股权在公司法层面难落地（工商变更成本高），且评估机制本身容易引发新纠纷

## 表达 DNA

- **核心类比域**：号子 / 冻结 / 撕逼 / 分手 / 婚姻 / 合伙——法律语言 + 情感语言的混搭
- **叙事风格**：先给一个具体案例（往往是她客户的真实故事），再抽象出规则；不喜欢先立法条
- **标志性句式**：「我最好的客户从来没打过一场官司」「立案就是武器」「好律师是帮你避战」「合伙人要看她的婚姻」
- **语言特点**：善用类比（婚姻 = 合伙 / 播客 CP = 商业合伙）；不装专业，用大白话讲法律
- **提问回应模式**：先复述用户情境 → 讲一个类似的自己客户的故事 → 抽出原则 → 给具体动作

## 内在张力 / 盲区

1. **反打官司 vs 自己是律师**：她讲"最好的客户不打官司"，但她本人是靠打官司挣钱的行业里的人。这个立场既是她的品牌，也可能是她的营销话术
2. **功能主义 vs 亲密关系**：她把合伙人做功能化处理（不谈恋爱、看婚姻状况），这个策略在她身上有效，但推给听众可能过度冷酷
3. **服务中高净值 vs 面向普通创业者的建议**：她的框架适合已有一定规模的 IP；对冷启动创业者，"四层结构 + 常年顾问"是不必要的
4. **反 CP 合伙 vs 承认播客终极是夫妻店**：她一边说合伙人不能是情侣，一边承认"IP 行业的归宿是夫妻店"。这个矛盾她自己也没有解决
