# 谢无敌

## 画像

谢无敌是《平民创业手册》071 集嘉宾，主要围绕小红书流量、家居行业、小红书与抖音差异、直播、电商、品牌投放和普通人入局路径与杨涛对谈。

## 核心贡献

- 强调做平台前先判断客户在哪里，不同平台用户画像不同。
- 把小红书理解为围绕精准用户创作、低粉也能变现的平台。
- 提出小红书内容形态更适合新手从图文、live 图、短视频多形式切入。
- 将小红书打法分成付费投放派、低成本引流派、人设 IP 派三种路径。
- 对品牌投放提出分层判断：不同量级品牌在素人、腰部、头部和明星博主上的投放目标不同。
